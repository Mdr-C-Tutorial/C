# 习题配套文件

本目录的文件用于第 3 章的习题，除 `inc_demo/` 与 `stats/` 外都是单文件程序。

| 文件 | 用途 |
| --- | --- |
| `three_errors.c` | 第 6 节与习题 20302：三处错误分别由预处理、编译、链接阶段报告 |
| `missing_semi.c` | 第 6 节：少一个分号引起的连锁诊断 |
| `wformat_mingw.c` | 第 7 节：MinGW GCC 13.2 对 `%zu` 的格式警告 |
| `inc_demo/` | 第 2 节：`-I` 与包含目录 |
| `stats/` | 习题 20306：缺少 `-I` 与缺少 `-lm` 的两次失败 |
| `static_scale/` | 习题 20307：`static` 函数无法被其他翻译单元链接 |
