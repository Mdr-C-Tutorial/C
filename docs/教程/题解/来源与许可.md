# 习题来源与许可

本页仅记录外部题型的来源、许可和主要改动。题面、接口、解析和参考实现均由本教程重新编写。

## 题目

- <span id="10716"></span>**10716 通用稳定排序** — [MIT 6.087 Assignment 4](https://ocw.mit.edu/courses/6-087-practical-programming-in-c-january-iap-2010/pages/assignments/)（CC BY-NC-SA 4.0）；改写为带失败契约的稳定通用排序接口。
- <span id="11413"></span>**11413 完整读取一行** — [MIT 6.087 Assignment 3](https://ocw.mit.edu/courses/6-087-practical-programming-in-c-january-iap-2010/pages/assignments/)（CC BY-NC-SA 4.0）；重写动态存储、流状态和输出保持语义。
- <span id="11414"></span>**11414 合并多个文件** — [MIT 6.087 Assignment 3](https://ocw.mit.edu/courses/6-087-practical-programming-in-c-january-iap-2010/pages/assignments/)（CC BY-NC-SA 4.0）；改写为逐资源获取、统一释放并区分错误类别的接口。
- <span id="11501"></span>**11501 环形缓冲区** — [Exercism：Circular Buffer](https://github.com/exercism/c/tree/main/exercises/practice/circular-buffer)（MIT）；重写接口、边界条件和复杂度要求。
- <span id="11502"></span>**11502 可增长字节缓冲区** — [NIST Juliet C/C++ 1.3](https://samate.nist.gov/SARD/test-suites/112)（[CC0 1.0](https://creativecommons.org/publicdomain/zero/1.0/)）；把分配大小溢出测试改写为缓冲区接口题。
- <span id="11603"></span>**11603 英语全字母句** — [Exercism：Pangram](https://github.com/exercism/c/tree/main/exercises/practice/pangram)（MIT）；重写接口并补充字符处理的可移植性要求。
- <span id="11604"></span>**11604 游程编码** — [Exercism：Run-Length Encoding](https://github.com/exercism/c/tree/main/exercises/practice/run-length-encoding)（MIT）；重写编码文法、错误处理和内存要求。
- <span id="11802"></span>**11802 统计不同值** — [CSES：Distinct Numbers](https://cses.fi/problemset/task/1621/)（[CC BY-NC-SA 4.0](https://new.cses.fi/problemset/text/2433)）；改为 `int64_t` 数组接口并限定使用 `qsort`。
- <span id="11904"></span>**11904 十亿秒后的时刻** — [Exercism：Gigasecond](https://github.com/exercism/c/tree/main/exercises/practice/gigasecond)（MIT）；改为无时区公历接口并补充日期校验。
- <span id="20001"></span>**20001 不透明整数栈 ADT** — Pat Morin 的 [Open Data Structures](https://opendatastructures.org/)（[CC BY 2.5 Canada](https://creativecommons.org/licenses/by/2.5/ca/)）；改写为不透明 C 接口并补充失败保证。
- <span id="20002"></span>**20002 顺序表区间插入与删除** — Pat Morin 的 [Open Data Structures](https://opendatastructures.org/)（[CC BY 2.5 Canada](https://creativecommons.org/licenses/by/2.5/ca/)）；改写为 C 区间操作并补充溢出与重叠规则。
- <span id="20003"></span>**20003 单链表所有权** — [MIT 6.087 Assignment 5](https://ocw.mit.edu/courses/6-087-practical-programming-in-c-january-iap-2010/pages/assignments/)（CC BY-NC-SA 4.0）；补充不透明接口、尾指针不变式和所有权约定。
- <span id="20004"></span>**20004 开放寻址字符串集合** — Pat Morin 的 [Open Data Structures](https://opendatastructures.org/)（[CC BY 2.5 Canada](https://creativecommons.org/licenses/by/2.5/ca/)）；改写为拥有字符串副本的不透明 C 接口。
- <span id="20409"></span>**20409 二分下界** — [Exercism：Binary Search](https://github.com/exercism/c/tree/main/exercises/practice/binary-search)（MIT）；改为下界查询并补充区间与溢出要求。
- <span id="20410"></span>**20410 最短生产时间** — [CSES：Factory Machines](https://cses.fi/problemset/task/1620/)（[CC BY-NC-SA 4.0](https://new.cses.fi/problemset/text/2433)）；改为 `uint64_t` 接口并补充溢出处理。
- <span id="20503"></span>**20503 最多可看电影** — [CSES：Movie Festival](https://cses.fi/problemset/task/1629/)（[CC BY-NC-SA 4.0](https://new.cses.fi/problemset/text/2433)）；改为原地排序接口并补充区间校验。
- <span id="20603"></span>**20603 编辑距离** — [CSES：Edit Distance](https://cses.fi/problemset/task/1639/)（[CC BY-NC-SA 4.0](https://new.cses.fi/problemset/text/2433)）；改为任意字节序列接口并压缩为一行存储。
