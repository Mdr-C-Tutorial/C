# 习题来源与许可

本页仅记录外部题型的来源、许可和主要改动。题面、接口、解析和参考实现均由本教程重新编写。

## 题目

- <span id="10803"></span>**10803 通用稳定排序** — [MIT 6.087 Assignment 4](https://ocw.mit.edu/courses/6-087-practical-programming-in-c-january-iap-2010/pages/assignments/)（CC BY-NC-SA 4.0）；改写为带失败契约的稳定通用排序接口。
- <span id="11006"></span>**11006 位域样式的可移植编码** — 《C Primer Plus（第 6 版）》第 15 章编程练习 6～7（Pearson © 2014；中文版 © 2015，保留所有权利）；仅借鉴位字段与掩码对照考点，题面、布局、接口和答案均独立编写。
- <span id="11005"></span>**11005 传感器批次汇总** — 《C Primer Plus（第 6 版）》第 14 章编程练习 6（Pearson © 2014；中文版 © 2015，保留所有权利）；仅借鉴重复记录聚合考点，题面、数据模型、接口和答案均独立编写。
- <span id="11308"></span>**11308 完整读取一行** — [MIT 6.087 Assignment 3](https://ocw.mit.edu/courses/6-087-practical-programming-in-c-january-iap-2010/pages/assignments/)（CC BY-NC-SA 4.0）；重写动态存储、流状态和输出保持语义。
- <span id="11314"></span>**11314 合并多个文件** — [MIT 6.087 Assignment 3](https://ocw.mit.edu/courses/6-087-practical-programming-in-c-january-iap-2010/pages/assignments/)（CC BY-NC-SA 4.0）；改写为逐资源获取、统一释放并区分错误类别的接口。
- <span id="11315"></span>**11315 灰度字符画降噪** — 《C Primer Plus（第 6 版）》第 13 章编程练习 12、14（Pearson © 2014；中文版 © 2015，保留所有权利）；仅借鉴数字图像与邻域降噪考点，题面、滤波规则、接口和答案均独立编写。
- <span id="11101"></span>**11101 环形缓冲区** — [Exercism：Circular Buffer](https://github.com/exercism/c/tree/main/exercises/practice/circular-buffer)（MIT）；重写接口、边界条件和复杂度要求。
- <span id="11102"></span>**11102 可增长字节缓冲区** — [NIST Juliet C/C++ 1.3](https://samate.nist.gov/SARD/test-suites/112)（[CC0 1.0](https://creativecommons.org/publicdomain/zero/1.0/)）；把分配大小溢出测试改写为缓冲区接口题。
- <span id="10903"></span>**10903 英语全字母句** — [Exercism：Pangram](https://github.com/exercism/c/tree/main/exercises/practice/pangram)（MIT）；重写接口并补充字符处理的可移植性要求。
- <span id="10905"></span>**10905 游程编码** — [Exercism：Run-Length Encoding](https://github.com/exercism/c/tree/main/exercises/practice/run-length-encoding)（MIT）；重写编码文法、错误处理和内存要求。
- <span id="10906"></span>**10906 字符串列表多视图排序** — 《C Primer Plus（第 6 版）》第 11 章编程练习 11（Pearson © 2014；中文版 © 2015，保留所有权利）；仅借鉴多种字符串次序考点，题面、比较规则、接口和答案均独立编写。
- <span id="11202"></span>**11202 统计不同值** — [CSES：Distinct Numbers](https://cses.fi/problemset/task/1621/)（[CC BY-NC-SA 4.0](https://new.cses.fi/problemset/text/2433)）；改为 `int64_t` 数组接口并限定使用 `qsort`。
- <span id="12004"></span>**12004 十亿秒后的时刻** — [Exercism：Gigasecond](https://github.com/exercism/c/tree/main/exercises/practice/gigasecond)（MIT）；改为无时区公历接口并补充日期校验。
- <span id="30001"></span>**30001 不透明整数栈 ADT** — Pat Morin 的 [Open Data Structures](https://opendatastructures.org/)（[CC BY 2.5 Canada](https://creativecommons.org/licenses/by/2.5/ca/)）；改写为不透明 C 接口并补充失败保证。
- <span id="30002"></span>**30002 顺序表区间插入与删除** — Pat Morin 的 [Open Data Structures](https://opendatastructures.org/)（[CC BY 2.5 Canada](https://creativecommons.org/licenses/by/2.5/ca/)）；改写为 C 区间操作并补充溢出与重叠规则。
- <span id="30003"></span>**30003 单链表所有权** — [MIT 6.087 Assignment 5](https://ocw.mit.edu/courses/6-087-practical-programming-in-c-january-iap-2010/pages/assignments/)（CC BY-NC-SA 4.0）；补充不透明接口、尾指针不变式和所有权约定。
- <span id="30004"></span>**30004 开放寻址字符串集合** — Pat Morin 的 [Open Data Structures](https://opendatastructures.org/)（[CC BY 2.5 Canada](https://creativecommons.org/licenses/by/2.5/ca/)）；改写为拥有字符串副本的不透明 C 接口。
- <span id="30005"></span>**30005 可替换的整数序列后端** — 《C Primer Plus（第 6 版）》第 17 章编程练习 2～3（Pearson © 2014；中文版 © 2015，保留所有权利）；仅借鉴同一列表接口替换表示的考点，题面、ADT、两种实现和答案均独立编写。
- <span id="30509"></span>**30509 二分下界** — [Exercism：Binary Search](https://github.com/exercism/c/tree/main/exercises/practice/binary-search)（MIT）；改为下界查询并补充区间与溢出要求。
- <span id="30510"></span>**30510 最短生产时间** — [CSES：Factory Machines](https://cses.fi/problemset/task/1620/)（[CC BY-NC-SA 4.0](https://new.cses.fi/problemset/text/2433)）；改为 `uint64_t` 接口并补充溢出处理。
- <span id="30603"></span>**30603 最多可看电影** — [CSES：Movie Festival](https://cses.fi/problemset/task/1629/)（[CC BY-NC-SA 4.0](https://new.cses.fi/problemset/text/2433)）；改为原地排序接口并补充区间校验。
- <span id="30803"></span>**30803 编辑距离** — [CSES：Edit Distance](https://cses.fi/problemset/task/1639/)（[CC BY-NC-SA 4.0](https://new.cses.fi/problemset/text/2433)）；改为任意字节序列接口并压缩为一行存储。
