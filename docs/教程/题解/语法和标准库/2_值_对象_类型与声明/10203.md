# 10203：判断整数的奇偶性

## 题目


写出能判断 `int x` 是否为偶数的布尔表达式：当 `x` 为偶数时结果为 `true`，否则为 `false`。要求对 `0`、`1`、`2`、`-3` 等若干输入分别给出该表达式的求值结果。

## 解析

```c
(x % 2) == 0
```

也可以封装为函数：

```c
#include <stdbool.h>

static bool is_even(int x) {
    return (x % 2) == 0;
}
```

若分别代入题目给出的值：

| `x` | 表达式结果 |
|---:|---|
| `0` | `true` |
| `1` | `false` |
| `2` | `true` |
| `-3` | `false` |
