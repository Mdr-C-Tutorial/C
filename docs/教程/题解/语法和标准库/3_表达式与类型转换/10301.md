# 10301：优先级与括号

## 题目


写一个程序，分别计算并输出以下表达式的结果：

1. `3 + 2 * 5`
2. `(3 + 2) * 5`

要求：解释为什么这两个结果不同（从“运算符优先级与括号”角度回答）。

## 解析

乘法的优先级高于加法，所以第一个表达式等价于 `3 + (2 * 5)`。第二个表达式中的括号要求先完成加法。

优先级决定表达式如何分组，不等同于规定各子表达式的实际求值先后。

## 解析

```c
#include <stdio.h>

int main(void) {
    int first = 3 + 2 * 5;
    int second = (3 + 2) * 5;

    printf("%d\n", first);
    printf("%d\n", second);
    return 0;
}
```

输出：

```text
13
25
```
