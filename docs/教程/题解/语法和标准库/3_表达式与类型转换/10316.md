# 10316：拆分前缀与后缀递增

## 题目


判断下列代码是否是 UB；如果是，改写为无 UB 的版本：

```c
int i = 0;
int x = ++i + i++;
```

## 解析

前缀递增和后缀递增都会修改 `i`。`+` 不规定两个操作数的求值次序，因此这两次修改彼此未排序，原代码具有未定义行为。

未定义行为没有需要保留的标准结果。改写必须明确选择一种执行次序。下面采用先完成左操作数的意图。

## 解析

```c
int i = 0;

int left = ++i;
int right = i++;
int x = left + right;
```

最终得到：

```text
left == 1
right == 1
i == 2
x == 2
```
