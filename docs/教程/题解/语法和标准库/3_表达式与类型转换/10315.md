# 10315：值计算与副作用

## 题目

判断 `1 + 2`、`i += 1` 和 `i++` 是否一定产生副作用。

## 解析

| 表达式 | 是否产生副作用 | 副作用 |
|---|---|---|
| `1 + 2` | 否 | 只计算值 3。 |
| `i += 1` | 是 | 读取 `i`、加 1，并把结果存回 `i`。 |
| `i++` | 是 | 产生递增前的值，同时把 `i` 增加 1。 |

## 解析

“表达式有结果”并不等于“表达式有副作用”。副作用关注的是执行状态或可观察行为是否改变。加法常量表达式不改变状态，两个更新运算则都会修改 `i`。

`i += 1` 的值是更新后的 `i`；`i++` 的值是更新前的 `i`。二者都产生副作用，但值语义不同。
