# 10308：温度换算与 BMI

## 题目

编写程序完成摄氏温度到华氏温度的换算，并计算 BMI。

## 解析

1. 摄氏温度转华氏温度：$F=C\times 9/5+32$。
2. BMI：$\mathrm{BMI}=w/h^2$，其中 `w` 是千克数，`h` 是米数。

## 解析

### 温度换算

```c
#include <stdio.h>

int main(void) {
    double celsius = 25.0;
    double fahrenheit = celsius * 9.0 / 5.0 + 32.0;

    printf("%.2f C = %.2f F\n", celsius, fahrenheit);
    return 0;
}
```

结果为 `25.00 C = 77.00 F`。

### BMI

```c
#include <stdio.h>

int main(void) {
    double height_metres = 1.75;
    double weight_kilograms = 68.0;

    if (height_metres <= 0.0) {
        return 1;
    }

    double bmi =
        weight_kilograms /
        (height_metres * height_metres);

    printf("BMI = %.2f\n", bmi);
    return 0;
}
```

结果约为 `BMI = 22.20`。
