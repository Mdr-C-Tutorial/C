# 10304：修复未排序的两次修改

## 题目


阅读并判断：以下代码是否具有未定义行为 (Undefined Behavior, UB)？若有，请指出原因并写出一个等价且无 UB 的版本。

```c
int i = 0;
int x = i++ + ++i;
```

## 解析

后缀递增和前缀递增都会修改 `i`。二元 `+` 不规定先求左操作数还是右操作数，这两次修改彼此未排序，因此原表达式具有未定义行为。

未定义行为没有可依赖的“原结果”。改写时必须先选定一种明确次序。下面采用从左到右完成原意的方式。

## 解析

```c
int i = 0;

int left = i;
++i;

++i;
int right = i;

int x = left + right;
```

也可以更直接地写成：

```c
int i = 0;

int left = i++;
int right = ++i;
int x = left + right;
```

两种改写最终都得到 `i == 2`、`x == 2`。
