# 10803：通用稳定排序

## 题目


实现使用函数指针比较元素的通用稳定排序：

```c
#include <stdbool.h>
#include <stddef.h>

typedef int (*CompareFn)(const void *left, const void *right);

bool generic_stable_sort(
    void *base,
    size_t count,
    size_t element_size,
    CompareFn compare
);
```

要求：

1. `compare` 的返回值小于、等于或大于 0 时，分别表示左侧元素应排在右侧元素之前、两者等价或左侧元素应排在右侧元素之后。
2. 等价元素排序后的相对次序不得改变。
3. `count` 为 0 时 `base` 可以为 `NULL`；`element_size` 必须大于 0，`compare` 必须有效。
4. 拒绝会使 `count * element_size` 溢出的调用，失败时不得修改数组。
5. 只能按字节交换对象表示，不得假设元素具有某个具体类型。
6. 使用稳定插入排序，额外空间复杂度为 $O(1)$。

## 解析

把数组首地址转换为 `unsigned char *` 后，第 `i` 个元素从 `i * element_size` 字节处开始。先检查这个乘积是否可能溢出，后续地址计算才有意义。

插入排序可以通过不断交换相邻逆序元素完成。只有比较结果大于 0 时才交换；比较结果为 0 时保留原次序，因此排序稳定。逐字节交换不依赖元素的具体类型，也不会违反对象表示的访问规则。

## 解析

```c
#include <stdbool.h>
#include <stddef.h>
#include <stdint.h>

typedef int (*CompareFn)(const void *left, const void *right);

bool generic_stable_sort(
    void *base,
    size_t count,
    size_t element_size,
    CompareFn compare
) {
    if (element_size == 0 || compare == NULL) {
        return false;
    }
    if (count > 0 && base == NULL) {
        return false;
    }
    if (count > SIZE_MAX / element_size) {
        return false;
    }

    unsigned char *bytes = base;

    for (size_t i = 1; i < count; ++i) {
        size_t j = i;

        while (j > 0) {
            unsigned char *left =
                bytes + (j - 1) * element_size;
            unsigned char *right =
                bytes + j * element_size;

            if (compare(left, right) <= 0) {
                break;
            }

            for (size_t k = 0; k < element_size; ++k) {
                unsigned char temporary = left[k];
                left[k] = right[k];
                right[k] = temporary;
            }
            --j;
        }
    }

    return true;
}
```
