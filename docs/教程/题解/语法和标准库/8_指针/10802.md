# 10802：带回调的条件计数

## 题目


实现带回调的条件计数：

```c
#include <stdbool.h>
#include <stddef.h>

typedef bool (*IntPredicate)(int value);

bool count_if_i32(
    const int *items,
    size_t count,
    IntPredicate predicate,
    size_t *out_count
);
```

要求：

1. 成功时按下标递增顺序把每个元素恰好传给 `predicate` 一次，并通过 `out_count` 返回结果。
2. `count` 为 0 时 `items` 可以为 `NULL`，函数应成功并返回计数 0。
3. `predicate` 或 `out_count` 为 `NULL`，以及 `count > 0` 但 `items` 为 `NULL` 时，返回 `false`。
4. 失败时不得修改 `*out_count`。
5. 时间复杂度为 $O(n)$，额外空间复杂度为 $O(1)$。

## 解析

先验证所有参数，再开始遍历。结果先保存在局部对象中，只有完整遍历成功后才写入 `*out_count`，这样所有失败分支都不会破坏调用方原有结果。

`count == 0` 时不进入循环，因此 `items == NULL` 是安全且有明确定义的。`predicate` 和 `out_count` 即使在空数组情况下也必须有效，因为它们属于接口本身的必要组成部分。

## 解析

```c
#include <stdbool.h>
#include <stddef.h>

typedef bool (*IntPredicate)(int value);

bool count_if_i32(
    const int *items,
    size_t count,
    IntPredicate predicate,
    size_t *out_count
) {
    if (predicate == NULL || out_count == NULL) {
        return false;
    }
    if (count > 0 && items == NULL) {
        return false;
    }

    size_t result = 0;
    const int *current = items;

    for (size_t remaining = count; remaining > 0; --remaining) {
        if (predicate(*current)) {
            ++result;
        }
        ++current;
    }

    *out_count = result;
    return true;
}
```
