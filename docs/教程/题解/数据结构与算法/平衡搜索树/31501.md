# 31501 - AVL 树左旋右旋与高度更新原子操作

## 题目描述

实现 AVL 树的左旋（Left Rotation）、右旋（Right Rotation）以及局部结点高度计算原子操作。

```c
#include <stddef.h>
#include <stdint.h>

typedef struct AvlNode AvlNode;

struct AvlNode {
    int64_t key;
    size_t height;
    AvlNode *left;
    AvlNode *right;
};

int64_t balance_factor(const AvlNode *node);
AvlNode *rotate_left(AvlNode *x);
AvlNode *rotate_right(AvlNode *y);
```

要求：

1. 结点高度定义为：空子树高度为 0，单叶子结点高度为 1；任意非空结点高度为其左右孩子高度最大值加 1。
2. 平衡因子计算为：左子树高度减去右子树高度；空结点平衡因子为 0。
3. 旋转操作必须在常数时间 $O(1)$ 内完成，严格维持二叉搜索树的中序遍历键序不变式，并在旋转完成后准确重算两个核心受影响结点的高度。
4. 函数返回旋转后子树的新根结点指针；若传入形参为空或不具备旋转条件（如右旋结点的左孩子为空），安全返回原结点。

## 解题思路

### 1. 旋转的代数拓扑不变式

设结点 $y$ 及其左孩子 $x$，其左、中、右三棵子树分别为 $T_1, T_2, T_3$。二叉搜索树的中序排列满足：

$$T_1 < x < T_2 < y < T_3$$

- **右旋 (`rotate_right(y)`)**：
  将 $x$ 提升为新根，将 $y$ 降为其右孩子。原 $x$ 的右子树 $T_2$ 转移挂接至 $y$ 的左孩子位置：
  `x->right = y; y->left = T_2;`
  变换后的中序顺序仍为 $T_1 < x < T_2 < y < T_3$，全局有序性得到严格保全。
- **左旋 (`rotate_left(x)`)**：
  右旋的完全对称操作。将 $x$ 的右孩子 $y$ 提升为新根，原 $y$ 的左子树 $T_2$ 挂接至 $x$ 的右孩子位置：
  `y->left = x; x->right = T_2;`

### 2. 高度更新的时序约束

旋转仅破坏了旋转轴涉及的两个局部结点 $x$ 与 $y$ 的子树高度，其余所有子树的内部拓扑与高度均保持不变。
- 在右旋后，$y$ 成为了 $x$ 的孩子，因此**必须先更新底层结点 $y$ 的高度，再更新顶层结点 $x$ 的高度**。
- 同理，在左旋后，**必须先更新底层结点 $x$ 的高度，再更新顶层结点 $y$ 的高度**。

## C 语言实现

```c
#include <assert.h>
#include <stdbool.h>
#include <stddef.h>
#include <stdint.h>
#include <stdlib.h>

typedef struct AvlNode AvlNode;

struct AvlNode {
    int64_t key;
    size_t height;
    AvlNode *left;
    AvlNode *right;
};

static size_t node_height(const AvlNode *node) {
    return node == NULL ? 0 : node->height;
}

static size_t max_size(size_t a, size_t b) {
    return a > b ? a : b;
}

static void update_height(AvlNode *node) {
    if (node == NULL) {
        return;
    }
    size_t hl = node_height(node->left);
    size_t hr = node_height(node->right);
    node->height = 1 + max_size(hl, hr);
}

int64_t balance_factor(const AvlNode *node) {
    if (node == NULL) {
        return 0;
    }
    size_t hl = node_height(node->left);
    size_t hr = node_height(node->right);
    return (int64_t)hl - (int64_t)hr;
}

AvlNode *rotate_right(AvlNode *y) {
    if (y == NULL || y->left == NULL) {
        return y;
    }
    AvlNode *x = y->left;
    AvlNode *t2 = x->right;

    x->right = y;
    y->left = t2;

    update_height(y);
    update_height(x);

    return x;
}

AvlNode *rotate_left(AvlNode *x) {
    if (x == NULL || x->right == NULL) {
        return x;
    }
    AvlNode *y = x->right;
    AvlNode *t2 = y->left;

    y->left = x;
    x->right = t2;

    update_height(x);
    update_height(y);

    return y;
}

static AvlNode *create_node(int64_t key) {
    AvlNode *n = (AvlNode *)malloc(sizeof(AvlNode));
    assert(n != NULL);
    n->key = key;
    n->height = 1;
    n->left = NULL;
    n->right = NULL;
    return n;
}

static void free_avl(AvlNode *n) {
    if (n == NULL) {
        return;
    }
    free_avl(n->left);
    free_avl(n->right);
    free(n);
}

int main(void) {
    /* 构造 LL 型失衡子树测试右旋:
            30 (y)
           /
          20 (x)
         /
        10
    */
    AvlNode *y = create_node(30);
    y->left = create_node(20);
    y->left->left = create_node(10);
    update_height(y->left);
    update_height(y);

    assert(node_height(y) == 3);
    assert(balance_factor(y) == 2);

    AvlNode *new_root = rotate_right(y);
    /* 右旋完成后结构:
            20 (new_root)
           /  \
          10   30
    */
    assert(new_root->key == 20);
    assert(new_root->left->key == 10);
    assert(new_root->right->key == 30);
    assert(node_height(new_root) == 2);
    assert(node_height(new_root->left) == 1);
    assert(node_height(new_root->right) == 1);
    assert(balance_factor(new_root) == 0);

    /* 单结点旋转边界安全测试 */
    AvlNode *rr_leaf = rotate_left(new_root->left);
    assert(rr_leaf->key == 10);

    /* 对根执行左旋，使 30 成为新根 */
    AvlNode *rotated_left = rotate_left(new_root);
    assert(rotated_left->key == 30);
    assert(rotated_left->left->key == 20);
    assert(rotated_left->left->left->key == 10);
    assert(node_height(rotated_left) == 3);

    free_avl(rotated_left);
    return 0;
}
```

## 复杂度分析

- **时间复杂度**：左旋与右旋操作仅修改 3 个指针并调用 2 次常数时间的高度重算函数，执行耗时为严格的 $O(1)$。
- **空间复杂度**：旋转操作为就地指针重连，无任何递归或动态内存申请，额外空间复杂度为严格的 $O(1)$。

## 延伸思考 / 模式总结

树旋转是所有平衡二叉搜索树（AVL 树、红黑树、伸展树、Treap）的**通用底层基石**。它在改变树形局部高度的同时，代数上严格维持了中序投影的不变性。牢固掌握旋转对父子指针的改写顺序以及自底向上的属性更新规则，是构建高级平衡树数据结构的前提。
