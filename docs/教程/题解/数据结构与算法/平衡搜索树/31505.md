# 31505 - 红黑树性质验证器

## 题目

实现红黑树（Red-Black Tree）5 条核心定义性质与二叉搜索有序性的完整验证器 `rb_validate_tree`。

```c
#include <stdbool.h>
#include <stddef.h>
#include <stdint.h>

typedef enum {
    RB_RED = 0,
    RB_BLACK = 1
} RbColor;

typedef struct RbNode RbNode;

struct RbNode {
    int64_t key;
    RbColor color;
    RbNode *left;
    RbNode *right;
};

bool rb_validate_tree(const RbNode *root);
```

要求：

1. **性质 1**：每个结点必须拥有明确的颜色属性（`RB_RED` 或 `RB_BLACK`）。
2. **性质 2**：根结点必须为黑色（空树合法，根为 `NULL`）。
3. **性质 3**：所有外部叶子结点（`NULL` 结点）均视为黑色，其黑高为 0。
4. **性质 4**：红色结点的所有子结点必须全为黑色（即树中任意从根向下的简单路径上，绝不允许出现连续两个红色结点）。
5. **性质 5（黑高一致性）**：对于任意结点，从该结点出发到达其所有后代外部空结点的每条简单路径上，包含的黑色结点总数必须严格相等。
6. 结合开区间检验全树的二叉搜索树全局偏序（左小右大），严禁通过加减 1 构造边界防溢出。
7. 单次全树验证时间复杂度为 $O(n)$。

## 解题思路

### 1. 递归黑高聚合与归一化校验

红黑树最关键且复杂的属性是性质 5（黑高一致）。后序递归自底向上汇总子树状态：
- 设空结点 `NULL` 的黑高为 0，且无条件合法。
- 递归计算左子树的黑高 `left_bh` 与右子树的黑高 `right_bh`。
- 若左右子树中任意一侧非法，或者 `left_bh != right_bh`，则当前子树不满足黑高一致性，立即返回 `false` 触发早停报错。
- 若一致，当前结点的黑高即为：
  $$\text{bh} = \text{left\_bh} + (\text{node->color} == \text{RB\_BLACK} ? 1 : 0)$$

### 2. 局部红黑约束与父结点传参

性质 4 要求“不存在连续两个红结点”。在递归下探时，将父结点的指针或颜色作为形参传递给子结点：
- 若当前结点为 `RB_RED`，且传入的父结点也是 `RB_RED`，则判定存在“红父红子”冲突，返回 `false`。
- 根结点调用时传入的父结点为 `NULL`，直接免除红父检查，但需在外层入口显式断言 `root->color == RB_BLACK`。

## C 语言实现

```c
#include <assert.h>
#include <stdbool.h>
#include <stddef.h>
#include <stdint.h>
#include <stdlib.h>

typedef enum {
    RB_RED = 0,
    RB_BLACK = 1
} RbColor;

typedef struct RbNode RbNode;

struct RbNode {
    int64_t key;
    RbColor color;
    RbNode *left;
    RbNode *right;
};

static RbNode *create_rb_node(int64_t key, RbColor color) {
    RbNode *n = (RbNode *)malloc(sizeof(RbNode));
    assert(n != NULL);
    n->key = key;
    n->color = color;
    n->left = NULL;
    n->right = NULL;
    return n;
}

static void free_rb(RbNode *n) {
    if (n == NULL) {
        return;
    }
    free_rb(n->left);
    free_rb(n->right);
    free(n);
}

static bool validate_rb_node(
    const RbNode *node,
    const RbNode *parent,
    bool has_lower,
    int64_t lower,
    bool has_upper,
    int64_t upper,
    size_t *out_bh
) {
    if (node == NULL) {
        /* 性质 3：空叶子结点视为黑色，黑高为 0 */
        *out_bh = 0;
        return true;
    }

    /* BST 有序性区间检查 */
    if ((has_lower && node->key <= lower) ||
        (has_upper && node->key >= upper)) {
        return false;
    }

    /* 性质 4：红色结点的孩子必须全为黑色（不得有连续红结点） */
    if (node->color == RB_RED) {
        if (parent != NULL && parent->color == RB_RED) {
            return false;
        }
    } else if (node->color != RB_BLACK) {
        return false;
    }

    size_t left_bh = 0;
    size_t right_bh = 0;
    if (!validate_rb_node(node->left, node, has_lower, lower, true, node->key, &left_bh) ||
        !validate_rb_node(node->right, node, true, node->key, has_upper, upper, &right_bh)) {
        return false;
    }

    /* 性质 5：从该结点出发的所有路径必须包含相同数目的黑色结点 */
    if (left_bh != right_bh) {
        return false;
    }

    *out_bh = left_bh + (node->color == RB_BLACK ? 1 : 0);
    return true;
}

bool rb_validate_tree(const RbNode *root) {
    if (root == NULL) {
        return true;
    }
    /* 性质 2：根结点必须为黑色 */
    if (root->color != RB_BLACK) {
        return false;
    }
    size_t bh = 0;
    return validate_rb_node(root, NULL, false, 0, false, 0, &bh);
}

int main(void) {
    /* 1. 测试空树 */
    assert(rb_validate_tree(NULL));

    /* 2. 构造一棵合法的红黑树:
             10 (黑)
            /       \
          5 (红)    20 (黑)
         /   \
        2(黑) 7(黑)
    */
    RbNode *root = create_rb_node(10, RB_BLACK);
    root->left = create_rb_node(5, RB_RED);
    root->right = create_rb_node(20, RB_BLACK);
    root->left->left = create_rb_node(2, RB_BLACK);
    root->left->right = create_rb_node(7, RB_BLACK);

    assert(rb_validate_tree(root));

    /* 3. 破坏性质 2：根结点置红 */
    root->color = RB_RED;
    assert(!rb_validate_tree(root));
    root->color = RB_BLACK;

    /* 4. 破坏性质 4：产生连续红色（5 为红，将 2 也置红） */
    root->left->left->color = RB_RED;
    assert(!rb_validate_tree(root));
    root->left->left->color = RB_BLACK;

    /* 5. 破坏性质 5：黑高失衡（将 20 置红，右路径黑高缺失 1） */
    root->right->color = RB_RED;
    assert(!rb_validate_tree(root));
    root->right->color = RB_BLACK;

    /* 6. 破坏 BST 搜索有序性：将 7 改为 25（在 10 的左子树中出现大于 10 的键） */
    root->left->right->key = 25;
    assert(!rb_validate_tree(root));
    root->left->right->key = 7;

    free_rb(root);
    return 0;
}
```

## 复杂度分析

- **时间复杂度**：每个结点仅被访问一次，后序回溯合并黑高，总时间复杂度为严格的 $O(n)$。
- **空间复杂度**：递归栈深度不超过红黑树的最大高度 $2 \log_2(n + 1)$，额外空间复杂度为 $O(\log n)$。

## 延伸思考 / 模式总结

红黑树的 5 条性质本质上是对“2-3-4 树”的一种二叉模拟（每个黑色结点与其附属的红色孩子构成一个多路超级结点）。
性质 4 保证了红结点不能直接相连（即一个多路结点最多容纳 3 个键，不允许出现 4 个键），而性质 5 保证了 2-3-4 树中所有叶子结点在同一层的高对称性。编写自动验证器是调试红黑树插入、删除修复逻辑的强有力武器。
