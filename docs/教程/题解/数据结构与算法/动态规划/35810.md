# 35810 - 树形 DP（树的最大权独立集）

## 题目

给定一棵包含 $n$ 个顶点的无向树（顶点编号为 $0, 1, \dots, n - 1$），每条树边连接两个顶点。每个顶点 $u$ 具有一个非负权重 $weights[u]$。

从树中选择一个顶点子集 $S$，使得 $S$ 中**任意两个顶点在树中均不相邻**（即 $S$ 为一个独立集）。求所有合法独立集中**权重之和的最大值**。

函数签名如下：

```c
#include <stdbool.h>
#include <stddef.h>
#include <stdint.h>

bool tree_max_independent_set(
    size_t n,
    const size_t edges[][2],
    size_t edge_count,
    const uint64_t *weights,
    uint64_t *out_max_weight
);
```

要求：
1. 参数有效性检查：当 $n > 0$ 时 `weights` 不能为 `NULL`；若 $n > 1$，边的数量 `edge_count` 必须等于 $n - 1$。
2. 当 $n = 0$ 时，最大权重为 0，输出 0 并返回 `true`。
3. 当加法发生 64 位无符号整数溢出时返回 `false` 且不修改输出对象。
4. 必须通过邻接表以深度优先搜索（DFS）后序遍历的方式实现树形动态规划，时间复杂度为 $O(n)$，空间复杂度为 $O(n)$。

## 解题思路

1. **树结构与有向化**：
   无向树任意选取一个顶点（通常为节点 0）作为根结点，即可转化为一棵以 0 为根的有向树。树的任意子树之间互不相交，具有天然的最优子结构。

2. **状态定义与转移方程**：
   对于树中任意结点 $u$，在独立集决策中仅存在两种互斥选择：
   - $dp[u][0]$：**不选择**结点 $u$ 时，以 $u$ 为根的子树所能获得的最大权；
   - $dp[u][1]$：**选择**结点 $u$ 时，以 $u$ 为根的子树所能获得的最大权。

   设 $children(u)$ 为结点 $u$ 的所有直接子结点集合：
   - 若不选 $u$，则每个子结点 $v$ 既可以选，也可以不选，各子树独立取最优：
     $$dp[u][0] = \sum_{v \in children(u)} \max(dp[v][0], \; dp[v][1])$$
   - 若选择 $u$，由于相邻约束，其所有子结点 $v$ 都**绝对不能被选**：
     $$dp[u][1] = weights[u] + \sum_{v \in children(u)} dp[v][0]$$

3. **后序遍历与自底向上求解**：
   叶子结点的初值自然为 $dp[leaf][0] = 0, dp[leaf][1] = weights[leaf]$。通过 DFS 在子结点递归返回后计算父结点的状态（后序遍历），最终整棵树的最优解即为：
   $$\max(dp[root][0], \; dp[root][1])$$

## C 语言实现

```c
#include <assert.h>
#include <stdbool.h>
#include <stddef.h>
#include <stdint.h>
#include <stdlib.h>

typedef struct EdgeNode EdgeNode;
struct EdgeNode {
    size_t to;
    EdgeNode *next;
};

static bool dfs_tree_dp(
    size_t u,
    size_t parent,
    const EdgeNode * const *adj,
    const uint64_t *weights,
    uint64_t *dp0,
    uint64_t *dp1
) {
    uint64_t sum0 = 0; // 不选 u: sum(max(dp[v][0], dp[v][1]))
    uint64_t sum1 = weights[u]; // 选择 u: weights[u] + sum(dp[v][0])

    for (const EdgeNode *edge = adj[u]; edge != NULL; edge = edge->next) {
        size_t v = edge->to;
        if (v == parent) {
            continue;
        }

        if (!dfs_tree_dp(v, u, adj, weights, dp0, dp1)) {
            return false;
        }

        uint64_t best_v = (dp0[v] > dp1[v]) ? dp0[v] : dp1[v];
        if (sum0 > UINT64_MAX - best_v) {
            return false;
        }
        sum0 += best_v;

        if (sum1 > UINT64_MAX - dp0[v]) {
            return false;
        }
        sum1 += dp0[v];
    }

    dp0[u] = sum0;
    dp1[u] = sum1;
    return true;
}

bool tree_max_independent_set(
    size_t n,
    const size_t edges[][2],
    size_t edge_count,
    const uint64_t *weights,
    uint64_t *out_max_weight
) {
    if (out_max_weight == NULL) {
        return false;
    }
    if (n == 0) {
        *out_max_weight = 0;
        return true;
    }
    if (weights == NULL) {
        return false;
    }
    if (n == 1) {
        *out_max_weight = weights[0];
        return true;
    }
    if (edges == NULL || edge_count != n - 1) {
        return false;
    }

    EdgeNode **adj = calloc(n, sizeof(EdgeNode*));
    uint64_t *dp0 = malloc(n * sizeof(uint64_t));
    uint64_t *dp1 = malloc(n * sizeof(uint64_t));
    EdgeNode *edge_pool = malloc(2 * edge_count * sizeof(EdgeNode));

    if (adj == NULL || dp0 == NULL || dp1 == NULL || edge_pool == NULL) {
        free(adj);
        free(dp0);
        free(dp1);
        free(edge_pool);
        return false;
    }

    size_t pool_idx = 0;
    for (size_t i = 0; i < edge_count; ++i) {
        size_t u = edges[i][0];
        size_t v = edges[i][1];
        if (u >= n || v >= n || u == v) {
            free(adj); free(dp0); free(dp1); free(edge_pool);
            return false;
        }

        // 添加边 u -> v
        edge_pool[pool_idx].to = v;
        edge_pool[pool_idx].next = adj[u];
        adj[u] = &edge_pool[pool_idx++];

        // 添加边 v -> u
        edge_pool[pool_idx].to = u;
        edge_pool[pool_idx].next = adj[v];
        adj[v] = &edge_pool[pool_idx++];
    }

    bool success = dfs_tree_dp(0, SIZE_MAX, (const EdgeNode * const *)adj, weights, dp0, dp1);
    if (success) {
        *out_max_weight = (dp0[0] > dp1[0]) ? dp0[0] : dp1[0];
    }

    free(adj);
    free(dp0);
    free(dp1);
    free(edge_pool);
    return success;
}

int main(void) {
    uint64_t max_wt = 0;

    // 参数校验
    assert(!tree_max_independent_set(3, NULL, 2, (const uint64_t[]){1, 2, 3}, &max_wt));
    assert(!tree_max_independent_set(3, (const size_t[][2]){{0, 1}}, 1, (const uint64_t[]){1, 2, 3}, &max_wt));

    // n = 0 边界
    assert(tree_max_independent_set(0, NULL, 0, NULL, &max_wt) && max_wt == 0);

    // n = 1 单结点
    const uint64_t w1[1] = {100};
    assert(tree_max_independent_set(1, NULL, 0, w1, &max_wt) && max_wt == 100);

    // 简单链: 0 - 1 - 2
    // 权重: [10, 20, 30]
    // 独立集可选 {0, 2} 权重 40，或选 {1} 权重 20 -> 最大为 40
    const size_t e_line[2][2] = {{0, 1}, {1, 2}};
    const uint64_t w_line[3] = {10, 20, 30};
    assert(tree_max_independent_set(3, e_line, 2, w_line, &max_wt) && max_wt == 40);

    // 星型树: 中心节点 0 (权重 50), 叶子节点 1, 2, 3 (权重各为 20)
    // 选中心: 50
    // 选所有叶子: 20 + 20 + 20 = 60 (最优!)
    const size_t e_star[3][2] = {{0, 1}, {0, 2}, {0, 3}};
    const uint64_t w_star[4] = {50, 20, 20, 20};
    assert(tree_max_independent_set(4, e_star, 3, w_star, &max_wt) && max_wt == 60);

    return 0;
}
```

## 复杂度分析

- **时间复杂度**：$O(n)$。整棵树包含 $n$ 个结点和 $n - 1$ 条边，DFS 过程中每条边和每个结点仅被遍历常数次。
- **空间复杂度**：$O(n)$。包含邻接表分配、状态数组 `dp0` 和 `dp1` 以及 DFS 递归调用栈空间。

## 延伸思考 / 模式总结

树形 DP 是在具有递归树状层次结构上的动态规划。其基本套路是后序遍历（自底向上），子结点的计算完成后父结点合并子结点的信息。本题是“选与不选”二维决策模型的典型代表（相当于“打家劫舍 III”在一般图论树上的推广）。
