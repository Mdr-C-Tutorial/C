# 35808 - 矩阵链乘法（区间 DP，最优加括号顺序）

## 题目

给定 $n$ 个矩阵组成的序列 $\langle A_1, A_2, \dots, A_n \rangle$，其中矩阵 $A_i$ 的维度为 $p_{i-1} \times p_i$。矩阵乘法满足结合律，但不同的加括号顺序所需的标量乘法次数差异巨大。

求计算矩阵乘积 $A_1 A_2 \dots A_n$ 所需的**最少标量乘法次数**，并将具有该最优乘法次数的**加括号方案字符串**输出到指定的缓冲区中（例如 `((A1(A2A3))((A4A5)A6))`）。

函数签名如下：

```c
#include <stdbool.h>
#include <stddef.h>
#include <stdint.h>

bool matrix_chain_order(
    const size_t *dims,
    size_t n,
    uint64_t *out_cost,
    char *out_parens,
    size_t parens_capacity
);
```

要求：
1. 数组 `dims` 的长度为 $n + 1$，对应维度序列 $\langle p_0, p_1, \dots, p_n \rangle$。
2. 当 $n = 0$ 时，视为无乘法，输出代价 0，括号字符串写为空字符串 `""` 并返回 `true`。
3. 当 $n = 1$ 时，单个矩阵无需相乘，代价为 0，输出 `"A1"` 并返回 `true`。
4. 参数无效或缓冲区不足以容纳结果（包含结尾 `'\0'`）时返回 `false`。
5. 采用区间动态规划求解，时间复杂度为 $O(n^3)$，空间复杂度为 $O(n^2)$。

## 解题思路

1. **区间子问题划分与状态定义**：
   考虑子链 $A_i \dots A_j$（$1 \le i \le j \le n$）的最优完全加括号方案。
   若最优方案在矩阵 $A_k$ 和 $A_{k+1}$ 之间切分（$i \le k < j$），则总代价等于：
   - 计算 $A_i \dots A_k$ 的最少乘法代价；
   - 计算 $A_{k+1} \dots A_j$ 的最少乘法代价；
   - 将两个结果矩阵（维度分别为 $p_{i-1} \times p_k$ 和 $p_k \times p_j$）相乘所需的代价 $p_{i-1} p_k p_j$。

   设 $m[i][j]$ 表示计算 $A_i \dots A_j$ 的最小标量乘法次数：
   $$m[i][j] = \begin{cases} 0 & \text{若 } i = j \\ \min_{i \le k < j} \{ m[i][k] + m[k+1][j] + p_{i-1} p_k p_j \} & \text{若 } i < j \end{cases}$$

2. **区间 DP 循环顺序**：
   状态转移依赖于长度更短的子区间。因此外层循环必须按**子链长度 $L$** 从 $2$ 到 $n$ 递增；内层循环枚举区间起点 $i$，由此确定终点 $j = i + L - 1$；最内层枚举切分点 $k$。
   同步维护一个大小为 $(n + 1) \times (n + 1)$ 的分割点记录表 $s[i][j] = k$。

3. **递归重建最优括号化序列**：
   有了表 $s$，我们可以递归构造括号序列：
   - 若 $i == j$，直接打印 `"Ai"`；
   - 若 $i < j$，先打印 `'('`，递归构建子链 $(i, s[i][j])$，再递归构建子链 $(s[i][j] + 1, j)$，最后打印 `')'`。

## C 语言实现

```c
#include <assert.h>
#include <stdbool.h>
#include <stddef.h>
#include <stdint.h>
#include <stdio.h>
#include <stdlib.h>
#include <string.h>

static bool append_char(char *buf, size_t cap, size_t *pos, char c) {
    if (*pos + 1 >= cap) {
        return false;
    }
    buf[(*pos)++] = c;
    buf[*pos] = 0;
    return true;
}

static bool append_name(char *buf, size_t cap, size_t *pos, size_t idx) {
    char tmp[32];
    int written = snprintf(tmp, sizeof(tmp), "A%llu", (unsigned long long)idx);
    if (written < 0 || (size_t)written >= sizeof(tmp)) {
        return false;
    }
    if (*pos + (size_t)written >= cap) {
        return false;
    }
    memcpy(buf + *pos, tmp, (size_t)written);
    *pos += (size_t)written;
    buf[*pos] = 0;
    return true;
}

static bool print_parens_rec(
    const size_t *s,
    size_t n_plus_1,
    size_t i,
    size_t j,
    char *buf,
    size_t cap,
    size_t *pos
) {
    if (i == j) {
        return append_name(buf, cap, pos, i);
    }
    if (!append_char(buf, cap, pos, '(')) {
        return false;
    }
    size_t k = s[i * n_plus_1 + j];
    if (!print_parens_rec(s, n_plus_1, i, k, buf, cap, pos)) {
        return false;
    }
    if (!print_parens_rec(s, n_plus_1, k + 1, j, buf, cap, pos)) {
        return false;
    }
    return append_char(buf, cap, pos, ')');
}

bool matrix_chain_order(
    const size_t *dims,
    size_t n,
    uint64_t *out_cost,
    char *out_parens,
    size_t parens_capacity
) {
    if (out_cost == NULL || (n > 0 && dims == NULL)) {
        return false;
    }
    if (n == 0) {
        *out_cost = 0;
        if (out_parens != NULL && parens_capacity > 0) {
            out_parens[0] = 0;
        }
        return true;
    }
    if (out_parens == NULL || parens_capacity == 0) {
        return false;
    }
    if (n == 1) {
        *out_cost = 0;
        if (parens_capacity < 3) {
            return false;
        }
        out_parens[0] = 'A';
        out_parens[1] = '1';
        out_parens[2] = 0;
        return true;
    }

    size_t stride = n + 1;
    if (stride > SIZE_MAX / stride ||
        stride * stride > SIZE_MAX / sizeof(uint64_t) ||
        stride * stride > SIZE_MAX / sizeof(size_t)) {
        return false;
    }

    uint64_t *m = calloc(stride * stride, sizeof *m);
    size_t *s = calloc(stride * stride, sizeof *s);
    if (m == NULL || s == NULL) {
        free(m);
        free(s);
        return false;
    }

    // 链长 L 从 2 到 n
    for (size_t len = 2; len <= n; ++len) {
        for (size_t i = 1; i <= n - len + 1; ++i) {
            size_t j = i + len - 1;
            m[i * stride + j] = UINT64_MAX;

            for (size_t k = i; k < j; ++k) {
                uint64_t p0 = dims[i - 1];
                uint64_t pk = dims[k];
                uint64_t pj = dims[j];

                // 乘积防溢出
                if (p0 > 0 && pk > UINT64_MAX / p0) {
                    free(m); free(s); return false;
                }
                uint64_t mult = p0 * pk;
                if (pj > 0 && mult > UINT64_MAX / pj) {
                    free(m); free(s); return false;
                }
                mult *= pj;

                uint64_t left_cost = m[i * stride + k];
                uint64_t right_cost = m[(k + 1) * stride + j];
                if (left_cost > UINT64_MAX - right_cost ||
                    left_cost + right_cost > UINT64_MAX - mult) {
                    free(m); free(s); return false;
                }
                uint64_t total = left_cost + right_cost + mult;
                if (total < m[i * stride + j]) {
                    m[i * stride + j] = total;
                    s[i * stride + j] = k;
                }
            }
        }
    }

    *out_cost = m[1 * stride + n];
    size_t pos = 0;
    out_parens[0] = 0;
    bool ok = print_parens_rec(s, stride, 1, n, out_parens, parens_capacity, &pos);

    free(m);
    free(s);
    return ok;
}

int main(void) {
    uint64_t cost = 0;
    char parens[128];

    // 参数校验
    assert(!matrix_chain_order(NULL, 3, &cost, parens, sizeof(parens)));
    assert(!matrix_chain_order((const size_t[]){10, 20}, 1, NULL, parens, sizeof(parens)));

    // n = 0 边界
    assert(matrix_chain_order(NULL, 0, &cost, parens, sizeof(parens)));
    assert(cost == 0 && strcmp(parens, "") == 0);

    // n = 1 边界
    const size_t d1[2] = {10, 20};
    assert(matrix_chain_order(d1, 1, &cost, parens, sizeof(parens)));
    assert(cost == 0 && strcmp(parens, "A1") == 0);

    // CLRS 经典 6 矩阵链
    // 维度: 30x35, 35x15, 15x5, 5x10, 10x20, 20x25
    // dims: {30, 35, 15, 5, 10, 20, 25} (长度 7, n = 6)
    // 最小乘法次数: 15125
    // 最优加括号顺序: "((A1(A2A3))((A4A5)A6))"
    const size_t d_clrs[7] = {30, 35, 15, 5, 10, 20, 25};
    assert(matrix_chain_order(d_clrs, 6, &cost, parens, sizeof(parens)));
    assert(cost == 15125);
    assert(strcmp(parens, "((A1(A2A3))((A4A5)A6))") == 0);

    return 0;
}
```

## 复杂度分析

- **时间复杂度**：$O(n^3)$。三层循环：区间长度循环 $O(n)$，左端点循环 $O(n)$，切分点枚举 $O(n)$，总步数为 $\sum_{L=2}^n (n - L + 1)(L - 1) = \frac{n^3 - n}{6}$。
- **空间复杂度**：$O(n^2)$。需要大小为 $(n + 1)^2$ 的二维矩阵存储代价表 $m$ 和切分点表 $s$。

## 延伸思考 / 模式总结

矩阵链乘法是**区间动态规划**的代表题型。区间 DP 的鲜明特征是子问题的拓扑序由区间长度决定，状态转移方程由左右两个子区间合并而成。同类问题还包括凸多边形最优三角剖分、括号匹配、石子合并等。
