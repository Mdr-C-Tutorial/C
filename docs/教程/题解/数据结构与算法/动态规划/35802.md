# 35802 - 网格最小路径代价与原地状态压缩

## 题目描述

在一个 $m 	imes n$ 的非负代价网格中，每次只能向下或向右移动一步。求从左上角格子 $(0, 0)$ 到右下角格子 $(m - 1, n - 1)$ 的最小总路径代价。

函数签名如下：

```c
#include <stdbool.h>
#include <stddef.h>
#include <stdint.h>

bool minimum_grid_path(
    const uint64_t *costs,
    size_t rows,
    size_t columns,
    uint64_t *out_cost
);
```

要求：
1. 代价矩阵以行优先方式扁平化存储，索引计算为 `row * columns + column`。
2. 输入参数无效（指针为空且大小大于 0、行列维度乘积溢出等）时返回 `false`。
3. 行数为 0 或列数为 0 时，路径代价视为 0，输出 0 并返回 `true`。
4. 若加法过程中发生 64 位无符号整数溢出，返回 `false` 且不修改输出对象。
5. 必须采用一维滚动数组将辅助空间压缩至 $O(	ext{columns})$。

## 解题思路

1. **状态定义与转移方程**：
   设 $dp[r][c]$ 表示从起点 $(0, 0)$ 到达格子 $(r, c)$ 的最小路径和。
   到达格子 $(r, c)$ 只能来自左侧 $(r, c - 1)$ 或上方 $(r - 1, c)$：
   - 起点边界：$dp[0][0] = 	ext{costs}[0][0]$；
   - 第一行边界：只能从左边移动而来，$dp[0][c] = dp[0][c - 1] + 	ext{costs}[0][c]$；
   - 第一列边界：只能从上方移动而来，$dp[r][0] = dp[r - 1][0] + 	ext{costs}[r][0]$；
   - 通用格子：$dp[r][c] = \min(dp[r - 1][c], dp[r][c - 1]) + 	ext{costs}[r][c]$。

2. **状态压缩（一维滚动数组）**：
   计算第 $r$ 行第 $c$ 列的状态时，只需要当前行左侧的值 $dp[r][c - 1]$ 以及上一行同列的值 $dp[r - 1][c]$。
   维持大小为 `columns` 的一维数组 `dp`。在处理第 $r$ 行第 $c$ 列之前：
   - `dp[c]` 中存放的是上一行第 $c$ 列的最优代价（即 $dp[r - 1][c]$）；
   - `dp[c - 1]` 刚刚在当前轮更新过，存放的是当前行左侧的最优代价（即 $dp[r][c - 1]$）。
   
   因此转移方程可原地化为：
   $$dp[c] = \min(dp[c], dp[c - 1]) + 	ext{costs}[r 	imes 	ext{columns} + c]$$
   额外空间由 $O(m 	imes n)$ 降至 $O(n)$。

## C 语言实现

```c
#include <assert.h>
#include <stdbool.h>
#include <stddef.h>
#include <stdint.h>
#include <stdlib.h>

bool minimum_grid_path(
    const uint64_t *costs,
    size_t rows,
    size_t columns,
    uint64_t *out_cost
) {
    if (out_cost == NULL) {
        return false;
    }
    if (rows == 0 || columns == 0) {
        *out_cost = 0;
        return true;
    }
    if (costs == NULL || rows > SIZE_MAX / columns ||
        columns > SIZE_MAX / sizeof(uint64_t)) {
        return false;
    }

    uint64_t *dp = malloc(columns * sizeof *dp);
    if (dp == NULL) {
        return false;
    }

    for (size_t row = 0; row < rows; ++row) {
        for (size_t column = 0; column < columns; ++column) {
            uint64_t cell = costs[row * columns + column];
            if (row == 0 && column == 0) {
                dp[column] = cell;
                continue;
            }

            uint64_t previous = UINT64_MAX;
            if (row > 0) {
                previous = dp[column];
            }
            if (column > 0 && dp[column - 1] < previous) {
                previous = dp[column - 1];
            }

            if (previous > UINT64_MAX - cell) {
                free(dp);
                return false;
            }
            dp[column] = previous + cell;
        }
    }

    *out_cost = dp[columns - 1];
    free(dp);
    return true;
}

int main(void) {
    uint64_t cost = 0;

    // 参数校验
    assert(!minimum_grid_path(NULL, 2, 2, &cost));
    assert(!minimum_grid_path((const uint64_t[]){1}, 1, 1, NULL));

    // 0 维度退化情形
    assert(minimum_grid_path(NULL, 0, 5, &cost) && cost == 0);

    // 1x1 网格
    const uint64_t g1[1] = {42};
    assert(minimum_grid_path(g1, 1, 1, &cost) && cost == 42);

    // 3x3 经典网格
    // 1  3  1
    // 1  5  1
    // 4  2  1
    // 最小路径: 1 -> 3 -> 1 -> 1 -> 1 = 7
    const uint64_t g2[9] = {
        1, 3, 1,
        1, 5, 1,
        4, 2, 1
    };
    assert(minimum_grid_path(g2, 3, 3, &cost) && cost == 7);

    // 溢出防护测试
    const uint64_t g_overflow[2] = {UINT64_MAX, 1};
    assert(!minimum_grid_path(g_overflow, 1, 2, &cost));

    return 0;
}
```

## 复杂度分析

- **时间复杂度**：$O(m 	imes n)$，其中 $m$ 为行数，$n$ 为列数。每个网格单元访问恰好一次。
- **空间复杂度**：$O(n)$，仅分配大小为 `columns` 的一维数组缓存当前行与上一行的状态信息。

## 延伸思考 / 模式总结

网格 DP 的空间压缩是一维滚动的标准范例。若行数远小于列数，还可通过转置矩阵将空间复杂度进一步降至 $O(\min(m, n))$。当需要输出完整的移动路径时，状态压缩会丢失历史前驱信息，此时通常需要保留完整的二维矩阵或采用分治算法（Hirschberg 思想）在 $O(n)$ 空间下重建最优路径。
