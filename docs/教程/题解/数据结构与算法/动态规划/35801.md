# 35801 - 爬楼梯与斐波那契线性递推滚动数组优化

## 题目描述

假设你正在爬楼梯。需要爬 $n$ 阶你才能到达楼顶。每次你可以爬 $1$ 或 $2$ 个台阶。编写一个函数，计算有多少种不同的方法可以爬到楼顶。

函数签名如下：

```c
#include <stdbool.h>
#include <stddef.h>
#include <stdint.h>

bool climb_stairs(size_t n, uint64_t *out_ways);
```

要求：
1. 当参数 `out_ways == NULL` 时，返回 `false` 且不修改输出。
2. 当 $n = 0$ 时，视为有 $1$ 种方法（原地不动），输出 $1$ 并返回 `true`。
3. 若计算结果超过 `UINT64_MAX`，返回 `false` 且不修改输出对象（检测无符号整数加法溢出）。
4. 算法的时间复杂度必须为 $O(n)$，空间复杂度必须为 $O(1)$，通过滚动状态对象消除数组分配。

## 解题思路

1. **子问题分解与状态定义**：
   到达第 $i$ 阶的方法只能来自两个前驱状态：
   - 从第 $i - 1$ 阶爬 $1$ 个台阶到达；
   - 从第 $i - 2$ 阶爬 $2$ 个台阶到达。
   
   因此，到达第 $i$ 阶的总方法数满足经典的二阶线性递推方程（斐波那契数列）：
   $$dp[i] = dp[i - 1] + dp[i - 2] \quad (i \ge 2)$$
   基础情形为 $dp[0] = 1, dp[1] = 1$。

2. **空间优化（滚动状态对象）**：
   在计算 $dp[i]$ 时，仅依赖紧邻的前两个状态值 $dp[i - 1]$ 与 $dp[i - 2]$，更早的历史状态不再需要。因此无需开辟大小为 $n + 1$ 的动态数组，只需维护两个 `uint64_t` 对象：
   - `prev2` 记录 $dp[i - 2]$；
   - `prev1` 记录 $dp[i - 1]$。
   
   每前进一步，计算新状态并进行滚动轮换，空间复杂度直接降至严格的 $O(1)$。

3. **算术溢出防护**：
   在 64 位无符号整数下，当两数相加时，若 `prev1 > UINT64_MAX - prev2` 则表明发生加法溢出。检测到溢出时立即终止计算并返回 `false`，确保输出对象不被污染。

## C 语言实现

```c
#include <assert.h>
#include <stdbool.h>
#include <stddef.h>
#include <stdint.h>

bool climb_stairs(size_t n, uint64_t *out_ways) {
    if (out_ways == NULL) {
        return false;
    }
    if (n == 0 || n == 1) {
        *out_ways = 1;
        return true;
    }

    uint64_t prev2 = 1;
    uint64_t prev1 = 1;
    uint64_t current = 0;

    for (size_t i = 2; i <= n; ++i) {
        if (prev1 > UINT64_MAX - prev2) {
            return false;
        }
        current = prev1 + prev2;
        prev2 = prev1;
        prev1 = current;
    }

    *out_ways = current;
    return true;
}

int main(void) {
    uint64_t ways = 0;

    // 参数校验测试
    assert(!climb_stairs(5, NULL));

    // 基础情形测试
    assert(climb_stairs(0, &ways) && ways == 1);
    assert(climb_stairs(1, &ways) && ways == 1);
    assert(climb_stairs(2, &ways) && ways == 2);
    assert(climb_stairs(3, &ways) && ways == 3);
    assert(climb_stairs(4, &ways) && ways == 5);
    assert(climb_stairs(5, &ways) && ways == 8);
    assert(climb_stairs(10, &ways) && ways == 89);

    // 较大合法值测试 (第 92 阶在 64 位无符号整数范围内)
    assert(climb_stairs(92, &ways) && ways == UINT64_C(12200160415121876738));

    // 溢出防护测试 (第 93 阶会发生 64 位溢出)
    assert(!climb_stairs(93, &ways));

    return 0;
}
```

## 复杂度分析

- **时间复杂度**：$O(n)$。从 $2$ 到 $n$ 执行单重线性循环，每次迭代仅涉及常数次加法与比较操作。
- **空间复杂度**：$O(1)$。仅使用常数个 64 位整型对象维护滚动状态，无需任何动态内存分配。

## 延伸思考 / 模式总结

线性递推状态压缩是动态规划优化空间的基石技巧。当状态转移仅依赖前 $k$ 步的状态时，状态数组均可压缩为大小为 $k$ 的固定窗口或循环缓冲区。进一步地，对于极大规模的 $n$（如 $n \ge 10^{18}$），可以通过齐次线性递推的矩阵形式构造转移矩阵，利用矩阵快速幂将时间复杂度加速至 $O(k^3 \log n)$。
