# 35806 - 最长公共子序列（LCS）状态转移与方案重建

## 题目描述

给定两个任意二进制字节序列 `left`（长度 `left_count`）和 `right`（长度 `right_count`），求它们的最长公共子序列（Longest Common Subsequence, LCS），并将其中一条确定的最长公共子序列输出到缓冲区 `out_sequence` 中。

函数签名如下：

```c
#include <stdbool.h>
#include <stddef.h>

bool lcs_u8(
    const unsigned char *left,
    size_t left_count,
    const unsigned char *right,
    size_t right_count,
    unsigned char *out_sequence,
    size_t capacity,
    size_t *out_length
);
```

要求：
1. 结果必须同时是两个输入的子序列，且必须在各自的原序列中保持原有的先后顺序。输入数据允许包含任意二进制字节（包括 `0x00`），绝不能假定以空字符结尾。
2. 当 `left_count == 0` 或 `right_count == 0` 时，最长公共子序列长度为 0，输出 0 并返回 `true`。
3. 当参数无效、矩阵乘积溢出或内存分配失败时返回 `false`，不得修改调用方缓冲区与输出对象。
4. 若最长公共子序列长度大于 `capacity`，返回 `false` 且不修改输出对象。
5. 必须具备确定性的回溯策略：当向上和向左的分支长度相等时，优先向上回溯，保证相同输入始终得到完全确定且可复现的方案。

## 解题思路

1. **二维动态规划状态定义**：
   设 $dp[i][j]$ 表示左序列前 $i$ 个字节与右序列前 $j$ 个字节的最长公共子序列长度。
   - 若末尾字节相同（$left[i - 1] == right[j - 1]$）：
     当前字节必然可以作为公共子序列的新末尾：
     $$dp[i][j] = dp[i - 1][j - 1] + 1$$
   - 若末尾字节不相同：
     最长公共子序列要么不包含 $left[i - 1]$，要么不包含 $right[j - 1]$：
     $$dp[i][j] = \max(dp[i - 1][j], \; dp[i][j - 1])$$
   边界条件为 $dp[0][j] = 0, dp[i][0] = 0$。

2. **二维表扁平化存储与溢出防护**：
   二维矩阵的行数为 $left\_count + 1$，列数为 $columns = right\_count + 1$。
   展平成一维数组时下标计算为 $i 	imes columns + j$。在分配内存前必须检查乘法溢出：
   $$(left\_count + 1) 	imes columns \le 	ext{SIZE\_MAX} / 	ext{sizeof}(size\_t)$$

3. **确定性方案回溯**：
   由二维表右下角 $(left\_count, right\_count)$ 开始反向回溯：
   - 若 $left[i - 1] == right[j - 1]$：该字节属于 LCS，存入输出缓冲区的末尾，指针向左上角移动（`--i, --j`）；
   - 若不相等：比较上方 $dp[i - 1][j]$ 与左方 $dp[i][j - 1]$。当 $dp[i - 1][j] \ge dp[i][j - 1]$ 时优先向上移动（`--i`），否则向左移动（`--j`）。
   从后向前填入缓冲区，避免了二次翻转，完成确定性重建。

## C 语言实现

```c
#include <assert.h>
#include <stdbool.h>
#include <stddef.h>
#include <stdint.h>
#include <stdlib.h>
#include <string.h>

bool lcs_u8(
    const unsigned char *left,
    size_t left_count,
    const unsigned char *right,
    size_t right_count,
    unsigned char *out_sequence,
    size_t capacity,
    size_t *out_length
) {
    if (out_length == NULL ||
        (left_count > 0 && left == NULL) ||
        (right_count > 0 && right == NULL)) {
        return false;
    }
    if (left_count == 0 || right_count == 0) {
        *out_length = 0;
        return true;
    }
    if (left_count == SIZE_MAX || right_count == SIZE_MAX) {
        return false;
    }

    size_t columns = right_count + 1;
    if (left_count + 1 > SIZE_MAX / columns ||
        (left_count + 1) * columns > SIZE_MAX / sizeof(size_t)) {
        return false;
    }

    size_t *dp = calloc((left_count + 1) * columns, sizeof *dp);
    if (dp == NULL) {
        return false;
    }

    for (size_t i = 1; i <= left_count; ++i) {
        for (size_t j = 1; j <= right_count; ++j) {
            size_t idx = i * columns + j;
            if (left[i - 1] == right[j - 1]) {
                size_t prev = dp[(i - 1) * columns + j - 1];
                if (prev == SIZE_MAX) {
                    free(dp);
                    return false;
                }
                dp[idx] = prev + 1;
            } else {
                size_t up = dp[(i - 1) * columns + j];
                size_t side = dp[i * columns + j - 1];
                dp[idx] = (up >= side) ? up : side;
            }
        }
    }

    size_t length = dp[left_count * columns + right_count];
    if (length > capacity || (length > 0 && out_sequence == NULL)) {
        free(dp);
        return false;
    }

    // 方案回溯重建
    size_t i = left_count;
    size_t j = right_count;
    size_t cursor = length;
    while (i > 0 && j > 0) {
        if (left[i - 1] == right[j - 1]) {
            out_sequence[--cursor] = left[i - 1];
            --i;
            --j;
        } else {
            size_t up = dp[(i - 1) * columns + j];
            size_t side = dp[i * columns + j - 1];
            if (up >= side) {
                --i;
            } else {
                --j;
            }
        }
    }

    free(dp);
    *out_length = length;
    return true;
}

int main(void) {
    size_t out_len = 0;
    unsigned char buf[64] = {0};

    // 参数校验测试
    assert(!lcs_u8(NULL, 5, (const unsigned char*)"abc", 3, buf, 64, &out_len));
    assert(!lcs_u8((const unsigned char*)"abc", 3, NULL, 5, buf, 64, &out_len));
    assert(!lcs_u8((const unsigned char*)"abc", 3, (const unsigned char*)"abc", 3, buf, 64, NULL));

    // 边界条件：空序列
    assert(lcs_u8(NULL, 0, (const unsigned char*)"abc", 3, buf, 64, &out_len) && out_len == 0);
    assert(lcs_u8((const unsigned char*)"abc", 3, NULL, 0, buf, 64, &out_len) && out_len == 0);

    // 标准字符串用例 1
    // left:  "ABCBDAB"
    // right: "BDCABA"
    // LCS 之一: "BCBA" (长度 4)
    const unsigned char s1[] = "ABCBDAB";
    const unsigned char s2[] = "BDCABA";
    assert(lcs_u8(s1, 7, s2, 6, buf, 64, &out_len));
    assert(out_len == 4);
    buf[out_len] = 0;
    assert(strcmp((char*)buf, "BCBA") == 0);

    // 完全不匹配
    const unsigned char s3[] = "ABC";
    const unsigned char s4[] = "XYZ";
    assert(lcs_u8(s3, 3, s4, 3, buf, 64, &out_len) && out_len == 0);

    // 缓冲区容量不足测试
    assert(!lcs_u8(s1, 7, s2, 6, buf, 3, &out_len));

    return 0;
}
```

## 复杂度分析

- **时间复杂度**：$O(n 	imes m)$，其中 $n = left\_count, m = right\_count$。双重循环填充大小为 $(n + 1) 	imes (m + 1)$ 的动态规划表，回溯阶段步数最多为 $n + m$。
- **空间复杂度**：$O(n 	imes m)$，需要维护完整的二维矩阵以支持方案回溯重建。

## 延伸思考 / 模式总结

若只需计算 LCS 的最大长度而无需输出具体序列，则可使用滚动数组将空间复杂度压缩至 $O(\min(n, m))$。若既要在线性空间内运行又要输出完整序列，可以应用 **Hirschberg 分治算法**，通过分而治之将空间压缩至 $O(m)$，时间保持为 $O(n 	imes m)$。
