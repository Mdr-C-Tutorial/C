# 35807 - 编辑距离（Levenshtein Distance）二维矩阵推导

## 题目描述

给定两个二进制字节序列 `left`（长度 `left_count`）和 `right`（长度 `right_count`），求将 `left` 转换为 `right` 所需的最少编辑操作次数。

允许的编辑操作仅包含：
1. 插入一个字节；
2. 删除一个字节；
3. 替换一个字节为另一个字节。

函数签名如下：

```c
#include <stdbool.h>
#include <stddef.h>

bool edit_distance(
    const unsigned char *left,
    size_t left_count,
    const unsigned char *right,
    size_t right_count,
    size_t *out_distance
);
```

要求：
1. 参数无效时返回 `false`，不得修改输出对象。
2. 空间复杂度必须压缩至 $O(\min(n, m))$，通过滚动行数组实现。
3. 加法计算必须进行饱和/溢出控制，防止数值上溢。

## 解题思路

1. **二维编辑距离状态定义**：
   设 $dp[i][j]$ 表示将 `left[0..i - 1]` 转换为 `right[0..j - 1]` 的最小编辑距离。
   考虑三种可能的转换来源：
   - **删除**：在 `left` 中删除字节 $left[i - 1]$，代价为 $dp[i - 1][j] + 1$；
   - **插入**：在 `left` 中插入字节 $right[j - 1]$，代价为 $dp[i][j - 1] + 1$；
   - **替换或相同**：若 $left[i - 1] == right[j - 1]$，无需修改，代价为 $dp[i - 1][j - 1]$；若不相等，替换该字节，代价为 $dp[i - 1][j - 1] + 1$。
   取三者最小值即得状态转移方程：
   $$dp[i][j] = \min \begin{cases} dp[i - 1][j] + 1 \\ dp[i][j - 1] + 1 \\ dp[i - 1][j - 1] + (left[i - 1] \neq right[j - 1]) \end{cases}$$
   边界条件：$dp[i][0] = i$（连续删除 $i$ 次），$dp[0][j] = j$（连续插入 $j$ 次）。

2. **空间压缩至一维行数组（$O(\min(n, m))$）**：
   观察计算 $dp[i][j]$ 所需的状态：
   - 上方：$dp[i - 1][j]$；
   - 左方：$dp[i][j - 1]$；
   - 左上方：$dp[i - 1][j - 1]$。
   若以较短序列作为列维度，只需维护长度为 $\min(n, m) + 1$ 的一维数组。
   在从左到右更新当前行时，用一个临时对象 `diagonal` 记录更新前的旧值（即左上方的状态 $dp[i - 1][j - 1]$），原位置上的值更新前为上方状态 $dp[i - 1][j]$，左侧相邻值为当前行左侧状态 $dp[i][j - 1]$。更新完毕后更新 `diagonal`，从而安全实现原地覆盖。

## C 语言实现

```c
#include <assert.h>
#include <stdbool.h>
#include <stddef.h>
#include <stdint.h>
#include <stdlib.h>
#include <string.h>

static size_t min3(size_t a, size_t b, size_t c) {
    size_t m = (a < b) ? a : b;
    return (m < c) ? m : c;
}

static size_t sat_add1(size_t val) {
    return (val == SIZE_MAX) ? SIZE_MAX : val + 1;
}

bool edit_distance(
    const unsigned char *left,
    size_t left_count,
    const unsigned char *right,
    size_t right_count,
    size_t *out_distance
) {
    if (out_distance == NULL ||
        (left_count > 0 && left == NULL) ||
        (right_count > 0 && right == NULL)) {
        return false;
    }

    // 确保以较短序列作为列，以优化内存
    if (left_count < right_count) {
        const unsigned char *tmp_seq = left;
        left = right;
        right = tmp_seq;
        size_t tmp_cnt = left_count;
        left_count = right_count;
        right_count = tmp_cnt;
    }

    if (right_count == SIZE_MAX ||
        right_count + 1 > SIZE_MAX / sizeof(size_t)) {
        return false;
    }

    size_t cols = right_count + 1;
    size_t *dp = malloc(cols * sizeof *dp);
    if (dp == NULL) {
        return false;
    }

    // 初始化第 0 行: 空序列转换到 right 前缀的插入代价
    for (size_t j = 0; j < cols; ++j) {
        dp[j] = j;
    }

    for (size_t i = 1; i <= left_count; ++i) {
        size_t diagonal = dp[0];
        dp[0] = i; // 第 i 行第 0 列: 删除 i 个字符

        for (size_t j = 1; j <= right_count; ++j) {
            size_t old_up = dp[j];
            size_t replace_cost = (left[i - 1] == right[j - 1]) ? 0 : 1;
            size_t diagonal_candidate = (diagonal > SIZE_MAX - replace_cost)
                ? SIZE_MAX : diagonal + replace_cost;

            size_t cell = min3(
                sat_add1(old_up),      // 删除
                sat_add1(dp[j - 1]),   // 插入
                diagonal_candidate     // 替换或相同
            );

            diagonal = old_up;
            dp[j] = cell;
        }
    }

    *out_distance = dp[right_count];
    free(dp);
    return true;
}

int main(void) {
    size_t dist = 0;

    // 参数校验
    assert(!edit_distance(NULL, 1, (const unsigned char*)"a", 1, &dist));
    assert(!edit_distance((const unsigned char*)"a", 1, NULL, 1, &dist));
    assert(!edit_distance((const unsigned char*)"a", 1, (const unsigned char*)"a", 1, NULL));

    // 相同字符串编辑距离为 0
    const unsigned char s1[] = "kitten";
    const unsigned char s2[] = "kitten";
    assert(edit_distance(s1, 6, s2, 6, &dist) && dist == 0);

    // 经典用例: "horse" -> "ros"
    // horse -> rorse (替换 'h' 为 'r')
    // rorse -> rose  (删除 'r')
    // rose  -> ros   (删除 'e')
    // 最少 3 次编辑
    const unsigned char s3[] = "horse";
    const unsigned char s4[] = "ros";
    assert(edit_distance(s3, 5, s4, 3, &dist) && dist == 3);

    // 空串转换
    assert(edit_distance(NULL, 0, s4, 3, &dist) && dist == 3);
    assert(edit_distance(s3, 5, NULL, 0, &dist) && dist == 5);
    assert(edit_distance(NULL, 0, NULL, 0, &dist) && dist == 0);

    return 0;
}
```

## 复杂度分析

- **时间复杂度**：$O(n 	imes m)$，其中 $n = left\_count, m = right\_count$。双层循环遍历所有可能的前缀对。
- **空间复杂度**：$O(\min(n, m))$。通过交换两序列使短者对应列维度，只需要长度为 $\min(n, m) + 1$ 的一维状态数组。

## 延伸思考 / 模式总结

编辑距离是一维空间压缩的经典升级版。与普通一维压缩只需“左”和“上”不同，编辑距离的替换操作需要“左上”（即对角线）的数据。通过在单层循环内部引入一个临时对象暂存被覆盖前的左上角数据，避免了额外分配整行历史数组的开销。
