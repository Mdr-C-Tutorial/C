# 35804 - 完全背包问题与正序滚动数组

## 题目描述

给定 $n$ 种物品，每种物品具有重量 $w_i$ 和价值 $v_i$。每种物品的数量是无限的（可以选取零次或任意多次）。背包的最大承重容量为 `capacity`。求在不超过背包总容量的前提下，能够装入物品的最大总价值。

函数签名如下：

```c
#include <stdbool.h>
#include <stddef.h>
#include <stdint.h>

bool knapsack_unbounded(
    const size_t *weights,
    const uint64_t *values,
    size_t count,
    size_t capacity,
    uint64_t *out_value
);
```

要求：
1. 参数无效（指针为空且计数大于 0、容量计算溢出等）时返回 `false`。
2. `count == 0` 或 `capacity == 0` 时，最大价值为 0，输出 0 并返回 `true`。
3. 若某件物品重量为 0 且价值大于 0，则背包总价值可以达到无穷大（无界），此时返回 `false` 提示无界错误。若重量为 0 且价值为 0，则忽略该物品。
4. 加法计算发生 64 位无符号整数溢出时返回 `false` 且不修改输出对象。
5. 必须采用一维正序滚动数组实现，空间复杂度为 $O(C)$。

## 解题思路

1. **完全背包状态转移方程**：
   与 0/1 背包不同，完全背包中同一物品可以被选取多次。
   设 $dp[i][c]$ 为只使用前 $i$ 种物品、容量为 $c$ 时的最大价值。
   - 不选第 $i$ 种物品：$dp[i - 1][c]$；
   - 至少选一件第 $i$ 种物品：在选了一件之后，剩余容量为 $c - w_i$，此时面对的仍是**前 $i$ 种物品**，因此状态来自 $dp[i][c - w_i] + v_i$。
   合并可得状态转移方程：
   $$dp[i][c] = \max(dp[i - 1][c], \; dp[i][c - w_i] + v_i)$$

2. **为什么完全背包采用正序更新**：
   观察转移方程中的项 $dp[i][c - w_i]$，它依赖的是**当前第 $i$ 轮**已更新过的左侧值！
   若将二维表压缩为一维数组 `dp[c]`：
   当内层循环**正序**从 $w_i$ 递增到 `capacity` 时，在更新 `dp[c]` 时，`dp[c - w_i]` 已经融入了当前物品被选取一次、两次直至多次的最优累积效果。
   这种正序覆盖正好天然契合了“物品无限次重复选取”的模型。

3. **零重量物品的边界分析**：
   若某物品 $w_i = 0$：
   - 当 $v_i > 0$ 时，容量不受消耗即可无限制累加价值，导致最优解发散至无穷大。因此必须在处理前检测该情形并返回 `false`；
   - 当 $v_i = 0$ 时，该物品既不消耗容量也不产生价值，直接跳过即可。

## C 语言实现

```c
#include <assert.h>
#include <stdbool.h>
#include <stddef.h>
#include <stdint.h>
#include <stdlib.h>

bool knapsack_unbounded(
    const size_t *weights,
    const uint64_t *values,
    size_t count,
    size_t capacity,
    uint64_t *out_value
) {
    if (out_value == NULL ||
        (count > 0 && (weights == NULL || values == NULL)) ||
        capacity == SIZE_MAX ||
        capacity + 1 > SIZE_MAX / sizeof(uint64_t)) {
        return false;
    }
    if (count == 0 || capacity == 0) {
        *out_value = 0;
        return true;
    }

    // 检查零重量物品
    for (size_t i = 0; i < count; ++i) {
        if (weights[i] == 0 && values[i] > 0) {
            return false; // 价值无界
        }
    }

    uint64_t *dp = calloc(capacity + 1, sizeof *dp);
    if (dp == NULL) {
        return false;
    }

    for (size_t item = 0; item < count; ++item) {
        size_t w = weights[item];
        uint64_t v = values[item];
        if (w == 0 || w > capacity) {
            continue;
        }

        // 正序滚动更新
        for (size_t c = w; c <= capacity; ++c) {
            if (dp[c - w] > UINT64_MAX - v) {
                free(dp);
                return false;
            }
            uint64_t candidate = dp[c - w] + v;
            if (candidate > dp[c]) {
                dp[c] = candidate;
            }
        }
    }

    *out_value = dp[capacity];
    free(dp);
    return true;
}

int main(void) {
    uint64_t max_val = 0;

    // 参数校验
    assert(!knapsack_unbounded(NULL, (const uint64_t[]){1}, 1, 10, &max_val));
    assert(!knapsack_unbounded((const size_t[]){1}, NULL, 1, 10, &max_val));
    assert(!knapsack_unbounded((const size_t[]){1}, (const uint64_t[]){1}, 1, 10, NULL));

    // 边界用例
    assert(knapsack_unbounded(NULL, NULL, 0, 10, &max_val) && max_val == 0);
    const size_t w_test[1] = {5};
    const uint64_t v_test[1] = {100};
    assert(knapsack_unbounded(w_test, v_test, 1, 0, &max_val) && max_val == 0);

    // 标准完全背包用例：
    // 物品 0: 重 2, 值 5
    // 物品 1: 重 3, 值 8
    // 背包容量: 7
    // 可能组合:
    // - 选 3 个物品 0: 重 6, 值 15
    // - 选 2 个物品 1: 重 6, 值 16
    // - 选 2 个物品 0 + 1 个物品 1: 重 2*2 + 3 = 7, 值 2*5 + 8 = 18 (最优!)
    const size_t w_std[2] = {2, 3};
    const uint64_t v_std[2] = {5, 8};
    assert(knapsack_unbounded(w_std, v_std, 2, 7, &max_val) && max_val == 18);

    // 零重无界测试
    const size_t w_unbounded[1] = {0};
    const uint64_t v_unbounded[1] = {10};
    assert(!knapsack_unbounded(w_unbounded, v_unbounded, 1, 10, &max_val));

    // 溢出防护测试
    const size_t w_ovf[1] = {1};
    const uint64_t v_ovf[1] = {UINT64_MAX / 2 + 10};
    assert(!knapsack_unbounded(w_ovf, v_ovf, 1, 3, &max_val));

    return 0;
}
```

## 复杂度分析

- **时间复杂度**：$O(n 	imes C)$，其中 $n$ 为物品种数，$C$ 为容量。对每种非零重量物品，内层循环正向扫描容量 $[w_i, C]$。
- **空间复杂度**：$O(C)$。通过正序覆盖，仅维护长度为 $C + 1$ 的一维状态数组。

## 延伸思考 / 模式总结

0/1 背包与完全背包在一维滚动实现上的唯一区别在于内层循环的方向：
- **逆序循环**：保证状态来自上一轮未修改的值，每件物品至多选一次；
- **正序循环**：允许状态在同一轮内由左至右连锁更新，使物品得以重复无限选取。
这种以循环方向切换逻辑语义的精巧设计，是动态规划状态转移与空间压缩结合的典范。
