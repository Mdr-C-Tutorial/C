# 35803 - 0/1 背包问题与一维逆序滚动数组

## 题目描述

给定 $n$ 件物品，每件物品具有重量 $w_i$ 和价值 $v_i$。背包的最大承重容量为 `capacity`。每件物品至多只能选择放入背包一次。求在不超过背包总容量的前提下，能够装入物品的最大总价值。

函数签名如下：

```c
#include <stdbool.h>
#include <stddef.h>
#include <stdint.h>

bool knapsack_01(
    const size_t *weights,
    const uint64_t *values,
    size_t count,
    size_t capacity,
    uint64_t *out_value
);
```

要求：
1. 若输入参数无效（指针为空且计数大于 0、容量计算溢出等），返回 `false` 且不修改输出对象。
2. 当 `count == 0` 或 `capacity == 0` 时，最大价值为 0，输出 0 并返回 `true`。
3. 若累加过程中总价值发生 64 位无符号整数溢出，返回 `false` 且不修改输出对象。
4. 必须采用一维滚动数组实现，空间复杂度为 $O(C)$（其中 $C$ 为背包容量 `capacity`）。

## 解题思路

1. **二维动态规划模型**：
   设 $dp[i][c]$ 表示只考虑前 $i$ 件物品、背包当前容量上限为 $c$ 时的最大总价值。
   对于第 $i$ 件物品（重量 $w_i$，价值 $v_i$）：
   - 不选第 $i$ 件物品：$dp[i][c] = dp[i - 1][c]$；
   - 选择第 $i$ 件物品（前提是 $c \ge w_i$）：$dp[i][c] = dp[i - 1][c - w_i] + v_i$。
   取两者较大值即为状态转移方程：
   $$dp[i][c] = \max(dp[i - 1][c], \; dp[i - 1][c - w_i] + v_i)$$

2. **空间压缩与逆序更新的不变式**：
   在计算第 $i$ 轮状态时，所依赖的上一轮状态仅位于容量小于等于 $c$ 的位置。
   若我们将二维数组压缩为一维数组 `dp[c]`，为了保证在计算 `dp[c]` 时，所读取的 `dp[c - w_i]` 仍然属于**前 $i - 1$ 件物品**的旧状态，内层循环必须**从容量 `capacity` 逆序倒推到 `w_i`**。
   若采用正序遍历，较小容量的值会被当前第 $i$ 件物品提前覆盖，导致该物品被重复计算（退化为完全背包）。

3. **健壮性与溢出控制**：
   在执行 `dp[c - weights[item]] + values[item]` 之前，严格核验加法是否超过 `UINT64_MAX`。一旦溢出则立即释放分配的数组并返回 `false`。

## C 语言实现

```c
#include <assert.h>
#include <stdbool.h>
#include <stddef.h>
#include <stdint.h>
#include <stdlib.h>

bool knapsack_01(
    const size_t *weights,
    const uint64_t *values,
    size_t count,
    size_t capacity,
    uint64_t *out_value
) {
    if (out_value == NULL ||
        (count > 0 && (weights == NULL || values == NULL)) ||
        capacity == SIZE_MAX ||
        capacity + 1 > SIZE_MAX / sizeof(uint64_t)) {
        return false;
    }
    if (count == 0 || capacity == 0) {
        *out_value = 0;
        return true;
    }

    uint64_t *dp = calloc(capacity + 1, sizeof *dp);
    if (dp == NULL) {
        return false;
    }

    for (size_t item = 0; item < count; ++item) {
        size_t w = weights[item];
        uint64_t v = values[item];
        if (w > capacity) {
            continue;
        }

        for (size_t c = capacity; c >= w; --c) {
            if (dp[c - w] > UINT64_MAX - v) {
                free(dp);
                return false;
            }
            uint64_t candidate = dp[c - w] + v;
            if (candidate > dp[c]) {
                dp[c] = candidate;
            }
        }
    }

    *out_value = dp[capacity];
    free(dp);
    return true;
}

int main(void) {
    uint64_t max_val = 0;

    // 参数校验测试
    assert(!knapsack_01(NULL, (const uint64_t[]){1}, 1, 10, &max_val));
    assert(!knapsack_01((const size_t[]){1}, NULL, 1, 10, &max_val));
    assert(!knapsack_01((const size_t[]){1}, (const uint64_t[]){1}, 1, 10, NULL));

    // 边界条件：物品数为 0 或容量为 0
    assert(knapsack_01(NULL, NULL, 0, 10, &max_val) && max_val == 0);
    const size_t w_test[1] = {5};
    const uint64_t v_test[1] = {100};
    assert(knapsack_01(w_test, v_test, 1, 0, &max_val) && max_val == 0);

    // 标准用例：
    // 物品重量: [2, 3, 4, 5]
    // 物品价值: [3, 4, 5, 6]
    // 背包容量: 5
    // 最优选择: 选物品 0 (重 2 值 3) 和物品 1 (重 3 值 4)，总重 5，总价值 7
    const size_t w_standard[4] = {2, 3, 4, 5};
    const uint64_t v_standard[4] = {3, 4, 5, 6};
    assert(knapsack_01(w_standard, v_standard, 4, 5, &max_val) && max_val == 7);

    // 物品重量超过容量测试
    const size_t w_heavy[2] = {10, 20};
    const uint64_t v_heavy[2] = {100, 200};
    assert(knapsack_01(w_heavy, v_heavy, 2, 5, &max_val) && max_val == 0);

    // 溢出防护测试
    const size_t w_ovf[2] = {1, 1};
    const uint64_t v_ovf[2] = {UINT64_MAX - 10, 20};
    assert(!knapsack_01(w_ovf, v_ovf, 2, 2, &max_val));

    return 0;
}
```

## 复杂度分析

- **时间复杂度**：$O(n 	imes C)$，其中 $n$ 为物品数量，$C$ 为背包容量。外层循环遍历所有物品，内层循环逆序遍历容量区间 $[w_i, C]$。
- **空间复杂度**：$O(C)$。通过逆序一维滚动状态数组，仅需分配长度为 $C + 1$ 的连续内存空间。

## 延伸思考 / 模式总结

0/1 背包的一维逆序压缩是动态规划空间优化的标志性技巧。其本质是利用数据依赖的单向性：当新一轮计算只需要旧一轮同列及左侧的离散状态时，从右向左覆盖可以自然保护左侧尚未读取的旧状态不被破坏。
