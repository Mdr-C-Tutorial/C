# 35809 - 状态压缩 DP（旅行商问题 TSP）

## 题目描述

给定包含 $n$ 个城市的图，城市之间的距离由矩阵 $dist$ 给出（$dist[u \times n + v]$ 表示从城市 $u$ 前往城市 $v$ 的非负距离，距离保证非对称或对称有效）。旅行商必须从城市 $0$ 出发，恰好访问每一个城市一次，最后回到城市 $0$。

求旅行商完成此旅行的**最短路径总长度**，并将具体的**最优城市访问路线**依次写入到数组 `out_path` 中。

函数签名如下：

```c
#include <stdbool.h>
#include <stddef.h>
#include <stdint.h>

bool tsp_solve(
    const uint32_t *dist,
    size_t n,
    uint64_t *out_min_cost,
    size_t *out_path,
    size_t path_capacity
);
```

要求：
1. 城市数量满足 $1 \le n \le 20$。当 $n > 20$ 时返回 `false`（防指数爆炸）。
2. 参数无效或缓冲区不足（路径长度为 $n + 1$，包含起点与终点城市 0）时返回 `false`。
3. 当 $n = 1$ 时，唯一回路代价为 0，路径为 `[0, 0]`，输出后返回 `true`。
4. 必须使用二进制位掩码表示已访问城市集合，空间复杂度为 $O(2^n \times n)$，时间复杂度为 $O(2^n \times n^2)$。

## 解题思路

1. **集合的状态压缩表示**：
   对于规模较小的问题（$n \le 20$），可以用一个整数的二进制位表示子集：
   若二进制数的第 $k$ 位为 `1`，表示城市 $k$ 已经被访问；若为 `0` 表示尚未访问。
   全集大小为 $2^n$。

2. **状态定义与转移方程**：
   定义状态 $dp[mask][u]$ 表示：已访问的城市集合为 $mask$（且 $mask$ 必须包含起点城市 0，即 `(mask & 1) != 0`），并且**当前所在城市为 $u$** 时的最小累计行程。
   
   初始边界条件：
   - 起点出发状态：$dp[1][0] = 0$（仅访问了城市 0，当前停在城市 0）；
   - 其余状态全设为无穷大（`UINT64_MAX`）。

   枚举当前集合 $mask$，以及当前所在城市 $u$（要求 $u \in mask$）：
   枚举下一个将要访问的城市 $v$（要求 $v \notin mask$）：
   $$next\_mask = mask \mid (1 \ll v)$$
   $$dp[next\_mask][v] = \min(dp[next\_mask][v], \; dp[mask][u] + dist[u][v])$$

3. **闭合回路与路径反向重建**：
   当遍历完所有子集后，访问全集为 $full\_mask = (1 \ll n) - 1$。
   此时需从最后的城市 $u$ 返回起始城市 0，最终最短回路长度为：
   $$min\_cost = \min_{1 \le u < n} (dp[full\_mask][u] + dist[u][0])$$
   通过维护前驱记录表 `parent[mask][u]`，可从终点一步步反向回溯找出唯一的最佳巡回顺序。

## C 语言实现

```c
#include <assert.h>
#include <stdbool.h>
#include <stddef.h>
#include <stdint.h>
#include <stdlib.h>
#include <string.h>

bool tsp_solve(
    const uint32_t *dist,
    size_t n,
    uint64_t *out_min_cost,
    size_t *out_path,
    size_t path_capacity
) {
    if (out_min_cost == NULL || (n > 0 && dist == NULL)) {
        return false;
    }
    if (n == 0 || n > 20) {
        return false; // 超出位掩码范围或无城市
    }
    if (out_path == NULL || path_capacity < n + 1) {
        return false;
    }
    if (n == 1) {
        *out_min_cost = 0;
        out_path[0] = 0;
        out_path[1] = 0;
        return true;
    }

    size_t num_states = (size_t)1 << n;
    size_t total_cells = num_states * n;
    if (total_cells > SIZE_MAX / sizeof(uint64_t) ||
        total_cells > SIZE_MAX / sizeof(size_t)) {
        return false;
    }

    uint64_t *dp = malloc(total_cells * sizeof *dp);
    size_t *parent = malloc(total_cells * sizeof *parent);
    if (dp == NULL || parent == NULL) {
        free(dp);
        free(parent);
        return false;
    }

    for (size_t i = 0; i < total_cells; ++i) {
        dp[i] = UINT64_MAX;
        parent[i] = SIZE_MAX;
    }

    // 初始状态: 仅访问城市 0
    dp[1 * n + 0] = 0;

    for (size_t mask = 1; mask < num_states; ++mask) {
        if ((mask & 1) == 0) {
            continue; // 起点城市 0 必须在集合中
        }
        for (size_t u = 0; u < n; ++u) {
            if ((mask & ((size_t)1 << u)) == 0) {
                continue;
            }
            uint64_t current_cost = dp[mask * n + u];
            if (current_cost == UINT64_MAX) {
                continue;
            }

            for (size_t v = 0; v < n; ++v) {
                if ((mask & ((size_t)1 << v)) != 0) {
                    continue; // 城市 v 已访问
                }
                size_t next_mask = mask | ((size_t)1 << v);
                uint64_t d = dist[u * n + v];
                if (current_cost > UINT64_MAX - d) {
                    continue;
                }
                uint64_t candidate = current_cost + d;
                if (candidate < dp[next_mask * n + v]) {
                    dp[next_mask * n + v] = candidate;
                    parent[next_mask * n + v] = u;
                }
            }
        }
    }

    // 回到起点 0
    size_t full_mask = num_states - 1;
    uint64_t min_total = UINT64_MAX;
    size_t best_last = SIZE_MAX;

    for (size_t u = 1; u < n; ++u) {
        uint64_t cost_to_u = dp[full_mask * n + u];
        if (cost_to_u == UINT64_MAX) {
            continue;
        }
        uint64_t d = dist[u * n + 0];
        if (cost_to_u > UINT64_MAX - d) {
            continue;
        }
        uint64_t total = cost_to_u + d;
        if (total < min_total) {
            min_total = total;
            best_last = u;
        }
    }

    if (best_last == SIZE_MAX) {
        free(dp);
        free(parent);
        return false;
    }

    // 重建路径: 从终点反推到起点 0
    out_path[n] = 0;
    size_t curr = best_last;
    size_t cur_mask = full_mask;
    for (size_t step = n; step > 1; --step) {
        out_path[step - 1] = curr;
        size_t p = parent[cur_mask * n + curr];
        cur_mask ^= ((size_t)1 << curr);
        curr = p;
    }
    out_path[0] = 0;

    *out_min_cost = min_total;
    free(dp);
    free(parent);
    return true;
}

int main(void) {
    uint64_t cost = 0;
    size_t path[16];

    // n = 1 边界
    const uint32_t d1[1] = {0};
    assert(tsp_solve(d1, 1, &cost, path, 16));
    assert(cost == 0 && path[0] == 0 && path[1] == 0);

    // 4 城市对称 TSP 经典用例
    // 0 - 1: 10,  0 - 2: 15,  0 - 3: 20
    // 1 - 2: 35,  1 - 3: 25,  2 - 3: 30
    // 最优回路: 0 -> 1 -> 3 -> 2 -> 0，权重 = 10 + 25 + 30 + 15 = 80
    const uint32_t d4[16] = {
        0,  10, 15, 20,
        10, 0,  35, 25,
        15, 35, 0,  30,
        20, 25, 30, 0
    };
    assert(tsp_solve(d4, 4, &cost, path, 16));
    assert(cost == 80);
    assert(path[0] == 0 && path[4] == 0);

    return 0;
}
```

## 复杂度分析

- **时间复杂度**：$O(2^n \times n^2)$。状态总数为 $2^n \times n$，每个状态枚举 $n$ 个候选邻居转移。相比于暴力枚举全排列的 $O(n!)$，在 $n=20$ 时计算量从 $2.4 \times 10^{18}$ 剧降至 $4 \times 10^8$。
- **空间复杂度**：$O(2^n \times n)$。动态规划表格和前驱表格均需要存储 $2^n \times n$ 个条目。

## 延伸思考 / 模式总结

TSP 算法即著名的 Held-Karp 算法。**状态压缩动态规划**的核心思想是将离散集合编码为二进制整数，利用位运算（`&`、`|`、`^`、`<<`）在 $O(1)$ 时间内完成集合包含、并集、差集等操作。
