# 题解：31202

## 题目

在连续顺序表上应用快慢双指针（读写双下标）技术，实现无额外空间开销的原地元素剔除与有序去重算法：

```c
#include <stddef.h>

size_t array_remove_val(int *arr, size_t len, int target);
size_t array_dedup_sorted(int *arr, size_t len);
```

要求：

1. **指定值就地剔除**：`array_remove_val` 原地移除所有等于 `target` 的元素，将其余保留元素按原始相对次序紧凑平移至数组前端，返回剔除后的有效长度。
2. **有序去重**：`array_dedup_sorted` 针对非递减升序顺序表，原地压缩连续重复项，使得每个数值在去重后的前缀中仅保留一份，返回压缩后的有效长度。
3. **复杂度约束**：两算法均要求在单次线性扫描 $O(n)$ 时间内完成，辅助空间复杂度严格为 $O(1)$，严禁开辟辅助数组。
4. **防御性契约**：当传入数组指针为 `NULL` 或输入长度为 0 时，安全返回 0。

## 解析

在顺序表中删除指定元素若采用朴素方法（每遇到一个目标元素就将后缀所有元素左移一位），最坏情况下的时间复杂度为 $O(n^2)$。快慢双下标模式将过滤与紧凑搬移合二为一，在单次扫描中完成全部整理。

1. **双下标不变式（剔除目标值）**：
   - 维护读下标 `read_idx`（遍历原数组的所有元素）和写下标 `write_idx`（指向当前已整理好的有效序列末尾）。
   - 状态不变式：在任意遍历时刻，下标区间 $[0, write\_idx)$ 内的所有元素均不等于 `target`，且它们严格保持了在原数组中的先后次序。
   - 遍历判定：若 `arr[read_idx] != target`，则将该元素搬移至写入位置 `arr[write_idx] = arr[read_idx]` 并递增 `write_idx++`；若等于 `target` 则直接跳过。
   - 遍历完成后，`write_idx` 即为保留元素的总数，时间复杂度为严格的 $O(n)$。

2. **升序连续去重机制**：
   - 对于非递减序列，相同数值必然在物理存储上紧密相邻。
   - 数组长度小于等于 1 时无需去重，直接返回原长度。
   - 长度大于 1 时，令写下标初始为 `write_idx = 1`（首元素必然被保留），读下标从 `read_idx = 1` 开始步进。
   - 判定准则：若 `arr[read_idx] != arr[write_idx - 1]`，说明读到了一个全新的数值，执行写入 `arr[write_idx] = arr[read_idx]` 并递增 `write_idx++`；否则说明与当前已提交的最新元素重复，忽略跳过。
   - 全程仅一次线性扫描，时间复杂度为 $O(n)$，空间复杂度严格为 $O(1)$。

## 答案

```c
#include <assert.h>
#include <stddef.h>

size_t array_remove_val(int *arr, size_t len, int target) {
    if (arr == NULL || len == 0) {
        return 0;
    }
    size_t write_idx = 0;
    for (size_t read_idx = 0; read_idx < len; ++read_idx) {
        if (arr[read_idx] != target) {
            arr[write_idx] = arr[read_idx];
            write_idx++;
        }
    }
    return write_idx;
}

size_t array_dedup_sorted(int *arr, size_t len) {
    if (arr == NULL || len == 0) {
        return 0;
    }
    size_t write_idx = 1;
    for (size_t read_idx = 1; read_idx < len; ++read_idx) {
        if (arr[read_idx] != arr[write_idx - 1]) {
            arr[write_idx] = arr[read_idx];
            write_idx++;
        }
    }
    return write_idx;
}

int main(void) {
    int a1[] = {3, 2, 2, 3, 4, 3, 5};
    size_t len1 = sizeof(a1) / sizeof(a1[0]);
    size_t new_len1 = array_remove_val(a1, len1, 3);
    assert(new_len1 == 4);
    assert(a1[0] == 2 && a1[1] == 2 && a1[2] == 4 && a1[3] == 5);

    int a2[] = {1, 1, 2, 2, 2, 3, 4, 4, 5};
    size_t len2 = sizeof(a2) / sizeof(a2[0]);
    size_t new_len2 = array_dedup_sorted(a2, len2);
    assert(new_len2 == 5);
    for (size_t i = 0; i < new_len2; ++i) {
        assert(a2[i] == (int)(i + 1));
    }

    int a3[] = {7, 7, 7, 7};
    assert(array_dedup_sorted(a3, 4) == 1);
    assert(a3[0] == 7);

    assert(array_remove_val(NULL, 10, 5) == 0);
    assert(array_dedup_sorted(NULL, 10) == 0);
    assert(array_remove_val(a1, 0, 3) == 0);
    assert(array_dedup_sorted(a2, 0) == 0);

    return 0;
}
```
