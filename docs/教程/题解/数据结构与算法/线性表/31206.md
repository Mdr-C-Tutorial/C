# 题解：31205

## 题目

实现单链表的反转、有序归并与环路检测三项核心拓扑算法：

```c
#include <stdbool.h>
#include <stddef.h>

typedef struct ListNode {
    int val;
    struct ListNode *next;
} ListNode;

ListNode *list_reverse(ListNode *head);
ListNode *list_merge_sorted(ListNode *l1, ListNode *l2);
bool list_detect_cycle(
    const ListNode *head,
    const ListNode **out_entry,
    size_t *out_cycle_len
);
```

要求：

1. **原地逆置**：`list_reverse` 原地翻转单链表，返回新头结点指针；严禁分配任何新结点，辅助空间严格为 $O(1)$。
2. **有序归并**：`list_merge_sorted` 将两个非递减单链表无缝融合成一条新的升序单链表；必须复用既有结点指针重新连接，严禁调用内存分配函数，辅助空间严格为 $O(1)$。
3. **环路判定与入口定位（Floyd 判圈算法）**：`list_detect_cycle` 检测单链表中是否存在环：若存在环，将 `*out_entry` 指向环入口首结点，将 `*out_cycle_len` 设置为环内结点总数，并返回 `true`；若无环返回 `false` 且输出项置空。
4. **复杂度契约**：所有算法的时间复杂度均为 $O(n)$，辅助空间严格为 $O(1)$。

## 解析

单链表拓扑关系调整是链式数据结构的基础。指针重连操作无需搬移数据本体，但要求指针修改次序具备极高的严谨性。

1. **三指针迭代原地反转**：
   - 维护三个指针：`prev`（已反转链表的新头，初始为 `NULL`）、`curr`（当前待处理结点，初始为 `head`）与 `next`（暂存未处理后缀）。
   - 迭代过程：先暂存后继 `next = curr->next`，然后翻转当前结点的指向 `curr->next = prev`，最后将双指针同步向前平移：`prev = curr`，`curr = next`。
   - 遍历直到 `curr == NULL`，最终 `prev` 即为反转后的新表头。

2. **哑结点（Dummy Head）归并双链表**：
   - 使用局部栈上分配的虚拟头结点 `ListNode dummy = {0, NULL};`，避免针对初始非空链表表头的繁琐特判。
   - 尾指针 `tail` 初始指向 `&dummy`。比对两个链表头结点的值，将较小者挂接在 `tail->next` 上并推进该链表指针与 `tail`；循环终止后将非空残余链表一次性拼接至 `tail->next`。最终返回 `dummy.next`。

3. **Floyd 判圈与入口相遇数学推导**：
   - **快慢双指针**：慢指针 `slow` 每次走 1 步，快指针 `fast` 每次走 2 步。若链表无环，`fast` 必然先抵达 `NULL`；若链表有环，快慢指针必然在环内相遇。
   - **入口距离推导**：设链表起点到环入口的无环距离为 $F$，环周长为 $C$。设相遇时慢指针在环内走了距离 $a$。
   - 相遇时慢指针总步数为 $F + a$，快指针总步数为 $F + a + kC$（$k \ge 1$ 为快指针多绕环的圈数）。
   - 由于快指针步速为慢指针的 2 倍：$2(F + a) = F + a + kC \implies F = kC - a = (k - 1)C + (C - a)$。
   - 这意味着：若此时让一个指针从链表起点 `head` 出发，另一个指针从相遇点 `slow` 出发，两指针均以每次 1 步的相同速度向前走，走过 $F$ 步后，从起点出发的指针抵达环入口，而从相遇点出发的指针恰好绕行 $(k - 1)$ 圈并走完剩余的 $C - a$ 段，两指针必然恰好在环入口首结点处相遇！
   - 定位入口后，让指针沿环前行一周回到入口，即可在 $O(C)$ 时间内统计出环的长度。

## 答案

```c
#include <assert.h>
#include <stdbool.h>
#include <stddef.h>
#include <stdlib.h>

typedef struct ListNode {
    int val;
    struct ListNode *next;
} ListNode;

ListNode *list_reverse(ListNode *head) {
    ListNode *prev = NULL;
    ListNode *curr = head;
    while (curr != NULL) {
        ListNode *next = curr->next;
        curr->next = prev;
        prev = curr;
        curr = next;
    }
    return prev;
}

ListNode *list_merge_sorted(ListNode *l1, ListNode *l2) {
    ListNode dummy = {0, NULL};
    ListNode *tail = &dummy;

    while (l1 != NULL && l2 != NULL) {
        if (l1->val <= l2->val) {
            tail->next = l1;
            l1 = l1->next;
        } else {
            tail->next = l2;
            l2 = l2->next;
        }
        tail = tail->next;
    }

    tail->next = (l1 != NULL) ? l1 : l2;
    return dummy.next;
}

bool list_detect_cycle(
    const ListNode *head,
    const ListNode **out_entry,
    size_t *out_cycle_len
) {
    if (head == NULL || head->next == NULL) {
        if (out_entry != NULL) {
            *out_entry = NULL;
        }
        if (out_cycle_len != NULL) {
            *out_cycle_len = 0;
        }
        return false;
    }

    const ListNode *slow = head;
    const ListNode *fast = head;
    bool has_cycle = false;

    while (fast != NULL && fast->next != NULL) {
        slow = slow->next;
        fast = fast->next->next;
        if (slow == fast) {
            has_cycle = true;
            break;
        }
    }

    if (!has_cycle) {
        if (out_entry != NULL) {
            *out_entry = NULL;
        }
        if (out_cycle_len != NULL) {
            *out_cycle_len = 0;
        }
        return false;
    }

    const ListNode *ptr1 = head;
    const ListNode *ptr2 = slow;
    while (ptr1 != ptr2) {
        ptr1 = ptr1->next;
        ptr2 = ptr2->next;
    }
    const ListNode *entry = ptr1;

    size_t cycle_len = 1;
    const ListNode *cursor = entry->next;
    while (cursor != entry) {
        cycle_len++;
        cursor = cursor->next;
    }

    if (out_entry != NULL) {
        *out_entry = entry;
    }
    if (out_cycle_len != NULL) {
        *out_cycle_len = cycle_len;
    }
    return true;
}

static ListNode *create_node(int val) {
    ListNode *n = malloc(sizeof(ListNode));
    assert(n != NULL);
    n->val = val;
    n->next = NULL;
    return n;
}

int main(void) {
    ListNode *n1 = create_node(1);
    ListNode *n2 = create_node(2);
    ListNode *n3 = create_node(3);
    n1->next = n2;
    n2->next = n3;

    ListNode *rev = list_reverse(n1);
    assert(rev == n3 && rev->next == n2 && rev->next->next == n1 && rev->next->next->next == NULL);

    ListNode *a1 = create_node(1);
    ListNode *a2 = create_node(3);
    ListNode *a3 = create_node(5);
    a1->next = a2;
    a2->next = a3;

    ListNode *b1 = create_node(2);
    ListNode *b2 = create_node(4);
    ListNode *b3 = create_node(6);
    b1->next = b2;
    b2->next = b3;

    ListNode *merged = list_merge_sorted(a1, b1);
    ListNode *cur = merged;
    for (int i = 1; i <= 6; ++i) {
        assert(cur != NULL && cur->val == i);
        cur = cur->next;
    }

    const ListNode *entry = NULL;
    size_t cycle_len = 0;
    assert(!list_detect_cycle(merged, &entry, &cycle_len));
    assert(entry == NULL && cycle_len == 0);

    b3->next = a2;
    assert(list_detect_cycle(merged, &entry, &cycle_len));
    assert(entry == a2);
    assert(cycle_len == 4);

    b3->next = NULL;
    while (merged != NULL) {
        ListNode *tmp = merged->next;
        free(merged);
        merged = tmp;
    }
    while (rev != NULL) {
        ListNode *tmp = rev->next;
        free(rev);
        rev = tmp;
    }

    return 0;
}
```
