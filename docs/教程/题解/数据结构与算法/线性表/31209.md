# 题解：31209

## 题目

设计并实现具有滞后收缩阈值（Hysteresis Shrinking）的动态数组抽象数据类型，彻底杜绝容量临界点交替插入与删除导致的复杂度抖动（Thrashing）：

```c
#include <stdbool.h>
#include <stddef.h>

typedef struct Hvec Hvec;

Hvec *hvec_create(void);
void hvec_destroy(Hvec *vec);
bool hvec_push_back(Hvec *vec, int value);
bool hvec_pop_back(Hvec *vec, int *out_value);
bool hvec_shrink_to_fit(Hvec *vec);
size_t hvec_size(const Hvec *vec);
size_t hvec_capacity(const Hvec *vec);
```

要求：

1. **扩容策略**：数组初始容量为 0（首次插入分配初始容量 8）。当元素数量达到当前容量时，按 2 倍几何扩容。
2. **滞后缩容策略**：当且仅当元素数量减少至 $capacity / 4$ 且当前容量大于等于 16 时，才将底层存储收缩至当前容量的 $1/2$。
3. **防抖动数学证明**：详细证明为什么“$1/4$ 阈值收缩至 $1/2$”能保证任意连续混合操作序列的单次均摊时间复杂度为严格的 $O(1)$，而“$1/2$ 阈值收缩至 $1/2$”会导致最坏 $O(n)$ 抖动。
4. **容错性契约**：缩容时若 `realloc` 失败，必须保持原容量与已有数据完好，操作正常成功完成（优雅降级）。
5. **手动紧凑**：`hvec_shrink_to_fit` 手动将底层容量收缩至当前元素个数（若大小为 0 则彻底释放底层存储并重置容量为 0）。

## 解析

动态数组（如 C++ `std::vector`）采用几何倍增扩容，其追加操作的均摊时间复杂度为 $O(1)$。但如果缩容策略设计不当，会引入严重的性能灾难。

1. **朴素缩容方案的“抖动（Thrashing）”陷阱**：
   - 假设缩容规则设定为“当元素数量低于容量一半时，将容量减半”：
     - 当前容量为 $N$，数组已满（$size = N$）；
     - 执行一次 `push_back`，触发扩容至 $2N$，需要耗费 $O(N)$ 搬移数据；
     - 紧接着执行两次 `pop_back`，此时 $size = N - 1 < (2N)/2$，立即触发缩容回 $N$，再次耗费 $O(N)$ 搬移数据；
     - 此时再执行一次 `push_back`，又立即触发扩容至 $2N$！
   - 在临界点附近交替执行插入与删除，每一次操作都伴随全数组的内存重分配与复制，单次均摊复杂度急剧恶化至 $O(n)$。这种现象称为复杂度抖动。

2. **势能分析法（Potential Method）证明滞后缩容的均摊 $O(1)$**：
   - 引入物理学中的势能函数 $\Phi$：
     - 当装载因子 $\alpha = size / capacity \ge 1/2$ 时，定义势能 $\Phi = 2 \cdot size - capacity$；
     - 当装载因子 $\alpha < 1/2$ 时，定义势能 $\Phi = capacity / 2 - size$。
   - 不变式性质：
     - 当刚完成扩容时，$\alpha = 1/2$，此时 $\Phi = 0$；
     - 当数组满需要扩容时，$\alpha = 1$，此时 $\Phi = capacity$。这积累的势能足以支付下一次扩容所消耗的 $O(capacity)$ 复制成本；
     - 当数组元素减少到 $1/4$ 需要缩容时，$\Phi = capacity / 2 - capacity / 4 = capacity / 4$。收缩至 $capacity / 2$ 后，新装载因子变为 $(capacity / 4) / (capacity / 2) = 1/2$，势能归零！
   - 这意味着从一次缩容状态到下一次扩容，或者从扩容到下一次缩容，中间至少必须经历 $\Omega(capacity)$ 次常数代价的普通操作。因此，平摊到每次操作上的均摊时间复杂度为严格的 $O(1)$。

3. **内存分配故障优雅降级**：
   - 扩容失败必须阻止操作并报错，因为新元素无处安放；
   - 缩容只是对未用空间的回收，若系统内核此时无法提供连续的新布局，直接保留原存储并不影响当前弹出操作的正确性，原顺序表依然可以安全运转。

## 答案

```c
#include <assert.h>
#include <stdbool.h>
#include <stddef.h>
#include <stdint.h>
#include <stdlib.h>

typedef struct Hvec Hvec;

Hvec *hvec_create(void);
void hvec_destroy(Hvec *vec);
bool hvec_push_back(Hvec *vec, int value);
bool hvec_pop_back(Hvec *vec, int *out_value);
bool hvec_shrink_to_fit(Hvec *vec);
size_t hvec_size(const Hvec *vec);
size_t hvec_capacity(const Hvec *vec);

struct Hvec {
    int *data;
    size_t size;
    size_t capacity;
};

enum {
    HVEC_INIT_CAPACITY = 8,
    HVEC_MIN_SHRINK_CAPACITY = 16
};

Hvec *hvec_create(void) {
    Hvec *vec = malloc(sizeof(Hvec));
    if (vec == NULL) {
        return NULL;
    }
    vec->data = NULL;
    vec->size = 0;
    vec->capacity = 0;
    return vec;
}

void hvec_destroy(Hvec *vec) {
    if (vec == NULL) {
        return;
    }
    free(vec->data);
    free(vec);
}

static bool hvec_grow(Hvec *vec) {
    size_t max_cap = SIZE_MAX / sizeof(int);
    if (vec->capacity >= max_cap) {
        return false;
    }

    size_t next = (vec->capacity == 0) ? HVEC_INIT_CAPACITY : vec->capacity * 2;
    if (next > max_cap || next < vec->capacity) {
        next = max_cap;
    }

    int *new_data = realloc(vec->data, next * sizeof(int));
    if (new_data == NULL) {
        return false;
    }

    vec->data = new_data;
    vec->capacity = next;
    return true;
}

static void hvec_maybe_shrink(Hvec *vec) {
    if (vec->capacity >= HVEC_MIN_SHRINK_CAPACITY && vec->size <= vec->capacity / 4) {
        size_t next = vec->capacity / 2;
        int *new_data = realloc(vec->data, next * sizeof(int));
        if (new_data != NULL) {
            vec->data = new_data;
            vec->capacity = next;
        }
    }
}

bool hvec_push_back(Hvec *vec, int value) {
    if (vec == NULL) {
        return false;
    }
    if (vec->size == vec->capacity) {
        if (!hvec_grow(vec)) {
            return false;
        }
    }
    vec->data[vec->size] = value;
    vec->size++;
    return true;
}

bool hvec_pop_back(Hvec *vec, int *out_value) {
    if (vec == NULL || out_value == NULL || vec->size == 0) {
        return false;
    }
    vec->size--;
    *out_value = vec->data[vec->size];
    hvec_maybe_shrink(vec);
    return true;
}

bool hvec_shrink_to_fit(Hvec *vec) {
    if (vec == NULL) {
        return false;
    }
    if (vec->size == vec->capacity) {
        return true;
    }
    if (vec->size == 0) {
        free(vec->data);
        vec->data = NULL;
        vec->capacity = 0;
        return true;
    }

    int *new_data = realloc(vec->data, vec->size * sizeof(int));
    if (new_data == NULL) {
        return false;
    }
    vec->data = new_data;
    vec->capacity = vec->size;
    return true;
}

size_t hvec_size(const Hvec *vec) {
    return (vec == NULL) ? 0 : vec->size;
}

size_t hvec_capacity(const Hvec *vec) {
    return (vec == NULL) ? 0 : vec->capacity;
}

int main(void) {
    hvec_destroy(NULL);
    assert(hvec_size(NULL) == 0);
    assert(hvec_capacity(NULL) == 0);

    Hvec *v = hvec_create();
    assert(v != NULL);
    assert(hvec_size(v) == 0 && hvec_capacity(v) == 0);

    for (int i = 0; i < 9; ++i) {
        assert(hvec_push_back(v, i));
    }
    assert(hvec_size(v) == 9);
    assert(hvec_capacity(v) == 16);

    int out = 0;
    for (int i = 0; i < 5; ++i) {
        assert(hvec_pop_back(v, &out));
    }
    assert(hvec_size(v) == 4);
    assert(hvec_capacity(v) == 8);

    assert(hvec_push_back(v, 99));
    assert(hvec_capacity(v) == 8);
    assert(hvec_pop_back(v, &out) && out == 99);
    assert(hvec_capacity(v) == 8);

    assert(hvec_shrink_to_fit(v));
    assert(hvec_size(v) == 4);
    assert(hvec_capacity(v) == 4);

    hvec_destroy(v);
    return 0;
}
```
