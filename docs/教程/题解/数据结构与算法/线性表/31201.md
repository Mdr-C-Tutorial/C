# 题解：31201

## 题目

基于连续内存的顺序表，实现原地闭区间逆置与左右循环移位算法：

```c
#include <stddef.h>

void array_reverse(int *arr, size_t start, size_t end);
void array_rotate_left(int *arr, size_t len, size_t k);
void array_rotate_right(int *arr, size_t len, size_t k);
```

要求：

1. **区间原地逆置**：`array_reverse` 原地翻转下标闭区间 $[start, end]$ 内的所有元素。若 $start \ge end$ 或数组指针为空，保持原数组不变。
2. **空间限制**：循环左移与循环右移必须使用三步反转法（Reversal Algorithm）原地完成，严禁分配任何动态辅助堆内存或变长栈数组，辅助空间复杂度严格为 $O(1)$。
3. **周期性与边界契约**：有效移位步数应当针对长度取模 $k \pmod{len}$；正确处理 $len \le 1$、$k = 0$ 以及数组指针为 `NULL` 的边界情况。
4. **时间复杂度**：整体算法的时间复杂度严格为 $O(n)$。

## 解析

顺序表物理内存连续，支持以常数时间 $O(1)$ 通过物理下标随机寻址。在不借助辅助缓冲区的前提下，直接平移元素可能导致被覆盖位置的数据丢失，或者需要复杂的置换环计算。三步反转法是解决循环移位的经典原地算法。

1. **双下标对向交换逆置**：
   - 逆置闭区间 $[start, end]$ 时，初始化左下标 `left = start`、右下标 `right = end`。
   - 每次交换 `arr[left]` 与 `arr[right]`，并同步执行 `left++` 与 `right--`，直到双下标相遇或交错。
   - 无论区间长度是奇数还是偶数，总交换次数为 $\lfloor(end - start + 1) / 2\rfloor$，耗时为 $O(end - start + 1)$，辅助空间为单个局部临时数值。

2. **三步反转定理推导**：
   - 设数组可拆分为前后两段：$A = arr[0 \dots k-1]$，$B = arr[k \dots len-1]$，原数组表示为序列 $AB$。
   - 循环左移 $k$ 步的目标是得到序列 $BA$。
   - 利用代数反转性质 $(A^R B^R)^R = (B^R)^R (A^R)^R = BA$：
     1. 第一步：反转前缀 $A \to A^R$，即调用 `array_reverse(arr, 0, k - 1)`；
     2. 第二步：反转后缀 $B \to B^R$，即调用 `array_reverse(arr, k, len - 1)`；
     3. 第三步：反转整体 $A^R B^R \to BA$，即调用 `array_reverse(arr, 0, len - 1)`。
   - 每个元素在整个过程中恰好被反转参与 2 次，总体时间复杂度为严格的 $2n = O(n)$。

3. **左右旋转对称性**：
   - 将长度为 $len$ 的数组循环右移 $k$ 步，数学上等价于循环左移 $(len - (k \pmod{len})) \pmod{len}$ 步。因此 `array_rotate_right` 可以直接复用左移逻辑。

## 答案

```c
#include <assert.h>
#include <stddef.h>

void array_reverse(int *arr, size_t start, size_t end) {
    if (arr == NULL || start >= end) {
        return;
    }
    size_t left = start;
    size_t right = end;
    while (left < right) {
        int tmp = arr[left];
        arr[left] = arr[right];
        arr[right] = tmp;
        left++;
        right--;
    }
}

void array_rotate_left(int *arr, size_t len, size_t k) {
    if (arr == NULL || len <= 1) {
        return;
    }
    k %= len;
    if (k == 0) {
        return;
    }
    array_reverse(arr, 0, k - 1);
    array_reverse(arr, k, len - 1);
    array_reverse(arr, 0, len - 1);
}

void array_rotate_right(int *arr, size_t len, size_t k) {
    if (arr == NULL || len <= 1) {
        return;
    }
    k %= len;
    if (k == 0) {
        return;
    }
    array_rotate_left(arr, len, len - k);
}

int main(void) {
    int a[] = {1, 2, 3, 4, 5, 6, 7};
    size_t n = sizeof(a) / sizeof(a[0]);

    array_reverse(a, 2, 5);
    assert(a[0] == 1 && a[1] == 2 && a[2] == 6 && a[3] == 5 && a[4] == 4 && a[5] == 3 && a[6] == 7);

    array_reverse(a, 2, 5);
    assert(a[2] == 3 && a[3] == 4 && a[4] == 5 && a[5] == 6);

    array_rotate_left(a, n, 2);
    assert(a[0] == 3 && a[1] == 4 && a[2] == 5 && a[3] == 6 && a[4] == 7 && a[5] == 1 && a[6] == 2);

    array_rotate_right(a, n, 2);
    for (size_t i = 0; i < n; ++i) {
        assert(a[i] == (int)(i + 1));
    }

    array_rotate_left(a, n, n * 3 + 1);
    assert(a[0] == 2 && a[6] == 1);
    array_rotate_right(a, n, n * 5 + 1);
    assert(a[0] == 1 && a[6] == 7);

    array_reverse(NULL, 0, 10);
    array_rotate_left(NULL, 0, 3);
    array_rotate_right(NULL, 0, 3);

    return 0;
}
```
