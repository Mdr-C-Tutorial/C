# 36002 - 二分图判定（BFS/DFS 染色法）

## 题目描述

给定一个无向图（顶点编号为 $0, 1, \dots, V - 1$），判定该图是否是一个**二分图（Bipartite Graph）**。

如果能将图的顶点集分割为两个互不相交的独立子集 $U$ 和 $V$，使得图中的每一条边的两个端点分别属于 $U$ 和 $V$（即子集内部不存在任何边），则该图为二分图。

函数签名如下：

```c
#include <stdbool.h>
#include <stddef.h>

bool is_bipartite_graph(
    size_t vertex_count,
    const size_t edges[][2],
    size_t edge_count,
    bool *out_is_bipartite
);
```

要求：
1. 参数无效时返回 `false`。
2. 当 $V = 0$ 或 $V = 1$ 时，图自然是二分图，输出 `true`。
3. 图可能是非连通的（包含多个独立的连通块），必须对每一个连通分量进行完整染色检验。
4. 采用 2-着色法（颜色标记为 1 和 2，0 表示未染色）。若发现任意一条边的两个端点颜色相同，则判定为非二分图。

## 解题思路

1. **二分图与奇环等价定理**：
   图论经典定理指出：**一个无向图是二分图，当且仅当该图中不包含任何奇数长度的环（Odd Cycle）**。
   因此，问题等价于尝试用两种颜色（1 和 2）为所有顶点染色，使任意相邻顶点的颜色都不相同。

2. **多连通分量的 BFS / DFS 染色遍历**：
   维护一个大小为 $V$ 的数组 `color`，初值全为 0。
   从 $0$ 到 $V - 1$ 遍历每一个顶点 $i$：
   - 若 `color[i] != 0`，说明该顶点已被之前的连通分量遍历染过色，跳过；
   - 若 `color[i] == 0`，则该顶点属于一个新的未染色的连通分量，将其初始染为颜色 1，并从该顶点启动染色遍历。

3. **相邻冲突判定**：
   在遍历过程中，对当前顶点 $u$（颜色为 $c$），其所有邻接点 $v$ 的颜色目标应为反色 $3 - c$（若 $c=1$ 则为 2，若 $c=2$ 则为 1）：
   - 若邻接点 $v$ 尚未染色（`color[v] == 0`）：将其染为反色并加入遍历队列；
   - 若邻接点 $v$ 已经染过色，且颜色恰好等于当前颜色（`color[v] == color[u]`）：**发现奇环冲突**，立即判定图非二分图，返回 `false`。

## C 语言实现

```c
#include <assert.h>
#include <stdbool.h>
#include <stddef.h>
#include <stdint.h>
#include <stdlib.h>

typedef struct EdgeNode EdgeNode;
struct EdgeNode {
    size_t to;
    EdgeNode *next;
};

bool is_bipartite_graph(
    size_t vertex_count,
    const size_t edges[][2],
    size_t edge_count,
    bool *out_is_bipartite
) {
    if (out_is_bipartite == NULL || (edge_count > 0 && edges == NULL)) {
        return false;
    }
    if (vertex_count <= 1) {
        *out_is_bipartite = true;
        return true;
    }

    EdgeNode **adj = calloc(vertex_count, sizeof(EdgeNode*));
    EdgeNode *pool = malloc(2 * edge_count * sizeof(EdgeNode));
    uint8_t *color = calloc(vertex_count, sizeof(uint8_t));
    size_t *queue = malloc(vertex_count * sizeof(size_t));

    if (adj == NULL || (edge_count > 0 && pool == NULL) || color == NULL || queue == NULL) {
        free(adj); free(pool); free(color); free(queue);
        return false;
    }

    // 建立无向图邻接表
    size_t pool_idx = 0;
    for (size_t i = 0; i < edge_count; ++i) {
        size_t u = edges[i][0];
        size_t v = edges[i][1];
        if (u >= vertex_count || v >= vertex_count) {
            free(adj); free(pool); free(color); free(queue);
            return false;
        }
        if (u == v) {
            // 自环必然不是二分图
            *out_is_bipartite = false;
            free(adj); free(pool); free(color); free(queue);
            return true;
        }

        pool[pool_idx].to = v;
        pool[pool_idx].next = adj[u];
        adj[u] = &pool[pool_idx++];

        pool[pool_idx].to = u;
        pool[pool_idx].next = adj[v];
        adj[v] = &pool[pool_idx++];
    }

    bool is_bipartite = true;

    // 遍历所有可能的连通块
    for (size_t start = 0; start < vertex_count && is_bipartite; ++start) {
        if (color[start] != 0) {
            continue;
        }

        size_t head = 0;
        size_t tail = 0;

        color[start] = 1;
        queue[tail++] = start;

        while (head < tail && is_bipartite) {
            size_t u = queue[head++];
            uint8_t next_color = (color[u] == 1) ? 2 : 1;

            for (const EdgeNode *edge = adj[u]; edge != NULL; edge = edge->next) {
                size_t v = edge->to;
                if (color[v] == 0) {
                    color[v] = next_color;
                    queue[tail++] = v;
                } else if (color[v] == color[u]) {
                    is_bipartite = false;
                    break;
                }
            }
        }
    }

    *out_is_bipartite = is_bipartite;

    free(adj);
    free(pool);
    free(color);
    free(queue);
    return true;
}

int main(void) {
    bool res = false;

    // 参数校验
    assert(!is_bipartite_graph(3, NULL, 1, &res));
    assert(!is_bipartite_graph(3, (const size_t[][2]){{0, 1}}, 1, NULL));

    // 简单偶环 (4 环: 0-1-2-3-0) -> 二分图
    const size_t e_c4[4][2] = {
        {0, 1}, {1, 2}, {2, 3}, {3, 0}
    };
    assert(is_bipartite_graph(4, e_c4, 4, &res) && res == true);

    // 奇环 (三角形 3 环: 0-1-2-0) -> 非二分图
    const size_t e_c3[3][2] = {
        {0, 1}, {1, 2}, {2, 0}
    };
    assert(is_bipartite_graph(3, e_c3, 3, &res) && res == false);

    // 包含多个非连通分量：一个树加一个偶环 -> 二分图
    const size_t e_multi[3][2] = {
        {0, 1}, // 连通块 1
        {2, 3}, {3, 4} // 连通块 2
    };
    assert(is_bipartite_graph(5, e_multi, 3, &res) && res == true);

    // 含有自环 -> 非二分图
    const size_t e_self[1][2] = {{0, 0}};
    assert(is_bipartite_graph(2, e_self, 1, &res) && res == false);

    return 0;
}
```

## 复杂度分析

- **时间复杂度**：$O(V + E)$。在邻接表表示下，每个顶点最多入队一次，每条边双向各访问一次。
- **空间复杂度**：$O(V + E)$。邻接表存储 $2E$ 个结点，队列与颜色标记数组占用 $O(V)$ 内存。

## 延伸思考 / 模式总结

二分图判定本质上是 2-着色问题。不同于一般的 $m$-着色（$m \ge 3$）属于 NP-完全问题，2-着色的每一个决策都是确定性强迫的（当前节点颜色确定后，邻居颜色必须被唯一确定），因此在线性时间内即可给出确凿的判断。
