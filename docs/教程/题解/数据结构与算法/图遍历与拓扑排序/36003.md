# 36003 - 拓扑排序 Kahn 算法（基于入度数组与队列）

## 题目描述

给定一个包含 $V$ 个顶点的有向图，使用 Kahn 算法生成一个拓扑序列。

拓扑排序是对有向无环图（DAG）的所有顶点进行线性排布，使得对于图中的任意有向边 $u \to v$，$u$ 在排布序列中均出现在 $v$ 之前。若图中存在有向环，则不可能生成拓扑序列，算法必须准确检测出环的存在。

函数签名如下：

```c
#include <stdbool.h>
#include <stddef.h>

typedef enum {
    TOPO_SUCCESS,
    TOPO_INVALID_ARGUMENT,
    TOPO_CONTAINS_CYCLE
} TopoResult;

TopoResult kahn_topological_sort(
    size_t vertex_count,
    const size_t edges[][2],
    size_t edge_count,
    size_t *out_order,
    size_t capacity
);
```

要求：
1. 参数无效或缓冲区不足（`capacity < vertex_count`）时返回 `TOPO_INVALID_ARGUMENT`。
2. 若图中存在有向环，返回 `TOPO_CONTAINS_CYCLE`，且不得修改输出数组。
3. 基于入度数组与 FIFO 队列实现标准 Kahn 算法。
4. 时间复杂度为 $O(V + E)$，空间复杂度为 $O(V + E)$。

## 解题思路

1. **入度统计与零入度队列**：
   - 拓扑序列的第一批元素必然是没有任何依赖的前置顶点（即入度为 0 的顶点）；
   - 扫描所有有向边，统计每个顶点的初始入度 `in_degree[v]`；
   - 遍历所有顶点，将所有 `in_degree[i] == 0` 的顶点推入入度队列。

2. **动态削减依赖与级联释放**：
   循环从队列中取出一个顶点 $u$：
   - 将 $u$ 写入拓扑排序临时数组；
   - 遍历 $u$ 的所有出边 $u \to v$：
     将目标顶点 $v$ 的入度减 1（`in_degree[v]--`）；
     若减完后 `in_degree[v] == 0`，说明依赖 $v$ 的所有前置前驱均已排入拓扑序，将 $v$ 推入队列。

3. **环路判定**：
   当队列为空时，检查已输出的顶点总数 `output_count`：
   - 若 `output_count == vertex_count`，说明所有顶点均被合法拓扑排序，将临时结果提交至 `out_order` 并返回 `TOPO_SUCCESS`；
   - 若 `output_count < vertex_count`，说明剩余未输出的顶点之间存在互为前驱的环路依赖，导致其入度永远无法降为 0，返回 `TOPO_CONTAINS_CYCLE`。

## C 语言实现

```c
#include <assert.h>
#include <stdbool.h>
#include <stddef.h>
#include <stdint.h>
#include <stdlib.h>
#include <string.h>

typedef enum {
    TOPO_SUCCESS,
    TOPO_INVALID_ARGUMENT,
    TOPO_CONTAINS_CYCLE
} TopoResult;

typedef struct EdgeNode EdgeNode;
struct EdgeNode {
    size_t to;
    EdgeNode *next;
};

TopoResult kahn_topological_sort(
    size_t vertex_count,
    const size_t edges[][2],
    size_t edge_count,
    size_t *out_order,
    size_t capacity
) {
    if (out_order == NULL || capacity < vertex_count ||
        (edge_count > 0 && edges == NULL)) {
        return TOPO_INVALID_ARGUMENT;
    }
    if (vertex_count == 0) {
        return TOPO_SUCCESS;
    }

    EdgeNode **adj = calloc(vertex_count, sizeof(EdgeNode*));
    EdgeNode *pool = malloc(edge_count * sizeof(EdgeNode));
    size_t *in_degree = calloc(vertex_count, sizeof(size_t));
    size_t *queue = malloc(vertex_count * sizeof(size_t));
    size_t *temp_order = malloc(vertex_count * sizeof(size_t));

    if (adj == NULL || (edge_count > 0 && pool == NULL) ||
        in_degree == NULL || queue == NULL || temp_order == NULL) {
        free(adj); free(pool); free(in_degree); free(queue); free(temp_order);
        return TOPO_INVALID_ARGUMENT;
    }

    // 构建有向图邻接表与入度统计
    for (size_t i = 0; i < edge_count; ++i) {
        size_t u = edges[i][0];
        size_t v = edges[i][1];
        if (u >= vertex_count || v >= vertex_count) {
            free(adj); free(pool); free(in_degree); free(queue); free(temp_order);
            return TOPO_INVALID_ARGUMENT;
        }

        pool[i].to = v;
        pool[i].next = adj[u];
        adj[u] = &pool[i];
        in_degree[v]++;
    }

    size_t head = 0;
    size_t tail = 0;

    // 所有入度为 0 的顶点入队
    for (size_t i = 0; i < vertex_count; ++i) {
        if (in_degree[i] == 0) {
            queue[tail++] = i;
        }
    }

    size_t count = 0;
    while (head < tail) {
        size_t u = queue[head++];
        temp_order[count++] = u;

        for (const EdgeNode *edge = adj[u]; edge != NULL; edge = edge->next) {
            size_t v = edge->to;
            in_degree[v]--;
            if (in_degree[v] == 0) {
                queue[tail++] = v;
            }
        }
    }

    TopoResult result;
    if (count == vertex_count) {
        memcpy(out_order, temp_order, vertex_count * sizeof(size_t));
        result = TOPO_SUCCESS;
    } else {
        result = TOPO_CONTAINS_CYCLE;
    }

    free(adj);
    free(pool);
    free(in_degree);
    free(queue);
    free(temp_order);
    return result;
}

int main(void) {
    size_t order[8];

    // 参数校验
    assert(kahn_topological_sort(3, NULL, 1, order, 8) == TOPO_INVALID_ARGUMENT);
    assert(kahn_topological_sort(3, (const size_t[][2]){{0, 1}}, 1, order, 2) == TOPO_INVALID_ARGUMENT);

    // 标准 DAG: 0 -> 1 -> 3, 0 -> 2 -> 3
    // 合法拓扑序可以为 [0, 1, 2, 3] 或 [0, 2, 1, 3]
    const size_t e_dag[4][2] = {
        {0, 1}, {0, 2}, {1, 3}, {2, 3}
    };
    assert(kahn_topological_sort(4, e_dag, 4, order, 8) == TOPO_SUCCESS);
    assert(order[0] == 0 && order[3] == 3);

    // 有向环测试: 0 -> 1 -> 2 -> 0
    const size_t e_cycle[3][2] = {
        {0, 1}, {1, 2}, {2, 0}
    };
    assert(kahn_topological_sort(3, e_cycle, 3, order, 8) == TOPO_CONTAINS_CYCLE);

    // 包含自环测试: 0 -> 0
    const size_t e_self[1][2] = {{0, 0}};
    assert(kahn_topological_sort(2, e_self, 1, order, 8) == TOPO_CONTAINS_CYCLE);

    return 0;
}
```

## 复杂度分析

- **时间复杂度**：$O(V + E)$。建图和统计入度耗时 $O(V + E)$；在 Kahn 算法主循环中，每个顶点入队并出队一次，每条出边被处理一次。
- **空间复杂度**：$O(V + E)$。邻接表占用 $O(E)$，队列、入度数组以及临时缓冲区占用 $O(V)$。

## 延伸思考 / 模式总结

Kahn 算法是典型的贪心消除策略。其核心思想类似于剥洋葱：每次剥掉没有外部依赖的最外层节点，从而暴露下一层。这种队列驱动的设计在工业界编译器依赖图调度、构建系统（Make/Ninja）拓扑构建以及微服务启动顺序编排中被广泛采用。
