# 36008 - 欧拉回路与欧拉路径判断及 Hierholzer 算法

## 题目

在一个包含 $V$ 个顶点的有向图中，**欧拉路径（Eulerian Path）**是一条恰好经过图中**每一条有向边各一次**的路径；如果这条路径的起点与终点是同一个顶点，则称为**欧拉回路（Eulerian Circuit）**。

实现判断有向图中是否存在欧拉路径（或欧拉回路），若存在，利用 **Hierholzer 算法**计算出具体经过的顶点序列并输出到数组 `out_path` 中。

函数签名如下：

```c
#include <stdbool.h>
#include <stddef.h>

bool hierholzer_eulerian_path(
    size_t vertex_count,
    const size_t edges[][2],
    size_t edge_count,
    size_t *out_path,
    size_t path_capacity,
    size_t *out_path_length,
    bool *out_has_eulerian
);
```

要求：
1. 参数无效或缓冲区不足（路径长度必须为 `edge_count + 1`）时返回 `false`。
2. 当 `edge_count == 0` 时，欧拉路径存在且长度为 0，输出后返回 `true`。
3. 正确统计各顶点的入度和出度，判断欧拉路径的存在性：
   - 若所有顶点的出度等于入度，存在欧拉回路（起点可任选具有非零度的顶点）；
   - 若恰好有一个顶点出度比入度大 1（起点），恰好有一个顶点入度比出度大 1（终点），其余顶点的入度等于出度，存在欧拉路径；
   - 其余情况均不存在欧拉路径。
4. 必须通过**当前弧优化（Current Arc Pointer）**保证线性时间复杂度，避免在已访问的边上重复回退扫描。

## 解题思路

1. **度数条件与起点选定**：
   统计每个顶点的入度 `in_deg` 与出度 `out_deg`。
   - 记录入度与出度不相等的顶点个数；
   - 若所有顶点的出度等于入度，说明存在欧拉回路。起点选为任意一个有出边的顶点；
   - 若恰好有且仅有一个顶点满足 $out\_deg - in\_deg == 1$，它必须作为欧拉路径的**起点**；有且仅有一个顶点满足 $in\_deg - out\_deg == 1$，它必须作为**终点**；
   - 若不满足上述两种情形之一，则该图绝不可能存在欧拉路径。

2. **Hierholzer 算法的核心机制**：
   Hierholzer 算法的思想是：从起点出发，沿着尚未走过的边不断前进，直到陷入某个死胡同（无法继续前进）：
   - 当无法继续从当前顶点 $u$ 前进时，**将顶点 $u$ 压入路径栈**；
   - 随后回退到前一个顶点，继续探索其它尚未访问的环路分支；
   - 最终将栈中的顶点逆序弹出，即得到完整的欧拉路径序列。

3. **当前弧优化（$O(E)$ 关键保证）**：
   在邻接表表示下，每次从链表头部 `adj[u]` 取下一条边后，直接将头指针更新为下一条边 `adj[u] = adj[u]->next`。这样每条边在遍历过程中被且仅被处理一次，彻底避免了 $O(E^2)$ 的反复扫描。

## C 语言实现

```c
#include <assert.h>
#include <stdbool.h>
#include <stddef.h>
#include <stdlib.h>

typedef struct EdgeNode EdgeNode;
struct EdgeNode {
    size_t to;
    EdgeNode *next;
};

static void hierholzer_dfs(
    size_t u,
    EdgeNode **cur_adj,
    size_t *stack,
    size_t *stack_top
) {
    while (cur_adj[u] != NULL) {
        EdgeNode *edge = cur_adj[u];
        cur_adj[u] = edge->next; // 移出当前边 (当前弧优化)
        size_t v = edge->to;
        hierholzer_dfs(v, cur_adj, stack, stack_top);
    }
    stack[(*stack_top)++] = u; // 无法前进时入栈
}

bool hierholzer_eulerian_path(
    size_t vertex_count,
    const size_t edges[][2],
    size_t edge_count,
    size_t *out_path,
    size_t path_capacity,
    size_t *out_path_length,
    bool *out_has_eulerian
) {
    if (out_path_length == NULL || out_has_eulerian == NULL) {
        return false;
    }
    if (edge_count == 0) {
        *out_has_eulerian = true;
        *out_path_length = 0;
        return true;
    }
    if (out_path == NULL || path_capacity < edge_count + 1 ||
        vertex_count == 0 || edges == NULL) {
        return false;
    }

    size_t *in_deg = calloc(vertex_count, sizeof(size_t));
    size_t *out_deg = calloc(vertex_count, sizeof(size_t));
    EdgeNode **adj = calloc(vertex_count, sizeof(EdgeNode*));
    EdgeNode *pool = malloc(edge_count * sizeof(EdgeNode));
    size_t *rev_stack = malloc((edge_count + 1) * sizeof(size_t));

    if (in_deg == NULL || out_deg == NULL || adj == NULL || pool == NULL || rev_stack == NULL) {
        free(in_deg); free(out_deg); free(adj); free(pool); free(rev_stack);
        return false;
    }

    for (size_t i = 0; i < edge_count; ++i) {
        size_t u = edges[i][0];
        size_t v = edges[i][1];
        if (u >= vertex_count || v >= vertex_count) {
            free(in_deg); free(out_deg); free(adj); free(pool); free(rev_stack);
            return false;
        }
        pool[i].to = v;
        pool[i].next = adj[u];
        adj[u] = &pool[i];
        out_deg[u]++;
        in_deg[v]++;
    }

    size_t start_node = SIZE_MAX;
    size_t end_node = SIZE_MAX;
    bool degree_valid = true;

    for (size_t i = 0; i < vertex_count; ++i) {
        if (out_deg[i] > in_deg[i]) {
            if (out_deg[i] - in_deg[i] == 1 && start_node == SIZE_MAX) {
                start_node = i;
            } else {
                degree_valid = false;
                break;
            }
        } else if (in_deg[i] > out_deg[i]) {
            if (in_deg[i] - out_deg[i] == 1 && end_node == SIZE_MAX) {
                end_node = i;
            } else {
                degree_valid = false;
                break;
            }
        }
    }

    if (!degree_valid) {
        *out_has_eulerian = false;
        free(in_deg); free(out_deg); free(adj); free(pool); free(rev_stack);
        return true;
    }

    // 若所有节点出入度相等，任选一个有出边的节点作为起点
    if (start_node == SIZE_MAX) {
        for (size_t i = 0; i < vertex_count; ++i) {
            if (out_deg[i] > 0) {
                start_node = i;
                break;
            }
        }
    }

    size_t stack_top = 0;
    hierholzer_dfs(start_node, adj, rev_stack, &stack_top);

    // 检查是否所有边均被遍历 (连通性验证)
    if (stack_top != edge_count + 1) {
        *out_has_eulerian = false;
    } else {
        *out_has_eulerian = true;
        *out_path_length = stack_top;
        // 逆序输出栈中顶点以还原正序路径
        for (size_t i = 0; i < stack_top; ++i) {
            out_path[i] = rev_stack[stack_top - 1 - i];
        }
    }

    free(in_deg);
    free(out_deg);
    free(adj);
    free(pool);
    free(rev_stack);
    return true;
}

int main(void) {
    size_t path[16];
    size_t len = 0;
    bool has_eulerian = false;

    // 参数校验
    assert(!hierholzer_eulerian_path(3, NULL, 1, path, 16, &len, &has_eulerian));

    // 经典欧拉路径: 0 -> 1 -> 2 -> 0 -> 2
    // 边: (0, 1), (1, 2), (2, 0), (0, 2)
    // 0: out 2, in 1 (起点, out - in = 1)
    // 2: out 1, in 2 (终点, in - out = 1)
    // 1: out 1, in 1
    const size_t e_path[4][2] = {
        {0, 1}, {1, 2}, {2, 0}, {0, 2}
    };
    assert(hierholzer_eulerian_path(3, e_path, 4, path, 16, &len, &has_eulerian));
    assert(has_eulerian);
    assert(len == 5);
    assert(path[0] == 0 && path[4] == 2);

    // 经典欧拉回路: 0 -> 1 -> 2 -> 0
    const size_t e_circuit[3][2] = {
        {0, 1}, {1, 2}, {2, 0}
    };
    assert(hierholzer_eulerian_path(3, e_circuit, 3, path, 16, &len, &has_eulerian));
    assert(has_eulerian);
    assert(len == 4);
    assert(path[0] == path[3]); // 回路起点等于终点

    // 不连通或度数不平衡测试 -> 无欧拉路径
    const size_t e_invalid[3][2] = {
        {0, 1}, {0, 2}, {0, 3}
    };
    assert(hierholzer_eulerian_path(4, e_invalid, 3, path, 16, &len, &has_eulerian));
    assert(!has_eulerian);

    return 0;
}
```

## 复杂度分析

- **时间复杂度**：$O(V + E)$。度数检查耗时 $O(V + E)$；在 Hierholzer 遍历中，利用当前弧指针直接剔除已走边，保证每条边仅入栈出栈一次，整体严格在线性时间内完成。
- **空间复杂度**：$O(V + E)$。邻接表需要 $O(E)$，DFS 递归调用栈与结果逆序栈需要 $O(E)$。

## 延伸思考 / 模式总结

欧拉路径（一笔画）是图论的发轫之源（哥尼斯堡七桥问题）。与哈密顿路径（访问每个顶点一次，NP-完全）相比，欧拉路径（访问每条边一次）由于具备局部出入度平衡这一深刻的拓扑不变式，使其具有优美的多项式线性解法。
