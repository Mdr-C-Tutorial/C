# 36001 - 无权图 BFS 单源最短路与路径反向重建

## 题目描述

在一个包含 $V$ 个顶点的无权有向图上，使用广度优先搜索（BFS）求从起始顶点 `source` 到目标顶点 `target` 的**最短跳数距离**，并**反向重建具体的路径顶点序列**输出到数组 `out_path` 中。

函数签名如下：

```c
#include <stdbool.h>
#include <stddef.h>
#include <stdint.h>

typedef struct GraphEdge GraphEdge;
struct GraphEdge {
    size_t to;
    GraphEdge *next;
};

typedef struct {
    GraphEdge *head;
    GraphEdge *tail;
} Adjacency;

typedef struct {
    Adjacency *adj;
    size_t vertex_count;
    bool directed;
} IntGraph;

bool int_graph_shortest_path(
    const IntGraph *graph,
    size_t source,
    size_t target,
    size_t *out_distance,
    size_t *out_path,
    size_t path_capacity
);
```

要求：
1. 若顶点不可达，设置 `*out_distance = SIZE_MAX`，不输出路径，返回 `true`。
2. 若 `source == target`，最短距离为 0，路径包含单个顶点 `[source]`。
3. 参数无效（图指针为空、顶点编号越界等）时返回 `false`。
4. 在 BFS 访问过程中，维护 `parent` 前驱数组；当命中目标顶点时，从 `target` 沿 `parent` 逐级反向追溯至 `source` 并正序填入 `out_path`。
5. 时间复杂度为 $O(V + E)$，空间复杂度为 $O(V)$。

## 解题思路

1. **BFS 的最短路性质**：
   在所有边权均为 1 的无权图中，广度优先搜索以按距离层序向外扩展的方式遍历顶点。某个顶点第一次被访问并入队时的搜索深度，严格等于从起点到该顶点的最短路径长度。

2. **前驱记录与路径重建**：
   维护三个大小为 $V$ 的数组：
   - `dist[v]`：记录起点到顶点 $v$ 的最短距离，初始设为 `SIZE_MAX`；
   - `visited[v]`：记录顶点是否已入队；
   - `parent[v]`：记录顶点 $v$ 在最短路搜索树中的直接父结点，初始设为 `SIZE_MAX`。
   
   起点 `dist[source] = 0`，`parent[source] = source`。当沿边 $u \to v$ 首次发现未访问的邻接点 $v$ 时，置 `dist[v] = dist[u] + 1`，并记录 `parent[v] = u`。

3. **反向追溯与正序写出**：
   若搜索结束后 `dist[target] == SIZE_MAX`，说明目标不可达。
   若可达，路径总长度为 $L = dist[target] + 1$。从下标 $L - 1$ 开始向前填充：
   令游标 $curr = target$，每次写入 `out_path[step] = curr`，随后沿前驱跳转 $curr = parent[curr]$，直至写完起点，完成确定性的正序路径重建。

## C 语言实现

```c
#include <assert.h>
#include <stdbool.h>
#include <stddef.h>
#include <stdint.h>
#include <stdlib.h>

typedef struct GraphEdge GraphEdge;
struct GraphEdge {
    size_t to;
    GraphEdge *next;
};

typedef struct {
    GraphEdge *head;
    GraphEdge *tail;
} Adjacency;

typedef struct {
    Adjacency *adj;
    size_t vertex_count;
    bool directed;
} IntGraph;

bool int_graph_shortest_path(
    const IntGraph *graph,
    size_t source,
    size_t target,
    size_t *out_distance,
    size_t *out_path,
    size_t path_capacity
) {
    if (graph == NULL || out_distance == NULL ||
        source >= graph->vertex_count ||
        target >= graph->vertex_count) {
        return false;
    }

    size_t n = graph->vertex_count;
    if (source == target) {
        *out_distance = 0;
        if (out_path != NULL && path_capacity >= 1) {
            out_path[0] = source;
        }
        return true;
    }

    size_t *dist = malloc(n * sizeof *dist);
    size_t *parent = malloc(n * sizeof *parent);
    size_t *queue = malloc(n * sizeof *queue);

    if (dist == NULL || parent == NULL || queue == NULL) {
        free(dist);
        free(parent);
        free(queue);
        return false;
    }

    for (size_t i = 0; i < n; ++i) {
        dist[i] = SIZE_MAX;
        parent[i] = SIZE_MAX;
    }

    size_t head = 0;
    size_t tail = 0;

    dist[source] = 0;
    parent[source] = source;
    queue[tail++] = source;

    bool reached = false;

    while (head < tail) {
        size_t u = queue[head++];
        if (u == target) {
            reached = true;
            break;
        }

        for (const GraphEdge *edge = graph->adj[u].head; edge != NULL; edge = edge->next) {
            size_t v = edge->to;
            if (dist[v] == SIZE_MAX) {
                dist[v] = dist[u] + 1;
                parent[v] = u;
                queue[tail++] = v;
            }
        }
    }

    if (!reached && dist[target] == SIZE_MAX) {
        *out_distance = SIZE_MAX;
        free(dist);
        free(parent);
        free(queue);
        return true;
    }

    size_t d = dist[target];
    *out_distance = d;

    if (out_path != NULL) {
        if (path_capacity < d + 1) {
            free(dist);
            free(parent);
            free(queue);
            return false; // 缓冲区不足
        }

        size_t curr = target;
        for (size_t step = d + 1; step > 0; --step) {
            out_path[step - 1] = curr;
            curr = parent[curr];
        }
    }

    free(dist);
    free(parent);
    free(queue);
    return true;
}

int main(void) {
    // 构造一个 5 顶点的有向图
    // 0 -> 1 -> 3 -> 4
    // 0 -> 2 -> 4
    // 最短路 0 到 4 为 0 -> 2 -> 4 (距离 2)
    Adjacency adj[5] = {0};
    GraphEdge edges[] = {
        {1, NULL}, // 0->1
        {2, NULL}, // 0->2
        {3, NULL}, // 1->3
        {4, NULL}, // 2->4
        {4, NULL}  // 3->4
    };

    adj[0].head = &edges[0]; edges[0].next = &edges[1];
    adj[1].head = &edges[2];
    adj[2].head = &edges[3];
    adj[3].head = &edges[4];

    IntGraph g = {
        .adj = adj,
        .vertex_count = 5,
        .directed = true
    };

    size_t dist = 0;
    size_t path[8];

    // 测试 0 到 4
    assert(int_graph_shortest_path(&g, 0, 4, &dist, path, 8));
    assert(dist == 2);
    assert(path[0] == 0 && path[1] == 2 && path[2] == 4);

    // 起点等于终点
    assert(int_graph_shortest_path(&g, 2, 2, &dist, path, 8));
    assert(dist == 0 && path[0] == 2);

    // 无法到达测试: 4 到 0
    assert(int_graph_shortest_path(&g, 4, 0, &dist, path, 8));
    assert(dist == SIZE_MAX);

    return 0;
}
```

## 复杂度分析

- **时间复杂度**：$O(V + E)$。每个顶点至多入队一次，每条有向边至多被遍历扫描一次；反向追溯路径仅花费 $O(d)$ 步（$d \le V$）。
- **空间复杂度**：$O(V)$。队列、前驱数组与距离数组的大小均正比于顶点数量 $V$。

## 延伸思考 / 模式总结

无权图上的最短路是所有加权最短路算法（如 Dijkstra）的特例。由于每条边的转移代价恒为 1，队列天然维持单调性与两段性（当前层与下一层），因而完全省去了优先队列对数堆化的额外开销。
