# 36005 - 课程表与拓扑排序唯一性判定（队列大小恒为 1）

## 题目描述

给定一个包含 `num_courses` 门课程（编号为 $0, 1, \dots, num\_courses - 1$）的有向先修图 `prerequisites`。每个先修关系对 `[u, v]` 表示必须在修读课程 `v` 之前先修完课程 `u`（即有向边 $u \to v$）。

请判断：
1. 是否存在能够修完所有课程的合法修读顺序（即图无环）；
2. 若存在合法顺序，进一步判定该修读顺序是否是**唯一的**（即全序关系/存在唯一的哈密顿路径）。

函数签名如下：

```c
#include <stdbool.h>
#include <stddef.h>

typedef enum {
    TOPO_STATUS_UNIQUE,      // 存在唯一的拓扑排序
    TOPO_STATUS_MULTIPLE,    // 存在多个合法拓扑排序
    TOPO_STATUS_CYCLE,       // 存在有向环，无法完成
    TOPO_STATUS_INVALID      // 参数无效
} TopoUniqueStatus;

TopoUniqueStatus check_course_schedule_uniqueness(
    size_t num_courses,
    const size_t prerequisites[][2],
    size_t edge_count,
    size_t *out_order,
    size_t capacity
);
```

要求：
1. 参数无效时返回 `TOPO_STATUS_INVALID`。
2. 若有向图中存在环，返回 `TOPO_STATUS_CYCLE`。
3. 扩展 Kahn 算法：在队列推进的每一步中，检验当前待选入度为 0 的节点数量是否**恒等于 1**。若某一时刻可选节点数大于 1，则拓扑序列不唯一。
4. 若存在唯一顺序，将该完整顺序写入 `out_order` 并返回 `TOPO_STATUS_UNIQUE`。

## 解题思路

1. **唯一拓扑序列与哈密顿路径**：
   一个有向无环图（DAG）拥有**唯一拓扑序列**的充要条件是：在拓扑排序生成的序列中，任意相邻的两个顶点之间都存在一条直接相连的有向边。这等价于图中存在一条经过所有顶点的**有向哈密顿路径**。

2. **Kahn 算法中的队列状态判定**：
   在标准 Kahn 算法中，队列中保存的所有顶点都是当前入度为 0（即所有前置课程均已修完）的候选课程：
   - 如果在初始入队时，或者在循环出队过程中的任意时刻，**队列中同时存在的元素个数大于 1**（即 `(tail - head) > 1`）：
     这意味着在当前阶段，存在至少两门互不依赖的课程可以任意调换先后顺序而均合法，因此图**必定存在多个合法的拓扑序列**！
   - 反之，如果在每一个决策时刻，队列中可供选择的候选课程**严格恰好只有 1 门**，则说明选修顺序在每一步都受到强迫唯一约束，整条拓扑序必是唯一的。

3. **算法流程与环路检测**：
   统计每个课程的入度。若初始入度为 0 的课程数大于 1，则标记 `unique = false`。
   进行出队与度数递减更新，每次新入队元素可能导致队列大小增加。
   若最终完成出队的课程总数小于 `num_courses`，说明先修依赖成环，返回 `TOPO_STATUS_CYCLE`；否则根据标记返回 `TOPO_STATUS_UNIQUE` 或 `TOPO_STATUS_MULTIPLE`。

## C 语言实现

```c
#include <assert.h>
#include <stdbool.h>
#include <stddef.h>
#include <stdlib.h>
#include <string.h>

typedef enum {
    TOPO_STATUS_UNIQUE,
    TOPO_STATUS_MULTIPLE,
    TOPO_STATUS_CYCLE,
    TOPO_STATUS_INVALID
} TopoUniqueStatus;

typedef struct EdgeNode EdgeNode;
struct EdgeNode {
    size_t to;
    EdgeNode *next;
};

TopoUniqueStatus check_course_schedule_uniqueness(
    size_t num_courses,
    const size_t prerequisites[][2],
    size_t edge_count,
    size_t *out_order,
    size_t capacity
) {
    if (out_order == NULL || capacity < num_courses ||
        (edge_count > 0 && prerequisites == NULL)) {
        return TOPO_STATUS_INVALID;
    }
    if (num_courses <= 1) {
        if (num_courses == 1) {
            out_order[0] = 0;
        }
        return TOPO_STATUS_UNIQUE;
    }

    EdgeNode **adj = calloc(num_courses, sizeof(EdgeNode*));
    EdgeNode *pool = malloc(edge_count * sizeof(EdgeNode));
    size_t *in_degree = calloc(num_courses, sizeof(size_t));
    size_t *queue = malloc(num_courses * sizeof(size_t));

    if (adj == NULL || (edge_count > 0 && pool == NULL) ||
        in_degree == NULL || queue == NULL) {
        free(adj); free(pool); free(in_degree); free(queue);
        return TOPO_STATUS_INVALID;
    }

    for (size_t i = 0; i < edge_count; ++i) {
        size_t u = prerequisites[i][0];
        size_t v = prerequisites[i][1];
        if (u >= num_courses || v >= num_courses) {
            free(adj); free(pool); free(in_degree); free(queue);
            return TOPO_STATUS_INVALID;
        }
        pool[i].to = v;
        pool[i].next = adj[u];
        adj[u] = &pool[i];
        in_degree[v]++;
    }

    size_t head = 0;
    size_t tail = 0;

    for (size_t i = 0; i < num_courses; ++i) {
        if (in_degree[i] == 0) {
            queue[tail++] = i;
        }
    }

    bool unique = true;
    size_t processed = 0;

    while (head < tail) {
        // 核心判据: 若某一时刻队列中待选节点多于 1 个，说明拓扑排序不唯一
        if ((tail - head) > 1) {
            unique = false;
        }

        size_t u = queue[head++];
        out_order[processed++] = u;

        for (const EdgeNode *edge = adj[u]; edge != NULL; edge = edge->next) {
            size_t v = edge->to;
            in_degree[v]--;
            if (in_degree[v] == 0) {
                queue[tail++] = v;
            }
        }
    }

    TopoUniqueStatus status;
    if (processed < num_courses) {
        status = TOPO_STATUS_CYCLE;
    } else if (unique) {
        status = TOPO_STATUS_UNIQUE;
    } else {
        status = TOPO_STATUS_MULTIPLE;
    }

    free(adj);
    free(pool);
    free(in_degree);
    free(queue);
    return status;
}

int main(void) {
    size_t order[8];

    // 唯一拓扑序: 链式依赖 0 -> 1 -> 2 -> 3
    const size_t e_unique[3][2] = {
        {0, 1}, {1, 2}, {2, 3}
    };
    assert(check_course_schedule_uniqueness(4, e_unique, 3, order, 8) == TOPO_STATUS_UNIQUE);
    assert(order[0] == 0 && order[1] == 1 && order[2] == 2 && order[3] == 3);

    // 多个拓扑序: 菱形依赖 0 -> 1 -> 3, 0 -> 2 -> 3 (1 和 2 顺序任意)
    const size_t e_mult[4][2] = {
        {0, 1}, {0, 2}, {1, 3}, {2, 3}
    };
    assert(check_course_schedule_uniqueness(4, e_mult, 4, order, 8) == TOPO_STATUS_MULTIPLE);

    // 循环依赖死锁: 0 -> 1 -> 0
    const size_t e_cycle[2][2] = {
        {0, 1}, {1, 0}
    };
    assert(check_course_schedule_uniqueness(2, e_cycle, 2, order, 8) == TOPO_STATUS_CYCLE);

    return 0;
}
```

## 复杂度分析

- **时间复杂度**：$O(V + E)$。与标准 Kahn 算法完全一致，仅在循环头部增加了一次 $O(1)$ 的队列长度检查。
- **空间复杂度**：$O(V + E)$。包含邻接表分配、入度统计数组与队列数组。

## 延伸思考 / 模式总结

拓扑排序的唯一性检验是许多实际系统（如 CI/CD 流水线严格串行校验、依赖重构全序化）的重要判定工具。只要队列大小恒等于 1，即可保证算法生成的不仅是一个偏序的拓扑扩充，而是一个强连通哈密顿链。
