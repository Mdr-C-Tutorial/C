# 36004 - DFS 时间戳与有向图环路检测

## 题目描述

在一个包含 $V$ 个顶点的有向图上，使用深度优先搜索（DFS）记录每个顶点的**发现时间戳（Discovery Time）**与**完成时间戳（Finish Time）**，并利用**三色标记法**判断图中是否存在有向环路。

函数签名如下：

```c
#include <stdbool.h>
#include <stddef.h>

bool dfs_timestamps_and_cycle(
    size_t vertex_count,
    const size_t edges[][2],
    size_t edge_count,
    size_t *out_discovery_time,
    size_t *out_finish_time,
    bool *out_has_cycle
);
```

要求：
1. 时间戳全局计数器从 1 开始单调递增，每次发现新节点或完成某节点的搜索时递增 1。
2. 采用白、灰、黑三色标记状态（0=WHITE 未访问，1=GRAY 正在递归路径中，2=BLACK 搜索完毕退出）。
3. 沿边扫描时若遭遇灰色顶点，说明存在反向回边（Back Edge），即发现了有向环。
4. 无论图是否连通，必须遍历森林中所有顶点。

## 解题思路

1. **三色标记的不变式与语义**：
   - **WHITE（白色，0）**：顶点尚未被发现；
   - **GRAY（灰色，1）**：顶点已被发现，当前正处于从根到该顶点的递归调用调用栈上（搜索正在进行中）；
   - **BLACK（黑色，2）**：以该顶点为根的整棵 DFS 子树已全部遍历完毕，已从调用栈弹出。

2. **有向边分类与环路判据**：
   在 DFS 遍历边 $u \to v$ 时：
   - 若 $v$ 为白色：说明是**树边（Tree Edge）**，正常递归深入；
   - 若 $v$ 为灰色：说明 $v$ 是当前搜索祖先路径上的前驱结点。存在边 $u \to v$ 形成闭环，这是一条**回边（Back Edge）**，直接证明**图中存在有向环**；
   - 若 $v$ 为黑色：说明 $v$ 是已完成的子树（前向边或交叉边），不会构成环。

3. **括号化定理（Parenthesis Theorem）**：
   每个顶点被赋予两个时间戳：
   - 发现时间 $d[u]$：顶点首次被置为灰色时的全局时间；
   - 完成时间 $f[u]$：顶点及其所有后代均搜索完毕被置为黑色时的全局时间。
   所有顶点的区间 $[d[u], f[u]]$ 必然呈现严格的嵌套或完全分离关系，如同合法的括号匹配。

## C 语言实现

```c
#include <assert.h>
#include <stdbool.h>
#include <stddef.h>
#include <stdint.h>
#include <stdlib.h>

typedef struct EdgeNode EdgeNode;
struct EdgeNode {
    size_t to;
    EdgeNode *next;
};

enum Color {
    COLOR_WHITE = 0,
    COLOR_GRAY = 1,
    COLOR_BLACK = 2
};

static void dfs_visit(
    size_t u,
    const EdgeNode * const *adj,
    uint8_t *color,
    size_t *d_time,
    size_t *f_time,
    size_t *timer,
    bool *has_cycle
) {
    color[u] = COLOR_GRAY;
    d_time[u] = ++(*timer);

    for (const EdgeNode *edge = adj[u]; edge != NULL; edge = edge->next) {
        size_t v = edge->to;
        if (color[v] == COLOR_GRAY) {
            *has_cycle = true; // 发现回边，存在有向环
        } else if (color[v] == COLOR_WHITE) {
            dfs_visit(v, adj, color, d_time, f_time, timer, has_cycle);
        }
    }

    color[u] = COLOR_BLACK;
    f_time[u] = ++(*timer);
}

bool dfs_timestamps_and_cycle(
    size_t vertex_count,
    const size_t edges[][2],
    size_t edge_count,
    size_t *out_discovery_time,
    size_t *out_finish_time,
    bool *out_has_cycle
) {
    if (out_discovery_time == NULL || out_finish_time == NULL ||
        out_has_cycle == NULL || (edge_count > 0 && edges == NULL)) {
        return false;
    }
    if (vertex_count == 0) {
        *out_has_cycle = false;
        return true;
    }

    EdgeNode **adj = calloc(vertex_count, sizeof(EdgeNode*));
    EdgeNode *pool = malloc(edge_count * sizeof(EdgeNode));
    uint8_t *color = calloc(vertex_count, sizeof(uint8_t));

    if (adj == NULL || (edge_count > 0 && pool == NULL) || color == NULL) {
        free(adj); free(pool); free(color);
        return false;
    }

    // 构建有向图邻接表
    for (size_t i = 0; i < edge_count; ++i) {
        size_t u = edges[i][0];
        size_t v = edges[i][1];
        if (u >= vertex_count || v >= vertex_count) {
            free(adj); free(pool); free(color);
            return false;
        }
        pool[i].to = v;
        pool[i].next = adj[u];
        adj[u] = &pool[i];
    }

    size_t timer = 0;
    bool has_cycle = false;

    // 遍历所有顶点（处理非连通森林）
    for (size_t u = 0; u < vertex_count; ++u) {
        if (color[u] == COLOR_WHITE) {
            dfs_visit(u, (const EdgeNode * const *)adj, color,
                      out_discovery_time, out_finish_time, &timer, &has_cycle);
        }
    }

    *out_has_cycle = has_cycle;

    free(adj);
    free(pool);
    free(color);
    return true;
}

int main(void) {
    size_t d[8];
    size_t f[8];
    bool has_cycle = false;

    // 参数校验
    assert(!dfs_timestamps_and_cycle(3, NULL, 1, d, f, &has_cycle));

    // 无环 DAG: 0 -> 1 -> 2
    const size_t e_dag[2][2] = {{0, 1}, {1, 2}};
    assert(dfs_timestamps_and_cycle(3, e_dag, 2, d, f, &has_cycle));
    assert(!has_cycle);
    // 括号嵌套性校验: [d[0], f[0]] 必须包含 [d[1], f[1]] 必须包含 [d[2], f[2]]
    assert(d[0] < d[1] && d[1] < d[2]);
    assert(f[2] < f[1] && f[1] < f[0]);

    // 经典有向环: 0 -> 1 -> 2 -> 0
    const size_t e_cycle[3][2] = {{0, 1}, {1, 2}, {2, 0}};
    assert(dfs_timestamps_and_cycle(3, e_cycle, 3, d, f, &has_cycle));
    assert(has_cycle);

    // 含有自环: 0 -> 0
    const size_t e_self[1][2] = {{1, 1}};
    assert(dfs_timestamps_and_cycle(2, e_self, 1, d, f, &has_cycle));
    assert(has_cycle);

    return 0;
}
```

## 复杂度分析

- **时间复杂度**：$O(V + E)$。每个顶点只在进入时变灰、退出时变黑，每条有向边仅在源顶点展开时被访问一次。
- **空间复杂度**：$O(V + E)$。邻接表空间为 $O(E)$，递归调用栈深度最坏情况下为 $V$。

## 延伸思考 / 模式总结

三色标记法是图论 DFS 中最经典的状态划分工具。在拓扑排序的 DFS 实现中，按照顶点的完成时间 $f[u]$ 逆序排列即可得到拓扑序列；同时，三色标记法能够无缝推广至分布式垃圾回收算法（如三色标记清除 GC）中识别存活对象。
