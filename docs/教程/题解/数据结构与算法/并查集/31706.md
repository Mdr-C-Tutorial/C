# 31706 - 可撤销并查集与时间旅行回退

## 题目

实现支持历史状态按序回退的**可撤销并查集（Undoable DSU）**，支持检查点（Checkpoint）保存与多步批量回退：

```c
#include <stdbool.h>
#include <stddef.h>

typedef struct UndoableDSU UndoableDSU;

UndoableDSU *undoable_dsu_create(size_t count);
void undoable_dsu_destroy(UndoableDSU *dsu);
bool undoable_dsu_union(UndoableDSU *dsu, size_t u, size_t v, bool *out_merged);
bool undoable_dsu_same(const UndoableDSU *dsu, size_t u, size_t v, bool *out_same);
bool undoable_dsu_rollback(UndoableDSU *dsu);
size_t undoable_dsu_checkpoint(const UndoableDSU *dsu);
bool undoable_dsu_rollback_to(UndoableDSU *dsu, size_t checkpoint);
```

要求：

1. 内部**严禁采用路径压缩**，仅允许使用**按秩合并（Union by Rank）**；详细证明为什么可撤销并查集不能使用路径压缩。
2. 维护动态操作历史栈 `history`。每次调用 `undoable_dsu_union` 无论是否发生实质合并，均向栈中压入一条快照记录，耗时 $O(1)$。
3. `undoable_dsu_rollback` 弹出栈顶的最近一次合并操作，并以 $O(1)$ 时间完全恢复树形拓扑结构与秩信息；若历史栈为空，返回 `false`。
4. `undoable_dsu_checkpoint` 返回当前历史栈的深度；`undoable_dsu_rollback_to` 反复回退至指定的检查点深度。
5. 结合线段树分治（Divide and Conquer on Time）场景，阐述可撤销并查集离线解决动态连通性问题的标准范式。

## 解题思路

### 1. 为什么可撤销并查集严禁使用路径压缩？

标准并查集依赖路径压缩将摊还时间压低至 $O(\alpha(n))$。但在需要支持**撤销（Rollback / Undo）**的场景下，路径压缩成为了不可承受之重：
- **拓扑信息不可逆破坏**：单次路径压缩会将沿途数十个节点的父指针全部批量改写为当前根节点。原始的树形层次结构被瞬间抹平；
- **历史记录爆炸**：若要撤销一次带路径压缩的查询，必须把沿途所有被修改节点的旧父指针逐一打包记录，单次记录的额外开销上升为 $O(\log n)$ 甚至更多，极易引发严重的空间膨胀；
- **只读查询产生副作用**：在路径压缩下，纯连通性查询 `same` 会对结构产生静默写操作，导致查询操作与合并操作的历史版本相互交织，回滚逻辑难以自洽。

### 2. 纯按秩合并的确定性契约

抛弃路径压缩后，我们仅依靠**按秩合并（Union by Rank）**：
1. **严格的对数树高保证**：通过将矮树挂在高树下，包含 $k$ 个节点的树其秩（高度上界）严格受限在 $\lfloor \log_2 k \rfloor$ 以内，因此任意单次 `find` 寻根的最坏时间严格为 $O(\log n)$；
2. **极简的单步修改契约**：一次 `union(u, v)` 操作对全系统的修改至多只有两处：
   - 某一个根节点的父指针：`parent[child] = parent`；
   - 接收树的秩自增（当且仅当两树原本等高）：`rank[parent]++`。
这意味着只需记录一个固定大小的三元组对象：
```c
typedef struct {
    size_t child;
    size_t parent;
    bool rank_increased;
    bool merged;
} DSUOp;
```
即可在 $O(1)$ 空间内对本次合并做完整快照；撤销时只需执行：
```c
dsu->parent[op.child] = op.child;
if (op.rank_increased) dsu->rank[op.parent]--;
```
即可严格在 $O(1)$ 时间内精准复原拓扑。

### 3. 时间分治与离线图论范式

在处理“加边、删边、查询连通性”的动态图问题时，若边仅在时间区间 $[L, R]$ 内有效：
1. 将每条边的存活区间插入时间线段树中；
2. 在线段树上进行深度优先遍历（DFS）：
   - 进入当前区间节点时，将落在该区间的所有边调用 `undoable_dsu_union` 批量加入并查集；
   - 递归访问左、右子树；
   - 递归返回离开当前区间时，调用 `undoable_dsu_rollback_to` 将并查集完全回退到进入该节点前的状态。
通过可撤销并查集，我们用无需显式删边的数据结构，成功解决了复杂的动态删边连通性问题，全局时间复杂度稳定在 $O(q \log q \log n)$。

## C 语言实现

```c
#include <assert.h>
#include <stdbool.h>
#include <stddef.h>
#include <stdint.h>
#include <stdio.h>
#include <stdlib.h>

typedef struct {
    size_t child;
    size_t parent;
    bool rank_increased;
    bool merged;
} DSUOp;

typedef struct UndoableDSU UndoableDSU;

struct UndoableDSU {
    size_t *parent;
    size_t *rank;
    DSUOp *history;
    size_t count;
    size_t history_size;
    size_t history_capacity;
};

UndoableDSU *undoable_dsu_create(size_t count) {
    UndoableDSU *dsu = malloc(sizeof *dsu);
    if (dsu == NULL) {
        return NULL;
    }
    dsu->count = count;
    dsu->history_size = 0;
    dsu->history_capacity = 0;
    dsu->parent = NULL;
    dsu->rank = NULL;
    dsu->history = NULL;
    if (count > 0) {
        if (count > SIZE_MAX / sizeof(size_t)) {
            free(dsu);
            return NULL;
        }
        dsu->parent = malloc(count * sizeof(size_t));
        dsu->rank = calloc(count, sizeof(size_t));
        if (dsu->parent == NULL || dsu->rank == NULL) {
            free(dsu->parent);
            free(dsu->rank);
            free(dsu);
            return NULL;
        }
        for (size_t i = 0; i < count; ++i) {
            dsu->parent[i] = i;
        }
    }
    return dsu;
}

void undoable_dsu_destroy(UndoableDSU *dsu) {
    if (dsu == NULL) {
        return;
    }
    free(dsu->parent);
    free(dsu->rank);
    free(dsu->history);
    free(dsu);
}

static size_t find_root(const UndoableDSU *dsu, size_t x) {
    while (x != dsu->parent[x]) {
        x = dsu->parent[x];
    }
    return x;
}

static bool ensure_history(UndoableDSU *dsu) {
    if (dsu->history_size < dsu->history_capacity) {
        return true;
    }
    size_t max_cap = SIZE_MAX / sizeof(DSUOp);
    if (dsu->history_capacity >= max_cap) {
        return false;
    }
    size_t next = dsu->history_capacity == 0 ? 16 : (dsu->history_capacity > max_cap / 2 ? max_cap : dsu->history_capacity * 2);
    if (next <= dsu->history_size) {
        return false;
    }
    DSUOp *new_h = realloc(dsu->history, next * sizeof(DSUOp));
    if (new_h == NULL) {
        return false;
    }
    dsu->history = new_h;
    dsu->history_capacity = next;
    return true;
}

bool undoable_dsu_union(UndoableDSU *dsu, size_t u, size_t v, bool *out_merged) {
    if (dsu == NULL || out_merged == NULL || u >= dsu->count || v >= dsu->count) {
        return false;
    }
    if (!ensure_history(dsu)) {
        return false;
    }

    size_t root_u = find_root(dsu, u);
    size_t root_v = find_root(dsu, v);
    if (root_u == root_v) {
        dsu->history[dsu->history_size++] = (DSUOp){
            .merged = false,
            .child = 0,
            .parent = 0,
            .rank_increased = false
        };
        *out_merged = false;
        return true;
    }

    *out_merged = true;
    if (dsu->rank[root_u] < dsu->rank[root_v]) {
        dsu->parent[root_u] = root_v;
        dsu->history[dsu->history_size++] = (DSUOp){
            .merged = true,
            .child = root_u,
            .parent = root_v,
            .rank_increased = false
        };
    } else if (dsu->rank[root_u] > dsu->rank[root_v]) {
        dsu->parent[root_v] = root_u;
        dsu->history[dsu->history_size++] = (DSUOp){
            .merged = true,
            .child = root_v,
            .parent = root_u,
            .rank_increased = false
        };
    } else {
        dsu->parent[root_v] = root_u;
        dsu->rank[root_u]++;
        dsu->history[dsu->history_size++] = (DSUOp){
            .merged = true,
            .child = root_v,
            .parent = root_u,
            .rank_increased = true
        };
    }
    return true;
}

bool undoable_dsu_same(const UndoableDSU *dsu, size_t u, size_t v, bool *out_same) {
    if (dsu == NULL || out_same == NULL || u >= dsu->count || v >= dsu->count) {
        return false;
    }
    *out_same = (find_root(dsu, u) == find_root(dsu, v));
    return true;
}

bool undoable_dsu_rollback(UndoableDSU *dsu) {
    if (dsu == NULL || dsu->history_size == 0) {
        return false;
    }
    dsu->history_size--;
    DSUOp op = dsu->history[dsu->history_size];
    if (op.merged) {
        dsu->parent[op.child] = op.child;
        if (op.rank_increased) {
            dsu->rank[op.parent]--;
        }
    }
    return true;
}

size_t undoable_dsu_checkpoint(const UndoableDSU *dsu) {
    if (dsu == NULL) {
        return 0;
    }
    return dsu->history_size;
}

bool undoable_dsu_rollback_to(UndoableDSU *dsu, size_t checkpoint) {
    if (dsu == NULL || checkpoint > dsu->history_size) {
        return false;
    }
    while (dsu->history_size > checkpoint) {
        undoable_dsu_rollback(dsu);
    }
    return true;
}

int main(void) {
    UndoableDSU *dsu = undoable_dsu_create(6);
    assert(dsu != NULL);

    bool merged = false;
    bool same = false;

    size_t cp0 = undoable_dsu_checkpoint(dsu);
    assert(cp0 == 0);

    assert(undoable_dsu_union(dsu, 0, 1, &merged) && merged);
    assert(undoable_dsu_union(dsu, 1, 2, &merged) && merged);
    assert(undoable_dsu_same(dsu, 0, 2, &same) && same);

    size_t cp1 = undoable_dsu_checkpoint(dsu);
    assert(cp1 == 2);

    assert(undoable_dsu_union(dsu, 3, 4, &merged) && merged);
    assert(undoable_dsu_union(dsu, 2, 3, &merged) && merged);
    assert(undoable_dsu_same(dsu, 0, 4, &same) && same);

    assert(undoable_dsu_rollback_to(dsu, cp1));
    assert(undoable_dsu_same(dsu, 0, 2, &same) && same);
    assert(undoable_dsu_same(dsu, 0, 4, &same) && !same);

    assert(undoable_dsu_rollback_to(dsu, cp0));
    assert(undoable_dsu_same(dsu, 0, 2, &same) && !same);

    undoable_dsu_destroy(dsu);
    return 0;
}
```

## 复杂度分析

- **时间复杂度**：
  - `find_root` 与 `undoable_dsu_same`：仅依赖按秩合并，树高严格受限在 $\log_2 n$ 以内，单次查询时间复杂度严格为最坏情况 $O(\log n)$。
  - `undoable_dsu_union`：寻根耗时 $O(\log n)$，随后记录单条历史快照，总耗时为 $O(\log n)$。
  - `undoable_dsu_rollback`：单次弹出栈顶并就地恢复指针与秩计数器，时间复杂度严格为 $O(1)$。
  - `undoable_dsu_rollback_to`：设回退步数为 $k$，时间复杂度严格为 $O(k)$。
- **空间复杂度**：除节点数组外，历史栈存储执行的操作记录，空间复杂度为 $O(n + M)$，其中 $M$ 为历史操作总数。

## 延伸思考 / 模式总结

1. **局部可撤销与版本控制哲学**：在计算机系统设计中，“不可撤销的高效优化”与“易于版本回退的保守设计”是恒久的博弈。路径压缩通过牺牲历史结构的确定性换取了极致摊还，而可撤销并查集放弃了这一非线性优化，却以极小的对数代价换取了完备的时光倒流能力。
2. **轻量事务栈的工程优雅性**：通过在堆上管理一个动态连续的历史数组 `DSUOp *history`，不仅杜绝了任何链表节点带来的内存碎片，更使得检查点管理退化为轻量级的整数下标比对，是工业级高性能引擎中状态快照机制的标准范例。
