# 31703 - 基础并查集结构与退化树形分析

## 题目

实现基础并查集的两种核心变体：基于展平标记数组的 **Quick-Find** 与基于父节点树形数组的无优化 **Quick-Union**，并深入分析两者的性能瓶颈与退化场景：

```c
#include <stdbool.h>
#include <stddef.h>

typedef struct QuickFindDSU QuickFindDSU;
typedef struct QuickUnionDSU QuickUnionDSU;

QuickFindDSU *qf_create(size_t n);
void qf_destroy(QuickFindDSU *dsu);
bool qf_find(const QuickFindDSU *dsu, size_t p, size_t *out_id);
bool qf_union(QuickFindDSU *dsu, size_t p, size_t q, bool *out_merged);

QuickUnionDSU *qu_create(size_t n);
void qu_destroy(QuickUnionDSU *dsu);
bool qu_find(const QuickUnionDSU *dsu, size_t p, size_t *out_root);
bool qu_union(QuickUnionDSU *dsu, size_t p, size_t q, bool *out_merged);
```

要求：

1. 初始时每个元素各自构成独立的单元素集合，外部标识符范围为 $[0, n - 1]$。
2. `QuickFindDSU` 维护 `id` 数组，保证同属一个集合的所有成员具有完全相同的标识：
   - `qf_find` 实现 $O(1)$ 常数时间查询；
   - `qf_union` 遍历整个数组将所有属于集合 $p$ 的槽位批量更新为集合 $q$ 的标识。
3. `QuickUnionDSU` 维护 `parent` 树形数组，根节点满足 `parent[root] == root`：
   - `qu_find` 沿父节点指针向上回溯直至根节点；
   - `qu_union` 找到两者的树根，若分属不同根则将其中一个树根直接作为另一个树根的孩子（`parent[root_p] = root_q`）。
4. 参数非法或内存分配失败时返回 `false` 且不修改输出对象；`destroy(NULL)` 安全。
5. 在题解中证明朴素 Quick-Union 在特定合并输入下会退化为高为 $n$ 的单链，导致单次操作时间复杂度劣化为 $O(n)$。

## 解题思路

### 1. Quick-Find 的“查快并慢”困境

Quick-Find 采用完全展平的一维分类标记：
- 若元素 $x$ 与 $y$ 连通，则必有 `id[x] == id[y]`；
- 查询连通性只需要比较 `id[p]` 与 `id[q]`，耗时严格为 $O(1)$；
- 但在执行合并时，必须扫描全表大小为 $n$ 的每一个槽位，把旧类别的所有元素全部刷写为新类别。进行 $n - 1$ 次合并的总时间复杂度为 $\Theta(n^2)$。当面对数以百万计的动态数据流时，二次方开销完全不可接受。

### 2. 朴素 Quick-Union 的树形结构与链化退化

Quick-Union 引入了树形拓扑结构，避免了每次合并扫描全数组：
- 节点只记录其父节点下标 `parent[x]`；
- 合并时只需执行两步：调用 `qu_find` 找到两个根，然后将 `parent[root_p] = root_q`，耗时似乎只取决于树高。
然而，在没有任何平衡策略（按秩/大小合并）和路径优化的情况下，树的形态完全受输入顺序摆布：

#### 单链退化构造
考虑依次执行以下 $n - 1$ 次合并操作：
$$\text{union}(0, 1), \; \text{union}(1, 2), \; \text{union}(2, 3), \; \dots, \; \text{union}(n - 2, n - 1)$$
- 初始时每个节点自成一棵单节点树（高为 1）；
- 合并 $(0, 1)$：将根 0 挂在 1 下面，形成边 $0 \to 1$；
- 合并 $(1, 2)$：从 1 找到根 1，从 2 找到根 2，将根 1 挂在 2 下面，形成链 $0 \to 1 \to 2$；
- $\dots$
- 最终生成一棵高度为 $n$ 的极端退化线性单链：
  $$0 \to 1 \to 2 \to \dots \to n - 1$$
此时从节点 $0$ 查找根节点必须逐级攀爬遍历全链的所有节点，单次 `find` 耗时劣化为 $\Theta(n)$，$m$ 次操作的最坏时间复杂度同样退化为 $O(m \cdot n)$。

## C 语言实现

```c
#include <assert.h>
#include <stdbool.h>
#include <stddef.h>
#include <stdint.h>
#include <stdio.h>
#include <stdlib.h>

typedef struct QuickFindDSU QuickFindDSU;
typedef struct QuickUnionDSU QuickUnionDSU;

struct QuickFindDSU {
    size_t *id;
    size_t count;
};

QuickFindDSU *qf_create(size_t n) {
    QuickFindDSU *dsu = malloc(sizeof *dsu);
    if (dsu == NULL) {
        return NULL;
    }
    dsu->count = n;
    dsu->id = NULL;
    if (n > 0) {
        if (n > SIZE_MAX / sizeof(size_t)) {
            free(dsu);
            return NULL;
        }
        dsu->id = malloc(n * sizeof(size_t));
        if (dsu->id == NULL) {
            free(dsu);
            return NULL;
        }
        for (size_t i = 0; i < n; ++i) {
            dsu->id[i] = i;
        }
    }
    return dsu;
}

void qf_destroy(QuickFindDSU *dsu) {
    if (dsu == NULL) {
        return;
    }
    free(dsu->id);
    free(dsu);
}

bool qf_find(const QuickFindDSU *dsu, size_t p, size_t *out_id) {
    if (dsu == NULL || p >= dsu->count || out_id == NULL) {
        return false;
    }
    *out_id = dsu->id[p];
    return true;
}

bool qf_union(QuickFindDSU *dsu, size_t p, size_t q, bool *out_merged) {
    if (dsu == NULL || p >= dsu->count || q >= dsu->count || out_merged == NULL) {
        return false;
    }
    size_t pid = dsu->id[p];
    size_t qid = dsu->id[q];
    if (pid == qid) {
        *out_merged = false;
        return true;
    }
    for (size_t i = 0; i < dsu->count; ++i) {
        if (dsu->id[i] == pid) {
            dsu->id[i] = qid;
        }
    }
    *out_merged = true;
    return true;
}

struct QuickUnionDSU {
    size_t *parent;
    size_t count;
};

QuickUnionDSU *qu_create(size_t n) {
    QuickUnionDSU *dsu = malloc(sizeof *dsu);
    if (dsu == NULL) {
        return NULL;
    }
    dsu->count = n;
    dsu->parent = NULL;
    if (n > 0) {
        if (n > SIZE_MAX / sizeof(size_t)) {
            free(dsu);
            return NULL;
        }
        dsu->parent = malloc(n * sizeof(size_t));
        if (dsu->parent == NULL) {
            free(dsu);
            return NULL;
        }
        for (size_t i = 0; i < n; ++i) {
            dsu->parent[i] = i;
        }
    }
    return dsu;
}

void qu_destroy(QuickUnionDSU *dsu) {
    if (dsu == NULL) {
        return;
    }
    free(dsu->parent);
    free(dsu);
}

bool qu_find(const QuickUnionDSU *dsu, size_t p, size_t *out_root) {
    if (dsu == NULL || p >= dsu->count || out_root == NULL) {
        return false;
    }
    size_t root = p;
    while (root != dsu->parent[root]) {
        root = dsu->parent[root];
    }
    *out_root = root;
    return true;
}

bool qu_union(QuickUnionDSU *dsu, size_t p, size_t q, bool *out_merged) {
    if (dsu == NULL || p >= dsu->count || q >= dsu->count || out_merged == NULL) {
        return false;
    }
    size_t root_p = 0;
    size_t root_q = 0;
    qu_find(dsu, p, &root_p);
    qu_find(dsu, q, &root_q);
    if (root_p == root_q) {
        *out_merged = false;
        return true;
    }
    dsu->parent[root_p] = root_q;
    *out_merged = true;
    return true;
}

int main(void) {
    qf_destroy(NULL);
    qu_destroy(NULL);

    QuickFindDSU *qf = qf_create(5);
    assert(qf != NULL);
    bool merged = false;
    assert(qf_union(qf, 0, 1, &merged) && merged);
    assert(qf_union(qf, 1, 2, &merged) && merged);
    assert(qf_union(qf, 0, 2, &merged) && !merged);
    size_t id0 = 0, id2 = 0, id3 = 0;
    assert(qf_find(qf, 0, &id0) && qf_find(qf, 2, &id2) && id0 == id2);
    assert(qf_find(qf, 3, &id3) && id0 != id3);
    qf_destroy(qf);

    QuickUnionDSU *qu = qu_create(5);
    assert(qu != NULL);
    assert(qu_union(qu, 0, 1, &merged) && merged);
    assert(qu_union(qu, 1, 2, &merged) && merged);
    assert(qu_union(qu, 0, 2, &merged) && !merged);
    size_t r0 = 0, r2 = 0, r3 = 0;
    assert(qu_find(qu, 0, &r0) && qu_find(qu, 2, &r2) && r0 == r2);
    assert(qu_find(qu, 3, &r3) && r0 != r3);
    qu_destroy(qu);

    return 0;
}
```

## 复杂度分析

- **Quick-Find 复杂度**：
  - `qf_find`：直接下标定位，时间复杂度为严格的 $O(1)$。
  - `qf_union`：每次必须遍历长度为 $n$ 的整个数组，时间复杂度严格为 $O(n)$。
- **Quick-Union 复杂度**：
  - `qu_find`：取决于节点在树中的深度。在最坏链化情形下，时间复杂度为 $O(n)$；最好情况（星形浅树）为 $O(1)$。
  - `qu_union`：开销主要集中在两次寻根过程，最坏情况时间复杂度同样为 $O(n)$。
- **空间复杂度**：两者均只需维护一个长度为 $n$ 的紧凑整数数组，空间复杂度均为 $O(n)$。

## 延伸思考 / 模式总结

1. **结构权衡的两极**：Quick-Find 走到了扁平化的极端（树高恒为 1，但合并代价巨大），Quick-Union 引入了层级树形指针（合并仅需修改一个指针，但放任树高无节制增长）。
2. **优化方向的启示**：两者的缺陷天然指明了终极并查集的进化路径：
   - 必须通过**按秩合并（Union by Rank）**控制合并时的树高增长，杜绝“长链”的出现；
   - 必须通过**路径压缩（Path Compression）**在寻根过程中动态展平树形，将深层节点直接悬挂至根节点，实现近乎常数级的高效摊还。
