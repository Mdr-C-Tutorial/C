# 31705 - 种类并查集与扩展域建模

## 题目

实现基于**扩展域（Extended Domain）**建模的种类并查集 `EnemyDisjointSet`，处理包含“朋友”与“敌人”二元对立关系的动态图场景（“敌人的敌人是朋友”），支持冲突关系检测与逻辑推断：

```c
#include <stdbool.h>
#include <stddef.h>

typedef struct EnemyDisjointSet EnemyDisjointSet;

EnemyDisjointSet *enemy_dsu_create(size_t n);
void enemy_dsu_destroy(EnemyDisjointSet *dsu);
bool enemy_dsu_add_friends(EnemyDisjointSet *dsu, size_t x, size_t y, bool *out_consistent);
bool enemy_dsu_add_enemies(EnemyDisjointSet *dsu, size_t x, size_t y, bool *out_consistent);
bool enemy_dsu_are_friends(EnemyDisjointSet *dsu, size_t x, size_t y, bool *out_friends);
bool enemy_dsu_are_enemies(EnemyDisjointSet *dsu, size_t x, size_t y, bool *out_enemies);
```

要求：

1. 集合包含 $n$ 个实体，编号为 $[0, n - 1]$。底层通过开辟 $2n$ 大小的扩展域数组进行逻辑推演：
   - 域 $[0, n - 1]$ 表示“实体处于同盟阵营”；
   - 域 $[n, 2n - 1]$ 表示“实体处于敌对阵营”（记实体 $x$ 的敌对域为 $x + n$）。
2. `enemy_dsu_add_friends`：若此前已推导出 $x$ 与 $y$ 为敌人（即 $x$ 与 $y + n$ 连通），产生逻辑冲突，置 `*out_consistent = false` 且不改变集合状态；否则合并 $(x, y)$ 与 $(x + n, y + n)$，置 `*out_consistent = true`。
3. `enemy_dsu_add_enemies`：若此前已推导出 $x$ 与 $y$ 为朋友（即 $x$ 与 $y$ 连通），产生逻辑冲突，置 `*out_consistent = false`；否则合并 $(x, y + n)$ 与 $(y, x + n)$，置 `*out_consistent = true`。
4. `enemy_dsu_are_friends` 与 `enemy_dsu_are_enemies` 分别查询两实体当前是否已确定属于朋友或敌对关系。
5. 在题解中对比分析“扩展域并查集”与“带权并查集”在建模思路、实现复杂度及应用场景上的异同。

## 解题思路

### 1. 扩展域的拆分逻辑与命题等价

面对“敌人的敌人是朋友”这种存在对立关系的问题，带权并查集通过边权模 2 运算维护势能差，而**扩展域并查集（Domain Expansion）**则通过将每个实体“分身”拆解为多个逻辑命题状态：
- 对于实体 $x$，将其拆为两个虚拟节点：
  - 节点 $x$：代表“与 $x$ 为友的集合（同盟命题）”；
  - 节点 $x + n$：代表“与 $x$ 为敌的集合（敌对命题）”。

在二元对立逻辑下：
1. **$x$ 与 $y$ 成为朋友**：
   - $x$ 的朋友必然是 $y$ 的朋友 $\implies \text{union}(x, y)$；
   - $x$ 的敌人必然是 $y$ 的敌人 $\implies \text{union}(x + n, y + n)$。
2. **$x$ 与 $y$ 成为敌人**：
   - $x$ 的朋友必然是 $y$ 的敌人 $\implies \text{union}(x, y + n)$；
   - $y$ 的朋友必然是 $x$ 的敌人 $\implies \text{union}(y, x + n)$。

### 2. 冲突判定与逻辑闭环

在尝试合并之前，进行先验矛盾探测：
- 声明朋友关系前：若 $\text{find}(x) == \text{find}(y + n)$，意味着此前已有确凿证据判定它们是敌人，立即判定冲突；
- 声明敌对关系前：若 $\text{find}(x) == \text{find}(y)$，意味着此前已有确凿证据判定它们是朋友，立即判定冲突。
若无矛盾，双向合并后的系统将自动闭合推导出所有连带关系。例如加入“$A$ 与 $B$ 为敌”以及“$B$ 与 $C$ 为敌”，系统自动合并了 $(A, B + n)$ 和 $(B + n, C)$，使得 $A$ 与 $C$ 归入同一等价类，无需编写任何额外逻辑便天然推导出了“$A$ 与 $C$ 为友”。

### 3. 扩展域并查集 vs 带权并查集 对比

| 维度 | 扩展域并查集 | 带权并查集 |
| :--- | :--- | :--- |
| **核心机制** | 将元素全域扩大为 $k \cdot n$ 个离散命题槽位 | 维持 $n$ 个节点，在边上维护模 $k$ 的差分边权 |
| **代码复杂度** | 极低（直接复用标准模板并查集，仅需扩展数组长度） | 较高（需在路径压缩和合并时严格推导群转移方程） |
| **内存消耗** | 占用 $k \cdot n$ 大小的 `parent` 与 `rank` 数组 | 仅占用 $n$ 大小的 `parent` 与边权数组 |
| **适用边界** | 仅适用于离散、状态数量较少（如 $k=2, 3$）的分类系统 | 适用于任意大模数群、实数势能差分（连续差分约束系统） |

## C 语言实现

```c
#include <assert.h>
#include <stdbool.h>
#include <stddef.h>
#include <stdint.h>
#include <stdio.h>
#include <stdlib.h>

typedef struct EnemyDisjointSet EnemyDisjointSet;

struct EnemyDisjointSet {
    size_t *parent;
    size_t *rank;
    size_t n;
};

EnemyDisjointSet *enemy_dsu_create(size_t n) {
    EnemyDisjointSet *dsu = malloc(sizeof *dsu);
    if (dsu == NULL) {
        return NULL;
    }
    dsu->n = n;
    dsu->parent = NULL;
    dsu->rank = NULL;
    if (n > 0) {
        if (n > SIZE_MAX / 2 || 2 * n > SIZE_MAX / sizeof(size_t)) {
            free(dsu);
            return NULL;
        }
        size_t total = 2 * n;
        dsu->parent = malloc(total * sizeof(size_t));
        dsu->rank = calloc(total, sizeof(size_t));
        if (dsu->parent == NULL || dsu->rank == NULL) {
            free(dsu->parent);
            free(dsu->rank);
            free(dsu);
            return NULL;
        }
        for (size_t i = 0; i < total; ++i) {
            dsu->parent[i] = i;
        }
    }
    return dsu;
}

void enemy_dsu_destroy(EnemyDisjointSet *dsu) {
    if (dsu == NULL) {
        return;
    }
    free(dsu->parent);
    free(dsu->rank);
    free(dsu);
}

static size_t find_root(EnemyDisjointSet *dsu, size_t x) {
    size_t root = x;
    while (root != dsu->parent[root]) {
        root = dsu->parent[root];
    }
    size_t curr = x;
    while (curr != root) {
        size_t next = dsu->parent[curr];
        dsu->parent[curr] = root;
        curr = next;
    }
    return root;
}

static void union_roots(EnemyDisjointSet *dsu, size_t a, size_t b) {
    size_t ra = find_root(dsu, a);
    size_t rb = find_root(dsu, b);
    if (ra == rb) {
        return;
    }
    if (dsu->rank[ra] < dsu->rank[rb]) {
        dsu->parent[ra] = rb;
    } else if (dsu->rank[ra] > dsu->rank[rb]) {
        dsu->parent[rb] = ra;
    } else {
        dsu->parent[rb] = ra;
        dsu->rank[ra]++;
    }
}

bool enemy_dsu_add_friends(EnemyDisjointSet *dsu, size_t x, size_t y, bool *out_consistent) {
    if (dsu == NULL || out_consistent == NULL || x >= dsu->n || y >= dsu->n) {
        return false;
    }
    size_t n = dsu->n;
    if (find_root(dsu, x) == find_root(dsu, y + n)) {
        *out_consistent = false;
        return true;
    }
    union_roots(dsu, x, y);
    union_roots(dsu, x + n, y + n);
    *out_consistent = true;
    return true;
}

bool enemy_dsu_add_enemies(EnemyDisjointSet *dsu, size_t x, size_t y, bool *out_consistent) {
    if (dsu == NULL || out_consistent == NULL || x >= dsu->n || y >= dsu->n) {
        return false;
    }
    size_t n = dsu->n;
    if (find_root(dsu, x) == find_root(dsu, y)) {
        *out_consistent = false;
        return true;
    }
    union_roots(dsu, x, y + n);
    union_roots(dsu, y, x + n);
    *out_consistent = true;
    return true;
}

bool enemy_dsu_are_friends(EnemyDisjointSet *dsu, size_t x, size_t y, bool *out_friends) {
    if (dsu == NULL || out_friends == NULL || x >= dsu->n || y >= dsu->n) {
        return false;
    }
    *out_friends = (find_root(dsu, x) == find_root(dsu, y));
    return true;
}

bool enemy_dsu_are_enemies(EnemyDisjointSet *dsu, size_t x, size_t y, bool *out_enemies) {
    if (dsu == NULL || out_enemies == NULL || x >= dsu->n || y >= dsu->n) {
        return false;
    }
    *out_enemies = (find_root(dsu, x) == find_root(dsu, y + dsu->n));
    return true;
}

int main(void) {
    EnemyDisjointSet *dsu = enemy_dsu_create(6);
    assert(dsu != NULL);

    bool consistent = false;
    bool is_f = false;
    bool is_e = false;

    assert(enemy_dsu_add_enemies(dsu, 0, 1, &consistent) && consistent);
    assert(enemy_dsu_add_enemies(dsu, 1, 2, &consistent) && consistent);

    assert(enemy_dsu_are_friends(dsu, 0, 2, &is_f) && is_f);
    assert(enemy_dsu_are_enemies(dsu, 0, 1, &is_e) && is_e);

    assert(enemy_dsu_add_friends(dsu, 0, 1, &consistent) && !consistent);

    enemy_dsu_destroy(dsu);
    return 0;
}
```

## 复杂度分析

- **时间复杂度**：内部寻根操作均采用了按秩合并与路径压缩，单次调用涉及常数次集合操作，单次摊还时间复杂度严格为 $O(\alpha(n))$。
- **空间复杂度**：为 $2n$ 个扩展域节点维护 `parent` 与 `rank` 数组，辅助空间复杂度严格为 $2 \times 2n \times \text{sizeof(size\_t)} = O(n)$。

## 延伸思考 / 模式总结

1. **命题逻辑与 2-SAT 的桥梁**：扩展域并查集的拆点思想是布尔可满足性问题（2-SAT）强连通分量解法的前置阶梯。将命题对象拆为“肯定”与“否定”两个真值节点，并利用连通性检验是否推出 $x \iff \neg x$ 的逻辑矛盾，是离散数学逻辑推理在算法工程中的标准实践。
2. **三元扩展与捕食环**：若实体间存在循环克制关系（例如经典的剪刀石头布或食物链三元捕食关系 $A \to B \to C \to A$），只需将全域扩大为 $3n$（分别代表同类域、捕食域、天敌域），便可依循相同原理以零推导难度解决极其复杂的多方关系推断。
