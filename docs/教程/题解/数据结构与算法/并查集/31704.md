# 31704 - 带权并查集与奇偶关系维护

## 题目描述

实现维护二元同类/异类关系的带权并查集 `ParityDisjointSet`，支持关系声明与冲突检测（`parity_dsu_relate`）以及相对关系查询（`parity_dsu_query`）：

```c
#include <stdbool.h>
#include <stddef.h>

typedef struct ParityDisjointSet ParityDisjointSet;

ParityDisjointSet *parity_dsu_create(size_t count);
void parity_dsu_destroy(ParityDisjointSet *set);
bool parity_dsu_relate(
    ParityDisjointSet *set,
    size_t left,
    size_t right,
    bool different,
    bool *out_consistent
);
bool parity_dsu_query(
    const ParityDisjointSet *set,
    size_t left,
    size_t right,
    bool *out_known,
    bool *out_different
);
```

要求：

1. 每个节点维护到父节点的模 $2$ 异或边权（`0` 表示与父节点同类，`1` 表示与父节点异类，根节点边权为 `0`）；支持按大小（或按秩）合并与带边权更新的两趟路径压缩。
2. `parity_dsu_relate` 尝试建立 `left` 与 `right` 的同类（`different == false`）或异类（`different == true`）关系：若两者已在同一连通分量且已有奇偶路径与新关系矛盾，成功返回 `true`、设置 `*out_consistent = false`，且不得改变集合中的已有拓扑关系；若一致或分属不同分量，执行合并并设置 `*out_consistent = true`。
3. `parity_dsu_query` 查询两者的奇偶关系：若两者尚不在同一连通分量，设置 `*out_known = false`，且不得修改 `*out_different`；若在同一分量，设置 `*out_known = true` 并将两者是否异类写入 `*out_different`。
4. 下标越界、分配失败或指针参数无效时返回 `false`，不得修改集合与输出对象；`count == 0` 可以创建空集合，`destroy(NULL)` 安全。
5. 详细推导路径压缩与两根合并时的模 2 异或边权转移方程，单次操作的摊还时间复杂度应达到 $O(\alpha(n))$。

## 解题思路

### 1. 模 2 差分势能系统

普通并查集仅维护“是否属于同一连通块”的定性关系。**带权并查集（Weighted Disjoint Set）**通过为树中的每条有向边赋予权值，进一步维护了元素相对于其根节点的**相对势能偏移量**。
在二分图判定或同类/敌对判定中，关系仅有两种可能（同类为 0，异类为 1）。边权满足模 2 加法（即位异或运算 $\oplus$）：
- 任意节点 $x$ 到其所在树根 $r$ 的总相对关系 $d(x)$ 等于从 $x$ 到 $r$ 沿途所有边权的异或和：
  $$d(x) = \bigoplus_{e \in \text{path}(x \to r)} w(e)$$
- 同一分量中两节点 $u$ 与 $v$ 的相对奇偶关系即为它们到共同根节点距离的异或和：
  $$w(u, v) = d(u) \oplus d(v)$$

### 2. 两趟迭代带权路径压缩

当执行路径压缩将节点 $x$ 直接挂接至根节点 $root$ 时，必须同步修正边权数组：
1. **第一趟**：沿 `parent` 链向上累异或，求出 $x$ 到 $root$ 的总权值 `total_xor`；
2. **第二趟**：从 $x$ 再次向上遍历，记当前指针为 `cursor`，当前剩余相对权值为 `remaining_xor`（初值为 `total_xor`）。在将 `parent[cursor]` 改写为 `root` 前，先缓存原有边权 `edge = parity[cursor]`，然后将 `parity[cursor]` 更新为 `remaining_xor`，并将剩余权值推进为 `remaining_xor ^= edge`。
这种两趟双指针迭代在 $O(1)$ 辅助栈空间下安全完成了带权路径压缩。

### 3. 按大小合并时的根间边权推导

设 `left` 到其根 $r_L$ 的相对权为 $d_L$，`right` 到其根 $r_R$ 的相对权为 $d_R$，新建立的关系为 $w \in \{0, 1\}$：
- **冲突检测**：若 $r_L == r_R$，两节点已在同一棵树中。两者的既有关系由 $d_L \oplus d_R$ 唯一决定。若 $(d_L \oplus d_R) \neq w$，说明产生了奇环矛盾（例如 $A$ 与 $B$ 异类、$B$ 与 $C$ 异类、现在又宣称 $A$ 与 $C$ 异类），返回冲突且不破坏原树；
- **跨根合并**：若 $r_L \neq r_R$，假设按大小合并将 $r_R$ 挂在 $r_L$ 之下（`parent[r_R] = r_L`），全路径满足：
  $$d_L \oplus \text{parity}[r_R] \oplus d_R = w$$
  在等式两边同时异或 $d_L \oplus d_R$，由异或自反律（$x \oplus x = 0$）可直接解得新生成的根间边权转移方程：
  $$\text{parity}[r_R] = d_L \oplus d_R \oplus w$$

## C 语言实现

```c
#include <assert.h>
#include <stdbool.h>
#include <stddef.h>
#include <stdint.h>
#include <stdio.h>
#include <stdlib.h>

typedef struct ParityDisjointSet ParityDisjointSet;

struct ParityDisjointSet {
    size_t *parent;
    size_t *sizes;
    unsigned char *parity;
    size_t count;
};

ParityDisjointSet *parity_dsu_create(size_t count) {
    ParityDisjointSet *set = malloc(sizeof *set);
    if (set == NULL) {
        return NULL;
    }
    set->parent = NULL;
    set->sizes = NULL;
    set->parity = NULL;
    set->count = count;

    if (count > 0) {
        if (count > SIZE_MAX / sizeof *set->parent) {
            free(set);
            return NULL;
        }
        set->parent = malloc(count * sizeof *set->parent);
        set->sizes = malloc(count * sizeof *set->sizes);
        set->parity = calloc(count, sizeof *set->parity);
        if (set->parent == NULL || set->sizes == NULL ||
            set->parity == NULL) {
            free(set->parent);
            free(set->sizes);
            free(set->parity);
            free(set);
            return NULL;
        }
        for (size_t i = 0; i < count; ++i) {
            set->parent[i] = i;
            set->sizes[i] = 1;
        }
    }
    return set;
}

void parity_dsu_destroy(ParityDisjointSet *set) {
    if (set == NULL) {
        return;
    }
    free(set->parent);
    free(set->sizes);
    free(set->parity);
    free(set);
}

static size_t find_compress(
    ParityDisjointSet *set,
    size_t element,
    unsigned char *out_parity
) {
    size_t root = element;
    unsigned char total_xor = 0;
    while (set->parent[root] != root) {
        total_xor ^= set->parity[root];
        root = set->parent[root];
    }

    unsigned char remaining_xor = total_xor;
    size_t cursor = element;
    while (cursor != root) {
        size_t next = set->parent[cursor];
        unsigned char edge = set->parity[cursor];
        set->parent[cursor] = root;
        set->parity[cursor] = remaining_xor;
        remaining_xor ^= edge;
        cursor = next;
    }

    if (out_parity != NULL) {
        *out_parity = total_xor;
    }
    return root;
}

static size_t find_const(
    const ParityDisjointSet *set,
    size_t element,
    unsigned char *out_parity
) {
    size_t root = element;
    unsigned char total_xor = 0;
    while (set->parent[root] != root) {
        total_xor ^= set->parity[root];
        root = set->parent[root];
    }
    if (out_parity != NULL) {
        *out_parity = total_xor;
    }
    return root;
}

bool parity_dsu_relate(
    ParityDisjointSet *set,
    size_t left,
    size_t right,
    bool different,
    bool *out_consistent
) {
    if (set == NULL || out_consistent == NULL ||
        left >= set->count || right >= set->count) {
        return false;
    }

    unsigned char p_left = 0;
    unsigned char p_right = 0;
    size_t root_left = find_compress(set, left, &p_left);
    size_t root_right = find_compress(set, right, &p_right);
    unsigned char expected_diff = different ? 1 : 0;

    if (root_left == root_right) {
        *out_consistent = ((p_left ^ p_right) == expected_diff);
        return true;
    }

    *out_consistent = true;
    unsigned char root_edge = p_left ^ p_right ^ expected_diff;

    if (set->sizes[root_left] < set->sizes[root_right]) {
        set->parent[root_left] = root_right;
        set->parity[root_left] = root_edge;
        set->sizes[root_right] += set->sizes[root_left];
    } else {
        set->parent[root_right] = root_left;
        set->parity[root_right] = root_edge;
        set->sizes[root_left] += set->sizes[root_right];
    }
    return true;
}

bool parity_dsu_query(
    const ParityDisjointSet *set,
    size_t left,
    size_t right,
    bool *out_known,
    bool *out_different
) {
    if (set == NULL || out_known == NULL ||
        left >= set->count || right >= set->count) {
        return false;
    }

    unsigned char p_left = 0;
    unsigned char p_right = 0;
    size_t root_left = find_const(set, left, &p_left);
    size_t root_right = find_const(set, right, &p_right);

    if (root_left != root_right) {
        *out_known = false;
        return true;
    }

    *out_known = true;
    if (out_different != NULL) {
        *out_different = ((p_left ^ p_right) == 1);
    }
    return true;
}

int main(void) {
    ParityDisjointSet *set = parity_dsu_create(6);
    assert(set != NULL);

    bool consistent = false;
    bool known = false;
    bool different = false;

    assert(parity_dsu_relate(set, 0, 1, true, &consistent) && consistent);
    assert(parity_dsu_relate(set, 1, 2, true, &consistent) && consistent);

    assert(parity_dsu_query(set, 0, 2, &known, &different));
    assert(known && !different);

    assert(parity_dsu_query(set, 0, 1, &known, &different));
    assert(known && different);

    assert(parity_dsu_relate(set, 0, 2, true, &consistent) && !consistent);

    parity_dsu_destroy(set);
    return 0;
}
```

## 复杂度分析

- **时间复杂度**：
  - `parity_dsu_relate` 与 `parity_dsu_query`：虽然在路径压缩中增加了边权的异或前缀和累加，但寻根与合并的树形结构本质与标准并查集完全一致，单次操作的摊还时间复杂度依然为理论最优的 $O(\alpha(n))$。
  - `parity_dsu_create`：初始化分配三组数组，时间复杂度为 $O(n)$。
- **空间复杂度**：除 `parent` 和 `sizes` 外，新增一个单字节 `parity` 边权数组，空间复杂度严格为 $O(n)$。

## 延伸思考 / 模式总结

1. **阿贝尔群上的势能系统推广**：模 2 异或在代数上构成了一个二阶循环阿贝尔群 $(\mathbb{Z}_2, \oplus)$。该数学框架可以完全等价推广到模 3 循环群 $(\mathbb{Z}_3, +)$（经典如“食物链”猎食、被食、同类三元环问题），以及连续实数加法群 $(\mathbb{R}, +)$（维护元素间的绝对数值差值方程 $\Delta x = x_i - x_j$）。
2. **两趟迭代消除递归爆栈**：带权路径压缩通常在教科书中被写为递归函数，但当初始树高退化严重时，过深的调用栈极易引发栈溢出崩溃。通过两次显式循环迭代，不仅保证了确定性的常数辅助栈消耗，更极大改善了编译器向量化与流水线分支预测效率。
