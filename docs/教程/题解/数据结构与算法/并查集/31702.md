# 31702 - 路径压缩与按秩合并并查集

## 题目描述

实现支持动态合并、连通性查询以及连通分量大小查询的整数并查集 `IntDisjointSet`，综合应用按大小/按秩合并（Union by Size / Rank）与路径压缩（Path Compression）双重优化策略：

```c
#include <stdbool.h>
#include <stddef.h>

typedef struct IntDisjointSet IntDisjointSet;

IntDisjointSet *int_dsu_create(size_t count);
void int_dsu_destroy(IntDisjointSet *set);
bool int_dsu_union(
    IntDisjointSet *set,
    size_t left,
    size_t right,
    bool *out_merged
);
bool int_dsu_same(
    const IntDisjointSet *set,
    size_t left,
    size_t right,
    bool *out_same
);
bool int_dsu_component_size(
    const IntDisjointSet *set,
    size_t element,
    size_t *out_size
);
```

要求：

1. 初始时每个元素单独成集合，外部标识符范围为 $[0, \text{count} - 1]$。
2. 合并操作必须采用启发式按大小（或按秩）合并，并在查找树根的过程中执行两趟完全展平路径压缩（Two-Pass Flattening）。
3. 重复合并已连通的元素时操作成功，设置 `*out_merged = false`；无效下标或参数错误时返回 `false` 且不修改输出对象。
4. `int_dsu_destroy(NULL)` 安全；`count == 0` 时允许创建空集合。
5. 证明双重优化下的单次操作摊还时间复杂度为 $O(\alpha(n))$（反阿克曼函数），并详细说明维护的不变式。

## 解题思路

### 1. 双重优化策略协同

朴素并查集性能退化的根源在于树高膨胀。通过双重优化策略协同，彻底压平树形结构：

1. **按大小合并（Union by Size）**：
   - 为每个树根维护一个计数器 `sizes[root]`，记录当前连通分量包含的节点总数；
   - 执行合并时，总是将节点较少的小树树根挂靠到节点较多的大树树根之下；
   - **树高不变式**：单独采用按大小合并时，一棵包含 $k$ 个节点的树其高度至多为 $\lfloor \log_2 k \rfloor + 1$。因为只有在合并两个规模相当的树时，树高才会增加 1，这确保了最坏情况下的深度增长极为缓慢。
2. **两趟完全展平路径压缩（Path Compression）**：
   - 第一次向上遍历：从待查询节点沿着 `parent` 链一路追踪到真正的树根 `root`；
   - 第二次向上遍历：重新从当前节点出发，将沿途每一个途径节点的 `parent[cursor]` 直接改写为 `root`。
   - 经过这一趟扫描，整条长链上的所有节点全部转为直接悬挂在根节点之下的叶节点，后继所有针对该分支的寻根查询均退化为单次数组访问。

### 2. 摊还复杂度 $O(\alpha(n))$ 的直观理解

阿克曼函数 $A(i, j)$ 是一个超指数级爆炸增长的函数：
- $A(1, j) = 2j$；
- $A(2, j) = 2^j$；
- $A(3, j) = 2^{2^{\dots^2}}$（高为 $j$ 的幂塔）；
- $A(4, j)$ 则以不可思议的速度飞升，在 $A(4, 1) = 16$ 之后，$A(4, 2) = 2^{65536}$，其数值已经远远超出了宇宙中全部基本粒子的总数。

其反函数 $\alpha(n) = \min \{ k \mid A(k, 1) \ge n \}$ 增长极其缓慢。对于整个现实宇宙中能够表示的任何宇宙级规模规模 $n$（即使 $n = 2^{65536}$），$\alpha(n) \le 4$。
Tarjan 证明了：同时采用路径压缩和按秩/按大小合并的并查集，在对包含 $n$ 个对象的集合执行序列长度为 $m$ 的操作时，总运行时间严格受限在 $O(m \cdot \alpha(n))$ 以内。平摊到单次操作的代价在工程上完全可以视作常数时间。

## C 语言实现

```c
#include <assert.h>
#include <stdbool.h>
#include <stddef.h>
#include <stdint.h>
#include <stdio.h>
#include <stdlib.h>

typedef struct IntDisjointSet IntDisjointSet;

struct IntDisjointSet {
    size_t *parent;
    size_t *sizes;
    size_t count;
};

IntDisjointSet *int_dsu_create(size_t count) {
    IntDisjointSet *set = malloc(sizeof *set);
    if (set == NULL) {
        return NULL;
    }
    set->parent = NULL;
    set->sizes = NULL;
    set->count = count;
    if (count > 0) {
        if (count > SIZE_MAX / sizeof *set->parent) {
            free(set);
            return NULL;
        }
        set->parent = malloc(count * sizeof *set->parent);
        set->sizes = malloc(count * sizeof *set->sizes);
        if (set->parent == NULL || set->sizes == NULL) {
            free(set->parent);
            free(set->sizes);
            free(set);
            return NULL;
        }
        for (size_t i = 0; i < count; ++i) {
            set->parent[i] = i;
            set->sizes[i] = 1;
        }
    }
    return set;
}

void int_dsu_destroy(IntDisjointSet *set) {
    if (set == NULL) {
        return;
    }
    free(set->parent);
    free(set->sizes);
    free(set);
}

static size_t find_root(IntDisjointSet *set, size_t element) {
    size_t root = element;
    while (set->parent[root] != root) {
        root = set->parent[root];
    }
    while (set->parent[element] != element) {
        size_t next = set->parent[element];
        set->parent[element] = root;
        element = next;
    }
    return root;
}

static size_t find_root_const(
    const IntDisjointSet *set,
    size_t element
) {
    while (set->parent[element] != element) {
        element = set->parent[element];
    }
    return element;
}

bool int_dsu_union(
    IntDisjointSet *set,
    size_t left,
    size_t right,
    bool *out_merged
) {
    if (set == NULL || out_merged == NULL ||
        left >= set->count || right >= set->count) {
        return false;
    }
    size_t left_root = find_root(set, left);
    size_t right_root = find_root(set, right);
    if (left_root == right_root) {
        *out_merged = false;
        return true;
    }

    if (set->sizes[left_root] < set->sizes[right_root]) {
        set->parent[left_root] = right_root;
        set->sizes[right_root] += set->sizes[left_root];
    } else {
        set->parent[right_root] = left_root;
        set->sizes[left_root] += set->sizes[right_root];
    }
    *out_merged = true;
    return true;
}

bool int_dsu_same(
    const IntDisjointSet *set,
    size_t left,
    size_t right,
    bool *out_same
) {
    if (set == NULL || out_same == NULL ||
        left >= set->count || right >= set->count) {
        return false;
    }
    *out_same = (find_root_const(set, left) == find_root_const(set, right));
    return true;
}

bool int_dsu_component_size(
    const IntDisjointSet *set,
    size_t element,
    size_t *out_size
) {
    if (set == NULL || out_size == NULL || element >= set->count) {
        return false;
    }
    size_t root = find_root_const(set, element);
    *out_size = set->sizes[root];
    return true;
}

int main(void) {
    int_dsu_destroy(NULL);

    IntDisjointSet *dsu = int_dsu_create(6);
    assert(dsu != NULL);

    bool merged = false;
    bool same = false;
    size_t comp_size = 0;

    assert(int_dsu_union(dsu, 0, 1, &merged) && merged);
    assert(int_dsu_union(dsu, 1, 2, &merged) && merged);
    assert(int_dsu_union(dsu, 0, 2, &merged) && !merged);

    assert(int_dsu_same(dsu, 0, 2, &same) && same);
    assert(int_dsu_same(dsu, 0, 3, &same) && !same);

    assert(int_dsu_component_size(dsu, 0, &comp_size) && comp_size == 3);
    assert(int_dsu_component_size(dsu, 3, &comp_size) && comp_size == 1);

    assert(int_dsu_union(dsu, 3, 4, &merged) && merged);
    assert(int_dsu_union(dsu, 4, 5, &merged) && merged);
    assert(int_dsu_union(dsu, 2, 5, &merged) && merged);

    assert(int_dsu_same(dsu, 0, 5, &same) && same);
    assert(int_dsu_component_size(dsu, 1, &comp_size) && comp_size == 6);

    int_dsu_destroy(dsu);
    return 0;
}
```

## 复杂度分析

- **时间复杂度**：
  - `int_dsu_create`：初始化分配两个数组并设置恒等下标，时间复杂度为 $O(n)$。
  - `int_dsu_union` 与 `int_dsu_same`：得益于按大小合并与两趟路径压缩，单次操作的摊还时间复杂度达到极其优越的 $O(\alpha(n))$，其中 $\alpha$ 为反阿克曼函数，在所有现实物理规模下恒有 $\alpha(n) \le 4$。
  - `int_dsu_component_size`：通过非修改式常数根查找，时间复杂度同样为 $O(\alpha(n))$。
- **空间复杂度**：维护 `parent` 与 `sizes` 两个连续数组，内存空间占用严格为 $2 \times n \times \text{sizeof(size\_t)} = O(n)$。

## 延伸思考 / 模式总结

1. **不可变查询 `find_root_const` 的设计美学**：在 C 语言规范中，`const IntDisjointSet *set` 约束了入参的只读语义。虽然带修改的路径压缩能够优化后续查询，但打破了只读合约；实现中专门提供不修改拓扑的 `find_root_const`，完美兼顾了接口的常量正确性（Const-Correctness）与线程安全只读语义。
2. **两趟展平与隔代压缩的取舍**：除了本解展示的两趟显式循环完全展平（Two-Pass Flattening）外，还有一种在单趟循环中直接将节点挂靠到祖父节点的**隔代压缩（Path Halving / Path Splitting）**：`parent[x] = parent[parent[x]]`。隔代压缩单趟完成，常数略小且同样能达到 $O(\alpha(n))$ 的理论保证。
