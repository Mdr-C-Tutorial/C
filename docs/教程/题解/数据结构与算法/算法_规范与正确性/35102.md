# 35102 - 欧几里得最大公约数与扩展欧几里得规约与停机性证明

## 题目描述

实现满足严格前置条件与后置条件契约的欧几里得最大公约数、防溢出最小公倍数与扩展欧几里得算法：

```c
#include <stdbool.h>
#include <stdint.h>

uint64_t gcd_u64(uint64_t a, uint64_t b);
bool lcm_u64(uint64_t a, uint64_t b, uint64_t *out_lcm);
bool extended_gcd_i64(
    int64_t a,
    int64_t b,
    int64_t *out_gcd,
    int64_t *out_x,
    int64_t *out_y
);
```

要求：

1. `gcd_u64`：对任意 `uint64_t` 输入返回 $\gcd(a, b)$；规定 $\gcd(a, 0) = \gcd(0, a) = a$，且 $\gcd(0, 0) = 0$。
2. `lcm_u64`：当 `out_lcm == NULL` 时返回 `false`；若 $a = 0$ 或 $b = 0$，最小公倍数规定为 `0`；否则先除后乘计算 $\frac{a}{\gcd(a, b)} \times b$，若乘积超出 `UINT64_MAX` 则返回 `false` 且不改写输出。
3. `extended_gcd_i64`：若任一输出指针为 `NULL` 返回 `false`；若 $\gcd(a, b)$ 无法表示为非负 `int64_t`（如 `a == INT64_MIN && b == 0`），返回 `false`；否则使 `*out_gcd >= 0` 并求出满足贝祖等式 $a \cdot (*\text{out\_x}) + b \cdot (*\text{out\_y}) = *\text{out\_gcd}$ 的整数解，运算全程不得触发有符号整数溢出。
4. 说明欧几里得算法的规约不变式与基于良基关系的停机性。

## 解题思路

### 1. 规约不变式与良基关系停机性

对于非负整数状态对 $(a, b)$，当 $b > 0$ 时，由带余除法 $a = q b + r\ (0 \le r < b)$，任意整除 $a$ 与 $b$ 的公因数必整除 $r = a - q b$，反之亦然。因此公因子集合在每一步保持不变，导出**规约不变式**：

$$\gcd(a, b) = \gcd(b, a \bmod b)$$

为了形式化证明停机性，定义自然数集合上的测度函数 $\mu(a, b) = b \in \mathbb{N}$。
- 在每一次迭代中，新状态的测度 $\mu' = a \bmod b < b = \mu$。
- 自然数小于关系 $(\mathbb{N}, <)$ 是一个良基偏序集（Well-founded Poset），不存在无限严格递减链。
- 因此，测度函数必然在有限步内递减至下界 $\mu = 0$（即 $b = 0$），循环强制终止，此时 $\gcd(a, 0) = a$ 即为最大公约数。

### 2. 防溢出最小公倍数

代数公式为 $\operatorname{lcm}(a, b) = \frac{a \cdot b}{\gcd(a, b)}$。若直接计算分子乘积 $a \cdot b$，极易在 `uint64_t` 中发生回绕溢出。正确的实现顺序为**先整除后相乘**：
1. 计算 $g = \gcd(a, b)$；
2. 令 $q = a / g$；
3. 判断 $q > \text{UINT64\_MAX} / b$：若为真则表明结果超出类型表示范围，安全返回 `false`；否则写入 $q \times b$ 并返回 `true`。

### 3. 扩展欧几里得与 `INT64_MIN` 边界

在 64 位有符号整型中，$\text{INT64\_MIN} = -2^{63}$，其绝对值 $2^{63} = \text{INT64\_MAX} + 1$ 无法表示为有符号 64 位整数。
- 若 $(a, b)$ 为 $(\text{INT64\_MIN}, 0)$、$(0, \text{INT64\_MIN})$ 或 $(\text{INT64\_MIN}, \text{INT64\_MIN})$，其数学公约数为 $2^{63}$，超出 `int64_t` 上界，按契约返回 `false`。
- 其他情况下，在无符号 `uint64_t` 空间中安全提取绝对值 $r_0 = |a|, r_1 = |b|$，并维护贝祖系数不变式：
  $$a x_0 + b y_0 = r_0, \quad a x_1 + b y_1 = r_1$$
- 由于 $|x_k| \le |b| / g \le 2^{62}$，中间运算在 64 位有符号整型范围内恒不溢出。

## C 语言实现

```c
#include <assert.h>
#include <inttypes.h>
#include <limits.h>
#include <stdbool.h>
#include <stdint.h>
#include <stdio.h>

static uint64_t abs_to_u64(int64_t v) {
    if (v >= 0) {
        return (uint64_t)v;
    }
    return 0ULL - (uint64_t)v;
}

uint64_t gcd_u64(uint64_t a, uint64_t b) {
    while (b != 0) {
        uint64_t r = a % b;
        a = b;
        b = r;
    }
    return a;
}

bool lcm_u64(uint64_t a, uint64_t b, uint64_t *out_lcm) {
    if (out_lcm == NULL) {
        return false;
    }
    if (a == 0 || b == 0) {
        *out_lcm = 0;
        return true;
    }
    uint64_t g = gcd_u64(a, b);
    uint64_t scaled_a = a / g;
    if (scaled_a > UINT64_MAX / b) {
        return false;
    }
    *out_lcm = scaled_a * b;
    return true;
}

bool extended_gcd_i64(
    int64_t a,
    int64_t b,
    int64_t *out_gcd,
    int64_t *out_x,
    int64_t *out_y
) {
    if (out_gcd == NULL || out_x == NULL || out_y == NULL) {
        return false;
    }
    if (b == 0) {
        if (a == INT64_MIN) {
            return false;
        }
        *out_gcd = a < 0 ? -a : a;
        *out_x = a < 0 ? -1 : (a > 0 ? 1 : 0);
        *out_y = 0;
        return true;
    }
    if (a == 0) {
        if (b == INT64_MIN) {
            return false;
        }
        *out_gcd = b < 0 ? -b : b;
        *out_x = 0;
        *out_y = b < 0 ? -1 : 1;
        return true;
    }
    if (a == INT64_MIN && b == INT64_MIN) {
        return false;
    }
    if (b == 1 || b == -1) {
        *out_gcd = 1;
        *out_x = 0;
        *out_y = b;
        return true;
    }
    if (a == 1 || a == -1) {
        *out_gcd = 1;
        *out_x = a;
        *out_y = 0;
        return true;
    }

    uint64_t r0 = abs_to_u64(a);
    uint64_t r1 = abs_to_u64(b);
    int64_t x0 = a < 0 ? -1 : 1;
    int64_t y0 = 0;
    int64_t x1 = 0;
    int64_t y1 = b < 0 ? -1 : 1;

    while (r1 != 0) {
        uint64_t q_u64 = r0 / r1;
        uint64_t r2 = r0 % r1;
        int64_t q = (int64_t)q_u64;

        int64_t x2 = x0 - q * x1;
        int64_t y2 = y0 - q * y1;

        r0 = r1;
        r1 = r2;
        x0 = x1;
        y0 = y1;
        x1 = x2;
        y1 = y2;
    }

    *out_gcd = (int64_t)r0;
    *out_x = x0;
    *out_y = y0;
    return true;
}

int main(void) {
    assert(gcd_u64(0, 0) == 0);
    assert(gcd_u64(48, 18) == 6);

    uint64_t lcm_val = 0;
    assert(lcm_u64(21, 6, &lcm_val) && lcm_val == 42);
    assert(lcm_u64(0, 99, &lcm_val) && lcm_val == 0);
    assert(!lcm_u64(UINT64_MAX, 2, &lcm_val));

    int64_t g = 0, x = 0, y = 0;
    assert(extended_gcd_i64(240, 46, &g, &x, &y));
    assert(g == 2 && 240 * x + 46 * y == g);

    assert(extended_gcd_i64(-240, 46, &g, &x, &y));
    assert(g == 2 && (-240) * x + 46 * y == g);

    assert(!extended_gcd_i64(INT64_MIN, 0, &g, &x, &y));
    assert(!extended_gcd_i64(INT64_MIN, INT64_MIN, &g, &x, &y));
    assert(extended_gcd_i64(INT64_MIN, 6, &g, &x, &y));
    assert(g == 2);

    printf("All gcd, lcm, and extended_gcd tests passed.\n");
    return 0;
}
```

## 复杂度分析

- **时间复杂度**：$O(\log(\min\{a, b\}))$。由 Lamé 定理，欧几里得辗转相除法在每两次连续迭代中，余数至少减半（$r_{k+2} < r_k / 2$），最坏迭代步数不超过较小数以黄金分割比为底的对数阶。
- **空间复杂度**：$\Theta(1)$。仅维护常数个 64 位整型对象，原地迭代。

## 延伸思考 / 模式总结

扩展欧几里得算法不仅求解了最大公约数，更产出了不定方程 $ax + by = \gcd(a, b)$ 的整数组合解。这一算法展现了算法规范与正确性分析中两个核心支柱的配合：
1. **规约不变式（Reduction Invariant）** 保证了算法每一步的局部变换不改变全局解的数学本质；
2. **良基测度函数（Well-Founded Measure）** 保证了有限步内必达基准情形从而停机。
