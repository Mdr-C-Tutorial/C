# 35102：欧几里得算法、防溢出最小公倍数与扩展欧几里得契约实现

## 题目

实现满足前置条件与后置条件契约的欧几里得最大公约数、防溢出最小公倍数与扩展欧几里得算法，接口如下：

```c
#include <stdbool.h>
#include <stdint.h>

uint64_t gcd_u64(uint64_t a, uint64_t b);

bool lcm_u64(uint64_t a, uint64_t b, uint64_t *out_lcm);

bool extended_gcd_i64(
    int64_t a,
    int64_t b,
    int64_t *out_gcd,
    int64_t *out_x,
    int64_t *out_y
);
```

## 解析

### 1. 欧几里得算法与终止性、正确性

对于非负整数 $a, b$，当 $b > 0$ 时，由带余除法 $a = q b + r\ (0 \le r < b)$ 可知，$a$ 与 $b$ 的公因子集合完全等同于 $b$ 与 $r = a \bmod b$ 的公因子集合，故有不变式：

$$\gcd(a, b) = \gcd(b, a \bmod b)$$

由于每次迭代后第二个参量严格递减（$0 \le a \bmod b < b$），且每经过两次迭代余数至少减半（若 $r < b / 2$ 显然减半；若 $r \ge b / 2$，则下一轮余数 $b \bmod r = b - r \le b / 2$），算法必然在 $O(\log(\min\{a, b\}))$ 步内终止于 $b = 0$，此时 $a$ 即为最大公约数。

### 2. 防溢出最小公倍数

数学关系为 $\operatorname{lcm}(a, b) = \frac{a \cdot b}{\gcd(a, b)}$。为防止中间乘积 $a \cdot b$ 超出 `UINT64_MAX`，必须**先整除后相乘**：先计算 $q = a / \gcd(a, b)$，再通过 `q > UINT64_MAX / b` 检查 $q \times b$ 是否溢出。

### 3. 扩展欧几里得算法与 `INT64_MIN` 边界处理

在有符号 64 位整数类型 `int64_t` 中，`INT64_MIN` 的绝对值为 $2^{63} = \text{INT64\_MAX} + 1$，直接对 `INT64_MIN` 取负会导致有符号整数溢出（未定义行为）。
- 当 $(a, b)$ 为 $(\text{INT64\_MIN}, 0)$、$(0, \text{INT64\_MIN})$ 或 $(\text{INT64\_MIN}, \text{INT64\_MIN})$ 时，真实最大公约数为 $2^{63}$，无法用非负 `int64_t` 表示，按契约返回 `false`。
- 当 $|b| = 1$ 时，$\gcd(a, b) = 1$，直接取系数 $x = 0, y = b$ 即可满足 $a \cdot 0 + b \cdot b = 1$；同理当 $|a| = 1$ 时，取 $x = a, y = 0$ 即可。
- 对于其余情况（$|a| \ge 2$ 且 $|b| \ge 2$，且不同时为 `INT64_MIN`），先在无符号类型 `uint64_t` 中安全提取绝对值 $r_0 = |a|, r_1 = |b|$，并维护满足不变式
  $$a x_0 + b y_0 = r_0, \quad a x_1 + b y_1 = r_1$$
  的贝祖系数对。因为 $|a|, |b| \ge 2$，每步商 $q = \lfloor r_0 / r_1 \rfloor \le 2^{62} \le \text{INT64\_MAX}$，且扩展欧几里得算法保证中间系数满足 $|x_k| \le |b| / \gcd(a, b) \le 2^{62}$、$|y_k| \le |a| / \gcd(a, b) \le 2^{62}$，全程不会发生有符号溢出。

## 答案

```c
#include <assert.h>
#include <inttypes.h>
#include <limits.h>
#include <stdbool.h>
#include <stdint.h>
#include <stdio.h>

static uint64_t abs_to_u64(int64_t v) {
    if (v >= 0) {
        return (uint64_t)v;
    }
    return 0ULL - (uint64_t)v;
}

uint64_t gcd_u64(uint64_t a, uint64_t b) {
    while (b != 0) {
        uint64_t r = a % b;
        a = b;
        b = r;
    }
    return a;
}

bool lcm_u64(uint64_t a, uint64_t b, uint64_t *out_lcm) {
    if (out_lcm == NULL) {
        return false;
    }
    if (a == 0 || b == 0) {
        *out_lcm = 0;
        return true;
    }
    uint64_t g = gcd_u64(a, b);
    uint64_t scaled_a = a / g;
    if (scaled_a > UINT64_MAX / b) {
        return false;
    }
    *out_lcm = scaled_a * b;
    return true;
}

bool extended_gcd_i64(
    int64_t a,
    int64_t b,
    int64_t *out_gcd,
    int64_t *out_x,
    int64_t *out_y
) {
    if (out_gcd == NULL || out_x == NULL || out_y == NULL) {
        return false;
    }
    if (b == 0) {
        if (a == INT64_MIN) {
            return false;
        }
        *out_gcd = a < 0 ? -a : a;
        *out_x = a < 0 ? -1 : (a > 0 ? 1 : 0);
        *out_y = 0;
        return true;
    }
    if (a == 0) {
        if (b == INT64_MIN) {
            return false;
        }
        *out_gcd = b < 0 ? -b : b;
        *out_x = 0;
        *out_y = b < 0 ? -1 : 1;
        return true;
    }
    if (a == INT64_MIN && b == INT64_MIN) {
        return false;
    }
    if (b == 1 || b == -1) {
        *out_gcd = 1;
        *out_x = 0;
        *out_y = b;
        return true;
    }
    if (a == 1 || a == -1) {
        *out_gcd = 1;
        *out_x = a;
        *out_y = 0;
        return true;
    }

    uint64_t r0 = abs_to_u64(a);
    uint64_t r1 = abs_to_u64(b);
    int64_t x0 = a < 0 ? -1 : 1;
    int64_t y0 = 0;
    int64_t x1 = 0;
    int64_t y1 = b < 0 ? -1 : 1;

    while (r1 != 0) {
        uint64_t q_u64 = r0 / r1;
        uint64_t r2 = r0 % r1;
        int64_t q = (int64_t)q_u64;

        int64_t x2 = x0 - q * x1;
        int64_t y2 = y0 - q * y1;

        r0 = r1;
        r1 = r2;
        x0 = x1;
        y0 = y1;
        x1 = x2;
        y1 = y2;
    }

    *out_gcd = (int64_t)r0;
    *out_x = x0;
    *out_y = y0;
    return true;
}

int main(void) {
    assert(gcd_u64(0, 0) == 0);
    assert(gcd_u64(48, 18) == 6);

    uint64_t lcm_val = 0;
    assert(lcm_u64(21, 6, &lcm_val) && lcm_val == 42);
    assert(lcm_u64(0, 99, &lcm_val) && lcm_val == 0);
    assert(!lcm_u64(UINT64_MAX, 2, &lcm_val));

    int64_t g = 0, x = 0, y = 0;
    assert(extended_gcd_i64(240, 46, &g, &x, &y));
    assert(g == 2 && 240 * x + 46 * y == g);

    assert(extended_gcd_i64(-240, 46, &g, &x, &y));
    assert(g == 2 && (-240) * x + 46 * y == g);

    assert(!extended_gcd_i64(INT64_MIN, 0, &g, &x, &y));
    assert(!extended_gcd_i64(INT64_MIN, INT64_MIN, &g, &x, &y));

    assert(extended_gcd_i64(INT64_MIN, 6, &g, &x, &y));
    assert(g == 2);

    printf("All tests passed: gcd(240, 46) = %" PRId64 ", x = %" PRId64 ", y = %" PRId64 "\n", g, x, y);
    return 0;
}
```
