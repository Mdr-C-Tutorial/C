# 35104 - 循环停机性与良基测度函数证明

## 题目描述

循环停机性与良基测度函数（Well-Founded Measure Function）证明：

1. 形式化说明良基集 $(\mathcal{S}, \prec)$ 的定义，以及如何构造测度函数 $\mu: \text{State} \to \mathcal{S}$ 证明循环必然终止（不存在无限严格递减链）。
2. 给出欧几里得算法、左闭右开区间二分查找以及非负整数除法迭代的良基测度函数，并严格证明其在每轮循环中均严格递减。
3. 探讨考拉兹猜想（Collatz 3n+1 猜想）循环停机性证明的难点所在，并编写 C 程序模拟并断言测度函数单调递减轨迹。

## 解题思路

### 1. 良基集与图灵停机性判别

一个偏序集 $(\mathcal{S}, \prec)$ 被称为**良基集（Well-Founded Set）**，当且仅当该集合中不存在无限严格递减链：

$$\dots \prec s_k \prec \dots \prec s_2 \prec s_1 \prec s_0$$

最经典的良基集是赋予标准小于关系的自然数集 $(\mathbb{N}, <)$，其具有最小元 $0$。

要证明某个状态转换循环 $S_{t+1} = f(S_t)$ 必然在有限步内停机，其核心方法是构造一个从程序状态空间映射到良基集的**测度函数（Measure Function / Ranking Function）**：

$$\mu: \text{State} \to \mathcal{S}$$

并证明对任意单步循环迭代，恒满足**单调严格递减条件**：

$$\forall t, \quad S_{t+1} \ne \text{HALT} \implies \mu(S_{t+1}) \prec \mu(S_t)$$

由良基性定理，任何严格递减序列必在有限步内达到极小元，迫使循环哨兵条件不满足从而终止。

### 2. 三个经典算法的测度函数构造

1. **欧几里得辗转相除法**：
   - 状态为对偶 $(a, b) \in \mathbb{N} \times \mathbb{N}$，循环条件为 $b \ne 0$。
   - 构造测度函数 $\mu(a, b) = b \in \mathbb{N}$。
   - 迭代后新状态为 $(b, a \bmod b)$。由于带余除法性质，对所有 $b > 0$ 恒有 $a \bmod b < b$。
   - 因此 $\mu' = a \bmod b < b = \mu$，测度每步严格递减，至多 $b$ 步（实际为对数步）必停机。

2. **左闭右开区间二分查找**：
   - 状态为区间端点 $(\text{left}, \text{right}) \in \mathbb{N} \times \mathbb{N}$，循环条件为 $\text{left} < \text{right}$。
   - 构造测度函数 $\mu(\text{left}, \text{right}) = \text{right} - \text{left} \in \mathbb{N}$。
   - 中点 $\text{mid} = \text{left} + \lfloor (\text{right} - \text{left}) / 2 \rfloor$。当 $\text{left} < \text{right}$ 时，必有 $\text{left} \le \text{mid} < \text{right}$。
     - 若 $\text{left}' = \text{mid} + 1$，则 $\mu' = \text{right} - (\text{mid} + 1) \le \text{right} - \text{left} - 1 < \mu$；
     - 若 $\text{right}' = \text{mid}$，则 $\mu' = \text{mid} - \text{left} \le \text{right} - 1 - \text{left} < \mu$。
   - 两种分支均满足 $\mu' \le \lfloor \mu / 2 \rfloor < \mu$，区间长度严格减半递减，算法必然停机。

3. **非负整数竖式除法/减法取模**：
   - 从被除数中逐次减去除数 $B$（$B > 0$），当前余数 $R$ 构成测度函数 $\mu(R) = R \in \mathbb{N}$。
   - 每次循环 $R' = R - B < R$ 严格递减，当下界 $R < B$ 时终止。

### 3. 考拉兹猜想（3n+1）为何难以证明停机

考拉兹映射定义为：若 $n$ 为偶数则 $n \leftarrow n / 2$；若 $n$ 为奇数则 $n \leftarrow 3n + 1$。
- 当 $n$ 为偶数时数值减小；但当 $n$ 为奇数时数值剧烈膨胀增大。
- 至今未找到能在全域 $\mathbb{N}$ 上保单调递减的已知良基测度函数，故其全局停机性仍为未解的数学猜想。

## C 语言实现

```c
#include <assert.h>
#include <inttypes.h>
#include <stdbool.h>
#include <stddef.h>
#include <stdint.h>
#include <stdio.h>

/* 欧几里得算法与良基测度函数断言 */
uint64_t gcd_with_measure_assert(uint64_t a, uint64_t b, size_t *out_steps) {
    size_t steps = 0;
    while (b != 0) {
        uint64_t prev_measure = b;
        uint64_t r = a % b;
        a = b;
        b = r;
        uint64_t curr_measure = b;

        /* 验证良基测度严格单调递减 */
        assert(curr_measure < prev_measure);
        steps++;
    }
    if (out_steps != NULL) {
        *out_steps = steps;
    }
    return a;
}

/* 二分查找测度函数严格减半递减断言 */
size_t binary_search_with_measure(const int64_t *arr, size_t count, int64_t target) {
    size_t left = 0;
    size_t right = count;

    while (left < right) {
        size_t prev_measure = right - left;
        size_t mid = left + (right - left) / 2;

        if (arr[mid] < target) {
            left = mid + 1;
        } else {
            right = mid;
        }

        size_t curr_measure = right - left;
        /* 测度函数严格递减性质 */
        assert(curr_measure < prev_measure);
    }
    return left;
}

int main(void) {
    size_t gcd_steps = 0;
    uint64_t g = gcd_with_measure_assert(1071, 462, &gcd_steps);
    assert(g == 21 && gcd_steps > 0);

    int64_t sorted_data[] = {2, 4, 6, 8, 10, 12, 14, 16};
    size_t found_idx = binary_search_with_measure(sorted_data, 8, 10);
    assert(found_idx == 4);

    printf("All measure function termination assertions passed successfully.\n");
    return 0;
}
```

## 复杂度分析

- **欧几里得辗转相除法**：时间复杂度为 $O(\log(\min\{a, b\}))$，辅助空间 $\Theta(1)$。
- **二分查找**：测度函数每步减半，时间复杂度严格为 $O(\log n)$，辅助空间 $\Theta(1)$。

## 延伸思考 / 模式总结

证明算法正确性需要两件利器：
1. **循环不变式（Loop Invariant）** 证明“只要停机，结果必定正确”（部分正确性，Partial Correctness）；
2. **良基测度函数（Measure Function）** 证明“算法绝不会死循环，必然在有限步内停机”（终止性，Termination）。

二者结合，即构成**完全正确性（Total Correctness）**的充分必要数学证明。
