# 35104 - 二分查找的前置条件与后置条件契约断言

## 题目

为经典二分查找算法编写形式化前置条件与后置条件契约断言，接口如下：

```c
#include <stdbool.h>
#include <stddef.h>
#include <stdint.h>

bool binary_search_contract(
    const int64_t *arr,
    size_t count,
    int64_t target,
    size_t *out_index
);
```

要求：

1. 前置条件断言：指针有效性（若 `count > 0` 则 `arr != NULL`，`out_index != NULL`），以及数组在区间 `[0, count)` 内严格满足非递减偏序关系。
2. 后置条件契约：若返回 `true`，`*out_index` 必满足分界性质——对所有下标 $i < *\text{out\_index}$ 恒有 $\text{arr}[i] < \text{target}$；若 $*\text{out\_index} < \text{count}$，则 $\text{arr}[*\text{out\_index}] \ge \text{target}$。
3. 在循环体内显式包含循环不变式断言，并分析其时间复杂度与空间复杂度。

## 解题思路

### 1. 契约式设计（Design by Contract）

在算法规范中，契约是调用方与实现方之间的双向承诺：
- **前置条件（Precondition）**：实现方要求调用方传入有效指针，且被查序列已排序；
- **后置条件（Postcondition）**：实现方承诺找到单调谓词 $P(x) \equiv (\text{arr}[x] \ge \text{target})$ 的首个真值分界下标；
- **不变式（Invariant）**：在搜索区间维护过程中，保证答案必然存在于当前半开区间内。

### 2. 左闭右开区间与不变式推导

维护搜索区间 $[\text{left}, \text{right})$，初始时 $\text{left} = 0, \text{right} = \text{count}$。
- **循环不变式**：
  1. 对所有 $0 \le i < \text{left}$，恒有 $\text{arr}[i] < \text{target}$；
  2. 对所有 $\text{right} \le j < \text{count}$，恒有 $\text{arr}[j] \ge \text{target}$。
- **区间收缩与良基测度**：
  取中点 $\text{mid} = \text{left} + (\text{right} - \text{left}) / 2$。
  - 若 $\text{arr}[\text{mid}] < \text{target}$，由于数组单调递增，对所有 $k \le \text{mid}$ 均有 $\text{arr}[k] < \text{target}$，故新下界 $\text{left}' = \text{mid} + 1$ 保持不变式；
  - 若 $\text{arr}[\text{mid}] \ge \text{target}$，新上界 $\text{right}' = \text{mid}$ 保持不变式；
  - 测度函数 $\mu = \text{right} - \text{left}$ 严格递减且下界为 0，保证 $O(\log n)$ 步后终止于 $\text{left} == \text{right}$。

## C 语言实现

```c
#include <assert.h>
#include <inttypes.h>
#include <stdbool.h>
#include <stddef.h>
#include <stdint.h>
#include <stdio.h>

static bool is_sorted_i64(const int64_t *a, size_t n) {
    for (size_t i = 1; i < n; ++i) {
        if (a[i - 1] > a[i]) {
            return false;
        }
    }
    return true;
}

bool binary_search_contract(
    const int64_t *arr,
    size_t count,
    int64_t target,
    size_t *out_index
) {
    /* 前置契约检查 */
    if (out_index == NULL || (count > 0 && arr == NULL)) {
        return false;
    }
    /* 前置条件断言：输入数组必须满足非递减有序性 */
    assert(count == 0 || is_sorted_i64(arr, count));

    size_t left = 0;
    size_t right = count;

    while (left < right) {
        /* 循环不变式断言 */
        for (size_t i = 0; i < left; ++i) {
            assert(arr[i] < target);
        }
        for (size_t j = right; j < count; ++j) {
            assert(arr[j] >= target);
        }

        size_t mid = left + (right - left) / 2;
        if (arr[mid] < target) {
            left = mid + 1;
        } else {
            right = mid;
        }
    }

    /* 后置条件断言：
       1. left 前面的所有元素均小于 target；
       2. 若 left 未越界，left 位置的元素必定大于等于 target。
    */
    for (size_t i = 0; i < left; ++i) {
        assert(arr[i] < target);
    }
    if (left < count) {
        assert(arr[left] >= target);
    }

    *out_index = left;
    return true;
}

int main(void) {
    int64_t a[] = {1, 3, 5, 7, 9};
    size_t idx = 0;

    /* 目标值存在 */
    assert(binary_search_contract(a, 5, 5, &idx) && idx == 2);
    assert(binary_search_contract(a, 5, 1, &idx) && idx == 0);
    assert(binary_search_contract(a, 5, 9, &idx) && idx == 4);

    /* 目标值不存在，位于区间两端及中间 */
    assert(binary_search_contract(a, 5, 0, &idx) && idx == 0);
    assert(binary_search_contract(a, 5, 6, &idx) && idx == 3);
    assert(binary_search_contract(a, 5, 10, &idx) && idx == 5);

    /* 边界测试：空数组与空指针 */
    assert(binary_search_contract(NULL, 0, 5, &idx) && idx == 0);
    assert(!binary_search_contract(a, 5, 5, NULL));

    printf("All binary_search_contract tests passed.\n");
    return 0;
}
```

## 复杂度分析

- **时间复杂度**：算法主体时间复杂度为 $O(\log n)$。若在循环体内部开启形式化断言遍历，契约验证开销为 $O(n)$，通常仅在调试（Debug）模式通过断言宏使能，发布（Release）模式由编译器优化消除。
- **空间复杂度**：$\Theta(1)$。仅维护常数个下标对象。

## 延伸思考 / 模式总结

二分查找是形式化验证最经典的案例之一。通过左闭右开区间 $[\text{left}, \text{right})$，搜索区间长度初始恰好为 $\text{count}$，每次迭代划分点 `mid` 严格属于 $[\text{left}, \text{right})$，保证了区间长度在每步严格递减至少 1，消除了闭区间二分容易出现的死循环与越界风险。
