# 35101：极值中点计数与环形取硬币博弈

## 题目

(1) 平面上有 $n(n>2)$ 个不重合的点，将它们两两连成线段，将这些线段的中点涂成红色（如果有两个或两个以上的中点重合，那里只会呈现出一个红点）。输入 $n$，输出红点个数的最小值。

(2) 甲乙两人在玩抽硬币游戏。$n(n>0)$ 枚硬币紧挨着摆成一圈，从甲开始，轮流抽走**一枚**或**紧挨着的**（如果 ABC 是紧挨着的并且 A 和 C 不是紧挨着的，那么 B 抽走之后，A 和 C 不再是紧挨着的）**两枚**硬币。抽走最后一枚硬币的人取得胜利。两个人都很聪明，会采取最优的策略。编写程序，输入 $n$，输出甲获胜的概率。

## 解析

### 第 (1) 问：最少红点个数

建立平面直角坐标系。若存在两个点的横坐标相同，可通过旋转坐标系使全部 $n$ 个点的横坐标互不相同。设这 $n$ 个点按横坐标严格递增排序后依次为 $P_1(x_1, y_1), P_2(x_2, y_2), \dots, P_n(x_n, y_n)$，其中 $x_1 < x_2 < \dots < x_n$。

线段 $P_i P_j$ 的中点横坐标为 $\frac{x_i + x_j}{2}$。考察以下 $2n - 3$ 条线段：

$$P_1 P_2,\ P_1 P_3,\ P_2 P_3,\ P_2 P_4,\ P_3 P_4,\ \dots,\ P_{n-2} P_n,\ P_{n-1} P_n$$

它们的中点横坐标满足严格递增关系：

$$\frac{x_1 + x_2}{2} < \frac{x_1 + x_3}{2} < \frac{x_2 + x_3}{2} < \frac{x_2 + x_4}{2} < \dots < \frac{x_{n-2} + x_n}{2} < \frac{x_{n-1} + x_n}{2}$$

由于这 $2n - 3$ 个中点的横坐标互不相等，它们必然是互不重合的红点。这说明无论 $n$ 个点如何摆放，红点个数至少为 $2n - 3$。

反之，当 $n$ 个点共线且等距排列时，取 $P_i = (2i, 0)\ (i = 1, 2, \dots, n)$，任意线段 $P_i P_j\ (i < j)$ 的中点坐标为 $(i + j, 0)$。整数和 $i + j$ 的取值范围恰好是从 $1 + 2 = 3$ 到 $(n - 1) + n = 2n - 1$ 的全部整数，共 $(2n - 1) - 3 + 1 = 2n - 3$ 个不同位置。因此红点个数的最小值为 $2n - 3$。

### 第 (2) 问：环形取硬币对称博弈

分情况讨论初始硬币数 $n$：

- 当 $n = 1$ 或 $n = 2$ 时，先手甲在第一回合可以直接拿走全部 $n$ 枚硬币从而立即获胜，因此甲获胜的概率为 $1$。
- 当 $n \ge 3$ 时，先手甲在第一回合取走 $1$ 枚或相邻的 $2$ 枚硬币后，原本首尾相连的圆环被剪开，剩余的 $n - 1$ 或 $n - 2$ 枚硬币形成一条连续的链（长度至少为 $1$）。
  此时后手乙可以采取**中心对称模仿策略**：
  - 若链的长度为奇数，乙取走正中间的 $1$ 枚硬币；
  - 若链的长度为偶数，乙取走正中间紧挨着的 $2$ 枚硬币。
  无论哪种情况，乙操作后都会把这条链分成左右两段长度完全相等、相互独立的子链。在此后的每一个回合中，无论甲在其中一段子链的某个位置取走 $1$ 枚或相邻 $2$ 枚硬币，乙总能在另一段子链的对称位置执行完全相同的操作。由于对称操作永远存在，乙必然是取走最后一枚硬币的人。因此在双方均采取最优策略的前提下，当 $n \ge 3$ 时后手乙必胜，先手甲获胜的概率为 $0$。

## 答案

### (1) 最少红点个数计算程序

```c
#include <inttypes.h>
#include <stdio.h>

int main(void) {
    int64_t n = 0;
    if (scanf("%" SCNd64, &n) != 1 || n <= 2) {
        return 1;
    }
    printf("%" PRId64 "\n", 2 * n - 3);
    return 0;
}
```

### (2) 环形取硬币先手获胜概率程序

```c
#include <inttypes.h>
#include <stdio.h>

int main(void) {
    int64_t n = 0;
    if (scanf("%" SCNd64, &n) != 1 || n <= 0) {
        return 1;
    }
    if (n <= 2) {
        printf("1\n");
    } else {
        printf("0\n");
    }
    return 0;
}
```
