# 35105 - 模算术乘法逆元与扩展欧几里得贝祖等式契约验证

## 题目描述

实现模算术乘法逆元（Modular Multiplicative Inverse）与扩展欧几里得贝祖等式契约验证：

```c
#include <stdbool.h>
#include <stdint.h>

bool mod_inverse_i64(int64_t a, int64_t m, int64_t *out_inv);
```

要求：

1. 前置条件：模数 $m > 1$ 且输出指针 `out_inv != NULL`。
2. 后置条件：当且仅当 $\gcd(a, m) = 1$ 时存在乘法逆元，求出唯一满足 $0 \le x < m$ 且 $(a \cdot x) \equiv 1 \pmod m$ 的解写入 `*out_inv` 并返回 `true`；若逆元不存在返回 `false`。
3. 运算过程必须严格规避 64 位有符号溢出，并提供断言验证贝祖等式及逆元正确性。

## 解题思路

### 1. 模算术乘法逆元的数学性质

对于整数 $a$ 与正整数 $m$，若存在整数 $x$ 使得：

$$a \cdot x \equiv 1 \pmod m$$

则称 $x$ 为 $a$ 模 $m$ 的乘法逆元。该同余式等价于存在整数 $y$ 使得线性丢番图方程成立：

$$a \cdot x + m \cdot y = 1$$

根据贝祖定理（Bézout's Theorem），上述方程有整数解当且仅当 $\gcd(a, m) = 1$（即 $a$ 与 $m$ 互质）。当 $\gcd(a, m) = 1$ 时，由扩展欧几里得算法求出的系数 $x$ 即为一个解，且在模 $m$ 意义下该解是唯一的，取模调整可使 $0 \le x < m$。

### 2. 契约与防溢出设计

1. **前置条件验证**：
   - 检查 `out_inv != NULL` 以及 $m > 1$（若模数为 $0$ 或 $1$ 无法定义乘法逆元）。
2. **扩展欧几里得求解**：
   - 调用扩展欧几里得算法求解 $a x + m y = g$。
   - 若 $g \ne 1$，说明不互素，不存在逆元，直接返回 `false`。
3. **解的标准范围规范化**：
   - 扩展欧几里得求得的系数 $x$ 可能为负数，通过 `inv = (x % m + m) % m` 将其映射至 $[0, m - 1]$ 规范区间。
4. **后置条件断言验证**：
   - 使用无符号 64 位乘积取模验证 $(a \cdot \text{inv}) \equiv 1 \pmod m$。

## C 语言实现

```c
#include <assert.h>
#include <inttypes.h>
#include <limits.h>
#include <stdbool.h>
#include <stdint.h>
#include <stdio.h>

static uint64_t abs_to_u64(int64_t v) {
    if (v >= 0) {
        return (uint64_t)v;
    }
    return 0ULL - (uint64_t)v;
}

static bool extended_gcd_internal(
    int64_t a,
    int64_t b,
    int64_t *out_gcd,
    int64_t *out_x,
    int64_t *out_y
) {
    if (out_gcd == NULL || out_x == NULL || out_y == NULL) {
        return false;
    }
    if (b == 0) {
        if (a == INT64_MIN) return false;
        *out_gcd = a < 0 ? -a : a;
        *out_x = a < 0 ? -1 : (a > 0 ? 1 : 0);
        *out_y = 0;
        return true;
    }
    uint64_t r0 = abs_to_u64(a);
    uint64_t r1 = abs_to_u64(b);
    int64_t x0 = a < 0 ? -1 : 1;
    int64_t y0 = 0;
    int64_t x1 = 0;
    int64_t y1 = b < 0 ? -1 : 1;

    while (r1 != 0) {
        uint64_t q_u64 = r0 / r1;
        uint64_t r2 = r0 % r1;
        int64_t q = (int64_t)q_u64;

        int64_t x2 = x0 - q * x1;
        int64_t y2 = y0 - q * y1;

        r0 = r1;
        r1 = r2;
        x0 = x1;
        y0 = y1;
        x1 = x2;
        y1 = y2;
    }

    *out_gcd = (int64_t)r0;
    *out_x = x0;
    *out_y = y0;
    return true;
}

bool mod_inverse_i64(int64_t a, int64_t m, int64_t *out_inv) {
    /* 前置条件契约检查 */
    if (out_inv == NULL || m <= 1) {
        return false;
    }

    int64_t g = 0, x = 0, y = 0;
    if (!extended_gcd_internal(a, m, &g, &x, &y) || g != 1) {
        return false; /* gcd(a, m) != 1 时乘法逆元不存在 */
    }

    /* 将系数 x 映射入规范区间 [0, m - 1] */
    int64_t inv = x % m;
    if (inv < 0) {
        inv += m;
    }

    /* 后置条件断言：验证 (a * inv) % m == 1 */
    int64_t rem = (int64_t)(((uint64_t)abs_to_u64(a) * (uint64_t)inv) % (uint64_t)m);
    if (a < 0) {
        rem = (m - rem) % m;
    }
    assert(rem == 1);

    *out_inv = inv;
    return true;
}

int main(void) {
    int64_t inv = 0;

    /* 经典质数模数测试：3 * 4 = 12 = 1 (mod 11) */
    assert(mod_inverse_i64(3, 11, &inv) && inv == 4);

    /* 10 * 12 = 120 = 7 * 17 + 1 = 1 (mod 17) */
    assert(mod_inverse_i64(10, 17, &inv) && inv == 12);

    /* 负数操作数测试：-3 * 7 = -21 = -2 * 11 + 1 = 1 (mod 11) */
    assert(mod_inverse_i64(-3, 11, &inv) && inv == 7);

    /* 不互质无解测试：gcd(6, 9) = 3 != 1 */
    assert(!mod_inverse_i64(6, 9, &inv));

    /* 模数不合法前置违约：m <= 1 */
    assert(!mod_inverse_i64(5, 1, &inv));
    assert(!mod_inverse_i64(5, 0, &inv));

    /* 空指针前置违约 */
    assert(!mod_inverse_i64(3, 11, NULL));

    printf("All mod_inverse_i64 tests passed successfully.\n");
    return 0;
}
```

## 复杂度分析

- **时间复杂度**：$O(\log m)$。主要瓶颈为求解贝祖系数的扩展欧几里得算法，步数受限于以黄金分割比为底的模数对数阶。
- **空间复杂度**：$\Theta(1)$。仅维护常数个 64 位整数对象。

## 延伸思考 / 模式总结

乘法逆元是将代数运算从实数域除法迁移至有限群/环（Galois Field $\mathbb{F}_p$ 与模算术）的基石。在 RSA 加密、椭圆曲线密码学（ECC）与组合数逆元预计算中，乘法逆元均扮演核心角色。通过贝祖等式的形式化后置断言，可在运行时以确定性保证解的数学真值。
