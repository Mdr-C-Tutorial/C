# 题解：31306

## 题目

在开放寻址散列表中，若探测序列不能覆盖全部 $m$ 个槽，就可能出现“表中仍有空槽但新键无法插入”的假满现象。

- (a) 证明：在双重散列 $h(k, i) = (h_1(k) + i \cdot h_2(k)) \bmod m$（$i = 0, 1, \dots, m - 1$）中，这 $m$ 个探测位置恰好构成 $\{0, 1, \dots, m - 1\}$ 的一个全排列，当且仅当 $\gcd(h_2(k), m) = 1$。
- (b) 设容量 $m = 2^p$（$p \ge 1$），考虑三角形数二次探测序列：

  $$h(k, i) = \left(h_1(k) + \frac{i(i + 1)}{2}\right) \bmod 2^p \quad (i = 0, 1, \dots, 2^p - 1)$$

  证明：对任意整数 $0 \le i < j < 2^p$，$\frac{j(j + 1)}{2} - \frac{i(i + 1)}{2}$ 绝不可能是 $2^p$ 的倍数，从而该探测序列必然无重复地遍历全部 $2^p$ 个槽（提示：将差值因式分解为 $\frac{(j - i)(j + i + 1)}{2}$，分析两因子的奇偶性）。
- (c) 实现检验函数 `bool verify_triangular_probing_power_of_two(unsigned p)`，对给定的 $1 \le p \le 12$ 构造位图或布尔标记数组，实测验证 $i = 0, 1, \dots, 2^p - 1$ 恰好访问 $2^p$ 个互异槽位。

## 解析

### (a) 双重散列互素全排列条件证明

根据鸽巢原理，大小为 $m$ 的有限序列恰好构成模 $m$ 全排列的充分必要条件是序列中的 $m$ 个元素两两互不相同（即单射）。

考虑任意两个不同的探测步数 $0 \le i < j < m$：

$$h(k, j) \equiv h(k, i) \pmod m \iff h_1(k) + j \cdot h_2(k) \equiv h_1(k) + i \cdot h_2(k) \pmod m$$

两边消去 $h_1(k)$：

$$(j - i) \cdot h_2(k) \equiv 0 \pmod m$$

即 $m \mid (j - i) \cdot h_2(k)$。

1. **充分性（若 $\gcd(h_2(k), m) = 1$ 则构成全排列）**：
   由初等数论性质，当 $m \mid (j - i) \cdot h_2(k)$ 且 $\gcd(h_2(k), m) = 1$ 时，必有 $m \mid (j - i)$。
   然而根据前提，$0 \le i < j < m$，差值范围为 $0 < j - i < m$。在此范围内不存在 $m$ 的非零倍数，产生矛盾！
   因此不可能存在冲突，这 $m$ 个探测位置两两互异，构成 $\{0, 1, \dots, m - 1\}$ 的全排列。
2. **必要性（若构成全排列则 $\gcd(h_2(k), m) = 1$）**：
   采用逆否命题。设 $d = \gcd(h_2(k), m) > 1$。
   取 $j = m / d$ 与 $i = 0$。显然 $0 < j < m$。
   计算两步之差：$(j - 0) \cdot h_2(k) = \frac{m}{d} \cdot h_2(k) = m \cdot \frac{h_2(k)}{d}$。
   因为 $d \mid h_2(k)$，所以 $\frac{h_2(k)}{d}$ 是整数，上式是 $m$ 的整数倍，即 $(j - i) \cdot h_2(k) \equiv 0 \pmod m$。
   这意味着在步数 $j$ 和步数 $0$ 产生了相同槽位的重复访问，序列不可能构成全排列。

证毕。

---

### (b) 三角形数二次探测在 $2^p$ 容量下的全覆盖证明

任取 $0 \le i < j < 2^p$，考察两步对应的三角形数之差：

$$\Delta = \frac{j(j + 1)}{2} - \frac{i(i + 1)}{2} = \frac{(j^2 - i^2) + (j - i)}{2} = \frac{(j - i)(j + i + 1)}{2}$$

假设 $\Delta$ 是 $2^p$ 的整数倍，即存在整数 $k$ 使得：

$$\frac{(j - i)(j + i + 1)}{2} = k \cdot 2^p \iff (j - i)(j + i + 1) = k \cdot 2^{p + 1}$$

考察等式左侧的两个乘积因子：

$$A = j - i, \quad B = j + i + 1$$

计算两因子之和：

$$A + B = (j - i) + (j + i + 1) = 2j + 1$$

由于 $2j + 1$ 是奇数，**因子 $A$ 与 $B$ 的奇偶性必然相反**（一奇一偶）。

因为奇数因子不能贡献任何质因子 2，所以 $k \cdot 2^{p+1}$ 中包含的所有 $p + 1$ 个因子 2 必须**完全由那个唯一的偶数因子单独承担**。换言之，必有 $2^{p + 1} \mid A$ 或 $2^{p + 1} \mid B$。

分别检验两种情形：
1. 若 $2^{p + 1} \mid A$：即 $2^{p + 1} \mid (j - i)$。但已知 $0 \le i < j < 2^p$，因此 $0 < j - i < 2^p < 2^{p + 1}$，$j - i$ 绝不可能是 $2^{p + 1}$ 的倍数；
2. 若 $2^{p + 1} \mid B$：即 $2^{p + 1} \mid (j + i + 1)$。由于 $0 \le i < j \le 2^p - 1$，两数和的最大上限为：
   $$j + i + 1 \le (2^p - 1) + (2^p - 2) + 1 = 2^{p + 1} - 2 < 2^{p + 1}$$
   且 $j + i + 1 \ge 1 + 0 + 1 = 2 > 0$。因此 $0 < j + i + 1 < 2^{p + 1}$，同样绝不可能是 $2^{p + 1}$ 的倍数。

两种情形均导致矛盾。因此 $\Delta$ 绝不是 $2^p$ 的倍数，即在 $i \in [0, 2^p - 1]$ 范围内不存在任意两步落入同一槽位。根据鸽巢原理，探测序列必然无重复地遍历全部 $2^p$ 个槽。

证毕。

## 答案代码

```c
#include <assert.h>
#include <stdbool.h>
#include <stddef.h>
#include <stdlib.h>

bool verify_triangular_probing_power_of_two(unsigned p) {
    if (p == 0 || p > 20) {
        return false;
    }
    size_t m = (size_t)1 << p;
    size_t mask = m - 1;

    // 分配布尔访问标记数组
    bool *visited = calloc(m, sizeof(bool));
    if (visited == NULL) {
        return false;
    }

    size_t h = 0; // 假定初始散列值为 0
    for (size_t i = 0; i < m; ++i) {
        // 三角形数：i * (i + 1) / 2
        size_t tri = (i * (i + 1)) / 2;
        size_t slot = (h + tri) & mask;
        if (visited[slot]) {
            free(visited);
            return false; // 出现重复槽位
        }
        visited[slot] = true;
    }

    // 确认每个槽都被访问过
    for (size_t i = 0; i < m; ++i) {
        if (!visited[i]) {
            free(visited);
            return false;
        }
    }

    free(visited);
    return true;
}

int main(void) {
    for (unsigned p = 1; p <= 12; ++p) {
        assert(verify_triangular_probing_power_of_two(p));
    }
    return 0;
}
```
