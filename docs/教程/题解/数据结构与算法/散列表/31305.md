# 31305 - 简单一致散列期望代价与生日悖论

## 题目

设采用分离链接法的散列表共有 $m$ 个槽，当前已存有 $n$ 个互不相同的键，装载因子 $\alpha = n / m$。在**简单一致散列假设 (SUHA)** 下，每个键等概率独立地散列到 $\{0, 1, \dots, m - 1\}$ 中的任意槽。

- (a) 定义指示器随机变量 $X_{ij} = \mathbb{I}\{h(k_i) = h(k_j)\}$（$1 \le i \neq j \le n$）。利用期望的线性性质严格证明：
  1. 查找一个不在表中的键时，期望检查的链表结点数为 $\alpha$；
  2. 等概率随机查找表中已有的 $n$ 个键之一（假设新键总是插入链表头部且无重复插入），期望检查的链表结点数为：

     $$1 + \frac{n - 1}{2m} = 1 + \frac{\alpha}{2} - \frac{\alpha}{2n}$$

- (b) **生日悖论与冲突概率**：当 $m = 365$ 时，求插入 $n$ 个键完全不发生任何冲突的概率 $P(\text{无冲突})$ 的精确表达式；并编写一段简短的 C 程序计算出使冲突概率 $1 - P(\text{无冲突})$ 首次超过 $50\%$ 和首次超过 $99\%$ 的最小键数 $n$。

## 解析

### (a) SUHA 期望查找代价证明（CLRS 定理 11.1 与 11.2）

#### 1. 未命中查找 (Unsuccessful Search)

设待查目标键为 $k$，且 $k$ 不在表中。在 SUHA 假设下，$h(k)$ 等概率地取 $\{0, 1, \dots, m - 1\}$ 中的任一槽，因此 $h(k)$ 所在槽对应的链表长度即为需要检查的结点数。

定义指示器随机变量：

$$X_j = \mathbb{I}\{h(k_j) = h(k)\} \quad (j = 1, 2, \dots, n)$$

根据简单一致散列假设，每个已有键 $k_j$ 与新键 $k$ 散列到同一槽的概率均为：

$$\mathbb{P}(h(k_j) = h(k)) = \frac{1}{m}$$

所以其数学期望为 $\mathbb{E}[X_j] = 1/m$。链表总长度为随机变量 $N = \sum_{j=1}^n X_j$，由期望的线性性质：

$$\mathbb{E}[N] = \mathbb{E}\left[\sum_{j=1}^n X_j\right] = \sum_{j=1}^n \mathbb{E}[X_j] = \sum_{j=1}^n \frac{1}{m} = \frac{n}{m} = \alpha$$

因此未命中查找期望检查的结点数恰为 $\alpha$。

#### 2. 命中查找 (Successful Search)

设查询的键 $k$ 等概率地取自已存入的 $n$ 个键之一，每个键被查到的概率为 $1/n$。

设元素按照 $k_1, k_2, \dots, k_n$ 的次序依次插入表中。由于每次插入新键时均将其置于链表头部，所以在最终链表中，排在键 $k_i$ **之前**的元素必然是在 $k_i$ **之后**插入且与 $k_i$ 散列到同一槽的键。

因此，查找键 $k_i$ 时需要检查的结点数等于：自身（1 次）加上排在它前面的同义词个数：

$$C_i = 1 + \sum_{j=i+1}^n \mathbb{I}\{h(k_j) = h(k_i)\}$$

取条件期望：

$$\mathbb{E}[C_i] = 1 + \sum_{j=i+1}^n \mathbb{E}[\mathbb{I}\{h(k_j) = h(k_i)\}] = 1 + \sum_{j=i+1}^n \frac{1}{m} = 1 + \frac{n - i}{m}$$

由于每个键等概率被查，整体命中查找的期望结点检查数为：

$$\mathbb{E}[C] = \frac{1}{n} \sum_{i=1}^n \mathbb{E}[C_i] = \frac{1}{n} \sum_{i=1}^n \left(1 + \frac{n - i}{m}\right) = 1 + \frac{1}{n \cdot m} \sum_{i=1}^n (n - i)$$

其中 $\sum_{i=1}^n (n - i) = \sum_{t=0}^{n-1} t = \frac{n(n - 1)}{2}$。代入得：

$$\mathbb{E}[C] = 1 + \frac{n(n - 1)}{2 n m} = 1 + \frac{n - 1}{2m} = 1 + \frac{\alpha}{2} - \frac{\alpha}{2n}$$

证毕。

### (b) 生日悖论与冲突概率计算

设散列表容量为 $m = 365$。
第 1 个键可任意放置，不冲突概率为 $365/365$；
第 2 个键避开前 1 个槽的概率为 $(365 - 1)/365$；
依此类推，第 $n$ 个键不发生冲突的累乘概率为：

$$P(\text{无冲突}) = \prod_{i=0}^{n-1} \frac{m - i}{m} = \frac{m \cdot (m - 1) \dots (m - n + 1)}{m^n}$$

发生至少一次冲突的概率即为补集：

$$P(\text{冲突}) = 1 - P(\text{无冲突}) = 1 - \prod_{i=0}^{n-1} \left(1 - \frac{i}{m}\right)$$

通过近似公式 $1 - x \approx e^{-x}$ 可估算：

$$P(\text{无冲突}) \approx \exp\left(-\sum_{i=0}^{n-1} \frac{i}{m}\right) = \exp\left(-\frac{n(n - 1)}{2m}\right)$$

令 $1 - e^{-n^2 / (2m)} \ge 0.5 \implies n \approx \sqrt{2m \ln 2} \approx \sqrt{2 \times 365 \times 0.693} \approx 22.5$。

精确数值推导与 C 代码计算表明：
- 当 $n = 23$ 时，冲突概率首次超过 $50\%$（精确值约为 $50.73\%$）；
- 当 $n = 57$ 时，冲突概率首次超过 $99\%$（精确值约为 $99.01\%$）。

## 答案代码

```c
#include <assert.h>
#include <stdio.h>

int main(void) {
    const int m = 365;
    double p_no_collision = 1.0;
    int n_50 = 0;
    int n_99 = 0;

    for (int n = 1; n <= m; ++n) {
        p_no_collision *= (double)(m - n + 1) / (double)m;
        double p_collision = 1.0 - p_no_collision;

        if (p_collision >= 0.5 && n_50 == 0) {
            n_50 = n;
        }
        if (p_collision >= 0.99 && n_99 == 0) {
            n_99 = n;
            break;
        }
    }

    assert(n_50 == 23);
    assert(n_99 == 57);

    return 0;
}
```
