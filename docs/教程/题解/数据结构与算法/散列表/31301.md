# 31301 - 直接寻址表与字节频次统计

## 题目

利用长度为 $256$ 的直接寻址表（`size_t` 频次数组），在线性时间与常数辅助空间下实现以下两个字节与字符串统计函数：

```c
#include <stdbool.h>
#include <stddef.h>

size_t byte_first_unique_index(const unsigned char *data, size_t len);
bool str_is_anagram(const char *a, const char *b);
```

要求：

1. `byte_first_unique_index` 返回长度为 `len` 的字节序列 `data` 中**第一个恰出现一次**的字节下标；若不存在（或 `len == 0`、`data == NULL`），返回 `SIZE_MAX`。
2. `str_is_anagram` 判断两个以 `'\0'` 结尾的字符串是否互为字节重排（每个字节值的出现次数完全一致）；任一参数为 `NULL` 时返回 `false`。
3. 解释为什么在遍历 `const char *` 索引长度为 $256$ 的直接寻址数组时，必须先将元素转换为 `unsigned char` 再作为数组下标。

## 解析

直接寻址表将关键字集合直接作为槽下标。当关键字全域为一个字节（$0 \dots 255$）时，分配大小为 $256$ 的局部静态或自动存储期数组即可达到严格 $O(1)$ 的寻址效率，无需哈希计算与冲突消解。

1. **第一个唯一字节查找**：
   - 第一次遍历：统计每个字节在 `data` 中出现的绝对频次，记入 `size_t freq[256]` 中；
   - 第二次遍历：按原始顺序检查 `data[i]`，一旦发现 `freq[data[i]] == 1` 即为首个唯一出现位置，直接返回下标 `i`；若遍历结束仍未命中，返回 `SIZE_MAX`。时间复杂度为 $O(n)$，空间复杂度为 $O(1)$。

2. **异位词判定**：
   - 互为异位词的充分必要条件是两个字符串长度相同且每个字符值出现的次数完全一致。
   - 分配计数器数组 `ptrdiff_t diff[256] = {0}`。遍历第一个串时将对应字符频次递增，遍历第二个串时递减。若两串长度不同则提前返回 `false`；遍历完成后检查所有槽位是否全部为 0。

3. **符号性陷阱**：
   - C 语言标准规定 `char` 的符号性由实现定义（可以是有符号 `signed char` 或无符号 `unsigned char`）。在 x86 等常见平台上，`char` 默认为有符号数，当读入 ASCII 范围之外的扩展字节（如 UTF-8 多字节编码前缀 `0xC3`）时，会被解释为负数（例如 `-61`）。若直接用作数组下标，将导致严重的数组负下标越界访问。强制转换为 `unsigned char` 可确保值严格落入 $[0, 255]$ 范围内。

## 答案

```c
#include <assert.h>
#include <stdbool.h>
#include <stddef.h>
#include <stdint.h>
#include <string.h>

size_t byte_first_unique_index(const unsigned char *data, size_t len) {
    if (data == NULL || len == 0) {
        return SIZE_MAX;
    }

    size_t freq[256] = {0};
    for (size_t i = 0; i < len; ++i) {
        freq[data[i]]++;
    }

    for (size_t i = 0; i < len; ++i) {
        if (freq[data[i]] == 1) {
            return i;
        }
    }

    return SIZE_MAX;
}

bool str_is_anagram(const char *a, const char *b) {
    if (a == NULL || b == NULL) {
        return false;
    }

    size_t len_a = strlen(a);
    size_t len_b = strlen(b);
    if (len_a != len_b) {
        return false;
    }

    size_t count_a[256] = {0};
    size_t count_b[256] = {0};

    for (size_t i = 0; i < len_a; ++i) {
        count_a[(unsigned char)a[i]]++;
        count_b[(unsigned char)b[i]]++;
    }

    for (size_t i = 0; i < 256; ++i) {
        if (count_a[i] != count_b[i]) {
            return false;
        }
    }

    return true;
}

int main(void) {
    const unsigned char bytes1[] = {10, 20, 30, 20, 10, 40, 50};
    assert(byte_first_unique_index(bytes1, sizeof(bytes1)) == 2); // 30 第一次出现

    const unsigned char bytes2[] = {5, 5, 5};
    assert(byte_first_unique_index(bytes2, sizeof(bytes2)) == SIZE_MAX);
    assert(byte_first_unique_index(NULL, 10) == SIZE_MAX);
    assert(byte_first_unique_index(bytes1, 0) == SIZE_MAX);

    assert(str_is_anagram("anagram", "nagaram"));
    assert(str_is_anagram("rat", "tar"));
    assert(!str_is_anagram("rat", "car"));
    assert(!str_is_anagram("hello", "world"));
    assert(!str_is_anagram("a", "ab"));
    assert(!str_is_anagram(NULL, "a"));

    // 测试扩展字符（非 ASCII 范围）安全转换
    const char utf8_a[] = "\xC3\xA9t\xC3\xA9";
    const char utf8_b[] = "t\xC3\xA9\xC3\xA9";
    assert(str_is_anagram(utf8_a, utf8_b));

    return 0;
}
```

两算法时间复杂度均为 $O(n)$，辅助空间严格为 $O(|\Sigma|) = O(256) = O(1)$。
