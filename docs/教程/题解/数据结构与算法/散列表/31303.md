# 题解：31303

## 题目

实现并对比定宽整数散列中的 Fibonacci 乘法散列与 SplitMix64 可逆位混合器：

```c
#include <stdint.h>

uint64_t fibonacci_hash_u64(uint64_t key, unsigned bits);
uint64_t splitmix64_mix(uint64_t x);
uint64_t splitmix64_unmix(uint64_t y);
```

要求：

1. 说明当散列表容量 $m = 2^p$ 且输入键全部为 $16$ 的倍数（例如 16 字节对齐的堆对象地址转换成的整数）时，直接使用除法散列 `key & (m - 1)` 会造成怎样的桶分布退化。
2. `fibonacci_hash_u64` 使用黄金分割奇常数 `UINT64_C(0x9e3779b97f4a7c15)` 将 `key` 映射到高 `bits` 位（返回值范围为 $[0, 2^{\text{bits}} - 1]$）；当 `bits == 0` 或 `bits > 64` 时返回 `0`。
3. `splitmix64_mix` 实现正文中的三步右移异或与奇常数乘法混合；利用模 $2^{64}$ 下的乘法逆元（`0xbf58476d1ce4e5b9` 的模 $2^{64}$ 逆元为 `0x96de1b173f119089`，`0x94d049bb133111eb` 的模 $2^{64}$ 逆元为 `0x319642b2d24d8ec3`）以及右移异或的逆变换实现 `splitmix64_unmix`，使对任意 `uint64_t x` 恒有 `splitmix64_unmix(splitmix64_mix(x)) == x`。
4. 说明为什么 `splitmix64_mix` 的双射（可逆）性质能够保证任意两个不同的 64 位整数在截断取模之前绝不发生散列值碰撞。

## 解析

### 1. 2 的幂除法散列在对齐数据上的退化

当散列表大小为 $m = 2^p$ 时，除法散列通过位掩码 `key & (m - 1)` 取出二进制表示的最低 $p$ 位。若输入键全为 16 的倍数（二进制末尾 4 位恒为 0），则：
- `key & (m - 1)` 的最低 4 位永远是 0；
- 只有下标为 $0, 16, 32, \dots$ 的桶才可能被命中；
- 整个散列表中至少有 $\frac{15}{16} \approx 93.75\%$ 的桶永远处于空闲状态，所有元素被挤入仅有的 $m / 16$ 个桶中，导致冲突率暴增 16 倍，查找退化。

### 2. Fibonacci 乘法散列原理

乘法散列法利用无理数黄金分割比 $\phi = \frac{1 + \sqrt{5}}{2} \approx 1.6180339887...$。其倒数 $1/\phi \approx 0.6180339887...$，在 64 位定宽整数环上对应的奇数常数为：

$$C = \lfloor 2^{64} / \phi \rfloor = \text{0x9e3779b97f4a7c15}$$

由于 $C$ 是奇数，它与 $2^{64}$ 互素。任意输入 $k$ 乘以 $C$ 会引发低位向高位的充分进位扩散。乘积的高 $p$ 位（即 `(k * C) >> (64 - p)`）具有极佳的一致分布特性，即使输入以 16 为步长递增，高位依然剧烈变化。

### 3. 可逆位混合器与双射不变式

SplitMix64 的每一级操作均为模 $2^{64}$ 环上的双射：
1. **右移异或 $z = x \oplus (x \gg k)$ 的逆运算**：
   由于高 $k$ 位未受任何影响，高 $k$ 位必然保持原值。通过重复右移异或可以将高位的精确原值逐块向低位异或恢复：
   - 当 $k = 30$ 时：只需两次即可覆盖 64 位，`z ^ (z >> 30) ^ (z >> 60)`；
   - 当 $k = 27$ 时：`z ^ (z >> 27) ^ (z >> 54)`；
   - 当 $k = 31$ 时：`z ^ (z >> 31) ^ (z >> 62)`。
2. **乘以奇常数的逆运算**：
   在模 $2^{64}$ 环上，任何奇常数均存在唯一的乘法逆元（通过扩展欧几里得算法可求得）。

因为复合映射中每一步都是单射且定义域与值域大小均为 $2^{64}$，所以复合映射是严格的双射。由单射定义可知：

$$x_1 \neq x_2 \implies \text{splitmix64\_mix}(x_1) \neq \text{splitmix64\_mix}(x_2)$$

因此在最终截断到 $m$ 个桶之前，输入在 64 位散列值空间内绝无任何碰撞。

## 答案

```c
#include <assert.h>
#include <stdint.h>

uint64_t fibonacci_hash_u64(uint64_t key, unsigned bits) {
    if (bits == 0 || bits > 64) {
        return 0;
    }
    const uint64_t phi_constant = UINT64_C(0x9e3779b97f4a7c15);
    uint64_t prod = key * phi_constant;
    if (bits == 64) {
        return prod;
    }
    return prod >> (64 - bits);
}

uint64_t splitmix64_mix(uint64_t x) {
    x = (x ^ (x >> 30)) * UINT64_C(0xbf58476d1ce4e5b9);
    x = (x ^ (x >> 27)) * UINT64_C(0x94d049bb133111eb);
    return x ^ (x >> 31);
}

uint64_t splitmix64_unmix(uint64_t y) {
    // 1. 逆 y = z4 ^ (z4 >> 31)
    uint64_t z4 = y ^ (y >> 31) ^ (y >> 62);

    // 2. 逆 z4 = z3 * 0x94d049bb133111eb
    const uint64_t inv_c2 = UINT64_C(0x319642b2d24d8ec3);
    uint64_t z3 = z4 * inv_c2;

    // 3. 逆 z3 = z2 ^ (z2 >> 27)
    uint64_t z2 = z3 ^ (z3 >> 27) ^ (z3 >> 54);

    // 4. 逆 z2 = z1 * 0xbf58476d1ce4e5b9
    const uint64_t inv_c1 = UINT64_C(0x96de1b173f119089);
    uint64_t z1 = z2 * inv_c1;

    // 5. 逆 z1 = x ^ (x >> 30)
    uint64_t x = z1 ^ (z1 >> 30) ^ (z1 >> 60);
    return x;
}

int main(void) {
    // 1. 验证 Fibonacci 散列边界与散布
    assert(fibonacci_hash_u64(12345, 0) == 0);
    assert(fibonacci_hash_u64(12345, 65) == 0);
    uint64_t h4 = fibonacci_hash_u64(16, 4);
    assert(h4 < 16);

    // 验证以 16 为步长的输入在 Fibonacci 散列下高 4 位不同
    uint64_t a = fibonacci_hash_u64(16, 4);
    uint64_t b = fibonacci_hash_u64(32, 4);
    uint64_t c = fibonacci_hash_u64(48, 4);
    assert(a != b || b != c);

    // 2. 验证 SplitMix64 的双射可逆性
    const uint64_t test_cases[] = {
        0,
        1,
        42,
        UINT64_C(0x123456789abcdef0),
        UINT64_C(0xffffffffffffffff),
        UINT64_C(0xaaaaaaaaaaaaaaaa),
        UINT64_C(0x5555555555555555)
    };
    for (size_t i = 0; i < sizeof(test_cases) / sizeof(test_cases[0]); ++i) {
        uint64_t orig = test_cases[i];
        uint64_t mixed = splitmix64_mix(orig);
        uint64_t restored = splitmix64_unmix(mixed);
        assert(restored == orig);
    }

    return 0;
}
```
