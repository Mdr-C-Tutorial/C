# 题解：31302

## 题目

设散列表容量 $m = 11$，主散列函数为 $h_1(k) = k \bmod 11$。按顺序依次插入关键字序列：

$$10, \; 22, \; 31, \; 4, \; 15, \; 28, \; 17, \; 88, \; 59$$

请分别手工推演并给出以下四种冲突解决方式下的最终表状态：

- (a) **分离链接法**：每个桶为一根单向链表，新元素总是采用头插法插入链表头部，写出槽 $0 \dots 10$ 各自的链表序列以及最终装载因子 $\alpha$。
- (b) **线性探测**：探测函数为 $h(k, i) = (h_1(k) + i) \bmod 11$，写出每个键插入时的探测次数以及最终槽数组 `slots[0..10]` 的内容。
- (c) **二次探测**：探测函数为 $h(k, i) = (h_1(k) + i + 3i^2) \bmod 11$，写出每个键插入时的探测次数以及最终槽数组 `slots[0..10]` 的内容。
- (d) **双重散列**：探测函数为 $h(k, i) = (h_1(k) + i \cdot h_2(k)) \bmod 11$，其中辅助散列函数为 $h_2(k) = 1 + (k \bmod 10)$，写出每个键插入时的探测次数以及最终槽数组 `slots[0..10]` 的内容，并比较 (b)、(c)、(d) 三种开放寻址策略在本次插入过程中的总探测次数。

## 解析

首先计算各关键字的主散列值 $h_1(k) = k \bmod 11$：

- $10 \bmod 11 = 10$
- $22 \bmod 11 = 0$
- $31 \bmod 11 = 9$
- $4 \bmod 11 = 4$
- $15 \bmod 11 = 4$
- $28 \bmod 11 = 6$
- $17 \bmod 11 = 6$
- $88 \bmod 11 = 0$
- $59 \bmod 11 = 4$

---

### (a) 分离链接法 (Separate Chaining)

采用单向链表头插法，同义词直接插入对应槽的头部：
- 槽 0：依次插入 22、88 $\to$ 链表为 `88 -> 22`
- 槽 4：依次插入 4、15、59 $\to$ 链表为 `59 -> 15 -> 4`
- 槽 6：依次插入 28、17 $\to$ 链表为 `17 -> 28`
- 槽 9：插入 31 $\to$ 链表为 `31`
- 槽 10：插入 10 $\to$ 链表为 `10`
- 其余槽（1, 2, 3, 5, 7, 8）均为空。

最终元素个数 $n = 9$，槽数 $m = 11$，装载因子：

$$\alpha = \frac{n}{m} = \frac{9}{11} \approx 0.818$$

---

### (b) 线性探测 (Linear Probing)

探测序列 $h(k, i) = (h_1(k) + i) \bmod 11$：
1. **10**：$h_1=10$，槽 10 为空，放入槽 10（探测 1 次）。
2. **22**：$h_1=0$，槽 0 为空，放入槽 0（探测 1 次）。
3. **31**：$h_1=9$，槽 9 为空，放入槽 9（探测 1 次）。
4. **4**：$h_1=4$，槽 4 为空，放入槽 4（探测 1 次）。
5. **15**：$h_1=4$，槽 4 冲突；$i=1$ 探测槽 5 为空，放入槽 5（探测 2 次）。
6. **28**：$h_1=6$，槽 6 为空，放入槽 6（探测 1 次）。
7. **17**：$h_1=6$，槽 6 冲突；$i=1$ 探测槽 7 为空，放入槽 7（探测 2 次）。
8. **88**：$h_1=0$，槽 0 冲突；$i=1$ 探测槽 1 为空，放入槽 1（探测 2 次）。
9. **59**：$h_1=4$，依次检查槽 4, 5, 6, 7（均被占用）；$i=4$ 探测槽 8 为空，放入槽 8（探测 5 次）。

总探测次数为 $1 + 1 + 1 + 1 + 2 + 1 + 2 + 2 + 5 = 16$ 次。

最终数组：
`[22, 88, EMPTY, EMPTY, 4, 15, 28, 17, 59, 31, 10]`

---

### (c) 二次探测 (Quadratic Probing)

探测序列 $h(k, i) = (h_1(k) + i + 3i^2) \bmod 11$：
1. **10**：$i=0 \implies$ 槽 10（1 次）。
2. **22**：$i=0 \implies$ 槽 0（1 次）。
3. **31**：$i=0 \implies$ 槽 9（1 次）。
4. **4**：$i=0 \implies$ 槽 4（1 次）。
5. **15**：$i=0 \implies$ 槽 4 冲突；$i=1 \implies (4 + 1 + 3) \bmod 11 = 8$（2 次）。
6. **28**：$i=0 \implies$ 槽 6（1 次）。
7. **17**：$i=0 \implies$ 槽 6 冲突；$i=1 \implies (6 + 1 + 3) \bmod 11 = 10$ 冲突；$i=2 \implies (6 + 2 + 12) \bmod 11 = 9$ 冲突；$i=3 \implies (6 + 3 + 27) \bmod 11 = 3$ 为空（4 次）。
8. **88**：$h_1=0$。依次探测 $i=0(0), i=1(4), i=2(3), i=3(8), i=4(8), i=5(3), i=6(4), i=7(0)$，直至 $i=8 \implies (0 + 8 + 3 \times 64) \bmod 11 = 200 \bmod 11 = 2$ 为空，放入槽 2（探测 9 次）。
9. **59**：$h_1=4$。$i=0(4)$ 冲突；$i=1(8)$ 冲突；$i=2 \implies (4 + 2 + 12) \bmod 11 = 7$ 为空，放入槽 7（探测 3 次）。

总探测次数为 $1 + 1 + 1 + 1 + 2 + 1 + 4 + 9 + 3 = 23$ 次。

最终数组：
`[22, EMPTY, 88, 17, 4, EMPTY, 28, 59, 15, 31, 10]`

---

### (d) 双重散列 (Double Hashing)

步长公式 $h_2(k) = 1 + (k \bmod 10)$：
- $k=10 \implies h_2=1$
- $k=22 \implies h_2=3$
- $k=31 \implies h_2=2$
- $k=4 \implies h_2=5$
- $k=15 \implies h_2=6$
- $k=28 \implies h_2=9$
- $k=17 \implies h_2=8$
- $k=88 \implies h_2=9$
- $k=59 \implies h_2=10$

探测过程：
1. **10**：槽 10（1 次）。
2. **22**：槽 0（1 次）。
3. **31**：槽 9（1 次）。
4. **4**：槽 4（1 次）。
5. **15**：$h_1=4, h_2=6$。$i=0(4)$ 冲突；$i=1 \implies (4 + 6) \bmod 11 = 10$ 冲突；$i=2 \implies (4 + 12) \bmod 11 = 5$ 为空，放入槽 5（3 次）。
6. **28**：槽 6（1 次）。
7. **17**：$h_1=6, h_2=8$。$i=0(6)$ 冲突；$i=1 \implies (6 + 8) \bmod 11 = 3$ 为空，放入槽 3（2 次）。
8. **88**：$h_1=0, h_2=9$。$i=0(0)$ 冲突；$i=1(9)$ 冲突；$i=2 \implies (0 + 18) \bmod 11 = 7$ 为空，放入槽 7（3 次）。
9. **59**：$h_1=4, h_2=10$。$i=0(4)$ 冲突；$i=1 \implies (4 + 10) \bmod 11 = 3$ 冲突；$i=2 \implies (4 + 20) \bmod 11 = 2$ 为空，放入槽 2（3 次）。

总探测次数为 $1 + 1 + 1 + 1 + 3 + 1 + 2 + 3 + 3 = 16$ 次。

最终数组：
`[22, EMPTY, 59, 17, 4, 15, 28, 88, EMPTY, 31, 10]`

---

### 对比结论

| 冲突解决策略 | 总探测次数 | 空槽分布 | 特点与聚集分析 |
| :--- | :---: | :--- | :--- |
| **线性探测** | 16 次 | 槽 2, 3 为空 | 存在明显的一次聚集，相邻槽块连结导致后续 59 经历了 5 次连续探测 |
| **二次探测** | 23 次 | 槽 1, 5 为空 | 由于选择的常数与模数在部分项上产生环绕，88 经历了较多回绕探测 |
| **双重散列** | 16 次 | 槽 1, 8 为空 | 元素散布最均匀，无聚集连片，单键最大探测次数仅为 3 次 |

#include <assert.h>
#include <stdbool.h>
#include <stdio.h>

int main(void) {
    const int keys[9] = {10, 22, 31, 4, 15, 28, 17, 88, 59};
    const int m = 11;

    // 1. 验证线性探测
    int lin[11];
    for (int i = 0; i < m; ++i) lin[i] = -1;
    int lin_probes = 0;
    for (int k = 0; k < 9; ++k) {
        int key = keys[k];
        int h0 = key % m;
        for (int i = 0; ; ++i) {
            lin_probes++;
            int pos = (h0 + i) % m;
            if (lin[pos] == -1) {
                lin[pos] = key;
                break;
            }
        }
    }
    assert(lin_probes == 16);
    assert(lin[0] == 22 && lin[1] == 88 && lin[4] == 4 && lin[5] == 15);
    assert(lin[6] == 28 && lin[7] == 17 && lin[8] == 59 && lin[9] == 31 && lin[10] == 10);

    // 2. 验证双重散列
    int dbl[11];
    for (int i = 0; i < m; ++i) dbl[i] = -1;
    int dbl_probes = 0;
    for (int k = 0; k < 9; ++k) {
        int key = keys[k];
        int h0 = key % m;
        int step = 1 + (key % 10);
        for (int i = 0; ; ++i) {
            dbl_probes++;
            int pos = (h0 + i * step) % m;
            if (dbl[pos] == -1) {
                dbl[pos] = key;
                break;
            }
        }
    }
    assert(dbl_probes == 16);
    assert(dbl[0] == 22 && dbl[2] == 59 && dbl[3] == 17 && dbl[4] == 4);
    assert(dbl[5] == 15 && dbl[6] == 28 && dbl[7] == 88 && dbl[9] == 31 && dbl[10] == 10);

    return 0;
}
