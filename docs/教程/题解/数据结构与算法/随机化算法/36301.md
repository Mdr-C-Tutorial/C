# 36301：无偏 Fisher–Yates 原地洗牌

## 题目

实现 Fisher–Yates 洗牌：

```c
#include <stdbool.h>
#include <stddef.h>
#include <stdint.h>

typedef uint64_t (*RandomBits)(void *context);

bool shuffle_i64(
    int64_t *items,
    size_t count,
    RandomBits random_bits,
    void *context
);
```

要求：

1. 原地生成所有排列的等概率分布；`count <= 1` 时不要求随机源非空。
2. 不得直接用随机数对上界取余而引入模偏差，应使用拒绝采样或等价方法。
3. 参数无效时返回 `false`；时间复杂度为 $O(n)$，额外空间复杂度为 $O(1)$。

## 解析

1. **消除模偏差（拒绝采样）**：当需要从 $[0, \text{bound})$ 中均匀抽取整数时，若 $2^{64}$ 不是 `bound` 的整数倍，直接计算 `random_bits(context) % bound` 会使小于 $R = 2^{64} \bmod \text{bound}$ 的余数比其余余数多出一个原像。利用无符号算术恒等式 `threshold = (UINT64_C(0) - bound) % bound` 即可在不溢出的情况下精确算出余数 $R$；循环采样直至随机值 `r >= threshold`，此时落入长度为 `bound` 整数倍的区间 $[R, 2^{64})$，再返回 `r % bound` 即可保证严格均匀。
2. **Fisher–Yates 倒序交换**：令下标 `i` 从 `count - 1` 递减至 `1`，每一步从闭区间 `[0, i]`（即上界 `bound = i + 1`）中等概率抽取下标 `j` 并交换 `items[i]` 与 `items[j]`。由乘法原理，生成的每种排列概率均为 $\frac{1}{n} \times \frac{1}{n-1} \times \cdots \times \frac{1}{1} = \frac{1}{n!}$。
3. **边界处理**：当 `count <= 1` 时，唯一排列已就绪，无需调用 `random_bits`，因此不要求 `random_bits` 非空（但 `count == 1` 时 `items` 仍不得为 `NULL`）。

## 答案

```c
#include <stdbool.h>
#include <stddef.h>
#include <stdint.h>

typedef uint64_t (*RandomBits)(void *context);

static uint64_t uniform_index(
    uint64_t bound,
    RandomBits random_bits,
    void *context
) {
    uint64_t threshold = (UINT64_C(0) - bound) % bound;
    for (;;) {
        uint64_t value = random_bits(context);
        if (value >= threshold) {
            return value % bound;
        }
    }
}

static void swap_i64(int64_t *left, int64_t *right) {
    int64_t temporary = *left;
    *left = *right;
    *right = temporary;
}

bool shuffle_i64(
    int64_t *items,
    size_t count,
    RandomBits random_bits,
    void *context
) {
    if (count > 0 && items == NULL) {
        return false;
    }
    if (count <= 1) {
        return true;
    }
    if (random_bits == NULL) {
        return false;
    }
    for (size_t i = count - 1; i > 0; --i) {
        size_t j = (size_t)uniform_index(
            (uint64_t)i + UINT64_C(1),
            random_bits,
            context
        );
        swap_i64(&items[i], &items[j]);
    }
    return true;
}
```

每次拒绝采样成功概率大于 $1/2$，单步期望采样次数为 $O(1)$，因此整体期望时间复杂度为 $O(n)$，原地交换的额外空间复杂度为 $O(1)$。
