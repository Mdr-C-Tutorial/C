# 36301 - 无偏 Fisher-Yates 原地洗牌算法与离散均匀分布证明

## 题目描述

给定一个包含 `count` 个 64 位有符号整数的数组 `items`，以及一个高质量的随机位源回调函数 `random_bits`。

使用 **Fisher-Yates 原地洗牌算法**，对数组进行随机置换，消除模偏差（Modulo Bias），使得全部 $n!$ 种可能排列出现的概率**严格且无偏地等于 $\frac{1}{n!}$**。

函数签名如下：

```c
#include <stdbool.h>
#include <stddef.h>
#include <stdint.h>

typedef uint64_t (*RandomBits)(void *context);

bool shuffle_i64(
    int64_t *items,
    size_t count,
    RandomBits random_bits,
    void *context
);
```

要求：
1. 参数无效时返回 `false`。当 `count <= 1` 时，唯一排列自然就绪，返回 `true`（无需调用随机位源）。
2. **严禁使用朴素取模 `rand() % bound`**：必须采用**拒绝采样法（Rejection Sampling）**消除模偏差。
3. 洗牌必须原地执行，额外辅助空间复杂度为严格的 $O(1)$。
4. 严格证明该算法能产出真正的离散均匀分布。

## 解题思路

1. **模偏差（Modulo Bias）的产生与消除**：
   当我们需要从闭区间 $[0, \text{bound} - 1]$ 中等概率抽取随机整数时，若简单的通过 `random_bits() % bound` 计算：
   由于 $2^{64}$ 通常不是 `bound` 的整数倍，前 $R = 2^{64} \bmod \text{bound}$ 个余数会比后面的余数多出一个原像（抽屉原理），从而破坏了均匀性。
   **消除方法（拒绝采样）**：
   利用无符号算术恒等式：
   $$threshold = (UINT64\_C(0) - bound) \% bound$$
   该式在无符号溢出环绕下精确计算出了 $2^{64} \bmod \text{bound}$。
   循环采样直到生成的随机数 $r \ge threshold$。此时 $r$ 必定落在一个长度恰为 `bound` 整数倍的区间内，然后再执行 $r \% bound$ 便能保证绝对数学上的无偏均匀。

2. **Fisher-Yates 洗牌的不变式**：
   指针 $i$ 从 `count - 1` 递减到 1：
   - 在闭区间 $[0, i]$ 中等概率抽取一个下标 $j$（上界为 `bound = i + 1`）；
   - 交换 `items[i]` 与 `items[j]`。

3. **数学证明（为什么每种排列概率严格为 $\frac{1}{n!}$）**：
   根据乘法原理，考察任意一个固定的排列 $\langle x_1, x_2, \dots, x_n \rangle$：
   - 在第一轮（确定位置 $n - 1$ 的元素），从 $n$ 个候选元素中抽中 $x_n$ 的概率为 $\frac{1}{n}$；
   - 在第二轮（确定位置 $n - 2$ 的元素），从剩余 $n - 1$ 个元素中抽中 $x_{n-1}$ 的概率为 $\frac{1}{n - 1}$；
   - $\dots$
   - 在第 $n - 1$ 轮，从最后 2 个元素中抽中对应元素的概率为 $\frac{1}{2}$；
   - 最后一轮概率为 1。
   所有步的联合独立概率为：
   $$P(\text{排列}) = \frac{1}{n} \times \frac{1}{n - 1} \times \dots \times \frac{1}{2} \times 1 = \frac{1}{n!}$$
   证毕。

## C 语言实现

```c
#include <assert.h>
#include <stdbool.h>
#include <stddef.h>
#include <stdint.h>

typedef uint64_t (*RandomBits)(void *context);

// 拒绝采样消除模偏差
static uint64_t uniform_index(
    uint64_t bound,
    RandomBits random_bits,
    void *context
) {
    uint64_t threshold = (UINT64_C(0) - bound) % bound;
    for (;;) {
        uint64_t val = random_bits(context);
        if (val >= threshold) {
            return val % bound;
        }
    }
}

static void swap_i64(int64_t *a, int64_t *b) {
    int64_t tmp = *a;
    *a = *b;
    *b = tmp;
}

bool shuffle_i64(
    int64_t *items,
    size_t count,
    RandomBits random_bits,
    void *context
) {
    if (count > 0 && items == NULL) {
        return false;
    }
    if (count <= 1) {
        return true; // 0 或 1 元素无需洗牌
    }
    if (random_bits == NULL) {
        return false;
    }

    for (size_t i = count - 1; i > 0; --i) {
        uint64_t bound = (uint64_t)i + 1;
        uint64_t j = uniform_index(bound, random_bits, context);
        swap_i64(&items[i], &items[j]);
    }

    return true;
}

// 伪随机生成器 (PCG/LCG) 用于自包含测试
static uint64_t test_lcg(void *ctx) {
    uint64_t *state = (uint64_t *)ctx;
    *state = (*state * 6364136223846793005ULL) + 1442695040888963407ULL;
    return *state;
}

int main(void) {
    uint64_t seed = 123456789ULL;

    // 参数校验
    assert(!shuffle_i64(NULL, 5, test_lcg, &seed));
    assert(!shuffle_i64((int64_t[]){1, 2}, 2, NULL, &seed));

    // 0 与 1 元素边界
    assert(shuffle_i64(NULL, 0, NULL, NULL));
    int64_t one[1] = {42};
    assert(shuffle_i64(one, 1, NULL, NULL) && one[0] == 42);

    // 标准洗牌测试: 数组包含 5 个元素
    int64_t arr[5] = {1, 2, 3, 4, 5};
    assert(shuffle_i64(arr, 5, test_lcg, &seed));

    // 校验洗牌后仍然是原元素的置换 (元素守恒)
    bool seen[6] = {false};
    for (size_t i = 0; i < 5; ++i) {
        assert(arr[i] >= 1 && arr[i] <= 5);
        assert(!seen[arr[i]]);
        seen[arr[i]] = true;
    }

    return 0;
}
```

## 复杂度分析

- **时间复杂度**：期望 $O(n)$。外层循环执行 $n - 1$ 次。在拒绝采样中，单次循环被拒绝的概率小于 $\frac{\text{bound}}{2^{64}} \le \frac{n}{2^{64}} \approx 0$，因此期望采样次数几乎恒为 1。
- **空间复杂度**：严格 $O(1)$。所有交换均为原地操作，仅占用常数个调用栈局部整型对象。

## 延伸思考 / 模式总结

错误洗牌（如经典错误循环 `for (i=0; i<n; ++i) swap(i, rand() % n)`）会产生 $n^n$ 种等可能的执行路径。因为 $n!$ 几乎从来无法整除 $n^n$（当 $n > 2$ 时），必然产生结构性偏差。Fisher-Yates 算法以严格的倒序收缩窗口，保证搜索路径总数恰好等于 $n!$。
