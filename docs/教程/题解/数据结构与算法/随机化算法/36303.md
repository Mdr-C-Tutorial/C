# 36303 - 随机化三路快速选择（Randomized Quickselect）

## 题目描述

给定一个包含 `count` 个 64 位有符号整数的数组 `items`。

使用**结合无偏随机枢轴与三路原地分区（Dutch National Flag）的快速选择算法**，找出数组中按升序排序后排名为第 `order` 小的元素（`order` 从 0 开始索引），并将结果写入 `out_value`。

函数签名如下：

```c
#include <stdbool.h>
#include <stddef.h>
#include <stdint.h>

typedef uint64_t (*RandomBits)(void *context);

bool randomized_select_i64(
    int64_t *items,
    size_t count,
    size_t order,
    RandomBits random_bits,
    void *context,
    int64_t *out_value
);
```

要求：
1. 枢轴元素必须通过拒绝采样在当前候选区间内等概率无偏随机选取。
2. 采用**荷兰国旗三路分区**，将区间划分为“严格小于”、“等于”与“严格大于”三段，防止大量重复元素退化为 $O(n^2)$。
3. 必须通过**单侧尾递归消除（迭代循环更新左右边界）**，确保递归/循环调用栈深度为 $O(1)$。
4. 期望时间复杂度为 $O(n)$。

## 解题思路

1. **三路原地分区（Dutch National Flag）**：
   在当前区间 $[left, right]$ 内，先随机选出一个枢轴元素 $pivot$。
   维护三个游标 $lt, i, gt$，维持以下循环不变式：
   - $items[left \dots lt - 1] < pivot$；
   - $items[lt \dots i - 1] == pivot$；
   - $items[i \dots gt]$ 尚未探索；
   - $items[gt + 1 \dots right] > pivot$。
   
   当游标 $i > gt$ 时分区完成，所有等于 $pivot$ 的元素全部集中在连续区间 $[lt, gt]$ 中。

2. **单侧转移与目标区间定位**：
   比较目标排名 `order` 与三路区间 $[lt, gt]$ 的位置关系：
   - 若 $order < lt$：目标必在严格小于段，更新 $right = lt - 1$；
   - 若 $order > gt$：目标必在严格大于段，更新 $left = gt + 1$；
   - 若 $lt \le order \le gt$：**目标已被精确命中**！直接输出 $pivot$ 并退出。

3. **为何三路分区能免疫退化**：
   若输入包含大量全相同元素，传统二路分区可能极度不平衡。而三路分区直接将所有重复元素整体剔除，单次迭代即可将问题规模缩减至 0，彻底化解退化风险。

## C 语言实现

```c
#include <assert.h>
#include <stdbool.h>
#include <stddef.h>
#include <stdint.h>

typedef uint64_t (*RandomBits)(void *context);

static uint64_t uniform_index(
    uint64_t bound,
    RandomBits random_bits,
    void *context
) {
    uint64_t threshold = (UINT64_C(0) - bound) % bound;
    for (;;) {
        uint64_t val = random_bits(context);
        if (val >= threshold) {
            return val % bound;
        }
    }
}

static void swap_i64(int64_t *a, int64_t *b) {
    int64_t tmp = *a;
    *a = *b;
    *b = tmp;
}

bool randomized_select_i64(
    int64_t *items,
    size_t count,
    size_t order,
    RandomBits random_bits,
    void *context,
    int64_t *out_value
) {
    if (out_value == NULL || items == NULL ||
        count == 0 || order >= count || random_bits == NULL) {
        return false;
    }

    size_t left = 0;
    size_t right = count - 1;

    // 迭代式单侧尾递归消除
    while (left <= right) {
        if (left == right) {
            *out_value = items[left];
            return true;
        }

        // 无偏随机选取枢轴
        uint64_t span = (uint64_t)(right - left + 1);
        size_t pivot_idx = left + (size_t)uniform_index(span, random_bits, context);
        int64_t pivot = items[pivot_idx];

        // 荷兰国旗三路分区
        size_t lt = left;
        size_t i = left;
        size_t gt = right;

        while (i <= gt) {
            if (items[i] < pivot) {
                swap_i64(&items[lt], &items[i]);
                lt++;
                i++;
            } else if (items[i] > pivot) {
                swap_i64(&items[i], &items[gt]);
                if (gt == 0) break;
                gt--;
            } else {
                i++;
            }
        }

        if (order < lt) {
            if (lt == 0) break;
            right = lt - 1;
        } else if (order > gt) {
            left = gt + 1;
        } else {
            // order 落在 [lt, gt] 内
            *out_value = pivot;
            return true;
        }
    }

    return false;
}

static uint64_t test_prng(void *ctx) {
    uint64_t *s = (uint64_t *)ctx;
    *s = (*s * 6364136223846793005ULL) + 1442695040888963407ULL;
    return *s;
}

int main(void) {
    uint64_t seed = 42ULL;
    int64_t val = 0;

    // 参数校验
    assert(!randomized_select_i64(NULL, 5, 2, test_prng, &seed, &val));
    assert(!randomized_select_i64((int64_t[]){1}, 1, 2, test_prng, &seed, &val)); // 越界

    // 单元素测试
    int64_t a1[1] = {100};
    assert(randomized_select_i64(a1, 1, 0, test_prng, &seed, &val) && val == 100);

    // 标准测试用例: [7, 10, 4, 3, 20, 15]
    // 排序后: [3, 4, 7, 10, 15, 20]
    // order 0: 3
    // order 2: 7
    // order 5: 20
    int64_t a2[6] = {7, 10, 4, 3, 20, 15};
    assert(randomized_select_i64(a2, 6, 0, test_prng, &seed, &val) && val == 3);
    assert(randomized_select_i64(a2, 6, 2, test_prng, &seed, &val) && val == 7);
    assert(randomized_select_i64(a2, 6, 5, test_prng, &seed, &val) && val == 20);

    // 含有大量重复元素测试: [5, 5, 5, 1, 5, 9, 5]
    // 排序后: [1, 5, 5, 5, 5, 5, 9]
    // order 3: 5
    int64_t a3[7] = {5, 5, 5, 1, 5, 9, 5};
    assert(randomized_select_i64(a3, 7, 3, test_prng, &seed, &val) && val == 5);

    return 0;
}
```

## 复杂度分析

- **时间复杂度**：期望 $O(n)$。每次分区将问题规模期望减半，递归几何级数和为 $T(n) = n + n/2 + n/4 + \dots = O(n)$。在三路分区加持下，即使全部元素相等也只需一次划分。
- **空间复杂度**：严格 $O(1)$。通过 `while` 循环修改边界实现单侧迭代，完全无需调用栈与辅助数组。

## 延伸思考 / 模式总结

Quickselect 将 Quicksort 的“分而治之双侧递归”优化为了“单侧追踪”。随机化枢轴破坏了输入数据的初始对抗排列，使得任何输入的最坏情况在概率上几乎不可能发生。
