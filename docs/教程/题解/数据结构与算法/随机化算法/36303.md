# 36303：随机化三路快速排序

## 题目

实现随机化快速排序：

```c
#include <stdbool.h>
#include <stddef.h>
#include <stdint.h>

typedef uint64_t (*RandomBits)(void *context);

bool randomized_quicksort_i64(
    int64_t *items,
    size_t count,
    RandomBits random_bits,
    void *context
);
```

要求：

1. 使用随机枢轴和三路分区，支持重复元素和 `int64_t` 的全部取值。
2. 原地排序为非递减顺序；参数无效时不得修改数组。
3. 平均时间复杂度为 $O(n\log n)$；优先递归较小分区、循环处理较大分区，使额外调用栈空间保持为 $O(\log n)$。
4. 说明随机化如何降低固定输入导致的最坏分区风险，但不能把平均复杂度当成最坏保证。

## 解析

1. **随机化如何化解固定输入的最坏情况**：在确定性快速排序中，枢轴选取规则是固定的，因此总存在针对该规则构造的特定输入序列（如已排序序列或特定置换）使每次划分都产生 $0$ 与 $n - 1$ 的极端失衡。引入无偏随机枢轴后，枢轴位置由算法内部的随机源决定，不再依赖输入数据的排列顺序；对**任何固定输入**，每次选到位于中间一半区域枢轴的概率恒不低于 $1/2$，从而将期望时间复杂度稳定在 $O(n \log n)$。但需要注意：拉斯维加斯随机化改变的是运行时间的概率分布，若随机数序列极其不幸地每次都抽中极值，最坏时间复杂度仍为 $O(n^2)$，因此不能把期望复杂度等同于确定性的最坏情况上界。
2. **三路分区与全值域安全比较**：直接用 `<` 与 `>` 比较 `int64_t` 元素，不涉及任何减法比较，因此对 `INT64_MIN` 至 `INT64_MAX` 的全部取值完全免于有符号减法溢出；相等元素集中归入 `[lt, gt]`，不再参与后续递归。
3. **调用栈深度限制为 $O(\log n)$**：每轮三路分区结束后，比较左子区间长度 `left_len = lt - left` 与右子区间长度 `right_len = right - gt`：总是**只对较短的子区间发起递归调用**，而将较长的子区间通过更新 `left` 或 `right` 留在当前函数的 `while` 循环中迭代处理。因为每次递归进入的子问题规模至多是原区间的一半，即便每次分区都极度失衡，调用栈深度也绝不会超过 $\lfloor \log_2 n \rfloor$。

## 答案

```c
#include <stdbool.h>
#include <stddef.h>
#include <stdint.h>

typedef uint64_t (*RandomBits)(void *context);

static uint64_t uniform_index(
    uint64_t bound,
    RandomBits random_bits,
    void *context
) {
    uint64_t threshold = (UINT64_C(0) - bound) % bound;
    for (;;) {
        uint64_t value = random_bits(context);
        if (value >= threshold) {
            return value % bound;
        }
    }
}

static void swap_i64(int64_t *left, int64_t *right) {
    int64_t temporary = *left;
    *left = *right;
    *right = temporary;
}

static void quicksort_range(
    int64_t *items,
    size_t left,
    size_t right,
    RandomBits random_bits,
    void *context
) {
    while (left < right) {
        uint64_t span = (uint64_t)(right - left) + UINT64_C(1);
        size_t pivot_index = left + (size_t)uniform_index(
            span, random_bits, context
        );
        int64_t pivot = items[pivot_index];

        size_t lt = left;
        size_t i = left;
        size_t gt = right;
        while (i <= gt) {
            if (items[i] < pivot) {
                swap_i64(&items[lt], &items[i]);
                ++lt;
                ++i;
            } else if (items[i] > pivot) {
                swap_i64(&items[i], &items[gt]);
                --gt;
            } else {
                ++i;
            }
        }

        size_t left_count = lt - left;
        size_t right_count = right - gt;
        if (left_count < right_count) {
            if (left_count > 1) {
                quicksort_range(
                    items, left, lt - 1, random_bits, context
                );
            }
            if (right_count <= 1) {
                break;
            }
            left = gt + 1;
        } else {
            if (right_count > 1) {
                quicksort_range(
                    items, gt + 1, right, random_bits, context
                );
            }
            if (left_count <= 1) {
                break;
            }
            right = lt - 1;
        }
    }
}

bool randomized_quicksort_i64(
    int64_t *items,
    size_t count,
    RandomBits random_bits,
    void *context
) {
    if ((count > 0 && items == NULL) || random_bits == NULL) {
        return false;
    }
    if (count <= 1) {
        return true;
    }
    quicksort_range(items, 0, count - 1, random_bits, context);
    return true;
}
```

对任意输入的期望时间复杂度为 $O(n \log n)$（含大量重复元素时可达 $O(n)$），最坏时间复杂度为 $O(n^2)$；由于每次仅对长度不超过一半的较小子区间递归，最坏情况下的额外调用栈空间复杂度严格限制在 $O(\log n)$。
