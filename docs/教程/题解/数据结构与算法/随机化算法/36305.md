# 36305 - Monte Carlo 与 Las Vegas 算法辨析及素数测试（Miller-Rabin）

## 题目描述

1. **辨析**：深入比较 **Monte Carlo（蒙特卡罗）** 与 **Las Vegas（拉斯维加斯）** 两大随机化算法流派的核心特征与设计权衡。
2. **编程实现**：实现 64 位无符号整数的 **Miller-Rabin 随机化素数测试算法**（标准的 Monte Carlo 算法），判断一个整数 $n$ 是否为素数。

函数签名如下：

```c
#include <stdbool.h>
#include <stddef.h>
#include <stdint.h>

typedef uint64_t (*RandomBits)(void *context);

bool miller_rabin_is_prime(
    uint64_t n,
    size_t iterations,
    RandomBits random_bits,
    void *context,
    bool *out_is_prime
);
```

要求：
1. 参数无效时返回 `false`。
2. 小于 2 的数不是素数；2 和 3 为素数；大于 2 的偶数不是素数。
3. 必须通过快速模幂与二次探测定理（$x^2 \equiv 1 \pmod n$ 仅有解 $x \equiv \pm 1 \pmod n$）筛选强伪素数。
4. 乘法模运算必须避免 64 位整型溢出（采用 `unsigned __int128` 或模乘辅助计算）。
5. 详细阐述多次独立测试如何将 Monte Carlo 错误率压缩至 $4^{-k}$。

## 解题思路

1. **Monte Carlo 与 Las Vegas 的本质对比**：
   - **Las Vegas 算法（如随机化快排、随机化快速选择）**：
     - **结果正确性**：绝对确定（100% 正确，永不出错）；
     - **运行时间**：是一个随机对象（期望性能优异，极小概率运行时间较长）；
   - **Monte Carlo 算法（如 Miller-Rabin 素数测试）**：
     - **运行时间**：绝对确定（严格受上界多项式时间约束）；
     - **结果正确性**：具有单向的极小出错概率（例如：若判定为合数则 100% 必定为合数；若判定为素数，则有至多 $4^{-k}$ 的极小概率误判合数为素数）。

2. **Miller-Rabin 数学定理（二次探测与费马小定理）**：
   对于奇整数 $n > 2$，可唯一分解为 $n - 1 = 2^s \cdot d$（其中 $d$ 为奇数）。
   随机选取基数 $a \in [2, n - 2]$：
   - 计算 $x = a^d \bmod n$；
   - 若 $x == 1$ 或 $x == n - 1$，通过本轮测试；
   - 否则，将 $x$ 连续执行平方操作至多 $s - 1$ 次（$x = x^2 \bmod n$）：
     若在中途某一步出现 $x == n - 1$，说明满足二次探测定理（$-1$ 的平方为 $1$），通过本轮测试；
   - 若平方 $s - 1$ 次后仍未出现 $n - 1$，则费马小定理必不满足，**$n$ 必为合数（100% 确信）**，基数 $a$ 成为 $n$ 为合数的铁证。

3. **独立重复实验抑制单向错误率**：
   Rabin 定理证明：对于任意合数 $n$，任选一个基数 $a$，使其能通过单轮 Miller-Rabin 测试的概率至多为 $1/4$。
   若独立重复执行 $k$ 轮测试，合数全部蒙混过关的概率将衰减至 $(1/4)^k = 4^{-k}$。
   当 $k = 40$ 时，错误率低于 $4^{-40} \approx 10^{-24}$，在物理世界中比宇宙射线翻转内存比特的概率还要低数个数量级。

## C 语言实现

```c
#include <assert.h>
#include <stdbool.h>
#include <stddef.h>
#include <stdint.h>

typedef uint64_t (*RandomBits)(void *context);

static inline uint64_t mul_mod_u64(uint64_t a, uint64_t b, uint64_t mod) {
#if defined(__SIZEOF_INT128__)
    return (uint64_t)(((unsigned __int128)a * (unsigned __int128)b) % mod);
#else
    uint64_t res = 0;
    a %= mod;
    while (b > 0) {
        if (b & 1) res = (res + a) % mod;
        a = (a + a) % mod;
        b >>= 1;
    }
    return res;
#endif
}

static uint64_t pow_mod_u64(uint64_t base, uint64_t exp, uint64_t mod) {
    uint64_t res = 1;
    base %= mod;
    while (exp > 0) {
        if (exp & 1) {
            res = mul_mod_u64(res, base, mod);
        }
        base = mul_mod_u64(base, base, mod);
        exp >>= 1;
    }
    return res;
}

static uint64_t uniform_range(
    uint64_t min_val,
    uint64_t max_val,
    RandomBits random_bits,
    void *context
) {
    uint64_t span = max_val - min_val + 1;
    uint64_t threshold = (UINT64_C(0) - span) % span;
    for (;;) {
        uint64_t val = random_bits(context);
        if (val >= threshold) {
            return min_val + (val % span);
        }
    }
}

bool miller_rabin_is_prime(
    uint64_t n,
    size_t iterations,
    RandomBits random_bits,
    void *context,
    bool *out_is_prime
) {
    if (out_is_prime == NULL) {
        return false;
    }

    if (n < 2) {
        *out_is_prime = false;
        return true;
    }
    if (n == 2 || n == 3) {
        *out_is_prime = true;
        return true;
    }
    if ((n & 1) == 0) {
        *out_is_prime = false;
        return true;
    }
    if (random_bits == NULL && iterations > 0) {
        return false;
    }

    // 分解 n - 1 = 2^s * d
    uint64_t d = n - 1;
    size_t s = 0;
    while ((d & 1) == 0) {
        d >>= 1;
        s++;
    }

    for (size_t iter = 0; iter < iterations; ++iter) {
        uint64_t a = uniform_range(2, n - 2, random_bits, context);
        uint64_t x = pow_mod_u64(a, d, n);

        if (x == 1 || x == n - 1) {
            continue; // 通过本轮
        }

        bool passed = false;
        for (size_t r = 1; r < s; ++r) {
            x = mul_mod_u64(x, x, n);
            if (x == n - 1) {
                passed = true;
                break;
            }
        }

        if (!passed) {
            *out_is_prime = false; // 100% 确定为合数
            return true;
        }
    }

    *out_is_prime = true; // 极大概率为素数
    return true;
}

static uint64_t test_prng(void *ctx) {
    uint64_t *val = (uint64_t *)ctx;
    *val = (*val * 6364136223846793005ULL) + 1442695040888963407ULL;
    return *val;
}

int main(void) {
    uint64_t seed = 777ULL;
    bool is_prime = false;

    // 参数校验
    assert(!miller_rabin_is_prime(5, 5, test_prng, &seed, NULL));

    // 小素数与合数测试
    assert(miller_rabin_is_prime(0, 10, test_prng, &seed, &is_prime) && !is_prime);
    assert(miller_rabin_is_prime(1, 10, test_prng, &seed, &is_prime) && !is_prime);
    assert(miller_rabin_is_prime(2, 10, test_prng, &seed, &is_prime) && is_prime);
    assert(miller_rabin_is_prime(3, 10, test_prng, &seed, &is_prime) && is_prime);
    assert(miller_rabin_is_prime(4, 10, test_prng, &seed, &is_prime) && !is_prime);
    assert(miller_rabin_is_prime(17, 10, test_prng, &seed, &is_prime) && is_prime);
    assert(miller_rabin_is_prime(100, 10, test_prng, &seed, &is_prime) && !is_prime);

    // 强伪素数测试 (卡迈克尔数 Carmichael Numbers, 能骗过费马测试但骗不过 Miller-Rabin)
    // 561 = 3 * 11 * 17
    assert(miller_rabin_is_prime(561, 20, test_prng, &seed, &is_prime) && !is_prime);
    // 1729 = 7 * 13 * 19
    assert(miller_rabin_is_prime(1729, 20, test_prng, &seed, &is_prime) && !is_prime);

    // 大素数测试: 1000000007 (10^9 + 7)
    assert(miller_rabin_is_prime(1000000007ULL, 20, test_prng, &seed, &is_prime) && is_prime);

    return 0;
}
```

## 复杂度分析

- **时间复杂度**：$O(k \log^3 n)$。执行 $k$ 轮测试，每轮进行一次模幂运算（包含 $O(\log n)$ 次模乘）。
- **空间复杂度**：严格 $O(1)$。仅占用常数个调用栈寄存器和局部整型对象。

## 延伸思考 / 模式总结

Monte Carlo 算法以极高明的哲学处理了“不可行问题的工程解”：当确定性算法代价高昂（如 AKS 素性测试 $O(\log^6 n)$）时，接受一个比物理宇宙毁灭概率还低的单向误差率，从而换取极快的多项式时间执行效率。
