# 36302：随机化三路快速选择

## 题目

在长度为 `count` 的 `int64_t` 数组 `items` 中，使用无偏随机枢轴与三路分区查找第 `order` 小的元素（`order` 从 `0` 开始计数），并将结果写入 `out_value`。

## 解析

1. **三路原地分区（Dutch National Flag）**：在当前候选闭区间 `[left, right]` 内，先用无偏拒绝采样等概率选出枢轴元素 `pivot`。维护三个游标 `lt`、`i`、`gt`，满足循环不变式：
   - `items[left..lt - 1]` 严格小于 `pivot`；
   - `items[lt..i - 1]` 等于 `pivot`；
   - `items[i..gt]` 尚未划分；
   - `items[gt + 1..right]` 严格大于 `pivot`。
2. **单侧尾递归消除**：当 `i > gt` 时分区完成，整个相等段落入 `[lt, gt]`。比较目标排名 `order` 与 `[lt, gt]` 的关系：
   - 若 `order < lt`，目标必在左子区间，令 `right = lt - 1`；
   - 若 `order > gt`，目标必在右子区间，令 `left = gt + 1`；
   - 若 `lt <= order && order <= gt`，则 `order` 恰好落在相等段内，直接输出 `pivot` 并返回。
   三路分区保证即使输入包含大量重复元素，所有等于 `pivot` 的元素也会在一次划分中被集中排除或直接命中，不会退化为 $O(n^2)$。

## 答案

```c
#include <stdbool.h>
#include <stddef.h>
#include <stdint.h>

typedef uint64_t (*RandomBits)(void *context);

static uint64_t uniform_index(
    uint64_t bound,
    RandomBits random_bits,
    void *context
) {
    uint64_t threshold = (UINT64_C(0) - bound) % bound;
    for (;;) {
        uint64_t value = random_bits(context);
        if (value >= threshold) {
            return value % bound;
        }
    }
}

static void swap_i64(int64_t *left, int64_t *right) {
    int64_t temporary = *left;
    *left = *right;
    *right = temporary;
}

bool randomized_select_i64(
    int64_t *items,
    size_t count,
    size_t order,
    RandomBits random_bits,
    void *context,
    int64_t *out_value
) {
    if (items == NULL || out_value == NULL ||
        random_bits == NULL || order >= count) {
        return false;
    }
    size_t left = 0;
    size_t right = count - 1;
    while (left < right) {
        uint64_t span = (uint64_t)(right - left) + UINT64_C(1);
        size_t pivot_index = left + (size_t)uniform_index(
            span, random_bits, context
        );
        int64_t pivot = items[pivot_index];

        size_t lt = left;
        size_t i = left;
        size_t gt = right;
        while (i <= gt) {
            if (items[i] < pivot) {
                swap_i64(&items[lt], &items[i]);
                ++lt;
                ++i;
            } else if (items[i] > pivot) {
                swap_i64(&items[i], &items[gt]);
                --gt;
            } else {
                ++i;
            }
        }

        if (order < lt) {
            right = lt - 1;
        } else if (order > gt) {
            left = gt + 1;
        } else {
            *out_value = pivot;
            return true;
        }
    }
    *out_value = items[left];
    return true;
}
```

每次随机选取枢轴使候选区间长度按常数比例期望缩减，对任意输入的期望时间复杂度均为 $O(n)$（最坏时间复杂度为 $O(n^2)$）；使用循环代替单侧递归后，额外空间复杂度严格为 $O(1)$。
