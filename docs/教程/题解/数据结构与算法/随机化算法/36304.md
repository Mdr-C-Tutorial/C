# 36304 - 随机化快速排序（Randomized Quicksort）期望运行时间证明

## 题目描述

实现**结合无偏随机枢轴、荷兰国旗三路原地分区与短子区间优先递归**的随机化快速排序算法，将 `int64_t` 数组按非递减顺序原地排好序。

函数签名如下：

```c
#include <stdbool.h>
#include <stddef.h>
#include <stdint.h>

typedef uint64_t (*RandomBits)(void *context);

bool randomized_quicksort_i64(
    int64_t *items,
    size_t count,
    RandomBits random_bits,
    void *context
);
```

要求：
1. 参数无效时返回 `false`；`count <= 1` 时直接返回 `true`。
2. 枢轴选取必须无偏均匀。
3. 采用**较短子区间优先发起递归、较长子区间通过迭代留在当前函数中处理**的尾递归优化，将调用栈最大深度严格限制为 $O(\log n)$。
4. 使用指示器随机对象严格推导并证明算法的期望比较次数为 $2n \ln n + O(n) = O(n \log n)$。

## 解题思路

1. **期望运行时间证明（基于指示器随机对象）**：
   设输入数组排好序后的元素为 $z_1 < z_2 < \dots < z_n$。
   定义指示器随机对象 $X_{ij}$（$1 \le i < j \le n$）：
   $$X_{ij} = \mathbb{I}\{\text{元素 } z_i \text{ 与 } z_j \text{ 在排序过程中发生了比较}\}$$
   算法的总比较次数为 $X = \sum_{i=1}^{n-1} \sum_{j=i+1}^n X_{ij}$。
   
   **分析两元素比较的充要条件**：
   考察集合 $Z_{ij} = \{z_i, z_{i+1}, \dots, z_j\}$。在算法递归将这些元素划入不同子问题之前，$z_i$ 与 $z_j$ 能够发生比较**当且仅当**在集合 $Z_{ij}$ 中选出的第一个枢轴元素恰好是 $z_i$ 或 $z_j$：
   - 若选中的第一个枢轴是中间的某个 $z_k$（$i < k < j$），则 $z_i$ 和 $z_j$ 会立刻被分入左右两个互斥的子区间，未来绝不可能再发生比较；
   - 在随机枢轴假设下，$Z_{ij}$ 中的每个元素被选为第一个枢轴的概率均等，总共有 $j - i + 1$ 个元素。
   因此比较发生的概率为：
   $$P(z_i \text{ 与 } z_j \text{ 发生比较}) = \frac{2}{j - i + 1}$$
   根据期望的线性性质：
   $$\mathbb{E}[X] = \sum_{i=1}^{n-1} \sum_{j=i+1}^n \frac{2}{j - i + 1} = \sum_{i=1}^{n-1} \sum_{k=1}^{n-i} \frac{2}{k + 1} < 2 \sum_{i=1}^n \sum_{k=1}^n \frac{1}{k} = 2n \ln n + O(n)$$
   证毕。期望时间复杂度严格为 $O(n \log n)$。

2. **调用栈深度限制为 $O(\log n)$**：
   三路分区完成后，得到左区间 $[left, lt - 1]$ 与右区间 $[gt + 1, right]$。
   比较两侧长度：
   总是**只对较短的子区间递归调用自身**，而将较长的子区间通过更新当前函数的边界参数留在 `while` 循环中继续迭代。
   因为每次递归进去的子问题规模至多是原区间的一半，所以即使每次划分极度失衡，递归调用栈深度也**绝不会超过 $\lfloor \log_2 n \rfloor$**。

## C 语言实现

```c
#include <assert.h>
#include <stdbool.h>
#include <stddef.h>
#include <stdint.h>

typedef uint64_t (*RandomBits)(void *context);

static uint64_t uniform_index(
    uint64_t bound,
    RandomBits random_bits,
    void *context
) {
    uint64_t threshold = (UINT64_C(0) - bound) % bound;
    for (;;) {
        uint64_t val = random_bits(context);
        if (val >= threshold) {
            return val % bound;
        }
    }
}

static void swap_i64(int64_t *a, int64_t *b) {
    int64_t tmp = *a;
    *a = *b;
    *b = tmp;
}

static void quicksort_range(
    int64_t *items,
    size_t left,
    size_t right,
    RandomBits random_bits,
    void *context
) {
    while (left < right) {
        uint64_t span = (uint64_t)(right - left + 1);
        size_t p_idx = left + (size_t)uniform_index(span, random_bits, context);
        int64_t pivot = items[p_idx];

        // 荷兰国旗三路分区
        size_t lt = left;
        size_t i = left;
        size_t gt = right;

        while (i <= gt) {
            if (items[i] < pivot) {
                swap_i64(&items[lt], &items[i]);
                lt++;
                i++;
            } else if (items[i] > pivot) {
                swap_i64(&items[i], &items[gt]);
                if (gt == 0) break;
                gt--;
            } else {
                i++;
            }
        }

        // 短子区间优先递归，长子区间迭代
        size_t left_len = (lt > left) ? (lt - left) : 0;
        size_t right_len = (right > gt) ? (right - gt) : 0;

        if (left_len < right_len) {
            if (left_len > 1) {
                quicksort_range(items, left, lt - 1, random_bits, context);
            }
            left = gt + 1; // 较长右区间在循环中处理
        } else {
            if (right_len > 1) {
                quicksort_range(items, gt + 1, right, random_bits, context);
            }
            if (lt == 0) break;
            right = lt - 1; // 较长左区间在循环中处理
        }
    }
}

bool randomized_quicksort_i64(
    int64_t *items,
    size_t count,
    RandomBits random_bits,
    void *context
) {
    if (count > 0 && items == NULL) {
        return false;
    }
    if (count <= 1) {
        return true;
    }
    if (random_bits == NULL) {
        return false;
    }

    quicksort_range(items, 0, count - 1, random_bits, context);
    return true;
}

static uint64_t test_prng(void *ctx) {
    uint64_t *s = (uint64_t *)ctx;
    *s = (*s * 6364136223846793005ULL) + 1442695040888963407ULL;
    return *s;
}

int main(void) {
    uint64_t seed = 2026ULL;

    // 参数校验
    assert(!randomized_quicksort_i64(NULL, 5, test_prng, &seed));

    // 单元素与空数组
    assert(randomized_quicksort_i64(NULL, 0, test_prng, &seed));
    int64_t a1[1] = {42};
    assert(randomized_quicksort_i64(a1, 1, test_prng, &seed) && a1[0] == 42);

    // 标准乱序数组测试 (含负数、极值与重复值)
    int64_t a2[10] = {5, -3, 8, 2, 5, -3, 0, 9, 2, -10};
    assert(randomized_quicksort_i64(a2, 10, test_prng, &seed));

    // 校验非递减单调性
    for (size_t i = 1; i < 10; ++i) {
        assert(a2[i - 1] <= a2[i]);
    }

    // 逆序输入测试
    int64_t a3[5] = {5, 4, 3, 2, 1};
    assert(randomized_quicksort_i64(a3, 5, test_prng, &seed));
    for (size_t i = 1; i < 5; ++i) {
        assert(a3[i - 1] <= a3[i]);
    }

    return 0;
}
```

## 复杂度分析

- **时间复杂度**：期望严格为 $O(n \log n)$。随机枢轴从根本上瓦解了针对固定枢轴策略的对抗性坏输入。最坏情况（极罕见的连续选中极值）为 $O(n^2)$。
- **空间复杂度**：严格限制在 $O(\log n)$。短子区间优先递归确保了递归深度对数上界，杜绝了单侧极度倾斜导致栈溢出。

## 延伸思考 / 模式总结

拉斯维加斯（Las Vegas）算法的核心魅力在于：输出结果永远 100% 正确无误，而随机性仅用于打破结构性的最坏性能死角。配合小区间递归优化，打造了工业界无懈可击的高性能就地排序引擎。
