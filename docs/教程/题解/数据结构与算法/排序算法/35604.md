# 35604 - 三向切分快速排序（Dijkstra 荷兰国旗三路划分）

## 题目描述

针对包含大量重复键的数据集，实现 Dijkstra 三向切分快速排序：

```c
#include <stddef.h>
#include <stdint.h>

void quick_sort_3way(int64_t *arr, size_t count);
```

要求：

1. 每次选取切分基准 $pivot$，将当前子数组划分为严格小于区、严格等于区和严格大于区；
2. 递归时仅对小于区与大于区继续递归，对等于区完全跳过；
3. 形式化证明：当数组中仅有常数个不同键值时，三向切分快速排序的时间复杂度直接优化为线性阶 $\Theta(n)$；
4. 编写包含极端全等数据、两值交替数据、随机数据的测试断言。

## 解题思路

### 1. 经典快速排序的“全等退化”困境

在处理含有大量重复元素的序列时（例如只有 0 和 1 的海量数据），传统两路划分无论将等于枢轴的元素全部分入左侧还是右侧，都会导致划分极度不平衡，令递归树深度退化为 $n$，时间复杂度恶化至 $O(n^2)$。

### 2. Dijkstra 荷兰国旗（Dutch National Flag）三向切分

Edsger Dijkstra 提出了三路划分算法。在闭区间 $[left, right]$ 中选取中点元素为枢轴 $pivot$，维护三个指针：
- `lt`：小于区的右边界；
- `gt`：大于区的左边界；
- `i`：当前扫描指针。

**三向切分循环不变式**：在扫描过程中，区间被严格划分为四段：
1. $[left, lt - 1]$：严格小于 $pivot$ 的元素；
2. $[lt, i - 1]$：严格等于 $pivot$ 的元素；
3. $[i, gt]$：尚未扫描的未知元素；
4. $[gt + 1, right]$：严格大于 $pivot$ 的元素。

- **状态转移**：
  - 若 $\text{arr}[i] < pivot$：交换 $\text{arr}[lt]$ 与 $\text{arr}[i]$，并令 $lt \leftarrow lt + 1, i \leftarrow i + 1$；
  - 若 $\text{arr}[i] > pivot$：交换 $\text{arr}[i]$ 与 $\text{arr}[gt]$，并令 $gt \leftarrow gt - 1$（此时新换到 $i$ 处的元素尚未检验，因此 $i$ 保持不变）；
  - 若 $\text{arr}[i] == pivot$：直接令 $i \leftarrow i + 1$。
- **递归优化**：
  当 $i > gt$ 时划分结束，区间 $[lt, gt]$ 中所有的元素已经全部归位（最终有序位置），后续递归**仅需处理 $[left, lt - 1]$ 与 $[gt + 1, right]$**！

### 3. 常数种不同键值下的线性时间证明

若数组中只包含 $k$ 种不同的键值：
第一轮三向划分后，至少有一种键值的全部实例被集中在 $[lt, gt]$ 并被永久移出递归。
递归树的深度至多为 $k$ 层。每一层的所有子数组大小总和不超过 $n$。
因此总时间复杂度为：

$$T(n) \le k \cdot O(n) = O(k \cdot n)$$

当不同键值数 $k = O(1)$ 为常数时，三向切分快速排序的时间复杂度为严格的 $\Theta(n)$，性能等同于非比较型的桶排序。

## C 语言实现

```c
#include <assert.h>
#include <stddef.h>
#include <stdint.h>
#include <stdio.h>

static void swap_i64(int64_t *a, int64_t *b) {
    int64_t tmp = *a;
    *a = *b;
    *b = tmp;
}

static void quick_sort_3way_internal(int64_t *a, size_t left, size_t right) {
    if (left >= right) {
        return;
    }

    /* 选取中点为枢轴 */
    int64_t pivot = a[left + (right - left) / 2];

    size_t lt = left;
    size_t i = left;
    size_t gt = right;

    while (i <= gt) {
        if (a[i] < pivot) {
            swap_i64(&a[lt++], &a[i++]);
        } else if (a[i] > pivot) {
            swap_i64(&a[i], &a[gt--]);
        } else {
            i++;
        }
    }

    /* 仅对严格小于区和严格大于区继续递归 */
    if (lt > left) {
        quick_sort_3way_internal(a, left, lt - 1);
    }
    if (gt < right) {
        quick_sort_3way_internal(a, gt + 1, right);
    }
}

void quick_sort_3way(int64_t *arr, size_t count) {
    if (arr == NULL || count <= 1) {
        return;
    }
    quick_sort_3way_internal(arr, 0, count - 1);
}

int main(void) {
    /* 1. 大量重复相等元素测试 */
    int64_t a1[] = {2, 1, 2, 0, 1, 2, 0, 0, 1, 2};
    size_t n1 = sizeof(a1) / sizeof(a1[0]);
    quick_sort_3way(a1, n1);
    for (size_t i = 1; i < n1; ++i) {
        assert(a1[i - 1] <= a1[i]);
    }

    /* 2. 极端全等元素测试：必须瞬间单轮收敛 */
    int64_t a2[] = {5, 5, 5, 5, 5, 5, 5};
    quick_sort_3way(a2, 7);
    for (size_t i = 0; i < 7; ++i) {
        assert(a2[i] == 5);
    }

    /* 3. 一般随机数据测试 */
    int64_t a3[] = {64, -25, 12, 22, -11, 90};
    quick_sort_3way(a3, 6);
    for (size_t i = 1; i < 6; ++i) {
        assert(a3[i - 1] <= a3[i]);
    }

    /* 4. 空数组与单元素边界 */
    quick_sort_3way(NULL, 0);
    int64_t single[] = {42};
    quick_sort_3way(single, 1);
    assert(single[0] == 42);

    printf("All quick_sort_3way tests passed successfully.\n");
    return 0;
}
```

## 复杂度分析

- **时间复杂度**：
  - 常规数据：平均 $\Theta(n \log n)$；
  - 常数种不同键值数据：严格 $\Theta(n)$；
  - 极端全等数据：单次三路划分即排布完毕，仅需 $\Theta(n)$。
- **空间复杂度**：平均 $O(\log n)$（递归调用栈开销）。

## 延伸思考 / 模式总结

三向切分是 Robert Sedgewick 将其发扬光大的快排利器，它不仅完美解决了重复键的退化问题，更是**三向单词查找树（Ternary Search Trie, TST）**与**三向字符串快速排序**的核心基石。
