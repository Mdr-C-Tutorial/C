# 35602：希尔排序增量序列与复杂度下界探究

## 题目

探究希尔排序。第 _3.5.6._ 问**查阅资料**即可，第 _7._ 问是截至目前计算机科学界的**未解**难题。

(1) 希尔排序通过一系列递减的增量（例如，`h = {..., 13, 4, 1}`）对数组进行多轮“h-排序”。请从概念上解释，为什么这种“分组预排序”的策略，通常会比直接进行一次完整的插入排序（即只有增量为 1）更有效率？

(2) 考虑希尔本人提出的原始增量序列 `h = {..., n/4, n/2, 1}`（其中 n 为 2 的幂）。请分析并证明，在使用此序列时，希尔排序的**最坏情况时间复杂度为 Θ(n²)**。

(3) **Hibbard 序列**是形如 `2^k - 1` 的序列 (`{..., 15, 7, 3, 1}`)。证明：它的时间复杂度为 $O(n^{\frac{3}{2}})$。

(4) **Knuth 序列**是形如 `(3^k - 1) / 2` 的序列 (`{..., 40, 13, 4, 1}`)。证明：它的时间复杂度为 $O(n^{\frac{3}{2}})$。

(5) **Hibbard 序列**和 **Knuth 序列**的时间复杂度相同。哪个更具优越性？

(6) **Sedgewick 序列**是形如 `4^k + 3*2^(k-1) + 1` 的序列 (`{..., 109, 41, 19, 5, 1}`)。证明：它的时间复杂度为 $O(n^{\frac{4}{3}})$。

(7) **最好的增量序列**是什么？希尔排序的**确切的时间复杂度下界**是什么？

## 解析

希尔排序的时间复杂度分析与组合数学及加性数论（特别是 Frobenius 硬币问题）密切相关。理解第 (3)、(4)、(6) 问的关键，在于掌握两个核心引理：

1. **有序性保持定理（Sorting Preservation Lemma）**：如果一个数组已经是 $g$-有序的（即对任意下标 $i$ 有 $A[i] \le A[i+g]$），那么再对其进行一次 $h$-排序后，**它依然保持 $g$-有序**（此时数组同时是 $g$-有序和 $h$-有序的）。
2. **Frobenius 硬币问题与上界引理**：若 $\gcd(g, h) = 1$，则不能表示为非负整数线性组合 $a g + b h\ (a, b \in \mathbb{N})$ 的最大整数（即 Frobenius 数）为：
   $$F(g, h) = g h - g - h = (g - 1)(h - 1) - 1$$
   这意味着：如果数组已经同时是 $g$-有序和 $h$-有序的，那么对于任意大于 $F(g, h)$ 的跨度 $\Delta \ge (g - 1)(h - 1)$，由于 $\Delta$ 必可写成 $a g + b h$，根据传递性必有 $A[i] \le A[i + \Delta]$。因此，在后续进行增量为 $d$ 的插入排序时，每个元素向左寻找插入位置所需跨越的逆序元素个数最多不超过 $\frac{(g - 1)(h - 1)}{d} = O\left(\frac{g h}{d}\right)$！

## 答案

### (1) 为什么分组预排序比直接插入排序更高效？

1. **消除远距离逆序对的效率差异**：直接插入排序（增量 $h = 1$）每次交换或移动相邻元素，只能将数组的总逆序对数量减少 $1$。因为长度为 $n$ 的随机数组平均有 $\Theta(n^2)$ 个逆序对（最坏有 $\frac{n(n-1)}{2}$ 个），直接插入排序必须执行 $\Theta(n^2)$ 次移动。而在希尔排序前期，使用较大的增量 $h$ 进行 $h$-排序时，元素一次移动的跨度为 $h$，**单次元素交换最多可以一次性消除 $2h - 1$ 个逆序对**，使小元素迅速大步跳向数组前端、大元素迅速跳向后端。
2. **$g$-有序与 $h$-有序的叠加效应**：根据有序性保持定理，后续较小增量 $h$ 的排序**不会破坏**此前较大增量 $g$ 已经建立的 $g$-有序性。随着多轮增量的累积，数组的全局无序度急剧下降，到最后一轮 $h = 1$ 的直接插入排序时，每个元素距离其最终正确位置的偏移量已经极小（接近有序），插入排序在接近有序序列上仅需接近线性的时间即可完成收尾。

---

### (2) 希尔原始序列 $h = \{n/2, n/4, \dots, 2, 1\}$ 的最坏复杂度 $\Theta(n^2)$ 证明

设 $n = 2^p$ 为 $2$ 的幂。此时增量序列为 $h_k = 2^k\ (k = p-1, p-2, \dots, 1, 0)$。

1. **上界 $O(n^2)$**：对于每个增量 $h$，数组被分为 $h$ 个长度为 $n/h$ 的独立子序列，每个子序列做插入排序最坏耗时 $O((n/h)^2)$，一轮 $h$-排序总耗时为 $h \cdot O((n/h)^2) = O(n^2 / h)$。对所有增量求和：
   $$\sum_{k=0}^{p-1} O\left(\frac{n^2}{2^k}\right) = O(n^2) \sum_{k=0}^{p-1} \frac{1}{2^k} < 2 \cdot O(n^2) = O(n^2)$$
2. **下界 $\Omega(n^2)$（最坏输入构造）**：
   注意到除最后一轮 $h_0 = 1$ 外，**前面所有增量 $h_k = 2^k\ (k \ge 1)$ 全都是偶数**！这意味着在 $h = 1$ 之前的所有轮次中，**奇数下标位置的元素只与奇数下标位置的元素比较和交换，偶数下标位置的元素只与偶数下标位置的元素比较和交换**，奇偶两组位置之间没有任何数据流动。
   构造如下长度为 $n$ 的输入数组 $A[0 \dots n-1]$：
   - 将最小的 $n / 2$ 个数 $\{1, 2, \dots, n/2\}$ 全部放在**奇数下标** $A[1], A[3], \dots, A[n-1]$ 上；
   - 将最大的 $n / 2$ 个数 $\{n/2 + 1, n/2 + 2, \dots, n\}$ 全部放在**偶数下标** $A[0], A[2], \dots, A[n-2]$ 上。
   在完成 $h = n/2, n/4, \dots, 2$ 的所有轮次后，偶数下标依次存放升序的 $\{n/2 + 1, \dots, n\}$，奇数下标依次存放升序的 $\{1, \dots, n/2\}$，即在进入最后一轮 $h = 1$ 之前，数组状态为：
   $$A = \left[\frac{n}{2} + 1,\ 1,\ \frac{n}{2} + 2,\ 2,\ \frac{n}{2} + 3,\ 3,\ \dots,\ n,\ \frac{n}{2}\right]$$
   此时考察最后一轮 $h = 1$ 的插入排序：对于第 $i$ 个奇数下标位置 $2i - 1\ (i = 1, 2, \dots, n/2)$ 上的小元素 $i$，在它左侧共有 $i$ 个大于它的偶数下标元素 $\left\{\frac{n}{2} + 1, \frac{n}{2} + 2, \dots, \frac{n}{2} + i\right\}$，因此将元素 $i$ 插入正确位置必须向左移动 $i$ 次。最后一轮的总移动次数为：
   $$\sum_{i=1}^{n/2} i = \frac{(n/2)(n/2 + 1)}{2} = \frac{n^2}{8} + \frac{n}{4} = \Omega(n^2)$$
3. **结论**：结合上界 $O(n^2)$ 与下界 $\Omega(n^2)$，希尔原始增量序列的最坏情况时间复杂度为 $\Theta(n^2)$。

### (3) Hibbard 序列 $h_k = 2^k - 1$ 的 $O(n^{3/2})$ 时间复杂度证明

Hibbard 序列为 $h_k = 2^k - 1\ (1, 3, 7, 15, \dots)$。其关键代数性质是**相邻两项互素**：
因为 $h_{k+1} = 2^{k+1} - 1 = 2(2^k - 1) + 1 = 2h_k + 1$，由欧几里得算法立得：

$$\gcd(h_{k+1}, h_k) = \gcd(2h_k + 1, h_k) = \gcd(1, h_k) = 1$$

现在用两种互补方式界定第 $k$ 轮（增量为 $h_k$）的运行时间：
1. **对较大增量（纯子表规模上界）**：
   增量为 $h_k$ 时，共有 $h_k$ 个子序列，每个子序列长度为 $O(n / h_k)$，直接做插入排序的总操作数不超过：
   $$T_k \le h_k \cdot O\left(\left(\frac{n}{h_k}\right)^2\right) = O\left(\frac{n^2}{h_k}\right)$$
2. **对较小增量（利用 Frobenius 硬币上界）**：
   在执行 $h_k$-排序之前，数组已经完成了 $h_{k+1}$-排序和 $h_{k+2}$-排序，且 $\gcd(h_{k+1}, h_{k+2}) = 1$。根据解析中的 Frobenius 引理，数组中任何距离大于等于 $(h_{k+1} - 1)(h_{k+2} - 1)$ 的元素对都已经有序。由于 $h_{k+1} \approx 2 h_k$、$h_{k+2} \approx 4 h_k$，在 $h_k$-排序中，每个元素向左比较和移动的次数至多为：
   $$\frac{(h_{k+1} - 1)(h_{k+2} - 1)}{h_k} + 1 = O\left(\frac{h_k \cdot h_k}{h_k}\right) = O(h_k)$$
   因此，对全部 $n$ 个元素完成 $h_k$-排序的总耗时不超过：
   $$T_k = O(n \cdot h_k)$$

**分段求和**：以阈值 $n^{1/2}$ 为分界点将增量分为两部分：
- 对于所有 $h_k \le n^{1/2}$ 的轮次，采用上界 $O(n h_k)$。由于 $h_k = 2^k - 1$ 按公比 $2$ 呈几何级数增长，这部分之和受限于最大项：
  $$\sum_{h_k \le n^{1/2}} O(n h_k) = O\left(n \sum_{2^k \le n^{1/2}} 2^k\right) = O(n \cdot n^{1/2}) = O(n^{3/2})$$
- 对于所有 $h_k > n^{1/2}$ 的轮次，采用上界 $O(n^2 / h_k)$。由于 $1 / h_k$ 按公比 $1/2$ 递减，这部分之和同样受限于首项：
  $$\sum_{h_k > n^{1/2}} O\left(\frac{n^2}{h_k}\right) = O\left(n^2 \sum_{2^k > n^{1/2}} \frac{1}{2^k}\right) = O\left(\frac{n^2}{n^{1/2}}\right) = O(n^{3/2})$$

两部分相加，总最坏时间复杂度为 $O(n^{3/2})$。

### (4) Knuth 序列 $h_k = (3^k - 1) / 2$ 的 $O(n^{3/2})$ 时间复杂度证明

Knuth 序列满足递推式 $h_{k+1} = 3h_k + 1\ (1, 4, 13, 40, \dots)$。
首先验证相邻两项互素：

$$\gcd(h_{k+1}, h_k) = \gcd(3h_k + 1, h_k) = \gcd(1, h_k) = 1$$

与第 (3) 问完全同理，对于第 $k$ 轮（增量为 $h_k$）：
1. 直接按子序列长度平方求和，耗时为 $O(n^2 / h_k)$；
2. 利用前两轮已完成的 $h_{k+1}$-有序和 $h_{k+2}$-有序性（且 $\gcd(h_{k+1}, h_{k+2}) = 1$，$h_{k+1} \approx 3h_k$，$h_{k+2} \approx 9h_k$），由 Frobenius 引理知每个元素在 $h_k$-排序中最多移动：
   $$\frac{(h_{k+1} - 1)(h_{k+2} - 1)}{h_k} = O\left(\frac{3h_k \cdot 9h_k}{h_k}\right) = O(h_k)$$
   故整轮耗时为 $O(n h_k)$。

再次以 $n^{1/2}$ 为分界点对几何级数 $h_k \approx \frac{1}{2} 3^k$ 分段求和：
- 当 $h_k \le n^{1/2}$ 时，$\sum_{h_k \le n^{1/2}} O(n h_k) = O(n \cdot n^{1/2}) = O(n^{3/2})$；
- 当 $h_k > n^{1/2}$ 时，$\sum_{h_k > n^{1/2}} O(n^2 / h_k) = O(n^2 / n^{1/2}) = O(n^{3/2})$。

因此 Knuth 序列的最坏情况时间复杂度同样为 $O(n^{3/2})$。

---

### (5) Hibbard 序列与 Knuth 序列哪个更具优越性？

虽然两者的最坏渐近上界同为 $O(n^{3/2})$，但在实际应用和综合性能上各有侧重，通常认为 **Knuth 序列在实用中更具优越性**（而 Hibbard 在最坏上界常数因子上略小），具体对比如下：

1. **排序趟数与扫描开销**：Knuth 序列的公比为 $3$，所需趟数约为 $\log_3 n \approx 0.63 \lg n$，比 Hibbard 序列（公比为 $2$，趟数约为 $\lg n$）**少约 $37\%$ 的扫描轮次**。由于每一轮都需要遍历整个数组，减少趟数显著降低了外层循环与缓存读取开销。
2. **动态递推计算便利性**：Knuth 序列在程序中可以直接按 `h = 3 * h + 1` 生成、按 `h = h / 3` 回退，无需预先存储数组；Hibbard 序列可通过位运算生成，也很简便。
3. **平均情况表现**：大量实验与平均情况分析表明，公比在 $2.2 \sim 3$ 之间的增量序列在随机输入上的平均比较次数少于公比为 $2$ 的序列，因此 Knuth 序列在工程教材（如 Sedgewick 的《Algorithms》早期版本）中被广泛推荐为简单计算型增量的首选。

### (6) Sedgewick 序列 $h_k = 4^k + 3 \cdot 2^{k-1} + 1$ 的 $O(n^{4/3})$ 时间复杂度证明

Sedgewick (1982) 提出的序列（首项补 $h_0 = 1$，对 $k \ge 1$ 取 $h_k = 4^k + 3 \cdot 2^{k-1} + 1$，即 $1, 8, 23, 77, 281, \dots$，或其交错改进版 $1, 5, 19, 41, 109, \dots$）之所以能突破 $O(n^{3/2})$ 达到 $O(n^{4/3})$，核心原因在于：**Hibbard/Knuth 仅保证了相邻两个大增量 $h_{k+1}, h_{k+2}$ 构成的二元线性组合覆盖范围，而 Sedgewick 精心设计的多项式形式使得当前增量 $h_k$ 之前的多个更大增量的组合（多元 Frobenius 数）能够将最大不可表出跨度从 $\Theta(h_k^2)$ 压缩到 $\Theta(h_k^{3/2})$**。

具体证明概要如下：
1. 注意到 $h_k = 4^k + 3 \cdot 2^{k-1} + 1 = (2^k)^2 + \frac{3}{2}(2^k) + 1 = \Theta(4^k)$。
2. Sedgewick 证明了对于该序列生成的增量，在执行 $h_k$-排序前，由于此前已完成的所有 $h_j\ (j > k)$ 排序的共同作用，它们构成的加性半群的 Frobenius 数满足：
   $$F(h_{k+1}, h_{k+2}, \dots) = O\left((2^k)^3\right) = O\left(h_k^{3/2}\right)$$
3. 因此，在执行第 $k$ 轮（增量为 $h_k$）的插入排序时，每个元素向左移动的最大步数不超过：
   $$\frac{F(h_{k+1}, h_{k+2}, \dots)}{h_k} = O\left(\frac{h_k^{3/2}}{h_k}\right) = O\left(h_k^{1/2}\right) = O(2^k)$$
   从而第 $k$ 轮的总耗时上界收紧为：
   $$T_k = O\left(n \cdot h_k^{1/2}\right)$$
4. 结合对大增量的平凡子表平方上界 $T_k = O(n^2 / h_k)$，选取平衡点使两项相等：
   $$n \cdot h_k^{1/2} = \frac{n^2}{h_k} \implies h_k^{3/2} = n \implies h_k = n^{2/3}$$
5. 以 $n^{2/3}$ 为阈值对几何级数分段求和：
   - 对所有 $h_k \le n^{2/3}$ 的轮次：
     $$\sum_{h_k \le n^{2/3}} O\left(n h_k^{1/2}\right) = O\left(n \cdot (n^{2/3})^{1/2}\right) = O(n^{4/3})$$
   - 对所有 $h_k > n^{2/3}$ 的轮次：
     $$\sum_{h_k > n^{2/3}} O\left(\frac{n^2}{h_k}\right) = O\left(\frac{n^2}{n^{2/3}}\right) = O(n^{4/3})$$

两部分之和即为 $O(n^{4/3})$。

### (7) 最好的增量序列与希尔排序的确切时间复杂度下界

这是一个兼具理论深度与开放性的问题，分**理论最优**、**实践最优**和**复杂度下界**三方面回答：

1. **理论最坏复杂度最优的已知序列**：
   - **Pratt 序列 (1971)**：取所有小于 $n$ 的 $3$-光滑数（形如 $2^p 3^q$ 的整数，即 $1, 2, 3, 4, 6, 8, 9, 12, \dots$）按降序排列。由于若数组已是 $2h$-有序和 $3h$-有序，则 Frobenius 数 $F(2, 3) = 2 \times 3 - 2 - 3 = 1$，所以在进行 $h$-排序时，每个元素至多只需与其紧邻的前驱比较 $1$ 次！因此每轮耗时严格为 $O(n)$。又因为小于 $n$ 的 $2^p 3^q$ 共有 $\Theta(\log^2 n)$ 个，所以 **Pratt 序列的最坏情况时间复杂度为 $\Theta(n \log^2 n)$**，这是目前已知确定性希尔排序最好的渐近最坏上界（但因趟数过多，实践中较慢）。
   - 若仅考虑趟数为 $O(\log n)$（几何级数增长）的增量序列，Incerpi-Sedgewick (1985) 构造的序列达到了 $O\left(n^{1 + \sqrt{8 \ln(5/2) / \ln n}}\right) = O(n^{1 + O(1/\sqrt{\log n})})$ 的最坏上界。

2. **工程实践中表现最好的增量序列**：
   - **Ciura 序列 (2001)**：Marcin Ciura 通过大规模实验搜索找出了在中小规模数组上平均比较次数最少的经验序列：
     $$1, 4, 10, 23, 57, 132, 301, 701, 1750$$
     对于更大的 $n$，通常以公比 $2.25$（即 $h_k = \lfloor 2.25 h_{k-1} \rfloor$）递推扩展，或使用 Tokuda (1992) 序列 $\lceil (9(9/4)^{k-1} - 4) / 5 \rceil$（$1, 4, 9, 20, 46, 103, \dots$）。Ciura 序列是迄今为止公认实际运行速度最快的希尔排序增量序列，但其理论渐近复杂度尚未被完全证明。

3. **希尔排序的确切时间复杂度下界（Jiang-Li-Vitányi 定理与未解难题）**：
   - **Jiang-Li-Vitányi 下界定理 (2000)**：姜涛、李明与 Paul Vitányi 利用 Kolmogorov 复杂度（不可压缩性方法）证明了一个里程碑式的定理——对于**任意**使用 $p$ 趟增量（$p \le \log_2 n$）的希尔排序，其**平均情况**（从而最坏情况）时间复杂度必满足下界：
     $$\Omega\left(p \cdot n^{1 + 1/p}\right)$$
   - **推论与未解之谜**：
     由该定理可知，如果增量序列只有常数趟 $p = O(1)$，希尔排序不可能达到 $O(n \log n)$；若要使希尔排序达到比较排序的理论最优界 $\Theta(n \log n)$，必须满足 $p \cdot n^{1/p} = O(\log n)$，即趟数必须满足 $p = \Omega(\log n / \log \log n)$。
     然而，**“是否存在某个增量序列，使得希尔排序的平均或最坏时间复杂度真正达到 $\Theta(n \log n)$？”** 至今仍是计算机科学界悬而未决的公开难题（普遍猜想这样的增量序列不存在，即希尔排序无法作为一种排序网络或增量插入排序达到 $\Theta(n \log n)$）。
