# 35601：比较排序算法的决策树下界证明

## 题目

比较排序算法的下界：

证明：任何基于比较的排序算法（即仅通过比较元素来确定顺序），在最坏情况下都需要 $\Omega(n \lg n)$ 次比较来排序 $n$ 个不同的元素。
_提示：考虑决策树模型。每个内部节点代表一次比较，叶子节点代表一种可能的排序结果。树的高度对应最坏情况下的比较次数。分析叶子节点的数量和树的高度之间的关系。_

## 解析

任何基于比较的确定性排序算法，其控制流完全由元素对之间的比较结果（如 $a_i \le a_j$ 是否成立）决定。当输入包含 $n$ 个互不相同的元素时，可以忽略等于号与严格不等号的区别，将每次比较抽象为二叉决策树的一个内部结点，从根到叶结点的路径长度即为对应输入下的比较次数。要证明最坏情况比较次数为 $\Omega(n \lg n)$，只需建立“排列总数 $\le$ 决策树可达叶结点数 $\le 2^h$”的不等式链，再对 $\lg(n!)$ 进行严格的下界放缩。

## 答案

### 证明

#### 第一步：建立决策树模型

设输入序列为 $n$ 个互不相同的元素 $\langle a_1, a_2, \dots, a_n \rangle$。任何基于比较的排序算法都可以表示为高度有限的**二叉决策树**：
- 每个**内部结点**标记为一对下标 $i : j$（$1 \le i, j \le n$），表示算法执行一次比较 $a_i \le a_j$；若 $a_i \le a_j$ 成立则转向左子树，若 $a_i > a_j$ 成立则转向右子树。
- 每个**叶结点**标记为一个排列 $\langle \pi(1), \pi(2), \dots, \pi(n) \rangle$，表示算法已确定元素的全序关系为 $a_{\pi(1)} < a_{\pi(2)} < \dots < a_{\pi(n)}$ 并输出该重排结果。
- 对于任意特定输入，算法从根结点开始沿着唯一路径走到某个叶结点，该路径上的内部结点个数（即叶结点的深度）就是算法在该输入下执行的比较次数。因此，**算法在最坏情况下的比较次数等于该决策树的高度 $h$**。

#### 第二步：叶结点数量的下界

$n$ 个互不相同的元素共有 $n!$ 种不同的输入排列。对于一个正确的排序算法，$n!$ 种不同的输入排列必须分别对应唯一的正确输出置换：如果存在两个不同的输入排列沿着完全相同的比较分支到达同一个叶结点，算法就会对它们施以相同的下标重排，从而至少对其中一个排列给出错误的未排序输出（由鸽巢原理）。

因此，每一种可能的排列都必须作为至少一个可达叶结点出现在决策树中。设决策树的叶结点总数为 $L$，则必有：

$$L \ge n!$$

#### 第三步：树高 $h$ 与叶结点数 $L$ 的关系

通过对树高 $h$ 进行数学归纳法易证：高度为 $h$ 的二叉树最多包含 $2^h$ 个叶结点（当 $h = 0$ 时只有 $1 = 2^0$ 个叶结点；高度为 $h$ 的树由两棵高度至多为 $h - 1$ 的子树组成，叶结点数至多为 $2^{h-1} + 2^{h-1} = 2^h$）。即：

$$L \le 2^h$$

联立上面两个不等式，得到：

$$n! \le L \le 2^h$$

由于对数函数 $\lg x = \log_2 x$ 单调递增，对两边同时取以 $2$ 为底的对数，可得最坏情况比较次数 $h$ 的下界：

$$h \ge \lg(n!)$$

#### 第四步：证明 $\lg(n!) = \Omega(n \lg n)$

下面用两种方法严格证明 $\lg(n!) = \Omega(n \lg n)$：

- **方法一（初等放缩法）**：
  展开阶乘并对前半部分和后半部分分别放缩，仅保留从 $\lceil n / 2 \rceil$ 到 $n$ 的后一半因子（共至少 $n / 2$ 个因子，且每个因子均大于等于 $n / 2$）：
  $$n! = 1 \times 2 \times \dots \times n \ge \prod_{k = \lceil n / 2 \rceil}^{n} k \ge \left(\frac{n}{2}\right)^{n/2}$$
  两边取以 $2$ 为底的对数：
  $$\lg(n!) \ge \frac{n}{2} \lg\left(\frac{n}{2}\right) = \frac{n}{2} \lg n - \frac{n}{2}$$
  当 $n \ge 4$ 时，$\lg n \ge 2$，即 $\frac{n}{2} \le \frac{1}{4} n \lg n$。于是对所有 $n \ge 4$，有：
  $$h \ge \lg(n!) \ge \frac{1}{2} n \lg n - \frac{1}{4} n \lg n = \frac{1}{4} n \lg n$$
  取常数 $c = \frac{1}{4} > 0$，$n_0 = 4$，即证得 $h = \Omega(n \lg n)$。

- **方法二（斯特林公式下界）**：
  由带余项的斯特林不等式（Stirling's inequality），对任意正整数 $n \ge 1$，恒有严格下界：
  $$n! \ge \sqrt{2\pi n} \left(\frac{n}{e}\right)^n$$
  两边取以 $2$ 为底的对数：
  $$h \ge \lg(n!) \ge n \lg n - (n \lg e) + \frac{1}{2}\lg(2\pi n) = \Omega(n \lg n)$$

综上所述，任何基于比较的排序算法在最坏情况下都至少需要进行 $\Omega(n \lg n)$ 次比较。证毕。
