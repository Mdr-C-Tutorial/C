# 35603 - 稳定自底向上（非递归迭代）归并排序

## 题目描述

实现稳定的归并排序，排序对象和接口如下：

```c
#include <stdbool.h>
#include <stddef.h>
#include <stdint.h>

typedef struct {
    int64_t key;
    uint64_t payload;
} SortRecord;

bool stable_merge_sort_records(
    SortRecord *items,
    size_t count
);
```

要求：

1. 排序后 `key` 非递减；当两个键相等时，`payload` 的相对顺序必须与输入一致（保持稳定性）。
2. `count == 0` 时允许 `items == NULL`；非空输入必须有效。辅助空间分配失败或大小计算溢出时返回 `false`，原数组保持不变。
3. 比较键时只能使用关系运算，不能通过相减得到比较结果，以正确处理 `INT64_MIN` 和 `INT64_MAX`。
4. 实现的时间复杂度为 $O(n\log n)$，额外空间复杂度为 $O(n)$；说明合并时为何在相等键下优先选取左侧记录才能保持稳定性。
5. 使用空数组、单个记录、全部键相等、已经有序、逆序以及包含两个极端键值的输入进行测试。

## 解题思路

### 1. 自底向上非递归归并原理

传统递归归并排序自顶向下递归切分，需要 $\log_2 n$ 层的函数调用栈。自底向上（Bottom-Up）归并排序采用迭代方式：
- 第一轮以步长 `width = 1` 为单位，将相邻长度为 1 的子区间两两合并为长度为 2 的有序区间；
- 第二轮以 `width = 2` 为单位两两合并；
- 每轮步长翻倍（`width *= 2`），直到 `width >= count` 时整个数组合并完毕。
这种模式完全消除了递归函数调用开销，对超大数据规模非常安全。

### 2. 稳定性的数学来源

归并排序的稳定性取决于两个有序子区间合并时的偏序抉择：
设左子区间为 $[left, mid)$，右子区间为 $[mid, right)$。
当比较左右两端的记录时：
- 若左侧键严格小于右侧键（`items[i].key < items[j].key`），自然选取左侧；
- **若两侧键完全相等（`items[i].key == items[j].key`）**：
  在输入序列中，左侧子区间的元素下标严格小于右侧子区间的元素下标（$i < j$）。为了使具有相同键的记录在排序后依然保持原来的先后相对次序，**必须优先选取左侧记录放入临时合并数组**！
  若将判断写为 `items[i].key <= items[j].key`，相等时自动优先取左侧，算法就是严格稳定的；若写成 `<`，相等时会优先取右侧，就会破坏稳定性。

### 3. 防溢出比较

在 C 语言中，两个 `int64_t` 的差值可能达到 $2^{64} - 1$（例如 $\text{INT64\_MAX} - \text{INT64\_MIN}$），相减会发生有符号整数溢出 UB。必须使用标准关系运算符 `<` 和 `<=`。

## C 语言实现

```c
#include <assert.h>
#include <limits.h>
#include <stdbool.h>
#include <stddef.h>
#include <stdint.h>
#include <stdio.h>
#include <stdlib.h>
#include <string.h>

typedef struct {
    int64_t key;
    uint64_t payload;
} SortRecord;

bool stable_merge_sort_records(SortRecord *items, size_t count) {
    if (count <= 1) {
        return true;
    }
    if (items == NULL || count > SIZE_MAX / sizeof(SortRecord)) {
        return false;
    }

    SortRecord *temp = malloc(count * sizeof(SortRecord));
    if (temp == NULL) {
        return false;
    }

    for (size_t width = 1; width < count; width *= 2) {
        for (size_t left = 0; left < count; left += 2 * width) {
            size_t mid = left + width;
            if (mid > count) {
                mid = count;
            }
            size_t right = left + 2 * width;
            if (right > count) {
                right = count;
            }

            size_t i = left;
            size_t j = mid;
            size_t k = left;

            /* 稳定合并：相等时优先取左侧记录 */
            while (i < mid && j < right) {
                if (items[i].key <= items[j].key) {
                    temp[k++] = items[i++];
                } else {
                    temp[k++] = items[j++];
                }
            }
            while (i < mid) {
                temp[k++] = items[i++];
            }
            while (j < right) {
                temp[k++] = items[j++];
            }

            memcpy(items + left, temp + left, (right - left) * sizeof(SortRecord));
        }
    }

    free(temp);
    return true;
}

int main(void) {
    /* 1. 稳定性验证：相同键的记录 payload 相对顺序必须严格保持 */
    SortRecord recs[] = {
        {3, 101}, {1, 201}, {3, 102}, {2, 301}, {1, 202}
    };
    assert(stable_merge_sort_records(recs, 5));
    assert(recs[0].key == 1 && recs[0].payload == 201);
    assert(recs[1].key == 1 && recs[1].payload == 202); // 保持顺序
    assert(recs[2].key == 2 && recs[2].payload == 301);
    assert(recs[3].key == 3 && recs[3].payload == 101);
    assert(recs[4].key == 3 && recs[4].payload == 102); // 保持顺序

    /* 2. 极端键值测试：INT64_MIN 与 INT64_MAX 防溢出 */
    SortRecord extreme[] = {
        {INT64_MAX, 1}, {INT64_MIN, 2}, {0, 3}
    };
    assert(stable_merge_sort_records(extreme, 3));
    assert(extreme[0].key == INT64_MIN);
    assert(extreme[1].key == 0);
    assert(extreme[2].key == INT64_MAX);

    /* 3. 已有序与完全逆序测试 */
    SortRecord rev[] = {{5, 0}, {4, 0}, {3, 0}, {2, 0}, {1, 0}};
    assert(stable_merge_sort_records(rev, 5));
    for (size_t i = 1; i < 5; ++i) {
        assert(rev[i - 1].key <= rev[i].key);
    }

    /* 4. 空数组与单元素测试 */
    assert(stable_merge_sort_records(NULL, 0));
    SortRecord single = {42, 1};
    assert(stable_merge_sort_records(&single, 1));

    printf("All stable_merge_sort_records tests passed successfully.\n");
    return 0;
}
```

## 复杂度分析

- **时间复杂度**：$\Theta(n \log n)$。外层循环执行 $\lceil \log_2 n \rceil$ 轮，每一轮内层对全量 $n$ 个元素执行一次线性合并复制，无论输入序列初态如何均稳定为 $\Theta(n \log n)$。
- **空间复杂度**：$O(n)$。需要一个容量为 $n$ 的辅助临时数组用于合并暂存。

## 延伸思考 / 模式总结

归并排序是唯二兼备“最坏情况 $O(n \log n)$ 时间”与“严格稳定性”的通用排序算法（另一个是蒂姆排序 Timsort，Timsort 本质也是自底向上归并的工程优化变体）。在数据库外排序与多关键字排序系统中，归并排序的稳定性是实现级联排序（如先按时间排序，再按部门排序）的根本保障。
