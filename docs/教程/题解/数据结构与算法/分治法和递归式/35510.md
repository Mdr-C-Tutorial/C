# 35510：通用约瑟夫环问题（报 k 的倍数出列）

## 题目

在 **35509** 的基础上，改为报 `k` 的倍数的人出列。

## 解析

这是经典的一般约瑟夫环（Josephus Problem）问题：$n$ 个人编号为 $1, 2, \dots, n$ 顺时针围成一圈，从 $1$ 号开始报数，每次报到 $k$ 的倍数（即每数到第 $k$ 个人）时该人出列，下一个人重新从 $1$（或继续累加报数，等价于每数 $k$ 个在圈中的人出列一人）开始，求最后幸存者的编号。下面同时给出**数组直接模拟法**与**数学递推法**。

### 方法一：数组模拟法

用长度为 $n + 1$ 的状态数组标记每个人是否已出列。每轮扫描在圈中的人并递增报数计数器，当计数器能被 $k$ 整除时将该位置标记为出列，并将剩余人数减 $1$，直到只剩 $1$ 人为止。时间复杂度为 $O(nk)$，空间复杂度为 $O(n)$。

### 方法二：线性时间递推法

为了便于取模运算，先采用从 $0$ 开始的编号 $0, 1, \dots, n - 1$，记规模为 $n$、步长为 $k$ 时最后幸存者的 $0$-起始编号为 $J(n, k)$：
- **基本情况**：当 $n = 1$ 时，唯一的人编号为 $0$，故 $J(1, k) = 0$。
- **递推关系**：当 $n > 1$ 时，第一个出列的人编号为 $(k - 1) \bmod n$。出列后剩下 $n - 1$ 个人，下一轮报数从原编号为 $k \bmod n$ 的人开始。若将这 $n - 1$ 个人按新的报数起点重新映射为新编号 $0, 1, \dots, n - 2$，则新编号 $x$ 与原编号 $y$ 之间的映射关系为：
  $$y = (x + k) \bmod n$$
  在规模为 $n - 1$ 的子问题中，最后幸存者的新编号为 $J(n - 1, k)$，映射回原编号即得递推式：
  $$J(n, k) = (J(n - 1, k) + k) \bmod n \quad (n \ge 2)$$
- **还原为 $1$-起始编号**：将递推求出的 $J(n, k)$ 加 $1$，即 $J(n, k) + 1$。该方法时间复杂度仅为 $\Theta(n)$，空间复杂度为 $\Theta(1)$。

## 答案

### 1. 递推法实现（$\Theta(n)$ 时间，$\Theta(1)$ 空间）

```c
#include <inttypes.h>
#include <stdio.h>

int64_t josephus_survivor(int64_t n, int64_t k) {
    int64_t survivor = 0;
    for (int64_t i = 2; i <= n; ++i) {
        survivor = (survivor + k) % i;
    }
    return survivor + 1;
}

int main(void) {
    int64_t n = 0;
    int64_t k = 0;
    printf("输入人数 n 和步长 k：");
    if (scanf("%" SCNd64 "%" SCNd64, &n, &k) != 2 || n <= 0 || k <= 0) {
        return 1;
    }
    printf("最后剩下：%" PRId64 "\n", josephus_survivor(n, k));
    return 0;
}
```

### 2. 数组模拟法实现（$O(nk)$ 时间，$O(n)$ 空间）

```c
#include <stdio.h>
#include <stdlib.h>

int main(void) {
    int n = 0;
    int k = 0;
    printf("输入人数 n 和步长 k：");
    if (scanf("%d %d", &n, &k) != 2 || n <= 0 || k <= 0) {
        return 1;
    }

    int *out = calloc((size_t)n + 1, sizeof(int));
    if (out == NULL) {
        return 1;
    }

    int remain = n;
    int count = 1;
    int pos = 1;

    while (remain > 1) {
        if (!out[pos]) {
            if (count % k == 0) {
                out[pos] = 1;
                remain--;
            }
            count++;
        }
        pos = pos % n + 1;
    }

    for (int i = 1; i <= n; i++) {
        if (!out[i]) {
            printf("最后剩下：%d\n", i);
            break;
        }
    }

    free(out);
    return 0;
}
```
