# 35508：不使用哨兵的归并排序合并函数

## 题目

在本教程的 `merge()` 函数实现中，使用了宏 `INT_MAX`。如果不允许使用这个值，你将如何修改 `merge()` 函数中的主循环来完成合并操作？

## 解析

教程正文中使用 `INT_MAX` 作为哨兵是为了省去边界耗尽检查，但这不仅要求每个临时数组多分配一个元素，还会导致当待排序数组中本身含有 `INT_MAX` 时难以区分真实数据与哨兵。

如果不使用哨兵 `INT_MAX`：
1. 临时数组 `L` 和 `R` 只需分别精确分配 `n1` 和 `n2` 个元素的空间；
2. 主循环改为当左右两个子数组都还有未取完的元素时（`while (i < n1 && j < n2)`）比较 `L[i]` 和 `R[j]`，将较小者放入 `A[k++]`；
3. 当主循环退出时，必然至少有一个子数组已经全部复制完毕，再使用两个收尾 `while` 循环将另一个子数组中剩余的元素依次追加到 `A` 的末尾即可。

## 答案

```c
#include <stdio.h>
#include <stdlib.h>

void merge(int A[], const int p, const int mid, const int r) {
    const int n1 = mid - p + 1;
    const int n2 = r - mid;
    int *L = malloc((size_t)n1 * sizeof(int));
    int *R = malloc((size_t)n2 * sizeof(int));
    if (L == NULL || R == NULL) {
        free(L);
        free(R);
        return;
    }

    for (int i = 0; i < n1; i++) {
        L[i] = A[p + i];
    }
    for (int j = 0; j < n2; j++) {
        R[j] = A[(mid + 1) + j];
    }

    int i = 0;
    int j = 0;
    int k = p;
    while (i < n1 && j < n2) {
        if (L[i] <= R[j]) {
            A[k++] = L[i++];
        } else {
            A[k++] = R[j++];
        }
    }
    while (i < n1) {
        A[k++] = L[i++];
    }
    while (j < n2) {
        A[k++] = R[j++];
    }

    free(L);
    free(R);
}

void merge_sort(int A[], int p, int r) {
    if (p < r) {
        int mid = p + (r - p) / 2;
        merge_sort(A, p, mid);
        merge_sort(A, mid + 1, r);
        merge(A, p, mid, r);
    }
}

int main(void) {
    int N[10] = {13, 5, 9, 6, 11, 2, 4, 7, 1, 8};
    merge_sort(N, 0, 9);
    for (int i = 0; i < 10; i++) {
        printf("%d ", N[i]);
    }
    printf("\n");
    return 0;
}
```
