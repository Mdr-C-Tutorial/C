# 35502：代入法证明线性递减递归式的平方上界

## 题目

对于递归式 $T(n) = T(n-1) + n$，使用代入法证明其解为 $T(n) = O(n^2)$。

## 解析

代入法的核心步骤是：先根据 $O(n^2)$ 的定义猜测解满足 $T(n) \le c n^2$（其中 $c > 0$、$n \ge n_0$），再通过数学归纳法验证归纳步骤与基本情况，并明确给出使不等式成立的常数 $c$ 与起始阈值 $n_0$。不妨设基本情况 $T(1)$ 为正常数（记 $T(1) = c_0 > 0$）。

## 答案

我们要证明存在正常数 $c > 0$ 和正整数 $n_0 \ge 1$，使得对所有整数 $n \ge n_0$，均有：

$$T(n) \le c n^2$$

### 1. 归纳步骤

假设对于规模 $n - 1$（其中 $n - 1 \ge n_0$）归纳假设成立，即：

$$T(n - 1) \le c (n - 1)^2$$

将其代入原递归式 $T(n) = T(n - 1) + n$，可得：

$$
\begin{aligned}
T(n) &= T(n - 1) + n \\
&\le c(n - 1)^2 + n \\
&= c(n^2 - 2n + 1) + n \\
&= c n^2 - (2c - 1)n + c
\end{aligned}
$$

为了使上式最右端不超过 $c n^2$，只需满足残余项非正：

$$-(2c - 1)n + c \le 0 \iff (2c - 1)n \ge c$$

当取 $c \ge 1$ 时，$2c - 1 \ge c > 0$，于是对任意 $n \ge 1$ 都有：

$$(2c - 1)n \ge c \cdot 1 = c$$

从而 $T(n) \le c n^2 - ((2c - 1)n - c) \le c n^2$ 对所有 $n \ge 2$ 成立。

### 2. 基本情况与常数选取

设递归基底为 $T(1) = c_0 > 0$。当 $n = 1$ 时，需要满足：

$$T(1) = c_0 \le c \cdot 1^2 = c$$

因此，只需选取常数：

$$c = \max\{1, T(1)\}, \quad n_0 = 1$$

此时：
- **奠基（$n = 1$）**：$T(1) \le \max\{1, T(1)\} \cdot 1^2 = c \cdot 1^2$ 成立；
- **归纳（$n \ge 2$）**：由 $c \ge 1$ 及归纳步骤可知，若 $T(n - 1) \le c(n - 1)^2$ 成立，则 $T(n) \le c n^2$ 必然成立。

由数学归纳法可知，对所有 $n \ge n_0 = 1$ 均有 $T(n) \le c n^2$，故 $T(n) = O(n^2)$。
