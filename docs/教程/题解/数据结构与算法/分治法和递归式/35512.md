# 35512：矩阵分治快速幂与常系数线性递推

## 题目

**分治快速幂与常系数线性递推**：
广义 Fibonacci 数列定义为 $F_0 = 0, F_1 = 1$，且当 $n \ge 2$ 时 $F_n = (a \cdot F_{n-1} + b \cdot F_{n-2}) \bmod M$（其中 $a, b, M$ 为给定常数正整数）。
- (a) **状态转移矩阵构建**：请写出对应的 $2 \times 2$ 状态转移矩阵 $\mathbf{T}$，使得 $\begin{bmatrix} F_{n} \\ F_{n-1} \end{bmatrix} = \mathbf{T}^{n-1} \begin{bmatrix} F_1 \\ F_0 \end{bmatrix}$。
- (b) **分治递归式与计算复杂度**：利用分治思想，矩阵幂 $\mathbf{T}^k$ 可由 $\mathbf{T}^{\lfloor k/2 \rfloor}$ 的自乘在 $O(1)$ 次模乘内完成。写出计算 $\mathbf{T}^k$ 乘法次数的递归式，并求解其时间复杂度。
- (c) **C 语言实现**：编写 C17 实现，封装 $2 \times 2$ 矩阵乘法与基于分治的二进制快速幂算法，计算大索引 $n$（例如 $n = 10^{18}$）下的数列值模 $M$，并与朴素 $O(n)$ 线性迭代在小规模数据下进行等价性校验。

## 解析

### 1. 状态转移矩阵构建

常系数齐次线性递推关系可以表示为向量的线性变换。根据题目给出的递推方程：

$$\begin{cases} F_n = a \cdot F_{n-1} + b \cdot F_{n-2} \\ F_{n-1} = 1 \cdot F_{n-1} + 0 \cdot F_{n-2} \end{cases}$$

将相邻两项封装为二维状态列向量 $\mathbf{V}_n = \begin{bmatrix} F_n \\ F_{n-1} \end{bmatrix}$，递推关系即可表述为矩阵与向量相乘的标准形式：

$$\begin{bmatrix} F_n \\ F_{n-1} \end{bmatrix} = \begin{bmatrix} a & b \\ 1 & 0 \end{bmatrix} \begin{bmatrix} F_{n-1} \\ F_{n-2} \end{bmatrix}$$

记转移矩阵为 $\mathbf{T} = \begin{bmatrix} a & b \\ 1 & 0 \end{bmatrix}$。通过归纳展开：

$$\mathbf{V}_n = \mathbf{T} \mathbf{V}_{n-1} = \mathbf{T}^2 \mathbf{V}_{n-2} = \dots = \mathbf{T}^{n-1} \mathbf{V}_1 = \mathbf{T}^{n-1} \begin{bmatrix} F_1 \\ F_0 \end{bmatrix} = \mathbf{T}^{n-1} \begin{bmatrix} 1 \\ 0 \end{bmatrix}$$

对于任意 $n \ge 2$，只要计算出矩阵幂 $\mathbf{T}^{n-1}$，将其第 0 行第 0 列的元素乘以 $F_1(1)$ 加上第 0 行第 1 列的元素乘以 $F_0(0)$，即可在 $\Theta(1)$ 时间内得到 $F_n$ 的值：$F_n = (\mathbf{T}^{n-1})_{0,0} \bmod M$。

---

### 2. 分治递归式与时间复杂度分析

要求解矩阵幂 $\mathbf{T}^k$，朴素做法是连续左乘 $k-1$ 次，需进行 $\Theta(k)$ 次矩阵乘法。利用**分治法**，可将幂次 $k$ 递归折半：

$$\mathbf{T}^k = \begin{cases} \mathbf{I}, & k = 0 \\ \left(\mathbf{T}^{\lfloor k/2 \rfloor}\right)^2, & k \text{ 为偶数} \\ \left(\mathbf{T}^{\lfloor k/2 \rfloor}\right)^2 \times \mathbf{T}, & k \text{ 为奇数} \end{cases}$$

设 $M(k)$ 表示计算 $\mathbf{T}^k$ 所需进行的 $2 \times 2$ 矩阵乘法次数。每一步递归先计算子问题 $\mathbf{T}^{\lfloor k/2 \rfloor}$，之后至多执行 2 次矩阵乘法（偶数时自乘 1 次，奇数时自乘 1 次后再乘基底 1 次）：

$$M(k) = M\left(\left\lfloor \frac{k}{2} \right\rfloor\right) + \Theta(1)$$

根据主定理第 2 种情况（$a = 1, b = 2, f(k) = \Theta(1) = \Theta(k^{\log_2 1})$）：

$$M(k) = \Theta(\log k)$$

对于固定的 $2 \times 2$ 阶矩阵，一次矩阵模乘包含 $2^3 = 8$ 次标量模乘与 4 次加法，其时间开销为严格常数 $\Theta(1)$。因此，计算 $F_n$ 的总时间复杂度为：

$$T(n) = \Theta(\log n)$$

自底向上实现的迭代二进制平方法无需递归函数调用栈，额外空间复杂度为 $\Theta(1)$。

---

### 3. C 语言实现设计细节

- **对象作用域与结构体设计**：定义值语义的 `Matrix2x2` 结构体对象，矩阵乘法函数接收结构体值传递并返回结果对象，避免动态内存分配。
- **乘法防溢出防护**：当模数 $M \le 10^9 + 7$ 时，中间乘积最大约为 $(10^9 + 7)^2 \approx 10^{18} < 2^{64} - 1 \approx 1.84 \times 10^{19}$。使用无符号 64 位整数类型 `uint64_t` 进行运算，保证不会发生无符号整数溢出。
- **边界条件健全性**：
  - 若 $M \le 1$，任何整数对 $M$ 取模的结果均为 $0$；
  - 若 $n = 0$，直接返回 $0$；若 $n = 1$，直接返回 $1 \bmod M$。

## 答案

```c
#include <assert.h>
#include <inttypes.h>
#include <stdbool.h>
#include <stdint.h>
#include <stdio.h>

typedef struct {
    uint64_t m[2][2];
} Matrix2x2;

// 2x2 矩阵模乘法：(a * b) mod mod
static Matrix2x2 matrix_mul_mod(Matrix2x2 a, Matrix2x2 b, uint64_t mod) {
    Matrix2x2 res = {{{0, 0}, {0, 0}}};
    for (int i = 0; i < 2; ++i) {
        for (int k = 0; k < 2; ++k) {
            if (a.m[i][k] == 0) {
                continue;
            }
            for (int j = 0; j < 2; ++j) {
                uint64_t prod = (a.m[i][k] % mod) * (b.m[k][j] % mod) % mod;
                res.m[i][j] = (res.m[i][j] + prod) % mod;
            }
        }
    }
    return res;
}

// 基于分治折半思想的矩阵快速幂：(base^exp) mod mod
static Matrix2x2 matrix_pow_mod(Matrix2x2 base, uint64_t exp, uint64_t mod) {
    Matrix2x2 result = {{{1 % mod, 0}, {0, 1 % mod}}}; // 单位矩阵对象
    Matrix2x2 cur = base;

    while (exp > 0) {
        if (exp & 1) {
            result = matrix_mul_mod(result, cur, mod);
        }
        cur = matrix_mul_mod(cur, cur, mod);
        exp >>= 1;
    }
    return result;
}

// 求解广义 Fibonacci 数列第 n 项模 mod
uint64_t generalized_fibonacci(uint64_t a, uint64_t b, uint64_t n, uint64_t mod) {
    if (mod <= 1) {
        return 0;
    }
    if (n == 0) {
        return 0;
    }
    if (n == 1) {
        return 1 % mod;
    }

    Matrix2x2 t = {{{a % mod, b % mod}, {1 % mod, 0}}};
    Matrix2x2 tn = matrix_pow_mod(t, n - 1, mod);

    // [F_n, F_{n-1}]^T = T^(n-1) * [F_1, F_0]^T = T^(n-1) * [1, 0]^T
    // 因此 F_n = tn.m[0][0] * 1 + tn.m[0][1] * 0
    return tn.m[0][0] % mod;
}

// 朴素线性迭代实现，用于单元测试校验结果
static uint64_t generalized_fibonacci_linear(
    uint64_t a,
    uint64_t b,
    uint64_t n,
    uint64_t mod
) {
    if (mod <= 1) {
        return 0;
    }
    if (n == 0) {
        return 0;
    }
    if (n == 1) {
        return 1 % mod;
    }

    uint64_t f0 = 0;
    uint64_t f1 = 1 % mod;
    for (uint64_t i = 2; i <= n; ++i) {
        uint64_t fn = ((a % mod) * f1 + (b % mod) * f0) % mod;
        f0 = f1;
        f1 = fn;
    }
    return f1;
}

int main(void) {
    const uint64_t mod = 1000000007ULL; // 10^9 + 7
    const uint64_t a = 3;
    const uint64_t b = 7;

    // 0 到 100 项与线性递推对拍验证
    for (uint64_t n = 0; n <= 100; ++n) {
        uint64_t expected = generalized_fibonacci_linear(a, b, n, mod);
        uint64_t actual = generalized_fibonacci(a, b, n, mod);
        assert(expected == actual);
    }

    // 标准 Fibonacci 数列 (a=1, b=1) 经典项检验
    // F_10 = 55
    assert(generalized_fibonacci(1, 1, 10, mod) == 55);

    // 大数据量 n = 10^18 毫秒级快速求解
    uint64_t big_n = 1000000000000000000ULL;
    uint64_t result_big = generalized_fibonacci(1, 1, big_n, mod);
    printf("Fibonacci(10^18) mod (10^9+7) = %" PRIu64 "\n", result_big);

    printf("矩阵分治快速幂测试全部通过！\n");
    return 0;
}
```
