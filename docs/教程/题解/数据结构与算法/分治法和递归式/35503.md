# 35503：递归树法求解归并排序递归式

## 题目

对于归并排序的递归式 $T(n) = 2T(n/2) + \Theta(n)$，请：
   - (a) 画出其递归树。
   - (b) 计算出树的每一层的代价总和。
   - (c) 计算树的高度，并求出所有层代价的总和，从而得出 $T(n)$ 的渐近界。

## 解析

将 $\Theta(n)$ 显式写作 $cn$（其中 $c > 0$ 为常数），把基本情况 $T(1) = \Theta(1)$ 记为常数 $d > 0$。不妨设 $n$ 为 $2$ 的幂（即 $n = 2^k$，对一般正整数 $n$ 渐近界保持不变）。在递归树中，每个内部结点表示当前子问题的合并与分解代价，它的两个子结点分别对应规模减半的两个子问题。

## 答案

设 $T(1) = d$，且当 $n > 1$ 时 $T(n) = 2T(n/2) + cn$（其中 $c, d > 0$ 为常数）。

### (a) 递归树结构

根节点位于第 $0$ 层，规模为 $n$，本层非递归代价为 $cn$；每向下深入一层，结点个数翻倍，单个结点的子问题规模减半，直至第 $\lg n$ 层子问题规模降为 $1$：

```text
第 0 层 (根):                         cn                              -> 本层总代价: cn
                                   /      \
第 1 层:                        c(n/2)    c(n/2)                      -> 本层总代价: cn
                               /    \      /    \
第 2 层:                    c(n/4) c(n/4) c(n/4) c(n/4)               -> 本层总代价: cn
                             ...    ...    ...    ...
第 i 层:                 共 2^i 个结点，每个结点代价 c(n / 2^i)         -> 本层总代价: cn
                             ...    ...    ...    ...
第 lg n 层 (叶):         T(1)   T(1)   T(1)  ...  T(1) (共 n 个叶结点) -> 本层总代价: dn
```

### (b) 每一层的代价总和

- 对于第 $i$ 层（$0 \le i < \lg n$）：共有 $2^i$ 个内部结点，每个结点的子问题规模为 $\frac{n}{2^i}$，产生的分解与合并代价为 $c \cdot \frac{n}{2^i}$。因此第 $i$ 层的代价总和为：
  $$2^i \cdot c\left(\frac{n}{2^i}\right) = cn$$
- 对于最底层的叶结点层（第 $\lg n$ 层）：每个叶结点规模为 $1$，共有 $2^{\lg n} = n$ 个叶结点，每个叶结点代价为 $T(1) = d$。因此叶结点层的代价总和为：
  $$n \cdot d = dn = \Theta(n)$$

### (c) 树的高度与总代价渐近界

- **树的高度**：第 $i$ 层的子问题规模为 $\frac{n}{2^i}$。当子问题到达递归触底状态时，满足 $\frac{n}{2^h} = 1 \implies 2^h = n \implies h = \lg n$。因此递归树的高度为 $h = \lg n$，共有 $\lg n + 1$ 层（从第 $0$ 层到第 $\lg n$ 层）。
- **所有层代价总和**：将第 $0$ 层到第 $\lg n - 1$ 层的内部结点代价与第 $\lg n$ 层的叶结点代价相加，得：
  $$
  \begin{aligned}
  T(n) &= \sum_{i = 0}^{\lg n - 1} cn + dn \\
  &= cn \lg n + dn
  \end{aligned}
  $$
  由于高阶项为 $cn \lg n$，低阶项 $dn$ 在渐近意义下可忽略，故得出渐近紧确界：
  $$T(n) = \Theta(n \lg n)$$
