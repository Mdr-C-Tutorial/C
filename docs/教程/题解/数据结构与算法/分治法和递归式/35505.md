# 35505：最大子数组和的分治算法

## 题目

本教程 6.2 节提到了**最大子数组和问题**。请设计一个分治算法来解决它。

- (a) **分解**：如何将数组分成子问题？
- (b) **解决**：子问题的解是什么？
- (c) **合并**：这是最关键的一步。一个最大和的子数组可能存在于三个地方：① 完全在左半部分；② 完全在右半部分；③ **跨越了中点**。请详细描述如何在线性时间 $\Theta(n)$ 内找到跨越中点的最大子数组，并结合左右子问题的解，得到原问题的解。
- (d) 写出该分治算法的递归式并求解其时间复杂度。

## 解析

分治法求解最大连续非空子数组和的核心洞察是：任意连续子数组 $A[i \dots j]$（其中 $\text{low} \le i \le j \le \text{high}$）相对于中点 $\text{mid} = \lfloor (\text{low} + \text{high}) / 2 \rfloor$ 的位置关系必然且仅能归入三类：
1. 完全位于左半区间 $A[\text{low} \dots \text{mid}]$（即 $\text{low} \le i \le j \le \text{mid}$）；
2. 完全位于右半区间 $A[\text{mid} + 1 \dots \text{high}]$（即 $\text{mid} + 1 \le i \le j \le \text{high}$）；
3. 跨越中点 $\text{mid}$（即 $\text{low} \le i \le \text{mid} < j \le \text{high}$）。

前两类与原问题结构完全相同，可通过递归调用求解；第三类因为受到“必须同时包含 $A[\text{mid}]$ 和 $A[\text{mid}+1]$”的约束，可以拆分为以 $\text{mid}$ 结尾的最大左后缀与以 $\text{mid}+1$ 开头的最大右前缀，分别向左右两侧线性扫描一次即可在 $\Theta(n)$ 时间内求出。

## 答案

### (a) 分解

设当前待求解的子数组区间为 $A[\text{low} \dots \text{high}]$，元素个数为 $n = \text{high} - \text{low} + 1$。
当 $\text{low} == \text{high}$（即 $n = 1$）时到达递归基本情况，该单元素区间本身即为最大子数组，直接返回其元素值 $A[\text{low}]$。
当 $\text{low} < \text{high}$ 时，计算中点下标 $\text{mid} = \text{low} + (\text{high} - \text{low}) / 2$，将原数组划分为两个规模约为 $n / 2$ 的子数组：$A[\text{low} \dots \text{mid}]$ 和 $A[\text{mid} + 1 \dots \text{high}]$。

### (b) 解决

递归调用分治函数，分别求出：
1. 完全位于左半子数组 $A[\text{low} \dots \text{mid}]$ 内的最大子数组和 $S_{\text{left}}$；
2. 完全位于右半子数组 $A[\text{mid} + 1 \dots \text{high}]$ 内的最大子数组和 $S_{\text{right}}$。

### (c) 合并

跨越中点的任何子数组 $A[i \dots j]$（满足 $\text{low} \le i \le \text{mid} < j \le \text{high}$）都由左半部分后缀 $A[i \dots \text{mid}]$ 和右半部分前缀 $A[\text{mid} + 1 \dots j]$ 拼接而成，其元素和等于这两部分元素和相加。由于左右两部分的选择彼此独立，要使总和最大，只需分别最大化左后缀和与右前缀和：

1. **向左扫描求最大左后缀和**：从下标 $i = \text{mid}$ 递减遍历至 $\text{low}$，维护累加和，记录遇到的最大和 $L_{\max} = \max_{\text{low} \le i \le \text{mid}} \sum_{k=i}^{\text{mid}} A[k]$。此步耗时 $\Theta(\text{mid} - \text{low} + 1)$。
2. **向右扫描求最大右前缀和**：从下标 $j = \text{mid} + 1$ 递增遍历至 $\text{high}$，维护累加和，记录遇到的最大和 $R_{\max} = \max_{\text{mid} + 1 \le j \le \text{high}} \sum_{k=\text{mid}+1}^{j} A[k]$。此步耗时 $\Theta(\text{high} - \text{mid})$。
3. **合成跨越中点的最大和**：令 $S_{\text{cross}} = L_{\max} + R_{\max}$。两次线性扫描共访问区间内的每个元素恰好一次，总耗时为 $\Theta(n)$。
4. **三者取最大**：比较 $S_{\text{left}}$、$S_{\text{right}}$ 和 $S_{\text{cross}}$，返回 $\max\{S_{\text{left}}, S_{\text{right}}, S_{\text{cross}}\}$ 作为原区间 $A[\text{low} \dots \text{high}]$ 的最大子数组和。

### (d) 递归式与时间复杂度

- 当 $n = 1$ 时，只需常数次基本操作，$T(1) = \Theta(1)$。
- 当 $n > 1$ 时，分解耗时 $\Theta(1)$，递归求解两个规模为 $n / 2$ 的子问题耗时 $2T(n/2)$，合并步骤寻找跨越中点最大子数组耗时 $\Theta(n)$。因此递归式为：
  $$T(n) = \begin{cases} \Theta(1) & n = 1 \\ 2T(n / 2) + \Theta(n) & n > 1 \end{cases}$$
- 应用主定理（$a = 2, b = 2, f(n) = \Theta(n)$）：由于 $n^{\log_b a} = n^{\log_2 2} = n$，满足 $f(n) = \Theta(n^{\log_b a})$，符合**主定理情况 2**，故该分治算法的时间复杂度为：
  $$T(n) = \Theta(n \lg n)$$

### C 语言完整实现

```c
#include <inttypes.h>
#include <limits.h>
#include <stddef.h>
#include <stdint.h>
#include <stdio.h>

typedef struct {
    size_t low;
    size_t high;
    int64_t sum;
} SubarrayResult;

static SubarrayResult find_max_crossing_subarray(
    const int64_t *arr,
    size_t low,
    size_t mid,
    size_t high
) {
    int64_t left_sum = INT64_MIN;
    int64_t current_sum = 0;
    size_t max_left = mid;

    for (size_t offset = 0; offset <= mid - low; ++offset) {
        size_t i = mid - offset;
        current_sum += arr[i];
        if (current_sum > left_sum) {
            left_sum = current_sum;
            max_left = i;
        }
    }

    int64_t right_sum = INT64_MIN;
    current_sum = 0;
    size_t max_right = mid + 1;

    for (size_t j = mid + 1; j <= high; ++j) {
        current_sum += arr[j];
        if (current_sum > right_sum) {
            right_sum = current_sum;
            max_right = j;
        }
    }

    SubarrayResult res = {
        .low = max_left,
        .high = max_right,
        .sum = left_sum + right_sum
    };
    return res;
}

static SubarrayResult find_maximum_subarray(
    const int64_t *arr,
    size_t low,
    size_t high
) {
    if (low == high) {
        SubarrayResult base = { .low = low, .high = high, .sum = arr[low] };
        return base;
    }

    size_t mid = low + (high - low) / 2;
    SubarrayResult left_res = find_maximum_subarray(arr, low, mid);
    SubarrayResult right_res = find_maximum_subarray(arr, mid + 1, high);
    SubarrayResult cross_res = find_max_crossing_subarray(arr, low, mid, high);

    if (left_res.sum >= right_res.sum && left_res.sum >= cross_res.sum) {
        return left_res;
    }
    if (right_res.sum >= left_res.sum && right_res.sum >= cross_res.sum) {
        return right_res;
    }
    return cross_res;
}

int main(void) {
    const int64_t arr[] = {13, -3, -25, 20, -3, -16, -23, 18, 20, -7, 12, -5, -22, 15, -4, 7};
    size_t n = sizeof(arr) / sizeof(arr[0]);
    SubarrayResult ans = find_maximum_subarray(arr, 0, n - 1);
    printf("low = %zu, high = %zu, max_sum = %" PRId64 "\n", ans.low, ans.high, ans.sum);
    return 0;
}
```
