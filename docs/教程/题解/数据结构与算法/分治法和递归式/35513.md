# 35513：Akra-Bazzi 方法求解非均匀与带对数项递归式

## 题目

使用本教程 4.5 节介绍的 **Akra-Bazzi 方法**，求解以下两个主定理无法直接适用的分治递归式渐近界：
- (a) **非均匀划分**：$T(n) = T\left(\left\lfloor \frac{n}{3} \right\rfloor\right) + T\left(\left\lfloor \frac{2n}{3} \right\rfloor\right) + cn$（其中 $c > 0$ 为常数）。
- (b) **带慢变因子（对数倒数）**：$T(n) = 2T\left(\left\lfloor \frac{n}{2} \right\rfloor\right) + \frac{n}{\ln n}$（当 $n \ge 2$ 时）。

请写出确定临界幂次 $p$ 的特征方程、验证多项式增长条件，并给出积分渐近估计的完整推导过程。

## 解析

### 1. Akra-Bazzi 方法通用框架

对于形如：

$$T(x) = \sum_{i=1}^{k} a_i T(b_i x) + g(x)$$

的分治递归式（其中 $a_i > 0, 0 < b_i < 1$），Akra-Bazzi 定理给出了求解渐近界的一般方法。其核心步骤包括：
1. **确定特征幂次 $p$**：解代数特征方程：
   $$\sum_{i=1}^{k} a_i b_i^p = 1$$
   由于函数 $f(p) = \sum_{i=1}^k a_i b_i^p$ 在实数集 $\mathbb{R}$ 上严格单调递减，该方程必然存在且仅存在唯一的实数解 $p$。
2. **验证增长条件**：验证驱动函数 $g(x)$ 满足多项式增长条件（即存在正常数 $c_1, c_2$ 使得对任意 $u \in [b_i x, x]$ 有 $c_1 g(x) \le g(u) \le c_2 g(x)$；或者满足一阶导数 $|g'(x)| \le C x^m$）。
3. **求解积分通解**：
   $$T(x) = \Theta\left(x^p \left(1 + \int_{x_0}^x \frac{g(u)}{u^{p+1}} \, du\right)\right)$$
   （积分下限 $x_0 \ge 1$ 选取在使被积函数有定义且非奇异的常数处即可）。由于 Akra-Bazzi 定理允许子问题规模存在 $O(x / \log^{1+\epsilon} x)$ 的扰动，取整函数 $\lfloor \cdot \rfloor$ 和 $\lceil \cdot \rceil$ 均被该方法完全吸收，不影响最终渐近阶。

---

### 2. 求解问题 (a)：非均匀划分递归式

$$T(n) = T\left(\left\lfloor \frac{n}{3} \right\rfloor\right) + T\left(\left\lfloor \frac{2n}{3} \right\rfloor\right) + cn$$

#### 步骤 1：参数匹配与条件验证
- 参数：$k = 2$；$a_1 = 1, b_1 = \frac{1}{3}$；$a_2 = 1, b_2 = \frac{2}{3}$。
- 驱动函数：$g(n) = cn$（$c > 0$ 为常数）。
- 多项式增长条件：$g'(u) = c = O(1)$，对任意 $u \in [n/3, n]$ 均有 $\frac{1}{3} g(n) \le g(u) \le g(n)$，多项式增长条件严格满足。

#### 步骤 2：建立并求解特征方程
根据特征方程定义：

$$a_1 b_1^p + a_2 b_2^p = 1 \implies \left(\frac{1}{3}\right)^p + \left(\frac{2}{3}\right)^p = 1$$

设函数 $f(p) = \left(\frac{1}{3}\right)^p + \left(\frac{2}{3}\right)^p$。
代入 $p = 1$：

$$f(1) = \frac{1}{3} + \frac{2}{3} = 1$$

由于底数 $\frac{1}{3}, \frac{2}{3} \in (0, 1)$，$f(p)$ 是严格单调递减函数，因此特征方程的唯一实根为：

$$p = 1$$

#### 步骤 3：积分渐近估计
将 $p = 1$ 与 $g(u) = cu$ 代入 Akra-Bazzi 通解公式：

$$T(n) = \Theta\left(n^1 \left(1 + \int_1^n \frac{g(u)}{u^{1+1}} \, du\right)\right) = \Theta\left(n \left(1 + \int_1^n \frac{cu}{u^2} \, du\right)\right)$$

计算被积函数积分：

$$\int_1^n \frac{cu}{u^2} \, du = c \int_1^n \frac{1}{u} \, du = c [\ln u]_1^n = c \ln n$$

将其代入通解：

$$T(n) = \Theta(n (1 + c \ln n)) = \Theta(n \log n)$$

**直观解释**：虽然子问题划分不对称（左支递归步长为 $1/3$，右支为 $2/3$），但每一层所有子问题的总规模之和恒为 $\frac{n}{3} + \frac{2n}{3} = n$。递归树非叶节点的每层总代价始终为 $cn$，递归树的最浅叶子深度为 $\log_3 n$，最深叶子深度为 $\log_{3/2} n$。由于两者的深度均为 $\Theta(\log n)$，整棵树的总工作量保持为 $\Theta(n \log n)$。

### 3. 求解问题 (b)：带慢变对数因子的递归式

$$T(n) = 2T\left(\left\lfloor \frac{n}{2} \right\rfloor\right) + \frac{n}{\ln n} \quad (n \ge 2)$$

#### 步骤 1：主定理失效原因分析
若试图直接套用经典主定理：
- 参数为 $a = 2, b = 2$，临界多项式为 $n^{\log_b a} = n^{\log_2 2} = n^1 = n$。
- 驱动函数为 $f(n) = \frac{n}{\ln n} = n (\ln n)^{-1}$。
- **检验情况 1**：要求存在 $\epsilon > 0$ 使得 $f(n) = O(n^{1-\epsilon})$。但对于任意 $\epsilon > 0$：
  $$\lim_{n \to \infty} \frac{n / \ln n}{n^{1-\epsilon}} = \lim_{n \to \infty} \frac{n^\epsilon}{\ln n} = \infty$$
  因此多项式差异条件不成立。
- **检验情况 2**：经典主定理情况 2 扩展要求 $f(n) = \Theta(n \log^k n)$ 且 $k \ge 0$。在此题中对数项的指数为 $k = -1 < 0$，经典情况 2 失效。
- **检验情况 3**：要求 $f(n) = \Omega(n^{1+\epsilon})$，同样不满足。

因此，主定理无法求解该递归式。

#### 步骤 2：Akra-Bazzi 方法求解
- 参数：$k = 1$；$a_1 = 2, b_1 = \frac{1}{2}$；驱动函数 $g(n) = \frac{n}{\ln n}$（当 $n \ge 2$ 时）。
- 增长条件检验：对任意 $u \in [n/2, n]$，由于对数函数增长极为缓慢，有 $\frac{1}{2} \frac{n}{\ln n} \le \frac{u}{\ln u} \le \frac{n}{\ln n - \ln 2} \le 2 \frac{n}{\ln n}$，多项式增长条件成立。
- 确定特征幂次 $p$：
  $$a_1 b_1^p = 1 \implies 2 \cdot \left(\frac{1}{2}\right)^p = 1 \implies \left(\frac{1}{2}\right)^{p-1} = 1 \implies p = 1$$

#### 步骤 3：积分渐近估计
选取积分下限 $x_0 = 2$（避开 $\ln 1 = 0$ 导致的奇点）：

$$T(n) = \Theta\left(n^1 \left(1 + \int_2^n \frac{g(u)}{u^{1+1}} \, du\right)\right) = \Theta\left(n \left(1 + \int_2^n \frac{u / \ln u}{u^2} \, du\right)\right)$$

化简被积表达式：

$$\frac{u / \ln u}{u^2} = \frac{1}{u \ln u}$$

采用换元积分法，令 $v = \ln u$，则微分关系为 $dv = \frac{1}{u} \, du$。积分限从 $u = 2$（对应 $v = \ln 2$）到 $u = n$（对应 $v = \ln n$）：

$$\int_2^n \frac{1}{u \ln u} \, du = \int_{\ln 2}^{\ln n} \frac{1}{v} \, dv = \left[ \ln v \right]_{\ln 2}^{\ln n} = \ln(\ln n) - \ln(\ln 2)$$

将积分结果代入渐近通解中：

$$T(n) = \Theta\Big(n \big(1 + \ln(\ln n) - \ln(\ln 2)\big)\Big) = \Theta(n \log \log n)$$

## 答案

1. 对于递归式 $T(n) = T\left(\left\lfloor \frac{n}{3} \right\rfloor\right) + T\left(\left\lfloor \frac{2n}{3} \right\rfloor\right) + cn$：
   - 特征方程为 $\left(\frac{1}{3}\right)^p + \left(\frac{2}{3}\right)^p = 1$，求得特征幂次 $p = 1$；
   - 渐近解为：
     $$T(n) = \Theta(n \log n)$$

2. 对于递归式 $T(n) = 2T\left(\left\lfloor \frac{n}{2} \right\rfloor\right) + \frac{n}{\ln n}$：
   - 特征方程为 $2 \cdot \left(\frac{1}{2}\right)^p = 1$，求得特征幂次 $p = 1$；
   - 通过积分 $\int_2^n \frac{1}{u \ln u} \, du = \ln \ln n - \ln \ln 2$ 得到渐近解为：
     $$T(n) = \Theta(n \log \log n)$$
