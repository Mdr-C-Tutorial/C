# 30510：最短生产时间

## 题目

若干台机器并行生产产品，求生产至少目标数量产品所需的最短时间。

## 解析

给定时间 `time`，第 `i` 台机器能生产：

```text
time / machine_times[i]
```

“能否达到目标”随时间单调变化，因此可以二分答案。为了避免累计产量溢出，不维护总和，而是维护尚缺的数量：单台产量已经不小于剩余数量时立即成功，否则从剩余数量中扣除。

上界从 1 开始倍增，并在即将溢出时饱和到 `UINT64_MAX`。如果最大可表示时间仍不能完成目标，答案便无法用返回类型表示。

## 解析

```c
#include <stdbool.h>
#include <stddef.h>
#include <stdint.h>

static bool production_reaches(
    const uint64_t *machine_times,
    size_t machine_count,
    uint64_t target,
    uint64_t time
) {
    uint64_t remaining = target;

    for (size_t i = 0; i < machine_count; ++i) {
        uint64_t produced = time / machine_times[i];
        if (produced >= remaining) {
            return true;
        }
        remaining -= produced;
    }
    return false;
}

bool minimum_production_time(
    const uint64_t *machine_times,
    size_t machine_count,
    uint64_t target,
    uint64_t *out_time
) {
    if (out_time == NULL ||
        (machine_count > 0 && machine_times == NULL)) {
        return false;
    }

    if (target == 0) {
        *out_time = 0;
        return true;
    }
    if (machine_count == 0) {
        return false;
    }

    for (size_t i = 0; i < machine_count; ++i) {
        if (machine_times[i] == 0) {
            return false;
        }
    }

    uint64_t high = 1;
    while (!production_reaches(
        machine_times,
        machine_count,
        target,
        high
    )) {
        if (high == UINT64_MAX) {
            return false;
        }
        high = high > UINT64_MAX / 2
            ? UINT64_MAX
            : high * 2;
    }

    uint64_t low = 0;
    while (low < high) {
        uint64_t middle = low + (high - low) / 2;

        if (production_reaches(
            machine_times,
            machine_count,
            target,
            middle
        )) {
            high = middle;
        } else {
            low = middle + 1;
        }
    }

    *out_time = low;
    return true;
}
```
