# 35504：换元法求解平方根规模递归式

## 题目

使用换元法，求解递归式 $T(n) = T(\sqrt{n}) + \Theta(\lg \lg n)$ 的时间复杂度。

## 解析

递归式中的子问题规模为 $\sqrt{n} = n^{1/2}$，每次递归会使对数规模 $\lg n$ 减半。通过引入第一次换元参量 $m = \lg n$，可将幂次开方转化为线性折半 $m / 2$；再引入第二次换元参量 $k = \lg m = \lg \lg n$，即可进一步将其转化为步长为 $1$ 的线性递推式进行求和。

## 答案

1. **第一次换元**：
   令换元参量 $m = \lg n$，则 $n = 2^m$，且 $\sqrt{n} = 2^{m/2}$，$\lg \lg n = \lg m$。将原递归式改写为关于 $m$ 的形式：
   $$T(2^m) = T(2^{m/2}) + \Theta(\lg m)$$
   定义辅助函数 $S(m) = T(2^m)$，则 $S(m)$ 满足递归式：
   $$S(m) = S(m / 2) + \Theta(\lg m)$$

2. **第二次换元**：
   令换元参量 $k = \lg m = \lg \lg n$，则 $m = 2^k$，且 $m / 2 = 2^{k-1}$。代入 $S(m)$ 的递归式得：
   $$S(2^k) = S(2^{k-1}) + \Theta(k)$$
   定义辅助函数 $R(k) = S(2^k)$，则 $R(k)$ 满足线性递推式：
   $$R(k) = R(k - 1) + \Theta(k)$$

3. **展开求和并回代**：
   对 $R(k)$ 逐层累加展开，由算术级数求和公式 $\sum_{i=1}^{k} i = \frac{k(k+1)}{2} = \Theta(k^2)$ 可得：
   $$R(k) = R(0) + \sum_{i = 1}^{k} \Theta(i) = \Theta(k^2)$$
   将 $k = \lg m$ 与 $m = \lg n$ 依次回代，最终得到原递归式的时间复杂度为：
   $$T(n) = S(m) = R(k) = \Theta(k^2) = \Theta((\lg \lg n)^2)$$
