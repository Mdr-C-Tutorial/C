# 35511：平面最近点对的分治算法实现

## 题目

本教程 6.1 节详细介绍了二维平面最近点对（Closest Pair of Points）的分治算法。
- (a) **算法设计**：简述如何在分治递归树的各层中，利用归并排序的合并过程在线性时间 $O(n)$ 内维护按 $y$ 坐标排序的点数组，从而避免在带状跨界区域检查时重复调用排序，使整个分治算法的时间复杂度达到严格的 $O(n \log n)$。
- (b) **几何约束证明**：证明在宽度为 $2d$ 的带状区域内，对每个位于左侧带状区域的点 $p$，右侧带状区域中与 $p$ 的 $y$ 坐标差不超过 $d$ 的点至多有几个？为什么在按 $y$ 坐标排序后，内层扫描循环至多只需检查后续的 7 个点？
- (c) **C 语言实现**：编写完整的 C17 语言实现。定义点结构体 `Point`，实现 $O(n \log n)$ 的分治算法，在计算点间欧几里得距离时避免浮点平方根精度损失，并提供自包含的验证代码。

## 解析

### 1. 分治框架与归并过程结合（避免重复排序）

在最近点对的分治算法中，通常先将所有点按 $x$ 坐标升序预排序。若在递归基出口或各层递归合并时，直接调用快速排序（如 `qsort`）对垂直带状区域内的候选点按 $y$ 坐标重新排序，该层的排序开销为 $O(n \log n)$，导致总时间复杂度递推式退化为：

$$T(n) = 2T(n/2) + O(n \log n) \implies T(n) = O(n \log^2 n)$$

为了消除这层额外的对数因子，可以将**归并排序（Merge Sort）的排序过程直接内嵌到分治递归**中：
1. 递归函数同时维护一个点数组切片，使其在当前递归区间 $[left, right]$ 返回时，不仅求得该区间内部的最近点对距离，同时保证该区间内的所有点**已经按 $y$ 坐标升序排列**。
2. 当递归划分到子问题规模 $count \le 3$ 时，直接通过暴力比较找出局部最近点对，并使用简单的插入排序按 $y$ 坐标排好序后返回。
3. 当子问题规模较大时，先递归求解左半区间 $[left, mid]$ 与右半区间 $[mid+1, right]$。递归返回后，左右两个子区间的点已各自按 $y$ 坐标有序。
4. 随后，只需执行双指针线性归并（耗时 $O(n)$），即可把两个 $y$ 序子数组合并为一个完整的按 $y$ 坐标升序排列的连续数组。
5. 在归并的同时或归并完成后，线性扫描该有序数组，筛选出与中轴线横坐标之差的绝对值小于当前最短距离 $d$ 的点，构建带状候选数组。

因为构建带状点集和合并 $y$ 序均仅耗时 $O(n)$，带状区域的点间比对同样在 $O(n)$ 内完成，递归树每层的合并代价严格为 $O(n)$：

$$T(n) = 2T(n/2) + O(n)$$

由主定理情况 2 可知，整体时间复杂度为严格的 $\Theta(n \log n)$。

### 2. 几何稀疏性约束与 7 点界限证明

设左半部分与右半部分递归求解出的最小距离分别为 $d_L$ 和 $d_R$，令 $d = \min(d_L, d_R)$。跨越分割线 $L: x = x_{\text{mid}}$ 的点对距离若小于 $d$，其两点横坐标必同时落在区间 $[x_{\text{mid}} - d, x_{\text{mid}} + d]$ 内。

考虑带状区域内的任意一个点 $p = (x_p, y_p)$：
- 若仅考虑 $y$ 坐标不小于 $y_p$ 的后续点（按 $y$ 升序遍历，两点间距离只需在较小 $y$ 处的点访问时被计算一次），则候选点 $q = (x_q, y_q)$ 的坐标范围被限制在一个矩形区域 $R$ 内：
  $$R = [x_{\text{mid}} - d, \, x_{\text{mid}} + d] \times [y_p, \, y_p + d]$$
  该矩形的水平宽度为 $2d$，垂直高度为 $d$。

- 将矩形 $R$ 沿分割线 $x = x_{\text{mid}}$ 划分为左、右两个半区：
  $$R_L = [x_{\text{mid}} - d, \, x_{\text{mid}}] \times [y_p, \, y_p + d], \quad R_R = [x_{\text{mid}}, \, x_{\text{mid}} + d] \times [y_p, \, y_p + d]$$
  $R_L$ 与 $R_R$ 均为边长为 $d \times d$ 的正方形。

- **子区域点数上界分析（抽屉原理）**：
  以右侧正方形 $R_R$ 为例，由于 $R_R$ 中的所有点在分治过程中均属于右侧子集，右侧子集中任意两点之间的欧几里得距离至少为 $d_R \ge d$。
  将 $R_R$ 等分成 4 个边长为 $d/2 \times d/2$ 的互不重叠的小正方形。每个小正方形的对角线长度为：
  $$\sqrt{\left(\frac{d}{2}\right)^2 + \left(\frac{d}{2}\right)^2} = \frac{\sqrt{2}}{2} d \approx 0.707 d < d$$
  根据鸽巢原理（抽屉原理），如果任意一个小正方形内包含 2 个或更多的点，则这两点之间的距离至多等于小正方形对角线长，必严格小于 $d$，这与右侧子集中任意两点距离 $\ge d$ 矛盾！
  因此，每个边长为 $d/2$ 的小正方形内部至多只能容纳 1 个点，整个 $d \times d$ 的正方形 $R_R$ 内至多存在 $4$ 个点。

- **整体候选点上限**：
  同理，$R_L$ 内部至多也只能容纳 4 个点。整个宽度为 $2d$、高度为 $d$ 的带状矩形 $R$ 内总共至多只能包含 $4 + 4 = 8$ 个点。
  由于点 $p$ 自身已经占据了这 8 个位置中的 1 个，因此在矩形 $R$ 内，除 $p$ 自身外，其余所有点（无论位于左半区还是右半区）的数量至多只有 $8 - 1 = 7$ 个。

- **算法遍历终止条件**：
  当候选带状点集按 $y$ 坐标升序排列后，对于任意点 $p_i$，内层循环按升序检查后续点 $p_j$（$j > i$）。一旦遇到 $y_j - y_i \ge d$，由几何单调性可知后续所有点的纵坐标差均不小于 $d$，内层扫描可立即 `break` 终止。几何稀疏性证明了在跳出循环之前，检查的候选点数量**绝对不会超过 7 个**。因此，内层循环的实际执行次数至多为常数 7，保证了合并阶段线性的比较代价。

### 3. C 语言工程实现设计

- **避免浮点开方损失**：在点间欧几里得距离比较过程中，由于开方 $\sqrt{dx^2 + dy^2}$ 存在单精度/双精度舍入误差，直接使用坐标差的平方和作为距离度量：
  $$\text{dist\_sq} = (\Delta x)^2 + (\Delta y)^2$$
  当两点坐标均为 $64$ 位有符号整数时，$\Delta x \le 2 \times 10^9$，平方和不会超出 `uint64_t` 的表示范围。内层扫描时，终止条件 $y_j - y_i \ge d$ 等价于 $(y_j - y_i)^2 \ge d^2$。
- **内存生命周期管理**：在分治入口处一次性分配所需的临时缓冲区对象（`temp_y` 等），避免在递归深层频繁调用 `malloc`/`free`，提升缓存局部性并降低动态分配开销。

## 答案

```c
#include <assert.h>
#include <inttypes.h>
#include <stdbool.h>
#include <stddef.h>
#include <stdint.h>
#include <stdio.h>
#include <stdlib.h>

typedef struct {
    int64_t x;
    int64_t y;
} Point;

typedef struct {
    Point p1;
    Point p2;
    uint64_t dist_sq;
} ClosestPairResult;

static inline uint64_t calc_dist_sq(Point a, Point b) {
    int64_t dx = a.x - b.x;
    int64_t dy = a.y - b.y;
    return (uint64_t)(dx * dx) + (uint64_t)(dy * dy);
}

static int cmp_point_x(const void *lhs, const void *rhs) {
    const Point *a = (const Point *)lhs;
    const Point *b = (const Point *)rhs;
    if (a->x != b->x) {
        return (a->x < b->x) ? -1 : 1;
    }
    if (a->y != b->y) {
        return (a->y < b->y) ? -1 : 1;
    }
    return 0;
}

static ClosestPairResult closest_pair_rec(
    Point *pts_x,
    Point *pts_y,
    Point *temp_y,
    size_t left,
    size_t right
) {
    ClosestPairResult best;
    size_t count = right - left + 1;

    // 递归基：子问题规模不超过 3 时直接暴力求解
    if (count <= 3) {
        best.dist_sq = UINT64_MAX;
        best.p1 = pts_x[left];
        best.p2 = pts_x[left + 1];

        for (size_t i = left; i <= right; ++i) {
            for (size_t j = i + 1; j <= right; ++j) {
                uint64_t d2 = calc_dist_sq(pts_x[i], pts_x[j]);
                if (d2 < best.dist_sq) {
                    best.dist_sq = d2;
                    best.p1 = pts_x[i];
                    best.p2 = pts_x[j];
                }
            }
        }

        // 将当前区间的点复制到 pts_y 中，并使用插入排序按 y 坐标升序排列
        for (size_t i = left; i <= right; ++i) {
            pts_y[i] = pts_x[i];
        }
        for (size_t i = left + 1; i <= right; ++i) {
            Point key = pts_y[i];
            size_t k = i;
            while (k > left && pts_y[k - 1].y > key.y) {
                pts_y[k] = pts_y[k - 1];
                --k;
            }
            pts_y[k] = key;
        }
        return best;
    }

    size_t mid = left + (right - left) / 2;
    int64_t mid_x = pts_x[mid].x;

    // 递归求解左右两部分
    ClosestPairResult res_l = closest_pair_rec(pts_x, pts_y, temp_y, left, mid);
    ClosestPairResult res_r = closest_pair_rec(pts_x, pts_y, temp_y, mid + 1, right);

    best = (res_l.dist_sq < res_r.dist_sq) ? res_l : res_r;
    uint64_t delta_sq = best.dist_sq;

    // 双指针线性归并：将已按 y 有序的左右两段合并到 temp_y 中，随后同步回 pts_y
    size_t i = left;
    size_t j = mid + 1;
    size_t k = left;
    while (i <= mid && j <= right) {
        if (pts_y[i].y <= pts_y[j].y) {
            temp_y[k++] = pts_y[i++];
        } else {
            temp_y[k++] = pts_y[j++];
        }
    }
    while (i <= mid) {
        temp_y[k++] = pts_y[i++];
    }
    while (j <= right) {
        temp_y[k++] = pts_y[j++];
    }
    for (size_t idx = left; idx <= right; ++idx) {
        pts_y[idx] = temp_y[idx];
    }

    // 提取横坐标与 mid_x 之差小于 delta 的跨界带状候选点
    size_t strip_count = 0;
    for (size_t idx = left; idx <= right; ++idx) {
        int64_t dx = pts_y[idx].x - mid_x;
        if ((uint64_t)(dx * dx) < delta_sq) {
            temp_y[strip_count++] = pts_y[idx];
        }
    }

    // 检查带状区域内的所有候选点，几何稀疏性保证内层循环至多执行 7 次
    for (size_t p = 0; p < strip_count; ++p) {
        for (size_t q = p + 1; q < strip_count; ++q) {
            int64_t dy = temp_y[q].y - temp_y[p].y;
            if ((uint64_t)(dy * dy) >= delta_sq) {
                break;
            }
            uint64_t d2 = calc_dist_sq(temp_y[p], temp_y[q]);
            if (d2 < best.dist_sq) {
                best.dist_sq = d2;
                best.p1 = temp_y[p];
                best.p2 = temp_y[q];
                delta_sq = d2;
            }
        }
    }

    return best;
}

bool find_closest_pair(
    const Point *points,
    size_t n,
    Point *out_p1,
    Point *out_p2,
    uint64_t *out_dist_sq
) {
    if (points == NULL || n < 2 || out_p1 == NULL || out_p2 == NULL || out_dist_sq == NULL) {
        return false;
    }

    Point *pts_x = malloc(n * sizeof *pts_x);
    Point *pts_y = malloc(n * sizeof *pts_y);
    Point *temp_y = malloc(n * sizeof *temp_y);
    if (pts_x == NULL || pts_y == NULL || temp_y == NULL) {
        free(pts_x);
        free(pts_y);
        free(temp_y);
        return false;
    }

    for (size_t i = 0; i < n; ++i) {
        pts_x[i] = points[i];
    }
    qsort(pts_x, n, sizeof(Point), cmp_point_x);

    ClosestPairResult res = closest_pair_rec(pts_x, pts_y, temp_y, 0, n - 1);

    free(pts_x);
    free(pts_y);
    free(temp_y);

    *out_p1 = res.p1;
    *out_p2 = res.p2;
    *out_dist_sq = res.dist_sq;
    return true;
}

// 暴力比较算法，用于单元测试校验结果
static uint64_t brute_force_closest(const Point *pts, size_t n) {
    uint64_t min_d2 = UINT64_MAX;
    for (size_t i = 0; i < n; ++i) {
        for (size_t j = i + 1; j < n; ++j) {
            uint64_t d2 = calc_dist_sq(pts[i], pts[j]);
            if (d2 < min_d2) {
                min_d2 = d2;
            }
        }
    }
    return min_d2;
}

int main(void) {
    Point pts[] = {
        {2, 3}, {12, 30}, {40, 50}, {5, 1}, {12, 10}, {3, 4}
    };
    size_t n = sizeof(pts) / sizeof(pts[0]);

    Point p1, p2;
    uint64_t d2;
    bool ok = find_closest_pair(pts, n, &p1, &p2, &d2);
    assert(ok);
    assert(d2 == brute_force_closest(pts, n));
    assert(d2 == 2); // 点 (2, 3) 与 (3, 4) 的平方距离为 1^2 + 1^2 = 2

    // 随机数据集对拍校验
    const size_t test_n = 200;
    Point random_pts[200];
    srand(42);
    for (size_t i = 0; i < test_n; ++i) {
        random_pts[i].x = (rand() % 2000) - 1000;
        random_pts[i].y = (rand() % 2000) - 1000;
    }
    uint64_t expected = brute_force_closest(random_pts, test_n);
    ok = find_closest_pair(random_pts, test_n, &p1, &p2, &d2);
    assert(ok);
    assert(d2 == expected);

    printf("平面最近点对分治算法测试全部通过！最小平方距离: %" PRIu64 "\n", d2);
    return 0;
}
```
