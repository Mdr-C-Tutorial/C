# 35506：基于归并排序统计数组逆序对总数

## 题目

在一个数组 $A[1 \dots n]$ 中，如果存在 $i < j$ 且 $A[i] > A[j]$，则称 $(i, j)$ 是一个**逆序对**。请设计一个分治算法来计算一个数组中逆序对的总数。
   - **提示**：尝试修改**归并排序**算法。在 `merge()` 过程中，当右边子数组的元素 `R[j]` 被复制回原数组时，左边子数组 `L` 中还剩下多少个元素？这与逆序对有什么关系？
   - 分析你的算法的时间复杂度。

## 解析

### 1. 分治思想与合并阶段的逆序对计数

设当前区间为 $A[p \dots r]$，中点为 $\text{mid} = \lfloor (p + r) / 2 \rfloor$。区间内的任意逆序对 $(i, j)$（满足 $p \le i < j \le r$ 且 $A[i] > A[j]$）必属于以下三类之一，且三类互不重叠：
1. **左半区间内部逆序对**：$p \le i < j \le \text{mid}$；
2. **右半区间内部逆序对**：$\text{mid} + 1 \le i < j \le r$；
3. **跨越中点的逆序对**：$p \le i \le \text{mid} < j \le r$ 且 $A[i] > A[j]$。

递归调用归并排序在对左右子数组 $L = A[p \dots \text{mid}]$（长度为 $n_1$）和 $R = A[\text{mid} + 1 \dots r]$（长度为 $n_2$）完成排序的同时，可以分别返回第 1 类和第 2 类逆序对的数量。关键在于如何在 `merge()` 合并两个**已经各自按非递减顺序排好序**的子数组 $L[0 \dots n_1 - 1]$ 和 $R[0 \dots n_2 - 1]$ 时，精确统计第 3 类跨越中点的逆序对：

- 当左游标位于 $i$、右游标位于 $j$ 时：
  - 若 $L[i] \le R[j]$，说明 $L[i]$ 不大于右侧尚未合并的任何元素 $R[j \dots n_2 - 1]$，故 $L[i]$ 不会与剩余的右侧元素构成逆序对，直接将 $L[i]$ 放入结果数组并将 $i$ 加 $1$（注意当 $L[i] == R[j]$ 时必须优先取 $L[i]$，以保证相等元素不会被误计为逆序对）。
  - 若 $L[i] > R[j]$，由于左半子数组 $L$ 已经非递减有序，从当前下标 $i$ 到末尾 $n_1 - 1$ 的所有剩余元素满足：
    $$L[n_1 - 1] \ge \dots \ge L[i + 1] \ge L[i] > R[j]$$
    这意味着左边子数组 $L$ 中当前剩余的全部 $n_1 - i$ 个元素都严格大于 $R[j]$，它们各自都与 $R[j]$ 构成一个跨越中点的逆序对。因此，将 $R[j]$ 复制回数组时，逆序对累加器直接加上 $n_1 - i$，随后将 $j$ 加 $1$。

因为每个右侧元素 $R[j]$ 被复制回原数组恰好一次，它与左侧所有元素构成的逆序对就在这一瞬间被一次性计入，不重不漏。

### 2. 时间与空间复杂度分析

在 `merge()` 过程中，每次比较后仅增加一步常数时间 $\Theta(1)$ 的加法操作 `inversions += (n1 - i)`，合并长度为 $n$ 的子区间依然只需 $\Theta(n)$ 时间。因此算法运行时间的递归式仍为：

$$T(n) = 2T(n / 2) + \Theta(n)$$

由主定理情况 2 可知，总时间复杂度为 $\Theta(n \lg n)$，额外辅助空间复杂度为 $\Theta(n)$（优于朴素双重循环枚举的 $\Theta(n^2)$）。

## 答案

```c
#include <inttypes.h>
#include <stddef.h>
#include <stdint.h>
#include <stdio.h>
#include <stdlib.h>

static uint64_t merge_and_count(
    int *arr,
    int *temp,
    size_t left,
    size_t mid,
    size_t right
) {
    size_t i = left;
    size_t j = mid + 1;
    size_t k = left;
    uint64_t inv_count = 0;

    while (i <= mid && j <= right) {
        if (arr[i] <= arr[j]) {
            temp[k++] = arr[i++];
        } else {
            temp[k++] = arr[j++];
            inv_count += (uint64_t)(mid - i + 1);
        }
    }
    while (i <= mid) {
        temp[k++] = arr[i++];
    }
    while (j <= right) {
        temp[k++] = arr[j++];
    }
    for (size_t idx = left; idx <= right; ++idx) {
        arr[idx] = temp[idx];
    }
    return inv_count;
}

static uint64_t sort_and_count(
    int *arr,
    int *temp,
    size_t left,
    size_t right
) {
    if (left >= right) {
        return 0;
    }
    size_t mid = left + (right - left) / 2;
    uint64_t inv_count = 0;
    inv_count += sort_and_count(arr, temp, left, mid);
    inv_count += sort_and_count(arr, temp, mid + 1, right);
    inv_count += merge_and_count(arr, temp, left, mid, right);
    return inv_count;
}

uint64_t count_inversions(int *arr, size_t n) {
    if (arr == NULL || n < 2) {
        return 0;
    }
    int *temp = malloc(n * sizeof *temp);
    if (temp == NULL) {
        return 0;
    }
    uint64_t total = sort_and_count(arr, temp, 0, n - 1);
    free(temp);
    return total;
}

int main(void) {
    int arr[] = {2, 3, 8, 6, 1};
    size_t n = sizeof(arr) / sizeof(arr[0]);
    uint64_t inversions = count_inversions(arr, n);
    printf("Inversions = %" PRIu64 "\n", inversions);
    return 0;
}
```
