# 31903 - 前缀频次统计与通配符模糊搜索

## 题目

在字典树上实现单词前缀出现频次的高效聚合统计，并支持包含单个字符通配符 `.`（匹配任意一个有效小写字母）的模糊模式串检索：

```c
#include <stdbool.h>
#include <stddef.h>

typedef struct WildcardTrie WildcardTrie;

WildcardTrie *wildcard_trie_create(void);
void wildcard_trie_destroy(WildcardTrie *trie);
bool wildcard_trie_insert(WildcardTrie *trie, const char *word);
size_t wildcard_trie_prefix_count(const WildcardTrie *trie, const char *prefix);
bool wildcard_trie_search(const WildcardTrie *trie, const char *pattern);
```

要求：

1. 单词由 ASCII 小写字母 `'a'` 到 `'z'` 组成。每个节点维护字段 `prefix_count`，记录有多少个已插入单词的前缀经过该节点。
2. `wildcard_trie_insert`：将新单词插入树中，沿途每个节点的 `prefix_count` 均自增 1，词尾节点标记为单词结尾。
3. `wildcard_trie_prefix_count`：在严格 $O(|prefix|)$ 时间内直接返回以 `prefix` 为前缀的已录入单词总数；若前缀在树中不存在则返回 0。
4. `wildcard_trie_search`：模式串 `pattern` 中除小写字母外还可包含字符 `.`（点号）。点号可通配任意一个存在的分支。利用深度优先回溯遍历（DFS）进行多路分支探索，若存在任何一条完全匹配的单词路径则返回 `true`。
5. 详细说明深度优先搜索在通配符递归剪枝中的终止条件与正确性保障。

## 解题思路

### 1. 前缀计数器的聚合传播

在常规 Trie 中，若要统计以某个字符串为前缀的单词数量，需要遍历以该前缀终点为根的整棵子树并累加所有叶节点的个数，耗时取决于子树规模。
通过在每个节点引入计数器 `prefix_count`：
- 当一个单词沿路径 $c_1 c_2 \dots c_L$ 插入时，将根节点及沿途经过的每一个节点的 `prefix_count` 均增加 1；
- 查询前缀 `prefix` 时，只需沿字符分支走到前缀的终点节点，直接读取该节点的 `prefix_count` 即可在 $O(|prefix|)$ 常数级步数内得到答案，完全无需遍历子树。

### 2. 通配符 `.` 的深度优先回溯搜索

当检索模式串 `pattern` 包含通配符 `.` 时，控制流由单分支确定性下潜演变为多分支搜索树：
- **普通字母 $ch \in ['a', 'z']$**：仅有一条确定分支 $idx = ch - 'a'$，若对应子节点非空则继续递归下一步，否则该分支失败截断；
- **通配符 $ch == '.'$**：由于点号可以代表当前层级出现的任意字符，算法必须遍历当前节点的所有 26 个子指针槽位，对每一个非空的子节点发起深度优先递归探测：
  ```c
  if (ch == '.') {
      for (int i = 0; i < 26; ++i) {
          if (curr->children[i] && dfs_match(curr->children[i], pattern, pos + 1)) {
              return true; // 只要任一分支命中，即可提前短路成功返回
          }
      }
      return false;
  }
  ```
- **递归基终止条件**：当模式串指针走完末尾 `\0` 时，当前节点必须满足 `is_word == true` 才算一次成功的全词匹配。

## C 语言实现

```c
#include <assert.h>
#include <stdbool.h>
#include <stddef.h>
#include <stdint.h>
#include <stdio.h>
#include <stdlib.h>

enum { ALPHA_SIZE = 26 };

typedef struct WildcardNode WildcardNode;

struct WildcardNode {
    WildcardNode *children[ALPHA_SIZE];
    size_t prefix_count;
    bool is_word;
};

typedef struct WildcardTrie WildcardTrie;

struct WildcardTrie {
    WildcardNode *root;
};

static void destroy_wnode(WildcardNode *n) {
    if (n == NULL) {
        return;
    }
    for (int i = 0; i < ALPHA_SIZE; ++i) {
        destroy_wnode(n->children[i]);
    }
    free(n);
}

WildcardTrie *wildcard_trie_create(void) {
    WildcardTrie *t = malloc(sizeof *t);
    if (t == NULL) {
        return NULL;
    }
    t->root = calloc(1, sizeof *t->root);
    if (t->root == NULL) {
        free(t);
        return NULL;
    }
    return t;
}

void wildcard_trie_destroy(WildcardTrie *t) {
    if (t == NULL) {
        return;
    }
    destroy_wnode(t->root);
    free(t);
}

bool wildcard_trie_insert(WildcardTrie *t, const char *word) {
    if (t == NULL || word == NULL) {
        return false;
    }
    for (size_t i = 0; word[i] != '\0'; ++i) {
        if (word[i] < 'a' || word[i] > 'z') {
            return false;
        }
    }

    WildcardNode *curr = t->root;
    curr->prefix_count++;
    for (size_t i = 0; word[i] != '\0'; ++i) {
        int idx = word[i] - 'a';
        if (curr->children[idx] == NULL) {
            curr->children[idx] = calloc(1, sizeof(WildcardNode));
            if (curr->children[idx] == NULL) {
                return false;
            }
        }
        curr = curr->children[idx];
        curr->prefix_count++;
    }
    curr->is_word = true;
    return true;
}

size_t wildcard_trie_prefix_count(const WildcardTrie *t, const char *prefix) {
    if (t == NULL || prefix == NULL) {
        return 0;
    }
    const WildcardNode *curr = t->root;
    for (size_t i = 0; prefix[i] != '\0'; ++i) {
        if (prefix[i] < 'a' || prefix[i] > 'z') {
            return 0;
        }
        int idx = prefix[i] - 'a';
        if (curr->children[idx] == NULL) {
            return 0;
        }
        curr = curr->children[idx];
    }
    return curr->prefix_count;
}

static bool dfs_match(const WildcardNode *curr, const char *pattern, size_t pos) {
    if (curr == NULL) {
        return false;
    }
    if (pattern[pos] == '\0') {
        return curr->is_word;
    }
    char ch = pattern[pos];
    if (ch == '.') {
        for (int i = 0; i < ALPHA_SIZE; ++i) {
            if (curr->children[i] != NULL && dfs_match(curr->children[i], pattern, pos + 1)) {
                return true;
            }
        }
        return false;
    } else if (ch >= 'a' && ch <= 'z') {
        int idx = ch - 'a';
        return dfs_match(curr->children[idx], pattern, pos + 1);
    }
    return false;
}

bool wildcard_trie_search(const WildcardTrie *t, const char *pattern) {
    if (t == NULL || pattern == NULL) {
        return false;
    }
    return dfs_match(t->root, pattern, 0);
}

int main(void) {
    wildcard_trie_destroy(NULL);

    WildcardTrie *t = wildcard_trie_create();
    assert(t != NULL);

    assert(wildcard_trie_insert(t, "bad"));
    assert(wildcard_trie_insert(t, "dad"));
    assert(wildcard_trie_insert(t, "mad"));
    assert(wildcard_trie_insert(t, "pad"));
    assert(wildcard_trie_insert(t, "bat"));

    assert(wildcard_trie_prefix_count(t, "ba") == 2);
    assert(wildcard_trie_prefix_count(t, "d") == 1);
    assert(wildcard_trie_prefix_count(t, "z") == 0);

    assert(!wildcard_trie_search(t, "pad."));
    assert(wildcard_trie_search(t, "bad"));
    assert(wildcard_trie_search(t, ".ad"));
    assert(wildcard_trie_search(t, "b.."));
    assert(!wildcard_trie_search(t, "..t."));
    assert(wildcard_trie_search(t, "..t"));
    assert(!wildcard_trie_search(t, "m."));

    wildcard_trie_destroy(t);
    return 0;
}
```

## 复杂度分析

- **时间复杂度**：
  - `wildcard_trie_insert` 与 `wildcard_trie_prefix_count`：沿单条分支下潜，时间复杂度严格为 $O(L)$。
  - `wildcard_trie_search`：若模式串不含通配符，为确定性下潜 $O(L)$；若模式串包含 $k$ 个通配符 `.`，最坏情况下分支因子为 26，时间复杂度为 $O(26^k \cdot L)$。实际搜索中空指针分支会触发大量剪枝，平均速度远快于全词典线性扫描。
- **空间复杂度**：每个节点包含 26 个指针槽位与一个计数器，空间复杂度为 $O(|\Sigma| \cdot \sum L)$。

## 延伸思考 / 模式总结

1. **确定有限状态自动机（DFA）的子集搜索**：通配符搜索本质上是将 Trie 作为非确定有限自动机（NFA）进行路径驱动。在现代文本引擎中，正则表达式与通配符的前缀索引均建立在该机制之上。
2. **多模式匹配与短路剪枝**：通过在 `dfs_match` 中引入 `return true` 的提前短路策略，一旦某条分支率先命中词尾，立刻终结其余 25 条可能分支的无效试探，体现了回溯算法中“搜索树剪枝”的核心威力。
