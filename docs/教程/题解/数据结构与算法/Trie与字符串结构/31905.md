# 31905 - 01-Trie与区间最大异或和求解

## 题目描述

给定一个非负整数数组，求解其所有非空连续子数组中，元素异或和（Subarray XOR Sum）的最大值。结合异或前缀和（Prefix XOR）的数学性质与 01-Trie 检索，实现在 $O(n)$ 时间内求解该问题：

```c
#include <stdbool.h>
#include <stddef.h>
#include <stdint.h>

bool max_subarray_xor(const uint32_t *nums, size_t count, uint32_t *out_max_xor);
```

要求：

1. 必须将任意连续区间 $[l, r]$ 的异或和：
   $$\text{XOR}(l, r) = \bigoplus_{i=l}^r nums[i]$$
   通过异或前缀和数学恒等式转化为两个前缀异或值之间的异或运算。
2. 内部构建 01-Trie，支持 32 位无符号整数的高位贪心查询。
3. 必须在插入任何前缀之前，**首先向 01-Trie 中插入初始哨兵值 $0$**（对应空前缀）；详细解释若缺少前缀 0 会导致何种边缘区间计算错误。
4. 算法时间复杂度严格为 $O(32 \cdot n) = O(n)$，空间复杂度严格为 $O(32 \cdot n) = O(n)$。若输入数组为空或指针参数非法，返回 `false`。

## 解题思路

### 1. 异或运算的差分逆性质

在普通加法数组中，连续区间的和通过前缀和做减法给出：
$$\sum_{i=l}^r nums[i] = S[r] - S[l - 1]$$
然而按位异或运算具有一个极其优异的代数性质：**自反性（自逆性）**：
$$x \oplus x = 0, \quad x \oplus 0 = x$$
定义异或前缀和数组 $P$：
$$P[0] = 0$$
$$P[k] = \bigoplus_{i=0}^{k-1} nums[i] \quad (1 \le k \le n)$$

考察连续子数组 $nums[l \dots r]$（$0 \le l \le r < n$）的异或和：
$$nums[l \dots r] = \left( \bigoplus_{i=0}^{l-1} nums[i] \right) \oplus \left( \bigoplus_{i=0}^{l-1} nums[i] \right) \oplus \left( \bigoplus_{i=l}^r nums[i] \right)$$
$$= P[l] \oplus P[r + 1]$$
这意味着：**任意连续子数组的异或和，等价于某两个前缀异或值的异或！**

### 2. 哨兵前缀 0 的不可或缺性

若一个最大异或和子数组恰好是从下标 0 开始的前缀区间（即 $l = 0$）：
$$nums[0 \dots r] = P[0] \oplus P[r + 1] = 0 \oplus P[r + 1] = P[r + 1]$$
如果我们在 01-Trie 中没有预先插入哨兵 $P[0] = 0$：
- 当只有单个元素构成的区间 $nums[0 \dots 0]$ 或以 0 开头的前缀区间成为全局最优解时，算法在 01-Trie 中将无法匹配到 $P[0] = 0$；
- 从而漏算所有以 0 为起点的候选子区间，导致错误答案。
因此，在遍历数组前先将 $0$ 入树，是保证边界正确性的绝对前置不变式。

### 3. 在线扫描流水线

算法执行步骤如下：
1. 创建空的 01-Trie，将前缀初始值 $0$ 插入树中；
2. 维护当前运行的异或前缀值 `prefix = 0`，全局最大异或和 `best = 0`；
3. 顺序遍历数组每个元素 $nums[i]$：
   - 更新当前前缀：`prefix ^= nums[i]`；
   - 在 01-Trie 中贪心查询与当前 `prefix` 异或结果最大的既有前缀，记为 `cur_max`；
   - 若 `cur_max > best`，更新全局最优解 `best = cur_max`；
   - 将当前 `prefix` 插入 01-Trie，作为后续更大右端点候选者的可能配对对象。

## C 语言实现

```c
#include <assert.h>
#include <stdbool.h>
#include <stddef.h>
#include <stdint.h>
#include <stdio.h>
#include <stdlib.h>

typedef struct BitTrieNode BitTrieNode;

struct BitTrieNode {
    BitTrieNode *children[2];
};

typedef struct BitTrie BitTrie;

struct BitTrie {
    BitTrieNode *root;
};

static void destroy_bit_node(BitTrieNode *n) {
    if (n == NULL) {
        return;
    }
    destroy_bit_node(n->children[0]);
    destroy_bit_node(n->children[1]);
    free(n);
}

static BitTrie *bit_trie_create(void) {
    BitTrie *t = malloc(sizeof *t);
    if (t == NULL) {
        return NULL;
    }
    t->root = calloc(1, sizeof *t->root);
    if (t->root == NULL) {
        free(t);
        return NULL;
    }
    return t;
}

static void bit_trie_destroy(BitTrie *t) {
    if (t == NULL) {
        return;
    }
    destroy_bit_node(t->root);
    free(t);
}

static bool bit_trie_insert(BitTrie *t, uint32_t val) {
    if (t == NULL) {
        return false;
    }
    BitTrieNode *curr = t->root;
    for (int i = 31; i >= 0; --i) {
        uint32_t b = (val >> i) & 1U;
        if (curr->children[b] == NULL) {
            BitTrieNode *new_node = calloc(1, sizeof(BitTrieNode));
            if (new_node == NULL) {
                return false;
            }
            curr->children[b] = new_node;
        }
        curr = curr->children[b];
    }
    return true;
}

static uint32_t bit_trie_query_max_xor(const BitTrie *t, uint32_t val) {
    if (t == NULL || t->root == NULL) {
        return 0;
    }
    const BitTrieNode *curr = t->root;
    uint32_t max_xor = 0;
    for (int i = 31; i >= 0; --i) {
        uint32_t b = (val >> i) & 1U;
        uint32_t opp = 1U - b;
        if (curr->children[opp] != NULL) {
            max_xor |= (1U << i);
            curr = curr->children[opp];
        } else if (curr->children[b] != NULL) {
            curr = curr->children[b];
        } else {
            break;
        }
    }
    return max_xor;
}

bool max_subarray_xor(const uint32_t *nums, size_t count, uint32_t *out_max_xor) {
    if (nums == NULL || out_max_xor == NULL || count == 0) {
        return false;
    }
    BitTrie *t = bit_trie_create();
    if (t == NULL) {
        return false;
    }

    if (!bit_trie_insert(t, 0)) {
        bit_trie_destroy(t);
        return false;
    }

    uint32_t prefix = 0;
    uint32_t best = 0;
    for (size_t i = 0; i < count; ++i) {
        prefix ^= nums[i];
        uint32_t cur = bit_trie_query_max_xor(t, prefix);
        if (cur > best) {
            best = cur;
        }
        if (!bit_trie_insert(t, prefix)) {
            bit_trie_destroy(t);
            return false;
        }
    }

    bit_trie_destroy(t);
    *out_max_xor = best;
    return true;
}

int main(void) {
    uint32_t arr1[] = {1, 2, 3, 4};
    uint32_t ans = 0;
    assert(max_subarray_xor(arr1, 4, &ans) && ans == 7);

    uint32_t arr2[] = {8, 1, 2, 12};
    assert(max_subarray_xor(arr2, 4, &ans) && ans == 15);

    uint32_t single[] = {42};
    assert(max_subarray_xor(single, 1, &ans) && ans == 42);

    assert(!max_subarray_xor(NULL, 5, &ans));
    assert(!max_subarray_xor(arr1, 0, &ans));

    return 0;
}
```

## 复杂度分析

- **时间复杂度**：
  - 维护前缀异或和单步耗时 $O(1)$；
  - 每个前缀向 01-Trie 中查询并插入各需 32 步位运算；
  - 处理长度为 $n$ 的数组，总时间复杂度严格为 $O(32 \cdot n) = O(n)$，彻底摆脱了 $\Theta(n^2)$ 枚举子数组的瓶颈。
- **空间复杂度**：树中最多容纳 $n + 1$ 个前缀数值的二进制分支，最坏空间复杂度为 $O(32 \cdot n) = O(n)$。

## 延伸思考 / 模式总结

1. **树上路径最大异或和的树上推广**：在树形图拓扑中，求树上任意简单路径的异或和最大值，同样具备完全相同的数学美感：定义 $D[u]$ 为从根节点到顶点 $u$ 的路径异或和，则任意路径 $u \leadsto v$ 的异或和恒等于 $D[u] \oplus D[v]$（因为根到公共祖先 LCA 的路径被异或了两次完全抵消）。因此树上任意两点最大路径异或和同样可等价映射为对 $D$ 数组求解最大异或对。
2. **前缀可逆算子的普适化**：任何满足阿贝尔群性质（包含结合律、单位元与逆元）的二元运算，均能通过前缀差分转化为两点查询。异或由于自逆性免除了减法借位的麻烦，使得代数变换极其干净利落。
