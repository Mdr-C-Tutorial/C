# 31901 - 标准固定字母表 Trie 树插入与前缀匹配

## 题目描述

实现基于固定 26 路 ASCII 小写字母（`'a'` 到 `'z'`）分支数组的字典树（Trie / 前缀树）`LowerTrie`，支持单词插入、精确匹配以及前缀存在性检索：

```c
#include <stdbool.h>
#include <stddef.h>

typedef struct LowerTrie LowerTrie;

LowerTrie *lower_trie_create(void);
void lower_trie_destroy(LowerTrie *trie);
bool lower_trie_insert(LowerTrie *trie, const char *word, bool *out_inserted);
bool lower_trie_contains(const LowerTrie *trie, const char *word, bool *out_found);
bool lower_trie_starts_with(const LowerTrie *trie, const char *prefix, bool *out_starts);
```

要求：

1. 单词仅包含 ASCII 小写字母 `'a'` 到 `'z'`，以空字符 `'\0'` 结尾。若字符非法或指针参数为 `NULL`，操作返回 `false` 且不修改输出对象与树结构。
2. 每个树节点维护大小为 26 的子指针静态数组 `children[26]` 以及词尾布尔标记 `is_word`。
3. `lower_trie_insert` 将新单词录入树中：若该单词此前已存在，设置 `*out_inserted = false`；若为全新录入，设置 `*out_inserted = true`。中途若发生内存分配失败，树结构必须保持一致性。
4. `lower_trie_contains` 进行单词全字匹配；`lower_trie_starts_with` 检验是否存在以 `prefix` 为前缀的任何有效单词。
5. 检索与插入的时间复杂度严格由字符串长度 $O(L)$ 决定，与树中已存储的单词总数 $N$ 完全无关。

## 解题思路

### 1. 字典树（Trie）的核心几何结构

Trie 是一种树形键值检索数据结构，其核心特征为：**键的内容并不直接保存在单一节点中，而是由节点在树中的深度路径隐式决定**。
- 树根节点代表空字符串 `""`；
- 从根节点出发，沿每条分支下潜一级对应读取字符串中的一个字符；
- 字符 `'a'` 到 `'z'` 通过简单的数组下标偏移计算完成寻址：
  $$\text{index} = \text{ch} - \text{'a'}$$
- 这一映射消除了字符与子节点之间的任何哈希或二分查找开销，单步下潜耗时严格为 $O(1)$。

### 2. 状态转移与词尾判定

每个节点包含布尔标记 `is_word`：
- 若插入了单词 `"app"`，路径 `根 -> 'a' -> 'p' -> 'p'` 的末尾节点标记为 `is_word = true`；
- 若随后插入单词 `"apple"`，继续沿原路径下潜拓展 `'l' -> 'e'`，并将末端 `'e'` 标记为 `is_word = true`；
- 在检索时：
  - `lower_trie_contains("appl")`：路径虽存在，但 `'l'` 节点的 `is_word == false`，因此判定不包含该单词；
  - `lower_trie_starts_with("appl")`：只需确认 `'l'` 节点在树中确实存在即可判定前缀匹配成功。

## C 语言实现

```c
#include <assert.h>
#include <stdbool.h>
#include <stddef.h>
#include <stdint.h>
#include <stdio.h>
#include <stdlib.h>

enum { LOWER_ALPHA = 26 };

typedef struct TrieNode TrieNode;

struct TrieNode {
    TrieNode *children[LOWER_ALPHA];
    bool is_word;
};

typedef struct LowerTrie LowerTrie;

struct LowerTrie {
    TrieNode *root;
};

static void destroy_node(TrieNode *n) {
    if (n == NULL) {
        return;
    }
    for (int i = 0; i < LOWER_ALPHA; ++i) {
        destroy_node(n->children[i]);
    }
    free(n);
}

LowerTrie *lower_trie_create(void) {
    LowerTrie *t = malloc(sizeof *t);
    if (t == NULL) {
        return NULL;
    }
    t->root = calloc(1, sizeof *t->root);
    if (t->root == NULL) {
        free(t);
        return NULL;
    }
    return t;
}

void lower_trie_destroy(LowerTrie *trie) {
    if (trie == NULL) {
        return;
    }
    destroy_node(trie->root);
    free(trie);
}

bool lower_trie_insert(LowerTrie *trie, const char *word, bool *out_inserted) {
    if (trie == NULL || out_inserted == NULL || word == NULL) {
        return false;
    }
    for (size_t i = 0; word[i] != '\0'; ++i) {
        if (word[i] < 'a' || word[i] > 'z') {
            return false;
        }
    }

    TrieNode *curr = trie->root;
    for (size_t i = 0; word[i] != '\0'; ++i) {
        int idx = word[i] - 'a';
        if (curr->children[idx] == NULL) {
            TrieNode *new_node = calloc(1, sizeof(TrieNode));
            if (new_node == NULL) {
                return false;
            }
            curr->children[idx] = new_node;
        }
        curr = curr->children[idx];
    }

    if (curr->is_word) {
        *out_inserted = false;
    } else {
        curr->is_word = true;
        *out_inserted = true;
    }
    return true;
}

bool lower_trie_contains(const LowerTrie *trie, const char *word, bool *out_found) {
    if (trie == NULL || out_found == NULL || word == NULL) {
        return false;
    }
    const TrieNode *curr = trie->root;
    for (size_t i = 0; word[i] != '\0'; ++i) {
        if (word[i] < 'a' || word[i] > 'z') {
            return false;
        }
        int idx = word[i] - 'a';
        if (curr->children[idx] == NULL) {
            *out_found = false;
            return true;
        }
        curr = curr->children[idx];
    }
    *out_found = curr->is_word;
    return true;
}

bool lower_trie_starts_with(const LowerTrie *trie, const char *prefix, bool *out_starts) {
    if (trie == NULL || out_starts == NULL || prefix == NULL) {
        return false;
    }
    const TrieNode *curr = trie->root;
    for (size_t i = 0; prefix[i] != '\0'; ++i) {
        if (prefix[i] < 'a' || prefix[i] > 'z') {
            return false;
        }
        int idx = prefix[i] - 'a';
        if (curr->children[idx] == NULL) {
            *out_starts = false;
            return true;
        }
        curr = curr->children[idx];
    }
    *out_starts = true;
    return true;
}

int main(void) {
    lower_trie_destroy(NULL);

    LowerTrie *t = lower_trie_create();
    assert(t != NULL);

    bool ins = false;
    bool fnd = false;
    bool st = false;

    assert(lower_trie_insert(t, "apple", &ins) && ins);
    assert(lower_trie_insert(t, "app", &ins) && ins);
    assert(lower_trie_insert(t, "apple", &ins) && !ins);

    assert(lower_trie_contains(t, "apple", &fnd) && fnd);
    assert(lower_trie_contains(t, "app", &fnd) && fnd);
    assert(lower_trie_contains(t, "appl", &fnd) && !fnd);
    assert(lower_trie_contains(t, "banana", &fnd) && !fnd);

    assert(lower_trie_starts_with(t, "appl", &st) && st);
    assert(lower_trie_starts_with(t, "app", &st) && st);
    assert(lower_trie_starts_with(t, "ban", &st) && !st);

    lower_trie_destroy(t);
    return 0;
}
```

## 复杂度分析

- **时间复杂度**：
  - `lower_trie_insert`：设单词长度为 $L$，算法自顶向下沿对应字符分支下潜 $L$ 步，时间复杂度严格为 $O(L)$。
  - `lower_trie_contains` 与 `lower_trie_starts_with`：同样仅下潜前缀长度步，时间复杂度为 $O(L)$。
  - 检索耗时与树中存储的词汇总数 $N$ 严格无关，这构成了 Trie 区别于平衡二叉搜索树（$O(L \log N)$）的核心优势。
- **空间复杂度**：每个节点包含 26 个指针槽位（$26 \times 8 = 208$ 字节）。若包含 $N$ 个字符串且字符重复度较低，最坏空间复杂度为 $O(|\Sigma| \cdot \sum L)$。

## 延伸思考 / 模式总结

1. **公共前缀空间复用机制**：当大量录入包含相同前缀的词汇（如 `"http"`, `"https"`, `"html"`）时，Trie 树将重叠前缀的节点完全合并，大幅降低了字符串冗余存储开销。
2. **固定字母表局限性**：固定 26 路指针数组在字符集极小（如小写英文字母、DNA 四进制碱基）时性能绝佳；但当字符集扩大为 ASCII（128/256 字符）或 Unicode 时，空指针将吞噬巨大的无效内存，这直接催生了动态链表子节点 Trie 以及基数树（Radix Tree）的设计。
