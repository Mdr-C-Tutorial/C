# 31901：支持前缀统计的小写字母 Trie

## 题目

实现仅包含 ASCII 小写字母 `a` 到 `z`（不含结尾空字节、允许长度为 `0` 的空单词）的字典树 `LowerTrie`，支持插入单词、精确查找与 $O(|prefix|)$ 前缀计数，并保证分配失败或参数非法时原树与输出对象保持不变。

## 解析

每个结点维护 26 路子指针数组 `children[26]`、经过该结点的不同单词数量 `prefix_count` 以及词尾标记 `is_word`。根结点在创建字典树时直接分配，对应长度为 `0` 的空前缀，因此空单词的插入、查找与前缀统计无需特殊分支即可统一处理。

为了满足强异常安全（插入失败不留半条路径，也不破坏原有计数），`lower_trie_insert` 分三步执行：

1. **前置校验与已有路径探测**：先校验全部字节均在 `'a'` 到 `'z'` 范围内，再从根结点向下走完已存在的最长前缀。若整条路径已存在且终点 `is_word` 为真，直接置 `*out_inserted = false` 并返回。
2. **离线构建缺失后缀链**：若路径在深度 `split` 处断开，不在原树上直接挂载新结点，而是先在独立指针链上分配剩余的 `length - split` 个新结点。一旦中途 `calloc` 失败，只需销毁这条尚未挂入原树的临时链即可安全返回 `false`。
3. **原子挂接与计数更新**：后缀链全部分配成功后，将其首结点挂入断开处的子指针，标记终点 `is_word = true`，随后沿完整路径将每个结点的 `prefix_count` 递增 `1`。

在 `lower_trie_contains` 与 `lower_trie_count_prefix` 中，同样必须先完整校验输入字节序列的合法性，再沿树下探；否则当输入前缀前半段恰好在树中不存在、后半段含有非法字符时，提前终止下探会漏检非法字符。

## 答案

```c
#include <stdbool.h>
#include <stddef.h>
#include <stdint.h>
#include <stdlib.h>

enum {
    LOWER_ALPHA = 26
};

typedef struct TrieNode {
    struct TrieNode *children[LOWER_ALPHA];
    size_t prefix_count;
    bool is_word;
} TrieNode;

struct LowerTrie {
    TrieNode *root;
};

typedef struct LowerTrie LowerTrie;

static bool valid_lower_bytes(
    const unsigned char *bytes,
    size_t length
) {
    if (length > 0 && bytes == NULL) {
        return false;
    }
    for (size_t i = 0; i < length; ++i) {
        if (bytes[i] < 'a' || bytes[i] > 'z') {
            return false;
        }
    }
    return true;
}

static void destroy_subtree(TrieNode *node) {
    if (node == NULL) {
        return;
    }
    for (size_t i = 0; i < LOWER_ALPHA; ++i) {
        destroy_subtree(node->children[i]);
    }
    free(node);
}

LowerTrie *lower_trie_create(void) {
    LowerTrie *trie = malloc(sizeof *trie);
    if (trie == NULL) {
        return NULL;
    }
    trie->root = calloc(1, sizeof *trie->root);
    if (trie->root == NULL) {
        free(trie);
        return NULL;
    }
    return trie;
}

void lower_trie_destroy(LowerTrie *trie) {
    if (trie == NULL) {
        return;
    }
    destroy_subtree(trie->root);
    free(trie);
}

bool lower_trie_insert(
    LowerTrie *trie,
    const unsigned char *word,
    size_t length,
    bool *out_inserted
) {
    if (trie == NULL || out_inserted == NULL ||
        !valid_lower_bytes(word, length)) {
        return false;
    }

    TrieNode *cursor = trie->root;
    size_t split = 0;
    while (split < length) {
        size_t index = (size_t)(word[split] - 'a');
        if (cursor->children[index] == NULL) {
            break;
        }
        cursor = cursor->children[index];
        ++split;
    }

    if (split == length && cursor->is_word) {
        *out_inserted = false;
        return true;
    }
    if (trie->root->prefix_count == SIZE_MAX) {
        return false;
    }

    TrieNode *chain_head = NULL;
    TrieNode *chain_tail = NULL;
    for (size_t i = split; i < length; ++i) {
        TrieNode *node = calloc(1, sizeof *node);
        if (node == NULL) {
            destroy_subtree(chain_head);
            return false;
        }
        if (chain_head == NULL) {
            chain_head = node;
        } else {
            size_t prev_index = (size_t)(word[i - 1] - 'a');
            chain_tail->children[prev_index] = node;
        }
        chain_tail = node;
    }

    if (chain_head != NULL) {
        size_t first_index = (size_t)(word[split] - 'a');
        cursor->children[first_index] = chain_head;
        chain_tail->is_word = true;
    } else {
        cursor->is_word = true;
    }

    TrieNode *walk = trie->root;
    ++walk->prefix_count;
    for (size_t i = 0; i < length; ++i) {
        walk = walk->children[(size_t)(word[i] - 'a')];
        ++walk->prefix_count;
    }

    *out_inserted = true;
    return true;
}

bool lower_trie_contains(
    const LowerTrie *trie,
    const unsigned char *word,
    size_t length,
    bool *out_found
) {
    if (trie == NULL || out_found == NULL ||
        !valid_lower_bytes(word, length)) {
        return false;
    }

    const TrieNode *cursor = trie->root;
    for (size_t i = 0; i < length; ++i) {
        size_t index = (size_t)(word[i] - 'a');
        if (cursor->children[index] == NULL) {
            *out_found = false;
            return true;
        }
        cursor = cursor->children[index];
    }
    *out_found = cursor->is_word;
    return true;
}

bool lower_trie_count_prefix(
    const LowerTrie *trie,
    const unsigned char *prefix,
    size_t length,
    size_t *out_count
) {
    if (trie == NULL || out_count == NULL ||
        !valid_lower_bytes(prefix, length)) {
        return false;
    }

    const TrieNode *cursor = trie->root;
    for (size_t i = 0; i < length; ++i) {
        size_t index = (size_t)(prefix[i] - 'a');
        if (cursor->children[index] == NULL) {
            *out_count = 0;
            return true;
        }
        cursor = cursor->children[index];
    }
    *out_count = cursor->prefix_count;
    return true;
}
```

单词插入、精确查找与前缀统计的时间复杂度均为 $O(L)$（$L$ 为输入字节长度），每次新插入最多分配 $L$ 个结点，空间复杂度与所有已插入单词的前缀树结点总数成正比。
