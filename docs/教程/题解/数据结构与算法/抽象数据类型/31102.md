# 题解：31102

## 题目

实现零动态内存分配的定长滑动窗口打点限流器抽象数据类型（RateLimiter ADT），内部以环形缓冲维护单调递增的时间戳序列：

```c
#include <stdbool.h>
#include <stddef.h>
#include <stdint.h>

typedef struct RateLimiter RateLimiter;

struct RateLimiter {
    uint64_t window_ms;
    size_t max_hits;
    uint64_t *timestamps;
    size_t capacity;
    size_t head;
    size_t count;
};

void rate_limiter_init(
    RateLimiter *limiter,
    uint64_t window_ms,
    size_t max_hits,
    uint64_t *timestamp_buffer,
    size_t buffer_capacity
);
bool rate_limiter_acquire(RateLimiter *limiter, uint64_t now_ms);
size_t rate_limiter_current_load(RateLimiter *limiter, uint64_t now_ms);
```

要求：

1. **外部存储提供契约**：ADT 内部不调用 `malloc`，所需环形缓冲内存由外部调用方显式注入；初始化后调用方仅通过公开函数访问，不得直接读写结构体成员。
2. **单调性前置条件**：调用方传入的当前时间戳 `now_ms` 必须关于时间单调非递减；若检测到时间倒退，`acquire` 返回 `false`，保持内部状态不变。
3. **过期淘汰机制**：打点请求发生或查询负载时，自动淘汰掉严格落在当前滑动窗口闭区间 $[now\_ms - window\_ms + 1, now\_ms]$ 之外的所有过期时间戳。
4. **配额判定**：淘汰过期记录后，若有效打点数未达到 `max_hits` 且未超出物理缓冲容量，记录本次时间戳并返回 `true`；否则拒绝请求返回 `false`。
5. **复杂度**：利用环形数组队列，每次淘汰与打点的均摊时间复杂度为 $O(1)$，空间复杂度严格限制在预分配的缓冲区大小。

## 解析

在嵌入式系统、高频交易及高可用服务网关中，为了避免堆内存碎片和不确定的动态分配延迟，许多 ADT 采用“调用方分配、被调用方全权管理”的无堆分配模式（Zero-heap Allocation）。

1. **环形队列实现滑动窗口**：
   - 线性扫描时间戳数组会导致 $O(n)$ 的清理耗时。
   - 由于输入时间戳单调非递减，最早存入的时间戳必然位于队列头部。使用环形下标（Circular Buffer），`head` 指向最久未过期的记录，`count` 为当前窗口内的有效打点数。
   - 物理下标映射公式：逻辑位置 `i`（$0 \le i < count$）对应的存储位置为 `(head + i) % capacity`。

2. **过期边界判定与时间回退防护**：
   - 当前时间为 `now_ms`，窗口长度为 `window_ms`，则过期阈值为 $T_{thresh} = now\_ms \ge window\_ms ? (now\_ms - window\_ms + 1) : 0$。
   - 当 `head` 处的时间戳严格小于 $T_{thresh}$ 时，弹出队首：`head = (head + 1) % capacity`，`count--`。该检查沿队首推进，直至遇到未过期项或队列变空。
   - 最新存入的时间戳位于 `(head + count - 1) % capacity`。若 `now_ms` 小于该时间戳，说明调用方时钟发生回退或并发乱序，必须拒绝该请求以防止不变式被破坏。

3. **契约封装与防御性检查**：
   - 空指针校验：`limiter == NULL` 或缓冲指针为空时直接返回安全状态码。
   - 额度满判定：当且仅当 `count < max_hits` 且 `count < capacity` 时才允许记录新打点。

## 答案

```c
#include <assert.h>
#include <stdbool.h>
#include <stddef.h>
#include <stdint.h>

typedef struct RateLimiter RateLimiter;

struct RateLimiter {
    uint64_t window_ms;
    size_t max_hits;
    uint64_t *timestamps;
    size_t capacity;
    size_t head;
    size_t count;
};

void rate_limiter_init(
    RateLimiter *limiter,
    uint64_t window_ms,
    size_t max_hits,
    uint64_t *timestamp_buffer,
    size_t buffer_capacity
) {
    if (limiter == NULL) {
        return;
    }
    limiter->window_ms = window_ms;
    limiter->max_hits = max_hits;
    limiter->timestamps = timestamp_buffer;
    limiter->capacity = buffer_capacity;
    limiter->head = 0;
    limiter->count = 0;
}

static void rate_limiter_evict(RateLimiter *limiter, uint64_t now_ms) {
    uint64_t threshold = (now_ms >= limiter->window_ms)
        ? (now_ms - limiter->window_ms + 1)
        : 0;

    while (limiter->count > 0) {
        uint64_t oldest = limiter->timestamps[limiter->head];
        if (oldest >= threshold) {
            break;
        }
        limiter->head = (limiter->head + 1) % limiter->capacity;
        limiter->count--;
    }
}

bool rate_limiter_acquire(RateLimiter *limiter, uint64_t now_ms) {
    if (limiter == NULL || limiter->timestamps == NULL || limiter->capacity == 0) {
        return false;
    }
    if (limiter->max_hits == 0) {
        return false;
    }

    if (limiter->count > 0) {
        size_t last_idx = (limiter->head + limiter->count - 1) % limiter->capacity;
        if (now_ms < limiter->timestamps[last_idx]) {
            return false;
        }
    }

    rate_limiter_evict(limiter, now_ms);

    if (limiter->count >= limiter->max_hits || limiter->count >= limiter->capacity) {
        return false;
    }

    size_t insert_idx = (limiter->head + limiter->count) % limiter->capacity;
    limiter->timestamps[insert_idx] = now_ms;
    limiter->count++;
    return true;
}

size_t rate_limiter_current_load(RateLimiter *limiter, uint64_t now_ms) {
    if (limiter == NULL || limiter->timestamps == NULL || limiter->capacity == 0) {
        return 0;
    }
    rate_limiter_evict(limiter, now_ms);
    return limiter->count;
}

int main(void) {
    uint64_t buf[5];
    RateLimiter limiter;
    rate_limiter_init(&limiter, 1000, 3, buf, 5);

    assert(rate_limiter_acquire(&limiter, 100));
    assert(rate_limiter_acquire(&limiter, 200));
    assert(rate_limiter_acquire(&limiter, 300));
    assert(!rate_limiter_acquire(&limiter, 400));

    assert(rate_limiter_current_load(&limiter, 400) == 3);

    assert(rate_limiter_acquire(&limiter, 1101));
    assert(rate_limiter_current_load(&limiter, 1101) == 3);

    assert(!rate_limiter_acquire(&limiter, 1000));

    assert(rate_limiter_current_load(&limiter, 5000) == 0);
    assert(rate_limiter_acquire(&limiter, 5000));
    assert(rate_limiter_current_load(&limiter, 5000) == 1);

    return 0;
}
```
