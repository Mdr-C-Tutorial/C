# 35206 - 原地数组划分（Lomuto 与 Hoare 划分）的循环不变式形式化推导与对比

## 题目

原地数组划分（Lomuto 划分与 Hoare 划分）的循环不变式形式化推导与对比：

在快速排序与快速选择中，分区算法是决定算法性能的核心。实现 Lomuto 划分与 Hoare 划分：

```c
#include <stddef.h>
#include <stdint.h>

size_t lomuto_partition(int64_t *arr, size_t low, size_t high);
size_t hoare_partition(int64_t *arr, size_t low, size_t high);
```

要求：

1. 分别形式化给出 Lomuto 划分（单向双指针）与 Hoare 划分（双向向内对撞指针）的循环不变式区域划分；
2. 证明两个划分算法在循环终止时，枢轴元素与左右子区间的偏序分界性质；
3. 深入对比两者的交换次数、比较次数以及在**大量重复相等元素**输入下的退化风险，编写 C 语言实现并用断言检验分区不变式。

## 解题思路

### 1. Lomuto 划分及其循环不变式

Lomuto 划分采用单向遍历策略，通常选取区间末尾元素 $pivot = \text{arr}[high]$ 作为枢轴，维护前缀游标 $i$ 和扫描游标 $j$。

**Lomuto 循环不变式**：在每一轮外层循环迭代开始前，区间 $[low, high - 1]$ 被严格划分为三个区域：
1. 若 $low \le k < i$，恒有 $\text{arr}[k] \le pivot$（已确定的较小元素区）；
2. 若 $i \le k < j$，恒有 $\text{arr}[k] > pivot$（已确定的较大元素区）；
3. 若 $j \le k < high$，为尚未处理的未知元素；
4. 末尾 $k = high$ 恒为枢轴 $\text{arr}[high] = pivot$。

- **初始化**：初始时 $i = low, j = low$。较小区与较大区均为空，不变式显然成立。
- **保持**：
  - 若 $\text{arr}[j] > pivot$：只需执行 $j \leftarrow j + 1$，较大区扩展一位；
  - 若 $\text{arr}[j] \le pivot$：交换 $\text{arr}[i]$ 与 $\text{arr}[j]$，并令 $i \leftarrow i + 1, j \leftarrow j + 1$。原本位于 $i$ 处的较大元素被移至 $j$ 处，较小区与较大区各自右移保持不变式。
- **终止**：当 $j = high$ 时循环终止。此时交换 $\text{arr}[i]$ 与 $\text{arr}[high]$，枢轴被安置在最终有序位置 $i$，左侧全部 $\le pivot$，右侧全部 $\ge pivot$。

### 2. Hoare 划分及其循环不变式

Hoare 原创的划分方法采用双向对撞指针。通常选取首元素 $pivot = \text{arr}[low]$，指针 $i$ 从左向右移动，指针 $j$ 从右向左移动。

**Hoare 循环不变式**：在主循环每一次向内扫描开始前：
1. 对所有 $k < i$，恒有 $\text{arr}[k] \le pivot$；
2. 对所有 $k > j$，恒有 $\text{arr}[k] \ge pivot$。

- **向内移动与交换**：
  - $i$ 自增直到 $\text{arr}[i] \ge pivot$；
  - $j$ 自减直到 $\text{arr}[j] \le pivot$；
  - 若 $i < j$，交换 $\text{arr}[i]$ 与 $\text{arr}[j]$，各自向内迈进一步保持不变式；
  - 若 $i \ge j$，循环终止，返回下标 $j$。此时子数组 $\text{arr}[low..j]$ 中的所有元素 $\le \text{arr}[j+1..high]$ 中的所有元素。

### 3. 性能与全等元素退化对比

| 特性指标 | Lomuto 划分 | Hoare 划分 |
| :--- | :--- | :--- |
| **指针移动方式** | 单向同向双指针（$j$ 线性扫描） | 双向对撞指针对移 |
| **平均交换次数** | 较多（约是 Hoare 的 3 倍） | 较少（仅在越界逆序对处交换） |
| **枢轴最终位置** | 枢轴确定落在返回值下标处 | 返回划分边界 $j$，枢轴不一定在 $j$ |
| **全等元素退化** | $\text{arr}[j] \le pivot$ 恒成立，划分极度不平衡，导致快速排序退化为 $O(n^2)$ | 遇到相等元素两端均停下对换，完美对半平分区间，保持 $O(n \log n)$ |

## C 语言实现

```c
#include <assert.h>
#include <stddef.h>
#include <stdint.h>
#include <stdio.h>

static void swap_i64(int64_t *a, int64_t *b) {
    int64_t tmp = *a;
    *a = *b;
    *b = tmp;
}

size_t lomuto_partition(int64_t *arr, size_t low, size_t high) {
    int64_t pivot = arr[high];
    size_t i = low;

    for (size_t j = low; j < high; ++j) {
        if (arr[j] <= pivot) {
            swap_i64(&arr[i], &arr[j]);
            i++;
        }
    }
    swap_i64(&arr[i], &arr[high]);
    return i;
}

size_t hoare_partition(int64_t *arr, size_t low, size_t high) {
    int64_t pivot = arr[low];
    size_t i = low;
    size_t j = high;

    for (;;) {
        while (arr[i] < pivot) {
            i++;
        }
        while (arr[j] > pivot) {
            j--;
        }
        if (i >= j) {
            return j;
        }
        swap_i64(&arr[i], &arr[j]);
        i++;
        j--;
    }
}

int main(void) {
    /* 1. 测试 Lomuto 划分不变式 */
    int64_t a1[] = {10, 80, 30, 90, 40, 50, 70};
    size_t p1 = lomuto_partition(a1, 0, 6);
    assert(a1[p1] == 70);
    for (size_t k = 0; k < p1; ++k) {
        assert(a1[k] <= 70);
    }
    for (size_t k = p1 + 1; k <= 6; ++k) {
        assert(a1[k] >= 70);
    }

    /* 2. 测试 Hoare 划分不变式 */
    int64_t a2[] = {5, 2, 8, 3, 1, 9, 4};
    size_t p2 = hoare_partition(a2, 0, 6);
    for (size_t k = 0; k <= p2; ++k) {
        for (size_t m = p2 + 1; m <= 6; ++m) {
            assert(a2[k] <= a2[m]);
        }
    }

    /* 3. 测试全等元素情形（Hoare 能够有效平衡对半切分） */
    int64_t a_equal[] = {7, 7, 7, 7, 7, 7};
    size_t p_eq = hoare_partition(a_equal, 0, 5);
    assert(p_eq == 2 || p_eq == 3); /* 均衡对半划分 */

    printf("All Lomuto and Hoare partition tests passed successfully.\n");
    return 0;
}
```

## 复杂度分析

- **时间复杂度**：两种划分算法单次执行时间均为 $\Theta(n)$，只需遍历一次区间。
- **空间复杂度**：$\Theta(1)$。原地划分，仅维护两个下标对象。

## 延伸思考 / 模式总结

Lomuto 划分逻辑清晰、易于用循环不变式进行形式化验证，因而常出现在教学教材中；而 Hoare 划分由于交换次数更少且对重复相等元素具备天然的均衡免疫力，是工业级快速排序库（如各种标准库 libc 的 `qsort` 原型）的标准实践。
