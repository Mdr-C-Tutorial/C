# 35201 - 竖式除法循环不变式的初始化证明

## 题目描述

设被除数 $A$ 是非负整数，其十进制表示为 $d_k d_{k-1} \dots d_0$；除数 $B$ 是正整数。算法从最高位 $d_k$ 开始逐位处理：初始时令 $q = 0$，$r = 0$；每次迭代落下下一位数字 $d$，令 $temp = r \times 10 + d$，商的当前位为 $digit = \lfloor temp / B \rfloor$，然后令 $r \leftarrow temp \bmod B$，$q \leftarrow q \times 10 + digit$。

记 $A_{prefix}$ 为已经处理过的高位数字组成的整数（尚未处理任何数字时为 $0$）。循环不变式为：每次迭代开始前，

$$A_{prefix} = q \times B + r, \quad 0 \le r < B$$

证明循环不变式在循环开始前成立（初始化）。

## 解题思路

证明循环不变式的“初始化（Initialization）”性质，对应于数学归纳法的基础步骤（Base Case）。
需要检验在第一轮循环迭代尚未开始、刚完成初始赋值时的各对象状态：
- 此时尚未扫描任何十进制数位，已处理前缀按定义为 $A_{prefix} = 0$；
- 商对象 $q$ 与余数对象 $r$ 的初值均为 $0$；
- 结合除数 $B$ 为正整数的前提条件即可直接代入验证等式与不等式。

## 形式化证明

在循环第一次迭代开始之前，算法尚未处理被除数 $A$ 的任何十进制位，根据定义有：

$$A_{prefix} = 0$$

算法的初始化步骤设定商 $q = 0$、余数 $r = 0$。将各值代入循环不变式右侧，可得：

$$q \times B + r = 0 \times B + 0 = 0 = A_{prefix}$$

此外，由于除数 $B$ 是正整数（即 $B \ge 1$），且初始时 $r = 0$，显然满足余数界限条件：

$$0 \le r < B$$

综上，循环不变式在循环开始前成立。

## 复杂度分析

- **时间复杂度**：$\Theta(1)$。初始赋值与界限检验仅涉及常数次基本操作。
- **空间复杂度**：$\Theta(1)$。仅分配常数个整型存储单元。

## 延伸思考 / 模式总结

循环不变式的初始化证明本质上是验证前置条件到不变式的“无缝衔接”。在算法实现中，空状态（如空数组、扫描前缀为 0）往往是初始化边界，必须确保归纳基底完全契合数学定义，防止后续迭代在虚假基础上产生偏差。
