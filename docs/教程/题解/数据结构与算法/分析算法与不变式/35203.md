# 35203 - 竖式除法循环不变式的终止性质证明

## 题目描述

在竖式除法算法中，循环不变式为：每次迭代开始前，

$$A_{prefix} = q \times B + r, \quad 0 \le r < B$$

说明循环终止时，循环不变式如何给出竖式除法的正确性（终止）。

## 解题思路

证明循环不变式的“终止（Termination）”性质，是将归纳积累的不变式转化为算法最终输出正确性的关键一步：
- 说明循环因良基测度函数单调递减而必然终止；
- 循环终止时，已处理前缀覆盖被除数全部数位，即 $A_{prefix} = A$；
- 将终态对象代入循环不变式，直接推导出整数带余除法定理所要求的商与余数关系，证明算法完全正确。

## 形式化证明

算法从最高位 $d_k$ 开始逐位向下处理，每轮迭代处理一位十进制数字。由于被除数 $A$ 的十进制位数有限（共 $k + 1$ 位），每次迭代消耗一位未处理数位，循环必然在完成最低位 $d_0$ 的处理后终止。

当循环终止时，从 $d_k$ 到 $d_0$ 的所有数字均已处理完毕，此时已经处理过的高位数字组成的整数 $A_{prefix}$ 恰好等于完整的被除数：

$$A_{prefix} = d_k d_{k-1} \dots d_0 = A$$

记循环终止时的商对象值为 $Q$，余数对象值为 $R$。由初始化和保持性质可知，循环终止时不变式依然成立，代入 $A_{prefix} = A$、$q = Q$、$r = R$ 即得：

$$A = Q \times B + R, \quad 0 \le R < B$$

由整数带余除法定理的唯一性可知：

$$Q = \lfloor A / B \rfloor, \quad R = A \bmod B$$

这证明了竖式除法算法在终止时输出的商 $Q$ 和余数 $R$ 完全正确。

## 复杂度分析

- **时间复杂度**：循环总共执行 $k + 1 = \lfloor \log_{10} A \rfloor + 1$ 步，时间复杂度为 $\Theta(\log A)$。
- **空间复杂度**：$\Theta(1)$。

## 延伸思考 / 模式总结

终止性分析回答了“为什么算法算出来的就是最终答案”。循环不变式通常只保证部分正确性（只要停机结果就对）；只有与良基终止性结合，才能得出完全正确性。
