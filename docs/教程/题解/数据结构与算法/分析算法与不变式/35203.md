# 35203：竖式除法循环不变式的终止性质证明

## 题目

在竖式除法算法中，循环不变式为：每次迭代开始前，

$$A_{prefix} = q \times B + r, \quad 0 \le r < B$$

说明循环终止时，循环不变式如何给出竖式除法的正确性（终止）。

## 解析

循环按从高位 $d_k$ 到最低位 $d_0$ 的顺序逐位迭代，共执行 $k + 1$ 次。当最低位 $d_0$ 处理完毕后循环终止，此时已处理的前缀恰好覆盖被除数 $A$ 的全部十进制位，把循环不变式在终止时刻实例化即可直接得出带余除法定理要求的商和余数关系。

## 答案

算法从最高位 $d_k$ 开始逐位向下处理，每轮迭代处理一位十进制数字。由于被除数 $A$ 的十进制位数有限（共 $k + 1$ 位），循环必然在完成最低位 $d_0$ 的处理后终止。

当循环终止时，从 $d_k$ 到 $d_0$ 的所有数字均已处理完毕，此时已经处理过的高位数字组成的整数 $A_{prefix}$ 恰好等于完整的被除数：

$$A_{prefix} = d_k d_{k-1} \dots d_0 = A$$

记循环终止时的商对象值为 $Q$，余数对象值为 $R$。由初始化和保持性质可知，循环终止时不变式依然成立，代入 $A_{prefix} = A$、$q = Q$、$r = R$ 即得：

$$A = Q \times B + R, \quad 0 \le R < B$$

由整数带余除法定理的唯一性可知，$Q = \lfloor A / B \rfloor$ 且 $R = A \bmod B$，这证明了竖式除法算法在终止时输出的商 $Q$ 和余数 $R$ 完全正确。
