# 35205 - 霍纳法则（Horner's Method）多项式求值的循环不变式证明与 C 实现

## 题目

霍纳法则（Horner's Method）多项式求值的循环不变式证明与 C 实现：

给定多项式 $P(x) = \sum_{i=0}^{n-1} a_i x^i = a_0 + a_1 x + a_2 x^2 + \dots + a_{n-1} x^{n-1}$，霍纳法则将其改写为嵌套乘法形式：

$$P(x) = a_0 + x \cdot (a_1 + x \cdot (a_2 + \dots + x \cdot (a_{n-2} + x \cdot a_{n-1}) \dots ))$$

实现接口：

```c
#include <stddef.h>
#include <stdint.h>

int64_t horner_eval_i64(const int64_t *coeffs, size_t count, int64_t x);
double horner_eval_f64(const double *coeffs, size_t count, double x);
```

要求：

1. 构造从最高项系数 $a_{n-1}$ 向常数项 $a_0$ 逆向扫描的循环不变式，形式化证明其**初始化**、**保持**与**终止**性质。
2. 对比朴素逐项求和（需 $O(n^2)$ 次乘法）与霍纳法则（仅需 $O(n)$ 次乘法与加法）的运算开销与数值稳定性。
3. 给出完整 C 语言实现与单元测试。

## 解题思路

### 1. 算法结构与循环不变式设计

设多项式由系数数组 $A = \langle a_0, a_1, \dots, a_{n-1} \rangle$ 表示，度数为 $n - 1$。霍纳法则从最高次项系数开始向下迭代：
1. 初始令 $y \leftarrow a_{n-1}$；
2. 循环计数器 $k$ 从 $n - 2$ 逆序递减至 $0$：
   $$y \leftarrow y \cdot x + a_k$$
3. 返回 $y$。

**循环不变式**：在循环体测试条件执行前（即即将处理系数 $a_k$ 时），累加对象 $y$ 的值满足：

$$y = \sum_{j = k + 1}^{n - 1} a_j x^{j - (k + 1)}$$

即 $y$ 等于高阶子多项式在 $x$ 处的求值结果。

### 2. 循环不变式证明

- **初始化**：
  在循环第一次迭代前，尚未进入循环，此时对应 $k = n - 2$。初值为 $y = a_{n-1}$。代入不变式右侧公式：
  $$\sum_{j = n - 1}^{n - 1} a_j x^{j - (n - 1)} = a_{n-1} x^0 = a_{n-1}$$
  等式成立，初始化得证。
- **保持**：
  假设某次循环开始前，对当前下标 $k$ 不变式成立，即 $y_{old} = \sum_{j = k + 1}^{n - 1} a_j x^{j - (k + 1)}$。
  在本次迭代中，执行更新：
  $$y_{new} = y_{old} \cdot x + a_k$$
  展开右侧：
  $$
  \begin{aligned}
  y_{new} &= \left( \sum_{j = k + 1}^{n - 1} a_j x^{j - (k + 1)} \right) \cdot x + a_k \\
  &= \sum_{j = k + 1}^{n - 1} a_j x^{j - k} + a_k x^0 \\
  &= \sum_{j = k}^{n - 1} a_j x^{j - k}
  \end{aligned}
  $$
  随后循环计数器递减，令 $k' = k - 1$。则有 $j - k = j - (k' + 1)$，代入得：
  $$y_{new} = \sum_{j = k' + 1}^{n - 1} a_j x^{j - (k' + 1)}$$
  这正是下一次迭代开始前关于 $k'$ 的不变式形式，保持性得证。
- **终止**：
  循环在 $k = -1$ 时终止。此时将 $k = -1$ 代入不变式：
  $$y = \sum_{j = 0}^{n - 1} a_j x^{j - 0} = \sum_{j = 0}^{n - 1} a_j x^j = P(x)$$
  累加对象 $y$ 恰好等于多项式 $P(x)$ 的真实值，算法完全正确。

### 3. 计算复杂度与数值稳定性对比

- **朴素逐项计算**：若依次计算每一项 $a_i x^i$，第 $i$ 项需要 $i$ 次乘法，总乘法次数为 $\sum_{i=1}^{n-1} i = \frac{n(n-1)}{2} = \Theta(n^2)$。
- **霍纳法则**：整个过程仅执行 $n - 1$ 次乘法和 $n - 1$ 次加法，计算复杂度直接降为严格的 $\Theta(n)$，减少了浮点中间幂次计算引入的舍入误差累积。

## C 语言实现

```c
#include <assert.h>
#include <math.h>
#include <stddef.h>
#include <stdint.h>
#include <stdio.h>

int64_t horner_eval_i64(const int64_t *coeffs, size_t count, int64_t x) {
    if (coeffs == NULL || count == 0) {
        return 0;
    }
    int64_t y = coeffs[count - 1];
    for (size_t i = count - 1; i > 0; --i) {
        y = y * x + coeffs[i - 1];
    }
    return y;
}

double horner_eval_f64(const double *coeffs, size_t count, double x) {
    if (coeffs == NULL || count == 0) {
        return 0.0;
    }
    double y = coeffs[count - 1];
    for (size_t i = count - 1; i > 0; --i) {
        y = y * x + coeffs[i - 1];
    }
    return y;
}

int main(void) {
    /* 测试多项式 P(x) = 2 + 3x + 4x^2 */
    /* P(0) = 2, P(1) = 9, P(2) = 2 + 6 + 16 = 24 */
    int64_t c_int[] = {2, 3, 4};
    assert(horner_eval_i64(c_int, 3, 0) == 2);
    assert(horner_eval_i64(c_int, 3, 1) == 9);
    assert(horner_eval_i64(c_int, 3, 2) == 24);

    /* 浮点测试：Q(x) = 1.5 - 2.0x + 0.5x^2 */
    /* Q(2.0) = 1.5 - 4.0 + 2.0 = -0.5 */
    double c_float[] = {1.5, -2.0, 0.5};
    assert(fabs(horner_eval_f64(c_float, 3, 2.0) - (-0.5)) < 1e-9);

    /* 单项式测试 */
    int64_t single[] = {42};
    assert(horner_eval_i64(single, 1, 100) == 42);

    /* 空输入前置保护 */
    assert(horner_eval_i64(NULL, 0, 5) == 0);
    assert(horner_eval_f64(NULL, 0, 5.0) == 0.0);

    printf("All Horner's Method tests passed successfully.\n");
    return 0;
}
```

## 复杂度分析

- **时间复杂度**：$\Theta(n)$。循环执行 $n - 1$ 次，每次单次乘法与加法。
- **空间复杂度**：$\Theta(1)$。仅维护单个累乘求和对象。

## 延伸思考 / 模式总结

霍纳法则不仅在数学和数值分析中处于基础地位，也是编译器优化中常数折叠与多项式计算指令生成（如 FMA 融合乘加指令）的核心转换技术。其不变式的逆向构造模式也是分析后缀表达式、进制转换（十进制转二进制数）的标准工具。
