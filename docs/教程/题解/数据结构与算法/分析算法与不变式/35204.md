# 35204：防溢出模乘与二进制快速幂的循环不变式证明及实现

## 题目

实现 64 位无符号整数的防溢出模乘与二进制快速幂算法，并使用循环不变式严格证明其正确性，接口如下：

```c
#include <stdbool.h>
#include <stdint.h>

uint64_t mul_mod_u64(uint64_t a, uint64_t b, uint64_t mod);

bool pow_mod_u64(
    uint64_t base,
    uint64_t exp,
    uint64_t mod,
    uint64_t *out_result
);
```

## 解析

### 1. 防溢出模加与二进制倍增模乘 `mul_mod_u64`

对于满足 $0 \le x < m$ 且 $0 \le y < m$ 的无符号整数，直接计算 $(x + y) \bmod m$ 在 $x + y \ge 2^{64}$ 时会发生无符号回绕。通过等价变形：
- 若 $x \ge m - y$，则 $x + y \ge m$，此时 $(x + y) \bmod m = x - (m - y)$；
- 若 $x < m - y$，则 $x + y < m \le 2^{64} - 1$，此时直接返回 $x + y$ 绝不溢出。

基于安全的模加法 `add_mod_u64`，设原始输入为 $A = a$、$B = b$、模数为 $m = \text{mod} > 0$。初始化时令 $u = A \bmod m$，$v = B$，$res = 0$。在每次迭代中，若 $v$ 为奇数则令 $res \leftarrow (res + u) \bmod m$，随后令 $u \leftarrow 2u \bmod m$，$v \leftarrow \lfloor v / 2 \rfloor$。

**`mul_mod_u64` 的循环不变式**：在每次迭代开始前，恒有 $0 \le res < m$，$0 \le u < m$，且：

$$(res + u \cdot v) \bmod m = (A \cdot B) \bmod m$$

- **初始化**：第一次迭代开始前，$res = 0$，$u = A \bmod m$，$v = B$。显然 $0 \le res, u < m$，且 $(0 + (A \bmod m) \cdot B) \bmod m = (A \cdot B) \bmod m$，不变式成立。
- **保持**：设某次迭代开始前不变式对 $(res, u, v)$ 成立。根据二进制最低位将 $v$ 写为 $v = 2 v' + r$（其中 $v' = \lfloor v / 2 \rfloor$，$r = v \bmod 2 \in \{0, 1\}$）。本次迭代将新累加值更新为 $res' = (res + r \cdot u) \bmod m$，新倍增值更新为 $u' = 2u \bmod m$，新乘数更新为 $v'$。于是：
  $$
  \begin{aligned}
  (res' + u' \cdot v') \bmod m &= ((res + r \cdot u) + (2u) \cdot v') \bmod m \\
  &= (res + u \cdot (2v' + r)) \bmod m \\
  &= (res + u \cdot v) \bmod m \\
  &= (A \cdot B) \bmod m
  \end{aligned}
  $$
  且模加保证 $0 \le res' < m$、$0 \le u' < m$，不变式保持成立。
- **终止**：由于 $v > 0$ 时每次右移一位都使 $v$ 严格减小，循环至多执行 $64$ 次后终止于 $v = 0$。代入不变式得：
  $$(res + u \cdot 0) \bmod m = res \bmod m = res = (A \cdot B) \bmod m$$
  证明了返回值的正确性。

### 2. 二进制快速幂 `pow_mod_u64` 的循环不变式证明

设原始底数为 $X = \text{base}$，原始指数为 $E = \text{exp}$，模数为 $m = \text{mod} \ge 2$。初始化时令 $b = X \bmod m$，$e = E$，$res = 1$。在每次迭代中，若 $e$ 为奇数则令 $res \leftarrow (res \cdot b) \bmod m$，随后令 $b \leftarrow b^2 \bmod m$，$e \leftarrow \lfloor e / 2 \rfloor$。

**`pow_mod_u64` 的循环不变式**：在每次迭代开始前，恒有 $0 \le res < m$，$0 \le b < m$，且：

$$\left(res \cdot b^e\right) \bmod m = X^E \bmod m$$

- **初始化**：循环开始前，$res = 1$，$b = X \bmod m$，$e = E$。由于 $m \ge 2$，有 $0 \le res < m$ 且 $0 \le b < m$，同时 $(1 \cdot (X \bmod m)^E) \bmod m = X^E \bmod m$，不变式成立。
- **保持**：设某次迭代开始前不变式对 $(res, b, e)$ 成立。将 $e$ 写为 $e = 2e' + r$（其中 $e' = \lfloor e / 2 \rfloor$，$r = e \bmod 2 \in \{0, 1\}$）。本次迭代更新 $res' = (res \cdot b^r) \bmod m$，$b' = b^2 \bmod m$，$e' = \lfloor e / 2 \rfloor$。在下一次迭代开始前：
  $$
  \begin{aligned}
  \left(res' \cdot (b')^{e'}\right) \bmod m &= \left((res \cdot b^r) \cdot (b^2)^{e'}\right) \bmod m \\
  &= \left(res \cdot b^{2e' + r}\right) \bmod m \\
  &= \left(res \cdot b^e\right) \bmod m \\
  &= X^E \bmod m
  \end{aligned}
  $$
  不变式保持成立。
- **终止**：每次迭代将指数 $e$ 右移一位，至多经过 $\lfloor \lg E \rfloor + 1$ 次迭代后终止于 $e = 0$。此时由不变式得：
  $$\left(res \cdot b^0\right) \bmod m = res = X^E \bmod m$$
  证明了快速幂算法的正确性。

### 3. 复杂度分析

- `mul_mod_u64`：循环次数至多为 $\lfloor \lg b \rfloor + 1 \le 64$，时间复杂度为 $O(\log b) = O(1)$（针对固定 64 位字长），空间复杂度为 $O(1)$。
- `pow_mod_u64`：外层循环执行 $O(\log \text{exp})$ 次，每次调用至多两次 `mul_mod_u64`，时间复杂度为 $O(\log \text{exp} \cdot \log \text{mod})$（视 64 位模乘为基本字长操作时为 $O(\log \text{exp})$），额外空间复杂度为 $O(1)$。

## 答案

```c
#include <assert.h>
#include <inttypes.h>
#include <stdbool.h>
#include <stdint.h>
#include <stdio.h>

static uint64_t add_mod_u64(uint64_t x, uint64_t y, uint64_t mod) {
    if (x >= mod - y) {
        return x - (mod - y);
    }
    return x + y;
}

uint64_t mul_mod_u64(uint64_t a, uint64_t b, uint64_t mod) {
    uint64_t u = a % mod;
    uint64_t v = b % mod;
    uint64_t res = 0;

    while (v > 0) {
        if ((v & 1ULL) != 0) {
            res = add_mod_u64(res, u, mod);
        }
        u = add_mod_u64(u, u, mod);
        v >>= 1;
    }
    return res;
}

bool pow_mod_u64(
    uint64_t base,
    uint64_t exp,
    uint64_t mod,
    uint64_t *out_result
) {
    if (out_result == NULL || mod == 0) {
        return false;
    }
    if (mod == 1) {
        *out_result = 0;
        return true;
    }

    uint64_t b = base % mod;
    uint64_t e = exp;
    uint64_t res = 1;

    while (e > 0) {
        if ((e & 1ULL) != 0) {
            res = mul_mod_u64(res, b, mod);
        }
        b = mul_mod_u64(b, b, mod);
        e >>= 1;
    }

    *out_result = res;
    return true;
}

int main(void) {
    const uint64_t large_mod = UINT64_MAX - 58ULL; // 大素数 2^64 - 59
    uint64_t prod = mul_mod_u64(large_mod - 2ULL, large_mod - 3ULL, large_mod);
    assert(prod == 6ULL);

    uint64_t power = 0;
    assert(!pow_mod_u64(2, 10, 0, &power));
    assert(pow_mod_u64(999, 999, 1, &power) && power == 0);
    assert(pow_mod_u64(0, 0, 1000, &power) && power == 1);
    assert(pow_mod_u64(2, 10, 1000, &power) && power == 24);

    // 费马小定理验证：a^(p-1) mod p == 1
    assert(pow_mod_u64(123456789ULL, large_mod - 1ULL, large_mod, &power));
    assert(power == 1ULL);

    printf("All tests passed: 123456789^(p-1) mod p = %" PRIu64 "\n", power);
    return 0;
}
```
