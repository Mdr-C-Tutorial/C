# 31806 - 图表示法空间复杂度分析与格式转换器

## 题目描述

深入对比图的三种主流计算机表示法——**邻接矩阵（Adjacency Matrix）**、**动态邻接表（Adjacency List）**与**链式前向星（Forward Star）**的时空复杂度与硬件缓存局部性特征，并实现三种表示法之间的格式转换器函数：

```c
#include <stdbool.h>
#include <stddef.h>
#include <stdint.h>

typedef struct MatrixGraph MatrixGraph;
typedef struct AdjListGraph AdjListGraph;
typedef struct ForwardStarGraph ForwardStarGraph;

AdjListGraph *matrix_to_adj_list(const MatrixGraph *mat);
ForwardStarGraph *adj_list_to_forward_star(const AdjListGraph *adj);
```

要求：

1. 给出三种表示法在空间占用、边查询时间、单点所有邻接边枚举时间上的综合对比分析，明确稠密图（Dense Graph，$E \approx V^2$）与稀疏图（Sparse Graph，$E \ll V^2$）下的选型决策树。
2. `matrix_to_adj_list` 将邻接矩阵转换为带头尾指针的动态邻接表结构；中途若发生内存分配失败，必须安全清理已分配的半成品并返回 `NULL`。
3. `adj_list_to_forward_star` 将动态邻接表转换为由紧凑数组构成的链式前向星结构，边数组容量恰好精确适配实际边数。
4. 从现代 CPU 体系结构的分支预测、TLB 页面命中与缓存预取角度，阐述为什么链式前向星在稠密遍历时通常具有更低的时钟周期开销。

## 解题思路

### 1. 三大图表示法的多维特征对比矩阵

设图包含 $V$ 个顶点与 $E$ 条边：

| 评估维度 | 邻接矩阵（Matrix） | 动态邻接表（Adj List） | 链式前向星（Forward Star） |
| :--- | :--- | :--- | :--- |
| **空间复杂度** | $\Theta(V^2)$（与边数完全无关） | $\Theta(V + E)$ | $\Theta(V + E)$ |
| **判定边 $(u, v)$ 存在性** | 严格 $O(1)$ | $O(\text{out\_deg}(u))$ | $O(\text{out\_deg}(u))$ |
| **枚举点 $u$ 的全部出边** | $\Theta(V)$（必须扫完整行） | $O(\text{out\_deg}(u))$ | $O(\text{out\_deg}(u))$ |
| **加边操作耗时** | 严格 $O(1)$ | 严格 $O(1)$（头插或尾插） | 严格 $O(1)$（数组头插法） |
| **内存连续性 / 缓存友好度** | 极佳（整块平铺连续二维数组） | 极差（离散指针，高频 Cache Miss） | 极佳（边与表头均在连续数组中） |
| **内存额外开销** | 稀疏时包含大量 $0$ 浪费 | 每个节点承受 8 字节指针+对齐元数据 | 仅纯数据数组，零堆分配器元数据 |

### 2. 选型决策准则

- **稠密图选型（$E \to V^2$）**：
  若边极其密集（如完备图、Floyd 全源最短路、最小割稠密网络），邻接矩阵以极简的地址计算（$u \cdot V + v$）和绝对线性的缓存行加载全面超越链表结构。
- **稀疏图选型（$E \ll V^2$）**：
  当 $V = 10^6$ 而 $E = 5 \times 10^6$ 时，邻接矩阵需要分配 $10^{12}$ 字节（约 1TB 内存），物理上不可行；而邻接表与链式前向星仅需数十兆字节即可完备存储。
- **工程高性能选型**：
  若图结构在建图后不再频繁删边，链式前向星以极致紧凑的数组布局排除了指针反引用（Pointer Chasing），具有最高的指令吞吐率。

### 3. 表示法格式转换与异常安全回滚

转换器设计遵循严格的防御性编程：
1. **矩阵转邻接表**：扫描矩阵中所有真值单元 $(u, v)$，依次调用边构建逻辑挂入邻接表。一旦中间某条边 `malloc` 失败，必须即时调用局部清理释放该顶点链表及前面所有顶点的半成品节点，防止内存泄漏；
2. **邻接表转前向星**：首先遍历一次邻接表统计总边数 $E_{\text{total}}$，随后一次性精确申请容量为 $E_{\text{total}}$ 的平整数组，再将每条边依序映射填入。

## C 语言实现

```c
#include <assert.h>
#include <stdbool.h>
#include <stddef.h>
#include <stdint.h>
#include <stdio.h>
#include <stdlib.h>

typedef struct {
    bool *matrix;
    size_t vertex_count;
    bool directed;
} MatrixGraph;

typedef struct GraphEdge GraphEdge;

struct GraphEdge {
    size_t to;
    GraphEdge *next;
};

typedef struct {
    GraphEdge *head;
    GraphEdge *tail;
} Adjacency;

typedef struct {
    Adjacency *adj;
    size_t vertex_count;
    bool directed;
} AdjListGraph;

typedef struct {
    size_t to;
    size_t next;
    int64_t weight;
} FSEdge;

typedef struct {
    size_t *head;
    FSEdge *edges;
    size_t vertex_count;
    size_t edge_count;
    size_t edge_capacity;
    bool directed;
} ForwardStarGraph;

static void free_adj_list_edges(AdjListGraph *g, size_t limit) {
    if (g == NULL || g->adj == NULL) {
        return;
    }
    for (size_t i = 0; i < limit; ++i) {
        GraphEdge *curr = g->adj[i].head;
        while (curr != NULL) {
            GraphEdge *next = curr->next;
            free(curr);
            curr = next;
        }
    }
}

AdjListGraph *matrix_to_adj_list(const MatrixGraph *mat) {
    if (mat == NULL) {
        return NULL;
    }
    AdjListGraph *g = malloc(sizeof *g);
    if (g == NULL) {
        return NULL;
    }
    g->vertex_count = mat->vertex_count;
    g->directed = mat->directed;
    g->adj = NULL;

    if (mat->vertex_count > 0) {
        if (mat->vertex_count > SIZE_MAX / sizeof(Adjacency)) {
            free(g);
            return NULL;
        }
        g->adj = calloc(mat->vertex_count, sizeof(Adjacency));
        if (g->adj == NULL) {
            free(g);
            return NULL;
        }
    }

    size_t n = mat->vertex_count;
    for (size_t u = 0; u < n; ++u) {
        for (size_t v = 0; v < n; ++v) {
            if (mat->matrix[u * n + v]) {
                GraphEdge *e = malloc(sizeof *e);
                if (e == NULL) {
                    free_adj_list_edges(g, u + 1);
                    free(g->adj);
                    free(g);
                    return NULL;
                }
                e->to = v;
                e->next = NULL;
                if (g->adj[u].head == NULL) {
                    g->adj[u].head = e;
                } else {
                    g->adj[u].tail->next = e;
                }
                g->adj[u].tail = e;
            }
        }
    }
    return g;
}

ForwardStarGraph *adj_list_to_forward_star(const AdjListGraph *adj) {
    if (adj == NULL) {
        return NULL;
    }
    size_t edge_cnt = 0;
    for (size_t i = 0; i < adj->vertex_count; ++i) {
        for (const GraphEdge *e = adj->adj[i].head; e != NULL; e = e->next) {
            edge_cnt++;
        }
    }

    ForwardStarGraph *fs = malloc(sizeof *fs);
    if (fs == NULL) {
        return NULL;
    }
    fs->vertex_count = adj->vertex_count;
    fs->edge_count = 0;
    fs->edge_capacity = edge_cnt;
    fs->directed = adj->directed;
    fs->head = NULL;
    fs->edges = NULL;

    if (adj->vertex_count > 0) {
        fs->head = malloc(adj->vertex_count * sizeof(size_t));
        if (fs->head == NULL) {
            free(fs);
            return NULL;
        }
        for (size_t i = 0; i < adj->vertex_count; ++i) {
            fs->head[i] = SIZE_MAX;
        }
    }
    if (edge_cnt > 0) {
        fs->edges = malloc(edge_cnt * sizeof(FSEdge));
        if (fs->edges == NULL) {
            free(fs->head);
            free(fs);
            return NULL;
        }
    }

    for (size_t u = 0; u < adj->vertex_count; ++u) {
        for (const GraphEdge *e = adj->adj[u].head; e != NULL; e = e->next) {
            size_t idx = fs->edge_count++;
            fs->edges[idx].to = e->to;
            fs->edges[idx].weight = 1;
            fs->edges[idx].next = fs->head[u];
            fs->head[u] = idx;
        }
    }
    return fs;
}

int main(void) {
    MatrixGraph mg;
    mg.vertex_count = 3;
    mg.directed = true;
    bool mat[9] = {
        0, 1, 1,
        0, 0, 1,
        1, 0, 0
    };
    mg.matrix = mat;

    AdjListGraph *alg = matrix_to_adj_list(&mg);
    assert(alg != NULL);
    assert(alg->adj[0].head != NULL && alg->adj[0].head->to == 1);
    assert(alg->adj[0].head->next != NULL && alg->adj[0].head->next->to == 2);

    ForwardStarGraph *fsg = adj_list_to_forward_star(alg);
    assert(fsg != NULL);
    assert(fsg->edge_count == 4);

    free_adj_list_edges(alg, alg->vertex_count);
    free(alg->adj);
    free(alg);

    free(fsg->head);
    free(fsg->edges);
    free(fsg);

    return 0;
}
```

## 复杂度分析

- **时间复杂度**：
  - `matrix_to_adj_list`：必须扫描整个大小为 $V \times V$ 的二维矩阵，时间复杂度为 $\Theta(V^2)$。
  - `adj_list_to_forward_star`：第一趟统计边数遍历全图 $O(V + E)$，第二趟拷贝边对象同样耗时 $O(V + E)$，总时间复杂度严格为线性时间 $O(V + E)$。
- **空间复杂度**：
  - 矩阵转邻接表：新分配了 $V$ 个表头与 $E$ 个链表节点，占用额外空间 $O(V + E)$。
  - 邻接表转前向星：新分配了长度为 $V$ 的表头数组与长度为 $E$ 的边数组，占用额外空间 $O(V + E)$。

## 延伸思考 / 模式总结

1. **图数据处理的 ETL 管道**：在工业图数据库与分布式图计算框架中，离线原始图文件通常以边三元组列表（Edge List）形式导入，随后在数据加载阶段批量转为链式前向星或 CSR 格式固化至共享内存，以提供每秒亿级遍历的吞吐能力。
2. **表示法转换的零拷贝展望**：对于已知边数量的静态图，构建阶段直接在单一整块内存中布局链式前向星，能省去中间动态链表的分配与垃圾回收损耗，体现了系统级高性能编程对“零拷贝”与“无锁数组”的终极追求。
