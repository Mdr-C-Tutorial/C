# 31803 - 邻接矩阵表示法与度数统计

## 题目

实现基于二维扁平数组存储的图邻接矩阵表示法 `MatrixGraph`，支持有向图与无向图建模、边存在性即时判定以及顶点的出度与入度统计：

```c
#include <stdbool.h>
#include <stddef.h>

typedef struct MatrixGraph MatrixGraph;

MatrixGraph *matrix_graph_create(size_t vertex_count, bool directed);
void matrix_graph_destroy(MatrixGraph *graph);
bool matrix_graph_add_edge(MatrixGraph *graph, size_t from, size_t to);
bool matrix_graph_has_edge(const MatrixGraph *graph, size_t from, size_t to, bool *out_has_edge);
bool matrix_graph_degrees(const MatrixGraph *graph, size_t vertex, size_t *out_in_deg, size_t *out_out_deg);
size_t matrix_graph_vertex_count(const MatrixGraph *graph);
```

要求：

1. 顶点编号为 $[0, \text{vertex\_count} - 1]$。底层通过长度为 $V^2$ 的连续布尔数组 `matrix` 紧凑维护。
2. 严谨校验 $V^2$ 的大小计算溢出；若 `vertex_count == 0`，允许创建空图。
3. `matrix_graph_add_edge`：
   - 若为有向图，设置 `matrix[from * V + to] = true`；
   - 若为无向图，必须同时将两个对称槽位 `matrix[from * V + to]` 与 `matrix[to * V + from]` 均置为 `true`。
4. `matrix_graph_has_edge` 在 $O(1)$ 常数时间内完成两顶点间是否存在直接邻接边的查询。
5. `matrix_graph_degrees` 统计顶点 `vertex` 的出度与入度：
   - 对于有向图，分别沿行与列扫描累加出度与入度；
   - 对于无向图，自环使得该顶点的出度和入度均自增 1；普通无向边使两端点度数各加 1。

## 解题思路

### 1. 邻接矩阵的代数表示与内存布局

邻接矩阵 $A \in \{0, 1\}^{V \times V}$ 是图论中最基本、最具代数美感的表示法：
- $A[u][v] = 1$ 表示存在从 $u$ 到 $v$ 的有向边（或无向边）；
- 若图为无向图，则邻接矩阵严格关于主对角线对称：$A = A^T$；
- 矩阵的第 $k$ 次幂 $A^k[u][v]$ 在图论代数中精确对应从顶点 $u$ 到顶点 $v$ 长度恰好为 $k$ 的通路总数。

在 C 语言工程实现中，避免分配 $V$ 个离散指针数组（`bool **`），而是分配一块连续的 $V \times V$ 一维内存块：
$$\text{offset}(u, v) = u \cdot V + v$$
这一平铺设计彻底消除了离散指针开销，并具有极佳的缓存行预取亲和力。

### 2. 度数计算的几何投影

顶点的度数在邻接矩阵中呈现为极度规则的行与列的几何投影：
- **出度（Out-Degree）**：从顶点 $u$ 出发的边数，等于矩阵第 $u$ **行**的全部元素之和：
  $$\text{deg}^+(u) = \sum_{v=0}^{V-1} A[u][v]$$
- **入度（In-Degree）**：指向顶点 $v$ 的边数，等于矩阵第 $v$ **列**的全部元素之和：
  $$\text{deg}^-(v) = \sum_{u=0}^{V-1} A[u][v]$$

对于无向图，由于对称性，$A[u][v] = A[v][u]$，行和与列和恒等，即出度等于入度，均等于无向图顶点的总度数。

## C 语言实现

```c
#include <assert.h>
#include <stdbool.h>
#include <stddef.h>
#include <stdint.h>
#include <stdio.h>
#include <stdlib.h>

typedef struct MatrixGraph MatrixGraph;

struct MatrixGraph {
    bool *matrix;
    size_t vertex_count;
    bool directed;
};

MatrixGraph *matrix_graph_create(size_t vertex_count, bool directed) {
    MatrixGraph *g = malloc(sizeof *g);
    if (g == NULL) {
        return NULL;
    }
    g->vertex_count = vertex_count;
    g->directed = directed;
    g->matrix = NULL;
    if (vertex_count > 0) {
        if (vertex_count > SIZE_MAX / vertex_count) {
            free(g);
            return NULL;
        }
        size_t total = vertex_count * vertex_count;
        if (total > SIZE_MAX / sizeof(bool)) {
            free(g);
            return NULL;
        }
        g->matrix = calloc(total, sizeof(bool));
        if (g->matrix == NULL) {
            free(g);
            return NULL;
        }
    }
    return g;
}

void matrix_graph_destroy(MatrixGraph *graph) {
    if (graph == NULL) {
        return;
    }
    free(graph->matrix);
    free(graph);
}

bool matrix_graph_add_edge(MatrixGraph *graph, size_t from, size_t to) {
    if (graph == NULL || from >= graph->vertex_count || to >= graph->vertex_count) {
        return false;
    }
    graph->matrix[from * graph->vertex_count + to] = true;
    if (!graph->directed) {
        graph->matrix[to * graph->vertex_count + from] = true;
    }
    return true;
}

bool matrix_graph_has_edge(const MatrixGraph *graph, size_t from, size_t to, bool *out_has_edge) {
    if (graph == NULL || out_has_edge == NULL ||
        from >= graph->vertex_count || to >= graph->vertex_count) {
        return false;
    }
    *out_has_edge = graph->matrix[from * graph->vertex_count + to];
    return true;
}

bool matrix_graph_degrees(const MatrixGraph *graph, size_t vertex, size_t *out_in_deg, size_t *out_out_deg) {
    if (graph == NULL || out_in_deg == NULL || out_out_deg == NULL ||
        vertex >= graph->vertex_count) {
        return false;
    }
    size_t in_deg = 0;
    size_t out_deg = 0;
    size_t n = graph->vertex_count;
    for (size_t j = 0; j < n; ++j) {
        if (graph->matrix[vertex * n + j]) {
            out_deg++;
        }
        if (graph->matrix[j * n + vertex]) {
            in_deg++;
        }
    }
    *out_in_deg = in_deg;
    *out_out_deg = out_deg;
    return true;
}

size_t matrix_graph_vertex_count(const MatrixGraph *graph) {
    if (graph == NULL) {
        return 0;
    }
    return graph->vertex_count;
}

int main(void) {
    matrix_graph_destroy(NULL);

    MatrixGraph *g = matrix_graph_create(4, true);
    assert(g != NULL);
    assert(matrix_graph_vertex_count(g) == 4);

    assert(matrix_graph_add_edge(g, 0, 1));
    assert(matrix_graph_add_edge(g, 0, 2));
    assert(matrix_graph_add_edge(g, 2, 0));

    bool has = false;
    assert(matrix_graph_has_edge(g, 0, 1, &has) && has);
    assert(matrix_graph_has_edge(g, 1, 0, &has) && !has);

    size_t in_deg = 0;
    size_t out_deg = 0;
    assert(matrix_graph_degrees(g, 0, &in_deg, &out_deg));
    assert(out_deg == 2 && in_deg == 1);

    assert(matrix_graph_degrees(g, 1, &in_deg, &out_deg));
    assert(out_deg == 0 && in_deg == 1);

    matrix_graph_destroy(g);
    return 0;
}
```

## 复杂度分析

- **时间复杂度**：
  - `matrix_graph_add_edge` 与 `matrix_graph_has_edge`：纯一维偏移量寻址计算，时间复杂度严格为 $O(1)$。
  - `matrix_graph_degrees`：需扫描一整行和一整列，时间复杂度为 $O(V)$。
  - `matrix_graph_create`：内存清零初始化，时间复杂度为 $O(V^2)$。
- **空间复杂度**：无论实际边数 $E$ 有多稀疏，矩阵存储规模恒定为 $V \times V$ 位单元，辅助空间复杂度严格为 $O(V^2)$。

## 延伸思考 / 模式总结

1. **稠密图的绝对王者**：在稠密图（$E \approx V^2$）中，邻接矩阵具有不可替代的统治级优势——判断两点是否有边无需任何链表遍历，严格一条指令完成；同时由于内存完全平铺连续，CPU 预取单元能最大化发挥效能。
2. **位压缩优化空间**：如果图仅需存储有向/无向的无权二元关系，可利用 `uint64_t` 进行 64 倍位压缩（Bitset 矩阵）。不仅使空间占用直降至 $V^2 / 64$ 字节，更可利用 64 位 CPU 的位运算指令（`AND`、`POPCNT`）以字为单位并行计算公共邻居或交集度数。
