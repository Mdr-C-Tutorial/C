# 31802：有向图的出入度统计与转置图构造

## 题目

在 `31801` 的邻接表有向图 `IntGraph` 上实现单点入度与出度统计函数 `int_graph_degrees`，以及构造反转所有边方向的转置有向图 `int_graph_transpose`。

## 解析

在标准出边邻接表表示中，每个顶点 `u` 的链表只存储从 `u` 出发的有向边 `u -> v`：

1. **出度与入度统计 (`int_graph_degrees`)**：顶点 `vertex` 的出度等于其自身邻接链表 `adj[vertex]` 的长度；而入度等于全图所有顶点的邻接链表中终点 `to == vertex` 的边结点总数。遍历全图所有邻接链表一次即可同时统计出度与入度（当扫描到 `u == vertex` 时顺便累加出度），遇到自环 `vertex -> vertex` 时，它既出现在 `adj[vertex]` 中（出度加 $1$），又满足 `edge->to == vertex`（入度加 $1$），无需特殊分支即自然符合图论定义。
2. **转置图构造与半成品回滚 (`int_graph_transpose`)**：首先调用 `int_graph_create(graph->vertex_count, true)` 创建空的转置图对象 `transposed`。随后按 `u = 0 .. vertex_count - 1` 的顺序遍历原图每条边 `u -> v`，在 `transposed` 中调用 `int_graph_add_edge(transposed, v, u)` 追加反向边 `v -> u`。由于每次 `int_graph_add_edge` 都维护了 `transposed` 的结构合法性，一旦某条反向边分配失败，直接调用 `int_graph_destroy(transposed)` 就能把此前已插入的所有反向边结点和邻接表数组完整释放，保证零内存泄漏。

## 答案

```c
#include <stdbool.h>
#include <stddef.h>
#include <stdint.h>
#include <stdlib.h>

typedef struct IntGraph IntGraph;
typedef struct GraphEdge GraphEdge;

struct GraphEdge {
    size_t to;
    GraphEdge *next;
};

typedef struct {
    GraphEdge *head;
    GraphEdge *tail;
} Adjacency;

struct IntGraph {
    Adjacency *adj;
    size_t vertex_count;
    bool directed;
};

IntGraph *int_graph_create(size_t vertex_count, bool directed) {
    IntGraph *graph = malloc(sizeof *graph);
    if (graph == NULL) {
        return NULL;
    }
    graph->adj = NULL;
    graph->vertex_count = vertex_count;
    graph->directed = directed;
    if (vertex_count > 0) {
        if (vertex_count > SIZE_MAX / sizeof *graph->adj) {
            free(graph);
            return NULL;
        }
        graph->adj = calloc(vertex_count, sizeof *graph->adj);
        if (graph->adj == NULL) {
            free(graph);
            return NULL;
        }
    }
    return graph;
}

static GraphEdge *make_edge(size_t to) {
    GraphEdge *edge = malloc(sizeof *edge);
    if (edge == NULL) {
        return NULL;
    }
    edge->to = to;
    edge->next = NULL;
    return edge;
}

static void append_edge(Adjacency *adj, GraphEdge *edge) {
    if (adj->tail == NULL) {
        adj->head = edge;
    } else {
        adj->tail->next = edge;
    }
    adj->tail = edge;
}

bool int_graph_add_edge(
    IntGraph *graph,
    size_t from,
    size_t to
) {
    if (graph == NULL || from >= graph->vertex_count ||
        to >= graph->vertex_count) {
        return false;
    }
    GraphEdge *first = make_edge(to);
    if (first == NULL) {
        return false;
    }
    GraphEdge *second = NULL;
    if (!graph->directed) {
        second = make_edge(from);
        if (second == NULL) {
            free(first);
            return false;
        }
    }
    append_edge(&graph->adj[from], first);
    if (second != NULL) {
        append_edge(&graph->adj[to], second);
    }
    return true;
}

void int_graph_destroy(IntGraph *graph) {
    if (graph == NULL) {
        return;
    }
    for (size_t i = 0; i < graph->vertex_count; ++i) {
        GraphEdge *edge = graph->adj[i].head;
        while (edge != NULL) {
            GraphEdge *next = edge->next;
            free(edge);
            edge = next;
        }
    }
    free(graph->adj);
    free(graph);
}

bool int_graph_degrees(
    const IntGraph *graph,
    size_t vertex,
    size_t *out_in_degree,
    size_t *out_out_degree
) {
    if (graph == NULL || !graph->directed ||
        out_in_degree == NULL || out_out_degree == NULL ||
        vertex >= graph->vertex_count) {
        return false;
    }

    size_t in_degree = 0;
    size_t out_degree = 0;
    for (size_t u = 0; u < graph->vertex_count; ++u) {
        for (const GraphEdge *edge = graph->adj[u].head;
             edge != NULL;
             edge = edge->next) {
            if (u == vertex) {
                if (out_degree == SIZE_MAX) {
                    return false;
                }
                ++out_degree;
            }
            if (edge->to == vertex) {
                if (in_degree == SIZE_MAX) {
                    return false;
                }
                ++in_degree;
            }
        }
    }

    *out_in_degree = in_degree;
    *out_out_degree = out_degree;
    return true;
}

IntGraph *int_graph_transpose(const IntGraph *graph) {
    if (graph == NULL || !graph->directed) {
        return NULL;
    }
    IntGraph *transposed = int_graph_create(
        graph->vertex_count, true
    );
    if (transposed == NULL) {
        return NULL;
    }

    for (size_t u = 0; u < graph->vertex_count; ++u) {
        for (const GraphEdge *edge = graph->adj[u].head;
             edge != NULL;
             edge = edge->next) {
            if (!int_graph_add_edge(transposed, edge->to, u)) {
                int_graph_destroy(transposed);
                return NULL;
            }
        }
    }
    return transposed;
}
```

在邻接表表示下，仅求单点出度只需 $O(\text{deg}^+(v))$，但同时统计入度需扫描全部边，因此 `int_graph_degrees` 的时间复杂度为 $O(V + E)$、额外空间复杂度为 $O(1)$；`int_graph_transpose` 利用链表尾指针以 $O(1)$ 追加每条反向边，总时间复杂度与新建图的空间复杂度均为 $\Theta(V + E)$。
