# 31404 - 二叉树最近公共祖先 (LCA)

## 题目描述

分别在普通二叉树和二叉搜索树（BST）中求解两个指定键值结点的最近公共祖先（Lowest Common Ancestor, LCA）。

```c
#include <stddef.h>

typedef struct TreeNode TreeNode;

struct TreeNode {
    int val;
    TreeNode *left;
    TreeNode *right;
};

const TreeNode *lca_binary_tree(const TreeNode *root, int p_val, int q_val);
const TreeNode *lca_bst(const TreeNode *root, int p_val, int q_val);
```

要求：

1. `lca_binary_tree` 针对无序普通二叉树，基于后序递归自底向上汇总子树匹配信息，时间复杂度为 $O(n)$。
2. `lca_bst` 充分利用二叉搜索树的键值有序性不变式，自顶向下迭代收敛，时间复杂度降至 $O(h)$，额外空间为严格的 $O(1)$。
3. 假设树中所有结点的键值均唯一，且目标键值均存在于树中。

## 解题思路

### 1. 普通二叉树的 LCA（后序自底向上回溯）

由于普通二叉树结点之间没有全序大小关系，我们必须完整检查子树：

- 若当前结点 `root == NULL`，或者 `root->val == p_val` 或 `root->val == q_val`，直接返回当前结点。
- 递归在左子树中寻找目标：`left_lca = lca_binary_tree(root->left, p_val, q_val)`。
- 递归在右子树中寻找目标：`right_lca = lca_binary_tree(root->right, p_val, q_val)`。
- **汇聚决策**：
  - 若 `left_lca` 与 `right_lca` 同时非空，说明目标结点分别散落在当前结点的左右两棵子树中，因此当前结点就是二者的分叉交汇点，即 LCA！
  - 若仅有一侧非空，说明两个目标均位于该侧子树中（或者只找到了其中一个先祖），直接向上传递非空指针即可。

### 2. 二叉搜索树的 LCA（键值引导自顶向下判定）

在 BST 中，对于任意结点 $u$，左子树所有键 $< u.\text{val} <$ 右子树所有键：

- 若 `p_val` 与 `q_val` 均严格小于当前结点的键值，则两个目标必然同时位于左子树中，转向 `curr = curr->left`。
- 若 `p_val` 与 `q_val` 均严格大于当前结点的键值，则两个目标必然同时位于右子树中，转向 `curr = curr->right`。
- **分流判定**：若上述两条件均不成立，说明当前结点的键值恰好落在 `[min(p, q), max(p, q)]` 闭区间内（可能是其中之一等于当前结点，也可能是一个在左、一个在右），此时当前结点就是二者自顶向下分叉的第一个公共祖先，循环立即终止并返回该结点。

## C 语言实现

```c
#include <assert.h>
#include <stdbool.h>
#include <stddef.h>
#include <stdio.h>
#include <stdlib.h>

typedef struct TreeNode {
    int val;
    struct TreeNode *left;
    struct TreeNode *right;
} TreeNode;

static TreeNode *create_node(int val) {
    TreeNode *node = (TreeNode *)malloc(sizeof(TreeNode));
    assert(node != NULL);
    node->val = val;
    node->left = NULL;
    node->right = NULL;
    return node;
}

static void free_tree(TreeNode *root) {
    if (root == NULL) {
        return;
    }
    free_tree(root->left);
    free_tree(root->right);
    free(root);
}

const TreeNode *lca_binary_tree(const TreeNode *root, int p_val, int q_val) {
    if (root == NULL) {
        return NULL;
    }
    if (root->val == p_val || root->val == q_val) {
        return root;
    }

    const TreeNode *left_lca = lca_binary_tree(root->left, p_val, q_val);
    const TreeNode *right_lca = lca_binary_tree(root->right, p_val, q_val);

    if (left_lca != NULL && right_lca != NULL) {
        return root;
    }
    return (left_lca != NULL) ? left_lca : right_lca;
}

const TreeNode *lca_bst(const TreeNode *root, int p_val, int q_val) {
    const TreeNode *curr = root;
    while (curr != NULL) {
        if (p_val < curr->val && q_val < curr->val) {
            curr = curr->left;
        } else if (p_val > curr->val && q_val > curr->val) {
            curr = curr->right;
        } else {
            return curr;
        }
    }
    return NULL;
}

int main(void) {
    /*
    二叉搜索树结构:
              6
            /   \
           2     8
          / \   / \
         0   4 7   9
            / \
           3   5
    */
    TreeNode *root = create_node(6);
    root->left = create_node(2);
    root->right = create_node(8);
    root->left->left = create_node(0);
    root->left->right = create_node(4);
    root->left->right->left = create_node(3);
    root->left->right->right = create_node(5);
    root->right->left = create_node(7);
    root->right->right = create_node(9);

    /* 测试 1: 跨根结点的最近公共祖先 -> 2 与 8 的 LCA 为 6 */
    const TreeNode *lca1_bt = lca_binary_tree(root, 2, 8);
    const TreeNode *lca1_bst = lca_bst(root, 2, 8);
    assert(lca1_bt != NULL && lca1_bt->val == 6);
    assert(lca1_bst != NULL && lca1_bst->val == 6);

    /* 测试 2: 一个结点是另一个结点的祖先 -> 2 与 4 的 LCA 为 2 */
    const TreeNode *lca2_bt = lca_binary_tree(root, 2, 4);
    const TreeNode *lca2_bst = lca_bst(root, 2, 4);
    assert(lca2_bt != NULL && lca2_bt->val == 2);
    assert(lca2_bst != NULL && lca2_bst->val == 2);

    /* 测试 3: 同一子树内的分叉 -> 3 与 5 的 LCA 为 4 */
    const TreeNode *lca3_bt = lca_binary_tree(root, 3, 5);
    const TreeNode *lca3_bst = lca_bst(root, 3, 5);
    assert(lca3_bt != NULL && lca3_bt->val == 4);
    assert(lca3_bst != NULL && lca3_bst->val == 4);

    /* 测试 4: 跨层非对称结构 -> 0 与 5 的 LCA 为 2 */
    const TreeNode *lca4_bt = lca_binary_tree(root, 0, 5);
    const TreeNode *lca4_bst = lca_bst(root, 0, 5);
    assert(lca4_bt != NULL && lca4_bt->val == 2);
    assert(lca4_bst != NULL && lca4_bst->val == 2);

    free_tree(root);
    return 0;
}
```

## 复杂度分析

- **普通二叉树 LCA**：
  - 时间复杂度：最坏情况下需遍历整棵树，为 $O(n)$。
  - 空间复杂度：系统调用栈深度为树高，为 $O(h)$。
- **二叉搜索树 LCA**：
  - 时间复杂度：单向沿一条路径下探，比较次数不超过树高 $h$，为 $O(h)$（平衡时为 $O(\log n)$）。
  - 空间复杂度：采用迭代循环，额外空间为严格的 $O(1)$。

## 延伸思考 / 模式总结

LCA 问题的两种解法深刻反映了“数据结构的不变式如何赋予算法加速能力”。普通二叉树因为缺乏有序性，算法只能做全树扫描；而 BST 通过二叉搜索不变式将问题转化为简单的单向区间分流，展示了有序结构在降维与剪枝上的强大威力。
