# 31404 - Morris 中序遍历与线索恢复

## 题目描述

实现 Morris 中序遍历算法：在不使用系统调用栈、也不分配辅助数据结构的条件下，以严格 $O(1)$ 的额外空间开销完成二叉树的中序遍历，并且在遍历结束后完整恢复二叉树的原有结构不变式。

```c
#include <stddef.h>

typedef struct TreeNode TreeNode;

struct TreeNode {
    int val;
    TreeNode *left;
    TreeNode *right;
};

void morris_inorder(TreeNode *root, int *out, size_t *count);
```

要求：

1. 额外空间复杂度必须为严格的 $O(1)$，禁止使用任何递归调用或动态分配的辅助容器。
2. 遍历结束后，二叉树中所有结点的左右指针必须恢复为初始状态，不得残留悬空线索指针。
3. 空树输入时将 `*count` 置为 0 并安全返回。

## 解题思路

### 1. 为什么常规遍历需要 $O(h)$ 空间

在标准中序遍历中，当访问完某个结点的左子树后，控制流必须返回到该结点本身。因为树的边是指向子结点的单向指针，缺乏逆向父指针，通常必须依靠函数栈或辅助栈保留回溯路径，从而带来 $O(h)$ 的空间开销。

### 2. Morris 线索化核心不变式

Morris 遍历利用了叶结点的空指针域（NULL 指针）来建立临时回溯通路：

- 设当前遍历指针为 `curr`。
- 若 `curr->left == NULL`，说明左子树为空，当前结点本身就是中序序列的下一项，直接记录 `curr->val` 并转向右孩子：`curr = curr->right`。
- 若 `curr->left != NULL`，在 `curr` 的左子树中找到其中序前驱结点 `pred`（即 `curr->left` 沿 `right` 走到底的结点）：
  - **情形 A（初次到达）**：`pred->right == NULL`。将临时线索挂接上去：`pred->right = curr`，然后进入左子树继续探索：`curr = curr->left`。
  - **情形 B（二次到达 / 回溯触发）**：`pred->right == curr`。说明左子树此前已经全部遍历完成，并且正是通过此临时线索回溯到了 `curr`！此时必须**恢复原状**：`pred->right = NULL`，然后记录当前结点的值 `curr->val`，最后转向右子树：`curr = curr->right`。

由于每条边在遍历过程中最多被访问 3 次（找前驱建线索 1 次，真正遍历 1 次，找前驱拆线索 1 次），总时间复杂度依然保持为 $O(n)$。

## C 语言实现

```c
#include <assert.h>
#include <stdbool.h>
#include <stddef.h>
#include <stdio.h>
#include <stdlib.h>

typedef struct TreeNode {
    int val;
    struct TreeNode *left;
    struct TreeNode *right;
} TreeNode;

static TreeNode *create_node(int val) {
    TreeNode *node = (TreeNode *)malloc(sizeof(TreeNode));
    assert(node != NULL);
    node->val = val;
    node->left = NULL;
    node->right = NULL;
    return node;
}

static void free_tree(TreeNode *root) {
    if (root == NULL) {
        return;
    }
    free_tree(root->left);
    free_tree(root->right);
    free(root);
}

void morris_inorder(TreeNode *root, int *out, size_t *count) {
    *count = 0;
    TreeNode *curr = root;
    while (curr != NULL) {
        if (curr->left == NULL) {
            out[(*count)++] = curr->val;
            curr = curr->right;
        } else {
            /* 寻找当前结点在中序遍历中的前驱结点 */
            TreeNode *pred = curr->left;
            while (pred->right != NULL && pred->right != curr) {
                pred = pred->right;
            }

            if (pred->right == NULL) {
                /* 建立回溯线索，转向左孩子 */
                pred->right = curr;
                curr = curr->left;
            } else {
                /* 拆除线索，恢复二叉树原有结构，输出当前结点值并转向右孩子 */
                pred->right = NULL;
                out[(*count)++] = curr->val;
                curr = curr->right;
            }
        }
    }
}

int main(void) {
    /* 测试空树 */
    {
        size_t count = 0;
        int buf[10];
        morris_inorder(NULL, buf, &count);
        assert(count == 0);
    }

    /* 测试标准二叉树:
              4
            /   \
           2     6
          / \   / \
         1   3 5   7
    */
    TreeNode *root = create_node(4);
    root->left = create_node(2);
    root->right = create_node(6);
    root->left->left = create_node(1);
    root->left->right = create_node(3);
    root->right->left = create_node(5);
    root->right->right = create_node(7);

    int out[16];
    size_t count = 0;
    morris_inorder(root, out, &count);
    assert(count == 7);
    for (size_t i = 0; i < 7; ++i) {
        assert(out[i] == (int)(i + 1));
    }

    /* 验证二叉树原有指针结构完好恢复，无悬空或环路 */
    assert(root->val == 4);
    assert(root->left->val == 2);
    assert(root->right->val == 6);
    assert(root->left->left->val == 1);
    assert(root->left->left->right == NULL);
    assert(root->left->right->right == NULL);
    assert(root->right->left->right == NULL);
    assert(root->right->right->right == NULL);

    /* 测试单链退化树 */
    TreeNode *skewed = create_node(3);
    skewed->left = create_node(2);
    skewed->left->left = create_node(1);
    morris_inorder(skewed, out, &count);
    assert(count == 3);
    assert(out[0] == 1 && out[1] == 2 && out[2] == 3);
    assert(skewed->left->left->right == NULL);

    free_tree(root);
    free_tree(skewed);
    return 0;
}
```

## 复杂度分析

- **时间复杂度**：每个包含左孩子的内部结点会被寻找前驱两次（一次建线索，一次拆线索）。所有寻找前驱路径上的边数总和不超过二叉树边数的两倍，故总时间复杂度为严格的 $O(n)$。
- **空间复杂度**：遍历过程中只使用了常数个指针与计数器对象，额外空间复杂度为严格的 $O(1)$。

## 延伸思考 / 模式总结

Morris 算法展示了“利用空闲结构空间暂存控制流状态”的思想。在工程中，这种技术常用于内存极度受限的嵌入式系统；但需要注意的是，由于遍历过程中二叉树结构被临时修改为带有环路的有向图，**Morris 遍历是非线程安全的**，多线程并发只读读取时不能采用此算法。
