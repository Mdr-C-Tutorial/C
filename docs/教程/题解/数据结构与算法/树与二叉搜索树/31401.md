# 31401 - 二叉树递归与非递归遍历

## 题目描述

实现二叉树前序、中序、后序遍历的递归与非递归（显式栈辅助）两种实现版本。

```c
#include <stddef.h>

typedef struct TreeNode TreeNode;

struct TreeNode {
    int val;
    TreeNode *left;
    TreeNode *right;
};

void preorder_rec(const TreeNode *root, int *out, size_t *count);
void inorder_rec(const TreeNode *root, int *out, size_t *count);
void postorder_rec(const TreeNode *root, int *out, size_t *count);

void preorder_iter(const TreeNode *root, int *out, size_t *count);
void inorder_iter(const TreeNode *root, int *out, size_t *count);
void postorder_iter(const TreeNode *root, int *out, size_t *count);
```

要求：

1. 递归版本与非递归版本对于任意合法二叉树输出序列必须完全一致。
2. 非递归版本使用显式分配的栈模拟函数调用帧，空间复杂度不得超过 $O(h)$（$h$ 为树高），遍历过程中不得破坏二叉树原有结构。
3. 空树输入时将 `*count` 置为 0 并安全返回。

## 解题思路

### 1. 遍历递归语义与调用栈映射

二叉树深度优先遍历的本质在于访问根结点与访问左、右子树的时序排列：

- **前序遍历**：访问当前结点 $\to$ 遍历左子树 $\to$ 遍历右子树。
- **中序遍历**：遍历左子树 $\to$ 访问当前结点 $\to$ 遍历右子树。
- **后序遍历**：遍历左子树 $\to$ 遍历右子树 $\to$ 访问当前结点。

### 2. 栈辅助非递归模拟

1. **前序非递归**：利用栈的后进先出（LIFO）特性。根结点入栈，每次弹出栈顶结点并记录其值，随后先将其右孩子压栈、再将左孩子压栈，保证下一轮弹出时左孩子优先出栈。
2. **中序非递归**：维护一个指向当前结点的指针。若当前指针非空，将其压栈并持续向左下探；若当前指针为空，说明左子树已处理完毕，从栈顶弹出结点访问其值，并将当前指针转向该结点的右孩子。
3. **后序非递归（单栈 + 最近访问标记）**：由于后序遍历必须在左右子树均遍历完毕后才访问根结点，因此从栈顶查看结点时，需判断其右孩子是否存在且是否刚刚被访问过。若右孩子存在且未被访问，则当前结点暂不出栈，转向右孩子继续深入；否则说明右子树已处理完成，弹出当前结点并更新最近访问指针。

## C 语言实现

```c
#include <assert.h>
#include <stdbool.h>
#include <stddef.h>
#include <stdio.h>
#include <stdlib.h>

typedef struct TreeNode {
    int val;
    struct TreeNode *left;
    struct TreeNode *right;
} TreeNode;

static TreeNode *create_node(int val) {
    TreeNode *node = (TreeNode *)malloc(sizeof(TreeNode));
    assert(node != NULL);
    node->val = val;
    node->left = NULL;
    node->right = NULL;
    return node;
}

static void free_tree(TreeNode *root) {
    if (root == NULL) {
        return;
    }
    free_tree(root->left);
    free_tree(root->right);
    free(root);
}

void preorder_rec(const TreeNode *root, int *out, size_t *count) {
    if (root == NULL) {
        return;
    }
    out[(*count)++] = root->val;
    preorder_rec(root->left, out, count);
    preorder_rec(root->right, out, count);
}

void inorder_rec(const TreeNode *root, int *out, size_t *count) {
    if (root == NULL) {
        return;
    }
    inorder_rec(root->left, out, count);
    out[(*count)++] = root->val;
    inorder_rec(root->right, out, count);
}

void postorder_rec(const TreeNode *root, int *out, size_t *count) {
    if (root == NULL) {
        return;
    }
    postorder_rec(root->left, out, count);
    postorder_rec(root->right, out, count);
    out[(*count)++] = root->val;
}

typedef struct Stack {
    const TreeNode **data;
    size_t capacity;
    size_t top;
} Stack;

static Stack *stack_create(size_t capacity) {
    Stack *s = (Stack *)malloc(sizeof(Stack));
    assert(s != NULL);
    s->data = (const TreeNode **)malloc(sizeof(const TreeNode *) * capacity);
    assert(s->data != NULL);
    s->capacity = capacity;
    s->top = 0;
    return s;
}

static void stack_free(Stack *s) {
    if (s != NULL) {
        free(s->data);
        free(s);
    }
}

static bool stack_is_empty(const Stack *s) {
    return s->top == 0;
}

static void stack_push(Stack *s, const TreeNode *node) {
    assert(s->top < s->capacity);
    s->data[s->top++] = node;
}

static const TreeNode *stack_pop(Stack *s) {
    assert(s->top > 0);
    return s->data[--s->top];
}

static const TreeNode *stack_peek(const Stack *s) {
    assert(s->top > 0);
    return s->data[s->top - 1];
}

void preorder_iter(const TreeNode *root, int *out, size_t *count) {
    *count = 0;
    if (root == NULL) {
        return;
    }
    Stack *s = stack_create(1024);
    stack_push(s, root);
    while (!stack_is_empty(s)) {
        const TreeNode *node = stack_pop(s);
        out[(*count)++] = node->val;
        if (node->right != NULL) {
            stack_push(s, node->right);
        }
        if (node->left != NULL) {
            stack_push(s, node->left);
        }
    }
    stack_free(s);
}

void inorder_iter(const TreeNode *root, int *out, size_t *count) {
    *count = 0;
    if (root == NULL) {
        return;
    }
    Stack *s = stack_create(1024);
    const TreeNode *curr = root;
    while (curr != NULL || !stack_is_empty(s)) {
        while (curr != NULL) {
            stack_push(s, curr);
            curr = curr->left;
        }
        curr = stack_pop(s);
        out[(*count)++] = curr->val;
        curr = curr->right;
    }
    stack_free(s);
}

void postorder_iter(const TreeNode *root, int *out, size_t *count) {
    *count = 0;
    if (root == NULL) {
        return;
    }
    Stack *s = stack_create(1024);
    const TreeNode *curr = root;
    const TreeNode *last_visited = NULL;

    while (curr != NULL || !stack_is_empty(s)) {
        while (curr != NULL) {
            stack_push(s, curr);
            curr = curr->left;
        }
        const TreeNode *peek = stack_peek(s);
        if (peek->right != NULL && last_visited != peek->right) {
            curr = peek->right;
        } else {
            out[(*count)++] = peek->val;
            last_visited = stack_pop(s);
        }
    }
    stack_free(s);
}

int main(void) {
    /* 测试空树 */
    {
        size_t count1 = 0, count2 = 0;
        int buf1[16], buf2[16];
        preorder_rec(NULL, buf1, &count1);
        preorder_iter(NULL, buf2, &count2);
        assert(count1 == 0 && count2 == 0);
    }

    /* 测试完全二叉树:
             1
           /   \
          2     3
         / \   / \
        4   5 6   7
    */
    TreeNode *root = create_node(1);
    root->left = create_node(2);
    root->right = create_node(3);
    root->left->left = create_node(4);
    root->left->right = create_node(5);
    root->right->left = create_node(6);
    root->right->right = create_node(7);

    int pre_r[16], pre_i[16];
    size_t c_pre_r = 0, c_pre_i = 0;
    preorder_rec(root, pre_r, &c_pre_r);
    preorder_iter(root, pre_i, &c_pre_i);
    assert(c_pre_r == 7 && c_pre_i == 7);
    for (size_t i = 0; i < 7; ++i) {
        assert(pre_r[i] == pre_i[i]);
    }
    int expected_pre[] = {1, 2, 4, 5, 3, 6, 7};
    for (size_t i = 0; i < 7; ++i) {
        assert(pre_r[i] == expected_pre[i]);
    }

    int in_r[16], in_i[16];
    size_t c_in_r = 0, c_in_i = 0;
    inorder_rec(root, in_r, &c_in_r);
    inorder_iter(root, in_i, &c_in_i);
    assert(c_in_r == 7 && c_in_i == 7);
    int expected_in[] = {4, 2, 5, 1, 6, 3, 7};
    for (size_t i = 0; i < 7; ++i) {
        assert(in_r[i] == in_i[i]);
        assert(in_r[i] == expected_in[i]);
    }

    int post_r[16], post_i[16];
    size_t c_post_r = 0, c_post_i = 0;
    postorder_rec(root, post_r, &c_post_r);
    postorder_iter(root, post_i, &c_post_i);
    assert(c_post_r == 7 && c_post_i == 7);
    int expected_post[] = {4, 5, 2, 6, 7, 3, 1};
    for (size_t i = 0; i < 7; ++i) {
        assert(post_r[i] == post_i[i]);
        assert(post_r[i] == expected_post[i]);
    }

    free_tree(root);
    return 0;
}
```

## 复杂度分析

- **时间复杂度**：每个结点进出栈常数次，三种遍历的递归与非递归版本均为严格的 $O(n)$，其中 $n$ 为二叉树结点总数。
- **空间复杂度**：显式栈和隐式调用栈的最大深度均为树的高度 $h$。在最坏退化情形下树高为 $O(n)$，在完全平衡情形下树高为 $O(\log n)$。

## 延伸思考 / 模式总结

非递归遍历的统一抽象模式是**利用状态机或辅助指针将隐式调用帧的断点（Program Counter）显式化**。在后序遍历中，单栈法通过记录“上一个刚刚访问的子结点指针”避免了在左、右子树回溯时的歧义，是理解图的后序深度优先搜索与拓扑排序的关键基石。
