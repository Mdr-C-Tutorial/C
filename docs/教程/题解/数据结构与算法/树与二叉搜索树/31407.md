# 31407 - 数组二叉搜索树合法性验证

## 题目描述

验证一个用数组保存的二叉搜索树结构。结点编号为 `0` 到 `count - 1`，`SIZE_MAX` 表示空孩子：

```c
#include <stdbool.h>
#include <stddef.h>
#include <stdint.h>

typedef struct {
    int64_t key;
    size_t left;
    size_t right;
} BstNode;

bool bst_validate(
    const BstNode *nodes,
    size_t count,
    size_t root
);
```

要求：

1. `count == 0` 时只有 `root == SIZE_MAX` 才合法；非空树的根必须是有效数组下标。
2. 所有孩子下标必须有效或为 `SIZE_MAX`，整棵树必须连通且不能出现环路、共享子树或无法从根到达的孤立结点。
3. 对每个结点，左子树所有键严格更小，右子树所有键严格更大；**严禁**通过 `key - 1` 或 `key + 1` 构造边界（防止在 `INT64_MIN` 与 `INT64_MAX` 处溢出）。
4. 形参无效时返回 `false`；不得修改输入数组。
5. 时间复杂度为 $O(n)$，额外空间复杂度为 $O(n)$。

## 解题思路

### 1. 结构完整性与图遍历染色

数组二叉树可能隐藏三类结构畸变：
- **环路**：某个结点的后代通过孩子指针反向指向了祖先。
- **共享子树（多亲结点）**：两个不同的结点拥有同一个孩子，违反了树中每个非根结点入度为 1 的定义。
- **孤立碎片**：数组中存在无法从 `root` 出发到达的冗余垃圾结点。

为此，引入基于三色标记法（0: 未访问，1: 正在当前路径访问，2: 已完成访问）的 DFS 遍历：
- 若在下探过程中遇到状态为 1 的结点，说明检测到环路；
- 若遇到状态为 2 的结点，说明该子树已被其他路径访问过，检测到共享子树；
- 遍历结束后，扫描状态数组，确认每个结点的状态均为 2。若有任何结点未被访问，则判定存在孤立不可达结点。

### 2. 数学开区间向下传递与防溢出

初学者常试图通过比较 `key < upper` 并把上界设为 `parent_key - 1` 来进行验证。然而当键值为 `INT64_MIN` 时，减 1 会发生有符号整数溢出（未定义行为，UB）。

正确做法是引入两个布尔标记 `has_lower` 和 `has_upper`，分别代表当前子树是否受祖先约束的下界与上界：
- 访问结点时，若 `has_lower && node->key <= lower`，非法；
- 若 `has_upper && node->key >= upper`，非法；
- 向左下探时，上界更新为当前结点的键（`has_upper = true, upper = node->key`），下界保持不变；
- 向右下探时，下界更新为当前结点的键（`has_lower = true, lower = node->key`），上界保持不变。
全程完全无需对键值做任何加减法运算，数学语义严谨且绝对杜绝溢出。

## C 语言实现

```c
#include <assert.h>
#include <stdbool.h>
#include <stddef.h>
#include <stdint.h>
#include <stdlib.h>

typedef struct {
    int64_t key;
    size_t left;
    size_t right;
} BstNode;

static bool validate_node(
    const BstNode *nodes,
    size_t count,
    size_t index,
    unsigned char *state,
    bool has_lower,
    int64_t lower,
    bool has_upper,
    int64_t upper
) {
    if (index == SIZE_MAX || index >= count || state[index] != 0) {
        return false;
    }
    const BstNode *node = &nodes[index];
    if ((has_lower && node->key <= lower) ||
        (has_upper && node->key >= upper)) {
        return false;
    }

    state[index] = 1;
    if (node->left != SIZE_MAX &&
        !validate_node(
            nodes, count, node->left, state,
            has_lower, lower, true, node->key
        )) {
        return false;
    }
    if (node->right != SIZE_MAX &&
        !validate_node(
            nodes, count, node->right, state,
            true, node->key, has_upper, upper
        )) {
        return false;
    }
    state[index] = 2;
    return true;
}

bool bst_validate(
    const BstNode *nodes,
    size_t count,
    size_t root
) {
    if (count == 0) {
        return root == SIZE_MAX;
    }
    if (nodes == NULL || root == SIZE_MAX || root >= count ||
        count > SIZE_MAX / sizeof(unsigned char)) {
        return false;
    }
    unsigned char *state = (unsigned char *)calloc(count, sizeof *state);
    if (state == NULL) {
        return false;
    }
    bool valid = validate_node(
        nodes, count, root, state,
        false, 0, false, 0
    );
    if (valid) {
        for (size_t i = 0; i < count; ++i) {
            if (state[i] != 2) {
                valid = false;
                break;
            }
        }
    }
    free(state);
    return valid;
}

int main(void) {
    /* 1. 空树检验 */
    assert(bst_validate(NULL, 0, SIZE_MAX));
    assert(!bst_validate(NULL, 0, 0));

    /* 2. 合法二叉搜索树
            10 (下标 0)
           /  \
      5 (下标 1) 15 (下标 2)
    */
    BstNode valid_tree[] = {
        {.key = 10, .left = 1, .right = 2},
        {.key = 5, .left = SIZE_MAX, .right = SIZE_MAX},
        {.key = 15, .left = SIZE_MAX, .right = SIZE_MAX}
    };
    assert(bst_validate(valid_tree, 3, 0));

    /* 3. 极值测试：边界包含 INT64_MIN 与 INT64_MAX */
    BstNode extreme_tree[] = {
        {.key = 0, .left = 1, .right = 2},
        {.key = INT64_MIN, .left = SIZE_MAX, .right = SIZE_MAX},
        {.key = INT64_MAX, .left = SIZE_MAX, .right = SIZE_MAX}
    };
    assert(bst_validate(extreme_tree, 3, 0));

    /* 4. 局部合法但全局破坏 BST 顺序的反例
            10 (0)
           /
          5 (1)
           \
           12 (2)  --> 12 位于 10 的左子树中却大于 10
    */
    BstNode invalid_tree[] = {
        {.key = 10, .left = 1, .right = SIZE_MAX},
        {.key = 5, .left = SIZE_MAX, .right = 2},
        {.key = 12, .left = SIZE_MAX, .right = SIZE_MAX}
    };
    assert(!bst_validate(invalid_tree, 3, 0));

    /* 5. 环路测试 */
    BstNode cycle_tree[] = {
        {.key = 10, .left = 1, .right = SIZE_MAX},
        {.key = 5, .left = 0, .right = SIZE_MAX}
    };
    assert(!bst_validate(cycle_tree, 2, 0));

    /* 6. 包含不可达碎片结点测试 */
    BstNode orphan_tree[] = {
        {.key = 10, .left = SIZE_MAX, .right = SIZE_MAX},
        {.key = 20, .left = SIZE_MAX, .right = SIZE_MAX}
    };
    assert(!bst_validate(orphan_tree, 2, 0));

    return 0;
}
```

## 复杂度分析

- **时间复杂度**：每个结点仅被 DFS 访问一次，随后进行一次 $O(n)$ 的线性扫描确认状态，总时间复杂度为严格的 $O(n)$。
- **空间复杂度**：`calloc` 分配大小为 $n$ 字节的状态数组，递归调用栈深度在最坏情况下为 $n$，故额外空间复杂度为 $O(n)$。

## 延伸思考 / 模式总结

在以数组形式组织树或图的紧凑存储结构（如平坦化序列化或内存映射文件）中，下标越界、反向环路与不可达死区是必须严防的常见漏洞。本题将“图的无环单连通性校验”与“二叉搜索树的全局偏序区间校验”结合起来，为二进制反序列化校验器提供了标准模板。
