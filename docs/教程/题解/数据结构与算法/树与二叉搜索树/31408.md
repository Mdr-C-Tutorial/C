# 31408 - 前序与中序序列重建二叉树

## 题目描述

给定一棵二叉树的前序遍历序列与中序遍历序列（假设树中所有结点的键值均唯一且不重复），重建出该二叉树的完整链式物理结构。

```c
#include <stddef.h>

typedef struct TreeNode TreeNode;

struct TreeNode {
    int val;
    TreeNode *left;
    TreeNode *right;
};

TreeNode *build_tree_pre_in(
    const int *preorder,
    const int *inorder,
    size_t n
);

void free_tree(TreeNode *root);
```

要求：

1. 前序序列的第一个元素必然是当前子树的根结点。在中序序列中定位该根结点的物理位置，以此将中序序列划分为左子树部分与右子树部分。
2. 依据左子树包含的结点数量，在前序序列中切分出左子树与右子树的前序区间，递归构建左右子树。
3. 若传入序列长度为 0 或指针为空，安全返回 `NULL`。
4. 若传入序列存在矛盾（如前序中出现的键在中序对应切片中未找到），必须安全清理已分配的结点并返回 `NULL`，严禁内存泄漏。

## 解题思路

### 1. 递归分治与区间划分不变式

对于包含 $n$ 个结点的任意树或子树：
- **前序遍历结构**：`[ 根结点 (1个) | 左子树前序序列 (k个) | 右子树前序序列 (n - 1 - k个) ]`
- **中序遍历结构**：`[ 左子树中序序列 (k个) | 根结点 (1个) | 右子树中序序列 (n - 1 - k个) ]`

分步推导如下：
1. 取根结点键值 `root_val = preorder[0]`，在堆上分配新结点；
2. 在中序序列 `inorder[0 .. n - 1]` 中线性扫描寻找值等于 `root_val` 的下标 $k$；
3. 左子树的结点个数恰好为 $k$：
   - 左子树的前序切片为：`preorder + 1`，长度为 $k$；
   - 左子树的中序切片为：`inorder`，长度为 $k$；
4. 右子树的结点个数为 $n - 1 - k$：
   - 右子树的前序切片为：`preorder + 1 + k`，长度为 $n - 1 - k$；
   - 右子树的中序切片为：`inorder + k + 1`，长度为 $n - 1 - k$；
5. 递归构建左右子结点并挂接在根结点上，返回根结点指针。

## C 语言实现

```c
#include <assert.h>
#include <stdbool.h>
#include <stddef.h>
#include <stdio.h>
#include <stdlib.h>

typedef struct TreeNode {
    int val;
    struct TreeNode *left;
    struct TreeNode *right;
} TreeNode;

static TreeNode *create_node(int val) {
    TreeNode *node = (TreeNode *)malloc(sizeof(TreeNode));
    assert(node != NULL);
    node->val = val;
    node->left = NULL;
    node->right = NULL;
    return node;
}

void free_tree(TreeNode *root) {
    if (root == NULL) {
        return;
    }
    free_tree(root->left);
    free_tree(root->right);
    free(root);
}

TreeNode *build_tree_pre_in(const int *preorder, const int *inorder, size_t n) {
    if (preorder == NULL || inorder == NULL || n == 0) {
        return NULL;
    }

    int root_val = preorder[0];
    TreeNode *root = create_node(root_val);

    /* 在中序序列中定位根结点位置 */
    size_t k = 0;
    while (k < n && inorder[k] != root_val) {
        k++;
    }
    if (k == n) {
        /* 输入数据不一致矛盾，销毁当前分配并失败返回 */
        free(root);
        return NULL;
    }

    size_t left_size = k;
    size_t right_size = n - 1 - k;

    root->left = build_tree_pre_in(preorder + 1, inorder, left_size);
    root->right = build_tree_pre_in(preorder + 1 + left_size, inorder + k + 1, right_size);

    return root;
}

static void postorder_collect(const TreeNode *root, int *out, size_t *count) {
    if (root == NULL) {
        return;
    }
    postorder_collect(root->left, out, count);
    postorder_collect(root->right, out, count);
    out[(*count)++] = root->val;
}

int main(void) {
    /* 1. 测试空输入 */
    assert(build_tree_pre_in(NULL, NULL, 0) == NULL);

    /* 2. 测试单结点树 */
    int pre1[] = {42};
    int in1[] = {42};
    TreeNode *t1 = build_tree_pre_in(pre1, in1, 1);
    assert(t1 != NULL && t1->val == 42 && t1->left == NULL && t1->right == NULL);
    free_tree(t1);

    /* 3. 测试标准多层树:
            3
           / \
          9   20
             /  \
            15   7
       前序序列: [3, 9, 20, 15, 7]
       中序序列: [9, 3, 15, 20, 7]
       对应后序: [9, 15, 7, 20, 3]
    */
    int pre[] = {3, 9, 20, 15, 7};
    int in[]  = {9, 3, 15, 20, 7};
    int expected_post[] = {9, 15, 7, 20, 3};

    TreeNode *root = build_tree_pre_in(pre, in, 5);
    assert(root != NULL);
    assert(root->val == 3);
    assert(root->left->val == 9);
    assert(root->right->val == 20);
    assert(root->right->left->val == 15);
    assert(root->right->right->val == 7);

    /* 验证生成树的后序遍历 */
    int post[10];
    size_t count = 0;
    postorder_collect(root, post, &count);
    assert(count == 5);
    for (size_t i = 0; i < 5; ++i) {
        assert(post[i] == expected_post[i]);
    }

    free_tree(root);
    return 0;
}
```

## 复杂度分析

- **时间复杂度**：每一层递归需要在线性中序切片中扫描定位根结点，扫描耗时为 $O(k)$。若树高平衡，递归方程为 $T(n) = 2T(n/2) + O(n)$，时间复杂度为 $O(n \log n)$；若使用哈希表对中序元素下标预建立索引映射，时间复杂度可优化至严格的 $O(n)$。在最坏退化为单链时，总耗时为 $O(n^2)$。
- **空间复杂度**：递归栈深度为树的高度 $h$，在平衡时为 $O(\log n)$，最坏退化情形下为 $O(n)$。

## 延伸思考 / 模式总结

只有前序序列与后序序列**无法**唯一确定一棵二叉树，因为无法确定单孩子分支究竟是左孩子还是右孩子；但**中序遍历**提供了明确的左右物理分割界限，因此“前序 + 中序”或“后序 + 中序”都可以唯一确定一棵二叉树。这是分治法在树形数据恢复与语法树重建中的经典应用。
