# 31604 - 二叉堆数组表示与索引计算

## 题目

二叉堆通常使用连续内存数组进行紧凑存储。对于基于 $0$ 的下标体系，实现一系列父子节点检索、叶节点判断、最后非叶节点定位及堆序不变式验证函数：

```c
#include <stdbool.h>
#include <stddef.h>
#include <stdint.h>

bool heap_parent(size_t index, size_t *out_parent);
bool heap_left_child(size_t index, size_t size, size_t *out_left);
bool heap_right_child(size_t index, size_t size, size_t *out_right);
bool heap_is_leaf(size_t index, size_t size);
size_t heap_last_non_leaf(size_t size);
bool heap_is_max_heap(const int64_t *array, size_t size);
bool heap_is_min_heap(const int64_t *array, size_t size);
```

要求：

1. 根节点下标为 $0$。若 `index == 0`，不存在父节点，`heap_parent` 返回 `false` 且不修改输出对象；若 `index > 0`，父节点下标为 `(index - 1) / 2`，写入 `*out_parent` 并返回 `true`。
2. 左孩子下标为 `2 * index + 1`，右孩子下标为 `2 * index + 2`。必须严谨防范整数乘法与加法溢出；若计算出的子节点下标超出 `size - 1` 或发生溢出，返回 `false` 且不修改输出对象。
3. `heap_is_leaf` 判定下标 `index` 在规模为 `size` 的二叉堆中是否为叶节点。若 `index >= size`，返回 `false`；若没有合法的左孩子（即 `index >= size / 2` 且 `index < size`），判定为叶节点并返回 `true`。
4. `heap_last_non_leaf` 计算并返回规模为 `size` 的二叉堆中最后一个非叶节点的下标。若 `size <= 1`，不存在非叶节点，返回 `0`；若 `size >= 2`，返回 `(size / 2) - 1`。
5. `heap_is_max_heap` 与 `heap_is_min_heap` 遍历所有非叶节点，验证堆序不变式是否全局成立。空堆或单节点堆恒返回 `true`；若数组指针参数为 `NULL` 且 `size > 0`，返回 `false`。

## 解题思路

### 1. 数组隐式树形拓扑映射

完全二叉树的几何性质决定了其节点可以无缝紧凑映射到一维数组中：
- 若根节点置于下标 $0$：
  - 节点 $i$ 的左孩子下标为 $2i + 1$；
  - 节点 $i$ 的右孩子下标为 $2i + 2$；
  - 节点 $i$ 的父节点下标为 $\lfloor (i - 1) / 2 \rfloor$。
- 若采用基于 $1$ 的下标体系（常用于教材纯理论展示），节点 $i$ 的子节点为 $2i$ 与 $2i + 1$，父节点为 $\lfloor i / 2 \rfloor$。基于 $0$ 的体系与 C 语言原生数组无缝契合，无需浪费下标 $0$ 处的存储单元。

### 2. 算术溢出与边界防御

在 64 位无符号整数 `size_t` 下，$2i + 1$ 或 $2i + 2$ 可能发生算术溢出：
- 当 $i > (\text{SIZE\_MAX} - 1) / 2$ 时，$2i + 1$ 必发生溢出；
- 当 $i > (\text{SIZE\_MAX} - 2) / 2$ 时，$2i + 2$ 必发生溢出。
前置防溢出校验是不受信任数据输入下的必要防御性措施。

### 3. 叶节点划分定理

对于规模为 $n$ 的完全二叉树：
- 内部节点（非叶节点）的个数恰为 $\lfloor n / 2 \rfloor$；
- 最后一个非叶节点的下标为 $\lfloor n / 2 \rfloor - 1$（当 $n \ge 2$ 时）；
- 下标满足 $i \ge \lfloor n / 2 \rfloor$ 且 $i < n$ 的节点均为叶节点。
这一性质使得在线性时间建堆（Floyd Build-Heap）中，只需从最后一个非叶节点向前逆序下滤即可，节省了一半以上无意义的叶节点下滤开销。

## C 语言实现

```c
#include <assert.h>
#include <stdbool.h>
#include <stddef.h>
#include <stdint.h>
#include <stdio.h>

bool heap_parent(size_t index, size_t *out_parent) {
    if (out_parent == NULL || index == 0) {
        return false;
    }
    *out_parent = (index - 1) / 2;
    return true;
}

bool heap_left_child(size_t index, size_t size, size_t *out_left) {
    if (out_left == NULL || index >= size) {
        return false;
    }
    if (index > (SIZE_MAX - 1) / 2) {
        return false;
    }
    size_t left = index * 2 + 1;
    if (left >= size) {
        return false;
    }
    *out_left = left;
    return true;
}

bool heap_right_child(size_t index, size_t size, size_t *out_right) {
    if (out_right == NULL || index >= size) {
        return false;
    }
    if (index > (SIZE_MAX - 2) / 2) {
        return false;
    }
    size_t right = index * 2 + 2;
    if (right >= size) {
        return false;
    }
    *out_right = right;
    return true;
}

bool heap_is_leaf(size_t index, size_t size) {
    if (index >= size) {
        return false;
    }
    return index >= size / 2;
}

size_t heap_last_non_leaf(size_t size) {
    if (size <= 1) {
        return 0;
    }
    return (size / 2) - 1;
}

bool heap_is_max_heap(const int64_t *array, size_t size) {
    if (size > 0 && array == NULL) {
        return false;
    }
    if (size <= 1) {
        return true;
    }
    size_t non_leaf_count = size / 2;
    for (size_t i = 0; i < non_leaf_count; ++i) {
        size_t left = i * 2 + 1;
        if (array[left] > array[i]) {
            return false;
        }
        size_t right = left + 1;
        if (right < size && array[right] > array[i]) {
            return false;
        }
    }
    return true;
}

bool heap_is_min_heap(const int64_t *array, size_t size) {
    if (size > 0 && array == NULL) {
        return false;
    }
    if (size <= 1) {
        return true;
    }
    size_t non_leaf_count = size / 2;
    for (size_t i = 0; i < non_leaf_count; ++i) {
        size_t left = i * 2 + 1;
        if (array[left] < array[i]) {
            return false;
        }
        size_t right = left + 1;
        if (right < size && array[right] < array[i]) {
            return false;
        }
    }
    return true;
}

int main(void) {
    size_t p = 999;
    assert(!heap_parent(0, &p));
    assert(p == 999);
    assert(heap_parent(1, &p) && p == 0);
    assert(heap_parent(2, &p) && p == 0);
    assert(heap_parent(3, &p) && p == 1);
    assert(heap_parent(4, &p) && p == 1);
    assert(heap_parent(5, &p) && p == 2);
    assert(heap_parent(6, &p) && p == 2);

    size_t c = 999;
    assert(heap_left_child(0, 10, &c) && c == 1);
    assert(heap_right_child(0, 10, &c) && c == 2);
    assert(heap_left_child(4, 10, &c) && c == 9);
    assert(!heap_right_child(4, 10, &c));
    assert(!heap_left_child(5, 10, &c));
    assert(!heap_left_child(10, 10, &c));

    assert(!heap_is_leaf(0, 5));
    assert(!heap_is_leaf(1, 5));
    assert(heap_is_leaf(2, 5));
    assert(heap_is_leaf(3, 5));
    assert(heap_is_leaf(4, 5));
    assert(!heap_is_leaf(5, 5));

    assert(heap_last_non_leaf(0) == 0);
    assert(heap_last_non_leaf(1) == 0);
    assert(heap_last_non_leaf(2) == 0);
    assert(heap_last_non_leaf(3) == 0);
    assert(heap_last_non_leaf(4) == 1);
    assert(heap_last_non_leaf(5) == 1);
    assert(heap_last_non_leaf(6) == 2);

    int64_t max_h[] = {90, 80, 70, 60, 50, 40, 30};
    assert(heap_is_max_heap(max_h, 7));
    assert(!heap_is_min_heap(max_h, 7));

    int64_t min_h[] = {10, 20, 30, 40, 50, 60, 70};
    assert(heap_is_min_heap(min_h, 7));
    assert(!heap_is_max_heap(min_h, 7));

    int64_t invalid_h[] = {90, 50, 70, 80};
    assert(!heap_is_max_heap(invalid_h, 4));

    return 0;
}
```

## 复杂度分析

- **时间复杂度**：
  - `heap_parent`、`heap_left_child`、`heap_right_child`、`heap_is_leaf`、`heap_last_non_leaf` 均为简单的纯算术求值与分支判断，时间复杂度严格为 $O(1)$。
  - `heap_is_max_heap` 与 `heap_is_min_heap` 需遍历所有非叶节点（共 $\lfloor n / 2 \rfloor$ 个），对每个节点进行至多 2 次比较，时间复杂度为 $O(n)$。
- **空间复杂度**：除形参与常量寄存器外不申请任何动态内存，辅助空间复杂度严格为 $O(1)$。

## 延伸思考 / 模式总结

1. **完全二叉树的连续存储红利**：与普通二叉树需要存储左右子节点指针不同，完全二叉树利用数组下标隐藏拓扑结构，不仅免去了每一个节点 $2 \times 8$ 字节的指针开销，更保证了极其优秀的 CPU 缓存局部性（Cache Locality）。
2. **防溢出算术模式**：在系统级 C 语言编程中，计算子节点下标时的 `2 * i + 1` 极易被忽视。通过比较 `index > (SIZE_MAX - 1) / 2` 进行守卫，避免了无符号整数绕回导致的缓冲区非法越界，是编写健壮基础设施的关键准则。
