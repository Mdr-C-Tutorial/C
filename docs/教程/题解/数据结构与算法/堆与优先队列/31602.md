# 31602 - 二叉大顶堆上滤与下滤

## 题目描述

实现不透明的大顶堆抽象数据类型 `IntMaxHeap`，支持动态插入元素、查看最大值以及弹出最大值，并在底层完整实现上滤（sift up）与下滤（sift down）核心调整算法：

```c
#include <stdbool.h>
#include <stddef.h>
#include <stdint.h>

typedef struct IntMaxHeap IntMaxHeap;

IntMaxHeap *int_max_heap_create(void);
void int_max_heap_destroy(IntMaxHeap *heap);
bool int_max_heap_push(IntMaxHeap *heap, int64_t value);
bool int_max_heap_peek(const IntMaxHeap *heap, int64_t *out_value);
bool int_max_heap_pop(IntMaxHeap *heap, int64_t *out_value);
size_t int_max_heap_size(const IntMaxHeap *heap);
```

要求：

1. 内部数组表示必须严格保持大顶堆不变式：对于除根节点外的每一个节点 $i$，其键值均不大于其父节点键值（`heap[parent] >= heap[i]`）。
2. 堆拥有独立的动态内存存储；在容量不足时自动以 2 倍策略平摊扩容。若扩容失败或容量计算溢出，`push` 返回 `false`，堆必须维持原结构完好不变。
3. 空堆或参数无效时，`peek` 与 `pop` 返回 `false`，且严禁修改输出对象。
4. `int_max_heap_destroy(NULL)` 保证安全无副作用；`int_max_heap_size(NULL)` 返回 `0`。
5. `push` 与 `pop` 的时间复杂度应保证为 $O(\log n)$，`peek` 为 $O(1)$。

## 解题思路

### 1. 大顶堆结构设计与 ADT 封装

在头文件中仅暴露不透明结构体指针 `IntMaxHeap *`，将底层成员隐藏于实现文件中：
```c
struct IntMaxHeap {
    int64_t *items;
    size_t size;
    size_t capacity;
};
```
堆的规模由 `size` 维护，实际分配槽位数由 `capacity` 跟踪。动态扩容采用成倍扩展策略，平摊单次插入的重新分配时间复杂度为 $O(1)$。

### 2. 上滤（Sift Up）与插入操作

当新元素入堆时，将其置于数组末尾（下标为 `size`），此时完全二叉树的拓扑结构保持完整，但可能破坏堆序不变式：
1. 记当前考察下标为 `index`。计算其父节点下标 `parent = (index - 1) / 2`。
2. 若 `items[parent] < items[index]`，说明子节点比父节点大，违反大顶堆序，交换两节点值。
3. 令 `index = parent`，沿树高继续向上攀爬比较，直到 `index == 0` 或 `items[parent] >= items[index]` 为止。
由于树的高度为 $\lfloor \log_2 n \rfloor$，上滤操作至多执行 $O(\log n)$ 次比较与交换。

### 3. 下滤（Sift Down）与删除最大值

弹出堆顶元素时，若直接移除根节点会使树分裂为两棵子树。经典解法为：
1. 取出根节点 `items[0]` 保存至输出对象。
2. 将数组末尾的最后一个元素 `items[size - 1]` 移到根节点 `items[0]` 处，规模减 1。
3. 此时左右子树各自仍满足大顶堆不变式，仅根节点可能破坏大顶堆序。从根节点开始执行下滤：
   - 比较当前节点与其左、右孩子的值；
   - 找出三者中的最大者；
   - 若当前节点已是最大者，堆序恢复，终止下滤；
   - 否则将当前节点与键值最大的子节点交换，并沿该子节点分支继续向下迭代。
由于每次至多沿一条高为 $\lfloor \log_2 n \rfloor$ 的单链下行，下滤时间复杂度同样严格为 $O(\log n)$。

## C 语言实现

```c
#include <assert.h>
#include <stdbool.h>
#include <stddef.h>
#include <stdint.h>
#include <stdio.h>
#include <stdlib.h>

typedef struct IntMaxHeap IntMaxHeap;

struct IntMaxHeap {
    int64_t *items;
    size_t size;
    size_t capacity;
};

IntMaxHeap *int_max_heap_create(void) {
    IntMaxHeap *heap = malloc(sizeof *heap);
    if (heap == NULL) {
        return NULL;
    }
    heap->items = NULL;
    heap->size = 0;
    heap->capacity = 0;
    return heap;
}

void int_max_heap_destroy(IntMaxHeap *heap) {
    if (heap == NULL) {
        return;
    }
    free(heap->items);
    free(heap);
}

static void swap_i64(int64_t *left, int64_t *right) {
    int64_t temp = *left;
    *left = *right;
    *right = temp;
}

static void sift_up(IntMaxHeap *heap, size_t index) {
    while (index > 0) {
        size_t parent = (index - 1) / 2;
        if (heap->items[parent] >= heap->items[index]) {
            break;
        }
        swap_i64(&heap->items[parent], &heap->items[index]);
        index = parent;
    }
}

static void sift_down(IntMaxHeap *heap, size_t index) {
    while (index < heap->size / 2) {
        size_t left = index * 2 + 1;
        size_t right = left + 1;
        size_t largest = index;

        if (heap->items[left] > heap->items[largest]) {
            largest = left;
        }
        if (right < heap->size && heap->items[right] > heap->items[largest]) {
            largest = right;
        }
        if (largest == index) {
            break;
        }
        swap_i64(&heap->items[index], &heap->items[largest]);
        index = largest;
    }
}

static bool heap_reserve(IntMaxHeap *heap) {
    if (heap->size < heap->capacity) {
        return true;
    }
    size_t max_cap = SIZE_MAX / sizeof(int64_t);
    if (heap->capacity >= max_cap) {
        return false;
    }
    size_t next = heap->capacity == 0 ? 8 : heap->capacity;
    if (next > max_cap / 2) {
        next = max_cap;
    } else {
        next *= 2;
    }
    if (next <= heap->size) {
        return false;
    }
    int64_t *new_items = realloc(heap->items, next * sizeof(int64_t));
    if (new_items == NULL) {
        return false;
    }
    heap->items = new_items;
    heap->capacity = next;
    return true;
}

bool int_max_heap_push(IntMaxHeap *heap, int64_t value) {
    if (heap == NULL) {
        return false;
    }
    if (!heap_reserve(heap)) {
        return false;
    }
    heap->items[heap->size] = value;
    sift_up(heap, heap->size);
    heap->size++;
    return true;
}

bool int_max_heap_peek(const IntMaxHeap *heap, int64_t *out_value) {
    if (heap == NULL || out_value == NULL || heap->size == 0) {
        return false;
    }
    *out_value = heap->items[0];
    return true;
}

bool int_max_heap_pop(IntMaxHeap *heap, int64_t *out_value) {
    if (heap == NULL || out_value == NULL || heap->size == 0) {
        return false;
    }
    *out_value = heap->items[0];
    heap->size--;
    if (heap->size > 0) {
        heap->items[0] = heap->items[heap->size];
        sift_down(heap, 0);
    }
    return true;
}

size_t int_max_heap_size(const IntMaxHeap *heap) {
    if (heap == NULL) {
        return 0;
    }
    return heap->size;
}

int main(void) {
    int_max_heap_destroy(NULL);
    assert(int_max_heap_size(NULL) == 0);

    IntMaxHeap *heap = int_max_heap_create();
    assert(heap != NULL);
    assert(int_max_heap_size(heap) == 0);

    int64_t val = 0;
    assert(!int_max_heap_peek(heap, &val));
    assert(!int_max_heap_pop(heap, &val));

    int64_t nums[] = {15, 10, 40, 30, 25, 5, 50};
    for (size_t i = 0; i < sizeof(nums) / sizeof(nums[0]); ++i) {
        assert(int_max_heap_push(heap, nums[i]));
    }
    assert(int_max_heap_size(heap) == 7);

    assert(int_max_heap_peek(heap, &val) && val == 50);

    int64_t expected[] = {50, 40, 30, 25, 15, 10, 5};
    for (size_t i = 0; i < sizeof(expected) / sizeof(expected[0]); ++i) {
        assert(int_max_heap_pop(heap, &val));
        assert(val == expected[i]);
    }
    assert(int_max_heap_size(heap) == 0);
    assert(!int_max_heap_pop(heap, &val));

    int_max_heap_destroy(heap);
    return 0;
}
```

## 复杂度分析

- **时间复杂度**：
  - `int_max_heap_push`：平摊动态数组扩容时间为 $O(1)$，上滤遍历树高路径，单次最坏情况为 $O(\log n)$。
  - `int_max_heap_pop`：将末尾元素移至根后进行下滤，每层进行至多 2 次比较，单次最坏情况为 $O(\log n)$。
  - `int_max_heap_peek` 与 `int_max_heap_size`：直接访问数组头部或结构体成员，严格为 $O(1)$。
- **空间复杂度**：动态数组持有 $n$ 个元素连续存储，空间复杂度为 $O(n)$。

## 延伸思考 / 模式总结

1. **局部性质驱动全局不变式**：无论是上滤还是下滤，算法均通过局部交换违反堆序的父子节点对，逐步将违例“挤压”至边界（堆顶或叶底）直至消解。由于每次交换只涉及一条祖先后代分支，其余兄弟子树的堆序性质不受任何干扰。
2. **异常安全防御设计**：在 `heap_reserve` 扩容失败时，原有的 `heap->items` 未被改写破坏，此时直接返回 `false`，堆内既有数据完全处于一致状态，达成了强异常安全保证。
