# 32006 - 外存 I/O 成本模型与页缓存模拟器

## 题目描述

实现外存数据结构（External Memory Data Structures）的核心基础——固定帧容量的页对齐块缓存模拟器（Buffer Pool Manager），基于 LRU（Least Recently Used）淘汰置换策略，准确度量外存读写 I/O 次数与脏页回写成本。

```c
#include <stdbool.h>
#include <stddef.h>
#include <stdint.h>

typedef struct BufferPool BufferPool;

BufferPool *buffer_pool_create(size_t num_frames, size_t page_size);
void buffer_pool_destroy(BufferPool *pool);
bool buffer_pool_read_page(BufferPool *pool, uint64_t page_id, void *out_buf);
bool buffer_pool_write_page(BufferPool *pool, uint64_t page_id, const void *in_buf);
void buffer_pool_get_stats(
    const BufferPool *pool,
    size_t *out_hits,
    size_t *out_misses,
    size_t *out_flushes
);
```

要求：

1. **缓存帧池设计**：缓存池维护固定数量 `num_frames` 的物理内存帧，每个帧大小严格等于块大小 `page_size`。
2. **LRU 淘汰链表**：双向链表管理帧的使用热度。每次读取或写入命中时，将对应帧提升至 MRU（最近刚使用）头部；当发生缓存未命中且无空闲帧时，淘汰位于 LRU 尾部的冷页面。
3. **脏页延迟回写（Dirty Page Write-Back）**：页面被修改（`write_page`）后标记为 `dirty = true`。淘汰脏页时，必须将其回写外存（模拟触发一次磁盘写入 I/O，递增 `flushes`）；淘汰干净页面则无需回写，直接覆盖复用。
4. 提供精确的性能统计：读取与写入命中数 `hits`、未命中物理读取数 `misses`、脏页回写磁盘数 `flushes`。

## 解题思路

### 1. 外存 I/O 复杂度模型（Aggarwal-Vitter 模型）

在现代计算机体系结构中，主存访问延迟约为数十纳秒，而机械磁盘寻道或闪存随机读取延迟在毫秒或数十微秒级，两者相差 $10^4 \sim 10^5$ 倍。
在**外存计算模型（External Memory Model）**中：
- 设总数据量为 $N$，主存可用容量为 $M$，单次磁盘传输块大小为 $B$（$1 < B \le M < N$）；
- 算法的运行时间不再由 CPU 指令数主导，而是完全由**从外存装载/写回数据块的 I/O 次数**决定；
- 二叉搜索树由于指针随机跳跃，单次查找最坏需 $\Theta(\log_2 N)$ 次物理 I/O；
- B 树通过令节点大小恰好契合磁盘块大小 $B$，单次查找仅需 $\Theta(\log_{M/B} \frac{N}{B})$ 次物理 I/O，将磁盘寻道降低了数个数量级！

### 2. 页缓存与双向链表解耦

`BufferPool` 采用数组分配连续的物理帧，并用侵入式指针串接成双向链表：
- `head` 指向最近刚刚被读写过的最高频页面（MRU）；
- `tail` 指向最久未被访问过的候选淘汰页面（LRU）。
- **页面命中**：从链表中将该帧剪切并挂接至 `head`，耗时 $O(1)$；
- **页面未命中**：
  - 若存在空闲帧（`valid == false`），直接填充；
  - 若无空闲帧，选定 `tail` 帧作为牺牲者（Victim）。若 `victim->dirty == true`，触发物理回写并增加 `flushes` 计数器；随后将该帧重新初始化并挂接至 `head`。

## C 语言实现

```c
#include <assert.h>
#include <stdbool.h>
#include <stddef.h>
#include <stdint.h>
#include <stdio.h>
#include <stdlib.h>
#include <string.h>

typedef struct CacheFrame {
    uint64_t page_id;
    bool valid;
    bool dirty;
    uint8_t *data;
    struct CacheFrame *prev;
    struct CacheFrame *next;
} CacheFrame;

typedef struct BufferPool {
    size_t num_frames;
    size_t page_size;
    CacheFrame *frames;
    CacheFrame *head; /* 最近刚使用 (MRU) */
    CacheFrame *tail; /* 最久未使用 (LRU) */

    size_t hits;
    size_t misses;
    size_t flushes;
} BufferPool;

BufferPool *buffer_pool_create(size_t num_frames, size_t page_size) {
    if (num_frames == 0 || page_size == 0) {
        return NULL;
    }
    BufferPool *pool = (BufferPool *)malloc(sizeof(BufferPool));
    if (pool == NULL) {
        return NULL;
    }

    pool->num_frames = num_frames;
    pool->page_size = page_size;
    pool->hits = 0;
    pool->misses = 0;
    pool->flushes = 0;
    pool->head = NULL;
    pool->tail = NULL;

    pool->frames = (CacheFrame *)malloc(sizeof(CacheFrame) * num_frames);
    if (pool->frames == NULL) {
        free(pool);
        return NULL;
    }

    for (size_t i = 0; i < num_frames; ++i) {
        pool->frames[i].page_id = UINT64_MAX;
        pool->frames[i].valid = false;
        pool->frames[i].dirty = false;
        pool->frames[i].data = (uint8_t *)malloc(page_size);
        assert(pool->frames[i].data != NULL);
        memset(pool->frames[i].data, 0, page_size);
        pool->frames[i].prev = NULL;
        pool->frames[i].next = NULL;
    }
    return pool;
}

void buffer_pool_destroy(BufferPool *pool) {
    if (pool == NULL) {
        return;
    }
    for (size_t i = 0; i < pool->num_frames; ++i) {
        free(pool->frames[i].data);
    }
    free(pool->frames);
    free(pool);
}

static void detach_frame(BufferPool *pool, CacheFrame *f) {
    if (f->prev != NULL) {
        f->prev->next = f->next;
    } else {
        pool->head = f->next;
    }
    if (f->next != NULL) {
        f->next->prev = f->prev;
    } else {
        pool->tail = f->prev;
    }
    f->prev = NULL;
    f->next = NULL;
}

static void attach_mru(BufferPool *pool, CacheFrame *f) {
    f->prev = NULL;
    f->next = pool->head;
    if (pool->head != NULL) {
        pool->head->prev = f;
    }
    pool->head = f;
    if (pool->tail == NULL) {
        pool->tail = f;
    }
}

static CacheFrame *find_frame(BufferPool *pool, uint64_t page_id) {
    for (size_t i = 0; i < pool->num_frames; ++i) {
        if (pool->frames[i].valid && pool->frames[i].page_id == page_id) {
            return &pool->frames[i];
        }
    }
    return NULL;
}

static CacheFrame *allocate_frame(BufferPool *pool, uint64_t new_page_id) {
    /* 1. 优先寻找未被使用的空闲帧 */
    for (size_t i = 0; i < pool->num_frames; ++i) {
        if (!pool->frames[i].valid) {
            pool->frames[i].valid = true;
            pool->frames[i].page_id = new_page_id;
            pool->frames[i].dirty = false;
            attach_mru(pool, &pool->frames[i]);
            return &pool->frames[i];
        }
    }

    /* 2. 淘汰 LRU 链表尾部的牺牲者帧 */
    CacheFrame *victim = pool->tail;
    assert(victim != NULL);

    if (victim->dirty) {
        pool->flushes++;
        victim->dirty = false;
    }

    detach_frame(pool, victim);
    victim->page_id = new_page_id;
    victim->dirty = false;
    attach_mru(pool, victim);
    return victim;
}

bool buffer_pool_read_page(BufferPool *pool, uint64_t page_id, void *out_buf) {
    if (pool == NULL || out_buf == NULL) {
        return false;
    }

    CacheFrame *f = find_frame(pool, page_id);
    if (f != NULL) {
        pool->hits++;
        detach_frame(pool, f);
        attach_mru(pool, f);
        memcpy(out_buf, f->data, pool->page_size);
        return true;
    }

    /* 缓存未命中：模拟从磁盘装载物理块 */
    pool->misses++;
    f = allocate_frame(pool, page_id);
    memset(f->data, (int)(page_id & 0xFF), pool->page_size);
    memcpy(out_buf, f->data, pool->page_size);
    return true;
}

bool buffer_pool_write_page(BufferPool *pool, uint64_t page_id, const void *in_buf) {
    if (pool == NULL || in_buf == NULL) {
        return false;
    }

    CacheFrame *f = find_frame(pool, page_id);
    if (f != NULL) {
        pool->hits++;
        detach_frame(pool, f);
        attach_mru(pool, f);
        memcpy(f->data, in_buf, pool->page_size);
        f->dirty = true;
        return true;
    }

    /* 写入时未命中：读入内存帧并置脏 */
    pool->misses++;
    f = allocate_frame(pool, page_id);
    memcpy(f->data, in_buf, pool->page_size);
    f->dirty = true;
    return true;
}

void buffer_pool_get_stats(
    const BufferPool *pool,
    size_t *out_hits,
    size_t *out_misses,
    size_t *out_flushes
) {
    if (pool == NULL) {
        return;
    }
    if (out_hits != NULL) {
        *out_hits = pool->hits;
    }
    if (out_misses != NULL) {
        *out_misses = pool->misses;
    }
    if (out_flushes != NULL) {
        *out_flushes = pool->flushes;
    }
}

int main(void) {
    size_t num_frames = 3;
    size_t page_size = 4096;
    BufferPool *pool = buffer_pool_create(num_frames, page_size);
    assert(pool != NULL);

    uint8_t buf[4096];
    size_t hits = 0, misses = 0, flushes = 0;

    /* 顺序读取页 1, 2, 3 -> 产生 3 次未命中装载 */
    assert(buffer_pool_read_page(pool, 1, buf));
    assert(buf[0] == 1);
    assert(buffer_pool_read_page(pool, 2, buf));
    assert(buf[0] == 2);
    assert(buffer_pool_read_page(pool, 3, buf));
    assert(buf[0] == 3);

    buffer_pool_get_stats(pool, &hits, &misses, &flushes);
    assert(hits == 0 && misses == 3 && flushes == 0);

    /* 再次读取页 1 -> 命中！LRU 顺序变为: 1 (MRU), 3, 2 (LRU) */
    assert(buffer_pool_read_page(pool, 1, buf));
    buffer_pool_get_stats(pool, &hits, &misses, &flushes);
    assert(hits == 1 && misses == 3 && flushes == 0);

    /* 写入页 2 -> 命中并标记为脏页！LRU 顺序变为: 2 (MRU), 1, 3 (LRU) */
    memset(buf, 0xAA, page_size);
    assert(buffer_pool_write_page(pool, 2, buf));
    buffer_pool_get_stats(pool, &hits, &misses, &flushes);
    assert(hits == 2 && misses == 3 && flushes == 0);

    /* 读取新页 4 -> 帧满，淘汰 LRU 尾部的干净页 3 -> misses = 4, flushes = 0 */
    assert(buffer_pool_read_page(pool, 4, buf));
    buffer_pool_get_stats(pool, &hits, &misses, &flushes);
    assert(hits == 2 && misses == 4 && flushes == 0);

    /* 读取新页 5 -> 淘汰 LRU 尾部的干净页 1 -> misses = 5, flushes = 0 */
    assert(buffer_pool_read_page(pool, 5, buf));
    buffer_pool_get_stats(pool, &hits, &misses, &flushes);
    assert(hits == 2 && misses == 5 && flushes == 0);

    /* 读取新页 6 -> 淘汰 LRU 尾部的页 2（脏页！）-> 必须先回写外存！misses = 6, flushes = 1! */
    assert(buffer_pool_read_page(pool, 6, buf));
    buffer_pool_get_stats(pool, &hits, &misses, &flushes);
    assert(hits == 2 && misses == 6 && flushes == 1);

    buffer_pool_destroy(pool);
    return 0;
}
```

## 复杂度分析

- **时间复杂度**：
  - 链表调整（提升至 MRU、从尾部剪切）：严格的 $O(1)$；
  - 查找帧：遍历包含 `num_frames` 项的数组，耗时为 $O(M/B)$（在实际工程中借助散列表可将定位优化为期望 $O(1)$）。
  - 单次读写操作的时间复杂度为 $O(M/B)$。
- **空间复杂度**：预分配包含 `num_frames` 个块大小为 $B$ 的连续缓冲池，内存空间复杂度为严格的 $O(M)$。

## 延伸思考 / 模式总结

本题构建的缓冲池模拟器精确再现了现代数据库系统（如 InnoDB Buffer Pool）与操作系统虚拟内存页表置换（Page Replacement）的底层运行机制。
外存数据结构的性能优劣，本质上取决于算法的内存访问模式与缓冲池的协作效应：B 树的高扇出与局部有序性，使得根和上层路标常驻缓冲池，而叶结点的顺序聚集使磁盘预读（Read-Ahead）的命中率逼近 $100\%$，完美攻克了海量数据下“内存容量有限与外存速度极慢”的永恒矛盾。
