# 32001 - B 树节点定义与关键字二分定位

## 题目描述

实现 B 树结点的内存定义、阶数 $M$（最小度数 $t \ge 2$）不变式校验，以及结点内部关键字的有序二分定位算法。

```c
#include <stdbool.h>
#include <stddef.h>
#include <stdint.h>

typedef struct BTreeNode BTreeNode;

struct BTreeNode {
    bool leaf;
    size_t key_count;
    int64_t *keys;
    BTreeNode **children;
};

bool btree_node_find_key(
    const BTreeNode *node,
    int64_t key,
    size_t *out_slot,
    bool *out_found
);

bool btree_check_node_invariants(
    const BTreeNode *node,
    size_t t,
    bool is_root
);

bool btree_search(
    const BTreeNode *root,
    int64_t key,
    const BTreeNode **out_node,
    size_t *out_slot,
    bool *out_found
);
```

要求：

1. 阶数不变式：最小度数为 $t$ 的 B 树中，非根结点包含的键数必须满足 $t - 1 \le \text{key\_count} \le 2t - 1$；非空树的根结点至少包含 1 个键。
2. 内部结点的孩子指针数必须严格等于 $\text{key\_count} + 1$，且所有有效孩子指针非空。
3. `btree_node_find_key` 在单结点的有序键数组中执行二分查找，定位第一个满足 `keys[slot] >= key` 的槽位，时间复杂度为 $O(\log t)$。
4. `btree_search` 沿多路树自顶向下分流下探，在树中搜索目标键，成功时输出目标结点指针与槽位下标。

## 解题思路

### 1. B 树结点的多路布局

B 树作为多路平衡搜索树，每个内部结点起到“多路路标”的作用：
- 包含 $k$ 个升序关键字 $K_0 < K_1 < \dots < K_{k-1}$；
- 包含 $k + 1$ 个子树指针 $C_0, C_1, \dots, C_k$；
- 子树 $C_i$ 中的所有关键字严格满足：$K_{i-1} < \text{keys}(C_i) < K_i$（其中边界 $K_{-1} = -\infty, K_k = +\infty$）。

### 2. 结点内部二分定位

由于 $2t - 1$ 可能较大（在外部存储系统中往往为几百至上千），线性扫描会带来较多的 CPU 比较指令。采用半开半闭区间 `[low, high)` 的二分下界查找（Lower Bound）：
- 若 `keys[mid] < key`，收紧下界 `low = mid + 1`；
- 否则收紧上界 `high = mid`；
- 循环终止于 `low == high`。此时 `low` 即为首个大于等于目标键的槽位。若 `low < key_count && keys[low] == key`，则说明在当前结点精确命中；否则，若当前结点为内部结点，则应沿着第 `low` 个孩子分支 $C_{\text{low}}$ 继续向下搜索。

## C 语言实现

```c
#include <assert.h>
#include <stdbool.h>
#include <stddef.h>
#include <stdint.h>
#include <stdlib.h>

typedef struct BTreeNode BTreeNode;

struct BTreeNode {
    bool leaf;
    size_t key_count;
    int64_t *keys;
    BTreeNode **children;
};

static BTreeNode *create_node(size_t t, bool leaf) {
    BTreeNode *node = (BTreeNode *)malloc(sizeof(BTreeNode));
    assert(node != NULL);
    node->leaf = leaf;
    node->key_count = 0;
    node->keys = (int64_t *)malloc(sizeof(int64_t) * (2 * t - 1));
    assert(node->keys != NULL);
    node->children = (BTreeNode **)malloc(sizeof(BTreeNode *) * (2 * t));
    assert(node->children != NULL);
    for (size_t i = 0; i < 2 * t; ++i) {
        node->children[i] = NULL;
    }
    return node;
}

static void free_node(BTreeNode *node) {
    if (node == NULL) {
        return;
    }
    if (!node->leaf) {
        for (size_t i = 0; i <= node->key_count; ++i) {
            free_node(node->children[i]);
        }
    }
    free(node->keys);
    free(node->children);
    free(node);
}

bool btree_node_find_key(
    const BTreeNode *node,
    int64_t key,
    size_t *out_slot,
    bool *out_found
) {
    if (node == NULL || out_slot == NULL || out_found == NULL) {
        return false;
    }
    size_t low = 0;
    size_t high = node->key_count;
    while (low < high) {
        size_t mid = low + (high - low) / 2;
        if (node->keys[mid] < key) {
            low = mid + 1;
        } else {
            high = mid;
        }
    }
    *out_slot = low;
    *out_found = (low < node->key_count && node->keys[low] == key);
    return true;
}

bool btree_check_node_invariants(
    const BTreeNode *node,
    size_t t,
    bool is_root
) {
    if (node == NULL || t < 2) {
        return false;
    }
    size_t max_keys = 2 * t - 1;
    size_t min_keys = is_root ? 1 : (t - 1);

    if (node->key_count > max_keys) {
        return false;
    }
    if (node->key_count < min_keys && !(is_root && node->key_count == 0 && node->leaf)) {
        return false;
    }
    for (size_t i = 1; i < node->key_count; ++i) {
        if (node->keys[i - 1] >= node->keys[i]) {
            return false;
        }
    }
    if (!node->leaf) {
        for (size_t i = 0; i <= node->key_count; ++i) {
            if (node->children[i] == NULL) {
                return false;
            }
        }
    }
    return true;
}

bool btree_search(
    const BTreeNode *root,
    int64_t key,
    const BTreeNode **out_node,
    size_t *out_slot,
    bool *out_found
) {
    if (root == NULL || out_found == NULL) {
        return false;
    }
    const BTreeNode *curr = root;
    while (curr != NULL) {
        size_t slot = 0;
        bool found = false;
        btree_node_find_key(curr, key, &slot, &found);
        if (found) {
            if (out_node != NULL) {
                *out_node = curr;
            }
            if (out_slot != NULL) {
                *out_slot = slot;
            }
            *out_found = true;
            return true;
        }
        if (curr->leaf) {
            break;
        }
        curr = curr->children[slot];
    }
    *out_found = false;
    return true;
}

int main(void) {
    size_t t = 2; /* 2-3-4 树，最大键数为 3 */
    BTreeNode *root = create_node(t, false);
    root->key_count = 1;
    root->keys[0] = 20;

    BTreeNode *c0 = create_node(t, true);
    c0->key_count = 2;
    c0->keys[0] = 10;
    c0->keys[1] = 15;

    BTreeNode *c1 = create_node(t, true);
    c1->key_count = 2;
    c1->keys[0] = 30;
    c1->keys[1] = 40;

    root->children[0] = c0;
    root->children[1] = c1;

    /* 校验结点不变式 */
    assert(btree_check_node_invariants(root, t, true));
    assert(btree_check_node_invariants(c0, t, false));
    assert(btree_check_node_invariants(c1, t, false));

    /* 结点内二分查找定位测试 */
    size_t slot = 0;
    bool found = false;
    assert(btree_node_find_key(c0, 10, &slot, &found) && found && slot == 0);
    assert(btree_node_find_key(c0, 15, &slot, &found) && found && slot == 1);
    assert(btree_node_find_key(c0, 12, &slot, &found) && !found && slot == 1);
    assert(btree_node_find_key(c0, 5, &slot, &found) && !found && slot == 0);
    assert(btree_node_find_key(c0, 20, &slot, &found) && !found && slot == 2);

    /* 多路下探查找测试 */
    const BTreeNode *hit_node = NULL;
    size_t hit_slot = 0;
    bool search_found = false;

    assert(btree_search(root, 20, &hit_node, &hit_slot, &search_found));
    assert(search_found && hit_node == root && hit_slot == 0);

    assert(btree_search(root, 40, &hit_node, &hit_slot, &search_found));
    assert(search_found && hit_node == c1 && hit_slot == 1);

    assert(btree_search(root, 999, &hit_node, &hit_slot, &search_found));
    assert(!search_found);

    free_node(root);
    return 0;
}
```

## 复杂度分析

- **时间复杂度**：在高度为 $h$ 的 B 树中查找目标键时，最多访问 $h + 1$ 个结点。每个结点内执行二分定位耗时 $O(\log t)$。由于树高 $h \le \log_t \frac{n + 1}{2}$，总比较次数为 $O(h \log t) = O(\frac{\log n}{\log t} \cdot \log t) = O(\log n)$。
- **空间复杂度**：采用自顶向下迭代循环，额外运行空间复杂度为 $O(1)$。

## 延伸思考 / 模式总结

在内存中，结点的二分查找使 CPU 比较次数降为 $O(\log n)$；而在外存中，每一次沿着指针下降代表一次磁盘页读取（I/O）。B 树之所以比二叉树快上千倍，正是因为它的高度降低了 $\log_2 t$ 倍，将宝贵的物理 I/O 次数压缩到了极低水平。
