# 32003 - B 树非满节点前插构建与完整插入

## 题目描述

实现 B 树完整的插入操作 `btree_insert`，采用自顶向下预先分裂策略（Top-Down Preemptive Split），确保在单次向下遍历过程中，绝不因回溯上溢而产生递归链。

```c
#include <stdbool.h>
#include <stddef.h>
#include <stdint.h>

typedef struct BTree BTree;

BTree *btree_create(size_t t);
void btree_destroy(BTree *tree);
bool btree_insert(
    BTree *tree,
    int64_t key,
    bool *out_inserted
);
bool btree_contains(const BTree *tree, int64_t key);
bool btree_validate(const BTree *tree);
```

要求：

1. 采用单趟自顶向下插入算法：若根结点已满，先通过创建新根并分裂将其降为非满；下探进入子结点前，若子结点已满，**立刻预先将其分裂**，从而保证当前下探结点的父结点永远拥有空闲槽位。
2. 重复键插入时保持原树不变，设置 `*out_inserted = false` 并成功返回。
3. 准确维护整棵树中存储的唯一键总数 `tree->size`。
4. 每次插入完成后，整棵树必须通过 `btree_validate` 验证器检查，保持严格的阶数与叶子等深不变式。

## 解题思路

### 1. 传统插入 vs 自顶向下预先分裂

- **传统回溯插入（Bottom-Up）**：直接下探到叶子插入；若叶子已满则分裂并向父结点插入中位数；若父结点也满则继续向祖父结点分裂……最坏情况下需要回溯并锁住整条从根到叶的路径，在多线程并发或外部 I/O 锁管理中容易导致连锁死锁。
- **自顶向下预先分裂（Top-Down Preemptive Split）**：
  在单向向下的搜索路径中，**只要发现下一个即将进入的子结点已包含 $2t - 1$ 个满键，便立刻调用 `btree_split_child` 将其分裂成两个各含 $t - 1$ 个键的子结点**！
  由于父结点此前必定已被确保为非满状态，因此提升的中位数绝不会导致父结点溢出。这意味着**插入操作只需单趟向下执行，完全杜绝了向上回溯！**

### 2. 叶结点的有序插入与去重

当控制流到达叶结点时，由于前置的不变式保证，该叶结点必定未满（最多包含 $2t - 2$ 个键）。
通过从右向左的扫描平移，找到正确的有序插入槽位：
- 若中途发现目标键已存在，恢复原样并置 `*out_inserted = false`；
- 否则将新键填入空出的槽位，递增 `key_count` 与 `tree->size`。

## C 语言实现

```c
#include <assert.h>
#include <stdbool.h>
#include <stddef.h>
#include <stdint.h>
#include <stdlib.h>

typedef struct BTreeNode BTreeNode;

struct BTreeNode {
    bool leaf;
    size_t key_count;
    int64_t *keys;
    BTreeNode **children;
};

typedef struct BTree {
    BTreeNode *root;
    size_t t;
    size_t size;
} BTree;

static BTreeNode *create_node(size_t t, bool leaf) {
    BTreeNode *n = (BTreeNode *)malloc(sizeof(BTreeNode));
    assert(n != NULL);
    n->leaf = leaf;
    n->key_count = 0;
    n->keys = (int64_t *)malloc(sizeof(int64_t) * (2 * t - 1));
    assert(n->keys != NULL);
    n->children = (BTreeNode **)malloc(sizeof(BTreeNode *) * (2 * t));
    assert(n->children != NULL);
    for (size_t i = 0; i < 2 * t; ++i) {
        n->children[i] = NULL;
    }
    return n;
}

static void free_nodes(BTreeNode *n) {
    if (n == NULL) {
        return;
    }
    if (!n->leaf) {
        for (size_t i = 0; i <= n->key_count; ++i) {
            free_nodes(n->children[i]);
        }
    }
    free(n->keys);
    free(n->children);
    free(n);
}

BTree *btree_create(size_t t) {
    if (t < 2) {
        return NULL;
    }
    BTree *tree = (BTree *)malloc(sizeof(BTree));
    if (tree == NULL) {
        return NULL;
    }
    tree->t = t;
    tree->root = create_node(t, true);
    tree->size = 0;
    return tree;
}

void btree_destroy(BTree *tree) {
    if (tree == NULL) {
        return;
    }
    free_nodes(tree->root);
    free(tree);
}

static void btree_split_child(BTreeNode *parent, size_t i, size_t t) {
    BTreeNode *y = parent->children[i];
    BTreeNode *z = create_node(t, y->leaf);
    z->key_count = t - 1;

    for (size_t j = 0; j < t - 1; ++j) {
        z->keys[j] = y->keys[j + t];
    }
    if (!y->leaf) {
        for (size_t j = 0; j < t; ++j) {
            z->children[j] = y->children[j + t];
            y->children[j + t] = NULL;
        }
    }
    y->key_count = t - 1;

    for (size_t j = parent->key_count + 1; j > i + 1; --j) {
        parent->children[j] = parent->children[j - 1];
    }
    parent->children[i + 1] = z;

    for (size_t j = parent->key_count; j > i; --j) {
        parent->keys[j] = parent->keys[j - 1];
    }
    parent->keys[i] = y->keys[t - 1];
    parent->key_count++;
}

static bool btree_insert_non_full(BTreeNode *node, int64_t key, size_t t, bool *out_inserted) {
    size_t i = node->key_count;
    if (node->leaf) {
        while (i > 0 && key < node->keys[i - 1]) {
            node->keys[i] = node->keys[i - 1];
            --i;
        }
        if (i > 0 && node->keys[i - 1] == key) {
            /* 键重复，恢复平移 */
            for (size_t k = i; k < node->key_count; ++k) {
                node->keys[k] = node->keys[k + 1];
            }
            *out_inserted = false;
            return true;
        }
        node->keys[i] = key;
        node->key_count++;
        *out_inserted = true;
        return true;
    } else {
        while (i > 0 && key < node->keys[i - 1]) {
            --i;
        }
        if (i > 0 && node->keys[i - 1] == key) {
            *out_inserted = false;
            return true;
        }
        /* 预先分裂满子结点 */
        if (node->children[i]->key_count == 2 * t - 1) {
            btree_split_child(node, i, t);
            if (key == node->keys[i]) {
                *out_inserted = false;
                return true;
            }
            if (key > node->keys[i]) {
                i++;
            }
        }
        return btree_insert_non_full(node->children[i], key, t, out_inserted);
    }
}

bool btree_insert(BTree *tree, int64_t key, bool *out_inserted) {
    if (tree == NULL || out_inserted == NULL) {
        return false;
    }
    BTreeNode *r = tree->root;
    if (r->key_count == 2 * tree->t - 1) {
        /* 根结点变满：先上升裂变出新根 */
        BTreeNode *s = create_node(tree->t, false);
        tree->root = s;
        s->children[0] = r;
        btree_split_child(s, 0, tree->t);
        bool ins = false;
        bool ok = btree_insert_non_full(s, key, tree->t, &ins);
        if (ok && ins) {
            tree->size++;
        }
        *out_inserted = ins;
        return ok;
    } else {
        bool ins = false;
        bool ok = btree_insert_non_full(r, key, tree->t, &ins);
        if (ok && ins) {
            tree->size++;
        }
        *out_inserted = ins;
        return ok;
    }
}

bool btree_contains(const BTree *tree, int64_t key) {
    if (tree == NULL) {
        return false;
    }
    const BTreeNode *curr = tree->root;
    while (curr != NULL) {
        size_t low = 0, high = curr->key_count;
        while (low < high) {
            size_t mid = low + (high - low) / 2;
            if (curr->keys[mid] < key) {
                low = mid + 1;
            } else {
                high = mid;
            }
        }
        if (low < curr->key_count && curr->keys[low] == key) {
            return true;
        }
        if (curr->leaf) {
            break;
        }
        curr = curr->children[low];
    }
    return false;
}

static bool validate_helper(
    const BTreeNode *node,
    size_t t,
    bool is_root,
    size_t current_depth,
    size_t *expected_leaf_depth,
    bool *has_leaf_depth,
    bool has_low,
    int64_t low,
    bool has_high,
    int64_t high
) {
    if (node == NULL) {
        return false;
    }
    size_t max_k = 2 * t - 1;
    size_t min_k = is_root ? 1 : (t - 1);
    if (is_root && node->key_count == 0 && node->leaf) {
        return true;
    }
    if (node->key_count > max_k || node->key_count < min_k) {
        return false;
    }

    for (size_t i = 0; i < node->key_count; ++i) {
        if ((has_low && node->keys[i] <= low) || (has_high && node->keys[i] >= high)) {
            return false;
        }
        if (i > 0 && node->keys[i] <= node->keys[i - 1]) {
            return false;
        }
    }

    if (node->leaf) {
        if (!*has_leaf_depth) {
            *has_leaf_depth = true;
            *expected_leaf_depth = current_depth;
        } else if (*expected_leaf_depth != current_depth) {
            return false;
        }
        return true;
    }

    for (size_t i = 0; i <= node->key_count; ++i) {
        if (node->children[i] == NULL) {
            return false;
        }
        bool child_has_low = (i > 0) ? true : has_low;
        int64_t child_low = (i > 0) ? node->keys[i - 1] : low;

        bool child_has_high = (i < node->key_count) ? true : has_high;
        int64_t child_high = (i < node->key_count) ? node->keys[i] : high;

        if (!validate_helper(
                node->children[i], t, false, current_depth + 1,
                expected_leaf_depth, has_leaf_depth,
                child_has_low, child_low, child_has_high, child_high)) {
            return false;
        }
    }
    return true;
}

bool btree_validate(const BTree *tree) {
    if (tree == NULL || tree->t < 2) {
        return false;
    }
    size_t expected_depth = 0;
    bool has_depth = false;
    return validate_helper(tree->root, tree->t, true, 0, &expected_depth, &has_depth, false, 0, false, 0);
}

int main(void) {
    BTree *tree = btree_create(3); /* t = 3, 阶数 M = 6 */
    assert(tree != NULL);
    assert(btree_validate(tree));

    bool ins = false;
    /* 顺序插入 100 个非单调散列键，频繁触发分裂 */
    for (int64_t i = 1; i <= 100; ++i) {
        assert(btree_insert(tree, i * 7 % 1000, &ins) && ins);
        assert(btree_validate(tree));
    }
    assert(tree->size == 100);

    /* 重复键插入测试 */
    assert(btree_insert(tree, 7, &ins) && !ins);
    assert(tree->size == 100);
    assert(btree_validate(tree));

    /* 成员查找测试 */
    for (int64_t i = 1; i <= 100; ++i) {
        assert(btree_contains(tree, i * 7 % 1000));
    }
    assert(!btree_contains(tree, 9999));

    btree_destroy(tree);
    return 0;
}
```

## 复杂度分析

- **时间复杂度**：自顶向下下探路径上的结点数不超过树高 $h \le \log_t \frac{n + 1}{2}$。由于预先分裂保证了每层至多执行一次 $O(t)$ 的分裂操作，单次插入的时间复杂度为严格的 $O(t \log_t n)$；对于固定的阶数 $t$，时间复杂度为 $O(\log n)$。
- **空间复杂度**：由于采用尾递归或迭代方式下探，调用栈深度不超过 $h = O(\log n)$，额外空间复杂度为 $O(\log n)$。

## 延伸思考 / 模式总结

自顶向下预先分裂策略不仅逻辑清晰，更是**数据库并发控制（Concurrency Control）的杀手级优化**。在两阶段加锁或闩锁耦合（Latch Crabbing）协议中，由于预先分裂保证了父结点绝不发生结构重构，线程在向子结点下探并持有锁后，可以**立刻安全释放父结点的写锁**，使得长事务绝不长期阻塞整棵树的根部分支，极大地释放了并发吞吐量。
