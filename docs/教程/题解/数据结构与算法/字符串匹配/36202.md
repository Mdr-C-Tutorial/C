# 36202：KMP 全匹配枚举与最小周期长度

## 题目

基于 KMP 前缀函数实现全匹配位置枚举与字节序列最小周期长度计算：

```c
#include <stdbool.h>
#include <stddef.h>

bool kmp_find_all_u8(
    const unsigned char *text,
    size_t text_count,
    const unsigned char *pattern,
    size_t pattern_count,
    size_t *out_indices,
    size_t capacity,
    size_t *out_count
);

bool shortest_period_u8(
    const unsigned char *bytes,
    size_t count,
    size_t *out_period
);
```

要求：

1. `kmp_find_all_u8` 查找非空模式（`pattern_count > 0`）在文本中全部可重叠出现的起始下标，按升序写入 `out_indices` 并通过 `out_count` 输出匹配总数；匹配数量超过 `capacity` 时返回 `false`。
2. `shortest_period_u8` 计算非空字节序列（`count > 0`）的最小整除周期长度 $p$（即满足 $p \mid \text{count}$ 且对所有 $0 \le i < \text{count} - p$ 有 `bytes[i] == bytes[i + p]` 的最小正整数 $p$）：若候选值 $k = \text{count} - \pi[\text{count} - 1]$ 整除 `count`，则最小周期为 $k$，否则为 `count`。
3. 参数无效、缓冲区容量不足或存储分配失败时返回 `false`，且不得修改调用方的输出对象。
4. 两个函数的时间复杂度分别应为 $O(n+m)$ 与 $O(n)$，额外空间复杂度分别为 $O(m)$ 与 $O(n)$。

## 解析

1. **可重叠全匹配枚举**：当 KMP 状态机在文本位置 `i` 处达到 `matched == pattern_count` 时，记录起始下标 `i + 1 - pattern_count`。为了继续寻找后续可能与当前匹配重叠的出现位置（例如在 `"ababa"` 中查找 `"aba"`），只需将当前状态视作一次在位置 `pattern_count` 处的虚拟失配，令 `matched = pi[matched - 1]`，即可无缝保持最长相等前后缀不变式并继续扫描下一个文本字节。为兼顾严格的 $O(m)$ 额外空间与失败时不修改 `out_indices` 的要求，可先扫描一遍统计匹配总数 `found`；确认 `found <= capacity` 后，再扫描第二遍将起始下标直接写入 `out_indices`。
2. **最小周期定理（$k = n - \pi[n - 1]$）**：对于长度为 $n$ 的序列 $S$，其最长真前后缀长度 $L = \pi[n - 1]$ 满足对所有 $0 \le i < L$ 有 $S[i] == S[i + (n - L)]$，这等价于 $k = n - \pi[n - 1]$ 是 $S$ 的**最短边界周期（Border Period）**。
   - 若 $k \mid n$，则整条序列由长度为 $k$ 的前缀恰好重复 $n / k$ 次拼接而成，且不可能存在更短的整除周期（否则会导出大于 $\pi[n - 1]$ 的相等真前后缀，矛盾），故最小整除周期为 $k$；
   - 若 $k \nmid n$，则没有任何真因子周期能整除 $n$，最小整除周期就是序列总长 $n$。

## 答案

```c
#include <stdbool.h>
#include <stddef.h>
#include <stdint.h>
#include <stdlib.h>

static size_t *build_prefix_table(
    const unsigned char *bytes,
    size_t count
) {
    if (count == 0 || count > SIZE_MAX / sizeof(size_t)) {
        return NULL;
    }
    size_t *pi = malloc(count * sizeof *pi);
    if (pi == NULL) {
        return NULL;
    }
    pi[0] = 0;
    size_t k = 0;
    for (size_t i = 1; i < count; ++i) {
        while (k > 0 && bytes[k] != bytes[i]) {
            k = pi[k - 1];
        }
        if (bytes[k] == bytes[i]) {
            ++k;
        }
        pi[i] = k;
    }
    return pi;
}

bool kmp_find_all_u8(
    const unsigned char *text,
    size_t text_count,
    const unsigned char *pattern,
    size_t pattern_count,
    size_t *out_indices,
    size_t capacity,
    size_t *out_count
) {
    if (out_count == NULL || pattern_count == 0 ||
        pattern == NULL ||
        (text_count > 0 && text == NULL) ||
        (capacity > 0 && out_indices == NULL)) {
        return false;
    }
    if (text_count < pattern_count) {
        *out_count = 0;
        return true;
    }

    size_t *pi = build_prefix_table(pattern, pattern_count);
    if (pi == NULL) {
        return false;
    }

    size_t found = 0;
    size_t matched = 0;
    for (size_t i = 0; i < text_count; ++i) {
        while (matched > 0 && pattern[matched] != text[i]) {
            matched = pi[matched - 1];
        }
        if (pattern[matched] == text[i]) {
            ++matched;
        }
        if (matched == pattern_count) {
            ++found;
            matched = pi[matched - 1];
        }
    }
    if (found > capacity || (found > 0 && out_indices == NULL)) {
        free(pi);
        return false;
    }

    size_t written = 0;
    matched = 0;
    for (size_t i = 0; i < text_count && written < found; ++i) {
        while (matched > 0 && pattern[matched] != text[i]) {
            matched = pi[matched - 1];
        }
        if (pattern[matched] == text[i]) {
            ++matched;
        }
        if (matched == pattern_count) {
            out_indices[written++] = i + 1 - pattern_count;
            matched = pi[matched - 1];
        }
    }
    free(pi);
    *out_count = found;
    return true;
}

bool shortest_period_u8(
    const unsigned char *bytes,
    size_t count,
    size_t *out_period
) {
    if (bytes == NULL || count == 0 || out_period == NULL) {
        return false;
    }
    size_t *pi = build_prefix_table(bytes, count);
    if (pi == NULL) {
        return false;
    }
    size_t candidate = count - pi[count - 1];
    free(pi);
    *out_period = (count % candidate == 0) ? candidate : count;
    return true;
}
```

`kmp_find_all_u8` 通过两遍线性扫描将时间复杂度保持在 $O(n + m)$，额外空间复杂度严格为存放前缀表的 $O(m)$；`shortest_period_u8` 的时间复杂度与额外空间复杂度均为 $O(n)$。
