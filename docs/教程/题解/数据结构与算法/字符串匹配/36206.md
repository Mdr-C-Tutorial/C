# 36206 - Boyer-Moore 算法坏字符与好后缀启发式规则解析

## 题目

实现 **Boyer-Moore（BM）字符串匹配算法**，在文本字节序列 `text` 中高效查找模式字节序列 `pattern` 首次出现的起始下标。

必须完整实现 BM 算法的两大核心启发式跳转规则：
1. **坏字符规则（Bad Character Heuristic）**；
2. **好后缀规则（Good Suffix Heuristic）**。

在每一步失配时，算法必须综合考量两项规则，**选取位移量较大者**作为滑动步长。

函数签名如下：

```c
#include <stdbool.h>
#include <stddef.h>
#include <stdint.h>

bool boyer_moore_search_u8(
    const unsigned char *text,
    size_t text_count,
    const unsigned char *pattern,
    size_t pattern_count,
    size_t *out_first_index
);
```

要求：
1. 比对方向必须**从后向前（从右向左）**逐字符比对模式串。
2. 坏字符表使用大小为 256 的直接寻址表，记录每个字节在模式串中最右出现的下标。
3. 参数无效时返回 `false`；未找到时输出 `*out_first_index = SIZE_MAX` 并返回 `true`。
4. 详细阐述好后缀规则与坏字符规则协同工作的力学原理。

## 解题思路

1. **从右向左逆向比对的优势**：
   不同于 KMP 和朴素算法从左向右比对，BM 算法选择从模式串的最末尾字符开始逆向向前比对。
   一旦末尾字符发生失配，往往可以直接跳过整个模式串长度的距离，从而在实际英文和文本检索中达到**亚线性（Sub-linear）**的极高平均速度（平均检查字符数甚至远小于 $n$）。

2. **坏字符规则（Bad Character Rule）**：
   假设在模式串下标 $j$ 处发生失配，对应的文本字符为 $c = text[i + j]$（称为“坏字符”）：
   - 若 $c$ 在模式串中存在，找到其在模式串中最靠右的位置 $k = last[c]$：
     若 $k < j$，向右滑动步长为 $j - k$（将模式串中的 $c$ 与文本中的 $c$ 对齐）；
     若 $k > j$，该对齐会导致模式串倒退，因此规则退化为移动 1 位；
   - 若 $c$ 在模式串中根本不存在，直接将整个模式串滑过该字符：滑动步长为 $j + 1$。

3. **好后缀规则（Good Suffix Rule）**：
   假设在模式串末尾已经有一段后缀 $P[j + 1 \dots m - 1]$ 成功匹配（称为“好后缀” $u$）：
   - 若在模式串的其他位置也存在等于 $u$ 的子串，将最靠右的那个匹配子串与好后缀对齐；
   - 若模式串中没有完整的 $u$，但存在 $u$ 的某个后缀恰好与模式串的某个**最长前缀**匹配，则将该前缀与好后缀对齐；
   - 否则，将整个模式串滑动 $m$ 位。

4. **协同决策**：
   在失配发生时：
   $$shift = \max(shift_{bc}, \; shift_{gs})$$
   始终取两者中位移最大的步长向右跳跃。

## C 语言实现

```c
#include <assert.h>
#include <stdbool.h>
#include <stddef.h>
#include <stdint.h>
#include <stdlib.h>
#include <string.h>

static void build_bad_char(
    const unsigned char *pattern,
    size_t m,
    ptrdiff_t bad_char[256]
) {
    for (size_t c = 0; c < 256; ++c) {
        bad_char[c] = -1;
    }
    for (size_t i = 0; i < m; ++i) {
        bad_char[pattern[i]] = (ptrdiff_t)i;
    }
}

static void build_good_suffix(
    const unsigned char *pattern,
    size_t m,
    size_t *good_suffix
) {
    size_t *suff = malloc(m * sizeof *suff);
    if (suff == NULL) {
        return;
    }

    // 计算 suff 数组: suff[i] 为以 i 结尾的子串与模式串后缀的最长公共后缀长度
    suff[m - 1] = m;
    for (ptrdiff_t i = (ptrdiff_t)m - 2; i >= 0; --i) {
        ptrdiff_t q = i;
        while (q >= 0 && pattern[q] == pattern[m - 1 - (i - q)]) {
            q--;
        }
        suff[i] = (size_t)(i - q);
    }

    // Case 3: 默认滑动 m
    for (size_t i = 0; i < m; ++i) {
        good_suffix[i] = m;
    }

    // Case 2: 好后缀的子后缀匹配模式串前缀
    size_t j = 0;
    for (ptrdiff_t i = (ptrdiff_t)m - 1; i >= 0; --i) {
        if (suff[i] == (size_t)(i + 1)) {
            for (; j < m - 1 - (size_t)i; ++j) {
                if (good_suffix[j] == m) {
                    good_suffix[j] = m - 1 - (size_t)i;
                }
            }
        }
    }

    // Case 1: 好后缀在模式串内部有完整重现
    for (size_t i = 0; i < m - 1; ++i) {
        good_suffix[m - 1 - suff[i]] = m - 1 - i;
    }

    free(suff);
}

bool boyer_moore_search_u8(
    const unsigned char *text,
    size_t text_count,
    const unsigned char *pattern,
    size_t pattern_count,
    size_t *out_first_index
) {
    if (out_first_index == NULL ||
        (text_count > 0 && text == NULL) ||
        (pattern_count > 0 && pattern == NULL)) {
        return false;
    }

    if (pattern_count == 0) {
        *out_first_index = 0;
        return true;
    }

    if (text_count < pattern_count) {
        *out_first_index = SIZE_MAX;
        return true;
    }

    size_t m = pattern_count;
    size_t n = text_count;

    ptrdiff_t bad_char[256];
    build_bad_char(pattern, m, bad_char);

    size_t *good_suffix = malloc(m * sizeof *good_suffix);
    if (good_suffix == NULL) {
        return false;
    }
    build_good_suffix(pattern, m, good_suffix);

    size_t s = 0; // 窗口相对于文本的起始偏移
    size_t found_idx = SIZE_MAX;

    while (s <= n - m) {
        ptrdiff_t j = (ptrdiff_t)m - 1;

        // 从右向左比对
        while (j >= 0 && pattern[j] == text[s + (size_t)j]) {
            j--;
        }

        if (j < 0) {
            // 完整匹配
            found_idx = s;
            break;
        } else {
            // 坏字符位移
            unsigned char bad_c = text[s + (size_t)j];
            ptrdiff_t bc_shift = j - bad_char[bad_c];
            if (bc_shift < 1) {
                bc_shift = 1;
            }

            // 好后缀位移
            size_t gs_shift = good_suffix[(size_t)j];

            size_t shift = ((size_t)bc_shift > gs_shift) ? (size_t)bc_shift : gs_shift;
            s += shift;
        }
    }

    free(good_suffix);
    *out_first_index = found_idx;
    return true;
}

int main(void) {
    size_t idx = 0;

    // 参数校验
    assert(!boyer_moore_search_u8(NULL, 1, (const unsigned char*)"a", 1, &idx));

    // 空模式
    assert(boyer_moore_search_u8((const unsigned char*)"abc", 3, NULL, 0, &idx));
    assert(idx == 0);

    // 标准测试用例
    // text: "HERE IS A SIMPLE EXAMPLE"
    // pattern: "EXAMPLE"
    const unsigned char t1[] = "HERE IS A SIMPLE EXAMPLE";
    const unsigned char p1[] = "EXAMPLE";
    assert(boyer_moore_search_u8(t1, 24, p1, 7, &idx));
    assert(idx == 17);

    // 重复字符与大跳步测试
    const unsigned char t2[] = "ABAAABCD";
    const unsigned char p2[] = "ABC";
    assert(boyer_moore_search_u8(t2, 8, p2, 3, &idx));
    assert(idx == 4);

    // 未找到
    const unsigned char p3[] = "XYZ";
    assert(boyer_moore_search_u8(t1, 24, p3, 3, &idx));
    assert(idx == SIZE_MAX);

    return 0;
}
```

## 复杂度分析

- **时间复杂度**：
  - **最好情况**：$O(n / m)$。在字母表较大且模式串中无匹配字符时，每次逆向比对首字符即失配，直接跳跃 $m$ 步，呈现超线性（亚线性）极速。
  - **最坏情况**：$O(n + m)$。在包含好后缀规则保障下，最坏情况时间复杂度依然具有严格的线性上界。
- **空间复杂度**：$O(m + \Sigma)$。其中 $\Sigma = 256$ 为坏字符表大小，好后缀表占用 $O(m)$。

## 延伸思考 / 模式总结

Boyer-Moore 算法被誉为单模式串匹配的黄金标准（GNU grep 核心算法之一）。从右向左逆向审视的逆向思维，颠覆了传统自左向右的比对直觉，将失配字符从“绊脚石”转变成了“大跨步跳跃的跳板”。
