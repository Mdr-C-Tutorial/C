# 36204 - KMP 全匹配位置枚举与字符串最小周期判定

## 题目描述

基于 KMP 算法的前缀函数 $\pi$ 数组，实现两个高级扩展操作：
1. `kmp_find_all_u8`：找出非空模式串在文本串中**全部可重叠出现的起始下标**；
2. `shortest_period_u8`：求一个非空字节序列的**最小整除周期长度**。

函数签名如下：

```c
#include <stdbool.h>
#include <stddef.h>
#include <stdint.h>

bool kmp_find_all_u8(
    const unsigned char *text,
    size_t text_count,
    const unsigned char *pattern,
    size_t pattern_count,
    size_t *out_indices,
    size_t capacity,
    size_t *out_count
);

bool shortest_period_u8(
    const unsigned char *bytes,
    size_t count,
    size_t *out_period
);
```

要求：
1. 参数无效时返回 `false`。
2. 枚举全匹配时若匹配总数超过 `capacity`，返回 `false` 报告容量不足，且不得修改输出数组。
3. 最小整除周期定理：利用最长相等真前后缀长度 $\pi[n - 1]$，在 $O(n)$ 时间内判定最小重复单元周期。

## 解题思路

1. **可重叠全匹配枚举的状态机虚拟跳转**：
   当在文本位置 $i$ 处达到完整匹配（`matched == pattern_count`）时，我们记录下了起始下标 $i + 1 - pattern\_count$。
   为了继续寻找后续可能与当前匹配相互重叠的位置（例如在 `"ababa"` 中查找 `"aba"`）：
   只需将当前状态视作一次**在位置 $pattern\_count$ 处的虚拟失配**，执行：
   $$matched = \pi[matched - 1]$$
   由于 $\pi[m - 1]$ 记录的是模式串本身的最长相等真前后缀，跳转后自动保留了最大的重叠前缀，可以直接继续无缝扫描下一个文本字符。

2. **最小整除周期定理（$k = n - \pi[n - 1]$）**：
   对于长度为 $n$ 的字符串 $S$，其最长真前后缀长度为 $L = \pi[n - 1]$。
   这意味着对所有的 $0 \le i < L$，均有 $S[i] == S[i + (n - L)]$。
   令候选周期长度 $k = n - L$：
   - 若 $k$ 能整除 $n$（即 $n \bmod k == 0$），且 $L > 0$：
     整条序列必然由长度为 $k$ 的前缀子串重复 $n / k$ 次拼接而成。且不可能存在更短的整除周期（否则会导出更长的相等真前后缀，与 $L$ 的极大性矛盾）。因此最小整除周期为 $k$；
   - 若 $k$ 不能整除 $n$（或 $L == 0$）：
     不存在任何真子串能够整除重复构成原序列，最小整除周期即为序列自身长度 $n$。

## C 语言实现

```c
#include <assert.h>
#include <stdbool.h>
#include <stddef.h>
#include <stdint.h>
#include <stdlib.h>

static size_t *build_prefix_table(const unsigned char *bytes, size_t count) {
    if (count == 0 || count > SIZE_MAX / sizeof(size_t)) {
        return NULL;
    }
    size_t *pi = malloc(count * sizeof *pi);
    if (pi == NULL) {
        return NULL;
    }
    pi[0] = 0;
    size_t k = 0;
    for (size_t i = 1; i < count; ++i) {
        while (k > 0 && bytes[k] != bytes[i]) {
            k = pi[k - 1];
        }
        if (bytes[k] == bytes[i]) {
            ++k;
        }
        pi[i] = k;
    }
    return pi;
}

bool kmp_find_all_u8(
    const unsigned char *text,
    size_t text_count,
    const unsigned char *pattern,
    size_t pattern_count,
    size_t *out_indices,
    size_t capacity,
    size_t *out_count
) {
    if (out_count == NULL || pattern_count == 0 ||
        (text_count > 0 && text == NULL) ||
        pattern == NULL) {
        return false;
    }

    if (text_count < pattern_count) {
        *out_count = 0;
        return true;
    }

    size_t *pi = build_prefix_table(pattern, pattern_count);
    if (pi == NULL) {
        return false;
    }

    // 第一遍扫描：统计匹配总数，确保不超过 capacity
    size_t total_found = 0;
    size_t matched = 0;
    for (size_t i = 0; i < text_count; ++i) {
        while (matched > 0 && pattern[matched] != text[i]) {
            matched = pi[matched - 1];
        }
        if (pattern[matched] == text[i]) {
            ++matched;
        }
        if (matched == pattern_count) {
            total_found++;
            matched = pi[matched - 1]; // 虚拟失配回退
        }
    }

    if (total_found > capacity || (total_found > 0 && out_indices == NULL)) {
        free(pi);
        return false; // 容量不足
    }

    // 第二遍扫描：记录所有起始下标
    matched = 0;
    size_t write_idx = 0;
    for (size_t i = 0; i < text_count; ++i) {
        while (matched > 0 && pattern[matched] != text[i]) {
            matched = pi[matched - 1];
        }
        if (pattern[matched] == text[i]) {
            ++matched;
        }
        if (matched == pattern_count) {
            out_indices[write_idx++] = i + 1 - pattern_count;
            matched = pi[matched - 1];
        }
    }

    free(pi);
    *out_count = total_found;
    return true;
}

bool shortest_period_u8(
    const unsigned char *bytes,
    size_t count,
    size_t *out_period
) {
    if (out_period == NULL || count == 0 || bytes == NULL) {
        return false;
    }

    size_t *pi = build_prefix_table(bytes, count);
    if (pi == NULL) {
        return false;
    }

    size_t l = pi[count - 1];
    size_t k = count - l;

    if (l > 0 && (count % k == 0)) {
        *out_period = k;
    } else {
        *out_period = count;
    }

    free(pi);
    return true;
}

int main(void) {
    size_t indices[16];
    size_t count = 0;
    size_t period = 0;

    // 全匹配测试: "abababa" 中查找 "aba"
    // 出现位置: 下标 0, 下标 2, 下标 4 (共 3 次重叠出现)
    const unsigned char t1[] = "abababa";
    const unsigned char p1[] = "aba";
    assert(kmp_find_all_u8(t1, 7, p1, 3, indices, 16, &count));
    assert(count == 3);
    assert(indices[0] == 0 && indices[1] == 2 && indices[2] == 4);

    // 最小整除周期测试:
    // "abcabcabc" -> 周期为 "abc"，长度 3
    const unsigned char s1[] = "abcabcabc";
    assert(shortest_period_u8(s1, 9, &period) && period == 3);

    // "aaaa" -> 周期为 "a"，长度 1
    const unsigned char s2[] = "aaaa";
    assert(shortest_period_u8(s2, 4, &period) && period == 1);

    // "abcde" -> 无整除周期，周期为 5
    const unsigned char s3[] = "abcde";
    assert(shortest_period_u8(s3, 5, &period) && period == 5);

    return 0;
}
```

## 复杂度分析

- **时间复杂度**：$O(n + m)$。全匹配扫描两遍文本串，每遍耗时严格 $O(n)$；最小整除周期仅需对原序列构建一次 $\pi$ 数组，耗时 $O(n)$。
- **空间复杂度**：$O(m)$。仅用于缓存模式串的 $\pi$ 数组。

## 延伸思考 / 模式总结

前缀函数 $\pi$ 不仅是一个用于匹配跳步的工具，它本质上揭示了字符串所有的**边界周期性质（Border Periodicities）**。通过 $\pi[n-1]$ 与整除关系的结合，把原本需要枚举因子的检验问题降维为单个代数恒等式。
