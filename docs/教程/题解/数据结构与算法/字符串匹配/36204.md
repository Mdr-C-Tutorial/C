# 36204 - Rabin-Karp 滚动哈希匹配算法（防哈希冲突与防溢出）

## 题目

实现基于多项式滚动哈希的 **Rabin-Karp 字符串匹配算法**，在文本字节序列 `text` 中查找模式字节序列 `pattern` 首次出现的起始下标。

为保证绝对正确性，当滚动哈希命中时，必须执行**二次精确逐字节比对**，以消除哈希碰撞（False Positive）导致的误报。

函数签名如下：

```c
#include <stdbool.h>
#include <stddef.h>
#include <stdint.h>

bool rabin_karp_search_u8(
    const unsigned char *text,
    size_t text_count,
    const unsigned char *pattern,
    size_t pattern_count,
    size_t *out_first_index
);
```

要求：
1. 参数无效时返回 `false`。未匹配到时写入 `*out_first_index = SIZE_MAX` 并返回 `true`。
2. 当 `pattern_count == 0` 时，输出首次下标 0 并返回 `true`。
3. 采用模大质数的多项式哈希：选择底数 $B = 257$，模数 $M = 1000000007$（$10^9 + 7$）。
4. 滑动窗口更新哈希值必须在 $O(1)$ 常数时间内完成。
5. 哈希匹配成功时立即进行 `memcmp` 二次精确核对，防止哈希冲突。

## 解题思路

1. **多项式滚动哈希定义**：
   将长度为 $m$ 的字节序列 $S$ 映射为一个大整数：
   $$H(S) = \left( \sum_{i=0}^{m-1} S[i] \cdot B^{m - 1 - i} \right) \bmod M$$
   其中基数 $B = 257$ 严格大于单字节取值范围 $[0, 255]$，模数 $M = 10^9 + 7$ 为大素数。

2. **$O(1)$ 窗口滚动更新**：
   当窗口从 $text[i \dots i + m - 1]$ 滑动到 $text[i + 1 \dots i + m]$ 时：
   - 减去旧窗口最高位字符 $text[i]$ 的贡献（乘以 $B^{m-1} \bmod M$）；
   - 整体乘以基数 $B$（相当于所有位左移一位）；
   - 加上新窗口最低位字符 $text[i + m]$ 的贡献；
   - 整体对 $M$ 取模。
   递推公式为：
   $$H_{new} = \left( (H_{old} - text[i] \cdot B^{m - 1}) \cdot B + text[i + m] \right) \bmod M$$
   在 C 语言无符号或有符号模算术中，为防止减法产生负数，计算时需加上模数偏移：
   `h = (h + M - (text[i] * power) % M) % M;`
   `h = (h * B + text[i + m]) % M;`

3. **双重防线拦截哈希冲突**：
   哈希函数将无穷域压缩到有限模域，根据抽屉原理必然存在碰撞。
   若仅依据 $H(text[i \dots i + m - 1]) == H(pattern)$ 就判定匹配，会在对抗样例或极端数据下产生致命错误。
   因此，**哈希相等仅作为快速候选过滤器**；一旦哈希相等，立即调用 `memcmp` 进行二次精确检验，从而在保持平均 $O(n + m)$ 高效的同时，确保 100% 的数学正确性。

## C 语言实现

```c
#include <assert.h>
#include <stdbool.h>
#include <stddef.h>
#include <stdint.h>
#include <string.h>

#define RK_BASE 257ULL
#define RK_MOD  1000000007ULL

bool rabin_karp_search_u8(
    const unsigned char *text,
    size_t text_count,
    const unsigned char *pattern,
    size_t pattern_count,
    size_t *out_first_index
) {
    if (out_first_index == NULL ||
        (text_count > 0 && text == NULL) ||
        (pattern_count > 0 && pattern == NULL)) {
        return false;
    }

    if (pattern_count == 0) {
        *out_first_index = 0;
        return true;
    }

    if (text_count < pattern_count) {
        *out_first_index = SIZE_MAX;
        return true;
    }

    size_t m = pattern_count;
    size_t n = text_count;

    // 预计算 high_power = BASE^(m - 1) % MOD
    uint64_t high_power = 1;
    for (size_t i = 0; i < m - 1; ++i) {
        high_power = (high_power * RK_BASE) % RK_MOD;
    }

    // 计算模式串哈希与文本首个窗口哈希
    uint64_t pattern_hash = 0;
    uint64_t window_hash = 0;
    for (size_t i = 0; i < m; ++i) {
        pattern_hash = (pattern_hash * RK_BASE + pattern[i]) % RK_MOD;
        window_hash = (window_hash * RK_BASE + text[i]) % RK_MOD;
    }

    size_t max_start = n - m;
    for (size_t i = 0; i <= max_start; ++i) {
        // 哈希命中，进行二次精确比对
        if (window_hash == pattern_hash) {
            if (memcmp(text + i, pattern, m) == 0) {
                *out_first_index = i;
                return true;
            }
        }

        // 滑动窗口更新哈希值
        if (i < max_start) {
            uint64_t remove_val = (text[i] * high_power) % RK_MOD;
            window_hash = (window_hash + RK_MOD - remove_val) % RK_MOD;
            window_hash = (window_hash * RK_BASE + text[i + m]) % RK_MOD;
        }
    }

    *out_first_index = SIZE_MAX;
    return true;
}

int main(void) {
    size_t first = 0;

    // 参数校验
    assert(!rabin_karp_search_u8(NULL, 5, (const unsigned char*)"a", 1, &first));

    // 空模式
    assert(rabin_karp_search_u8((const unsigned char*)"abc", 3, NULL, 0, &first));
    assert(first == 0);

    // 标准测试用例
    const unsigned char t1[] = "the quick brown fox jumps over the lazy dog";
    const unsigned char p1[] = "fox";
    assert(rabin_karp_search_u8(t1, 43, p1, 3, &first));
    assert(first == 16);

    // 匹配末尾
    const unsigned char p2[] = "dog";
    assert(rabin_karp_search_u8(t1, 43, p2, 3, &first));
    assert(first == 40);

    // 未找到
    const unsigned char p3[] = "cat";
    assert(rabin_karp_search_u8(t1, 43, p3, 3, &first));
    assert(first == SIZE_MAX);

    // 二进制含 0x00 字节测试
    const unsigned char t4[5] = {0x01, 0x00, 0x02, 0x00, 0x03};
    const unsigned char p4[2] = {0x02, 0x00};
    assert(rabin_karp_search_u8(t4, 5, p4, 2, &first));
    assert(first == 2);

    return 0;
}
```

## 复杂度分析

- **时间复杂度**：
  - **平均情况**：$O(n + m)$。滚动哈希的计算与更新耗时为严格 $O(1)$，在良好的哈希分布下冲突率极低，二次精确比较触发次数很少。
  - **最坏情况**：$O(nm)$。若遭遇哈希严重碰撞的极端对抗数据，每次哈希均命中导致频繁触发完整 `memcmp`。
- **空间复杂度**：$O(1)$。仅维护常数个 64 位无符号整型对象，无需辅助表分配。

## 延伸思考 / 模式总结

Rabin-Karp 算法的独特价值在于它可以极低代价泛化为**多模式匹配**和**二维矩阵匹配**。例如，同时查找 $k$ 个相同长度的模式串时，只需将所有模式串的哈希值存入哈希集合，滑动文本窗口时只需进行 $O(1)$ 的集合查询即可同时检索所有模式。
