# 36203 - KMP 算法前缀函数（pi 数组）推导与首次匹配

## 题目描述

在任意二进制字节序列 `text`（长度为 `text_count`）中，使用 **Knuth-Morris-Pratt（KMP）算法**查找模式字节序列 `pattern`（长度为 `pattern_count`）首次出现的起始下标。

函数签名如下：

```c
#include <stdbool.h>
#include <stddef.h>
#include <stdint.h>

bool find_subsequence_u8(
    const unsigned char *text,
    size_t text_count,
    const unsigned char *pattern,
    size_t pattern_count,
    size_t *out_index
);
```

要求：
1. 参数无效时返回 `false`。未找到时输出 `*out_index = SIZE_MAX` 并返回 `true`。
2. 当 `pattern_count == 0` 时，输出首次下标 0 并返回 `true`。
3. 文本指针在主扫描过程中必须**单调向前递增，绝不回退**。
4. 必须通过动态规划自匹配构建前缀函数表（$\pi$ 数组 / `next` 数组），时间复杂度严格达到 $O(n + m)$，空间复杂度为 $O(m)$。

## 解题思路

1. **前缀函数（$\pi$ 数组）的数学定义**：
   对于模式串 $P[0 \dots m - 1]$，前缀函数 $\pi[i]$ 定义为：
   子串 $P[0 \dots i]$ 的**最长相等真前缀与真后缀的长度**。
   即满足 $P[0 \dots k - 1] == P[i - k + 1 \dots i]$ 的最大 $k < i + 1$。

2. **前缀函数的高效推导（自匹配 DP）**：
   通过动态规划在线性时间内计算 $\pi$ 数组：
   - 基础情形：$\pi[0] = 0$；
   - 设当前已知前一个位置的最长前后缀长度为 $k = \pi[i - 1]$；
   - 若 $P[i] == P[k]$，则最长前后缀自然延长一位：$\pi[i] = k + 1$；
   - 若 $P[i] \neq P[k]$，则不断回退至次长相等前后缀 $k = \pi[k - 1]$，直到找到可扩展的字符或 $k == 0$。

3. **KMP 主扫描过程（文本指针永不回退）**：
   扫描文本串 $T[0 \dots n - 1]$，维护当前已匹配的长度 $q$：
   - 当遇到失配字符 $T[i] \neq P[q]$ 时，文本下标 $i$ **保持不变**，利用 $\pi$ 数组跳转回退：$q = \pi[q - 1]$；
   - 当 $T[i] == P[q]$ 时，匹配长度递增：$q++$；
   - 一旦已匹配长度达到 $q == m$，说明在起始位置 $i + 1 - m$ 处找到完整匹配，立即返回。

## C 语言实现

```c
#include <assert.h>
#include <stdbool.h>
#include <stddef.h>
#include <stdint.h>
#include <stdlib.h>

bool find_subsequence_u8(
    const unsigned char *text,
    size_t text_count,
    const unsigned char *pattern,
    size_t pattern_count,
    size_t *out_index
) {
    if (out_index == NULL ||
        (text_count > 0 && text == NULL) ||
        (pattern_count > 0 && pattern == NULL)) {
        return false;
    }

    if (pattern_count == 0) {
        *out_index = 0;
        return true;
    }

    if (text_count < pattern_count) {
        *out_index = SIZE_MAX;
        return true;
    }

    if (pattern_count > SIZE_MAX / sizeof(size_t)) {
        return false;
    }

    size_t *pi = malloc(pattern_count * sizeof *pi);
    if (pi == NULL) {
        return false;
    }

    // 1. 构建前缀函数表 pi
    pi[0] = 0;
    size_t k = 0;
    for (size_t i = 1; i < pattern_count; ++i) {
        while (k > 0 && pattern[k] != pattern[i]) {
            k = pi[k - 1];
        }
        if (pattern[k] == pattern[i]) {
            ++k;
        }
        pi[i] = k;
    }

    // 2. KMP 主扫描
    size_t q = 0;
    size_t found_index = SIZE_MAX;

    for (size_t i = 0; i < text_count; ++i) {
        while (q > 0 && pattern[q] != text[i]) {
            q = pi[q - 1];
        }
        if (pattern[q] == text[i]) {
            ++q;
        }
        if (q == pattern_count) {
            found_index = i + 1 - pattern_count;
            break;
        }
    }

    free(pi);
    *out_index = found_index;
    return true;
}

int main(void) {
    size_t idx = 0;

    // 参数校验
    assert(!find_subsequence_u8(NULL, 1, (const unsigned char*)"a", 1, &idx));

    // 空模式测试
    assert(find_subsequence_u8((const unsigned char*)"hello", 5, NULL, 0, &idx));
    assert(idx == 0);

    // 经典 KMP 测试用例
    // text: "bacbababaabcbab"
    // pattern: "abababca" (不存在)
    // pattern2: "ababa" (首次出现在 4)
    const unsigned char t1[] = "bacbababaabcbab";
    const unsigned char p1[] = "ababa";
    assert(find_subsequence_u8(t1, 15, p1, 5, &idx));
    assert(idx == 4);

    // 未找到测试
    const unsigned char p2[] = "xyz";
    assert(find_subsequence_u8(t1, 15, p2, 3, &idx));
    assert(idx == SIZE_MAX);

    return 0;
}
```

## 复杂度分析

- **时间复杂度**：严格 $O(n + m)$。构建 $\pi$ 数组耗时 $O(m)$；在主扫描中，文本指针 $i$ 步进 $n$ 次，已匹配长度 $q$ 每次至多增加 1，因此 $q$ 回退的总次数不会超过 $n$，摊还时间复杂度为严格的线性。
- **空间复杂度**：$O(m)$。仅分配用于模式串前缀函数的 $\pi$ 数组。

## 延伸思考 / 模式总结

KMP 算法的精髓在于**有限状态自动机（DFA）**的思想转移。通过事先分析模式串内部的自同构对称性，使得算法在遭遇任何失败时都能立刻跳转至“依然能够保持匹配的最长历史状态”，彻底消除了文本回溯。
