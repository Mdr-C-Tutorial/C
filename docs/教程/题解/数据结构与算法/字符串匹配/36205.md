# 36205 - 扩展 KMP（Z 算法: Z-array 线性时间构造与匹配）

## 题目

给定一个文本字节序列 `text`（长度为 `text_count`）和一个模式字节序列 `pattern`（长度为 `pattern_count`）。

使用 **Z 算法（扩展 KMP, Z-Algorithm）**在严格线性时间复杂度内计算出模式串在文本串中首次出现的起始下标。

函数签名如下：

```c
#include <stdbool.h>
#include <stddef.h>
#include <stdint.h>

bool z_algorithm_search_u8(
    const unsigned char *text,
    size_t text_count,
    const unsigned char *pattern,
    size_t pattern_count,
    size_t *out_first_index
);
```

要求：
1. 参数无效时返回 `false`；未找到时输出 `*out_first_index = SIZE_MAX` 并返回 `true`。
2. 当 `pattern_count == 0` 时，输出首次下标 0 并返回 `true`。
3. 深入解析 **Z-box 匹配区间 $[l, r]$** 的维护机制与对称性复用。
4. 算法时间复杂度必须达到严格的 $O(n + m)$，空间复杂度为 $O(m)$。

## 解题思路

1. **Z 数组的数学定义**：
   对于长度为 $n$ 的字符串 $S$，$Z[i]$ 定义为：
   从位置 $i$ 开始的后缀 $S[i \dots n - 1]$ 与原字符串 $S[0 \dots n - 1]$ 的**最长公共前缀（LCP）的长度**。

2. **Z-box 维护与 $O(n)$ 线性构造**：
   维护一个右端点延伸最远的匹配区间 $[l, r]$（即 $S[l \dots r] == S[0 \dots r - l]$），称为 **Z-box**。
   当遍历计算 $Z[i]$（$i \ge 1$）时：
   - 若 $i > r$：当前位置完全落在已探索的边界之外，直接从 $i$ 开始向后与前缀暴力比对，更新 $[l, r]$；
   - 若 $i \le r$：当前位置落在已知匹配区间 $[l, r]$ 内部！
     此时，位置 $i$ 在前缀中的镜像对应位置为 $k = i - l$。
     - 若 $Z[k] < r - i + 1$：说明从 $k$ 开始的公共前缀完全被包裹在 $[l, r]$ 内，根据对称性直接得出 $Z[i] = Z[k]$，耗时 $O(1)$！
     - 若 $Z[k] \ge r - i + 1$：说明公共前缀至少延伸到了 $r$。我们直接以 $r - i + 1$ 作为基准，从 $r + 1$ 开始向后继续延伸比对，并更新新的 $l = i, r$。
   由于右指针 $r$ 仅单调向右推进，整个数组的构建耗时为严格的线性 $O(n)$。

3. **应用于单模式串匹配**：
   首先对模式串 $P$ 构建自身的 $Z$ 数组；
   随后以模式串为基准，对文本串 $T$ 维护相对前缀的最长公共前缀数组 $Z_{text}[i]$。
   一旦某个位置的 $Z_{text}[i] == pattern\_count$，说明在该起始下标处完整匹配到了模式串。

## C 语言实现

```c
#include <assert.h>
#include <stdbool.h>
#include <stddef.h>
#include <stdint.h>
#include <stdlib.h>

static void compute_z(const unsigned char *s, size_t n, size_t *z) {
    z[0] = n;
    size_t l = 0;
    size_t r = 0;
    for (size_t i = 1; i < n; ++i) {
        if (i <= r) {
            size_t k = i - l;
            if (z[k] < r - i + 1) {
                z[i] = z[k];
            } else {
                size_t j = r - i + 1;
                while (i + j < n && s[i + j] == s[j]) {
                    j++;
                }
                z[i] = j;
                l = i;
                r = i + j - 1;
            }
        } else {
            size_t j = 0;
            while (i + j < n && s[i + j] == s[j]) {
                j++;
            }
            z[i] = j;
            if (j > 0) {
                l = i;
                r = i + j - 1;
            }
        }
    }
}

bool z_algorithm_search_u8(
    const unsigned char *text,
    size_t text_count,
    const unsigned char *pattern,
    size_t pattern_count,
    size_t *out_first_index
) {
    if (out_first_index == NULL ||
        (text_count > 0 && text == NULL) ||
        (pattern_count > 0 && pattern == NULL)) {
        return false;
    }

    if (pattern_count == 0) {
        *out_first_index = 0;
        return true;
    }

    if (text_count < pattern_count) {
        *out_first_index = SIZE_MAX;
        return true;
    }

    size_t m = pattern_count;
    size_t *z_pattern = malloc(m * sizeof *z_pattern);
    if (z_pattern == NULL) {
        return false;
    }

    // 1. 预处理模式串自身的 Z 数组
    compute_z(pattern, m, z_pattern);

    // 2. 利用 Z-box 在文本上匹配
    size_t l = 0;
    size_t r = 0;
    size_t found_idx = SIZE_MAX;

    for (size_t i = 0; i < text_count; ++i) {
        size_t z_val = 0;
        if (i <= r) {
            size_t k = i - l;
            if (z_pattern[k] < r - i + 1) {
                z_val = z_pattern[k];
            } else {
                size_t j = r - i + 1;
                while (j < m && i + j < text_count && text[i + j] == pattern[j]) {
                    j++;
                }
                z_val = j;
                l = i;
                r = i + j - 1;
            }
        } else {
            size_t j = 0;
            while (j < m && i + j < text_count && text[i + j] == pattern[j]) {
                j++;
            }
            z_val = j;
            if (j > 0) {
                l = i;
                r = i + j - 1;
            }
        }

        if (z_val == m) {
            found_idx = i;
            break;
        }
    }

    free(z_pattern);
    *out_first_index = found_idx;
    return true;
}

int main(void) {
    size_t idx = 0;

    // 参数校验
    assert(!z_algorithm_search_u8(NULL, 1, (const unsigned char*)"a", 1, &idx));

    // 空模式
    assert(z_algorithm_search_u8((const unsigned char*)"abc", 3, NULL, 0, &idx));
    assert(idx == 0);

    // 标准测试用例
    const unsigned char t1[] = "abacabaaabacaba";
    const unsigned char p1[] = "aabac";
    assert(z_algorithm_search_u8(t1, 15, p1, 5, &idx));
    assert(idx == 7); // 首次出现在下标 7: "...aabac..."

    // 未找到测试
    const unsigned char p2[] = "xyz";
    assert(z_algorithm_search_u8(t1, 15, p2, 3, &idx));
    assert(idx == SIZE_MAX);

    return 0;
}
```

## 复杂度分析

- **时间复杂度**：严格 $O(n + m)$。构建模式串 $Z$ 数组耗时 $O(m)$，在文本串上推进 Z-box 耗时 $O(n)$。右端指针 $r$ 在比对成功时单调向右延伸，字符比较失败时直接跳入下一个位置，字符比对总次数不超过 $2(n + m)$。
- **空间复杂度**：$O(m)$。仅为模式串分配长度为 $m$ 的 $Z$ 数组。

## 延伸思考 / 模式总结

Z 算法是比 KMP 在逻辑上更为直观的前缀匹配利器。其不仅能解决字符串匹配，还能在 $O(n)$ 线性时间内求解模式串在文本中的所有前缀覆盖、回文最长前缀等问题。
