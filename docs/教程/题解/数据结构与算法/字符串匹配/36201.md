# 36201：KMP 字节序列首次匹配

## 题目

在任意字节序列 `text`（长度 `text_count`）中，使用 KMP 算法查找模式字节序列 `pattern`（长度 `pattern_count`）首次出现的起始下标，并通过 `out_index` 输出（未找到时输出 `SIZE_MAX`）。

## 解析

由于输入是任意二进制字节序列（可能包含 `0x00` 字节且不以空字符结尾），算法全程基于显式长度 `text_count` 与 `pattern_count` 访问字节，绝不调用依赖结尾空字符的字符串库函数：

1. **边界情形**：先校验参数有效性（`out_index != NULL`，且长度非零时对应缓冲区指针非空）。若 `pattern_count == 0`，空模式是任意序列在下标 `0` 处的前缀，直接写入 `*out_index = 0` 并返回 `true`；若 `text_count < pattern_count`，模式不可能出现，直接写入 `*out_index = SIZE_MAX` 并返回 `true`。
2. **构造前缀函数表 $\pi$**：分配长度为 `pattern_count` 的 `size_t` 数组 `pi`。对每个位置 `i`（从 `1` 到 `pattern_count - 1`），维护前一步的最长相等真前后缀长度 `k`，失配时沿 `k = pi[k - 1]` 回退，直至 `k == 0` 或 `pattern[k] == pattern[i]`。
3. **主扫描**：文本下标 `i` 从 `0` 单调递增到 `text_count - 1` 永不回退；当前已匹配长度 `q` 在失配时通过 `q = pi[q - 1]` 跳转，一旦 `q == pattern_count`，即在起始位置 `i + 1 - pattern_count` 找到首次完整匹配。

## 答案

```c
#include <stdbool.h>
#include <stddef.h>
#include <stdint.h>
#include <stdlib.h>

bool find_subsequence_u8(
    const unsigned char *text,
    size_t text_count,
    const unsigned char *pattern,
    size_t pattern_count,
    size_t *out_index
) {
    if (out_index == NULL ||
        (text_count > 0 && text == NULL) ||
        (pattern_count > 0 && pattern == NULL)) {
        return false;
    }
    if (pattern_count == 0) {
        *out_index = 0;
        return true;
    }
    if (text_count < pattern_count) {
        *out_index = SIZE_MAX;
        return true;
    }
    if (pattern_count > SIZE_MAX / sizeof(size_t)) {
        return false;
    }
    size_t *pi = malloc(pattern_count * sizeof *pi);
    if (pi == NULL) {
        return false;
    }
    pi[0] = 0;
    size_t k = 0;
    for (size_t i = 1; i < pattern_count; ++i) {
        while (k > 0 && pattern[k] != pattern[i]) {
            k = pi[k - 1];
        }
        if (pattern[k] == pattern[i]) {
            ++k;
        }
        pi[i] = k;
    }

    size_t matched = 0;
    for (size_t i = 0; i < text_count; ++i) {
        while (matched > 0 && pattern[matched] != text[i]) {
            matched = pi[matched - 1];
        }
        if (pattern[matched] == text[i]) {
            ++matched;
        }
        if (matched == pattern_count) {
            free(pi);
            *out_index = i + 1 - pattern_count;
            return true;
        }
    }
    free(pi);
    *out_index = SIZE_MAX;
    return true;
}
```

由势能法分析可知，构造前缀表和扫描文本时匹配长度每次外层循环至多加 `1`、每次内层回退至少减 `1`，总比较次数为线性，时间复杂度为 $O(n + m)$，额外空间复杂度为存放前缀表的 $O(m)$。
