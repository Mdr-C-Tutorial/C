# 36208 - Aho-Corasick 多模式匹配自动机（AC 自动机 Fail 指针构建）

## 题目

给定一个文本字节序列 `text`（长度为 `text_count`）以及包含 `num_patterns` 个不同模式串的模式集 `patterns`。

实现 **Aho-Corasick 多模式匹配自动机（AC 自动机）**，在**单次线性扫描文本串**的过程中，统计并输出每一个模式串在文本串中出现的总次数（包含可重叠出现）。

函数签名如下：

```c
#include <stdbool.h>
#include <stddef.h>
#include <stdint.h>

bool ac_automaton_search_u8(
    const unsigned char *text,
    size_t text_count,
    const unsigned char * const *patterns,
    const size_t *pattern_counts,
    size_t num_patterns,
    size_t *out_match_counts
);
```

要求：
1. 参数无效时返回 `false`。
2. 构建阶段：
   - 将全部模式串插入到 Trie 树中；
   - 使用广度优先搜索（BFS）层序构建失配指针（`fail`）。
3. 匹配阶段：在文本上单次扫描转移，每到一个状态沿 `fail` 链统计命中模式，时间复杂度为 $O(text\_count + \sum pattern\_len)$。

## 解题思路

1. **AC 自动机的本质**：
   AC 自动机是 **Trie 字典树**与 **KMP 状态转移思想**的结合体。
   - Trie 树将所有模式串的前缀公用压缩存储；
   - KMP 在单模式串上定义前缀函数 $\pi$；
   - AC 自动机在 Trie 树的每个节点上定义 **`fail` 失配指针**：若从根到节点 $u$ 表示字符串 $S$，则 $fail[u]$ 指向 Trie 树中代表 $S$ 的**最长严格真后缀**的那个节点。

2. **BFS 层序构建 Fail 指针**：
   - 深度为 1 的节点（根节点的所有直接子节点）：其最长真后缀只能是空串，故其 `fail` 指针一律指向根节点 0；
   - 使用队列按 BFS 层序遍历其余节点：
     设当前父节点为 $u$，其子节点 $v$ 由字符 $c$ 转移而来（即 $children[u][c] = v$）。
     要寻找 $v$ 的失配指针：
     从父节点的失配指针 $p = fail[u]$ 开始，若 $children[p][c]$ 存在，则 $fail[v] = children[p][c]$；
     若不存在，则令 $p = fail[p]$ 继续向上回溯，直到找到匹配的分支或回到根节点。

3. **文本单次扫描匹配**：
   文本扫描从根节点出发，游标状态为 $curr$：
   对于文本中的每一个字节 $c$：
   - 若当前节点没有字符 $c$ 的转移分支，沿着 `fail` 指针回退，直至找到有对应转移的节点或回退到根节点；
   - 若有对应转移，步进至对应子节点；
   - 沿 `fail` 链回溯：检查该节点及其所有 `fail` 祖先是否代表某个模式串的结尾，若代表则对应模式串的计数器递增 1。

## C 语言实现

```c
#include <assert.h>
#include <stdbool.h>
#include <stddef.h>
#include <stdint.h>
#include <stdlib.h>
#include <string.h>

typedef struct ACNode ACNode;
struct ACNode {
    size_t children[256];
    size_t fail;
    size_t pattern_index; // 若为 SIZE_MAX 表示非模式结尾
};

typedef struct {
    ACNode *nodes;
    size_t size;
    size_t capacity;
} ACTrie;

static size_t ac_new_node(ACTrie *trie) {
    if (trie->size >= trie->capacity) {
        size_t new_cap = (trie->capacity == 0) ? 128 : trie->capacity * 2;
        ACNode *new_nodes = realloc(trie->nodes, new_cap * sizeof(ACNode));
        if (new_nodes == NULL) return SIZE_MAX;
        trie->nodes = new_nodes;
        trie->capacity = new_cap;
    }
    size_t idx = trie->size++;
    memset(trie->nodes[idx].children, 0, sizeof(trie->nodes[idx].children));
    trie->nodes[idx].fail = 0;
    trie->nodes[idx].pattern_index = SIZE_MAX;
    return idx;
}

bool ac_automaton_search_u8(
    const unsigned char *text,
    size_t text_count,
    const unsigned char * const *patterns,
    const size_t *pattern_counts,
    size_t num_patterns,
    size_t *out_match_counts
) {
    if (out_match_counts == NULL ||
        (text_count > 0 && text == NULL) ||
        (num_patterns > 0 && (patterns == NULL || pattern_counts == NULL))) {
        return false;
    }

    for (size_t i = 0; i < num_patterns; ++i) {
        out_match_counts[i] = 0;
    }
    if (num_patterns == 0 || text_count == 0) {
        return true;
    }

    ACTrie trie = { .nodes = NULL, .size = 0, .capacity = 0 };
    // 0 号节点为根节点
    if (ac_new_node(&trie) == SIZE_MAX) {
        return false;
    }

    // 1. 将所有模式串插入 Trie 树
    for (size_t p = 0; p < num_patterns; ++p) {
        size_t m = pattern_counts[p];
        const unsigned char *pat = patterns[p];
        if (m == 0 || pat == NULL) {
            continue;
        }

        size_t curr = 0;
        for (size_t i = 0; i < m; ++i) {
            unsigned char c = pat[i];
            if (trie.nodes[curr].children[c] == 0) {
                size_t next_node = ac_new_node(&trie);
                if (next_node == SIZE_MAX) {
                    free(trie.nodes);
                    return false;
                }
                trie.nodes[curr].children[c] = next_node;
            }
            curr = trie.nodes[curr].children[c];
        }
        trie.nodes[curr].pattern_index = p;
    }

    // 2. BFS 构建 Fail 指针
    size_t *queue = malloc(trie.size * sizeof(size_t));
    if (queue == NULL) {
        free(trie.nodes);
        return false;
    }

    size_t head = 0;
    size_t tail = 0;

    // 深度为 1 的节点 fail 指向根 0
    for (size_t c = 0; c < 256; ++c) {
        size_t child = trie.nodes[0].children[c];
        if (child != 0) {
            trie.nodes[child].fail = 0;
            queue[tail++] = child;
        }
    }

    while (head < tail) {
        size_t u = queue[head++];

        for (size_t c = 0; c < 256; ++c) {
            size_t v = trie.nodes[u].children[c];
            if (v != 0) {
                size_t p = trie.nodes[u].fail;
                while (p > 0 && trie.nodes[p].children[c] == 0) {
                    p = trie.nodes[p].fail;
                }
                if (trie.nodes[p].children[c] != 0 && trie.nodes[p].children[c] != v) {
                    trie.nodes[v].fail = trie.nodes[p].children[c];
                } else {
                    trie.nodes[v].fail = 0;
                }
                queue[tail++] = v;
            }
        }
    }

    // 3. 文本单次扫描匹配
    size_t curr = 0;
    for (size_t i = 0; i < text_count; ++i) {
        unsigned char c = text[i];
        while (curr > 0 && trie.nodes[curr].children[c] == 0) {
            curr = trie.nodes[curr].fail;
        }
        curr = trie.nodes[curr].children[c];

        // 沿 fail 链收集所有匹配项
        size_t check = curr;
        while (check > 0) {
            if (trie.nodes[check].pattern_index != SIZE_MAX) {
                out_match_counts[trie.nodes[check].pattern_index]++;
            }
            check = trie.nodes[check].fail;
        }
    }

    free(queue);
    free(trie.nodes);
    return true;
}

int main(void) {
    size_t counts[4] = {0};

    // 模式集:
    // P0: "he"
    // P1: "she"
    // P2: "his"
    // P3: "hers"
    // 文本: "ushers"
    // 匹配分析:
    // "ushers" 中包含:
    // "she" (在 "ushe") -> 1 次
    // "he"  (在 "she" 和 "hers") -> 2 次
    // "hers" (在 "hers") -> 1 次
    // "his" -> 0 次
    const unsigned char *patterns[4] = {
        (const unsigned char*)"he",
        (const unsigned char*)"she",
        (const unsigned char*)"his",
        (const unsigned char*)"hers"
    };
    const size_t p_counts[4] = {2, 3, 3, 4};
    const unsigned char text[] = "ushers";

    assert(ac_automaton_search_u8(text, 6, patterns, p_counts, 4, counts));
    assert(counts[0] == 1); // "he" 出现 1 次 (在 "ushe" / "hers" 的重叠处)
    assert(counts[1] == 1); // "she" 出现 1 次
    assert(counts[2] == 0); // "his" 出现 0 次
    assert(counts[3] == 1); // "hers" 出现 1 次

    return 0;
}
```

## 复杂度分析

- **时间复杂度**：
  - **预处理阶段**：$O(\sum |P_i| \times \Sigma)$，将所有模式串插入字典树并 BFS 计算 Fail 指针；
  - **搜索阶段**：$O(|T| + M)$，其中 $|T|$ 为文本长度，$M$ 为总匹配发生次数。文本字符仅被向前单向处理一次。
- **空间复杂度**：$O(\sum |P_i| \times \Sigma)$，用于存储 Trie 节点状态机。

## 延伸思考 / 模式总结

Aho-Corasick 算法是多模式匹配领域的基石，广泛应用于入侵检测系统（Snort/Suricata 规则匹配）、敏感词过滤系统以及生物信息学基因片段并行比对。通过将单模式 KMP 扩展至字典树，实现了与模式串数量无关的恒定吞吐效率。
