# 36108 - 有向图强连通分量（SCC）Tarjan 算法与缩点 DAG

## 题目描述

在一个有向图 $G = (V, E)$ 中，如果两个顶点 $u$ 和 $v$ 之间既存在从 $u$ 到 $v$ 的有向路径，也存在从 $v$ 到 $u$ 的有向路径，则称 $u$ 和 $v$ 是强连通的。有向图的极大强连通子图称为**强连通分量（Strongly Connected Component, SCC）**。

请实现 Tarjan 算法：
1. 计算有向图中的强连通分量总数；
2. 为每个顶点赋予所属强连通分量的唯一标识 ID（从 0 开始连续标号）。

函数签名如下：

```c
#include <stdbool.h>
#include <stddef.h>

bool tarjan_scc(
    size_t vertex_count,
    const size_t edges[][2],
    size_t edge_count,
    size_t *out_scc_id,
    size_t *out_scc_count
);
```

要求：
1. 参数无效时返回 `false`。
2. 当 $V = 0$ 时，SCC 数量为 0，返回 `true`。
3. 利用显式栈、时间戳 `dfn` 与追溯值 `low` 在一次单遍深度优先搜索中完成求解，时间复杂度必须为 $O(V + E)$。
4. 缩点性质保证：同一强连通分量内的所有顶点具有完全相同的 `out_scc_id`，而将每个 SCC 缩为单个超级节点后，新图必然是一个**有向无环图（DAG）**。

## 解题思路

1. **强连通分量在 DFS 树中的结构**：
   在 DFS 过程中，每个强连通分量在搜索树中必然存在一个最早被访问的“根顶点”（该 SCC 中 `dfn` 最小的节点）。整个强连通分量的所有其他节点都是该根节点的子孙节点。

2. **栈维护与追溯值更新**：
   维护一个栈 `stack`，用于保存当前搜索路径上的顶点以及尚未确定所属分量的子树节点。
   - 访问顶点 $u$ 时，$u$ 入栈并标记 `in_stack[u] = true`；
   - 遍历 $u$ 的出边 $u \to v$：
     - 若 $v$ 尚未访问（`dfn[v] == 0`）：递归访问 $v$，返回后更新 $low[u] = \min(low[u], low[v])$；
     - 若 $v$ 已经访问过，且当前仍在栈中（`in_stack[v] == true`）：说明通过边 $u \to v$ 形成了一个可以回到祖先的回环，更新 $low[u] = \min(low[u], dfn[v])$；
     - 若 $v$ 已经访问但不在栈中：说明 $v$ 属于此前已经确定并弹出的其他强连通分量，直接忽略。

3. **分量确定与弹栈（`low[u] == dfn[u]`）**：
   当遍历完 $u$ 的所有出边后，若 $low[u] == dfn[u]$，说明从以 $u$ 为根的子树中的任何节点出发，都无法到达比 $u$ 更早的祖先！
   因此，$u$ 就是当前强连通分量的总根节点：
   从栈顶不断弹出节点，赋予当前的 `scc_id`，并将 `in_stack` 设为 `false`，直到弹出节点 $u$ 为止。

## C 语言实现

```c
#include <assert.h>
#include <stdbool.h>
#include <stddef.h>
#include <stdlib.h>

typedef struct EdgeNode EdgeNode;
struct EdgeNode {
    size_t to;
    EdgeNode *next;
};

static void scc_dfs(
    size_t u,
    const EdgeNode * const *adj,
    size_t *dfn,
    size_t *low,
    size_t *timer,
    size_t *stack,
    size_t *stack_top,
    bool *in_stack,
    size_t *scc_id,
    size_t *scc_count
) {
    dfn[u] = low[u] = ++(*timer);
    stack[(*stack_top)++] = u;
    in_stack[u] = true;

    for (const EdgeNode *e = adj[u]; e != NULL; e = e->next) {
        size_t v = e->to;
        if (dfn[v] == 0) {
            scc_dfs(v, adj, dfn, low, timer, stack, stack_top, in_stack, scc_id, scc_count);
            if (low[v] < low[u]) {
                low[u] = low[v];
            }
        } else if (in_stack[v]) {
            if (dfn[v] < low[u]) {
                low[u] = dfn[v];
            }
        }
    }

    // 命中 SCC 根节点
    if (low[u] == dfn[u]) {
        size_t current_id = (*scc_count)++;
        for (;;) {
            size_t node = stack[--(*stack_top)];
            in_stack[node] = false;
            scc_id[node] = current_id;
            if (node == u) {
                break;
            }
        }
    }
}

bool tarjan_scc(
    size_t vertex_count,
    const size_t edges[][2],
    size_t edge_count,
    size_t *out_scc_id,
    size_t *out_scc_count
) {
    if (out_scc_id == NULL || out_scc_count == NULL ||
        (edge_count > 0 && edges == NULL)) {
        return false;
    }
    if (vertex_count == 0) {
        *out_scc_count = 0;
        return true;
    }

    EdgeNode **adj = calloc(vertex_count, sizeof(EdgeNode*));
    EdgeNode *pool = malloc(edge_count * sizeof(EdgeNode));
    size_t *dfn = calloc(vertex_count, sizeof(size_t));
    size_t *low = calloc(vertex_count, sizeof(size_t));
    size_t *stack = malloc(vertex_count * sizeof(size_t));
    bool *in_stack = calloc(vertex_count, sizeof(bool));

    if (adj == NULL || (edge_count > 0 && pool == NULL) || dfn == NULL ||
        low == NULL || stack == NULL || in_stack == NULL) {
        free(adj); free(pool); free(dfn); free(low); free(stack); free(in_stack);
        return false;
    }

    for (size_t i = 0; i < edge_count; ++i) {
        size_t u = edges[i][0];
        size_t v = edges[i][1];
        if (u >= vertex_count || v >= vertex_count) {
            free(adj); free(pool); free(dfn); free(low); free(stack); free(in_stack);
            return false;
        }
        pool[i].to = v;
        pool[i].next = adj[u];
        adj[u] = &pool[i];
    }

    size_t timer = 0;
    size_t stack_top = 0;
    size_t scc_cnt = 0;

    for (size_t i = 0; i < vertex_count; ++i) {
        if (dfn[i] == 0) {
            scc_dfs(i, (const EdgeNode * const *)adj, dfn, low, &timer,
                    stack, &stack_top, in_stack, out_scc_id, &scc_cnt);
        }
    }

    *out_scc_count = scc_cnt;

    free(adj);
    free(pool);
    free(dfn);
    free(low);
    free(stack);
    free(in_stack);
    return true;
}

int main(void) {
    size_t scc_id[8];
    size_t scc_count = 0;

    // 参数校验
    assert(!tarjan_scc(3, NULL, 1, scc_id, &scc_count));

    // 经典有向图测试:
    // 分量 1: 0 -> 1 -> 2 -> 0 (强连通环)
    // 分量 2: 3 -> 4 (单向边，各自独立)
    // 边: (0, 1), (1, 2), (2, 0), (2, 3), (3, 4)
    const size_t e5[5][2] = {
        {0, 1}, {1, 2}, {2, 0}, {2, 3}, {3, 4}
    };

    assert(tarjan_scc(5, e5, 5, scc_id, &scc_count));
    // 共有 3 个强连通分量: {0, 1, 2}, {3}, {4}
    assert(scc_count == 3);

    // 0, 1, 2 属于同一个强连通分量
    assert(scc_id[0] == scc_id[1] && scc_id[1] == scc_id[2]);
    // 3 和 4 属于不同的分量
    assert(scc_id[3] != scc_id[0]);
    assert(scc_id[4] != scc_id[0]);
    assert(scc_id[3] != scc_id[4]);

    return 0;
}
```

## 复杂度分析

- **时间复杂度**：$O(V + E)$。每个顶点入栈出栈各一次，每条有向边被正向遍历一次，算法在线性时间内彻底解决。
- **空间复杂度**：$O(V + E)$。邻接表需要 $O(E)$ 内存，栈、`dfn`、`low` 和递归调用栈占用 $O(V)$。

## 延伸思考 / 模式总结

强连通分量分解是有向图分析的终极化简工具。通过将每个 SCC 缩为单个超顶点，可以将任何含有复杂环路的一般有向图转化为有向无环图（DAG），从而可以在缩点后的 DAG 上进行拓扑排序、最长路与动态规划计算。
