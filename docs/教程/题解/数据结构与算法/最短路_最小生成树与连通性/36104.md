# 36104 - Prim 最小生成树（优先队列优化，适合稠密图）

## 题目描述

给定一个包含 $V$ 个顶点的无向连通带权图，使用基于优先队列（最小堆）优化的 Prim 算法计算该图的**最小生成树权重之和**。

函数签名如下：

```c
#include <stdbool.h>
#include <stddef.h>
#include <stdint.h>

bool prim_mst_weight(
    size_t vertex_count,
    const size_t edges[][2],
    const uint64_t *weights,
    size_t edge_count,
    uint64_t *out_mst_weight
);
```

要求：
1. 图不连通时返回 `false`，且不修改输出对象。
2. 边权求和发生 64 位无符号整数溢出时返回 `false`。
3. 从任意一个顶点（通常为顶点 0）开始逐步扩充生成树割，使用二叉堆维护所有不在树中的顶点到树集合的最短横切边。
4. 时间复杂度为 $O((V + E) \log V)$，空间复杂度为 $O(V + E)$。

## 解题思路

1. **Prim 算法的扩展割机制**：
   Prim 算法从单点开始逐步向外“生长”出一棵最小生成树。
   将顶点集划分为两个互斥集合：
   - 树顶点集合 $S$（初始仅包含起点 0）；
   - 非树顶点集合 $V \setminus S$。
   在每一步中，找到跨越割 $(S, V \setminus S)$ 且权重最小的横切边 $(u, v)$，将顶点 $v$ 并入 $S$，并将该边权计入生成树总重。

2. **堆优化状态设计**：
   维护大小为 $V$ 的布尔数组 `in_mst`，记录顶点是否已加入生成树。
   二叉小顶堆存放候选边 `(weight, to_vertex)`：
   - 初始时将起点 0 的距离设为 0 入堆；
   - 每次从堆顶弹出权重最小的结点 $(w, u)$：
     若 `in_mst[u]` 已为真，说明该顶点已在树中，忽略（惰性删除）；
     否则，将 `in_mst[u] = true`，累计总权重；
     遍历 $u$ 的所有邻接边 $(u, v, weight)$：
     若 $v$ 尚未在树中，将 $(weight, v)$ 推入小顶堆；
   - 重复该过程直到所有顶点均并入树中（选出 $V$ 个顶点）。

## C 语言实现

```c
#include <assert.h>
#include <stdbool.h>
#include <stddef.h>
#include <stdint.h>
#include <stdlib.h>

typedef struct {
    uint64_t weight;
    size_t u;
} PrimHeapNode;

typedef struct {
    PrimHeapNode *data;
    size_t size;
} PrimMinHeap;

static void prim_heap_swap(PrimHeapNode *a, PrimHeapNode *b) {
    PrimHeapNode tmp = *a;
    *a = *b;
    *b = tmp;
}

static void prim_heap_push(PrimMinHeap *h, uint64_t w, size_t u) {
    size_t i = h->size++;
    h->data[i] = (PrimHeapNode){w, u};
    while (i > 0) {
        size_t p = (i - 1) / 2;
        if (h->data[i].weight < h->data[p].weight) {
            prim_heap_swap(&h->data[i], &h->data[p]);
            i = p;
        } else {
            break;
        }
    }
}

static PrimHeapNode prim_heap_pop(PrimMinHeap *h) {
    PrimHeapNode min_val = h->data[0];
    h->data[0] = h->data[--h->size];
    size_t i = 0;
    while (2 * i + 1 < h->size) {
        size_t left = 2 * i + 1;
        size_t right = 2 * i + 2;
        size_t best = left;
        if (right < h->size && h->data[right].weight < h->data[left].weight) {
            best = right;
        }
        if (h->data[best].weight < h->data[i].weight) {
            prim_heap_swap(&h->data[i], &h->data[best]);
            i = best;
        } else {
            break;
        }
    }
    return min_val;
}

typedef struct EdgeNode EdgeNode;
struct EdgeNode {
    size_t to;
    uint64_t weight;
    EdgeNode *next;
};

bool prim_mst_weight(
    size_t vertex_count,
    const size_t edges[][2],
    const uint64_t *weights,
    size_t edge_count,
    uint64_t *out_mst_weight
) {
    if (out_mst_weight == NULL || (edge_count > 0 && (edges == NULL || weights == NULL))) {
        return false;
    }
    if (vertex_count <= 1) {
        *out_mst_weight = 0;
        return true;
    }

    EdgeNode **adj = calloc(vertex_count, sizeof(EdgeNode*));
    EdgeNode *pool = malloc(2 * edge_count * sizeof(EdgeNode));
    bool *in_mst = calloc(vertex_count, sizeof(bool));
    PrimMinHeap heap = {
        .data = malloc((2 * edge_count + 1) * sizeof(PrimHeapNode)),
        .size = 0
    };

    if (adj == NULL || (edge_count > 0 && pool == NULL) || in_mst == NULL || heap.data == NULL) {
        free(adj); free(pool); free(in_mst); free(heap.data);
        return false;
    }

    // 构建无向图邻接表
    size_t pool_idx = 0;
    for (size_t i = 0; i < edge_count; ++i) {
        size_t u = edges[i][0];
        size_t v = edges[i][1];
        if (u >= vertex_count || v >= vertex_count) {
            free(adj); free(pool); free(in_mst); free(heap.data);
            return false;
        }
        pool[pool_idx].to = v;
        pool[pool_idx].weight = weights[i];
        pool[pool_idx].next = adj[u];
        adj[u] = &pool[pool_idx++];

        pool[pool_idx].to = u;
        pool[pool_idx].weight = weights[i];
        pool[pool_idx].next = adj[v];
        adj[v] = &pool[pool_idx++];
    }

    uint64_t total_weight = 0;
    size_t vertices_included = 0;

    // 从顶点 0 开始生长
    prim_heap_push(&heap, 0, 0);

    while (heap.size > 0 && vertices_included < vertex_count) {
        PrimHeapNode node = prim_heap_pop(&heap);
        size_t u = node.u;
        uint64_t w = node.weight;

        if (in_mst[u]) {
            continue; // 惰性丢弃
        }

        in_mst[u] = true;
        if (total_weight > UINT64_MAX - w) {
            free(adj); free(pool); free(in_mst); free(heap.data);
            return false;
        }
        total_weight += w;
        vertices_included++;

        for (const EdgeNode *e = adj[u]; e != NULL; e = e->next) {
            size_t v = e->to;
            if (!in_mst[v]) {
                prim_heap_push(&heap, e->weight, v);
            }
        }
    }

    free(adj);
    free(pool);
    free(in_mst);
    free(heap.data);

    if (vertices_included != vertex_count) {
        return false; // 图不连通
    }

    *out_mst_weight = total_weight;
    return true;
}

int main(void) {
    uint64_t mst_wt = 0;

    // 参数校验
    assert(!prim_mst_weight(3, NULL, NULL, 1, &mst_wt));

    // 0 与 1 顶点边界
    assert(prim_mst_weight(0, NULL, NULL, 0, &mst_wt) && mst_wt == 0);
    assert(prim_mst_weight(1, NULL, NULL, 0, &mst_wt) && mst_wt == 0);

    // 标准无向图测试:
    // (0, 1): 1,  (1, 2): 2,  (2, 3): 3,  (0, 3): 4,  (0, 2): 5
    // MST 权重和 = 1 + 2 + 3 = 6
    const size_t e4[5][2] = {
        {0, 1}, {1, 2}, {2, 3}, {0, 3}, {0, 2}
    };
    const uint64_t w4[5] = {1, 2, 3, 4, 5};
    assert(prim_mst_weight(4, e4, w4, 5, &mst_wt));
    assert(mst_wt == 6);

    // 非连通图测试
    const size_t e_dis[2][2] = {{0, 1}, {2, 3}};
    const uint64_t w_dis[2] = {10, 20};
    assert(!prim_mst_weight(4, e_dis, w_dis, 2, &mst_wt));

    return 0;
}
```

## 复杂度分析

- **时间复杂度**：$O((V + E) \log V)$。使用二叉小顶堆后，每个顶点最多入堆一次，每条无向边双向入堆各一次，单次堆操作耗时 $O(\log V)$。在稠密图中结合斐波那契堆可进一步优化为 $O(E + V \log V)$。
- **空间复杂度**：$O(V + E)$。邻接表和优先队列数组分别占用 $O(E)$ 与 $O(V)$。

## 延伸思考 / 模式总结

Prim 算法与 Dijkstra 算法在逻辑结构上高度孪生。二者的根本区别在于优先队列中的排序键（Key）：Dijkstra 比较的是“从源点出发的累计总距离”，而 Prim 比较的是“跨越当前割的单条边的直接权重”。
