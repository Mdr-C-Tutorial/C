# 36104 - Bellman-Ford 算法与可达负权环检测

## 题目描述

在一个包含 $V$ 个顶点的有向图中，**允许存在负权边**。使用 Bellman-Ford 算法求解从源点 `source` 出发的单源最短路径。

若图中存在从 `source` **可达的负权回路（Negative Cycle）**，则最短路径可被无限缩短至负无穷，此时算法必须准确检测出该负权环并返回相应状态。

函数签名如下：

```c
#include <stdbool.h>
#include <stddef.h>
#include <stdint.h>

typedef enum {
    BELLMAN_FORD_OK,
    BELLMAN_FORD_INVALID,
    BELLMAN_FORD_NEGATIVE_CYCLE
} BellmanFordResult;

BellmanFordResult bellman_ford_shortest_paths(
    size_t vertex_count,
    const size_t edges[][2],
    const int64_t *weights,
    size_t edge_count,
    size_t source,
    int64_t *out_distances
);
```

要求：
1. 不可达顶点的距离用 `INT64_MAX` 哨兵值标记。
2. 必须执行严格的 64 位有符号整数溢出防护，防止因 `INT64_MAX` 加上负数或负数相加越界产生未定义行为。
3. 最多执行 $V - 1$ 轮全边松弛。若某轮未发生任何松弛，提前跳出循环。
4. 第 $V$ 轮若仍能成功松弛某条边，证明存在从源点可达的负权环，返回 `BELLMAN_FORD_NEGATIVE_CYCLE`。

## 解题思路

1. **为什么 $V - 1$ 轮松弛足以收敛简单最短路**：
   在不含负权环的图中，从源点到任意顶点的最短路径至多包含 $V - 1$ 条边（即一条无自交的简单路径）。
   Bellman-Ford 算法建立循环不变式：在第 $k$ 轮全边松弛结束后，所有边数不超过 $k$ 的最短路径距离均已精确收敛。因此，经过 $V - 1$ 轮松弛，所有顶点的最短路径必定全部确定。

2. **第 $V$ 轮检测负权环**：
   如果经过 $V - 1$ 轮松弛后，在第 $V$ 轮中仍存在某条边 $(u, v, w)$ 满足：
   `dist[u] != INT64_MAX && dist[u] + w < dist[v]`
   这意味着从源点到 $v$ 存在一条包含至少 $V$ 条边的更短路径。由抽屉原理，该路径上必有至少一个顶点重复出现，即存在一个负权回路。

3. **有符号整数溢出与不可达防污染**：
   C 语言标准规定有符号整数溢出为未定义行为（UB）：
   - 只有 `dist[u] != INT64_MAX`（即从源点已可达）的顶点，其出边才允许参与松弛，避免未激活孤立分量中的负边非法更新距离；
   - 在计算 `dist[u] + w` 之前，必须先通过条件判断（如 `w > 0 && dist[u] >= INT64_MAX - w`）拦截溢出。

## C 语言实现

```c
#include <assert.h>
#include <stdbool.h>
#include <stddef.h>
#include <stdint.h>
#include <stdlib.h>

typedef enum {
    BELLMAN_FORD_OK,
    BELLMAN_FORD_INVALID,
    BELLMAN_FORD_NEGATIVE_CYCLE
} BellmanFordResult;

static bool safe_add(int64_t base, int64_t w, int64_t *res) {
    if (w > 0 && base >= INT64_MAX - w) {
        return false;
    }
    if (w < 0 && base < INT64_MIN - w) {
        return false;
    }
    *res = base + w;
    return true;
}

BellmanFordResult bellman_ford_shortest_paths(
    size_t vertex_count,
    const size_t edges[][2],
    const int64_t *weights,
    size_t edge_count,
    size_t source,
    int64_t *out_distances
) {
    if (out_distances == NULL || source >= vertex_count ||
        (edge_count > 0 && (edges == NULL || weights == NULL))) {
        return BELLMAN_FORD_INVALID;
    }
    if (vertex_count == 0) {
        return BELLMAN_FORD_OK;
    }

    int64_t *dist = malloc(vertex_count * sizeof *dist);
    if (dist == NULL) {
        return BELLMAN_FORD_INVALID;
    }

    for (size_t i = 0; i < vertex_count; ++i) {
        dist[i] = INT64_MAX;
    }
    dist[source] = 0;

    // 最多执行 V - 1 轮全边松弛
    for (size_t round = 1; round < vertex_count; ++round) {
        bool any_relaxed = false;

        for (size_t e = 0; e < edge_count; ++e) {
            size_t u = edges[e][0];
            size_t v = edges[e][1];
            int64_t w = weights[e];

            if (u >= vertex_count || v >= vertex_count) {
                free(dist);
                return BELLMAN_FORD_INVALID;
            }

            if (dist[u] != INT64_MAX) {
                int64_t cand = 0;
                if (!safe_add(dist[u], w, &cand)) {
                    free(dist);
                    return BELLMAN_FORD_INVALID;
                }
                if (cand < dist[v]) {
                    dist[v] = cand;
                    any_relaxed = true;
                }
            }
        }

        if (!any_relaxed) {
            break; // 提前收敛
        }
    }

    // 第 V 轮检测负权环
    for (size_t e = 0; e < edge_count; ++e) {
        size_t u = edges[e][0];
        size_t v = edges[e][1];
        int64_t w = weights[e];

        if (dist[u] != INT64_MAX) {
            int64_t cand = 0;
            if (!safe_add(dist[u], w, &cand)) {
                free(dist);
                return BELLMAN_FORD_INVALID;
            }
            if (cand < dist[v]) {
                free(dist);
                return BELLMAN_FORD_NEGATIVE_CYCLE;
            }
        }
    }

    for (size_t i = 0; i < vertex_count; ++i) {
        out_distances[i] = dist[i];
    }

    free(dist);
    return BELLMAN_FORD_OK;
}

int main(void) {
    int64_t dist[8];

    // 参数校验
    assert(bellman_ford_shortest_paths(3, NULL, NULL, 1, 0, dist) == BELLMAN_FORD_INVALID);

    // 标准负权边收敛图:
    // 0 -> 1 (权 4)
    // 0 -> 2 (权 5)
    // 1 -> 2 (权 -3) -> 使得 0->2 距离优化为 4 + (-3) = 1
    // 2 -> 3 (权 2)  -> 0->3 距离为 1 + 2 = 3
    const size_t e4[4][2] = {
        {0, 1}, {0, 2}, {1, 2}, {2, 3}
    };
    const int64_t w4[4] = {4, 5, -3, 2};

    assert(bellman_ford_shortest_paths(4, e4, w4, 4, 0, dist) == BELLMAN_FORD_OK);
    assert(dist[0] == 0);
    assert(dist[1] == 4);
    assert(dist[2] == 1);
    assert(dist[3] == 3);

    // 负权环测试: 1 -> 2 (权 -5), 2 -> 1 (权 2), 环路权值 -3
    const size_t e_neg[3][2] = {
        {0, 1}, {1, 2}, {2, 1}
    };
    const int64_t w_neg[3] = {1, -5, 2};

    assert(bellman_ford_shortest_paths(3, e_neg, w_neg, 3, 0, dist) == BELLMAN_FORD_NEGATIVE_CYCLE);

    return 0;
}
```

## 复杂度分析

- **时间复杂度**：$O(V \times E)$。外层循环执行 $V$ 轮，每轮遍历全部 $E$ 条有向边。若图提前收敛，实际轮数远小于 $V$。
- **空间复杂度**：$O(V)$。仅维护大小为 $V$ 的距离状态数组。

## 延伸思考 / 模式总结

Bellman-Ford 算法以牺牲运行时间（从对数级退化为 $O(VE)$）为代价，换取了处理负权边与检测负权环的核心能力。它是分布式网络路由协议（如 RIP 距离向量路由算法）的核心理论支柱。
