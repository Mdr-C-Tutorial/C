# 36102 - Kruskal 最小生成树（边排序+并查集判环）

## 题目描述

给定一个包含 $V$ 个顶点的无向连通带权图，求该图的**最小生成树（Minimum Spanning Tree, MST）的边权总和**。

函数签名如下：

```c
#include <stdbool.h>
#include <stddef.h>
#include <stdint.h>

bool kruskal_mst_weight(
    size_t vertex_count,
    const size_t edges[][2],
    const uint64_t *weights,
    size_t edge_count,
    uint64_t *out_mst_weight
);
```

要求：
1. 若图不连通（无法选出 $V - 1$ 条边连接所有顶点），返回 `false` 报告失败，且不修改输出对象。
2. 边权总和发生 64 位无符号整数溢出时返回 `false`。
3. 当 $V \le 1$ 时，生成树权值和为 0，输出 0 并返回 `true`。
4. 算法必须采用 Kruskal 策略：先按边权非递减排序，利用**并查集（Disjoint Set Union, DSU）结合路径压缩**高效判环与合并。

## 解题思路

1. **贪心准则与割性质**：
   Kruskal 算法基于割性质（Cut Property）：在连接两个不同连通分量的所有候选边中，权重最小的那条边必然属于某棵最小生成树。
   因此，算法一开始将所有边按权重从小到大进行全局排序。

2. **并查集维护连通分支**：
   初始化并查集，每个顶点各自独立构成一个集合（`parent[i] = i`）。
   按权重升序扫描每条候选边 $(u, v, w)$：
   - 查询 $u$ 和 $v$ 所在的集合根节点 $root_u = find(u), root_v = find(v)$；
   - 若 $root_u == root_v$：说明 $u$ 和 $v$ 已经通过之前加入的更小权边连通，若再加入此边必然**产生环**，因此必须舍弃（剪枝）；
   - 若 $root_u \neq root_v$：将边 $(u, v)$ 加入最小生成树，累计权重并合并两个集合（`parent[root_u] = root_v`）。

3. **连通性校验**：
   对于包含 $V$ 个顶点的连通图，最小生成树必须恰好包含 $V - 1$ 条边。遍历完所有边后，检查已选中的边数是否等于 $V - 1$。若不足则说明原图不连通。

## C 语言实现

```c
#include <assert.h>
#include <stdbool.h>
#include <stddef.h>
#include <stdint.h>
#include <stdlib.h>

typedef struct {
    size_t u;
    size_t v;
    uint64_t weight;
} UndirectedEdge;

static int compare_edges(const void *a, const void *b) {
    const UndirectedEdge *ea = (const UndirectedEdge *)a;
    const UndirectedEdge *eb = (const UndirectedEdge *)b;
    if (ea->weight < eb->weight) return -1;
    if (ea->weight > eb->weight) return 1;
    return 0;
}

static size_t dsu_find(size_t *parent, size_t x) {
    size_t root = x;
    while (parent[root] != root) {
        root = parent[root];
    }
    // 路径压缩
    while (parent[x] != root) {
        size_t nxt = parent[x];
        parent[x] = root;
        x = nxt;
    }
    return root;
}

bool kruskal_mst_weight(
    size_t vertex_count,
    const size_t edges[][2],
    const uint64_t *weights,
    size_t edge_count,
    uint64_t *out_mst_weight
) {
    if (out_mst_weight == NULL || (edge_count > 0 && (edges == NULL || weights == NULL))) {
        return false;
    }
    if (vertex_count <= 1) {
        *out_mst_weight = 0;
        return true;
    }
    if (edge_count < vertex_count - 1) {
        return false; // 边数不足，必不连通
    }

    UndirectedEdge *edge_list = malloc(edge_count * sizeof(UndirectedEdge));
    size_t *parent = malloc(vertex_count * sizeof(size_t));

    if (edge_list == NULL || parent == NULL) {
        free(edge_list);
        free(parent);
        return false;
    }

    for (size_t i = 0; i < vertex_count; ++i) {
        parent[i] = i;
    }

    for (size_t i = 0; i < edge_count; ++i) {
        size_t u = edges[i][0];
        size_t v = edges[i][1];
        if (u >= vertex_count || v >= vertex_count) {
            free(edge_list);
            free(parent);
            return false;
        }
        edge_list[i].u = u;
        edge_list[i].v = v;
        edge_list[i].weight = weights[i];
    }

    // 边按权重升序排序
    qsort(edge_list, edge_count, sizeof(UndirectedEdge), compare_edges);

    uint64_t total_weight = 0;
    size_t edges_chosen = 0;

    for (size_t i = 0; i < edge_count; ++i) {
        size_t u = edge_list[i].u;
        size_t v = edge_list[i].v;
        uint64_t w = edge_list[i].weight;

        size_t root_u = dsu_find(parent, u);
        size_t root_v = dsu_find(parent, v);

        if (root_u != root_v) {
            parent[root_u] = root_v;
            if (total_weight > UINT64_MAX - w) {
                free(edge_list);
                free(parent);
                return false; // 溢出防护
            }
            total_weight += w;
            edges_chosen++;

            if (edges_chosen == vertex_count - 1) {
                break;
            }
        }
    }

    free(edge_list);
    free(parent);

    if (edges_chosen != vertex_count - 1) {
        return false; // 图不连通
    }

    *out_mst_weight = total_weight;
    return true;
}

int main(void) {
    uint64_t mst_wt = 0;

    // 参数校验
    assert(!kruskal_mst_weight(3, NULL, NULL, 1, &mst_wt));

    // 0 与 1 顶点退化用例
    assert(kruskal_mst_weight(0, NULL, NULL, 0, &mst_wt) && mst_wt == 0);
    assert(kruskal_mst_weight(1, NULL, NULL, 0, &mst_wt) && mst_wt == 0);

    // 标准 4 顶点无向图测试:
    // (0, 1): 1
    // (1, 2): 2
    // (2, 3): 3
    // (0, 3): 4
    // (0, 2): 5
    // MST 选取 (0, 1) [1], (1, 2) [2], (2, 3) [3], 权值和 = 1 + 2 + 3 = 6
    const size_t e4[5][2] = {
        {0, 1}, {1, 2}, {2, 3}, {0, 3}, {0, 2}
    };
    const uint64_t w4[5] = {1, 2, 3, 4, 5};
    assert(kruskal_mst_weight(4, e4, w4, 5, &mst_wt));
    assert(mst_wt == 6);

    // 非连通图测试: 4 个顶点只有边 (0, 1) 和 (2, 3) -> 无法构成生成树
    const size_t e_disconn[2][2] = {{0, 1}, {2, 3}};
    const uint64_t w_disconn[2] = {10, 20};
    assert(!kruskal_mst_weight(4, e_disconn, w_disconn, 2, &mst_wt));

    return 0;
}
```

## 复杂度分析

- **时间复杂度**：$O(E \log E)$。瓶颈在于所有边的快速排序；并查集在路径压缩优化下，每次查询与合并的摊还时间复杂度为反阿克曼函数 $O(\alpha(V)) \approx O(1)$。
- **空间复杂度**：$O(V + E)$。包含排序所需的边结构体数组以及并查集父指针数组。

## 延伸思考 / 模式总结

Kruskal 算法是贪心算法（Greedy Algorithm）在拟阵（Matroid）理论上的经典应用。通过边排序与并查集的精巧配合，算法无需关注图的拓扑层级，非常适合于边稀疏的图结构。
