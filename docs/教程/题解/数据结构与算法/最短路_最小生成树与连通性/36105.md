# 36105 - SPFA 队列优化 Bellman-Ford 算法及 SLF 优化

## 题目

在一个包含 $V$ 个顶点的有向图中（允许存在负权边），实现基于队列优化的 Bellman-Ford 算法（Shortest Path Faster Algorithm, SPFA），计算从源点 `source` 出发的单源最短距离，并在图中存在负权回路时予以精准拦截。

为进一步改善最坏情况下的收敛速度，必须集成 **Small Label First（SLF）双端队列优化**。

函数签名如下：

```c
#include <stdbool.h>
#include <stddef.h>
#include <stdint.h>

typedef enum {
    SPFA_OK,
    SPFA_NEGATIVE_CYCLE,
    SPFA_INVALID
} SpfaResult;

SpfaResult spfa_shortest_paths(
    size_t vertex_count,
    const size_t edges[][2],
    const int64_t *weights,
    size_t edge_count,
    size_t source,
    int64_t *out_distances
);
```

要求：
1. 参数无效或源点越界时返回 `SPFA_INVALID`。
2. 不可达顶点距离用 `INT64_MAX` 表示。
3. 采用循环双端队列（Deque）实现 SLF 优化：新顶点入队时，若其暂定距离小于队首顶点的暂定距离，将其插入队首；否则插入队尾。
4. 记录每个顶点的松弛入队次数，一旦某个顶点的入队次数达到 $V$，立即判定存在从源点可达的负权环，返回 `SPFA_NEGATIVE_CYCLE`。

## 解题思路

1. **SPFA 的核心思想（动态松弛通知）**：
   朴素 Bellman-Ford 算法每轮无差别地遍历所有 $E$ 条边，其中许多未被松弛顶点的出边遍历是完全无效的。
   SPFA 的观察是：**只有自身距离被成功松弛缩短的顶点，其出边才有可能使邻接点的距离进一步缩短**。
   因此，SPFA 用一个队列保存所有“暂定距离刚被更新”的顶点，每次仅取出队列中的顶点来松弛其出边。结合 `in_queue` 布尔数组，确保同一个顶点在队列中至多只存在一份。

2. **SLF 优化（Small Label First）**：
   SLF 是一种基于局部贪心的双端队列优化技巧：
   当顶点 $v$ 满足入队条件时，比较 $dist[v]$ 与当前队首元素 $front$ 的 $dist[front]$：
   - 若 $dist[v] < dist[front]$：说明 $v$ 具有更小的标签（距离更优），更有潜力提前松弛后续节点，因此使用 `push_front` 将其插至队首；
   - 否则：按常规执行 `push_back` 插至队尾。
   这显著平滑了处理顺序，在随机图和网格图上能大幅减少重复入队次数。

3. **负权环判定不变式**：
   在不含负权回路的图中，任意简单最短路径至多经过 $V - 1$ 条边。
   因此，任何一个合法顶点被加入队列的次数至多为 $V - 1$ 次。若某个顶点被松弛入队的计数 `relax_count[v] >= V`，根据抽屉原理，必存在负权回路。

## C 语言实现

```c
#include <assert.h>
#include <stdbool.h>
#include <stddef.h>
#include <stdint.h>
#include <stdlib.h>

typedef enum {
    SPFA_OK,
    SPFA_NEGATIVE_CYCLE,
    SPFA_INVALID
} SpfaResult;

typedef struct EdgeNode EdgeNode;
struct EdgeNode {
    size_t to;
    int64_t weight;
    EdgeNode *next;
};

static bool safe_add(int64_t base, int64_t w, int64_t *res) {
    if (w > 0 && base >= INT64_MAX - w) return false;
    if (w < 0 && base < INT64_MIN - w) return false;
    *res = base + w;
    return true;
}

SpfaResult spfa_shortest_paths(
    size_t vertex_count,
    const size_t edges[][2],
    const int64_t *weights,
    size_t edge_count,
    size_t source,
    int64_t *out_distances
) {
    if (out_distances == NULL || source >= vertex_count ||
        (edge_count > 0 && (edges == NULL || weights == NULL))) {
        return SPFA_INVALID;
    }
    if (vertex_count == 0) {
        return SPFA_OK;
    }

    EdgeNode **adj = calloc(vertex_count, sizeof(EdgeNode*));
    EdgeNode *pool = malloc(edge_count * sizeof(EdgeNode));
    int64_t *dist = malloc(vertex_count * sizeof *dist);
    bool *in_queue = calloc(vertex_count, sizeof *in_queue);
    size_t *relax_count = calloc(vertex_count, sizeof *relax_count);

    // 循环双端队列 (容量为 vertex_count + 1)
    size_t q_cap = vertex_count + 2;
    size_t *deque = malloc(q_cap * sizeof(size_t));

    if (adj == NULL || (edge_count > 0 && pool == NULL) || dist == NULL ||
        in_queue == NULL || relax_count == NULL || deque == NULL) {
        free(adj); free(pool); free(dist); free(in_queue); free(relax_count); free(deque);
        return SPFA_INVALID;
    }

    for (size_t i = 0; i < edge_count; ++i) {
        size_t u = edges[i][0];
        size_t v = edges[i][1];
        if (u >= vertex_count || v >= vertex_count) {
            free(adj); free(pool); free(dist); free(in_queue); free(relax_count); free(deque);
            return SPFA_INVALID;
        }
        pool[i].to = v;
        pool[i].weight = weights[i];
        pool[i].next = adj[u];
        adj[u] = &pool[i];
    }

    for (size_t i = 0; i < vertex_count; ++i) {
        dist[i] = INT64_MAX;
    }

    size_t head = 0;
    size_t tail = 0;
    size_t count = 0;

    dist[source] = 0;
    deque[tail] = source;
    tail = (tail + 1) % q_cap;
    count++;
    in_queue[source] = true;
    relax_count[source] = 1;

    SpfaResult result = SPFA_OK;

    while (count > 0) {
        size_t u = deque[head];
        head = (head + 1) % q_cap;
        count--;
        in_queue[u] = false;

        for (const EdgeNode *e = adj[u]; e != NULL; e = e->next) {
            size_t v = e->to;
            int64_t w = e->weight;
            int64_t cand = 0;

            if (!safe_add(dist[u], w, &cand)) {
                result = SPFA_INVALID;
                break;
            }

            if (cand < dist[v]) {
                dist[v] = cand;

                if (!in_queue[v]) {
                    relax_count[v]++;
                    if (relax_count[v] >= vertex_count) {
                        result = SPFA_NEGATIVE_CYCLE;
                        break;
                    }

                    // SLF 优化插入
                    if (count > 0 && dist[v] < dist[deque[head]]) {
                        head = (head + q_cap - 1) % q_cap;
                        deque[head] = v;
                    } else {
                        deque[tail] = v;
                        tail = (tail + 1) % q_cap;
                    }
                    count++;
                    in_queue[v] = true;
                }
            }
        }

        if (result != SPFA_OK) {
            break;
        }
    }

    if (result == SPFA_OK) {
        for (size_t i = 0; i < vertex_count; ++i) {
            out_distances[i] = dist[i];
        }
    }

    free(adj);
    free(pool);
    free(dist);
    free(in_queue);
    free(relax_count);
    free(deque);
    return result;
}

int main(void) {
    int64_t dist[8];

    // 参数校验
    assert(spfa_shortest_paths(3, NULL, NULL, 1, 0, dist) == SPFA_INVALID);

    // 标准负权边有向图
    // 0 -> 1 (权 4)
    // 0 -> 2 (权 5)
    // 1 -> 2 (权 -3) -> 0 到 2 最短为 4 + (-3) = 1
    // 2 -> 3 (权 2)  -> 0 到 3 最短为 1 + 2 = 3
    const size_t e4[4][2] = {
        {0, 1}, {0, 2}, {1, 2}, {2, 3}
    };
    const int64_t w4[4] = {4, 5, -3, 2};

    assert(spfa_shortest_paths(4, e4, w4, 4, 0, dist) == SPFA_OK);
    assert(dist[0] == 0);
    assert(dist[1] == 4);
    assert(dist[2] == 1);
    assert(dist[3] == 3);

    // 负权回路测试: 1 -> 2 (权 -5), 2 -> 1 (权 2)
    const size_t e_cycle[3][2] = {
        {0, 1}, {1, 2}, {2, 1}
    };
    const int64_t w_cycle[3] = {1, -5, 2};

    assert(spfa_shortest_paths(3, e_cycle, w_cycle, 3, 0, dist) == SPFA_NEGATIVE_CYCLE);

    return 0;
}
```

## 复杂度分析

- **时间复杂度**：在随机稀疏图上平均时间复杂度为 $O(kE)$（其中 $k$ 为常数，通常 $k \le 2$），极具竞争力；最坏情况下（如精心构造的网格图或菊花图）退化为 $O(VE)$。
- **空间复杂度**：$O(V + E)$。邻接表占用 $O(E)$，双端队列与辅助数组占用 $O(V)$。

## 延伸思考 / 模式总结

SPFA 的本质是用队列维护“松弛波前”。结合 SLF（Small Label First）与 LLL（Large Label Last）启发式技术，能使波前始终优先沿着局部最优方向推进，极大减少无效松弛次数。
