# 36107 - 无向图割点（Articulation Points）与桥（Bridges）Tarjan 算法

## 题目

在一个包含 $V$ 个顶点的无向图中：
- **割点（关节点，Articulation Point）**：若在图中删除该顶点及其所有关联的边后，图的连通分量数量增加，则称该顶点为割点。
- **桥（割边，Bridge）**：若在图中删除该边后，图的连通分量数量增加，则称该边为桥。

请使用 **Tarjan 算法（基于 DFS 搜索树的时间戳）**在线性时间内找出无向图中的所有割点与所有桥。

函数签名如下：

```c
#include <stdbool.h>
#include <stddef.h>

bool tarjan_cut_vertices_and_bridges(
    size_t vertex_count,
    const size_t edges[][2],
    size_t edge_count,
    bool *out_is_cut_vertex,
    bool *out_is_bridge
);
```

要求：
1. 图可能包含多个不连通的分量，也可能存在重边。
2. 参数无效时返回 `false`。
3. 必须通过一次深度优先搜索，维护发现时间戳 `dfn[u]` 和追溯值 `low[u]`，时间复杂度为 $O(V + E)$。
4. 准确区分树根节点（至少两棵独立子树）与非根节点（$low[v] \ge dfn[u]$）的割点判定准则。

## 解题思路

1. **DFS 搜索树与时间戳定义**：
   在无向图上运行深度优先搜索，会生成一棵 DFS 搜索树。图中的边被分为两类：
   - **树边（Tree Edge）**：在 DFS 树中连接父子节点的边；
   - **回边（Back Edge）**：连接某个节点与其在树中的某个祖先节点的非树边（无向图不存在横叉边）。
   
   定义两个关键标量：
   - `dfn[u]`：顶点 $u$ 在 DFS 遍历中被访问到的次序号（时间戳）；
   - `low[u]`：顶点 $u$ 及其子树中的顶点，通过**至多一条回边**所能到达的在树中深度最浅的祖先的最小 `dfn`。

2. **割点（Cut Vertex）判定定理**：
   - **若 $u$ 是 DFS 树的根节点**：
     $u$ 是割点当且仅当它在 DFS 树中有**两棵或两棵以上互不连通的子树**（若只有一棵子树，删去根后其余部分依然连通）。
   - **若 $u$ 不是 DFS 树的根节点**：
     $u$ 是割点当且仅当存在 $u$ 的某个直接子节点 $v$，满足：
     $$low[v] \ge dfn[u]$$
     这说明子节点 $v$ 及其子树无论如何也无法绕过父节点 $u$“跨越”连接到 $u$ 之上的祖先节点。一旦删除 $u$，$v$ 所在子树立刻与外部断开连通。

3. **桥（Bridge / 割边）判定定理**：
   对于一条树边 $e = (u, v)$（假设 $u$ 是 $v$ 的父节点）：
   边 $e$ 是桥当且仅当：
   $$low[v] > dfn[u]$$
   注意这里是**严格大于**！如果 $low[v] == dfn[u]$，说明 $v$ 的子树还可以通过另一条回边连回到 $u$，删去边 $(u, v)$ 后 $v$ 仍可通过该回边连到 $u$，因此边不是桥。
   **防止重边误判**：递归向下传递生成当前树边的唯一**边编号（edge id）**，反向扫描时跳过该边编号，而不是单纯根据父节点编号跳过。

## C 语言实现

```c
#include <assert.h>
#include <stdbool.h>
#include <stddef.h>
#include <stdlib.h>

typedef struct EdgeNode EdgeNode;
struct EdgeNode {
    size_t to;
    size_t edge_idx;
    EdgeNode *next;
};

static void tarjan_dfs(
    size_t u,
    size_t parent_edge_idx,
    const EdgeNode * const *adj,
    size_t *dfn,
    size_t *low,
    size_t *timer,
    bool *is_cut_v,
    bool *is_bridge
) {
    dfn[u] = low[u] = ++(*timer);
    size_t children = 0;

    for (const EdgeNode *e = adj[u]; e != NULL; e = e->next) {
        size_t v = e->to;
        size_t e_idx = e->edge_idx;

        if (e_idx == parent_edge_idx) {
            continue; // 沿反向边返回父节点，跳过
        }

        if (dfn[v] > 0) {
            // 回边：更新追溯值
            if (dfn[v] < low[u]) {
                low[u] = dfn[v];
            }
        } else {
            // 树边：递归深入
            children++;
            tarjan_dfs(v, e_idx, adj, dfn, low, timer, is_cut_v, is_bridge);

            if (low[v] < low[u]) {
                low[u] = low[v];
            }

            // 割点判定 (非根节点)
            if (parent_edge_idx != SIZE_MAX && low[v] >= dfn[u]) {
                is_cut_v[u] = true;
            }

            // 桥判定
            if (low[v] > dfn[u]) {
                is_bridge[e_idx] = true;
            }
        }
    }

    // 割点判定 (根节点)
    if (parent_edge_idx == SIZE_MAX && children >= 2) {
        is_cut_v[u] = true;
    }
}

bool tarjan_cut_vertices_and_bridges(
    size_t vertex_count,
    const size_t edges[][2],
    size_t edge_count,
    bool *out_is_cut_vertex,
    bool *out_is_bridge
) {
    if ((vertex_count > 0 && out_is_cut_vertex == NULL) ||
        (edge_count > 0 && (out_is_bridge == NULL || edges == NULL))) {
        return false;
    }
    if (vertex_count == 0) {
        return true;
    }

    EdgeNode **adj = calloc(vertex_count, sizeof(EdgeNode*));
    EdgeNode *pool = malloc(2 * edge_count * sizeof(EdgeNode));
    size_t *dfn = calloc(vertex_count, sizeof(size_t));
    size_t *low = calloc(vertex_count, sizeof(size_t));

    if (adj == NULL || (edge_count > 0 && pool == NULL) || dfn == NULL || low == NULL) {
        free(adj); free(pool); free(dfn); free(low);
        return false;
    }

    size_t pool_idx = 0;
    for (size_t i = 0; i < edge_count; ++i) {
        size_t u = edges[i][0];
        size_t v = edges[i][1];
        if (u >= vertex_count || v >= vertex_count) {
            free(adj); free(pool); free(dfn); free(low);
            return false;
        }

        pool[pool_idx].to = v;
        pool[pool_idx].edge_idx = i;
        pool[pool_idx].next = adj[u];
        adj[u] = &pool[pool_idx++];

        pool[pool_idx].to = u;
        pool[pool_idx].edge_idx = i;
        pool[pool_idx].next = adj[v];
        adj[v] = &pool[pool_idx++];

        out_is_bridge[i] = false;
    }

    for (size_t i = 0; i < vertex_count; ++i) {
        out_is_cut_vertex[i] = false;
    }

    size_t timer = 0;
    for (size_t i = 0; i < vertex_count; ++i) {
        if (dfn[i] == 0) {
            tarjan_dfs(i, SIZE_MAX, (const EdgeNode * const *)adj,
                       dfn, low, &timer, out_is_cut_vertex, out_is_bridge);
        }
    }

    free(adj);
    free(pool);
    free(dfn);
    free(low);
    return true;
}

int main(void) {
    bool is_cut[8];
    bool is_bridge[8];

    // 哑铃图测试:
    // 三角形 A: 0 - 1 - 2 - 0
    // 桥边: 2 - 3 (活动 3)
    // 三角形 B: 3 - 4 - 5 - 3
    // 割点应为 2 和 3；桥应为边 (2, 3)
    const size_t e7[7][2] = {
        {0, 1}, {1, 2}, {2, 0}, // 三角形 A
        {2, 3},                 // 桥边 (编号 3)
        {3, 4}, {4, 5}, {5, 3}  // 三角形 B
    };

    assert(tarjan_cut_vertices_and_bridges(6, e7, 7, is_cut, is_bridge));

    // 校验割点
    assert(is_cut[2] == true);
    assert(is_cut[3] == true);
    assert(is_cut[0] == false && is_cut[1] == false && is_cut[4] == false);

    // 校验桥
    assert(is_bridge[3] == true);
    assert(is_bridge[0] == false && is_bridge[1] == false && is_bridge[2] == false);
    assert(is_bridge[4] == false && is_bridge[5] == false && is_bridge[6] == false);

    return 0;
}
```

## 复杂度分析

- **时间复杂度**：$O(V + E)$。每个顶点与每条无向边在深度优先搜索中仅被访问常数次。
- **空间复杂度**：$O(V + E)$。包含邻接表分配、时间戳数组与递归调用栈。

## 延伸思考 / 模式总结

Tarjan 割点与桥算法充分展现了深度优先搜索生成树的强大威力。通过维护子树所能追溯到的最浅祖先（`low`），将全局的“断连检验”巧妙转化为局部的“祖先深度比较”，成为求解双连通分量（点双与边双）的核心构件。
