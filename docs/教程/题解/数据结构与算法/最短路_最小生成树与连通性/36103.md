# 36103：Bellman–Ford 单源最短路与可达负权环检测

## 题目

在允许负权有向边的图上实现 Bellman–Ford 算法，求从 `source` 出发的单源最短距离（不可达顶点记为 `INT64_MAX`），并在存在从 `source` 可达的负权环时返回 `BELLMAN_FORD_NEGATIVE_CYCLE`。

## 解析

1. **为什么 $V - 1$ 轮松弛足以收敛最短简单路径**：在不含可达负权环的图中，从源点 $s$ 到任意可达顶点 $v$ 的最短路径必然可以取为一条不含重复顶点的**简单路径**。由于图中仅有 $V$ 个顶点，任何简单路径至多包含 $V - 1$ 条边。记第 $k$ 轮全边松弛前的距离数组满足不变式：所有边数不超过 $k$ 的最短路径长度均已精确收敛；则经过 $V - 1$ 轮全边松弛后，所有简单最短路径均已收敛到最终最短距离。若某一轮未发生任何更新，可提前跳出循环。
2. **第 $V$ 轮检测可达负权环**：在完成前 $V - 1$ 轮松弛后，执行第 $V$ 轮（下标 `round == vertex_count - 1`）扫描。若某条满足 `distance[u] != INT64_MAX` 的边 $(u, v, w)$ 依然能够使 `distance[u] + w < distance[v]`，说明存在从 `source` 可达且边数达到 $V$ 的更短路径，由抽屉原理该路径必含负权环。由于只有 `distance[u] != INT64_MAX` 的顶点才参与松弛，从 `source` 不可达的连通分量中的负权环永远不会被激活，从而避免误报。
3. **有符号加法防溢出**：C 语言中有符号整数溢出属于未定义行为，且 `INT64_MAX` 已被用作不可达哨兵，因此合法有限距离必须落在 `[INT64_MIN, INT64_MAX - 1]` 内。计算 `distance[u] + w` 前：
   - 若 `w > 0 && distance[u] >= INT64_MAX - w`，则结果会溢出或碰撞 `INT64_MAX` 哨兵；
   - 若 `w < 0 && distance[u] < INT64_MIN - w`，则结果会发生有符号下溢。
   一旦触发上述任一情况，立即释放临时数组并返回 `BELLMAN_FORD_INVALID`。

## 答案

```c
#include <stdbool.h>
#include <stddef.h>
#include <stdint.h>
#include <stdlib.h>
#include <string.h>

typedef struct {
    size_t from;
    size_t to;
    int64_t weight;
} SignedWeightedEdge;

typedef enum {
    BELLMAN_FORD_OK,
    BELLMAN_FORD_INVALID,
    BELLMAN_FORD_NEGATIVE_CYCLE
} BellmanFordResult;

static bool checked_relax_sum(
    int64_t base,
    int64_t weight,
    int64_t *out_candidate
) {
    if (weight > 0 && base >= INT64_MAX - weight) {
        return false;
    }
    if (weight < 0 && base < INT64_MIN - weight) {
        return false;
    }
    *out_candidate = base + weight;
    return true;
}

BellmanFordResult bellman_ford_distances(
    size_t vertex_count,
    const SignedWeightedEdge *edges,
    size_t edge_count,
    size_t source,
    int64_t *out_distances
) {
    if (vertex_count == 0 || source >= vertex_count ||
        out_distances == NULL ||
        (edge_count > 0 && edges == NULL) ||
        vertex_count > SIZE_MAX / sizeof(int64_t)) {
        return BELLMAN_FORD_INVALID;
    }
    for (size_t i = 0; i < edge_count; ++i) {
        if (edges[i].from >= vertex_count ||
            edges[i].to >= vertex_count) {
            return BELLMAN_FORD_INVALID;
        }
    }

    int64_t *distance = malloc(vertex_count * sizeof *distance);
    if (distance == NULL) {
        return BELLMAN_FORD_INVALID;
    }
    for (size_t i = 0; i < vertex_count; ++i) {
        distance[i] = INT64_MAX;
    }
    distance[source] = 0;

    for (size_t round = 0; round < vertex_count; ++round) {
        bool updated = false;
        for (size_t i = 0; i < edge_count; ++i) {
            size_t u = edges[i].from;
            size_t v = edges[i].to;
            int64_t w = edges[i].weight;
            if (distance[u] == INT64_MAX) {
                continue;
            }
            int64_t candidate = 0;
            if (!checked_relax_sum(distance[u], w, &candidate)) {
                free(distance);
                return BELLMAN_FORD_INVALID;
            }
            if (candidate < distance[v]) {
                if (round == vertex_count - 1) {
                    free(distance);
                    return BELLMAN_FORD_NEGATIVE_CYCLE;
                }
                distance[v] = candidate;
                updated = true;
            }
        }
        if (!updated) {
            break;
        }
    }

    memcpy(
        out_distances,
        distance,
        vertex_count * sizeof *out_distances
    );
    free(distance);
    return BELLMAN_FORD_OK;
}
```

算法至多执行 $V$ 轮全边扫描，每轮检查 $E$ 条边，最坏时间复杂度为 $O(VE)$；仅维护一份长度为 $V$ 的临时距离数组，额外空间复杂度为 $O(V)$。
