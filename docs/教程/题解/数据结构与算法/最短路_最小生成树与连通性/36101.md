# 36101 - Dijkstra 单源最短路（小顶堆优化，非负权图）

## 题目描述

在一个包含 $V$ 个顶点的非负权有向图上，使用最小二叉堆（优先队列）优化的 Dijkstra 算法，计算从指定的源点 `source` 到所有其他顶点的**最短单源距离**。

函数签名如下：

```c
#include <stdbool.h>
#include <stddef.h>
#include <stdint.h>

bool dijkstra_shortest_paths(
    size_t vertex_count,
    const size_t edges[][2],
    const uint64_t *weights,
    size_t edge_count,
    size_t source,
    uint64_t *out_distances
);
```

要求：
1. 边权必须为非负整数。若不可达，对应的最短距离用 `UINT64_MAX` 表示；源点自身的最短距离为 0。
2. 参数无效或源点越界时返回 `false`。
3. 必须采用**小顶堆**优先队列维护候选顶点距离，时间复杂度必须达到 $O((V + E) \log V)$。
4. 正确处理堆中包含同一顶点的多次松弛条目（惰性删除：当弹出条目的距离大于已知最优距离时直接丢弃）。

## 解题思路

1. **贪心选择性质与非负权前提**：
   Dijkstra 算法基于贪心策略：在每一轮中，当前未确定集合中距源点最近的顶点 $u$，其当前暂定距离必然就是全局最短距离。
   **注意**：这一贪心策略严格依赖于**图中的所有边权非负**。若存在负权边，经由后续负权边可能使某条更长路径的权值变小，导致贪心前提崩溃。

2. **最小二叉堆优先队列设计**：
   二叉堆中存放 `(distance, vertex)` 结构体，按 `distance` 升序排列。
   - 源点以距离 0 入堆；
   - 每次从堆顶取出距离最小的元素 $(d, u)$：
     若 $d > dist[u]$，说明这是一个被后续更优路径替代的**过期旧条目**，直接跳过（惰性删除）；
     否则，$dist[u] = d$ 正式确立为最短距离；
   - 遍历 $u$ 的所有出边 $(u, v, w)$：
     若 $dist[u] + w < dist[v]$（注意防止 64 位无符号加法溢出），则更新 $dist[v] = dist[u] + w$，并将新条目 $(dist[v], v)$ 推入二叉堆。

## C 语言实现

```c
#include <assert.h>
#include <stdbool.h>
#include <stddef.h>
#include <stdint.h>
#include <stdlib.h>

typedef struct {
    uint64_t dist;
    size_t u;
} HeapNode;

typedef struct {
    HeapNode *data;
    size_t size;
    size_t capacity;
} MinHeap;

static void heap_swap(HeapNode *a, HeapNode *b) {
    HeapNode tmp = *a;
    *a = *b;
    *b = tmp;
}

static void heap_push(MinHeap *h, uint64_t dist, size_t u) {
    size_t i = h->size++;
    h->data[i] = (HeapNode){dist, u};
    while (i > 0) {
        size_t p = (i - 1) / 2;
        if (h->data[i].dist < h->data[p].dist) {
            heap_swap(&h->data[i], &h->data[p]);
            i = p;
        } else {
            break;
        }
    }
}

static HeapNode heap_pop(MinHeap *h) {
    HeapNode min_item = h->data[0];
    h->data[0] = h->data[--h->size];
    size_t i = 0;
    while (2 * i + 1 < h->size) {
        size_t left = 2 * i + 1;
        size_t right = 2 * i + 2;
        size_t best = left;
        if (right < h->size && h->data[right].dist < h->data[left].dist) {
            best = right;
        }
        if (h->data[best].dist < h->data[i].dist) {
            heap_swap(&h->data[i], &h->data[best]);
            i = best;
        } else {
            break;
        }
    }
    return min_item;
}

typedef struct EdgeNode EdgeNode;
struct EdgeNode {
    size_t to;
    uint64_t weight;
    EdgeNode *next;
};

bool dijkstra_shortest_paths(
    size_t vertex_count,
    const size_t edges[][2],
    const uint64_t *weights,
    size_t edge_count,
    size_t source,
    uint64_t *out_distances
) {
    if (out_distances == NULL || source >= vertex_count ||
        (edge_count > 0 && (edges == NULL || weights == NULL))) {
        return false;
    }

    if (vertex_count == 0) {
        return true;
    }

    EdgeNode **adj = calloc(vertex_count, sizeof(EdgeNode*));
    EdgeNode *pool = malloc(edge_count * sizeof(EdgeNode));
    MinHeap heap = {
        .data = malloc((edge_count + 1) * sizeof(HeapNode)),
        .size = 0,
        .capacity = edge_count + 1
    };

    if (adj == NULL || (edge_count > 0 && pool == NULL) || heap.data == NULL) {
        free(adj); free(pool); free(heap.data);
        return false;
    }

    // 建图
    for (size_t i = 0; i < edge_count; ++i) {
        size_t u = edges[i][0];
        size_t v = edges[i][1];
        if (u >= vertex_count || v >= vertex_count) {
            free(adj); free(pool); free(heap.data);
            return false;
        }
        pool[i].to = v;
        pool[i].weight = weights[i];
        pool[i].next = adj[u];
        adj[u] = &pool[i];
    }

    for (size_t i = 0; i < vertex_count; ++i) {
        out_distances[i] = UINT64_MAX;
    }

    out_distances[source] = 0;
    heap_push(&heap, 0, source);

    while (heap.size > 0) {
        HeapNode top = heap_pop(&heap);
        uint64_t d = top.dist;
        size_t u = top.u;

        if (d > out_distances[u]) {
            continue; // 惰性丢弃过期旧记录
        }

        for (const EdgeNode *e = adj[u]; e != NULL; e = e->next) {
            size_t v = e->to;
            uint64_t w = e->weight;
            if (out_distances[u] <= UINT64_MAX - w) {
                uint64_t cand = out_distances[u] + w;
                if (cand < out_distances[v]) {
                    out_distances[v] = cand;
                    heap_push(&heap, cand, v);
                }
            }
        }
    }

    free(adj);
    free(pool);
    free(heap.data);
    return true;
}

int main(void) {
    uint64_t dist[8];

    // 参数校验
    assert(!dijkstra_shortest_paths(3, NULL, NULL, 1, 0, dist));
    assert(!dijkstra_shortest_paths(3, (const size_t[][2]){{0, 1}}, (const uint64_t[]){10}, 1, 5, dist));

    // 经典带权有向图测试:
    // 0 -> 1 (权 4)
    // 0 -> 2 (权 2)
    // 2 -> 1 (权 1)  (更优路径: 0->2->1 距离 3)
    // 1 -> 3 (权 5)
    // 2 -> 3 (权 8)
    // 3 -> 4 (权 6)
    // 顶点 5 孤立不可达
    const size_t edges[6][2] = {
        {0, 1}, {0, 2}, {2, 1}, {1, 3}, {2, 3}, {3, 4}
    };
    const uint64_t weights[6] = {
        4, 2, 1, 5, 8, 6
    };

    assert(dijkstra_shortest_paths(6, edges, weights, 6, 0, dist));
    assert(dist[0] == 0);
    assert(dist[1] == 3); // 0 -> 2 -> 1
    assert(dist[2] == 2);
    assert(dist[3] == 8); // 0 -> 2 -> 1 -> 3 (3 + 5 = 8)
    assert(dist[4] == 14); // 8 + 6 = 14
    assert(dist[5] == UINT64_MAX); // 不可达

    return 0;
}
```

## 复杂度分析

- **时间复杂度**：$O((V + E) \log V)$。二叉堆中的元素个数最多为 $E$，每次堆插入与弹出耗时 $O(\log E) = O(\log V)$，每个顶点只在其最优距离被确立时展开一次。
- **空间复杂度**：$O(V + E)$。邻接表占用 $O(E)$，二叉堆与距离数组占用 $O(V + E)$ 辅助内存。

## 延伸思考 / 模式总结

Dijkstra 算法是广度优先搜索在非负带权图上的自然推广。通过优先队列将 BFS 的“按跳数扩展”提升为“按累积权值扩展”，确立了最短路问题贪心松弛的标准框架。
