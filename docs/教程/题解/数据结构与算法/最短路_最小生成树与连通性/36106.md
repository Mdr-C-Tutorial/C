# 36106 - Floyd-Warshall 全源最短路算法与状态压缩三维递推

## 题目描述

在一个包含 $V$ 个顶点的有向带权图中（边权可正可负），计算**所有顶点对之间（All-Pairs）的最短距离**。

若图中存在负权回路，算法必须能够准确检测出负权环的存在。

函数签名如下：

```c
#include <stdbool.h>
#include <stddef.h>
#include <stdint.h>

bool floyd_warshall_all_pairs(
    size_t vertex_count,
    const size_t edges[][2],
    const int64_t *weights,
    size_t edge_count,
    int64_t *out_matrix,
    bool *out_has_negative_cycle
);
```

要求：
1. 结果矩阵以行优先方式展平存储在 `out_matrix` 中（大小为 $V \times V$）。
2. 若顶点 $i$ 与 $j$ 之间不可达，距离设为 `INT64_MAX`；对于任意 $i$，自身到自身的初始距离为 0。
3. 参数无效或内存分配失败时返回 `false`。
4. 必须采用三维到二维的原地状态压缩，外层循环严格按照允许使用的**中间松弛顶点 $k$** 进行递推。
5. 遍历结束后，通过检查对角线元素（是否存在某个 $i$ 使得 $dist[i][i] < 0$）判定负权环。

## 解题思路

1. **三维动态规划状态定义**：
   设 $d^{(k)}[i][j]$ 表示从顶点 $i$ 到顶点 $j$，且**所有中间顶点编号均取自集合 $\{0, 1, \dots, k\}$** 时的最短路径长度。
   
   考虑中间点 $k$ 是否在最优路径中：
   - 最优路径不经过顶点 $k$：$d^{(k)}[i][j] = d^{(k - 1)}[i][j]$；
   - 最优路径经过顶点 $k$：路径可拆分为从 $i$ 到 $k$ 再从 $k$ 到 $j$ 的两段，代价为 $d^{(k - 1)}[i][k] + d^{(k - 1)}[k][j]$。
   状态转移方程为：
   $$d^{(k)}[i][j] = \min(d^{(k - 1)}[i][j], \; d^{(k - 1)}[i][k] + d^{(k - 1)}[k][j])$$

2. **原地二维状态压缩**：
   在计算第 $k$ 层状态时，转移项中的 $d^{(k - 1)}[i][k]$ 和 $d^{(k - 1)}[k][j]$ 自身的中间点集合不包含 $k$，即使在原地覆盖更新中，同一行与同一列的数据也不会在当前轮发生自相冲突。
   因此，可以直接在同一个二维数组 `dist[i][j]` 上原地迭代，空间复杂度从 $O(V^3)$ 降至 $O(V^2)$。
   **循环层次非常关键**：必须是 $k$ 在最外层，$i$ 和 $j$ 在内层！

3. **负权回路检测**：
   在不含负权回路的图中，任何简单路径都不可能使 $dist[i][i] < 0$（自环距离始终保持 0）。
   当全部 $V$ 轮松弛结束后，若存在某个顶点 $i$ 满足 $dist[i][i] < 0$，说明存在一条从 $i$ 出发回到 $i$ 且权值和为负的回路，即检测到负权环。

## C 语言实现

```c
#include <assert.h>
#include <stdbool.h>
#include <stddef.h>
#include <stdint.h>
#include <stdlib.h>

static bool safe_add(int64_t a, int64_t b, int64_t *res) {
    if (b > 0 && a >= INT64_MAX - b) return false;
    if (b < 0 && a < INT64_MIN - b) return false;
    *res = a + b;
    return true;
}

bool floyd_warshall_all_pairs(
    size_t vertex_count,
    const size_t edges[][2],
    const int64_t *weights,
    size_t edge_count,
    int64_t *out_matrix,
    bool *out_has_negative_cycle
) {
    if (out_matrix == NULL || out_has_negative_cycle == NULL ||
        (edge_count > 0 && (edges == NULL || weights == NULL))) {
        return false;
    }
    if (vertex_count == 0) {
        *out_has_negative_cycle = false;
        return true;
    }

    if (vertex_count > SIZE_MAX / vertex_count) {
        return false;
    }

    // 初始化全源距离矩阵
    for (size_t i = 0; i < vertex_count; ++i) {
        for (size_t j = 0; j < vertex_count; ++j) {
            out_matrix[i * vertex_count + j] = (i == j) ? 0 : INT64_MAX;
        }
    }

    // 录入直连边 (注意处理两点间可能存在的多重边，保留最小权值)
    for (size_t e = 0; e < edge_count; ++e) {
        size_t u = edges[e][0];
        size_t v = edges[e][1];
        int64_t w = weights[e];

        if (u >= vertex_count || v >= vertex_count) {
            return false;
        }

        size_t idx = u * vertex_count + v;
        if (w < out_matrix[idx]) {
            out_matrix[idx] = w;
        }
    }

    // Floyd-Warshall 核心三重循环
    // 必须 k 在最外层！
    for (size_t k = 0; k < vertex_count; ++k) {
        for (size_t i = 0; i < vertex_count; ++i) {
            int64_t ik = out_matrix[i * vertex_count + k];
            if (ik == INT64_MAX) {
                continue; // i 到 k 不可达，无需松弛
            }

            for (size_t j = 0; j < vertex_count; ++j) {
                int64_t kj = out_matrix[k * vertex_count + j];
                if (kj == INT64_MAX) {
                    continue; // k 到 j 不可达
                }

                int64_t cand = 0;
                if (!safe_add(ik, kj, &cand)) {
                    return false; // 算术溢出
                }

                if (cand < out_matrix[i * vertex_count + j]) {
                    out_matrix[i * vertex_count + j] = cand;
                }
            }
        }
    }

    // 检测负权环
    bool has_cycle = false;
    for (size_t i = 0; i < vertex_count; ++i) {
        if (out_matrix[i * vertex_count + i] < 0) {
            has_cycle = true;
            break;
        }
    }

    *out_has_negative_cycle = has_cycle;
    return true;
}

int main(void) {
    int64_t mat[16];
    bool has_cycle = false;

    // 参数校验
    assert(!floyd_warshall_all_pairs(3, NULL, NULL, 1, mat, &has_cycle));

    // 经典 4 顶点图
    // 0 -> 2 (权 -2)
    // 1 -> 0 (权 4), 1 -> 2 (权 3)
    // 2 -> 3 (权 2)
    // 3 -> 1 (权 -1)
    const size_t e4[5][2] = {
        {0, 2}, {1, 0}, {1, 2}, {2, 3}, {3, 1}
    };
    const int64_t w4[5] = {-2, 4, 3, 2, -1};

    assert(floyd_warshall_all_pairs(4, e4, w4, 5, mat, &has_cycle));
    assert(!has_cycle);

    // 验证各对距离
    // 0 到 1: 0 -> 2 -> 3 -> 1, 权值 = -2 + 2 + (-1) = -1
    assert(mat[0 * 4 + 1] == -1);
    // 0 到 3: 0 -> 2 -> 3, 权值 = -2 + 2 = 0
    assert(mat[0 * 4 + 3] == 0);
    // 3 到 0: 3 -> 1 -> 0, 权值 = -1 + 4 = 3
    assert(mat[3 * 4 + 0] == 3);

    // 负权环测试: 0 -> 1 (权 1), 1 -> 2 (权 -5), 2 -> 0 (权 2) -> 环路 -2
    const size_t e_neg[3][2] = {
        {0, 1}, {1, 2}, {2, 0}
    };
    const int64_t w_neg[3] = {1, -5, 2};

    assert(floyd_warshall_all_pairs(3, e_neg, w_neg, 3, mat, &has_cycle));
    assert(has_cycle);

    return 0;
}
```

## 复杂度分析

- **时间复杂度**：严格 $O(V^3)$。三重嵌套循环，每重循环执行 $V$ 次，与边的数量无直接关系，非常适合稠密图的全源最短路计算。
- **空间复杂度**：$O(V^2)$。通过原地压缩仅需维护一个大小为 $V \times V$ 的二维距离矩阵。

## 延伸思考 / 模式总结

Floyd-Warshall 是区间/子集动态规划的精妙体现。它的子问题划分不是基于“走过多少步”，而是基于“允许使用的中继顶点子集规模”。该算法结构极其规整，在现代硬件上极易向量化（SIMD）与并行化。
