# 35306 - 二进制计数器自增的势能函数设计与摊还复杂度分析

## 题目

$k$ 位二进制计数器自增的势能函数设计与摊还复杂度分析：

考虑一个 $k$ 位二进制数组 $A[0..k-1]$，初值为全 0。每次自增操作由低位向高位扫描，将连续的 1 翻转为 0，直到遇到首个 0 将其翻转为 1（若全部为 1 则溢出）：

```c
#include <stdbool.h>
#include <stddef.h>
#include <stdint.h>

typedef struct BinaryCounter BinaryCounter;

bool counter_init(BinaryCounter *c, size_t k);
void counter_free(BinaryCounter *c);
bool counter_increment(BinaryCounter *c);
```

要求：

1. 定义状态势能函数 $\Phi(A_i)$ 为计数器中数值为 1 的比特位数 $b_i$；
2. 证明连续执行 $n$ 次 `counter_increment` 的总比特翻转次数满足 $\sum c_i < 2n$；
3. 严格计算单次自增操作的摊还代价 $\hat{c}_i = c_i + \Phi(A_i) - \Phi(A_{i-1})$，证明其为常数 $\Theta(1)$；
4. 编写 C 语言实现并用断言统计检验实际翻转总次数上界。

## 解题思路

### 1. 实际操作代价与聚合分析

在 $k$ 位二进制计数器自增过程中：
- 最低位 $A[0]$ 在每一次自增时都会翻转，执行 $n$ 次自增共翻转 $n$ 次；
- 次低位 $A[1]$ 每 2 次自增翻转一次，执行 $n$ 次自增共翻转 $\lfloor n / 2 \rfloor$ 次；
- 一般地，第 $j$ 位比特 $A[j]$ 每 $2^j$ 次自增翻转一次，执行 $n$ 次自增共翻转 $\lfloor n / 2^j \rfloor$ 次。

因此，$n$ 次连续自增操作引起的总比特翻转次数为：

$$\sum_{i=1}^{n} c_i = \sum_{j=0}^{k-1} \left\lfloor \frac{n}{2^j} \right\rfloor < n \sum_{j=0}^{\infty} \left(\frac{1}{2}\right)^j = n \cdot \frac{1}{1 - 1/2} = 2n$$

由此直接导出：$n$ 次操作的总时间为 $O(n)$，单次操作的平摊翻转次数严格小于 $2$。

### 2. 势能法（Potential Method）形式化推导

定义第 $i$ 次操作后计数器的状态为 $A_i$。定义势能函数 $\Phi(A_i)$ 为当前计数器中值为 1 的比特数：

$$\Phi(A_i) = b_i \ge 0$$

初始状态 $A_0$ 为全 0，故 $\Phi(A_0) = 0$。由于对任意状态均有 $\Phi(A_i) \ge 0$，$\Phi$ 为合法势能函数。

设第 $i$ 次自增操作将连续的 $t_i$ 个 1 翻转为了 0，并将紧随其后的第 1 个 0 翻转为了 1（若未溢出）：
- **实际代价**：翻转了 $t_i$ 个 1 和 1 个 0，故实际翻转次数为：
  $$c_i = t_i + 1$$
- **势能变化**：1 的个数减少了 $t_i$ 个，增加了 1 个，故操作后的 1 总数为 $b_i = b_{i-1} - t_i + 1$。势能变化量为：
  $$\Delta \Phi = \Phi(A_i) - \Phi(A_{i-1}) = b_i - b_{i-1} = 1 - t_i$$
- **摊还代价**：
  $$\hat{c}_i = c_i + \Delta \Phi = (t_i + 1) + (1 - t_i) = 2$$

计算表明，单次自增操作的摊还代价恒等于常数 $2 = \Theta(1)$！高昂的级联进位翻转（$t_i$ 很大时）由于大幅降低了计数器内部的势能（释放了先前积累的 1），其实际开销被势能释放完美抵消。

## C 语言实现

```c
#include <assert.h>
#include <stdbool.h>
#include <stddef.h>
#include <stdint.h>
#include <stdio.h>
#include <stdlib.h>

typedef struct BinaryCounter {
    uint8_t *bits;
    size_t k;
    size_t total_flips;
} BinaryCounter;

bool counter_init(BinaryCounter *c, size_t k) {
    if (c == NULL || k == 0) {
        return false;
    }
    c->bits = calloc(k, sizeof(uint8_t));
    if (c->bits == NULL) {
        return false;
    }
    c->k = k;
    c->total_flips = 0;
    return true;
}

void counter_free(BinaryCounter *c) {
    if (c != NULL) {
        free(c->bits);
        c->bits = NULL;
        c->k = 0;
    }
}

bool counter_increment(BinaryCounter *c) {
    if (c == NULL) {
        return false;
    }
    size_t i = 0;
    while (i < c->k && c->bits[i] == 1) {
        c->bits[i] = 0;
        c->total_flips++;
        i++;
    }
    if (i < c->k) {
        c->bits[i] = 1;
        c->total_flips++;
        return true;
    }
    return false; /* 计数器所有位均为 1 时产生上溢 */
}

int main(void) {
    BinaryCounter c;
    assert(counter_init(&c, 16));

    const size_t n = 1000;
    for (size_t i = 0; i < n; ++i) {
        assert(counter_increment(&c));
    }

    /* 形式化定理断言：n 次操作总翻转次数严格小于 2n */
    assert(c.total_flips < 2 * n);

    /* 验证当前计数器中 1 的个数 */
    size_t ones = 0;
    for (size_t i = 0; i < c.k; ++i) {
        if (c.bits[i] == 1) {
            ones++;
        }
    }
    /* 势能求和恒等式检验：Total Flips = 2 * n - ones */
    assert(c.total_flips == 2 * n - ones);

    counter_free(&c);
    printf("Binary counter amortized tests passed: total flips = %zu (< %zu)\n", c.total_flips, 2 * n);
    return 0;
}
```

## 复杂度分析

- **单步最坏时间复杂度**：$O(k)$（当全为 1 时全部翻转）。
- **摊还时间复杂度**：$\Theta(1)$。每次自增摊还代价为 2。
- **空间复杂度**：$\Theta(k)$。维护 $k$ 个二进制位对象。

## 延伸思考 / 模式总结

二进制计数器是展示势能法威力的经典范例。通过将每个数值为 1 的比特视为持有 1 单位“势能水滴”，每次将 0 置为 1 时存入 1 单位势能（平摊花费 2：1 用于翻转本身，1 用于存入势能）；未来当它被清零时，动用该势能支付翻转开销。这一模式在红黑树重新着色、斐波那契堆级联剪枝等高级数据结构中被广泛沿用。
