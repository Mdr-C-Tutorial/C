# 35303：双栈实现先进先出队列与势能法摊还分析

## 题目

使用两个动态数组栈（输入栈 `in_stack` 与输出栈 `out_stack`）实现先进先出（FIFO）整数队列 `TwoStackQueue`，接口如下：

```c
#include <stdbool.h>
#include <stddef.h>
#include <stdint.h>

typedef struct TwoStackQueue TwoStackQueue;

TwoStackQueue *ts_queue_create(size_t initial_capacity);
void ts_queue_destroy(TwoStackQueue *q);

bool ts_queue_enqueue(TwoStackQueue *q, int64_t value);
bool ts_queue_dequeue(TwoStackQueue *q, int64_t *out_value);
bool ts_queue_peek(const TwoStackQueue *q, int64_t *out_value);
size_t ts_queue_size(const TwoStackQueue *q);
```

## 解析

### 1. 双栈模拟队列的 FIFO 原理

栈是后进先出（LIFO）结构。当我们将元素依次压入输入栈 `in_stack` 时，最先入队的元素位于 `in_stack` 栈底，最后入队的元素位于 `in_stack` 栈顶。当需要出队或查看队首而输出栈 `out_stack` 为空时，将 `in_stack` 中的所有元素依次弹出并压入 `out_stack`。经过两次 LIFO 反转后，元素的先后顺序恢复为最初入队的 FIFO 顺序——最早入队的元素恰好位于 `out_stack` 的栈顶，此后可直接以 $O(1)$ 时间弹出或读取，直到 `out_stack` 再次变空。

### 2. 势能法证明每个操作的摊还时间复杂度为 $O(1)$

将单次基础栈操作（压栈 `push` 或弹栈 `pop`，由本节正文 6.1 已知动态数组倍增扩容下每次压栈的摊还代价为常数 $O(1)$，这里将其计为 $1$ 个基本时间单位）作为实际代价 $c_i$ 的度量基准。

定义队列在完成第 $i$ 次操作后的状态为 $D_i$，并定义**势能函数** $\Phi(D_i)$ 为当前输入栈 `in_stack` 中的元素个数：

$$\Phi(D_i) = \text{size}(\text{in\_stack}_i)$$

显然，初始空队列状态 $D_0$ 满足 $\Phi(D_0) = 0$，且在任意时刻 $i$ 均有 $\Phi(D_i) \ge 0$，因此 $\Phi$ 是合法的势能函数。

下面分别计算三种队列操作的摊还代价 $\hat{c}_i = c_i + \Phi(D_i) - \Phi(D_{i-1})$：

1. **入队操作 `ts_queue_enqueue`**：
   - 将新元素压入 `in_stack`，执行 $1$ 次压栈操作，实际代价 $c_i = 1$；
   - `in_stack` 的元素个数增加 $1$，势能变化量 $\Delta \Phi = \Phi(D_i) - \Phi(D_{i-1}) = (k + 1) - k = 1$；
   - 因此摊还代价为：
     $$\hat{c}_i = c_i + \Delta \Phi = 1 + 1 = 2 = O(1)$$

2. **出队操作 `ts_queue_dequeue`**：
   设操作前 `in_stack` 中有 $k$ 个元素（即 $\Phi(D_{i-1}) = k$），分两种情况讨论：
   - **情况 A（`out_stack` 非空）**：直接从 `out_stack` 弹出栈顶元素，实际代价 $c_i = 1$；`in_stack` 未发生改变，$\Delta \Phi = 0$。故摊还代价为：
     $$\hat{c}_i = 1 + 0 = 1 = O(1)$$
   - **情况 B（`out_stack` 为空，且 $k > 0$）**：需要将 `in_stack` 中的 $k$ 个元素逐一弹出（$k$ 次 `pop`）并压入 `out_stack`（$k$ 次 `push`），最后从 `out_stack` 弹出队首元素（$1$ 次 `pop`），实际代价高达 $c_i = 2k + 1$。但与此同时，`in_stack` 被完全清空，操作后 $\Phi(D_i) = 0$，势能变化量为 $\Delta \Phi = 0 - k = -k$（若定义势能系数为 $2$，即 $\Phi(D_i) = 2 \cdot \text{size}(\text{in\_stack}_i)$，则 $\Delta \Phi = -2k$）。
     若取 $\Phi(D_i) = 2 \cdot \text{size}(\text{in\_stack}_i)$：
     - `enqueue` 的摊还代价为 $\hat{c}_i = 1 + 2 = 3 = O(1)$；
     - `dequeue`（情况 A）的摊还代价为 $\hat{c}_i = 1 + 0 = 1 = O(1)$；
     - `dequeue`（情况 B）的摊还代价为：
       $$\hat{c}_i = (2k + 1) + (0 - 2k) = 1 = O(1)$$

3. **队首查询 `ts_queue_peek`**：
   在 $\Phi(D_i) = 2 \cdot \text{size}(\text{in\_stack}_i)$ 下：
   - 若 `out_stack` 非空，直接读取栈顶，$c_i = 1$，$\Delta \Phi = 0$，$\hat{c}_i = 1 = O(1)$；
   - 若 `out_stack` 为空，将 $k$ 个元素从 `in_stack` 倾倒至 `out_stack` 并读取栈顶，$c_i = 2k + 1$，而势能减少 $\Delta \Phi = -2k$，故 $\hat{c}_i = (2k + 1) - 2k = 1 = O(1)$。

综上，任意连续 $m$ 次队列操作的总实际代价满足 $\sum_{i=1}^{m} c_i \le \sum_{i=1}^{m} \hat{c}_i \le 3m = O(m)$，每个操作的摊还时间复杂度均为 $O(1)$。

## 答案

```c
#include <assert.h>
#include <inttypes.h>
#include <stdbool.h>
#include <stddef.h>
#include <stdint.h>
#include <stdio.h>
#include <stdlib.h>

typedef struct {
    int64_t *data;
    size_t top;
    size_t capacity;
} IntStack;

struct TwoStackQueue {
    IntStack in_stack;
    IntStack out_stack;
};

static bool stack_init(IntStack *s, size_t initial_capacity) {
    size_t cap = initial_capacity > 0 ? initial_capacity : 4;
    if (cap > SIZE_MAX / sizeof *s->data) {
        return false;
    }
    s->data = malloc(cap * sizeof *s->data);
    if (s->data == NULL) {
        return false;
    }
    s->top = 0;
    s->capacity = cap;
    return true;
}

static void stack_free(IntStack *s) {
    free(s->data);
    s->data = NULL;
    s->top = 0;
    s->capacity = 0;
}

static bool stack_push(IntStack *s, int64_t value) {
    if (s->top == s->capacity) {
        if (s->capacity > SIZE_MAX / (2 * sizeof *s->data)) {
            return false;
        }
        size_t new_cap = s->capacity * 2;
        int64_t *new_data = realloc(s->data, new_cap * sizeof *new_data);
        if (new_data == NULL) {
            return false;
        }
        s->data = new_data;
        s->capacity = new_cap;
    }
    s->data[s->top++] = value;
    return true;
}

static bool transfer_in_to_out(TwoStackQueue *q) {
    while (q->in_stack.top > 0) {
        int64_t val = q->in_stack.data[q->in_stack.top - 1];
        if (!stack_push(&q->out_stack, val)) {
            return false;
        }
        q->in_stack.top--;
    }
    return true;
}

TwoStackQueue *ts_queue_create(size_t initial_capacity) {
    TwoStackQueue *q = malloc(sizeof *q);
    if (q == NULL) {
        return NULL;
    }
    if (!stack_init(&q->in_stack, initial_capacity)) {
        free(q);
        return NULL;
    }
    if (!stack_init(&q->out_stack, initial_capacity)) {
        stack_free(&q->in_stack);
        free(q);
        return NULL;
    }
    return q;
}

void ts_queue_destroy(TwoStackQueue *q) {
    if (q == NULL) {
        return;
    }
    stack_free(&q->in_stack);
    stack_free(&q->out_stack);
    free(q);
}

bool ts_queue_enqueue(TwoStackQueue *q, int64_t value) {
    if (q == NULL) {
        return false;
    }
    return stack_push(&q->in_stack, value);
}

bool ts_queue_dequeue(TwoStackQueue *q, int64_t *out_value) {
    if (q == NULL || out_value == NULL) {
        return false;
    }
    if (q->out_stack.top == 0) {
        if (q->in_stack.top == 0 || !transfer_in_to_out(q)) {
            return false;
        }
    }
    *out_value = q->out_stack.data[--q->out_stack.top];
    return true;
}

bool ts_queue_peek(const TwoStackQueue *q, int64_t *out_value) {
    if (q == NULL || out_value == NULL) {
        return false;
    }
    if (q->out_stack.top > 0) {
        *out_value = q->out_stack.data[q->out_stack.top - 1];
        return true;
    }
    if (q->in_stack.top == 0) {
        return false;
    }
    TwoStackQueue *mutable_q = (TwoStackQueue *)q;
    if (!transfer_in_to_out(mutable_q)) {
        return false;
    }
    *out_value = mutable_q->out_stack.data[mutable_q->out_stack.top - 1];
    return true;
}

size_t ts_queue_size(const TwoStackQueue *q) {
    if (q == NULL) {
        return 0;
    }
    return q->in_stack.top + q->out_stack.top;
}

int main(void) {
    TwoStackQueue *q = ts_queue_create(2);
    assert(q != NULL);
    assert(ts_queue_size(q) == 0);

    for (int64_t i = 1; i <= 10; ++i) {
        assert(ts_queue_enqueue(q, i * 10));
    }
    assert(ts_queue_size(q) == 10);

    int64_t front = 0;
    assert(ts_queue_peek(q, &front) && front == 10);

    for (int64_t i = 1; i <= 5; ++i) {
        assert(ts_queue_dequeue(q, &front) && front == i * 10);
    }
    for (int64_t i = 11; i <= 15; ++i) {
        assert(ts_queue_enqueue(q, i * 10));
    }
    for (int64_t i = 6; i <= 15; ++i) {
        assert(ts_queue_dequeue(q, &front) && front == i * 10);
    }

    assert(ts_queue_size(q) == 0);
    assert(!ts_queue_dequeue(q, &front));
    ts_queue_destroy(q);

    printf("All TwoStackQueue tests passed!\n");
    return 0;
}
```
