# 35907 - 图的 m-着色问题回溯与邻接冲突剪枝

## 题目

给定一个包含 $V$ 个顶点的无向图，以及 $m$ 种可用颜色（颜色编号为 $1, 2, \dots, m$）。

使用回溯法判定是否存在一种给所有顶点分配颜色的方案，使得**任意两个相邻的顶点具有不同的颜色**。若存在合法着色方案，将其中一种可行方案输出到数组 `out_color` 中；若不存在，输出指示无法着色。

函数签名如下：

```c
#include <stdbool.h>
#include <stddef.h>

bool graph_m_coloring(
    size_t vertex_count,
    const size_t edges[][2],
    size_t edge_count,
    size_t m,
    size_t *out_color,
    bool *out_solvable
);
```

要求：
1. 参数无效（指针为空且计数大于 0）时返回 `false`。
2. 当 $V = 0$ 时，方案自然存在，输出 `*out_solvable = true` 并返回 `true`。
3. 邻接矩阵或邻接表构建准确。在尝试给顶点 $u$ 染上颜色 $c$ 时，必须检查其所有已着色的邻接顶点是否冲突。
4. 递归调用时若某个分支无解，必须将顶点的颜色重新清零（对称回溯）。

## 解题思路

1. **图的表示与冲突判定**：
   对于无向图，用布尔邻接矩阵 `adj[u][v]` 记录顶点 $u$ 与顶点 $v$ 是否存在边。
   当为顶点 $u$ 尝试指定颜色 $c$（$1 \le c \le m$）时：
   遍历所有其他顶点 $v$（$0 \le v < V$）：
   若 $adj[u][v] == true$ 且 $color[v] == c$，说明该着色方案导致相邻同色，立即放弃该颜色（冲突剪枝）。

2. **按顶点顺序递归回溯**：
   函数 `color_dfs(u, ...)` 负责为顶点 $u$ 决策颜色：
   - 基准情形：若 $u == V$，说明全部顶点均已合法着色，找到一个可行解，返回 `true`；
   - 逐一尝试颜色 $c \in [1, m]$：
     - 若颜色 $c$ 安全无冲突：
       设置 $color[u] = c$；
       递归调用 `color_dfs(u + 1)`；
       若子调用成功，直接层层返回 `true`；
       若失败，**回溯重置**：$color[u] = 0$；
   - 若所有 $m$ 种颜色均无法合法填入，返回 `false` 触发上层回溯。

## C 语言实现

```c
#include <assert.h>
#include <stdbool.h>
#include <stddef.h>
#include <stdlib.h>
#include <string.h>

static bool is_safe(
    size_t u,
    size_t c,
    size_t vertex_count,
    const bool *adj,
    const size_t *color
) {
    for (size_t v = 0; v < vertex_count; ++v) {
        if (adj[u * vertex_count + v] && color[v] == c) {
            return false;
        }
    }
    return true;
}

static bool coloring_dfs(
    size_t u,
    size_t vertex_count,
    const bool *adj,
    size_t m,
    size_t *color
) {
    if (u == vertex_count) {
        return true; // 所有顶点成功着色
    }

    for (size_t c = 1; c <= m; ++c) {
        if (is_safe(u, c, vertex_count, adj, color)) {
            color[u] = c;

            if (coloring_dfs(u + 1, vertex_count, adj, m, color)) {
                return true;
            }

            color[u] = 0; // 回溯复原
        }
    }

    return false;
}

bool graph_m_coloring(
    size_t vertex_count,
    const size_t edges[][2],
    size_t edge_count,
    size_t m,
    size_t *out_color,
    bool *out_solvable
) {
    if (out_solvable == NULL) {
        return false;
    }
    if (vertex_count == 0) {
        *out_solvable = true;
        return true;
    }
    if (out_color == NULL || (edge_count > 0 && edges == NULL)) {
        return false;
    }
    if (m == 0 && vertex_count > 0) {
        *out_solvable = false;
        return true;
    }

    if (vertex_count > SIZE_MAX / vertex_count) {
        return false;
    }

    bool *adj = calloc(vertex_count * vertex_count, sizeof *adj);
    if (adj == NULL) {
        return false;
    }

    // 构建无向图邻接矩阵
    for (size_t i = 0; i < edge_count; ++i) {
        size_t u = edges[i][0];
        size_t v = edges[i][1];
        if (u >= vertex_count || v >= vertex_count) {
            free(adj);
            return false;
        }
        if (u != v) {
            adj[u * vertex_count + v] = true;
            adj[v * vertex_count + u] = true;
        }
    }

    memset(out_color, 0, vertex_count * sizeof *out_color);

    bool solvable = coloring_dfs(0, vertex_count, adj, m, out_color);
    *out_solvable = solvable;

    free(adj);
    return true;
}

int main(void) {
    size_t colors[16];
    bool solvable = false;

    // 参数校验
    assert(!graph_m_coloring(3, NULL, 1, 3, colors, &solvable));
    assert(!graph_m_coloring(3, (const size_t[][2]){{0, 1}}, 1, 3, NULL, &solvable));

    // 0 顶点
    assert(graph_m_coloring(0, NULL, 0, 1, colors, &solvable) && solvable);

    // K4 完全图 (4 个顶点，任意两点间均有边)
    // 染色数至少需要 4 种颜色
    const size_t k4_edges[6][2] = {
        {0, 1}, {0, 2}, {0, 3},
        {1, 2}, {1, 3}, {2, 3}
    };

    // 用 m = 3 种颜色给 K4 着色 -> 必不可解
    assert(graph_m_coloring(4, k4_edges, 6, 3, colors, &solvable));
    assert(!solvable);

    // 用 m = 4 种颜色给 K4 着色 -> 可解
    assert(graph_m_coloring(4, k4_edges, 6, 4, colors, &solvable));
    assert(solvable);
    // 校验相邻点颜色不同
    for (size_t i = 0; i < 6; ++i) {
        size_t u = k4_edges[i][0];
        size_t v = k4_edges[i][1];
        assert(colors[u] != colors[v]);
        assert(colors[u] >= 1 && colors[u] <= 4);
    }

    // 二分图 (环长为偶数: 0-1-2-3-0), 2 种颜色即可解
    const size_t c4_edges[4][2] = {
        {0, 1}, {1, 2}, {2, 3}, {3, 0}
    };
    assert(graph_m_coloring(4, c4_edges, 4, 2, colors, &solvable));
    assert(solvable);
    assert(colors[0] != colors[1] && colors[1] != colors[2]);

    return 0;
}
```

## 复杂度分析

- **时间复杂度**：最坏情况下为 $O(m^V)$。每个顶点尝试 $m$ 种颜色。但在实际搜索中，连通分支间的冲突会极早截断无效染色序列。
- **空间复杂度**：$O(V^2)$。主要用于邻接矩阵，递归调用栈深度为 $V$。

## 延伸思考 / 模式总结

图着色问题是典型的 NP-完全问题（对于 $m \ge 3$）。其回溯模型展示了离散约束满足问题的标准范式：顺序赋予决策值，遇到与已固定的邻居产生冲突时立即剪枝并复原。
