# 35906 - 0-1 背包的分支限界法（Branch and Bound: 上界松弛剪枝）

## 题目描述

给定 $n$ 件物品，每件物品具有重量 $w_i$ 和价值 $v_i$。背包的最大承重容量为 `capacity`。每件物品最多选择一次。

请采用**分支限界法（Branch and Bound）**求解在不超过背包容量的前提下所能获得的最大总价值。

函数签名如下：

```c
#include <stdbool.h>
#include <stddef.h>
#include <stdint.h>

bool knapsack_branch_and_bound(
    const size_t *weights,
    const uint64_t *values,
    size_t count,
    size_t capacity,
    uint64_t *out_max_value
);
```

要求：
1. 参数无效时返回 `false`；`count == 0` 或 `capacity == 0` 时最大价值为 0，输出 0 并返回 `true`。
2. 物品必须先按照**单位价值比（$v_i / w_i$）降序**进行预排序。
3. 搜索过程中，利用**分数背包线性松弛（Fractional Knapsack Relaxation）**作为当前节点的最优价值上界（Bound）。
4. 若当前累计价值加上计算出的松弛上界不超过已知的全局最优价值（`current_value + bound <= best_value`），则该分支不可能产生更优解，必须**立即剪枝**。

## 解题思路

1. **上界函数构造（连续分数松弛）**：
   在决策当前物品 $index$ 时，背包已有剩余容量 $rem\_cap$ 和累计价值 $cur\_val$。
   如果允许将后续物品切分按比例装入（即分数背包问题），贪心策略可以给出该子树能获得的最大价值的理论上限 $upper\_bound$。
   因为连续松弛解空间包含离散整数解空间，所以必有：
   $$\text{最优整数解} \le \text{最优松弛解}$$
   具体计算：按性价比降序依次扫描剩余物品，能完整放入则全放；遇到第一件放不下的物品，按剩余空间比例放入该物品的一部分价值。此累加总和即为可靠的上界。

2. **剪枝准则（Branch & Bound）**：
   维护全局最优解 `best_value`：
   - 每次搜索到一个合法可行叶子或部分解时，若当前价值超过 `best_value` 则更新它；
   - 在进入任何子分支前，若计算出的 $cur\_val + upper\_bound \le best\_value$，则整棵子树直接被剪除（限界）。

3. **优先搜索左分支**：
   通常“选择当前物品”更有可能快速建立一个较高的 `best_value`，从而在后续对“不选当前物品”的右分支实施强力剪枝。

## C 语言实现

```c
#include <assert.h>
#include <stdbool.h>
#include <stddef.h>
#include <stdint.h>
#include <stdlib.h>

typedef struct {
    size_t weight;
    uint64_t value;
    double ratio;
} KnapItem;

static int compare_items(const void *a, const void *b) {
    const KnapItem *item_a = (const KnapItem *)a;
    const KnapItem *item_b = (const KnapItem *)b;
    if (item_a->ratio > item_b->ratio) return -1;
    if (item_a->ratio < item_b->ratio) return 1;
    return 0;
}

// 计算分数背包连续松弛上界
static double compute_bound(
    const KnapItem *items,
    size_t count,
    size_t index,
    size_t remaining_cap,
    uint64_t current_val
) {
    double bound = (double)current_val;
    size_t cap = remaining_cap;

    for (size_t i = index; i < count; ++i) {
        if (items[i].weight <= cap) {
            cap -= items[i].weight;
            bound += (double)items[i].value;
        } else {
            // 装入部分物品
            bound += (double)items[i].value * ((double)cap / (double)items[i].weight);
            break;
        }
    }

    return bound;
}

static void bb_dfs(
    const KnapItem *items,
    size_t count,
    size_t index,
    size_t current_weight,
    uint64_t current_value,
    size_t capacity,
    uint64_t *best_value
) {
    if (current_value > *best_value) {
        *best_value = current_value;
    }

    if (index == count) {
        return;
    }

    // 计算松弛上界剪枝
    double bound = compute_bound(
        items, count, index, capacity - current_weight, current_value
    );
    if (bound <= (double)(*best_value)) {
        return; // 上界不足，直接剪除整棵子树
    }

    // 分支 1: 尝试放入当前物品 (若容量允许)
    if (current_weight + items[index].weight <= capacity) {
        bb_dfs(
            items,
            count,
            index + 1,
            current_weight + items[index].weight,
            current_value + items[index].value,
            capacity,
            best_value
        );
    }

    // 分支 2: 不放当前物品
    bb_dfs(
        items,
        count,
        index + 1,
        current_weight,
        current_value,
        capacity,
        best_value
    );
}

bool knapsack_branch_and_bound(
    const size_t *weights,
    const uint64_t *values,
    size_t count,
    size_t capacity,
    uint64_t *out_max_value
) {
    if (out_max_value == NULL || (count > 0 && (weights == NULL || values == NULL))) {
        return false;
    }
    if (count == 0 || capacity == 0) {
        *out_max_value = 0;
        return true;
    }

    KnapItem *items = malloc(count * sizeof *items);
    if (items == NULL) {
        return false;
    }

    for (size_t i = 0; i < count; ++i) {
        items[i].weight = weights[i];
        items[i].value = values[i];
        items[i].ratio = (weights[i] == 0) ? 1e18 : ((double)values[i] / (double)weights[i]);
    }

    // 按性价比降序排序
    qsort(items, count, sizeof(KnapItem), compare_items);

    uint64_t best_value = 0;
    bb_dfs(items, count, 0, 0, 0, capacity, &best_value);

    *out_max_value = best_value;
    free(items);
    return true;
}

int main(void) {
    uint64_t res = 0;

    // 参数校验
    assert(!knapsack_branch_and_bound(NULL, (const uint64_t[]){1}, 1, 10, &res));
    assert(!knapsack_branch_and_bound((const size_t[]){1}, NULL, 1, 10, &res));
    assert(!knapsack_branch_and_bound((const size_t[]){1}, (const uint64_t[]){1}, 1, 10, NULL));

    // 边界用例
    assert(knapsack_branch_and_bound(NULL, NULL, 0, 10, &res) && res == 0);
    const size_t w0[1] = {5};
    const uint64_t v0[1] = {100};
    assert(knapsack_branch_and_bound(w0, v0, 1, 0, &res) && res == 0);

    // 标准测试用例:
    // 重量: [2, 3, 4, 5]
    // 价值: [3, 4, 5, 6]
    // 容量: 5
    // 最优选择: 选 0 和 1, 重量 2 + 3 = 5, 价值 3 + 4 = 7
    const size_t w_std[4] = {2, 3, 4, 5};
    const uint64_t v_std[4] = {3, 4, 5, 6};
    assert(knapsack_branch_and_bound(w_std, v_std, 4, 5, &res) && res == 7);

    // 较大差值对比测试
    const size_t w_test[4] = {10, 20, 30, 40};
    const uint64_t v_test[4] = {60, 100, 120, 240};
    // 容积 50: 最优选 10 (60) + 40 (240) = 300
    assert(knapsack_branch_and_bound(w_test, v_test, 4, 50, &res) && res == 300);

    return 0;
}
```

## 复杂度分析

- **时间复杂度**：最坏情况下为 $O(2^n)$。但在实践中，当背包容量 $C$ 很大导致动态规划 $O(nC)$ 无法承受时（例如 $C = 10^{12}$），分支限界法通过分数上界能剪除绝大部分无效子树，表现出极高的效率。
- **空间复杂度**：$O(n)$。包含排序后的结构体数组以及最大深度为 $n$ 的递归调用栈。

## 延伸思考 / 模式总结

分支限界法与纯回溯的区别在于**主动估算上界**。回溯通常只利用可行性做被动修剪，而分支限界引入了优化目标函数：通过求解一个计算代价低廉的松弛问题（如线性规划、贪心松弛），为不可行的分支宣判死刑。
