# 35901：子集和回溯计数

## 题目

给定一组非负整数，使用回溯统计元素和等于 `target` 的下标子集数量：

```c
#include <stdbool.h>
#include <stddef.h>
#include <stdint.h>

bool count_subsets_with_sum(
    const uint64_t *items,
    size_t count,
    uint64_t target,
    uint64_t *out_count
);
```

要求：

1. 每个位置最多选择一次；相同数值但位置不同的元素仍视为不同选择。
2. `count == 0` 时，只有 `target == 0` 的空子集计数为 1；数组指针可以为 `NULL`。
3. 使用回溯，并利用非负性在当前和超过 `target` 时剪枝。
4. 计数加法溢出、参数无效时返回 `false`，输出对象保持不变；分析最坏时间复杂度。

## 解析

在子集树上按位置 `index` 从 `0` 到 `count` 逐层决策每个位置“不选”或“选”：

1. **基准情形**：当 `index == count` 时，若当前累加和 `current_sum == target`，则找到一个合法子集。累加解数量前先检查 `*out_solutions == UINT64_MAX`，防止极端输入（例如 64 个 `0` 且 `target == 0`）导致 `uint64_t` 计数溢出。
2. **可行性剪枝**：由于所有元素均为非负整数（`uint64_t`），后续元素的加入只会使累加和单调不减。因此在尝试选择 `items[index]` 的分支前，先通过 `items[index] <= target - current_sum` 判断加入该元素后是否会超过 `target`；这种减法形式既等价于无溢出的 `current_sum + items[index] <= target`，又能在超界时直接剪掉“选当前元素”的整棵子树。
3. **注意不能在 `current_sum == target` 时提前终止递归**：后续位置可能包含值为 `0` 的元素，只有递归到达叶结点 `index == count` 才能不重不漏地计入含 `0` 元素的不同下标子集。

## 答案

```c
#include <stdbool.h>
#include <stddef.h>
#include <stdint.h>

static bool subset_sum_dfs(
    const uint64_t *items,
    size_t count,
    size_t index,
    uint64_t current_sum,
    uint64_t target,
    uint64_t *out_solutions
) {
    if (index == count) {
        if (current_sum == target) {
            if (*out_solutions == UINT64_MAX) {
                return false;
            }
            ++*out_solutions;
        }
        return true;
    }
    if (!subset_sum_dfs(
            items,
            count,
            index + 1,
            current_sum,
            target,
            out_solutions
        )) {
        return false;
    }
    if (items[index] <= target - current_sum) {
        if (!subset_sum_dfs(
                items,
                count,
                index + 1,
                current_sum + items[index],
                target,
                out_solutions
            )) {
            return false;
        }
    }
    return true;
}

bool count_subsets_with_sum(
    const uint64_t *items,
    size_t count,
    uint64_t target,
    uint64_t *out_count
) {
    if (out_count == NULL || (count > 0 && items == NULL)) {
        return false;
    }
    uint64_t solutions = 0;
    if (!subset_sum_dfs(items, count, 0, 0, target, &solutions)) {
        return false;
    }
    *out_count = solutions;
    return true;
}
```

当所有子集和都不超过 `target` 时，剪枝不会裁剪任何分支，状态空间树共有 $2^n$ 个叶结点，因此最坏时间复杂度为 $O(2^n)$；递归调用栈深度至多为 $n + 1$，额外空间复杂度为 $O(n)$。
