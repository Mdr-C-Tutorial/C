# 35901 - 组合总和与子集生成

## 题目描述

给定一个包含 `count` 个非负整数的数组 `items` 与一个目标总和 `target`。使用回溯法求解：从数组中选取若干下标不重复的元素，使得这些元素的累加和恰好等于 `target` 的不同子集总数。

函数签名如下：

```c
#include <stdbool.h>
#include <stddef.h>
#include <stdint.h>

bool count_subsets_with_sum(
    const uint64_t *items,
    size_t count,
    uint64_t target,
    uint64_t *out_count
);
```

要求：
1. 参数无效（`out_count == NULL`，或 `count > 0 && items == NULL`）时返回 `false`。
2. 当 `target == 0` 时，空子集（不选任何元素，总和为 0）视为一个合法解。
3. 统计解的总数若超过 `UINT64_MAX`，返回 `false` 且不修改输出对象（防加法溢出）。
4. 必须通过剪枝优化：利用元素非负性在累加和超界时提早剪除分支。注意数组中可能存在数值为 0 的元素，必须正确处理含有 0 时的解计数。
5. 辅助空间复杂度为 $O(n)$（递归调用栈深度），最坏时间复杂度为 $O(2^n)$。

## 解题思路

1. **子集树搜索结构**：
   在解空间树中，每个下标位置 $i$ 对应一个决策层：
   - 分支一：**不选** `items[i]`，当前累加和保持不变，递归搜索下一个下标；
   - 分支二：**选择** `items[i]`，累加和增加 `items[i]`，递归搜索下一个下标。

2. **可行性剪枝（减法防溢出判定）**：
   由于数组中所有元素均为非负整数（`uint64_t`），随着选取的元素增多，当前累加和单调不减。
   在尝试选择 `items[i]` 之前，若当前累加和加上该元素会超过目标值，则该子树不可能存在合法解。
   为了防止加法溢出，判断条件写为减法形式：
   `items[i] <= target - current_sum`
   若不满足该条件，则直接剪去“选当前元素”的整棵子树。

3. **零元素与叶子终止**：
   特别注意：当搜索中途达到 `current_sum == target` 时，**不能提前返回终止递归**。
   因为后续未访问的元素中可能包含数值为 0 的项，选择或不选择 0 会派生出不同的下标子集。因此搜索必须行进至树的叶子结点 `index == count`，才能不重不漏地完成统计。

## C 语言实现

```c
#include <assert.h>
#include <stdbool.h>
#include <stddef.h>
#include <stdint.h>

static bool subset_sum_dfs(
    const uint64_t *items,
    size_t count,
    size_t index,
    uint64_t current_sum,
    uint64_t target,
    uint64_t *out_solutions
) {
    if (index == count) {
        if (current_sum == target) {
            if (*out_solutions == UINT64_MAX) {
                return false;
            }
            ++*out_solutions;
        }
        return true;
    }

    // 分支 1: 不选当前元素
    if (!subset_sum_dfs(items, count, index + 1, current_sum, target, out_solutions)) {
        return false;
    }

    // 分支 2: 选当前元素 (可行性剪枝)
    if (items[index] <= target - current_sum) {
        if (!subset_sum_dfs(items, count, index + 1, current_sum + items[index], target, out_solutions)) {
            return false;
        }
    }

    return true;
}

bool count_subsets_with_sum(
    const uint64_t *items,
    size_t count,
    uint64_t target,
    uint64_t *out_count
) {
    if (out_count == NULL || (count > 0 && items == NULL)) {
        return false;
    }

    uint64_t solutions = 0;
    if (!subset_sum_dfs(items, count, 0, 0, target, &solutions)) {
        return false;
    }

    *out_count = solutions;
    return true;
}

int main(void) {
    uint64_t count = 0;

    // 参数校验测试
    assert(!count_subsets_with_sum(NULL, 1, 5, &count));
    assert(!count_subsets_with_sum((const uint64_t[]){1}, 1, 5, NULL));

    // 空集测试: target = 0 有且仅有空集 1 种
    assert(count_subsets_with_sum(NULL, 0, 0, &count) && count == 1);
    assert(count_subsets_with_sum(NULL, 0, 10, &count) && count == 0);

    // 标准测试: items = [1, 2, 3, 4, 5], target = 5
    // 解子集: [5], [2, 3], [1, 4] 共 3 种
    const uint64_t a1[5] = {1, 2, 3, 4, 5};
    assert(count_subsets_with_sum(a1, 5, 5, &count) && count == 3);

    // 含 0 元素测试: items = [0, 0, 1], target = 1
    // 下标解: {2}, {0, 2}, {1, 2}, {0, 1, 2} 共 4 种
    const uint64_t a2[3] = {0, 0, 1};
    assert(count_subsets_with_sum(a2, 3, 1, &count) && count == 4);

    return 0;
}
```

## 复杂度分析

- **时间复杂度**：$O(2^n)$。在最坏情形下（如所有元素均为 0 且 target = 0），必须遍历完整二叉子集树的全部 $2^n$ 个叶子节点。剪枝在平均情况下大幅裁剪超过 target 的分支。
- **空间复杂度**：$O(n)$。递归调用栈最大深度为 $n + 1$，仅占用常数个调用栈帧。

## 延伸思考 / 模式总结

回溯法解决子集生成的核心是不变式维护。当元素全部非负时，累加和的单调性提供了强有力的上界剪枝依据。在处理含有零元素的问题时，必须警惕“贪心提前终止”陷阱，确保遍历完整深度以覆盖所有等价解。
