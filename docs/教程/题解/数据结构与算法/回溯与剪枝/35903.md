# 35903 - 位掩码剪枝求解 N 皇后问题

## 题目描述

在 $n \times n$ 的国际象棋棋盘上摆放 $n$ 个皇后，使其不能互相攻击。即任意两个皇后都不能处于同一行、同一列或同一对角线上。

使用回溯法计算在 $n \times n$ 棋盘上放置 $n$ 个皇后的所有合法放置方案总数。

函数签名如下：

```c
#include <stdbool.h>
#include <stddef.h>
#include <stdint.h>

bool count_n_queens_solutions(size_t n, uint64_t *out_solutions);
```

要求：
1. 采用位掩码（bitmask）维护列、主对角线、副对角线的冲突状态，在 $O(1)$ 时间内确定当前行所有允许摆放的位置。
2. 参数无效或 $n > 64$（超出 64 位无符号整数表示范围）时返回 `false`。
3. 当 $n = 0$ 时，方案数为 1（空棋盘），输出 1 并返回 `true`。
4. 递归调用时通过位运算快速提取最低有效位，状态通过函数值传递自然恢复，空间复杂度严格限制在 $O(n)$。

## 解题思路

1. **逐行放置消除行冲突**：
   在搜索的第 $row$ 层仅在第 $row$ 行放置一个皇后，天然保证任意两个皇后不同行。

2. **三个位掩码刻画三维冲突**：
   维护三个 64 位整型掩码：
   - `cols`：第 $c$ 位为 1 表示第 $c$ 列已被此前某行的皇后占据；
   - `diag1`：主对角线（左上至右下方向，斜率 1）。每向下移动一行，主对角线冲突在列上向右偏移一位，向下传递时执行 `(diag1 | bit) << 1`；
   - `diag2`：副对角线（右上至左下方向，斜率 -1）。每向下移动一行，副对角线冲突在列上向左偏移一位，向下传递时执行 `(diag2 | bit) >> 1`。

3. **位运算提取可用位置与快速迭代**：
   设满棋盘掩码为 `full_mask = ((uint64_t)1 << n) - 1`。
   当前行中所有允许放置皇后的列集合为：
   $$available = full\_mask \land \neg(cols \lor diag1 \lor diag2)$$
   利用位运算技巧：
   `bit = available & (~available + 1)`（即 `available & -available`）
   在 $O(1)$ 时间内快速提取最低位的可用列，放置皇后并向下递归，随后执行 `available -= bit` 清除该位。若 $available = 0$ 则说明无可用列，自动触发回溯。

## C 语言实现

```c
#include <assert.h>
#include <stdbool.h>
#include <stddef.h>
#include <stdint.h>

static bool n_queens_dfs(
    size_t row,
    size_t n,
    uint64_t full_mask,
    uint64_t cols,
    uint64_t diag1,
    uint64_t diag2,
    uint64_t *out_solutions
) {
    if (row == n) {
        if (*out_solutions == UINT64_MAX) {
            return false;
        }
        ++*out_solutions;
        return true;
    }

    uint64_t available = full_mask & ~(cols | diag1 | diag2);
    while (available != 0) {
        uint64_t bit = available & (~available + UINT64_C(1));
        available -= bit;

        if (!n_queens_dfs(
                row + 1,
                n,
                full_mask,
                cols | bit,
                (diag1 | bit) << 1,
                (diag2 | bit) >> 1,
                out_solutions
            )) {
            return false;
        }
    }

    return true;
}

bool count_n_queens_solutions(size_t n, uint64_t *out_solutions) {
    if (out_solutions == NULL || n > 64) {
        return false;
    }
    if (n == 0) {
        *out_solutions = 1;
        return true;
    }

    uint64_t full_mask = (n == 64) ? UINT64_MAX : (((uint64_t)1 << n) - 1);
    uint64_t solutions = 0;

    if (!n_queens_dfs(0, n, full_mask, 0, 0, 0, &solutions)) {
        return false;
    }

    *out_solutions = solutions;
    return true;
}

int main(void) {
    uint64_t sol = 0;

    // 参数校验
    assert(!count_n_queens_solutions(5, NULL));
    assert(!count_n_queens_solutions(65, &sol));

    // OEIS A000170 标准解数校验:
    // N = 0 -> 1
    // N = 1 -> 1
    // N = 2 -> 0
    // N = 3 -> 0
    // N = 4 -> 2
    // N = 5 -> 10
    // N = 6 -> 4
    // N = 7 -> 40
    // N = 8 -> 92
    assert(count_n_queens_solutions(0, &sol) && sol == 1);
    assert(count_n_queens_solutions(1, &sol) && sol == 1);
    assert(count_n_queens_solutions(2, &sol) && sol == 0);
    assert(count_n_queens_solutions(3, &sol) && sol == 0);
    assert(count_n_queens_solutions(4, &sol) && sol == 2);
    assert(count_n_queens_solutions(5, &sol) && sol == 10);
    assert(count_n_queens_solutions(6, &sol) && sol == 4);
    assert(count_n_queens_solutions(7, &sol) && sol == 40);
    assert(count_n_queens_solutions(8, &sol) && sol == 92);

    return 0;
}
```

## 复杂度分析

- **时间复杂度**：上界为 $O(n!)$。由于位掩码在每一步将无效分支全部瞬间剪除，实际访问的状态数远少于朴素回溯。
- **空间复杂度**：$O(n)$。掩码参数全部按值传递于调用栈中，无需在堆上分配棋盘数组，递归最大深度为 $n$。

## 延伸思考 / 模式总结

位掩码优化是回溯搜索的极致加速器。它将原本需要 $O(n)$ 检查的冲突判定压缩为单指令周期的按位与和按位或运算。由于掩码通过形参直接压入调用栈，子调用返回后父栈帧天然维持原状态，完全省去了显式的状态回退操作。
