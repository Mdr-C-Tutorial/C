# 35904 - 单词搜索（二维网格 DFS 回溯与已访问标记复原）

## 题目描述

给定一个包含 $m \times n$ 个字符的网格 `board` 和一个目标字符串 `word`。判断目标字符串是否能在网格中被连续搜寻出来。

单词必须按照字符顺序，通过相邻（水平或垂直相邻单元格）的单元格内的字母构成。**同一个单元格内的字母在一趟路径中不允许重复使用**。

函数签名如下：

```c
#include <stdbool.h>
#include <stddef.h>

bool word_search(
    char *board,
    size_t rows,
    size_t columns,
    const char *word,
    bool *out_found
);
```

要求：
1. 网格按行优先展平存储为一维数组，大小为 $rows \times columns$。
2. 目标字符串 `word` 以空字符 `'\0'` 结尾。若 `word[0] == '\0'`（空串），视为找到，输出 `true`。
3. 必须通过**原地覆写与对称复原**的方式追踪访问状态（例如将当前格子临时修改为 `'\0'` 作为占用哨兵，回溯时复原为原字符），避免动态分配 $O(mn)$ 的访问数组。
4. 退出函数前，网格中的所有字符必须完全还原至初始状态。

## 解题思路

1. **起点枚举**：
   遍历二维网格中的每一个单元格 $(r, c)$。若当前单元格字符与目标单词的首字符 `word[0]` 匹配，则以该格子为起点启动深度优先搜索。

2. **原地状态标记与对称复原**：
   在搜索过程中，为保证路径不自交，走过的单元格不能再次踏入：
   - 进入单元格 $(r, c)$ 时，暂存原字符 `char original = board[r * columns + c]`；
   - 将该单元格原地覆写为一个特殊标记（如 `'\0'` 或其他不可能在字母表中出现的字符）；
   - 向上下左右四个方向分别发起递归；
   - **对称复原不变式**：无论四个方向是否成功，在当前递归层退出之前，**必须无条件将原字符写回**：`board[r * columns + c] = original`。

3. **早停与边界剪枝**：
   - 越界判断：行坐标 $r < 0$ 或 $r \ge rows$，列坐标 $c < 0$ 或 $c \ge columns$；
   - 字符失配：`board[r * columns + c] != word[index]`；
   - 只要有任意一个方向返回 `true`，立即提早结束后续分支的搜索。

## C 语言实现

```c
#include <assert.h>
#include <stdbool.h>
#include <stddef.h>
#include <string.h>

static bool search_dfs(
    char *board,
    size_t rows,
    size_t columns,
    size_t r,
    size_t c,
    const char *word,
    size_t index
) {
    if (word[index] == '\0') {
        return true; // 目标串已全部匹配完成
    }
    if (r >= rows || c >= columns) {
        return false;
    }

    size_t pos = r * columns + c;
    if (board[pos] != word[index]) {
        return false;
    }

    if (word[index + 1] == '\0') {
        return true; // 匹配到最后一个字符
    }

    // 暂存原字符并设置访问标记
    char original = board[pos];
    board[pos] = '\0';

    bool found = false;

    // 上
    if (r > 0 && search_dfs(board, rows, columns, r - 1, c, word, index + 1)) {
        found = true;
    }
    // 下
    if (!found && r + 1 < rows && search_dfs(board, rows, columns, r + 1, c, word, index + 1)) {
        found = true;
    }
    // 左
    if (!found && c > 0 && search_dfs(board, rows, columns, r, c - 1, word, index + 1)) {
        found = true;
    }
    // 右
    if (!found && c + 1 < columns && search_dfs(board, rows, columns, r, c + 1, word, index + 1)) {
        found = true;
    }

    // 对称复原原字符
    board[pos] = original;

    return found;
}

bool word_search(
    char *board,
    size_t rows,
    size_t columns,
    const char *word,
    bool *out_found
) {
    if (out_found == NULL || word == NULL) {
        return false;
    }
    if (word[0] == '\0') {
        *out_found = true;
        return true;
    }
    if (rows == 0 || columns == 0 || board == NULL) {
        *out_found = false;
        return true;
    }

    for (size_t r = 0; r < rows; ++r) {
        for (size_t c = 0; c < columns; ++c) {
            if (board[r * columns + c] == word[0]) {
                if (search_dfs(board, rows, columns, r, c, word, 0)) {
                    *out_found = true;
                    return true;
                }
            }
        }
    }

    *out_found = false;
    return true;
}

int main(void) {
    bool found = false;

    // 参数校验
    assert(!word_search(NULL, 3, 3, "ABC", NULL));
    assert(!word_search((char[]){'A'}, 1, 1, NULL, &found));

    // 网格 3x4:
    // A B C E
    // S F C S
    // A D E E
    char b1[] = "ABCESFCSADEE";

    // 测试 1: 寻找 "ABCCED" -> 存在
    assert(word_search(b1, 3, 4, "ABCCED", &found) && found);
    // 确认网格字符完全被复原
    assert(strcmp(b1, "ABCESFCSADEE") == 0);

    // 测试 2: 寻找 "SEE" -> 存在
    assert(word_search(b1, 3, 4, "SEE", &found) && found);
    assert(strcmp(b1, "ABCESFCSADEE") == 0);

    // 测试 3: 寻找 "ABCB" -> 不存在 (不能重复使用同一格中的 'C' 或折返)
    assert(word_search(b1, 3, 4, "ABCB", &found) && !found);
    assert(strcmp(b1, "ABCESFCSADEE") == 0);

    // 空串测试
    assert(word_search(b1, 3, 4, "", &found) && found);

    return 0;
}
```

## 复杂度分析

- **时间复杂度**：$O(m 	imes n 	imes 4^L)$，其中 $L$ 为目标单词长度。在每个单元格上最多向 4 个方向探索，实际由于失配剪枝，运行速度极快。
- **空间复杂度**：$O(L)$。递归调用栈最大深度等于目标单词长度 $L$。通过原地字符覆写与复原，省去了大小为 $O(mn)$ 的访问矩阵分配。

## 延伸思考 / 模式总结

网格搜索回溯的核心机制是“原地标记 + 递归后复原”。这种技巧被称为“侵入式状态标记（In-place Marking）”，它将图遍历中的辅助集合转化为对原有数据结构的微小临时修改，既节省了内存分配开销，又消除了分配失败的异常分支。
