# 35902：全排列原地回溯枚举

## 题目

实现枚举一组互不相同整数的全部排列：

```c
#include <stdbool.h>
#include <stddef.h>
#include <stdint.h>

typedef bool (*PermutationVisitor)(
    const int64_t *items,
    size_t count,
    void *context
);

bool enumerate_permutations(
    int64_t *items,
    size_t count,
    PermutationVisitor visit,
    void *context
);
```

要求：

1. 通过交换或标记已使用位置进行回溯；每个完整排列只访问一次。
2. `visit` 返回 `false` 时立即停止枚举，但函数返回前必须把 `items` 恢复为调用前的顺序。
3. 参数无效时返回 `false`；`count == 0` 时应访问一次空排列。
4. 不复制整棵搜索树，额外空间复杂度应为 $O(n)$（不计调用方提供的数组），并说明递归深度。

## 解析

排列树的第 `depth` 层负责确定位置 `depth` 上的元素：

1. **原地交换构造排列**：在进入第 `depth` 层时，子区间 `items[0..depth - 1]` 已经固定为当前前缀，而 `items[depth..count - 1]` 存放尚未使用的候选元素。循环令下标 `i` 从 `depth` 遍历到 `count - 1`，每次将 `items[depth]` 与 `items[i]` 交换，然后递归进入 `depth + 1`。
2. **对称恢复不变式**：从 `depth + 1` 层递归返回后，无论子调用返回 `true`（继续搜索）还是 `false`（回调请求提前中止），当前层都**立即再次交换 `items[depth]` 与 `items[i]`**，将本层所做的修改撤销，随后再判断是继续下一轮迭代还是向父层返回 `false`。
3. **顺序恢复保证**：由于每一层都在返回父层前撤销了自身的交换操作，整条调用链按后进先出顺序回退完毕时，数组 `items` 必然精确还原为调用前的初始排列。

## 答案

```c
#include <stdbool.h>
#include <stddef.h>
#include <stdint.h>

typedef bool (*PermutationVisitor)(
    const int64_t *items,
    size_t count,
    void *context
);

static void swap_i64(int64_t *left, int64_t *right) {
    int64_t temporary = *left;
    *left = *right;
    *right = temporary;
}

static bool permute_dfs(
    int64_t *items,
    size_t count,
    size_t depth,
    PermutationVisitor visit,
    void *context
) {
    if (depth == count) {
        return visit(items, count, context);
    }
    for (size_t i = depth; i < count; ++i) {
        swap_i64(&items[depth], &items[i]);
        bool keep_going = permute_dfs(
            items, count, depth + 1, visit, context
        );
        swap_i64(&items[depth], &items[i]);
        if (!keep_going) {
            return false;
        }
    }
    return true;
}

bool enumerate_permutations(
    int64_t *items,
    size_t count,
    PermutationVisitor visit,
    void *context
) {
    if (visit == NULL || (count > 0 && items == NULL)) {
        return false;
    }
    (void)permute_dfs(items, count, 0, visit, context);
    return true;
}
```

完整枚举全部 $n!$ 个排列时，时间复杂度为 $O(n \cdot n!)$（若每次回调耗时 $O(1)$，则内部树结点交换总次数为 $O(n!)$）；递归深度最大为 $n$，不计调用方提供的数组，额外调用栈空间复杂度为 $O(n)$。
