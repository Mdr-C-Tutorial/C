# 35905 - 数独求解器（Sudoku Solver: 行列宫三维约束位运算回溯）

## 题目描述

编写一个程序，通过填充空格来解决 $9 \times 9$ 的数独谜题。

数独的规则是：
1. 数字 $1-9$ 在每一行只能出现一次。
2. 数字 $1-9$ 在每一列只能出现一次。
3. 数字 $1-9$ 在每一个以粗实线分隔的 $3 \times 3$ 宫（box）内只能出现一次。

空白格用数字 `0` 表示，已填入的数字为 `1-9`。若数独有解，将其原地填满并返回 `true`；若无解，返回 `false`。

函数签名如下：

```c
#include <stdbool.h>
#include <stdint.h>

bool sudoku_solve(uint8_t grid[9][9]);
```

要求：
1. 参数为空指针时返回 `false`。
2. 输入的预填数字若本身存在行、列或宫冲突，返回 `false` 报告非法。
3. 采用**位掩码**跟踪行、列、宫中数字 $1-9$ 的占用状态。
4. 结合**最少剩余值启发式（MRV, Minimum Remaining Values）**：每次优先选择可用候选数字最少的空格进行分支扩展，最大限度减少回溯分支。

## 解题思路

1. **三维约束的位掩码表示**：
   数独中填入的数字为 $1 \dots 9$。我们可以用一个 16 位整型数（`uint16_t`）的二进制位跟踪数字占用情况：
   若第 $d$ 位（$1 \le d \le 9$）为 1，表示数字 $d$ 已被使用。
   - `row_mask[r]`：第 $r$ 行的占用掩码；
   - `col_mask[c]`：第 $c$ 列的占用掩码；
   - `box_mask[b]`：第 $b$ 个 $3 \times 3$ 宫的占用掩码，其中宫索引为 $b = (r / 3) \times 3 + (c / 3)$。

2. **MRV 启发式选择最优待填格子**：
   在每一步决策前，扫描棋盘上所有的空格（值为 0 的格子）。
   对空格 $(r, c)$，其被三个维度共同限制，允许填入的数字位掩码为：
   $$avail = 0x3FE \land \neg (row\_mask[r] \lor col\_mask[c] \lor box\_mask[b])$$
   其中 $0x3FE$ 是第 1 位到第 9 位全为 1 的掩码（即二进制 `1111111110`）。
   - 若某个空格的 $avail == 0$，说明该格子已经没有任何合法数字可填，当前搜索路径必死，**立即提前触发回溯**；
   - 在所有空格中，选出候选数字个数（即 $avail$ 中 1 的个数）**最少**的那个格子作为下一步决策点。该启发式能以极大概率在树的浅层触发剪枝。

3. **递归试填与状态回退**：
   提取当前格子的所有候选位。依次尝试填入数字 $d$：
   - 原地更新棋盘：`grid[r][c] = d`；
   - 同步更新三个掩码：`row_mask[r] |= bit` 等；
   - 递归进入下一状态；
   - 若子调用返回失败，**对称撤销修改**：`grid[r][c] = 0`，掩码清除该位，尝试下一个数字。

## C 语言实现

```c
#include <assert.h>
#include <stdbool.h>
#include <stddef.h>
#include <stdint.h>

static inline size_t get_box_index(size_t r, size_t c) {
    return (r / 3) * 3 + (c / 3);
}

static inline int count_bits(uint16_t mask) {
    int count = 0;
    while (mask > 0) {
        mask &= (mask - 1);
        count++;
    }
    return count;
}

static bool solve_dfs(
    uint8_t grid[9][9],
    uint16_t row_mask[9],
    uint16_t col_mask[9],
    uint16_t box_mask[9]
) {
    size_t best_r = 9;
    size_t best_c = 9;
    int min_candidates = 10;
    uint16_t best_avail = 0;

    // 扫描所有空格，寻找 MRV 格子
    for (size_t r = 0; r < 9; ++r) {
        for (size_t c = 0; c < 9; ++c) {
            if (grid[r][c] == 0) {
                size_t b = get_box_index(r, c);
                uint16_t used = row_mask[r] | col_mask[c] | box_mask[b];
                uint16_t avail = 0x3FE & ~used;
                int candidates = count_bits(avail);

                if (candidates == 0) {
                    return false; // 无可用候选数，剪枝回溯
                }

                if (candidates < min_candidates) {
                    min_candidates = candidates;
                    best_r = r;
                    best_c = c;
                    best_avail = avail;
                    if (candidates == 1) {
                        break; // 唯一可能解，无需继续寻找
                    }
                }
            }
        }
        if (min_candidates == 1) {
            break;
        }
    }

    // 所有空格已填满
    if (best_r == 9) {
        return true;
    }

    size_t b = get_box_index(best_r, best_c);
    for (uint8_t d = 1; d <= 9; ++d) {
        uint16_t bit = (uint16_t)(1 << d);
        if ((best_avail & bit) != 0) {
            // 前进
            grid[best_r][best_c] = d;
            row_mask[best_r] |= bit;
            col_mask[best_c] |= bit;
            box_mask[b] |= bit;

            if (solve_dfs(grid, row_mask, col_mask, box_mask)) {
                return true;
            }

            // 回溯撤销
            grid[best_r][best_c] = 0;
            row_mask[best_r] &= ~bit;
            col_mask[best_c] &= ~bit;
            box_mask[b] &= ~bit;
        }
    }

    return false;
}

bool sudoku_solve(uint8_t grid[9][9]) {
    if (grid == NULL) {
        return false;
    }

    uint16_t row_mask[9] = {0};
    uint16_t col_mask[9] = {0};
    uint16_t box_mask[9] = {0};

    // 校验初始数独局面并初始化位掩码
    for (size_t r = 0; r < 9; ++r) {
        for (size_t c = 0; c < 9; ++c) {
            uint8_t val = grid[r][c];
            if (val > 9) {
                return false;
            }
            if (val > 0) {
                uint16_t bit = (uint16_t)(1 << val);
                size_t b = get_box_index(r, c);
                if ((row_mask[r] & bit) || (col_mask[c] & bit) || (box_mask[b] & bit)) {
                    return false; // 初始局面冲突
                }
                row_mask[r] |= bit;
                col_mask[c] |= bit;
                box_mask[b] |= bit;
            }
        }
    }

    return solve_dfs(grid, row_mask, col_mask, box_mask);
}

int main(void) {
    // 参数校验
    assert(!sudoku_solve(NULL));

    // 经典标准合法数独题面
    uint8_t puzzle[9][9] = {
        {5, 3, 0, 0, 7, 0, 0, 0, 0},
        {6, 0, 0, 1, 9, 5, 0, 0, 0},
        {0, 9, 8, 0, 0, 0, 0, 6, 0},
        {8, 0, 0, 0, 6, 0, 0, 0, 3},
        {4, 0, 0, 8, 0, 3, 0, 0, 1},
        {7, 0, 0, 0, 2, 0, 0, 0, 6},
        {0, 6, 0, 0, 0, 0, 2, 8, 0},
        {0, 0, 0, 4, 1, 9, 0, 0, 5},
        {0, 0, 0, 0, 8, 0, 0, 7, 9}
    };

    assert(sudoku_solve(puzzle));

    // 验证解的正确性：无 0，每行每列每宫和均为 45
    for (size_t r = 0; r < 9; ++r) {
        int r_sum = 0;
        for (size_t c = 0; c < 9; ++c) {
            assert(puzzle[r][c] >= 1 && puzzle[r][c] <= 9);
            r_sum += puzzle[r][c];
        }
        assert(r_sum == 45);
    }

    return 0;
}
```

## 复杂度分析

- **时间复杂度**：最坏情况下为指数级 $O(9^m)$（$m$ 为空格数量），但 MRV 启发式结合位运算剪枝将实际搜索树缩减数个数量级，绝大多数标准数独在数毫秒内即能收敛。
- **空间复杂度**：$O(m)$。递归调用栈最大深度为 81，掩码数组仅占用常数栈空间。

## 延伸思考 / 模式总结

数独求解是约束满足问题（CSP, Constraint Satisfaction Problem）的标准范例。结合位运算与 MRV（最少剩余值优先）策略，构成了现代回溯搜索器的两大支柱。对于更极端困难的数独，还可以使用下一题介绍的精确覆盖与 Dancing Links（DLX）算法。
