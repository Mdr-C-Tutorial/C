# 35408 - 两个有序数组的合并中位数

## 题目描述

给定两个升序排列的整数数组 `a`（长度为 $m$）和 `b`（长度为 $n$），在不对两数组进行实际合并的前提下求出合并后的中位数：

```c
#include <stdbool.h>
#include <stddef.h>
#include <stdint.h>

bool median_of_two_sorted(
    const int64_t *a, size_t m,
    const int64_t *b, size_t n,
    double *out_median
);
```

要求：

1. 采用对切分边界二分的思想，时间复杂度必须为严格的 $O(\log(\min(m, n)))$，辅助空间为 $O(1)$；
2. 形式化推导切分条件：左半部最大值小于等于右半部最小值，分别处理奇数长度与偶数长度的中位数公式；
3. 完善处理切分点落在数组端点（`i == 0` 或 `i == m`）时的无穷边界哨兵逻辑；
4. 编写包含空数组、等长/不等长、极值互不重叠等完整用例的测试断言。

## 解题思路

### 1. 数组虚拟切分与中位数定义

合并中位数的本质是将两个数组联合划分为元素数量相等的两部分：**左半部分（较小值）**与**右半部分（较大值）**。
为了确保时间复杂度达到 $O(\log(\min(m, n)))$，我们规定在较短的数组（设为长度为 $m$ 的数组 $A$，$m \le n$）上执行二分查找。
设在数组 $A$ 中切出前 $i$ 个元素放入左半部（$0 \le i \le m$），则为了满足左右两部分元素数量平衡，数组 $B$ 中必须切出前 $j$ 个元素放入左半部：

$$j = \left\lfloor \frac{m + n + 1}{2} \right\rfloor - i$$

此时左半部总元素个数为 $i + j = \lfloor (m + n + 1) / 2 \rfloor$：
- 若总长度 $m + n$ 为奇数，左半部元素个数恰比右半部多 1，中位数即为左半部的最大值；
- 若总长度 $m + n$ 为偶数，左右两部分元素个数完全相等，中位数即为（左半部最大值 + 右半部最小值）/ 2。

### 2. 切分合法性判定与二分收缩

为了使左半部的所有元素都不大于右半部的所有元素，由于 $A$ 与 $B$ 自身已有序，只需检验交叉边界条件：

$$A[i - 1] \le B[j] \quad \text{且} \quad B[j - 1] \le A[i]$$

- 若 $A[i - 1] > B[j]$：说明数组 $A$ 切出的左半部元素过大，应减小 $i$，向左半区收缩：`imax = i - 1`；
- 若 $B[j - 1] > A[i]$：说明数组 $A$ 切出的左半部元素过小，应增大 $i$，向右半区收缩：`imin = i + 1`；
- 若上述两条件同时满足，说明找到了完美切分点！

### 3. 边界哨兵处理

当切分点落在数组边缘时（如 $i = 0$ 表示数组 $A$ 没有元素被分入左半部），引入代数极值哨兵：
- $i = 0 \implies A[i - 1] = -\infty$（在 C 中用 `INT64_MIN` 表示）；
- $i = m \implies A[i] = +\infty$（在 C 中用 `INT64_MAX` 表示）；
同理处理 $j = 0$ 与 $j = n$ 的极端情形。

## C 语言实现

```c
#include <assert.h>
#include <limits.h>
#include <stdbool.h>
#include <stddef.h>
#include <stdint.h>
#include <stdio.h>

static int64_t max_i64(int64_t a, int64_t b) {
    return a > b ? a : b;
}

static int64_t min_i64(int64_t a, int64_t b) {
    return a < b ? a : b;
}

bool median_of_two_sorted(
    const int64_t *a, size_t m,
    const int64_t *b, size_t n,
    double *out_median
) {
    if (out_median == NULL || (m > 0 && a == NULL) || (n > 0 && b == NULL) || (m == 0 && n == 0)) {
        return false;
    }

    /* 保证在较短数组上二分，确保对数时间复杂度严格为 O(log(min(m, n))) */
    if (m > n) {
        return median_of_two_sorted(b, n, a, m, out_median);
    }

    size_t imin = 0;
    size_t imax = m;
    size_t half_len = (m + n + 1) / 2;

    while (imin <= imax) {
        size_t i = imin + (imax - imin) / 2;
        size_t j = half_len - i;

        int64_t a_left  = (i == 0) ? INT64_MIN : a[i - 1];
        int64_t a_right = (i == m) ? INT64_MAX : a[i];
        int64_t b_left  = (j == 0) ? INT64_MIN : b[j - 1];
        int64_t b_right = (j == n) ? INT64_MAX : b[j];

        if (a_left <= b_right && b_left <= a_right) {
            /* 满足完美切分条件 */
            int64_t max_left = max_i64(a_left, b_left);
            if ((m + n) % 2 == 1) {
                *out_median = (double)max_left;
            } else {
                int64_t min_right = min_i64(a_right, b_right);
                *out_median = ((double)max_left + (double)min_right) / 2.0;
            }
            return true;
        } else if (a_left > b_right) {
            imax = i - 1;
        } else {
            imin = i + 1;
        }
    }

    return false;
}

int main(void) {
    double med = 0.0;

    /* 奇数总长度测试：[1, 3] 与 [2] -> [1, 2, 3]，中位数 2.0 */
    int64_t a1[] = {1, 3};
    int64_t b1[] = {2};
    assert(median_of_two_sorted(a1, 2, b1, 1, &med) && med == 2.0);

    /* 偶数总长度测试：[1, 2] 与 [3, 4] -> [1, 2, 3, 4]，中位数 (2+3)/2 = 2.5 */
    int64_t a2[] = {1, 2};
    int64_t b2[] = {3, 4};
    assert(median_of_two_sorted(a2, 2, b2, 2, &med) && med == 2.5);

    /* 一个数组为空测试：[] 与 [1] -> 中位数 1.0 */
    int64_t b3[] = {1};
    assert(median_of_two_sorted(NULL, 0, b3, 1, &med) && med == 1.0);

    /* 极值完全不重叠测试：[10, 20] 与 [100, 200] -> 中位数 60.0 */
    int64_t a4[] = {10, 20};
    int64_t b4[] = {100, 200};
    assert(median_of_two_sorted(a4, 2, b4, 2, &med) && med == 60.0);

    /* 双空数组非法输入保护 */
    assert(!median_of_two_sorted(NULL, 0, NULL, 0, &med));

    printf("All median_of_two_sorted tests passed successfully.\n");
    return 0;
}
```

## 复杂度分析

- **时间复杂度**：$O(\log(\min\{m, n\}))$。二分检索范围受限于较短数组的长度 $m$，单步操作为 $O(1)$，无需合并两数组。
- **空间复杂度**：$\Theta(1)$。仅维护常数个 64 位整数与双指针对象。

## 延伸思考 / 模式总结

两个有序数组求中位数问题是“**二分切分（Binary Partition）**”思想的最高境界。它突破了“在值域上二分”和“在序列上下标二分”的常规局限，直接在“两个数组元素的空间配比”上二分，将原本 $O(m + n)$ 的归并选择直接优化到跨维度的对数级极限。
