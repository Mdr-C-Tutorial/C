# 35401 - 二分下界（Lower Bound）

## 题目描述

实现有序数组的二分下界查找：

```c
#include <stddef.h>
#include <stdint.h>

size_t lower_bound_i64(
    const int64_t *items,
    size_t count,
    int64_t target
);
```

`items` 按非递减顺序排列。函数返回第一个满足 `items[i] >= target` 的下标；若不存在，则返回 `count`。`count` 为 0 时应返回 0，此时 `items` 可以为 `NULL`。

要求使用左闭右开的搜索区间，不得用 `left + right` 计算中点，并说明循环不变式与 $O(\log n)$ 时间复杂度。

## 解题思路

### 1. 左闭右开区间与不变式设计

采用半开区间范式 $[\text{left}, \text{right})$，初始时 $\text{left} = 0, \text{right} = \text{count}$。

**循环不变式**：在每次循环判断前，状态满足：
1. 对所有 $0 \le i < \text{left}$，恒有 $\text{items}[i] < \text{target}$；
2. 对所有 $\text{right} \le j < \text{count}$，恒有 $\text{items}[j] \ge \text{target}$。

初始时，两个子区间 $[0, 0)$ 与 $[\text{count}, \text{count})$ 均为空集，不变式自然为真。

### 2. 区间收缩与防溢出

计算中点时，若直接使用 $(\text{left} + \text{right}) / 2$，当 $\text{left}$ 与 $\text{right}$ 较大且和超过 `SIZE_MAX` 时会导致无符号回绕错误。采用防溢出写法：

$$\text{mid} = \text{left} + \frac{\text{right} - \text{left}}{2}$$

- 若 $\text{items}[\text{mid}] < \text{target}$：由非递减单调性，$\text{mid}$ 及其左侧所有元素均严格小于 $\text{target}$，令 $\text{left} \leftarrow \text{mid} + 1$；
- 若 $\text{items}[\text{mid}] \ge \text{target}$：$\text{mid}$ 可能是首个满足条件的候选位置，令 $\text{right} \leftarrow \text{mid}$。

循环终止于 $\text{left} == \text{right}$，此时由不变式可知 $\text{left}$ 恰好是首个大于等于目标值的下标。

## C 语言实现

```c
#include <assert.h>
#include <stddef.h>
#include <stdint.h>
#include <stdio.h>

size_t lower_bound_i64(
    const int64_t *items,
    size_t count,
    int64_t target
) {
    size_t left = 0;
    size_t right = count;

    while (left < right) {
        size_t mid = left + (right - left) / 2;
        if (items[mid] < target) {
            left = mid + 1;
        } else {
            right = mid;
        }
    }

    return left;
}

int main(void) {
    int64_t a[] = {10, 20, 20, 20, 30, 40};
    size_t n = sizeof(a) / sizeof(a[0]);

    /* 存在多个相等元素：返回首个出现的下标 */
    assert(lower_bound_i64(a, n, 20) == 1);

    /* 元素不存在：返回第一个大于它的下标 */
    assert(lower_bound_i64(a, n, 25) == 4);

    /* 小于所有元素：返回 0 */
    assert(lower_bound_i64(a, n, 5) == 0);

    /* 大于所有元素：返回 count */
    assert(lower_bound_i64(a, n, 50) == 6);

    /* 空数组测试 */
    assert(lower_bound_i64(NULL, 0, 100) == 0);

    printf("All lower_bound_i64 tests passed successfully.\n");
    return 0;
}
```

## 复杂度分析

- **时间复杂度**：$\Theta(\log n)$。区间长度在每步严格折半，至多经过 $\lfloor \log_2 n \rfloor + 1$ 步终止。
- **空间复杂度**：$\Theta(1)$。仅维护常数个下标对象。

## 延伸思考 / 模式总结

`lower_bound` 本质上是在单调谓词 $P(x) \equiv (\text{items}[x] \ge \text{target})$ 的真值表序列 `[false, false, ..., true, true]` 上寻找第一个 `true` 的位置。这种单调谓词分界模型是所有二分查找与答案二分的统一认知原模。
