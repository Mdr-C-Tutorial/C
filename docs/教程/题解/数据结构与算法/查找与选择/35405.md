# 35405 - 旋转有序数组的最小元素与目标值二分查找

## 题目

旋转有序数组的最小元素与目标值二分查找：

一个原本非递减排列的无重复元素数组在某个未知的轴点上发生了旋转（例如 `[0,1,2,4,5,6,7]` 旋转为 `[4,5,6,7,0,1,2]`）。实现：

```c
#include <stdbool.h>
#include <stddef.h>
#include <stdint.h>

bool find_min_rotated(
    const int64_t *arr,
    size_t count,
    int64_t *out_min
);

bool search_rotated(
    const int64_t *arr,
    size_t count,
    int64_t target,
    size_t *out_index
);
```

要求：

1. `find_min_rotated`：在严格 $O(\log n)$ 时间内找出数组中的全局最小元素；
2. `search_rotated`：在严格 $O(\log n)$ 时间内检索目标值 `target` 的下标，若不存在返回 `false`；
3. 说明如何通过比较中点元素与右边界元素判定有序单调半区，并分析循环不变式。

## 解题思路

### 1. 旋转有序数组的分段单调性

一个升序数组旋转后，整体被划分为两个有序的升序子数组，且左半段的所有元素严格大于右半段的所有元素（例如 $[4,5,6,7]$ 与 $[0,1,2]$）。
当我们在区间 $[\text{left}, \text{right}]$ 中取中点 $\text{mid}$ 时：
- 若将 $\text{arr}[\text{mid}]$ 与右端点 $\text{arr}[\text{right}]$ 比较：
  - 若 $\text{arr}[\text{mid}] > \text{arr}[\text{right}]$：说明从 $\text{mid}$ 到 $\text{right}$ 发生了跌落，旋转分界点（全局最小值）必定严格位于右半区 $[\text{mid} + 1, \text{right}]$；
  - 若 $\text{arr}[\text{mid}] \le \text{arr}[\text{right}]$：说明从 $\text{mid}$ 到 $\text{right}$ 保持单调递增，旋转分界点绝不可能在 $\text{mid}$ 右侧，但 $\text{mid}$ 自身可能是最小值，故最小值落在 $[\text{left}, \text{mid}]$。

### 2. 目标值查找的局部单调分支

对于 `search_rotated`，当区间被划分后，$[\text{left}, \text{mid}]$ 与 $[\text{mid}, \text{right}]$ 中必有至少一段是严格连续单调递增的：
1. 若 $\text{arr}[\text{left}] \le \text{arr}[\text{mid}]$：说明左半段完全有序。
   - 若目标值满足 $\text{arr}[\text{left}] \le \text{target} < \text{arr}[\text{mid}]$，则目标必定在左半段，令 $\text{right} \leftarrow \text{mid} - 1$；
   - 否则必定在右半段，令 $\text{left} \leftarrow \text{mid} + 1$。
2. 若 $\text{arr}[\text{left}] > \text{arr}[\text{mid}]$：说明右半段完全有序。
   - 若目标值满足 $\text{arr}[\text{mid}] < \text{target} \le \text{arr}[\text{right}]$，令 $\text{left} \leftarrow \text{mid} + 1$；
   - 否则令 $\text{right} \leftarrow \text{mid} - 1$。

每步均将搜索范围缩减一半，且不变式始终保证目标存在于当前区间。

## C 语言实现

```c
#include <assert.h>
#include <stdbool.h>
#include <stddef.h>
#include <stdint.h>
#include <stdio.h>

bool find_min_rotated(const int64_t *arr, size_t count, int64_t *out_min) {
    if (arr == NULL || out_min == NULL || count == 0) {
        return false;
    }
    size_t left = 0;
    size_t right = count - 1;

    while (left < right) {
        size_t mid = left + (right - left) / 2;
        if (arr[mid] > arr[right]) {
            left = mid + 1;
        } else {
            right = mid;
        }
    }

    *out_min = arr[left];
    return true;
}

bool search_rotated(const int64_t *arr, size_t count, int64_t target, size_t *out_index) {
    if (arr == NULL || out_index == NULL || count == 0) {
        return false;
    }
    size_t left = 0;
    size_t right = count - 1;

    while (left <= right) {
        size_t mid = left + (right - left) / 2;
        if (arr[mid] == target) {
            *out_index = mid;
            return true;
        }

        if (arr[left] <= arr[mid]) {
            /* 左半段完全有序 */
            if (arr[left] <= target && target < arr[mid]) {
                if (mid == 0) break;
                right = mid - 1;
            } else {
                left = mid + 1;
            }
        } else {
            /* 右半段完全有序 */
            if (arr[mid] < target && target <= arr[right]) {
                left = mid + 1;
            } else {
                if (mid == 0) break;
                right = mid - 1;
            }
        }
    }

    return false;
}

int main(void) {
    int64_t rot[] = {4, 5, 6, 7, 0, 1, 2};
    size_t n = sizeof(rot) / sizeof(rot[0]);

    /* 寻找最小值 */
    int64_t min_v = 0;
    assert(find_min_rotated(rot, n, &min_v) && min_v == 0);

    /* 检索各个目标值 */
    size_t idx = 0;
    assert(search_rotated(rot, n, 0, &idx) && idx == 4);
    assert(search_rotated(rot, n, 4, &idx) && idx == 0);
    assert(search_rotated(rot, n, 2, &idx) && idx == 6);
    assert(!search_rotated(rot, n, 3, &idx));

    /* 未发生旋转的原生单调递增数组测试 */
    int64_t sorted[] = {1, 2, 3, 4, 5};
    assert(find_min_rotated(sorted, 5, &min_v) && min_v == 1);
    assert(search_rotated(sorted, 5, 3, &idx) && idx == 2);

    /* 单元素数组测试 */
    int64_t single[] = {100};
    assert(find_min_rotated(single, 1, &min_v) && min_v == 100);
    assert(search_rotated(single, 1, 100, &idx) && idx == 0);
    assert(!search_rotated(single, 1, 50, &idx));

    printf("All rotated sorted array tests passed successfully.\n");
    return 0;
}
```

## 复杂度分析

- **时间复杂度**：$\Theta(\log n)$。无论数组从哪个位置断开，中点两侧必有一半保持完美单调，每次决策只需 $O(1)$ 时间即可将候选区间砍掉一半。
- **空间复杂度**：$\Theta(1)$。仅维护常数个下标对象。

## 延伸思考 / 模式总结

旋转数组查找表明：**二分查找的核心依赖并不在于全局严格有序，而在于能够通过局部测试将解空间确定性地排除一半**。识别并利用局部的单调性分支，是拓展二分算法应用边界的核心技巧。
