# 35405 - 寻找局部峰值元素（局部二分查找）

## 题目描述

寻找局部峰值元素（局部二分查找）：

峰值元素是指其值严格大于左右相邻元素的元素。给定整数数组 `arr`，满足任意相邻元素均不相等（即 $\text{arr}[i] \ne \text{arr}[i+1]$），且假定虚拟边界 $\text{arr}[-1] = \text{arr}[n] = -\infty$。实现：

```c
#include <stdbool.h>
#include <stddef.h>
#include <stdint.h>

bool find_peak_element(
    const int64_t *arr,
    size_t count,
    size_t *out_index
);
```

要求：

1. 在 $O(\log n)$ 时间复杂度与 $O(1)$ 空间复杂度内找到任意一个局部峰值下标；
2. 证明“沿上坡梯度方向二分必然存在峰值”的单调收敛性；
3. 边界输入（单元素数组、单调递增/递减数组）的鲁棒性契约处理。

## 解题思路

### 1. 上坡梯度与峰值存在性定理

题目规定数组两端为负无穷大 $\text{arr}[-1] = \text{arr}[n] = -\infty$，且相邻元素互不相等。
考虑当前区间中点 $\text{mid}$ 与其右侧邻居 $\text{mid} + 1$：
- **情况 1（处于上坡，$\text{arr}[\text{mid}] < \text{arr}[\text{mid} + 1]$）**：
  从 $\text{mid} + 1$ 开始向右看，由于右边界为 $\text{arr}[n] = -\infty$，数值不可能一直严格上升；只要首次出现数值下降，那个转折点就是局部峰值。因此，右半区间 $[\text{mid} + 1, \text{right}]$ 中**必然存在至少一个局部峰值**，令 $\text{left} \leftarrow \text{mid} + 1$；
- **情况 2（处于下坡，$\text{arr}[\text{mid}] > \text{arr}[\text{mid} + 1]$）**：
  说明峰值要么就是 $\text{mid}$ 自身，要么位于 $\text{mid}$ 的左侧（因为左边界为 $\text{arr}[-1] = -\infty$）。因此，左半区间 $[\text{left}, \text{mid}]$ 中**必然存在至少一个局部峰值**，令 $\text{right} \leftarrow \text{mid}$。

### 2. 循环不变式与良基收敛

- **循环不变式**：在闭区间 $[\text{left}, \text{right}]$ 内，必然包含至少一个合法的局部峰值元素；
- **测度函数**：$\mu = \text{right} - \text{left}$ 严格单调递减；
- **终止状态**：当 $\text{left} == \text{right}$ 时，区间长度收缩为 1。由于不变式自始至终成立，此时唯一的下标 $\text{left}$ 必然是局部峰值。

## C 语言实现

```c
#include <assert.h>
#include <stdbool.h>
#include <stddef.h>
#include <stdint.h>
#include <stdio.h>

bool find_peak_element(const int64_t *arr, size_t count, size_t *out_index) {
    if (arr == NULL || out_index == NULL || count == 0) {
        return false;
    }
    size_t left = 0;
    size_t right = count - 1;

    while (left < right) {
        size_t mid = left + (right - left) / 2;
        if (arr[mid] < arr[mid + 1]) {
            /* 沿上坡方向探索 */
            left = mid + 1;
        } else {
            /* 沿下坡方向锁定左半区 */
            right = mid;
        }
    }

    *out_index = left;
    return true;
}

int main(void) {
    /* 1. 多峰值数组测试：可能返回下标 1 (值为 2) 或下标 5 (值为 6) */
    int64_t a1[] = {1, 2, 1, 3, 5, 6, 4};
    size_t idx = 0;
    assert(find_peak_element(a1, 7, &idx));
    assert(idx == 1 || idx == 5);

    /* 2. 单调递增数组：峰值在末尾下标 3 (值为 4) */
    int64_t a2[] = {1, 2, 3, 4};
    assert(find_peak_element(a2, 4, &idx) && idx == 3);

    /* 3. 单调递减数组：峰值在起始下标 0 (值为 4) */
    int64_t a3[] = {4, 3, 2, 1};
    assert(find_peak_element(a3, 4, &idx) && idx == 0);

    /* 4. 单元素数组 */
    int64_t a4[] = {42};
    assert(find_peak_element(a4, 1, &idx) && idx == 0);

    /* 5. 空数组与空指针前置契约防御 */
    assert(!find_peak_element(NULL, 0, &idx));
    assert(!find_peak_element(a1, 7, NULL));

    printf("All find_peak_element tests passed successfully.\n");
    return 0;
}
```

## 复杂度分析

- **时间复杂度**：$\Theta(\log n)$。区间每步严格减半，比较次数不超过 $\lceil \log_2 n \rceil$。
- **空间复杂度**：$\Theta(1)$。仅维护常数个双指针对象。

## 延伸思考 / 模式总结

本题是“**非单调数组上的二分查找**”的绝佳典范。许多初学者误以为二分查找只能应用于整体排序的序列，但只要我们能在局部通过导数/差分判定出“解必然存在的半区”（类似微积分中求根的二分法 Intermediate Value Theorem），二分思想就能发挥 $O(\log n)$ 的威力。
