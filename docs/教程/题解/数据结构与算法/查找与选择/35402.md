# 35402 - 二分上界（Upper Bound）

## 题目描述

在 `35401` 的基础上实现有序数组的二分上界查找：

```c
#include <stddef.h>
#include <stdint.h>

size_t upper_bound_i64(
    const int64_t *items,
    size_t count,
    int64_t target
);
```

`items` 按非递减顺序排列。函数返回第一个满足 `items[i] > target` 的下标；若不存在，则返回 `count`。

要求使用左闭右开的搜索区间，处理中间位置计算的溢出风险，并说明循环不变式与 $O(\log n)$ 时间复杂度。

## 解题思路

### 1. 语义差异与循环不变式

与 `lower_bound` 寻找第一个 $\ge \text{target}$ 的元素不同，`upper_bound` 寻找的是第一个**严格大于** $\text{target}$ 的元素位置。
在半开区间 $[\text{left}, \text{right})$ 下，其**循环不变式**调整为：
1. 对所有 $0 \le i < \text{left}$，恒有 $\text{items}[i] \le \text{target}$（即小于等于目标值的元素已被全部排除）；
2. 对所有 $\text{right} \le j < \text{count}$，恒有 $\text{items}[j] > \text{target}$。

### 2. 区间转移条件

计算防溢出中点 $\text{mid} = \text{left} + (\text{right} - \text{left}) / 2$：
- 若 $\text{items}[\text{mid}] \le \text{target}$：$\text{mid}$ 处的元素仍不大于目标值，不可能成为上界答案，因此令 $\text{left} \leftarrow \text{mid} + 1$；
- 若 $\text{items}[\text{mid}] > \text{target}$：$\text{mid}$ 满足严格大于条件，是潜在的候选上界，令 $\text{right} \leftarrow \text{mid}$。

当 $\text{left} == \text{right}$ 时，区间收缩完毕，返回 $\text{left}$。
目标值在已排序数组中的出现频次恰好由下式计算：

$$\text{count}(\text{target}) = \text{upper\_bound}(\text{target}) - \text{lower\_bound}(\text{target})$$

## C 语言实现

```c
#include <assert.h>
#include <stddef.h>
#include <stdint.h>
#include <stdio.h>

size_t upper_bound_i64(
    const int64_t *items,
    size_t count,
    int64_t target
) {
    size_t left = 0;
    size_t right = count;

    while (left < right) {
        size_t mid = left + (right - left) / 2;
        if (items[mid] <= target) {
            left = mid + 1;
        } else {
            right = mid;
        }
    }

    return left;
}

int main(void) {
    int64_t a[] = {10, 20, 20, 20, 30, 40};
    size_t n = sizeof(a) / sizeof(a[0]);

    /* 存在重复元素：返回最后一个 20 的后一个位置（下标 4，对应值为 30） */
    assert(upper_bound_i64(a, n, 20) == 4);

    /* 元素不存在：行为与 lower_bound 相同 */
    assert(upper_bound_i64(a, n, 25) == 4);

    /* 小于所有元素：返回 0 */
    assert(upper_bound_i64(a, n, 5) == 0);

    /* 大于或等于最大元素：返回 count */
    assert(upper_bound_i64(a, n, 40) == 6);
    assert(upper_bound_i64(a, n, 50) == 6);

    /* 空数组测试 */
    assert(upper_bound_i64(NULL, 0, 100) == 0);

    printf("All upper_bound_i64 tests passed successfully.\n");
    return 0;
}
```

## 复杂度分析

- **时间复杂度**：$\Theta(\log n)$。每轮迭代将待搜索半开区间折半，严格执行 $O(\log n)$ 次比较。
- **空间复杂度**：$\Theta(1)$。原地二分，仅使用常数个辅助对象。

## 延伸思考 / 模式总结

`lower_bound` 与 `upper_bound` 的代码仅有一处极其微小的符号差别（`items[mid] < target` 对比 `items[mid] <= target`），却精确刻画了“开区间/闭区间”对应的分界点。结合两者返回的下标半开区间 $[\text{lower\_bound}, \text{upper\_bound})$，即可在对数时间内直接提取任意元素的所有相等副本。
