# 35406 - 快速选择算法（Quickselect）期望 O(n) 时间选第 k 小元素

## 题目描述

给定可修改的整数数组和从 0 开始的顺序统计量秩 `order`，返回排序后下标为 `order` 的元素：

```c
#include <stdbool.h>
#include <stddef.h>
#include <stdint.h>

bool select_kth_i64(
    int64_t *items,
    size_t count,
    size_t order,
    int64_t *out_value
);
```

要求：

1. `order < count`；数组可以原地重排，在接口文档中明确声明这一副作用；
2. 采用荷兰国旗三路分区（Dutch National Flag 3-Way Partition），彻底消除重复相等元素导致的退化；
3. 严格证明该算法的期望时间复杂度为 $O(n)$，并分析其最坏情况时间复杂度与规避手段。

## 解题思路

### 1. 快速选择（Quickselect）原理

若要求出大小为 $n$ 的未排序数组中排在第 $k$ 位的元素（0-based 秩为 $k$），如果先完全排序再取值需 $O(n \log n)$。Tony Hoare 提出的快速选择算法利用分治思想：
- 选取一个枢轴元素 $pivot$；
- 通过分区操作将数组原地重排为三段：
  1. 小于区：`items[left..less-1] < pivot`；
  2. 等于区：`items[less..greater-1] == pivot`；
  3. 大于区：`items[greater..right-1] > pivot`。
- **降维剪枝**：
  - 若目标秩 $order < less$：目标必然在小于区，只需递归/迭代处理左半部分；
  - 若 $order \ge greater$：目标必然在大于区，只需递归/迭代处理右半部分；
  - 若 $less \le order < greater$：目标恰好等于枢轴 $pivot$，直接返回结果！

与快速排序不同，快速选择在每次划分后**只进入单侧子问题**，无需对两侧同时递归。

### 2. 三路划分避免重复键退化

经典的两路划分在面对包含大量相等元素的数组时，极易因重复划分导致子区间长度每次仅缩减 1，使得算法严重退化至 $O(n^2)$。三路划分在一次扫描中将**所有与枢轴相等的元素一次性聚拢在中间**，即使全表元素相同，仅需一次分区即可命中目标并直接终止。

### 3. 期望时间复杂度证明

在随机或中点枢轴假定下，划分规模平均大致减半：

$$T(n) \le T(n/2) + c \cdot n$$

展开等比级数：

$$T(n) \le c \cdot n + c \cdot \frac{n}{2} + c \cdot \frac{n}{4} + \dots = c \cdot n \sum_{i=0}^{\infty} \left(\frac{1}{2}\right)^i = 2c \cdot n = O(n)$$

在最坏情况下（例如每次选中的枢轴均为当前极值），递归方程变为 $T(n) = T(n - 1) + O(n)$，此时退化为 $O(n^2)$。

## C 语言实现

```c
#include <assert.h>
#include <stdbool.h>
#include <stddef.h>
#include <stdint.h>
#include <stdio.h>

static void swap_i64(int64_t *a, int64_t *b) {
    int64_t tmp = *a;
    *a = *b;
    *b = tmp;
}

bool select_kth_i64(
    int64_t *items,
    size_t count,
    size_t order,
    int64_t *out_value
) {
    if (items == NULL || out_value == NULL || count == 0 || order >= count) {
        return false;
    }

    size_t left = 0;
    size_t right = count;

    while (left < right) {
        /* 选取中点作为枢轴，避免单调序列退化 */
        size_t mid = left + (right - left) / 2;
        int64_t pivot = items[mid];

        /* 荷兰国旗三路划分 */
        size_t less = left;
        size_t scan = left;
        size_t greater = right;

        while (scan < greater) {
            if (items[scan] < pivot) {
                swap_i64(&items[less], &items[scan]);
                less++;
                scan++;
            } else if (items[scan] > pivot) {
                greater--;
                swap_i64(&items[scan], &items[greater]);
            } else {
                scan++;
            }
        }

        /* 判定目标秩 order 所在的分区区间 */
        if (order < less) {
            right = less;
        } else if (order >= greater) {
            left = greater;
        } else {
            *out_value = pivot;
            return true;
        }
    }

    return false;
}

int main(void) {
    int64_t a[] = {42, 15, 8, 42, 23, 4, 16};
    size_t n = sizeof(a) / sizeof(a[0]);
    int64_t res = 0;

    /* 升序排序后应为: 4, 8, 15, 16, 23, 42, 42 */
    assert(select_kth_i64(a, n, 0, &res) && res == 4);
    assert(select_kth_i64(a, n, 1, &res) && res == 8);
    assert(select_kth_i64(a, n, 3, &res) && res == 16);
    assert(select_kth_i64(a, n, 6, &res) && res == 42);

    /* 重复相等元素密集测试 */
    int64_t eq[] = {5, 5, 5, 5, 5};
    assert(select_kth_i64(eq, 5, 2, &res) && res == 5);

    /* 非法输入前置防御 */
    assert(!select_kth_i64(a, n, 7, &res)); // 越界
    assert(!select_kth_i64(NULL, 0, 0, &res));

    printf("All select_kth_i64 Quickselect tests passed successfully.\n");
    return 0;
}
```

## 复杂度分析

- **时间复杂度**：
  - **平均情况**：$\Theta(n)$。主定理展开为收敛公比为 $1/2$ 的等比数列；
  - **最坏情况**：$O(n^2)$。当数组已逆序且固定枢轴造成极端单侧倾斜时出现。
- **空间复杂度**：$\Theta(1)$。原地迭代改写数组，辅助空间为常数。

## 延伸思考 / 模式总结

快速选择是顺序统计量求解的工业标配（如 C++ 的 `std::nth_element`）。为了消除 $O(n^2)$ 最坏情况，理论上有中位数的中位数算法（BFPRT），工程上则常采用内省选择（Introselect，在递归深度过深时退回为堆选择或中位数选择）。
