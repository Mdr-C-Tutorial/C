# 35707 - 加油站环形循环回路存在性（贪心前缀和波谷定位）

## 题目

加油站环形循环回路存在性（贪心前缀和波谷定位）：

在一条环形公路上有 $n$ 个加油站，第 $i$ 个加油站有汽油 `gas[i]`，从第 $i$ 个加油站开往下一个加油站消耗汽油 `cost[i]`。判断是否存在一个起始加油站，使得汽车能顺时针绕环路行驶一周：

```c
#include <stddef.h>
#include <stdint.h>

int64_t can_complete_circuit(
    const int64_t *gas,
    const int64_t *cost,
    size_t n
);
```

要求：

1. 若存在解，返回起始加油站下标（保证若有解则解唯一）；若不存在返回 -1；
2. 形式化证明：环路可完成的充分必要条件为净收益总和 $\sum_{i=0}^{n-1} (\text{gas}[i] - \text{cost}[i]) \ge 0$；
3. 证明合法的唯一出发点必然位于前缀净油量和的**全局波谷（全局最小值）的下一个站点**；
4. 一次遍历完成求解，时间复杂度严格为 $\Theta(n)$，空间复杂度严格为 $O(1)$。

## 解题思路

### 1. 净收益与前缀和模型

定义站点 $i$ 到站点 $i+1$ 的净油量收益为：

$$\Delta[i] = \text{gas}[i] - \text{cost}[i]$$

行驶完一整圈回到出发点，油箱的累计净收益为环路所有站点净收益之和：

$$T = \sum_{i=0}^{n-1} \Delta[i]$$

若汽车能够顺时针环绕一周，沿途每一站汽车油箱内的油量都必须非负。

### 2. 充分必要条件与波谷定位定理

#### 定理一（必要性）
环路可完整通行的必要条件是 $T \ge 0$。

**证明**：设出发点为 $s$。汽车转完一圈回到 $s$ 时，油箱净增量为 $T$。若 $T < 0$，不论汽车从中途哪个站点出发，转完一整圈后的剩余油量必然严格小于初始油量（而初始油量为 0），这意味着中途必定存在断油点，无法跑完全程。因此必须有 $T \ge 0$。

#### 定理二（充分性与全局波谷定位）
若 $T \ge 0$，则必存在合法出发点；且以以站点 0 为基准的前缀和全局波谷（最小值点）的下一站作为出发点，必能环绕一周。

**证明**：
定义以站点 0 为起点的离散前缀和序列 $S$：

$$S[-1] = 0, \quad S[k] = \sum_{i=0}^{k} \Delta[i] \quad (0 \le k < n)$$

设 $S$ 在下标 $m \in \{0, 1, \dots, n-1\}$ 处取得全局最小值（全局波谷）：

$$\forall k \in \{0, 1, \dots, n-1\}, \quad S[m] \le S[k]$$

我们选取站点 $s = (m + 1) \bmod n$ 作为出发站点。考察从 $s$ 出发顺时针到达任意站点 $t$ 时的油箱油量：
1. **若 $t > m$**：从 $m+1$ 到 $t$ 的净油量收益为：
   $$\sum_{i=m+1}^{t} \Delta[i] = S[t] - S[m]$$
   因为 $S[m]$ 为全局最小值，所以 $S[t] \ge S[m]$，即 $S[t] - S[m] \ge 0$。
2. **若 $t \le m$**：汽车先从 $m+1$ 行驶至环尾 $n-1$，再从 0 行驶至 $t$。此时净油量收益为：
   $$\sum_{i=m+1}^{n-1} \Delta[i] + \sum_{i=0}^{t} \Delta[i] = (S[n-1] - S[m]) + S[t] = S[n-1] + (S[t] - S[m])$$
   由于 $S[n-1] = T \ge 0$，且 $S[t] - S[m] \ge 0$，两项非负项之和必然非负！

综上所述，从波谷后继站点 $m+1$ 出发，行驶到环上任意位置，累计油量恒大于等于 0，证明完毕。

### 3. 一次遍历贪心算法

我们无需显式申请数组记录全部前缀和，只需在单次线性扫描中维护两个累计对象：
- `total_tank`：记录全局总净收益 $\sum_{i=0}^{n-1} \Delta[i]$；
- `curr_tank`：记录当前候选出发点以来的累计油量。
- 一旦 `curr_tank < 0`，说明从当前候选站点出发无法越过站点 $i$（站点 $i$ 到 $i+1$ 产生欠费），根据前缀性质，区间内的任何站点都不可能作为合法出发点；因此将候选起点推移至 $i + 1$，并将 `curr_tank` 重置为 0。

遍历结束后，若 `total_tank >= 0`，则当前记录的候选起点即为合法起点；若 `total_tank < 0`，则全环油量入不敷出，返回 -1。

## C 语言实现

```c
#include <assert.h>
#include <stddef.h>
#include <stdint.h>
#include <stdio.h>

int64_t can_complete_circuit(
    const int64_t *gas,
    const int64_t *cost,
    size_t n
) {
    if (gas == NULL || cost == NULL || n == 0) {
        return -1;
    }

    int64_t total_tank = 0;
    int64_t curr_tank = 0;
    size_t start_station = 0;

    for (size_t i = 0; i < n; ++i) {
        int64_t diff = gas[i] - cost[i];
        total_tank += diff;
        curr_tank += diff;

        /* 当前油量降为负数，说明 [start_station, i] 中的任何站点都无法作为合法起点 */
        if (curr_tank < 0) {
            start_station = i + 1;
            curr_tank = 0;
        }
    }

    return (total_tank >= 0) ? (int64_t)start_station : -1;
}

int main(void) {
    /* 测试用例 1: 经典有解场景，唯一合法出发点为下标 3 */
    int64_t gas1[] = {1, 2, 3, 4, 5};
    int64_t cost1[] = {3, 4, 5, 1, 2};
    assert(can_complete_circuit(gas1, cost1, 5) == 3);

    /* 测试用例 2: 总消耗大于总补给，无解场景 */
    int64_t gas2[] = {2, 3, 4};
    int64_t cost2[] = {3, 4, 3};
    assert(can_complete_circuit(gas2, cost2, 3) == -1);

    /* 测试用例 3: 单个站点且油量充足 */
    int64_t gas3[] = {5};
    int64_t cost3[] = {4};
    assert(can_complete_circuit(gas3, cost3, 1) == 0);

    /* 测试用例 4: 单个站点油量不足 */
    int64_t gas4[] = {2};
    int64_t cost4[] = {3};
    assert(can_complete_circuit(gas4, cost4, 1) == -1);

    /* 测试用例 5: 空指针或大小为 0 的防御性检查 */
    assert(can_complete_circuit(NULL, cost1, 5) == -1);
    assert(can_complete_circuit(gas1, NULL, 5) == -1);
    assert(can_complete_circuit(gas1, cost1, 0) == -1);

    printf("All 35707 tests passed successfully.\n");
    return 0;
}
```

## 复杂度分析

- **时间复杂度**：$\Theta(n)$。算法仅需对长度为 $n$ 的环形站点数组执行一次单向遍历，循环内部只包含常数次算术运算与条件判断。
- **空间复杂度**：$O(1)$。算法仅需维护常数个标量对象（`total_tank`、`curr_tank`、`start_station`），无任何动态内存分配或额外容器开销。

## 延伸思考 / 模式总结

1. **守恒律与势能波谷**：将差值序列看作势能的离散微分，前缀和就是势能函数。在环状守恒系统中，为了确保势能处处不低于基准线，必然要将势能最低点（全局波谷）作为参照零点，将其后继作为实际起点。
2. **贪心区间的不可行跳跃**：当从 $A$ 出发在 $B$ 点首次遇到油量为负时，不仅 $A$ 不能作为起点，处于 $A$ 与 $B$ 之间的任意中间站点 $C$ 同样无法作为起点（因为从 $A$ 到 $C$ 累计油量 $\ge 0$，去掉这段正收益后从 $C$ 到 $B$ 只会更快耗尽）。这一单调性质允许我们将扫描游标直接跳跃至 $B+1$，保证了 $\Theta(n)$ 的线性复杂度。
