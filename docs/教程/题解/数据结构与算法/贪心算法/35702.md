# 35702 - 最小合并代价（哈夫曼树前缀编码）

## 题目描述

有若干堆材料，第 `i` 堆的重量为 `weights[i]`。每次可以合并两堆材料，代价等于两堆重量之和。实现求合并成一堆所需的最小总代价：

```c
#include <stdbool.h>
#include <stddef.h>
#include <stdint.h>

bool minimum_merge_cost(
    const uint64_t *weights,
    size_t count,
    uint64_t *out_cost
);
```

要求：

1. `count == 0` 或 `count == 1` 时总代价为 0；非空数组指针必须有效。
2. 不得修改输入数组；任意中间代价或总代价无法用 `uint64_t` 表示时返回 `false`，输出对象保持不变。
3. 每次选择当前最小的两堆合并，并使用优先队列实现 $O(n\log n)$ 时间复杂度。
4. 说明“先合并最小两项”为什么不会破坏最优性。

## 解题思路

### 1. 二叉合并树与带权路径长度（WPL）

$n$ 堆材料的两两合并过程，等价于构建一棵以这 $n$ 堆材料初始重量为叶节点的二叉树。
每次合并两个节点（权重为 $x$ 与 $y$），产生一个权重为 $x + y$ 的父节点。
递归累加所有合并代价的总和，恰好等于所有初始叶节点的**带权路径长度（Weighted Path Length, WPL）**：

$$\text{Total Cost} = \sum_{i=1}^{n} w_i \cdot d_i$$

其中 $d_i$ 是第 $i$ 个叶节点在合并二叉树中的深度（即该堆材料参与合并的总次数）。

### 2. 交换论证法证明贪心选择性质

要使 $\sum w_i d_i$ 最小化：
直观上，权重 $w_i$ 越大的材料，其深度 $d_i$ 应该越小（参与合并的次数越少）；反之，权重最小的材料应该位于树的最底层（深度最大）。

**交换论证**：
设在某个最优合并树 $T$ 中，深度最大的两个兄弟叶节点分别为 $u$ 和 $v$。
设整个数据集中权重最小的两堆材料分别为 $x$ 和 $y$。
- 若 $\{x, y\} = \{u, v\}$，则贪心选择已经在最优解中；
- 若 $x$ 不在最底层（$d(x) < d(u)$）：
  在树 $T$ 中交换 $x$ 与 $u$ 的位置，构造新树 $T'$。树的带权路径长度变化量为：
  $$\Delta \text{WPL} = w_x \cdot d(u) + w_u \cdot d(x) - (w_x \cdot d(x) + w_u \cdot d(u)) = (w_x - w_u)(d(u) - d(x))$$
  由于 $x$ 是全局最小项，故 $w_x \le w_u$（即 $w_x - w_u \le 0$）；又因为 $u$ 位于最底层，故 $d(u) \ge d(x)$（即 $d(u) - d(x) \ge 0$）。
  因此乘积必有：
  $$\Delta \text{WPL} \le 0$$
  这说明交换后总代价没有增加，$T'$ 依然是最优合并树！同理可以将 $y$ 交换至最底层作为 $x$ 的兄弟节点。
- 这证明了：**必然存在一棵最优合并树，其中全局最小的两堆材料是最底层的兄弟节点（即它们在第一步被优先合并）**。贪心选择性质成立。

### 3. 小根堆与溢出防护

维护一个大小为 $n$ 的小根堆（Min-Heap）：
每轮循环弹出堆顶最小的两项 $x$ 和 $y$，在相加前使用 `x > UINT64_MAX - y` 进行溢出检查；随后将新重量 $x + y$ 压入小根堆，并将 $x + y$ 安全累加至总代价。

## C 语言实现

```c
#include <assert.h>
#include <stdbool.h>
#include <stddef.h>
#include <stdint.h>
#include <stdio.h>
#include <stdlib.h>

static void swap_u64(uint64_t *a, uint64_t *b) {
    uint64_t tmp = *a;
    *a = *b;
    *b = tmp;
}

static void sift_down(uint64_t *heap, size_t size, size_t i) {
    while (i * 2 + 1 < size) {
        size_t left = i * 2 + 1;
        size_t right = left + 1;
        size_t smallest = i;

        if (heap[left] < heap[smallest]) {
            smallest = left;
        }
        if (right < size && heap[right] < heap[smallest]) {
            smallest = right;
        }
        if (smallest == i) {
            break;
        }
        swap_u64(&heap[i], &heap[smallest]);
        i = smallest;
    }
}

static void push_min(uint64_t *heap, size_t *size, uint64_t val) {
    size_t i = (*size)++;
    heap[i] = val;
    while (i > 0) {
        size_t p = (i - 1) / 2;
        if (heap[p] <= heap[i]) {
            break;
        }
        swap_u64(&heap[p], &heap[i]);
        i = p;
    }
}

static uint64_t pop_min(uint64_t *heap, size_t *size) {
    uint64_t ret = heap[0];
    heap[0] = heap[--*size];
    sift_down(heap, *size, 0);
    return ret;
}

bool minimum_merge_cost(
    const uint64_t *weights,
    size_t count,
    uint64_t *out_cost
) {
    if (out_cost == NULL || (count > 0 && weights == NULL)) {
        return false;
    }
    if (count <= 1) {
        *out_cost = 0;
        return true;
    }
    if (count > SIZE_MAX / sizeof(uint64_t)) {
        return false;
    }

    uint64_t *heap = malloc(count * sizeof(uint64_t));
    if (heap == NULL) {
        return false;
    }

    /* 线性建堆 O(n) */
    for (size_t i = 0; i < count; ++i) {
        heap[i] = weights[i];
    }
    for (size_t i = count / 2; i > 0; --i) {
        sift_down(heap, count, i - 1);
    }

    size_t heap_size = count;
    uint64_t total = 0;

    while (heap_size > 1) {
        uint64_t x = pop_min(heap, &heap_size);
        uint64_t y = pop_min(heap, &heap_size);

        /* 溢出防范：两数相加溢出 */
        if (x > UINT64_MAX - y) {
            free(heap);
            return false;
        }
        uint64_t sum = x + y;

        /* 溢出防范：总代价累加溢出 */
        if (total > UINT64_MAX - sum) {
            free(heap);
            return false;
        }
        total += sum;

        push_min(heap, &heap_size, sum);
    }

    free(heap);
    *out_cost = total;
    return true;
}

int main(void) {
    /*
     * 材料 [1, 2, 3, 4, 5]:
     * 1) 1 + 2 = 3, 代价 3, 剩余 [3, 3, 4, 5]
     * 2) 3 + 3 = 6, 代价 6, 剩余 [4, 5, 6]
     * 3) 4 + 5 = 9, 代价 9, 剩余 [6, 9]
     * 4) 6 + 9 = 15, 代价 15, 剩余 [15]
     * 总代价 = 3 + 6 + 9 + 15 = 33
     */
    uint64_t w[] = {1, 2, 3, 4, 5};
    uint64_t ans = 0;
    assert(minimum_merge_cost(w, 5, &ans) && ans == 33);

    /* 边界情况：0 堆或 1 堆无需合并 */
    assert(minimum_merge_cost(w, 0, &ans) && ans == 0);
    assert(minimum_merge_cost(w, 1, &ans) && ans == 0);

    /* 大数溢出安全拦截 */
    uint64_t big[] = {UINT64_MAX - 10, UINT64_MAX - 20};
    assert(!minimum_merge_cost(big, 2, &ans));

    printf("All minimum_merge_cost tests passed successfully.\n");
    return 0;
}
```

## 复杂度分析

- **时间复杂度**：$O(n \log n)$。自底向上建堆为 $O(n)$，循环执行 $n - 1$ 次，每次执行两次弹出与一次插入（每次耗时 $O(\log n)$），总时间复杂度为 $\Theta(n \log n)$。
- **空间复杂度**：$O(n)$。需要大小为 $n$ 的小根堆数组缓冲区。

## 延伸思考 / 模式总结

最小合并代价问题与 David Huffman 在 1952 年发明的数据压缩**哈夫曼编码（Huffman Coding）**在数学结构上完全一致：字符出现频次越低，编码长度越长；频次越高，编码长度越短，从而使文本传输的总比特数达到香农信息论极限。
