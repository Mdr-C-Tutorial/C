# 35706 - 无重叠区间移除计数（区间调度对偶问题）

## 题目

无重叠区间移除计数（区间调度对偶问题）：

给定若干区间，求最少需要移除多少个区间，才能使剩余的区间两两互不重叠：

```c
#include <stdbool.h>
#include <stddef.h>
#include <stdint.h>

typedef struct {
    int64_t start;
    int64_t end;
} Interval;

bool min_intervals_erase_overlap(
    Interval *items,
    size_t count,
    size_t *out_erased
);
```

要求：

1. 阐述该问题与“最大不重叠区间调度（习题 35701）”的数学对偶关系；
2. 证明：最少移除区间数 = 总区间数 - 最大不重叠区间数；
3. 实现算法，时间复杂度满足 $O(n \log n)$，额外空间为 $O(1)$。

## 解题思路

### 1. 数学对偶（Mathematical Duality）转化

设全量区间集合为 $S$，包含 $n = |S|$ 个区间。
我们希望选出一个子集 $R \subseteq S$ 将其移除，使得剩余子集 $K = S \setminus R$ 中的区间两两互不重叠，并使得 $|R|$ 最小化。
根据集合代数关系：

$$|R| = |S| - |K| = n - |K|$$

由于总数 $n$ 是固定不变的常数，**使移除数量 $|R|$ 最小化，完全等价于使保留数量 $|K|$ 最大化**！
因此，“最少移除区间问题”与“最大不重叠区间调度问题（习题 35701）”是严格的一对一数学对偶问题。
我们只需调用贪心策略选出**最大不重叠区间数 $k$**，最终答案即为 $n - k$。

### 2. 贪心算法执行流程

1. 按照区间的**结束时间 $end$ 升序**排列；
2. 线性扫描：
   - 记录上一个保留区间的结束时刻 $last\_end$；
   - 遍历后续每个区间：若其开始时间 $start \ge last\_end$，则保留该区间，并更新 $last\_end \leftarrow end$；
   - 若 $start < last\_end$，说明发生重叠，根据贪心最优性，该区间必须被移除（移除计数器递增）；
3. 遍历结束，输出被移除的区间总数。

## C 语言实现

```c
#include <assert.h>
#include <stdbool.h>
#include <stddef.h>
#include <stdint.h>
#include <stdio.h>
#include <stdlib.h>

typedef struct {
    int64_t start;
    int64_t end;
} Interval;

static int cmp_interval_end(const void *a, const void *b) {
    const Interval *ia = (const Interval *)a;
    const Interval *ib = (const Interval *)b;

    if (ia->end != ib->end) {
        return (ia->end > ib->end) - (ia->end < ib->end);
    }
    return (ia->start > ib->start) - (ia->start < ib->start);
}

bool min_intervals_erase_overlap(
    Interval *items,
    size_t count,
    size_t *out_erased
) {
    if (out_erased == NULL || (count > 0 && items == NULL)) {
        return false;
    }

    /* 前置合法性检查：start 必须小于 end */
    for (size_t i = 0; i < count; ++i) {
        if (items[i].start >= items[i].end) {
            return false;
        }
    }

    if (count <= 1) {
        *out_erased = 0;
        return true;
    }

    /* 按结束时间升序排序 */
    qsort(items, count, sizeof(Interval), cmp_interval_end);

    size_t retained = 1;
    int64_t last_end = items[0].end;

    for (size_t i = 1; i < count; ++i) {
        if (items[i].start >= last_end) {
            retained++;
            last_end = items[i].end;
        }
    }

    /* 对偶公式：最少移除数 = 总数 - 最大保留数 */
    *out_erased = count - retained;
    return true;
}

int main(void) {
    /* 1. 测试用例：[1,2], [2,3], [3,4], [1,3] -> 移除 [1,3] 即可，返回 1 */
    Interval ivs1[] = {{1, 2}, {2, 3}, {3, 4}, {1, 3}};
    size_t erased = 0;
    assert(min_intervals_erase_overlap(ivs1, 4, &erased) && erased == 1);

    /* 2. 完全重叠区间：[1,2], [1,2], [1,2] -> 需移除 2 个 */
    Interval ivs2[] = {{1, 2}, {1, 2}, {1, 2}};
    assert(min_intervals_erase_overlap(ivs2, 3, &erased) && erased == 2);

    /* 3. 本身已互不重叠：需移除 0 个 */
    Interval ivs3[] = {{1, 2}, {2, 3}};
    assert(min_intervals_erase_overlap(ivs3, 2, &erased) && erased == 0);

    /* 4. 空数组与单元素边界 */
    assert(min_intervals_erase_overlap(NULL, 0, &erased) && erased == 0);
    Interval single[] = {{10, 20}};
    assert(min_intervals_erase_overlap(single, 1, &erased) && erased == 0);

    printf("All min_intervals_erase_overlap tests passed successfully.\n");
    return 0;
}
```

## 复杂度分析

- **时间复杂度**：$O(n \log n)$。瓶颈在于对 $n$ 个区间按结束时间排序，后续一次线性遍历仅耗费 $\Theta(n)$。
- **空间复杂度**：$O(1)$。原地重排，使用常数个辅助标量对象。

## 延伸思考 / 模式总结

在最优化算法设计中，“**正向最大化**”与“**反向最小化**”常常互为对偶表里。当你面对一个看似复杂的“最少删除/剔除”问题时，不妨逆向思考其补集：“在原集合中最多能够合法保留多少元素？”这种对偶转化往往能瞬间将新问题规约到已知的经典贪心模型中。
