# 35705 - 跳跃游戏（最小跳跃步数与贪心最远边界）

## 题目描述

给定非负整数数组 `nums`，每个元素代表在当前位置可以向后跳跃的最大步长。求从下标 0 出发跳跃至最后下标的最少跳跃次数：

```c
#include <stdbool.h>
#include <stddef.h>

bool jump_game_min_jumps(
    const size_t *nums,
    size_t n,
    size_t *out_jumps
);
```

要求：

1. 维护当前跳跃步数下能够到达的最远边界 `current_end` 与下一步探索中发现的全局最远边界 `farthest`；
2. 若当前遍历游标到达 `current_end`，则步数自增且更新 `current_end = farthest`；
3. 严格证明该局部贪心扩张策略能产出全局最少步数；若无法到达末尾返回 `false`；
4. 算法时间复杂度为 $\Theta(n)$，空间复杂度为 $O(1)$。

## 解题思路

### 1. 广度优先搜索（BFS）的分层贪心投影

将跳跃过程抽象为图上的单源最短路径。从起点 $0$ 出发：
- 跳 1 步能到达的所有位置构成第 1 层；
- 从第 1 层的所有节点出发能跳到的所有新位置构成第 2 层；
- 依次类推，第 $k$ 层的最右端点即为**跳 $k$ 步所能到达的最远右边界**。
由于从任何点出发都可以跳跃 $1 \dots nums[i]$ 步，任意一层能覆盖的到达点必然是一个**连续前缀区间** $[0, current\_end]$。因此我们根本不需要使用队列进行完整的图 BFS，只需用贪心双指针记录当前层的右边界即可！

### 2. 双指针贪心边界推进

遍历下标 $i$ 从 $0$ 到 $n - 2$：
1. **探索最远边界**：对遍历到的每个位置 $i$，计算从该点能够跳达的局部最远点 $i + nums[i]$，更新全局探明最远边界：
   $$farthest \leftarrow \max(farthest, i + nums[i])$$
2. **步数结算点**：当游标 $i$ 到达当前这一跳的边界 $current\_end$ 时：
   - 意味着第 $k$ 步的所有潜在落脚点已被全部勘探完毕；
   - 必须多跳一步（$jumps \leftarrow jumps + 1$）；
   - 下一步的覆盖范围拓展至已勘探出的最远边界：$current\_end \leftarrow farthest$；
   - 若此时 $current\_end \ge n - 1$，说明已经能够覆盖终点，可提前退出。
3. **不可达断言**：若在某个时刻 $i \ge farthest$ 且 $current\_end < n - 1$，说明遇到“零步长死胡同”，无法继续向右跃迁，直接返回 `false`。

### 3. 最少步数的最优性归纳

**数学归纳法**：
- 设跳 $\le k$ 步所能到达的最远位置为 $R_k$。
- 根据定义，跳 $k + 1$ 步能到达的任意位置 $y$ 必定满足存在某个 $x \le R_k$ 使得 $y \le x + nums[x]$。
- 因此跳 $k + 1$ 步能到达的最远位置 $R_{k+1}$ 严格等于 $\max_{0 \le x \le R_k} (x + nums[x])$。
- 算法维护的 $farthest$ 恰好在 $i = current\_end$ 时求出了这个确切的最大值。因此算法计算的每一步右边界均为全局不可逾越的理论物理极限，最终得出的跳跃次数必然全局最少。

## C 语言实现

```c
#include <assert.h>
#include <stdbool.h>
#include <stddef.h>
#include <stdio.h>

bool jump_game_min_jumps(
    const size_t *nums,
    size_t n,
    size_t *out_jumps
) {
    if (out_jumps == NULL || (n > 0 && nums == NULL)) {
        return false;
    }
    if (n <= 1) {
        *out_jumps = 0; /* 起点即终点，无需跳跃 */
        return true;
    }

    size_t jumps = 0;
    size_t current_end = 0;
    size_t farthest = 0;

    /* 仅需遍历到 n - 2，若遍历到 n - 1 会多计入一次无意义的边界结算 */
    for (size_t i = 0; i < n - 1; ++i) {
        if (i + nums[i] > farthest) {
            farthest = i + nums[i];
        }

        /* 遇到断崖无法继续前进 */
        if (i >= farthest) {
            return false;
        }

        /* 结算当前跳步边界 */
        if (i == current_end) {
            jumps++;
            current_end = farthest;
            if (current_end >= n - 1) {
                break;
            }
        }
    }

    if (current_end < n - 1) {
        return false;
    }

    *out_jumps = jumps;
    return true;
}

int main(void) {
    /* 1. 经典跳跃用例：[2, 3, 1, 1, 4] -> 最少 2 步 (0 -> 1 -> 4) */
    size_t nums1[] = {2, 3, 1, 1, 4};
    size_t jumps = 0;
    assert(jump_game_min_jumps(nums1, 5, &jumps) && jumps == 2);

    /* 2. 无法到达终点的陷阱数组测试：[3, 2, 1, 0, 4] -> 停滞在下标 3 无法逾越 */
    size_t nums2[] = {3, 2, 1, 0, 4};
    assert(!jump_game_min_jumps(nums2, 5, &jumps));

    /* 3. 一步直达测试 */
    size_t nums3[] = {10, 1, 1};
    assert(jump_game_min_jumps(nums3, 3, &jumps) && jumps == 1);

    /* 4. 单元素边界（起点即终点） */
    size_t nums4[] = {0};
    assert(jump_game_min_jumps(nums4, 1, &jumps) && jumps == 0);

    /* 5. 空指针前置拦截 */
    assert(!jump_game_min_jumps(NULL, 0, &jumps));

    printf("All jump_game_min_jumps tests passed successfully.\n");
    return 0;
}
```

## 复杂度分析

- **时间复杂度**：$\Theta(n)$。游标仅需线性扫描数组一遍，各步骤均为常数阶比较。
- **空间复杂度**：$\Theta(1)$。仅维护常数个计数器与指针标量。

## 延伸思考 / 模式总结

跳跃游戏展示了“**将隐式图的最短路退化为单调区间扩张**”的高阶建模技巧。当图的邻接边具有连续区间性时，往往无需运行 Dijkstra 或显式队列 BFS，而可以直接用贪心边界跟踪将复杂度压榨至理论极限 $O(n)$。
