# 35701 - 最多不重叠区间调度（最多可看电影）

## 题目描述

电影院在同一个放映厅安排了若干部电影。每部电影用半开区间 `[start, end)` 表示，实现：

```c
#include <stdbool.h>
#include <stddef.h>
#include <stdint.h>

typedef struct {
    int64_t start;
    int64_t end;
} Movie;

bool maximum_movie_count(
    Movie *movies,
    size_t count,
    size_t *out_count
);
```

要求：

1. 求一个人从头到尾能够观看的最多电影数量；一部电影结束时可以立即观看此时开始的另一部电影。
2. 每个区间必须满足 `start < end`；先检查全部区间，再修改数组。
3. 可以使用 `qsort` 原地重排输入数组，并在接口说明中明确这一点。
4. 比较器不得用两个时间直接相减来决定顺序。
5. 参数无效时返回 `false`，并保持输出对象和电影数组不变。
6. 排序后使用一次线性扫描完成选择，总时间复杂度为 $O(n\log n)$。

## 解题思路

### 1. 贪心策略：最早结束时间优先（Earliest Deadline First）

在区间调度问题中，直觉上可能存在多种贪心策略：
- 按开始时间最早：容易被一个跨度极长、从早演到晚的电影破坏；
- 按持续时间最短：可能被两端各跨越一段的电影破坏；
- **按结束时间最早**：每次选择结束时间最早的合法电影，能够**为后续留出尽可能充裕的时间空间**。这一策略具有严格的贪心选择性质。

### 2. 交换论证法（Exchange Argument）证明

设全局最优解按时间先后顺序选出的区间序列为 $O = \langle o_1, o_2, \dots, o_m \rangle$。
设贪心算法按结束时间最早选出的第一个区间为 $g_1$。
- 根据贪心选择，$g_1$ 是所有可用区间中结束时间最早者，因此必有：
  $$end(g_1) \le end(o_1)$$
- 在最优解 $O$ 中，用 $g_1$ 替换掉 $o_1$，构造新解 $O' = \langle g_1, o_2, \dots, o_m \rangle$：
  由于 $end(g_1) \le end(o_1) \le start(o_2)$，新首项 $g_1$ 与原最优解中的后续区间 $o_2, o_3, \dots$ 互不重叠！
  新解 $O'$ 的区间数量同样为 $m$，因而 $O'$ 也是一个全局最优解。
- 这证明了：**必存在一个包含贪心选择 $g_1$ 的全局最优解**（贪心选择性质成立）。通过对剩余子问题重复此论证，归纳可知贪心策略产生的解必为全局最优解。

### 3. 比较器防溢出规范

在为 `qsort` 编写回调函数时，禁止写成 `a->end - b->end`。如果一个电影结束时间为 `INT64_MAX`，另一个为 `-1`，相减直接导致有符号溢出未定义行为。标准安全写法为：

```c
return (a->end > b->end) - (a->end < b->end);
```

## C 语言实现

```c
#include <assert.h>
#include <stdbool.h>
#include <stddef.h>
#include <stdint.h>
#include <stdio.h>
#include <stdlib.h>

typedef struct {
    int64_t start;
    int64_t end;
} Movie;

static int compare_movies(const void *a, const void *b) {
    const Movie *ma = (const Movie *)a;
    const Movie *mb = (const Movie *)b;

    if (ma->end != mb->end) {
        return (ma->end > mb->end) - (ma->end < mb->end);
    }
    return (ma->start > mb->start) - (ma->start < mb->start);
}

bool maximum_movie_count(
    Movie *movies,
    size_t count,
    size_t *out_count
) {
    if (out_count == NULL || (count > 0 && movies == NULL)) {
        return false;
    }

    /* 前置契约校验：必须先检查全部区间合法性，再改动数组 */
    for (size_t i = 0; i < count; ++i) {
        if (movies[i].start >= movies[i].end) {
            return false;
        }
    }

    if (count == 0) {
        *out_count = 0;
        return true;
    }

    /* 按结束时间升序排列 */
    qsort(movies, count, sizeof(Movie), compare_movies);

    size_t selected = 1;
    int64_t last_end = movies[0].end;

    /* 贪心线性扫描 */
    for (size_t i = 1; i < count; ++i) {
        if (movies[i].start >= last_end) {
            selected++;
            last_end = movies[i].end;
        }
    }

    *out_count = selected;
    return true;
}

int main(void) {
    /* 1. 经典区间调度测试 */
    Movie list[] = {
        {1, 4}, {3, 5}, {0, 6}, {5, 7}, {8, 9}, {5, 9}
    };
    size_t count = 0;
    assert(maximum_movie_count(list, 6, &count) && count == 3);

    /* 2. 刚好首尾相连边界测试：[1, 3) 与 [3, 5) 可以连续观看 */
    Movie touching[] = {{1, 3}, {3, 5}};
    assert(maximum_movie_count(touching, 2, &count) && count == 2);

    /* 3. 非法区间前置拦截（start >= end），数组保持不变 */
    Movie invalid[] = {{5, 2}};
    assert(!maximum_movie_count(invalid, 1, &count));

    /* 4. 空数组测试 */
    assert(maximum_movie_count(NULL, 0, &count) && count == 0);

    printf("All maximum_movie_count tests passed successfully.\n");
    return 0;
}
```

## 复杂度分析

- **时间复杂度**：$O(n \log n)$。排序耗费 $O(n \log n)$，后续线性贪心扫描仅耗费 $\Theta(n)$。
- **空间复杂度**：$O(1)$ 或 $O(\log n)$（取决于标准库 `qsort` 的递归栈开销）。

## 延伸思考 / 模式总结

最多不重叠区间调度是贪心算法中最具代表性的“**最早截止时间优先（EDF）**”模型。交换论证法是证明贪心选择性质的标准数学模板：通过证明“用贪心选择替换最优解的第一步选择，解的质量绝不下降”，为后续子问题归纳铺平道路。
