# 35703 - 区间分组与最少资源分配（会议室分配）

## 题目描述

有若干任务，每个任务占用半开时间区间 `[start, end)`。实现安排这些任务所需的最少资源数量；同一资源上的任务不能重叠：

```c
#include <stdbool.h>
#include <stddef.h>
#include <stdint.h>

typedef struct {
    int64_t start;
    int64_t end;
} ResourceTask;

bool minimum_resource_count(
    ResourceTask *tasks,
    size_t count,
    size_t *out_resources
);
```

要求：

1. `start < end`；结束时刻等于下一任务开始时刻时可以复用资源。
2. 先检查全部区间，再修改任务数组；参数无效时输出对象和任务数组均保持不变。
3. 以开始时刻排序，并用保存当前最早结束时刻的最小堆计算峰值并发数。
4. 比较器不得通过两个 `int64_t` 直接相减决定顺序，时间复杂度为 $O(n\log n)$。

## 解题思路

### 1. 区间分组与峰值并发重叠数

给定一组时间区间，要求将其划分为若干组，使同一组内的区间两两不重叠。
数学上，**最少所需的分组数（资源数/会议室数），精确等于任意时刻的最大并发重叠区间数量（Peak Concurrency）**。

### 2. 贪心策略：开始时间优先 + 小根堆维护最早释放资源

1. **按开始时间升序排列**：按时间先后顺序考虑每一个待分配的任务 $[s_i, e_i)$；
2. **小根堆维护活跃资源**：小根堆中的每个元素代表一台当前正在运行任务的资源的“结束时刻”。堆顶即为**最早空闲出来的资源的结束时刻**；
3. **分配决策**：
   - 若堆非空，且堆顶元素 $\le s_i$：说明最早空闲的这台资源在 $s_i$ 之前或恰好此时已经完成前序任务，可以**复用该资源**！弹出旧结束时刻，将该任务的结束时刻 $e_i$ 压入堆中；
   - 否则（堆为空，或最早空闲资源的结束时刻仍 $> s_i$）：说明当前所有已分配的资源均处于繁忙状态，必须**新开辟一台资源**，直接将 $e_i$ 压入堆中。
4. 遍历结束时，堆中的元素个数（或历史最大堆规模）即为所需的最少资源总数。

### 3. 最优性证明

设贪心算法最终分配了 $d$ 台资源。
当分配第 $d$ 台资源时，必然存在某个任务 $[s_k, e_k)$，在此时堆中已有 $d - 1$ 台资源的结束时刻均严格大于 $s_k$。
这意味着这 $d - 1$ 个任务与当前第 $d$ 个任务在时刻 $s_k$ 同时处于进行状态，即时刻 $s_k$ 存在 $d$ 个相互重叠的区间！
由于任何合法分配方案都不可能让重叠任务共用同一资源，因此任意方案所需的资源数至少为 $d$。故贪心分配的 $d$ 必然是全局最优解。

## C 语言实现

```c
#include <assert.h>
#include <stdbool.h>
#include <stddef.h>
#include <stdint.h>
#include <stdio.h>
#include <stdlib.h>

typedef struct {
    int64_t start;
    int64_t end;
} ResourceTask;

static int compare_tasks(const void *a, const void *b) {
    const ResourceTask *ta = (const ResourceTask *)a;
    const ResourceTask *tb = (const ResourceTask *)b;

    if (ta->start != tb->start) {
        return (ta->start > tb->start) - (ta->start < tb->start);
    }
    return (ta->end > tb->end) - (ta->end < tb->end);
}

static void swap_i64(int64_t *a, int64_t *b) {
    int64_t tmp = *a;
    *a = *b;
    *b = tmp;
}

static void heap_sift_down(int64_t *heap, size_t size, size_t i) {
    while (i * 2 + 1 < size) {
        size_t left = i * 2 + 1;
        size_t right = left + 1;
        size_t smallest = i;

        if (heap[left] < heap[smallest]) {
            smallest = left;
        }
        if (right < size && heap[right] < heap[smallest]) {
            smallest = right;
        }
        if (smallest == i) {
            break;
        }
        swap_i64(&heap[i], &heap[smallest]);
        i = smallest;
    }
}

static void heap_push(int64_t *heap, size_t *size, int64_t val) {
    size_t i = (*size)++;
    heap[i] = val;
    while (i > 0) {
        size_t p = (i - 1) / 2;
        if (heap[p] <= heap[i]) {
            break;
        }
        swap_i64(&heap[p], &heap[i]);
        i = p;
    }
}

static void heap_pop(int64_t *heap, size_t *size) {
    heap[0] = heap[--*size];
    heap_sift_down(heap, *size, 0);
}

bool minimum_resource_count(
    ResourceTask *tasks,
    size_t count,
    size_t *out_resources
) {
    if (out_resources == NULL || (count > 0 && tasks == NULL)) {
        return false;
    }

    /* 前置契约校验：必须先检查全部区间合法性 */
    for (size_t i = 0; i < count; ++i) {
        if (tasks[i].start >= tasks[i].end) {
            return false;
        }
    }

    if (count == 0) {
        *out_resources = 0;
        return true;
    }

    if (count > SIZE_MAX / sizeof(int64_t)) {
        return false;
    }

    int64_t *heap = malloc(count * sizeof(int64_t));
    if (heap == NULL) {
        return false;
    }

    /* 按开始时间升序排列 */
    qsort(tasks, count, sizeof(ResourceTask), compare_tasks);

    size_t heap_size = 0;
    size_t max_concurrent = 0;

    for (size_t i = 0; i < count; ++i) {
        /* 将所有在当前任务开始前已结束的资源释放出堆 */
        while (heap_size > 0 && heap[0] <= tasks[i].start) {
            heap_pop(heap, &heap_size);
        }
        /* 将当前任务结束时刻压入堆 */
        heap_push(heap, &heap_size, tasks[i].end);

        if (heap_size > max_concurrent) {
            max_concurrent = heap_size;
        }
    }

    free(heap);
    *out_resources = max_concurrent;
    return true;
}

int main(void) {
    /* 1. 经典会议室分配测试 */
    ResourceTask tasks[] = {
        {1, 4}, {2, 5}, {4, 6}, {6, 8}
    };
    size_t res = 0;
    /*
     * [1, 4) 与 [2, 5) 重叠 -> 需要 2 台
     * [4, 6) 可以复用第 1 台（4 >= 4）
     * [6, 8) 可以复用已结束资源
     * 峰值并发为 2
     */
    assert(minimum_resource_count(tasks, 4, &res) && res == 2);

    /* 2. 互不重叠链式任务：只需 1 台资源 */
    ResourceTask seq[] = {{1, 2}, {2, 3}, {3, 4}};
    assert(minimum_resource_count(seq, 3, &res) && res == 1);

    /* 3. 完全包含重叠任务：需要 3 台资源 */
    ResourceTask overlap[] = {{1, 10}, {2, 9}, {3, 8}};
    assert(minimum_resource_count(overlap, 3, &res) && res == 3);

    /* 4. 空数组与非法输入 */
    assert(minimum_resource_count(NULL, 0, &res) && res == 0);
    ResourceTask bad[] = {{5, 3}};
    assert(!minimum_resource_count(bad, 1, &res));

    printf("All minimum_resource_count tests passed successfully.\n");
    return 0;
}
```

## 复杂度分析

- **时间复杂度**：$O(n \log n)$。对 $n$ 个任务排序耗费 $O(n \log n)$；遍历过程中每个任务至多入堆一次、出堆一次，堆操作总耗时为 $O(n \log n)$。
- **空间复杂度**：$O(n)$。需要大小为 $n$ 的小根堆缓冲区。

## 延伸思考 / 模式总结

与“最多不重叠区间调度（35701，按结束时间排序）”不同，“区间分组/最少资源”**必须按开始时间排序**。两者的区别在于：35701 是要在单一时间轴上尽可能多地安插区间（选谁放弃谁）；而 35703 必须安排全部任务，核心是模拟真实时间推进过程中各活跃资源的状态流转。
