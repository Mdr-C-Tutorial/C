# 35708 - 拟阵（Matroid）与贪心选择性质的形式化证明

## 题目描述

拟阵是定义在有限子集系统上的代数结构，为贪心算法提供统一的理论框架。

1. 形式化给出拟阵 $M = (S, \mathcal{I})$ 的三条公理：非空性、遗传性（Hereditary Property）与交换性（Exchange Property / Augmentation Property）；
2. 证明 Rado-Edmonds 定理：对有限子集系统赋予任意正权函数，贪心算法总能找到具有最大权值的基（极大独立集），当且仅当该系统是一个拟阵；
3. 将最小生成树问题形式化为图拟阵（Graphic Matroid），并使用拟阵理论证明 Kruskal 算法贪心选择的全局最优性；
4. 编写 C 语言通用的拟阵贪心算法求解框架，并在图拟阵上测试验证。

## 解题思路

### 1. 拟阵（Matroid）的形式化公理体系

设 $S$ 为有限集合（称为基础集，Ground Set），$\mathcal{I}$ 为 $S$ 的子集族（即 $\mathcal{I} \subseteq 2^S$）。有序对 $M = (S, \mathcal{I})$ 称为一个**拟阵**，当且仅当满足以下三条公理：

1. **非空性（Non-emptiness）**：
   $$\emptyset \in \mathcal{I}$$
2. **遗传性（Hereditary Property）**：
   $$\forall B \in \mathcal{I}, \quad A \subseteq B \implies A \in \mathcal{I}$$
   属于 $\mathcal{I}$ 的子集称为 $M$ 的**独立集（Independent Set）**。
3. **交换性 / 增广性（Exchange Property / Augmentation Property）**：
   $$\forall A, B \in \mathcal{I}, \quad |A| < |B| \implies \exists x \in B \setminus A \text{ 使得 } A \cup \{x\} \in \mathcal{I}$$

由交换公理可直接得出重要推论：**拟阵中所有的极大独立集（称为基，Base）都具有相同大小**。该固定大小称为拟阵的**秩（Rank）**，记作 $r(M)$。

### 2. Rado-Edmonds 定理与贪心最优性证明

赋予基础集中每个元素非负权值 $w: S \to \mathbb{R}^+$。独立集的权值定义为其包含元素的权值和：$w(I) = \sum_{x \in I} w(x)$。
拟阵贪心算法先将 $S$ 中元素按权值降序排列，初始化独立集 $A = \emptyset$，随后依次考查元素：若加入后仍然保持独立，则并入 $A$。

#### 充分性证明（若 $M$ 是拟阵，则贪心算法必得最大权基）
设拟阵的秩为 $r$。贪心算法选出的序列为 $A = \{a_1, a_2, \dots, a_r\}$，且由贪心选择顺序可知：

$$w(a_1) \ge w(a_2) \ge \dots \ge w(a_r)$$

假设存在另一个基 $B = \{b_1, b_2, \dots, b_r\}$，其元素权值降序排列 $w(b_1) \ge w(b_2) \ge \dots \ge w(b_r)$，且总权值严格大于贪心解：$w(B) > w(A)$。
则必定存在某个最小下标 $k \in \{1, 2, \dots, r\}$，满足：

$$w(b_k) > w(a_k)$$

构造前缀集合：
- $A_{k-1} = \{a_1, a_2, \dots, a_{k-1}\}$，其大小 $|A_{k-1}| = k - 1$；
- $B_k = \{b_1, b_2, \dots, b_k\}$，其大小 $|B_k| = k$。

由于 $A_{k-1}, B_k \in \mathcal{I}$ 且 $|A_{k-1}| < |B_k|$，根据拟阵的交换公理，必存在某个元素 $x \in B_k \setminus A_{k-1}$，使得：

$$A_{k-1} \cup \{x\} \in \mathcal{I}$$

由于 $x \in B_k$，由 $B$ 的降序排列可知：

$$w(x) \ge w(b_k) > w(a_k)$$

这意味着在贪心算法决定第 $k$ 个元素 $a_k$ 时，$x$ 不仅与当前已选集合 $A_{k-1}$ 保持独立，而且其权值 $w(x)$ 严格大于算法选取的 $a_k$。但贪心算法在第 $k$ 步必然选取所有可加入候选元素中权值最大者，因此贪心算法必然会选取 $x$ 或某个权值不小于 $w(x)$ 的元素，这与 $a_k$ 的选取产生直接矛盾！
因此假设不成立，贪心算法获得的基必为全局最大权基。

### 3. 图拟阵（Graphic Matroid）与 Kruskal 算法

给定无向图 $G = (V, E)$：
- 基础集 $S = E$（图的边集）；
- 独立集族 $\mathcal{I} = \{F \subseteq E \mid (V, F) \text{ 无环，即为无向森林}\}$。

验证图拟阵公理：
1. $\emptyset$ 边集无环，属于 $\mathcal{I}$；
2. 森林的任意子边集依然无环，遗传性显然成立；
3. 设两森林边集满足 $|F_1| < |F_2|$。由于 $n$ 个顶点的森林具有 $n - |F|$ 个连通分量，所以 $F_1$ 的连通分量个数严格多于 $F_2$。由鸽巢原理，$F_2$ 中必存在某条边，其两个端点属于 $F_1$ 的不同连通分量。将该边并入 $F_1$ 不会构成环，即 $F_1 \cup \{e\} \in \mathcal{I}$。交换公理成立！

因此，图拟阵是一个标准拟阵。Kruskal 算法在图拟阵上执行贪心选择（通过并查集判环维护独立性），其产出的无环生成树必定具有最优权值。

## C 语言实现

```c
#include <assert.h>
#include <stdbool.h>
#include <stddef.h>
#include <stdint.h>
#include <stdio.h>
#include <stdlib.h>

/* 拟阵基础集元素 */
typedef struct {
    size_t id;
    int64_t weight;
} MatroidElement;

/* 拟阵独立集谓词函数指针类型 */
typedef bool (*MatroidIndependenceFn)(
    const size_t *chosen_ids,
    size_t chosen_count,
    size_t candidate_id,
    void *context
);

static int cmp_matroid_elem_desc(const void *a, const void *b) {
    const MatroidElement *ea = (const MatroidElement *)a;
    const MatroidElement *eb = (const MatroidElement *)b;
    return (eb->weight > ea->weight) - (eb->weight < ea->weight);
}

/* 通用拟阵贪心最大权独立集求解算法 */
bool matroid_greedy_max_weight(
    MatroidElement *elements,
    size_t count,
    MatroidIndependenceFn is_independent,
    void *context,
    size_t *out_chosen,
    size_t *out_chosen_count,
    int64_t *out_total_weight
) {
    if (out_chosen == NULL || out_chosen_count == NULL || out_total_weight == NULL) {
        return false;
    }
    if (count > 0 && (elements == NULL || is_independent == NULL)) {
        return false;
    }

    if (count == 0) {
        *out_chosen_count = 0;
        *out_total_weight = 0;
        return true;
    }

    /* 按照元素权值降序排列 */
    qsort(elements, count, sizeof(MatroidElement), cmp_matroid_elem_desc);

    size_t num_chosen = 0;
    int64_t total_w = 0;

    for (size_t i = 0; i < count; ++i) {
        if (is_independent(out_chosen, num_chosen, elements[i].id, context)) {
            out_chosen[num_chosen++] = elements[i].id;
            total_w += elements[i].weight;
        }
    }

    *out_chosen_count = num_chosen;
    *out_total_weight = total_w;
    return true;
}

/* ==================== 单元测试：图拟阵（Kruskal 最大生成森林） ==================== */

typedef struct {
    size_t u[10];
    size_t v[10];
    size_t parent[10];
} GraphicMatroidCtx;

static size_t dsu_find(size_t *parent, size_t x) {
    while (x != parent[x]) {
        parent[x] = parent[parent[x]];
        x = parent[x];
    }
    return x;
}

static bool test_graphic_independent(
    const size_t *chosen_ids,
    size_t chosen_count,
    size_t candidate_id,
    void *context
) {
    (void)chosen_ids;
    (void)chosen_count;
    GraphicMatroidCtx *ctx = (GraphicMatroidCtx *)context;

    size_t root_u = dsu_find(ctx->parent, ctx->u[candidate_id]);
    size_t root_v = dsu_find(ctx->parent, ctx->v[candidate_id]);

    /* 两端点已在同一连通分量，加入该边会构成环，违反独立性 */
    if (root_u == root_v) {
        return false;
    }

    /* 合并连通块 */
    ctx->parent[root_u] = root_v;
    return true;
}

int main(void) {
    /* 构造包含 4 个顶点、4 条边的图拟阵测试用例 */
    GraphicMatroidCtx ctx;
    for (size_t i = 0; i < 4; ++i) {
        ctx.parent[i] = i;
    }

    /* 边 0: (0, 1), 权值 10
       边 1: (1, 2), 权值 6
       边 2: (2, 3), 权值 5
       边 3: (0, 3), 权值 15 */
    ctx.u[0] = 0; ctx.v[0] = 1;
    ctx.u[1] = 1; ctx.v[1] = 2;
    ctx.u[2] = 2; ctx.v[2] = 3;
    ctx.u[3] = 0; ctx.v[3] = 3;

    MatroidElement edges[] = {
        {0, 10},
        {1, 6},
        {2, 5},
        {3, 15}
    };

    size_t chosen[4] = {0};
    size_t chosen_cnt = 0;
    int64_t total_w = 0;

    bool ok = matroid_greedy_max_weight(
        edges,
        4,
        test_graphic_independent,
        &ctx,
        chosen,
        &chosen_cnt,
        &total_w
    );

    assert(ok);
    /* 贪心选择应选出权值 15, 10, 6，构成包含 3 条边的极大独立集（生成树），总权值为 31 */
    assert(chosen_cnt == 3);
    assert(total_w == 31);

    /* 边界测试：空集合 */
    size_t empty_chosen = 0;
    int64_t empty_w = 0;
    assert(matroid_greedy_max_weight(NULL, 0, NULL, NULL, &empty_chosen, &empty_chosen, &empty_w));
    assert(empty_chosen == 0 && empty_w == 0);

    printf("All 35708 tests passed successfully.\n");
    return 0;
}
```

## 复杂度分析

- **时间复杂度**：
  - 排序阶段：$O(n \log n)$，其中 $n$ 为拟阵基础集大小。
  - 独立性判定阶段：执行 $n$ 次独立性谓词 `is_independent` 调用。若独立性测试的时间开销为 $T_I$，则总时间复杂度为 $O(n \log n + n \cdot T_I)$。在图拟阵中使用带路径压缩与按秩合并的并查集时，$T_I = O(\alpha(|V|))$，总体时间复杂度为 $O(n \log n)$。
- **空间复杂度**：$O(1)$ 额外辅助空间（不计用于记录解集的输出缓冲区和并查集上下文），符合严苛嵌入式标准。

## 延伸思考 / 模式总结

1. **拟阵与贪心选择的等价性**：Rado-Edmonds 定理表明，拟阵结构与贪心最优性是“充分且必要”的双向等价关系。若一个组合优化问题无法被拟阵涵盖（例如带有容量约束的 0-1 背包问题、二分图最大匹配问题），纯粹的单拟阵贪心策略便无法保证全局最优解，必须求助于拟阵交（Matroid Intersection）或动态规划等更通用的方法。
2. **抽象数据与行为分离**：在 C 语言中，通过引入函数指针 `MatroidIndependenceFn` 与通用上下文指针 `void *context`，实现了纯粹代数算法结构与具体领域问题（图、向量空间、二分图）的解耦，体现了正统 C 语言面向对象与模块化抽象的最佳实践。
