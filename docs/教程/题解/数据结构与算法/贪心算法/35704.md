# 35704 - 分数背包问题按性价比贪心求解与形式化证明

## 题目

分数背包问题（Fractional Knapsack）按性价比贪心求解与形式化证明：

给定 $n$ 种物品，每种物品具有重量 $w_i > 0$ 和总价值 $v_i \ge 0$。背包最大承重为 $W$。物品可以分割任意连续比例装入：

```c
#include <stdbool.h>
#include <stddef.h>

typedef struct {
    double weight;
    double value;
} KnapsackItem;

bool fractional_knapsack(
    KnapsackItem *items,
    size_t count,
    double capacity,
    double *out_max_value
);
```

要求：

1. 按照单位重量价值（性价比 $\rho_i = v_i / w_i$）降序排列物品；
2. 优先装入性价比最高者，最后一件若容量不足则按剩余容量比例切分装入；
3. 使用**交换论证法（Exchange Argument）**严格证明：若存在不同于贪心选择的最优解，总能通过等量替换转化为包含贪心解且总价值不减的新解，从而确立贪心选择性质；
4. 编写包含容量不足、容量富余、性价比相同等场景的测试断言。

## 解题思路

### 1. 0-1 背包与分数背包的本质区别

在 0-1 背包问题中，每件物品必须完整装入或完全不装（$x_i \in \{0, 1\}$）。若盲目按性价比贪心，可能因高性价比物品占用体积导致巨大空隙无法填补，因此 0-1 背包**不具备贪心选择性质**，必须使用动态规划求解。
而在分数背包问题中，物品可以连续任意分割（$x_i \in [0, 1]$）。这意味着每一克背包容量都可以被分配给当前可用的“最高单价”物品，因此**贪心选择性质成立**。

### 2. 交换论证法（Exchange Argument）严格证明

设物品已按性价比降序排列：$\rho_1 \ge \rho_2 \ge \dots \ge \rho_n$，其中 $\rho_i = v_i / w_i$。
设贪心解为向量 $G = (x_1, x_2, \dots, x_n)$，满足前若干项 $x_1 = \dots = x_{k-1} = 1$，第 $k$ 项 $x_k = \frac{W - \sum_{i=1}^{k-1} w_i}{w_k} \in [0, 1]$，后续项均为 0。
假设存在一个全局最优解 $O = (y_1, y_2, \dots, y_n)$ 且 $O \ne G$。

找到第一个分歧项下标 $k$，使得 $x_k \ne y_k$。
- 根据贪心策略的定义，$G$ 在下标 $k$ 处一定是尽可能多地装入该物品，因此必有：
  $$x_k > y_k$$
- 由于背包总容量受限于 $W$，且 $O$ 在第 $k$ 项装入的重量比 $G$ 少了 $(x_k - y_k) w_k$，在最优解 $O$ 中必然存在某个后续项 $j > k$，使得 $y_j > 0$（即 $O$ 将部分重量分给了性价比更低的第 $j$ 种物品）。
- 构造替换微元：取重量 $\Delta w = \min\left(y_j w_j, (x_k - y_k) w_k\right) > 0$。
  在最优解 $O$ 中，我们将第 $j$ 种物品减少 $\Delta w$ 重量，并将这 $\Delta w$ 重量腾挪给性价比更高的第 $k$ 种物品，得到新解 $O'$。
- **总价值变化量**：
  $$\Delta V = \Delta w \cdot \rho_k - \Delta w \cdot \rho_j = \Delta w \cdot (\rho_k - \rho_j)$$
  由于物品按性价比降序排列且 $k < j$，恒有 $\rho_k \ge \rho_j$（即 $\rho_k - \rho_j \ge 0$），因此：
  $$\Delta V \ge 0$$
  这表明替换后新解 $O'$ 的总价值**不低于原最优解 $O$ 的总价值**！
- 经过有限次这样的等量正收益替换，可将最优解逐步转化为贪心解 $G$ 而总价值不降。这严格证明了贪心解 $G$ 本身就是一个全局最优解。

## C 语言实现

```c
#include <assert.h>
#include <math.h>
#include <stdbool.h>
#include <stddef.h>
#include <stdio.h>
#include <stdlib.h>

typedef struct {
    double weight;
    double value;
} KnapsackItem;

static int compare_density(const void *a, const void *b) {
    const KnapsackItem *ia = (const KnapsackItem *)a;
    const KnapsackItem *ib = (const KnapsackItem *)b;

    double da = ia->value / ia->weight;
    double db = ib->value / ib->weight;

    if (da != db) {
        return (da < db) - (da > db); /* 降序排列 */
    }
    return 0;
}

bool fractional_knapsack(
    KnapsackItem *items,
    size_t count,
    double capacity,
    double *out_max_value
) {
    if (out_max_value == NULL || (count > 0 && items == NULL) || capacity < 0.0) {
        return false;
    }

    /* 前置合法性校验：重量必须为正数，价值非负 */
    for (size_t i = 0; i < count; ++i) {
        if (items[i].weight <= 0.0 || items[i].value < 0.0) {
            return false;
        }
    }

    if (count == 0 || capacity == 0.0) {
        *out_max_value = 0.0;
        return true;
    }

    /* 按性价比降序排序 */
    qsort(items, count, sizeof(KnapsackItem), compare_density);

    double total_value = 0.0;
    double rem_capacity = capacity;

    for (size_t i = 0; i < count; ++i) {
        if (rem_capacity <= 0.0) {
            break;
        }

        if (items[i].weight <= rem_capacity) {
            /* 能够整件装入 */
            total_value += items[i].value;
            rem_capacity -= items[i].weight;
        } else {
            /* 仅能按剩余比例部分切分装入 */
            total_value += items[i].value * (rem_capacity / items[i].weight);
            rem_capacity = 0.0;
            break;
        }
    }

    *out_max_value = total_value;
    return true;
}

int main(void) {
    /*
     * 物品 1: 重 10, 价 60  -> 性价比 6.0
     * 物品 2: 重 20, 价 100 -> 性价比 5.0
     * 物品 3: 重 30, 价 120 -> 性价比 4.0
     * 背包容量 50:
     * 1) 装入物品 1 (重 10, 价 60), 剩余容量 40
     * 2) 装入物品 2 (重 20, 价 100), 剩余容量 20
     * 3) 切分装入物品 3 (取 20/30 = 2/3, 获得价值 80)
     * 最大总价值 = 60 + 100 + 80 = 240
     */
    KnapsackItem list[] = {
        {10.0, 60.0}, {20.0, 100.0}, {30.0, 120.0}
    };
    double ans = 0.0;
    assert(fractional_knapsack(list, 3, 50.0, &ans) && fabs(ans - 240.0) < 1e-6);

    /* 背包容量充足：装入全部物品总价 280 */
    assert(fractional_knapsack(list, 3, 100.0, &ans) && fabs(ans - 280.0) < 1e-6);

    /* 容量为 0 测试 */
    assert(fractional_knapsack(list, 3, 0.0, &ans) && fabs(ans - 0.0) < 1e-6);

    /* 非法重量防御（weight <= 0） */
    KnapsackItem bad[] = {{0.0, 10.0}};
    assert(!fractional_knapsack(bad, 1, 50.0, &ans));

    printf("All fractional_knapsack tests passed successfully.\n");
    return 0;
}
```

## 复杂度分析

- **时间复杂度**：$O(n \log n)$。排序 $n$ 种物品耗时 $O(n \log n)$，后续线性遍历装载耗时 $\Theta(n)$。
- **空间复杂度**：$O(1)$。原地重排，使用常数个浮点计算对象。

## 延伸思考 / 模式总结

分数背包问题是算法设计中“**连续性带来贪心可解性，离散性引发 NP-hard**”的代表性写照。当约束条件允许实数微元调整时，局部梯度最陡方向直接导向全局极值；而离散整数约束打破了这种微元连续置换的链条。
