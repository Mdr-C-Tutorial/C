### 开发与工程基础模块

本模块位于“语法和标准库”之后，为后续算法、系统和项目学习建立共同的开发基础。规划内容如下：

1. **工程环境与命令行速成**：当前工作目录、路径、命令参数、退出码和输入输出重定向。
2. **编译与链接**：从源文件到可执行文件、编译器诊断、标准模式和常用警告选项。
3. **Git**：工作区、暂存区、提交、分支、合并、冲突处理与安全恢复。
4. [**多文件项目与头文件边界**](/教程/正文/项目/1_项目结构.md)：声明、定义、接口与实现的组织方式。
5. **构建系统**：Make、[CMake](/教程/正文/项目/3_CMake.md) 与 [XMake](/教程/正文/项目/4_XMake.md) 的基本工作流。
6. **调试与测试**：调试器、调用栈、断点、单元测试和回归测试。
7. **程序检查**：编译器警告、AddressSanitizer、UndefinedBehaviorSanitizer、静态分析和模糊测试。
8. **持续集成与可移植性**：在不同实现与平台上自动构建和验证程序。

### 系统编程模块

本模块讲解 ISO C 标准库之外、由操作系统及其开发接口提供的能力。规划内容如下：

1. **平台边界**：ISO C、POSIX、Linux 和 Windows 接口各自提供什么。
2. **文件与文件描述符**：底层输入输出、缓冲、阻塞与错误处理。
3. **进程与进程间通信**：进程创建、程序替换、管道、信号和共享资源。
4. **线程与同步**：操作系统线程、互斥、条件等待及其与 C 标准线程库的关系。
5. **网络基础**：[ISO 七层模型](/教程/正文/项目/74_ISO七层模型.md)、[TCP](/教程/正文/项目/75_TCP.md) 与 [UDP](/教程/正文/项目/76_UDP.md)。
6. **套接字编程**：客户端、服务端、地址解析和可靠的输入输出循环。
7. **终端与事件循环**：终端模式、非阻塞输入输出和事件驱动程序。
