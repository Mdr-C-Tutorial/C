# 21.2 字符串函数

一个循环往缓冲区里追加单词，追加到八千个时，一共访问了一亿六千万个字节；同样多的内容，把末尾位置留在手上只需四万个字节。另一处，代码用 `strncpy(dst, src, sizeof dst)` 做「安全的复制」，目标缓冲区是 8 字节而源字符串有 11 字节，随后用 `printf("%s")` 打印，输出末尾多出几个看不懂的字符。两个毛病都不是循环写错了，而是没有按规格理解这两个函数：`strcat` 的代价与目标串当前长度成正比，`strncpy` 在源不短于 `n` 时根本不写终止空字符。

这一节按规格实现 `<string.h>` 中与区域设置无关的十二个字符串函数，放进 `src/mdr_string.c`。写的过程中会反复碰到三件事：哪些字节算字符串的一部分，返回值只保证什么，以及标准库为什么把某些接口设计成现在这样。

## 1. 表示与比较规则

C 的字符串是以空字符（null character，值为 0 的字节）结尾的字节序列。`strlen` 数的是终止空字符之前的字节数，`strcmp` 在第一个不同的字节处停下，`strchr` 把终止空字符也算作字符串的一部分。所有函数都假定实参满足这个前提，谁传进来一个没有终止空字符的缓冲区，谁就违反了前置条件，函数不检查。

比较规则在 21.1 的 `mdr_strcmp` 里已经定下：按 `unsigned char` 的值逐字节比较。

```c
int mdr_strcmp(const char *lhs, const char *rhs) {
    const unsigned char *p1 = (const unsigned char *)lhs;
    const unsigned char *p2 = (const unsigned char *)rhs;

    MDR_ASSERT(lhs != NULL);
    MDR_ASSERT(rhs != NULL);
    while (*p1 != '\0' && *p1 == *p2) {
        p1++;
        p2++;
    }
    return (int)*p1 - (int)*p2;
}
```

为什么必须转成 `unsigned char`：`char` 是否有符号由实现决定，在 `char` 有符号的平台上，`(char)0x80` 是负数，拿它和 `'a'` 直接比较会得出与字节值相反的顺序。转成 `unsigned char` 之后，比较的就是 0 到 255 的字节值，与平台无关。

复制函数的目标和源都带 `restrict`：两个区域不允许重叠。`restrict` 只是把这条前置条件写进了类型，编译器据此可以假定写入目标不会影响源，从而放宽指令顺序；真的传了重叠的区域，结果由实现决定。需要允许重叠时用 21.3 的 `mdr_memmove`。

返回指针的那些查找函数有一处历史包袱。C17 及更早的声明是：

```c
char *strchr(const char *s, int ch);
```

实参是 `const char *`，返回值却是可写的 `char *`。这允许通过返回的指针修改一个本来是只读的字符串，编译器不会拦。C23 把 `strchr`、`strrchr`、`strstr` 等改成类型泛型（type-generic）：实参是 `const char *` 时返回 `const char *`，是 `char *` 时返回 `char *`（C23）。本章的 `mdr_` 版本沿用旧声明，与 C17 的标准库保持一致；C11 里可以用 `_Generic` 做出同样的效果，写法见[泛型选择](/教程/正文/语法和标准库/12_函数接口进阶/12_1_泛型选择)。C 运行库是否已经提供 C23 版本，取决于实现和所处的标准模式，不能假定。

十二个函数的规格要点与实现要点：

| 函数 | 规格要点 | 实现要点 |
| --- | --- | --- |
| `mdr_strcpy` | 复制含终止空字符；返回 `dest` | 赋值结果参与条件判断，一次读写一个字节 |
| `mdr_strncpy` | 最多写 `count` 个字节；源短则补零，源不短则无终止符 | 两个循环：先复制，再补零 |
| `mdr_strcat` | 追加并覆盖原终止符；返回 `dest` | 先 `mdr_strlen` 定位末尾，再复制 |
| `mdr_strncat` | 最多追加 `count` 个字符，总是补终止符 | 空间要求是 `strlen(dest) + count + 1` |
| `mdr_strncmp` | 最多比较 `count` 个字节 | 越界前遇到终止符也要停 |
| `mdr_strchr` | 查首次出现，终止空字符也查 | 循环条件写成「非空且不等」 |
| `mdr_strrchr` | 查最后一次出现 | 一次扫描，记住最后命中的位置 |
| `mdr_strspn` | 最大前缀，字符都在 `accept` 中 | 256 项查找表 |
| `mdr_strcspn` | 最大前缀，字符都不在 `reject` 中 | 同一张表，条件取反 |
| `mdr_strpbrk` | 首个出现在集合中的字符 | 用 `mdr_strcspn` 定位 |
| `mdr_strstr` | 子串首次出现；空 `needle` 返回 `haystack` | 用 `mdr_strchr` 找首字节，再比其余 |
| `mdr_strtok` | 按分隔符切分，改写输入，进度保存在静态对象 | `mdr_strspn` 跳过分隔符，`mdr_strcspn` 找字段尾 |

## 2. 复制与连接

`mdr_strcpy` 的循环把赋值和判断合成一步：

```c
char *mdr_strcpy(char *restrict dest, const char *restrict src) {
    char *d = dest;

    MDR_ASSERT(dest != NULL);
    MDR_ASSERT(src != NULL);
    while ((*d = *src) != '\0') {
        d++;
        src++;
    }
    return dest;
}
```

`*d = *src` 的结果就是刚写入的那个字节，拿它和 `'\0'` 比较，循环在复制完终止空字符之后退出。返回值是 `dest`，这样可以嵌套进别的调用。

`mdr_strcat` 先用 `mdr_strlen` 找到末尾，再从那里调用 `mdr_strcpy`：

```c
char *mdr_strcat(char *restrict dest, const char *restrict src) {
    char *d;

    MDR_ASSERT(dest != NULL);
    MDR_ASSERT(src != NULL);
    d = dest + mdr_strlen(dest);
    mdr_strcpy(d, src);
    return dest;
}
```

这个写法有个代价：每次追加都要重新扫描一遍 `dest`。连续追加 n 个单词，扫描的字节数是 0 + 5 + 10 + …，与 n² 成正比。下面这个程序统计两种写法一共访问了多少字节，每次追加的都是 5 个字符的 `"word "`：

```c
#include <stdio.h>

static unsigned long scanned;
static unsigned long copied;

/* 与 strcat 相同：每次都从开头找末尾 */
static char *append_head(char *dest, const char *word) {
    char *d = dest;

    while (*d != '\0') {
        d++;
        scanned++;
    }
    while ((*d = *word) != '\0') {
        d++;
        word++;
        copied++;
    }
    return dest;
}

/* 返回新的末尾位置，下一次从这里继续追加 */
static char *append_tail(char *tail, const char *word) {
    while ((*tail = *word) != '\0') {
        tail++;
        word++;
        copied++;
    }
    return tail;
}

int main(void) {
    static char buf[200000];

    printf("%8s %14s %14s\n", "words", "strcat", "tail");
    for (unsigned long n = 1000; n <= 8000; n *= 2) {
        unsigned long head_bytes;
        unsigned long tail_bytes;
        char *tail = buf;

        buf[0] = '\0';
        scanned = 0;
        copied = 0;
        for (unsigned long i = 0; i < n; i++) {
            append_head(buf, "word ");
        }
        head_bytes = scanned + copied;

        buf[0] = '\0';
        scanned = 0;
        copied = 0;
        tail = buf;
        for (unsigned long i = 0; i < n; i++) {
            tail = append_tail(tail, "word ");
        }
        tail_bytes = scanned + copied;
        printf("%8lu %14lu %14lu\n", n, head_bytes, tail_bytes);
    }
    return 0;
}
```

两次追加的词数每翻一倍，第一列访问的字节数变成四倍，第二列只翻一倍：

::: terminal title="zsh - tailcat"

```text
$ gcc -std=c17 -Wall -Wextra -O2 -o tailcat tailcat.c
$ ./tailcat
   words         strcat           tail
    1000        2502500           5000
    2000       10005000          10000
    4000        40010000          20000
    8000       160020000          40000
```

:::

把「末尾位置」留在手上，总代价就与总长度成正比。标准库为此提供了 `stpcpy`：它返回指向目标中终止空字符的指针，正好可以喂给下一次复制。`stpcpy` 不在 C17 的标准库里，21.5 实现它的 `mdr_` 版本。亲手写代码时不必等这个函数，像上面那样让追加函数返回新的末尾即可。

接下来是这一节最需要小心的函数。`mdr_strncpy` 的规格有两条分支：

```c
char *mdr_strncpy(char *restrict dest, const char *restrict src, size_t count) {
    size_t i = 0;

    MDR_ASSERT(dest != NULL);
    MDR_ASSERT(src != NULL);
    for (; i < count && src[i] != '\0'; i++) {
        dest[i] = src[i];
    }
    for (; i < count; i++) {
        dest[i] = '\0';
    }
    return dest;
}
```

第一个循环复制到源结束或写满 `count` 个字节；第二个循环把剩下的位置全部填零。两种结果完全不同：

- 源串短于 `count`：目标是一个内容等于源的字符串，后面补满空字符，补零一直补到第 `count` 个字节。
- 源串不短于 `count`：目标前 `count` 个字节等于源的前 `count` 个字节，**没有终止空字符**。

把目标缓冲区先填满 `#`（0x23），再按字节打印，两种情况一目了然：

```c
#include "mdr_string.h"
#include <stdio.h>
#include <string.h>

static void dump(const char *label, const unsigned char *p, size_t n) {
    printf("%-22s", label);
    for (size_t i = 0; i < n; i++) {
        printf(" %02X", p[i]);
    }
    printf("\n");
}

int main(void) {
    unsigned char buf[8];

    memset(buf, '#', sizeof buf);
    mdr_strncpy((char *)buf, "ab", sizeof buf);
    dump("src \"ab\" (2):", buf, sizeof buf);

    memset(buf, '#', sizeof buf);
    mdr_strncpy((char *)buf, "abcdefgh", sizeof buf);
    dump("src \"abcdefgh\" (8):", buf, sizeof buf);

    memset(buf, '#', sizeof buf);
    mdr_strncpy((char *)buf, "abcdefghij", sizeof buf);
    dump("src \"abcdefghij\" (10):", buf, sizeof buf);
    return 0;
}
```

```text
$ gcc -std=c17 -Wall -Wextra -Iinclude -o nc nc.c src/mdr_string.c
$ ./nc

src "abcdefgh" (8):    61 62 63 64 65 66 67 68
```

第一行是字符串，后两行不是：八个字节里一个零都没有，紧跟着的字节是缓冲区外面的东西。

::: concept mdr-strncpy-semantics title="strncpy 的后置条件有两种情形"

`strncpy(dest, src, count)` 最多写 `count` 个字节。`src` 作为字符串短于 `count` 时，复制完后继续补空字符直到写满 `count` 个字节，结果是字符串；`src` 不短于 `count` 时，`dest` 的前 `count` 个字节等于 `src` 的前 `count` 个字节，不带终止空字符，结果不是字符串。函数的返回值始终是 `dest`。

:::

这条规格解释了很多事故。`strncpy` 的名字里有 `n`，看起来像是「最多复制 n 个字节，保证结果有终止符」，实际保证的只是「不会写超过 n 个字节」，终止符有没有取决于源有多长。下面这种写法在字段长度恰好用满时留下一个没有终止符的数组：

```c
#include "mdr_string.h"
#include <stdio.h>
#include <string.h>

struct record {
    char name[8];
    char note[8];
};

int main(void) {
    struct record r;

    /* 两个字段预先填满 '#'，再用 strncpy 写入 */
    memset(&r, '#', sizeof r);
    mdr_strncpy(r.name, "Christopher", sizeof r.name);
    mdr_strncpy(r.note, "ok", sizeof r.note);
    printf("name = [%s]\n", r.name);
    printf("note = [%s]\n", r.note);
    printf("sizeof r = %lu\n", (unsigned long)sizeof r);
    return 0;
}
```

`"Christopher"` 有 11 个字母，8 字节装不下，前 8 个字节写进去之后就没有然后了：

::: terminal title="zsh - struct_nc"

```text
$ gcc -std=c17 -Wall -Wextra -Iinclude -o struct_nc struct_nc.c src/mdr_string.c
$ ./struct_nc

note = [ok]
sizeof r = 16
```

:::

`name` 打印出 `Christopok`：前 8 个字节是 `Christop`，紧接着就是相邻字段 `note` 的 `ok`，因为 `name` 里没有终止符，`printf` 一路读了过去。这类输出看起来只是「多了几个字符」，实际是一次越界读取。

修正的办法不是换一个更长的 `n`，而是换一个语义正确的函数。`snprintf` 总是补终止符，代价是截断时静默丢掉后面的内容：

::: compare left-title="用 strncpy 做安全复制" right-title="用 snprintf 限制长度"

```c
char name[8];

/* 源比目标长时没有终止空字符 */
strncpy(name, src, sizeof name);
printf("%s\n", name);
```

---

```c
char name[8];

/* 总是有终止空字符，超长部分被截掉 */
snprintf(name, sizeof name, "%s", src);
printf("%s\n", name);
```

:::

同样的源和目标，两个函数写出的字节：

```c
#include <stdio.h>
#include <string.h>

static void dump(const char *label, const unsigned char *p, size_t n) {
    printf("%-12s", label);
    for (size_t i = 0; i < n; i++) {
        printf(" %02X", p[i]);
    }
    printf("\n");
}

int main(int argc, char *argv[]) {
    const char *name = argc > 1 ? argv[1] : "";
    char dst[8];

    memset(dst, '#', sizeof dst);
    strncpy(dst, name, sizeof dst);
    dump("strncpy:", (const unsigned char *)dst, sizeof dst);

    memset(dst, '#', sizeof dst);
    snprintf(dst, sizeof dst, "%s", name);
    dump("snprintf:", (const unsigned char *)dst, sizeof dst);
    printf("snprintf 的结果: [%s]\n", dst);
    return 0;
}
```

```text
$ gcc -std=c17 -Wall -Wextra -o snp snp.c
$ ./snp Christopher

snprintf 的结果: [Christo]
```

:::

`snprintf` 把第 8 个字节留给了终止空字符，代价是少复制一个字符，打印出来是 `Christo`。需要知道是否发生截断时，看它的返回值：返回值是「假如空间足够，本来会写多少个字符」，大于等于 `sizeof` 就说明被截断了。

不要用 `strncpy` 做安全复制：它在源较长时不终止，在源较短时又把剩余空间全部填零，两种行为都不是调用方想要的。固定宽度的字段用它，是为了「不用终止符、字段恰好填满」这种场景；普通的字符串复制用 `snprintf`，或者用 21.5 实现的 `mdr_strlcpy`。

`mdr_strncat` 的规格与它相反，总写终止符：

```c
char *mdr_strncat(char *restrict dest, const char *restrict src, size_t count) {
    char *d;

    MDR_ASSERT(dest != NULL);
    MDR_ASSERT(src != NULL);
    d = dest + mdr_strlen(dest);
    while (count > 0 && *src != '\0') {
        *d = *src;
        d++;
        src++;
        count--;
    }
    *d = '\0';
    return dest;
}
```

目标是 `dest` 原有内容加上至多 `count` 个字符，再加一个终止空字符，所以缓冲区至少要 `strlen(dest) + count + 1` 个字节。少算一个字节是这类代码最常见的错误，写完终止符正好越过缓冲区末尾。

## 3. 比较

`mdr_strncmp` 在 `mdr_strcmp` 的基础上加一个计数：

```c
int mdr_strncmp(const char *lhs, const char *rhs, size_t count) {
    const unsigned char *p1 = (const unsigned char *)lhs;
    const unsigned char *p2 = (const unsigned char *)rhs;

    MDR_ASSERT(lhs != NULL);
    MDR_ASSERT(rhs != NULL);
    while (count > 0 && *p1 != '\0' && *p1 == *p2) {
        p1++;
        p2++;
        count--;
    }
    if (count == 0) {
        return 0;
    }
    return (int)*p1 - (int)*p2;
}
```

`count` 减到 0 时两个前缀相同，返回 0。循环里 `*p1 != '\0'` 这个条件不能省：`count` 比两个字符串都长时，不检查终止符就会越过末尾继续读。

返回值的数值不必一致。标准只规定符号：`lhs` 小于 `rhs` 时为负，相等时为 0，大于时为正。同一对字符串在不同运行库上得到的数不同。下面这个程序把三个比较函数的返回值都打印出来：

```c
#include <stdio.h>
#include <string.h>

int main(int argc, char *argv[]) {
    const char *a = argc > 1 ? argv[1] : "apple";
    const char *b = argc > 2 ? argv[2] : "apricot";

    printf("strcmp   = %d\n", strcmp(a, b));
    printf("strncmp5 = %d\n", strncmp(a, b, 5));
    printf("memcmp5  = %d\n", memcmp(a, b, 5));
    return 0;
}
```

实参取自 `argv` 而不是写成字符串字面量，这样 GCC 没法在编译期把结果折叠成常数，调用才会真正落到库里。

## 4. 查找单个字符

`mdr_strchr` 的关键在终止空字符：

```c
char *mdr_strchr(const char *s, int ch) {
    char c = (char)ch;

    MDR_ASSERT(s != NULL);
    while (*s != '\0' && *s != c) {
        s++;
    }
    if (*s == c) {
        return (char *)s;
    }
    return NULL;
}
```

参数类型是 `int ch`，与标准库一致，但比较的是转换后的 `char`。循环停下来有两种原因：遇到终止空字符，或者找到目标。所以退出循环后要再比较一次，这样才能命中 `mdr_strchr(s, '\0')` 这种调用。规格里「终止空字符也在查找范围内」写的就是这件事，`mdr_strchr(s, '\0')` 返回指向终止符自身的指针，找不到时才返回 `NULL`。

`mdr_strrchr` 要一次走到底，记住最后一次命中的位置：

```c
char *mdr_strrchr(const char *s, int ch) {
    const char *last = NULL;
    char c = (char)ch;

    MDR_ASSERT(s != NULL);
    do {
        if (*s == c) {
            last = s;
        }
    } while (*s++ != '\0');
    return (char *)last;
}
```

这里用 `do … while` 而不是 `while`，是为了让终止空字符也进入循环体一次；`*s++ != '\0'` 在判断之后把指针推进一格，指针最后会停在终止符后面一个位置，但那已经不用了。`last` 为 `NULL` 的判断同时覆盖「没找到」和「`s` 为空串」两种情形。

两个函数对 `"banana"` 的结果：

```c
#include "mdr_string.h"
#include <stdio.h>

static int offset_of(const char *base, const char *p) {
    return p != NULL ? (int)(p - base) : -1;
}

int main(void) {
    const char text[] = "banana";

    printf("strchr(text, 'a')     偏移 %d\n", offset_of(text, mdr_strchr(text, 'a')));
```

## 5. 字符集合

`mdr_strspn` 返回 `s` 开头由 `accept` 中字符组成的最大前缀长度，`mdr_strcspn` 反过来，返回不含 `reject` 中任何字符的最大前缀长度。最直接的写法是对每个字符把集合扫一遍，代价是两层循环：长度为 n 的字符串、大小为 m 的集合，最多比较 n·m 次。

把集合先摊成一张 256 项的表，每个字节值一格，扫描时每步只查一次表，代价降到 n + m：

```c
size_t mdr_strspn(const char *s, const char *accept) {
    bool in_set[256] = {false};
    size_t n = 0;

    MDR_ASSERT(s != NULL);
    MDR_ASSERT(accept != NULL);
    while (*accept != '\0') {
        in_set[(unsigned char)*accept] = true;
        accept++;
    }
    while (s[n] != '\0' && in_set[(unsigned char)s[n]]) {
        n++;
    }
    return n;
}
```

下标必须转成 `unsigned char`。如果 `char` 有符号且某个字节是 0x80 以上，直接拿去当下标会变成负数，越界写到表前面。

两种实现的比较次数用一个计数器量出来：

```c
#include <stdbool.h>
#include <stdio.h>
#include <string.h>

static unsigned long compares;

/* 朴素版：对每个字符在 accept 里从头找一遍 */
static size_t naive_strspn(const char *s, const char *accept) {
    size_t n = 0;

    while (s[n] != '\0') {
        const char *a = accept;
        bool found = false;

        while (*a != '\0') {
            compares++;
            if (*a == s[n]) {
                found = true;
                break;
            }
            a++;
        }
        if (!found) {
            break;
        }
        n++;
    }
    return n;
}

/* 查找表版：先把 accept 摊成 256 项表，再线性扫描 */
static size_t table_strspn(const char *s, const char *accept) {
    bool in_set[256] = {false};
    size_t n = 0;

    while (*accept != '\0') {
        in_set[(unsigned char)*accept] = true;
        accept++;
    }
    while (s[n] != '\0') {
        compares++;
        if (!in_set[(unsigned char)s[n]]) {
            break;
        }
        n++;
    }
    return n;
}

int main(void) {
    static char text[1u << 20];
    const char *accept = "0123456789abcdefghijklmnopqrstuvwxyz";

    memset(text, 'z', sizeof text - 1u);

    compares = 0;
    size_t n1 = naive_strspn(text, accept);
    unsigned long c1 = compares;

    compares = 0;
    size_t n2 = table_strspn(text, accept);
    unsigned long c2 = compares;

    printf("输入 %lu 个字符，集合 %lu 个字符，命中集合最后一个字符\n",
           (unsigned long)strlen(text), (unsigned long)strlen(accept));
    printf("朴素版：%lu 次比较\n", c1);
    printf("查找表版：%lu 次比较\n", c2);
    printf("结果：%lu 与 %lu\n", (unsigned long)n1, (unsigned long)n2);
    return 0;
}
```

查找表还可以再小。每个字节值只需要一位，256 位就是 32 个字节：

```c
static size_t bitmap_strspn(const char *s, const char *accept) {
    unsigned char bitmap[32] = {0};
    size_t n = 0;

    while (*accept != '\0') {
        unsigned char c = (unsigned char)*accept;

        bitmap[c / 8] |= (unsigned char)(1u << (c % 8));
        accept++;
    }
    while (s[n] != '\0') {
        unsigned char c = (unsigned char)s[n];

        if ((bitmap[c / 8] & (1u << (c % 8))) == 0) {
            break;
        }
        n++;
    }
    return n;
}
```

musl 的 `strspn` 用的就是这个思路，只是把 256 位装进一张按机器字大小划分的位图，而不是每个字节一格。本章的 `mdr_strspn` 留用 `bool` 表，读起来更直白，编译出来也就 256 字节，在栈上不心疼。

`mdr_strcspn` 的代码与它只差一个取反：

```c
size_t mdr_strcspn(const char *s, const char *reject) {
    bool in_set[256] = {false};
    size_t n = 0;

    MDR_ASSERT(s != NULL);
    MDR_ASSERT(reject != NULL);
    while (*reject != '\0') {
        in_set[(unsigned char)*reject] = true;
        reject++;
    }
    while (s[n] != '\0' && !in_set[(unsigned char)s[n]]) {
        n++;
    }
    return n;
}
```

`mdr_strpbrk` 不必自己再扫一遍，它要的「首个出现在集合里的字符」正是 `mdr_strcspn` 停下的位置：

```c
char *mdr_strpbrk(const char *s, const char *breakset) {
    size_t n = mdr_strcspn(s, breakset);

    if (s[n] == '\0') {
        return NULL;
    }
    return (char *)(s + n);
}
```

`mdr_strcspn` 只在遇到集合中的字符或终止空字符时停下，所以 `s[n]` 是终止空字符就说明整个字符串里没有集合中的字符。用一套查找表实现四个函数，省掉了重复的代码。

## 6. 子串查找

`mdr_strstr` 用 `mdr_strchr` 找 `needle` 的第一个字节，找到之后比较剩下的部分：

```c
char *mdr_strstr(const char *haystack, const char *needle) {
    size_t nlen = mdr_strlen(needle);
    const char *p = haystack;

    MDR_ASSERT(haystack != NULL);
    MDR_ASSERT(needle != NULL);
    if (nlen == 0) {
        return (char *)haystack;
    }
    while ((p = mdr_strchr(p, needle[0])) != NULL) {
        if (mdr_strncmp(p, needle, nlen) == 0) {
            return (char *)p;
        }
        p++;
    }
    return NULL;
}
```

空 `needle` 直接返回 `haystack`，这是规格规定的，不能返回 `NULL`。剩下的循环里，`mdr_strchr` 的第二个实参是 `needle[0]`，它可能是任意字节，包括 0x80 以上，这正是 `mdr_strchr` 接受 `int` 的原因。

这个朴素算法的最坏代价与 `n·m` 成正比。把 haystack 设成 n 个 `'a'`，needle 设成 n-1 个 `'a'` 加一个 `'b'`，每个起点都要比较到 needle 末尾才失败。下面按同样的算法统计比较次数：

```c
#include <stdio.h>
#include <string.h>

/* 与 mdr_strstr 相同的朴素算法，只加了比较计数 */
static unsigned long compares;

static const char *counted_strstr(const char *haystack, const char *needle) {
    size_t nlen = strlen(needle);
    const char *p = haystack;

    if (nlen == 0) {
        return haystack;
    }
    while ((p = strchr(p, needle[0])) != NULL) {
        size_t i = 0;

        while (i < nlen) {
            compares++;
            if (p[i] != needle[i]) {
                break;
            }
            i++;
        }
        if (i == nlen) {
            return p;
        }
        p++;
    }
    return NULL;
}

int main(void) {
    static char haystack[4097];
    static char needle[4097];

    printf("%6s %12s\n", "n", "comparisons");
    for (size_t n = 128; n <= 2048; n *= 2) {
        memset(haystack, 'a', n);
        haystack[n] = '\0';
        memset(needle, 'a', n);
        needle[n - 1] = 'b';
        needle[n] = '\0';

        compares = 0;
        const char *hit = counted_strstr(haystack, needle);
        printf("%6lu %12lu  %s\n", (unsigned long)n, compares,
               hit != NULL ? "found" : "not found");
    }
    return 0;
}
```

## 7. 分词：strtok

`mdr_strtok` 把 `str` 按 `delim` 中的字符切开，每次调用返回一个字段。它有两个特点，都写进了规格：

1. 改写输入。字段之间的分隔符被替换成终止空字符。
2. 进度保存在静态对象里。第一次调用传字符串，之后传 `NULL`，函数靠内部指针接着切。

```c
char *mdr_strtok(char *restrict str, const char *restrict delim) {
    static char *next;
    char *start;
    char *end;

    MDR_ASSERT(delim != NULL);
    if (str != NULL) {
        next = str;
    }
    if (next == NULL) {
        return NULL;
    }
    start = next + mdr_strspn(next, delim);
    if (*start == '\0') {
        next = NULL;
        return NULL;
    }
    end = start + mdr_strcspn(start, delim);
    if (*end != '\0') {
        *end = '\0';
        next = end + 1;
    } else {
        next = NULL;
    }
    return start;
}
```

`mdr_strspn` 跳过开头的分隔符，`mdr_strcspn` 找到字段尾。字段尾是分隔符时把它改成终止空字符，下一次从它后面继续；字段尾已经是终止空字符时，这是最后一个字段，把 `next` 置空。连续的分隔符被跳过，所以 `"a,,b"` 只得到 `a` 和 `b`，中间的空字段丢掉。这一点与 `strsep` 不同，21.5 会讲。

静态对象是这套接口最大的问题。同时切两个字符串时，内层调用会覆盖外层的进度。下面这个程序先按行切，再对每一行按逗号切：

```c
#include "mdr_string.h"
#include <stdio.h>
#include <string.h>

int main(void) {
    const char text[] = "red,green,blue\ncyan,magenta,yellow";
    char copy[sizeof text];
    char *line;
    unsigned long lines = 0;
    unsigned long fields = 0;

    memcpy(copy, text, sizeof text);
    printf("按行切分，再对每一行按逗号切分：\n");
    for (line = mdr_strtok(copy, "\n"); line != NULL;
         line = mdr_strtok(NULL, "\n")) {
        char *field;

        lines++;
        printf("  行 %lu: %s\n", lines, line);
        for (field = mdr_strtok(line, ","); field != NULL;
             field = mdr_strtok(NULL, ",")) {
            fields++;
            printf("    字段: %s\n", field);
        }
    }
    printf("共 %lu 行、%lu 个字段（期望 2 行、6 个字段）\n", lines, fields);
    return 0;
}
```

两行文本，每行三个字段，期望六行输出。实际只有一行：

标准库的 `strtok` 有同样的问题，换成它结果一样。修复的办法不是调整调用顺序，而是换一个把进度放在调用方手里的版本：`strtok_r` 多一个 `saveptr` 参数，`strsep` 直接推进调用方的指针。两者都由 21.5 实现，那里会把这段程序改用 `mdr_strtok_r` 重跑一遍。

::: concept mdr-strtok-static-state title="strtok 的进度存在静态对象里"

`strtok` 在内部用一块静态存储保存下一次从哪里继续，第一次调用传入字符串，之后传空指针。静态存储只有一份，因此同一个程序里不能同时进行两路分词：内层对另一个字符串的调用会覆盖外层的进度。它还会改写输入，把分隔符换成终止空字符。需要同时切分或者保持输入不变时，用把进度放在调用方提供的对象里的版本。

:::

新代码里能用 `strtok_r` 就别用 `strtok`，多写一个参数换来可嵌套、可并发；只有一行命令式的简单切分，用 `strtok` 省事。

## 8. 测试

十二个函数写完之后，`tests/test_string.c` 里的检查增加到 103 个，按函数分成若干个 `static` 函数，`main` 依次调用，最后 `return check_report("test_string");`。

有三类检查值得单独说。第一类是与标准库对照，同一组输入分别交给 `mdr_` 版本和 `<string.h>`，只比较结果：

```c
/* 与标准库对照：同一组输入分别交给 mdr_ 版本和 <string.h>，比较结果 */

    const char *haystack;
    const char *needle;
};

static void test_against_libc(void) {
    static const struct find_case spans[] = {
        {"", ""},
        {"abc", ""},
        {"", "abc"},
        {"aabb", "ab"},
        {"12345abc", "0123456789"},
        {"12345abc", "abc"},
        {"hello world", " "},
    };
    static const struct find_case finds[] = {
        {"the cat sat on the mat", "cat"},
        {"the cat sat on the mat", "the"},
        {"the cat sat on the mat", "the m"},
        {"the cat sat on the mat", ""},
        {"the cat sat on the mat", "dog"},
        {"abc", "abcd"},
        {"aaaaab", "aab"},
    };

    for (size_t i = 0; i < sizeof spans / sizeof spans[0]; i++) {
        const char *h = spans[i].haystack;
        const char *n = spans[i].needle;

        CHECK_EQ_SIZE(mdr_strspn(h, n), strspn(h, n));
        CHECK_EQ_SIZE(mdr_strcspn(h, n), strcspn(h, n));
        CHECK(offset_or_neg(h, mdr_strpbrk(h, n)) ==
              offset_or_neg(h, strpbrk(h, n)));
    }
    for (size_t i = 0; i < sizeof finds / sizeof finds[0]; i++) {
        const char *h = finds[i].haystack;
        const char *n = finds[i].needle;

        CHECK(offset_or_neg(h, mdr_strstr(h, n)) == offset_or_neg(h, strstr(h, n)));
    }
}
```

`spans` 那组用例同时跑三个按集合查找的函数，`finds` 那组跑 `mdr_strstr`；`{"", ""}` 与 `{"abc", ""}` 这类用例专门覆盖空串。

比较的是「相对于 `haystack` 的偏移」，不是两个指针本身。两份实现返回的指针指向不同的字符串对象，直接比指针永远不相等；偏移是 `-1` 就表示没找到，`offset_or_neg` 把这两种情况统一成一个数。

第二类是整缓冲区比较。复制函数不能只看目标里有没有想要的字符串，还要看目标之外的字节有没有被改动。`test_strncpy` 先给整个缓冲区填 `#`，调用之后逐个检查 `count` 之后的字节：

```c
static void test_strncpy(void) {
    char buf[8];

    memset(buf, '#', sizeof buf);
    CHECK(mdr_strncpy(buf, "ab", 4u) == buf);
    CHECK_EQ_SIZE((unsigned char)buf[0], 'a');
    CHECK_EQ_SIZE((unsigned char)buf[1], 'b');
    CHECK_EQ_SIZE((unsigned char)buf[2], 0u);
    CHECK_EQ_SIZE((unsigned char)buf[3], 0u);
    CHECK_EQ_SIZE((unsigned char)buf[4], '#');

    memset(buf, '#', sizeof buf);
    CHECK(mdr_strncpy(buf, "abcdefgh", 4u) == buf);
    CHECK(memcmp(buf, "abcd", 4u) == 0);
    CHECK_EQ_SIZE((unsigned char)buf[4], '#');
}
```

第三类是表驱动。查找函数有大量「查某个字符、期望某个偏移」的组合，逐条写 `CHECK` 只是把同一段代码抄十遍，写成数组加循环更清楚：

```c
struct chr_case {
    int ch;
    int first;
    int last;
};

static void test_strchr(void) {
    static const struct chr_case cases[] = {
        {'b', 0, 0},
        {'a', 1, 5},
        {'n', 2, 4},
        {'z', -1, -1},
    };
    const char text[] = "banana";

    for (size_t i = 0; i < sizeof cases / sizeof cases[0]; i++) {
        CHECK(offset_or_neg(text, mdr_strchr(text, cases[i].ch)) == cases[i].first);
        CHECK(offset_or_neg(text, mdr_strrchr(text, cases[i].ch)) == cases[i].last);
    }

    /* 终止空字符也在查找范围内：strchr 返回指向它的指针 */
    CHECK(mdr_strchr(text, 0) == text + 6);
    CHECK(mdr_strrchr(text, 0) == text + 6);
}
```

表里放 `-1` 表示「找不到」，`offset_or_neg` 把 `NULL` 换算成 -1，循环体只有一行。加一个用例就是加一行数据，不用碰判断逻辑。
