# 9. 回溯与剪枝

当问题要求统计满足复杂约束的所有解、枚举全部合法排列组合，或问题本身不具备贪心选择性质与多项式规模的动态规划状态时，我们需要在隐式构成的**状态空间树 (State-Space Tree)** 上进行系统化的深度优先搜索。这种“按步构造候选解、遇到冲突立即退回上一步尝试其他分支”的算法范式称为**回溯法 (Backtracking)**。

## 1. 状态空间树与“修改—递归—恢复”不变式

回溯法将求解过程分解为 $d = 0, 1, \dots, n - 1$ 共 $n$ 个决策阶段：

- **子集树**：每个元素有“选”与“不选”两个分支，共有 $2^n$ 个叶结点（如子集和问题）。
- **排列树**：第 $d$ 层从剩余未使用的 $n - d$ 个元素中任选一个放在位置 $d$，共有 $n!$ 个叶结点（如全排列生成）。

为了将额外空间复杂度控制在递归深度 $O(n)$ 内，回溯算法不在每个结点处复制整份候选数组，而是**原地修改同一个共享状态**。这要求递归函数严格遵守**状态对称恢复不变式**：

```text
BACKTRACK(depth, state)
1  if depth == TARGET_DEPTH
2      RECORD-SOLUTION(state)
3      return
4  for each candidate c available at depth
5      if PRUNE(state, c) then continue
6      APPLY-CHOICE(state, c)      // 向下递归前修改共享状态
7      BACKTRACK(depth + 1, state)
8      UNDO-CHOICE(state, c)       // 递归返回后立即逆序恢复共享状态
```

::: warning 提前终止时的状态恢复

在支持访问者回调（如 `bool visit(const int64_t *items, size_t count, void *ctx)`）的枚举接口中，如果回调函数返回 `false` 请求提前中止搜索，当前层在向调用方返回前**依然必须执行 `UNDO-CHOICE`**（例如把交换过的数组元素换回原位），确保最外层函数退出时输入数组完全恢复为调用前的初始顺序。

:::

## 2. 剪枝策略 (Pruning)

不加限制地遍历整棵状态空间树往往面临指数级或阶乘级爆炸。通过在分支扩展前判断当前部分解是否还有可能导向合法/更优解，提前砍掉整棵无效子树的操作称为**剪枝**：

1. **可行性剪枝 (Feasibility Pruning)**：当前部分解已经违反问题约束，继续向下扩展绝无可能恢复合法。
   - **非负整数子集和剪枝**：由于所有元素非负，一旦当前累加和 `current_sum > target`（写成 `item > target - current_sum` 以防加法溢出），后续无论选不选其他元素，和都只会单调不减，可立即剪掉该分支。
   - **$N$ 皇后冲突剪枝**：在 $n \times n$ 棋盘上逐行放置皇后（每行天然只有一个）。当尝试在第 $r$ 行第 $c$ 列放置皇后时，只需检查第 $c$ 列、主对角线 $r - c + (n - 1)$ 以及副对角线 $r + c$ 是否已被之前的行占用。用三个布尔数组或三个 `uint64_t` 位掩码（`col_mask`、`diag1_mask`、`diag2_mask`）即可在 $O(1)$ 时间内完成冲突检测，避免生成全部 $n^n$ 或 $n!$ 种布局后再事后检验。
2. **最优性剪枝 (Bound Pruning / Branch and Bound)**：在求最优解时，若当前部分解的代价加上剩余步数的乐观下界已经不优于目前已找到的最佳完整解，则直接剪枝。

## 3. C 语言实现示例：位掩码剪枝求解 $N$ 皇后问题

下面的程序利用列与两条对角线的位掩码在 $O(1)$ 内完成冲突判定与状态恢复，计算 $N$ 皇后问题的合法摆法总数：

```c
#include <stdint.h>
#include <stdio.h>

static void nqueens_dfs(
    unsigned int row,
    unsigned int n,
    uint64_t cols,
    uint64_t diag1,
    uint64_t diag2,
    uint64_t *out_count
) {
    if (row == n) {
        (*out_count)++;
        return;
    }
    uint64_t available = ((UINT64_C(1) << n) - 1) & ~(cols | diag1 | diag2);
    while (available != 0) {
        uint64_t bit = available & (~available + 1); // 提取最低位的 1
        available -= bit;
        nqueens_dfs(
            row + 1,
            n,
            cols | bit,
            (diag1 | bit) << 1,
            (diag2 | bit) >> 1,
            out_count
        );
    }
}

int main(void) {
    for (unsigned int n = 1; n <= 8; ++n) {
        uint64_t count = 0;
        nqueens_dfs(0, n, 0, 0, 0, &count);
        printf("N = %u: %llu solutions\n", n, (unsigned long long)count);
    }
    return 0;
}
```

运行结果：

::: terminal

N = 1: 1 solutions
N = 2: 0 solutions
N = 3: 0 solutions
N = 4: 2 solutions
N = 5: 10 solutions
N = 6: 4 solutions
N = 7: 40 solutions
N = 8: 92 solutions

:::

编写一个程序，通过填充空格来解决 $9 \times 9$ 的数独谜题。

数独的规则是：
1. 数字 $1-9$ 在每一行只能出现一次。
2. 数字 $1-9$ 在每一列只能出现一次。
3. 数字 $1-9$ 在每一个以粗实线分隔的 $3 \times 3$ 宫（box）内只能出现一次。

空白格用数字 `0` 表示，已填入的数字为 `1-9`。若数独有解，将其原地填满并返回 `true`；若无解，返回 `false`。

函数签名如下：

```c
#include <stdbool.h>
#include <stdint.h>

bool sudoku_solve(uint8_t grid[9][9]);
```

要求：
1. 参数为空指针时返回 `false`。
2. 输入的预填数字若本身存在行、列或宫冲突，返回 `false` 报告非法。
3. 采用**位掩码**跟踪行、列、宫中数字 $1-9$ 的占用状态。
4. 结合**最少剩余值启发式（MRV, Minimum Remaining Values）**：每次优先选择可用候选数字最少的空格进行分支扩展，最大限度减少回溯分支。

</Exercise>

给定 $n$ 件物品，每件物品具有重量 $w_i$ 和价值 $v_i$。背包的最大承重容量为 `capacity`。每件物品最多选择一次。

请采用**分支限界法（Branch and Bound）**求解在不超过背包容量的前提下所能获得的最大总价值。

函数签名如下：

```c
#include <stdbool.h>
#include <stddef.h>
#include <stdint.h>

bool knapsack_branch_and_bound(
    const size_t *weights,
    const uint64_t *values,
    size_t count,
    size_t capacity,
    uint64_t *out_max_value
);
```

要求：
1. 参数无效时返回 `false`；`count == 0` 或 `capacity == 0` 时最大价值为 0，输出 0 并返回 `true`。
2. 物品必须先按照**单位价值比（$v_i / w_i$）降序**进行预排序。
3. 搜索过程中，利用**分数背包线性松弛（Fractional Knapsack Relaxation）**作为当前节点的最优价值上界（Bound）。
4. 若当前累计价值加上计算出的松弛上界不超过已知的全局最优价值（`current_value + bound <= best_value`），则该分支不可能产生更优解，必须**立即剪枝**。

</Exercise>
