# 11. 最短路、最小生成树与连通性

当图的每条边带有非负数值权重（代表路程、时延或造价）时，“两点之间最少经过几条边”推广为**带权最短路径问题**，“用最少边连接所有顶点”推广为**最小生成树 (Minimum Spanning Tree, MST) 问题**。这两个经典问题均可借助贪心策略与前面建立的最小堆、并查集高效求解。

## 1. 最短路距离上界与边松弛 (Relaxation)

在单源最短路问题中，给定带权图 $G = (V, E, w)$ 与源点 $s$，算法为每个顶点 $v$ 维护一个当前已知最短距离上界 `dist[v]`：

- **初始化**：令 `dist[s] = 0`，对所有 $v \neq s$ 令 `dist[v] = UINT64_MAX`（代表 $+\infty$ 不可达）。
- **松弛操作 (`relax(u, v, w)`)**：若已知从 $s$ 到 $u$ 可达（`dist[u] != UINT64_MAX`），且经由 $u$ 走边 $(u, v)$ 到达 $v$ 的路径总长 `dist[u] + w` 小于当前的 `dist[v]`，则将 `dist[v]` 更新为 `dist[u] + w`。

::: warning 松弛加法的无符号溢出检查

在 C 语言中用 `uint64_t` 存储距离与边权时，判断 `dist[u] + w < dist[v]` 前**必须先检查加法是否溢出**（即检查 `w > UINT64_MAX - dist[u]`）。若直接计算 `dist[u] + w`，一旦真实路径长度超过 `UINT64_MAX`，无符号加法会回绕成一个很小的数并错误地覆盖 `dist[v]`。

:::

## 2. Dijkstra 单源最短路算法

当图中**所有边权均非负**（$\forall e \in E, \; w(e) \ge 0$）时，**Dijkstra 算法**维护一个已确定最终最短距离的顶点集合 $S$：

1. 使用**小根堆**存储待处理的二元组 `(dist, vertex)`，初始将 `(0, source)` 压入堆中；
2. 每次从堆顶弹出距离最小的条目 `(d, u)`：
   - **惰性删除过期条目**：由于标准二叉堆不支持高效按顶点下标直接修改键（`decrease_key`），我们在每次成功松弛 `dist[v]` 时直接向堆中压入一条新的 `(dist[v], v)`。因此弹出 `(d, u)` 时，若发现 `d > dist[u]`，说明它是更早压入的**过期条目**，直接跳过即可；
3. 对 $u$ 的每条出边 $(u, v, w)$ 执行松弛；若 `dist[v]` 被更新，则将 `(dist[v], v)` 压入小根堆。

### 2.1 为什么正确性证明依赖“边权非负”

设算法当前刚从堆中取出未确定顶点中 `dist` 最小的顶点 $u$。假设从 $s$ 到 $u$ 存在另一条更短的路径 $P$。由于 $s \in S$ 而 $u \notin S$，路径 $P$ 必然在某一步首次离开集合 $S$ 到达某个边界顶点 $y \notin S$。

- 因为 $y$ 是 $P$ 上首个不在 $S$ 中的顶点，其前驱已在 $S$ 中并被完整松弛过，故 $s$ 沿 $P$ 到 $y$ 的子路径长度不小于 `dist[y]`；
- 又因为 $u$ 是当前所有未确定顶点中 `dist` 最小者，故 `dist[y] >= dist[u]`；
- **关键一步**：从 $y$ 继续沿路径 $P$ 走到 $u$ 的剩余边权之和，只有在**所有边权非负**的前提下才保证 $\ge 0$！从而整条路径 $P$ 的总长 $\ge \text{dist}[y] + 0 \ge \text{dist}[u]$，不可能性严格小于 `dist[u]`。一旦存在负权边，后续负权边可能把已离开 $S$ 的路径总长拉低，Dijkstra 的贪心前提即告失效。

由于每条边至多触发一次有效松弛与入堆，堆中元素总数不超过 $E + 1$，总时间复杂度为 $O((V + E) \log V)$。

## 3. 最小生成树 (MST) 与 Kruskal 算法

给定连通的无向带权图 $G = (V, E, w)$，从 $E$ 中选出 $V - 1$ 条边使所有顶点连通且边权总和最小的子图称为**最小生成树**。

最小生成树建立在**切割性质 (Cut Property)** 之上：将顶点集 $V$ 任意划分为两个非空集合 $(S, V \setminus S)$，横跨该切割的所有边中权重最小的一条边，必然包含在某棵最小生成树中。

**Kruskal 算法**直接按边权从小到大应用切割性质：

1. 将全部 $E$ 条无向边按权重非递减排序（耗时 $O(E \log E)$）；
2. 初始化含 $V$ 个元素的**并查集 (DSU)**，已选边数 `chosen = 0`，总权重 `total = 0`；
3. 按序扫描每条边 $(u, v, w)$：用并查集检查 $u$ 与 $v$ 是否已在同一连通分量中；
   - 若在同一分量中，加入该边会产生环，跳过；
   - 若不在同一分量中，该边就是连接这两个分量的最轻横跨边，执行 `dsu_union(u, v)`，将 `w` 累加进 `total`（注意检查 `uint64_t` 加法溢出），并令 `chosen++`。
4. 扫描结束时，若 $V \le 1$ 或 `chosen == V - 1`，则 `total` 即为最小生成树总权重；若 $V > 1$ 且 `chosen < V - 1`，说明原无向图**不连通**，不存在生成树。

## 4. C 语言实现示例：Kruskal 最小生成树算法

```c
#include <stdbool.h>
#include <stddef.h>
#include <stdint.h>
#include <stdio.h>
#include <stdlib.h>

typedef struct {
    size_t u;
    size_t v;
    uint64_t w;
} Edge;

static int cmp_edge(const void *lhs, const void *rhs) {
    const Edge *a = (const Edge *)lhs;
    const Edge *b = (const Edge *)rhs;
    return (a->w > b->w) - (a->w < b->w);
}

static size_t find_root(size_t *parent, size_t x) {
    size_t r = x;
    while (parent[r] != r) {
        r = parent[r];
    }
    while (x != r) {
        size_t next = parent[x];
        parent[x] = r;
        x = next;
    }
    return r;
}

static bool kruskal_mst(size_t v_count, Edge *edges, size_t e_count, uint64_t *out_w) {
    if (v_count <= 1) {
        *out_w = 0;
        return true;
    }
    qsort(edges, e_count, sizeof(Edge), cmp_edge);
    size_t *parent = (size_t *)malloc(v_count * sizeof(size_t));
    if (parent == NULL) {
        return false;
    }
    for (size_t i = 0; i < v_count; ++i) {
        parent[i] = i;
    }
    size_t chosen = 0;
    uint64_t total = 0;
    for (size_t i = 0; i < e_count && chosen < v_count - 1; ++i) {
        size_t ru = find_root(parent, edges[i].u);
        size_t rv = find_root(parent, edges[i].v);
        if (ru != rv) {
            parent[rv] = ru;
            total += edges[i].w;
            chosen++;
        }
    }
    free(parent);
    if (chosen != v_count - 1) {
        return false;
    }
    *out_w = total;
    return true;
}

int main(void) {
    Edge edges[] = {{0, 1, 4}, {0, 2, 3}, {1, 2, 1}, {1, 3, 2}, {2, 3, 4}};
    uint64_t mst_w = 0;
    if (kruskal_mst(4, edges, 5, &mst_w)) {
        printf("MST weight = %llu\n", (unsigned long long)mst_w);
    }
    return 0;
}
```

MST weight = 6

:::

<Exercise id="36108" :d="6" :w="4">

在一个有向图 $G = (V, E)$ 中，如果两个顶点 $u$ 和 $v$ 之间既存在从 $u$ 到 $v$ 的有向路径，也存在从 $v$ 到 $u$ 的有向路径，则称 $u$ 和 $v$ 是强连通的。有向图的极大强连通子图称为**强连通分量（Strongly Connected Component, SCC）**。

请实现 Tarjan 算法：
1. 计算有向图中的强连通分量总数；
2. 为每个顶点赋予所属强连通分量的唯一标识 ID（从 0 开始连续标号）。

函数签名如下：

```c
#include <stdbool.h>
#include <stddef.h>

bool tarjan_scc(
    size_t vertex_count,
    const size_t edges[][2],
    size_t edge_count,
    size_t *out_scc_id,
    size_t *out_scc_count
);
```

要求：
1. 参数无效时返回 `false`。
2. 当 $V = 0$ 时，SCC 数量为 0，返回 `true`。
3. 利用显式栈、时间戳 `dfn` 与追溯值 `low` 在一次单遍深度优先搜索中完成求解，时间复杂度必须为 $O(V + E)$。
4. 缩点性质保证：同一强连通分量内的所有顶点具有完全相同的 `out_scc_id`，而将每个 SCC 缩为单个超级节点后，新图必然是一个**有向无环图（DAG）**。

</Exercise>
