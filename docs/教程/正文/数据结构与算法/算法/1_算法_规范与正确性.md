# 1. 算法、规范与正确性

在这一模块中，我们将介绍算法的定义和分析方法，并讲解一些经典算法的 C 语言实现。

::: warning 数学基础要求

本模块假定读者有一定的数学水平：基本的算术 + 集合论 + 概率论 + 矩阵。

《算法导论》附录 A~D 中有对这部分数学的简明扼要的讲解。

:::

## 1. 基本概念

### 1.1 定义

算法是为了解决某类问题而规定的一个有限长的操作序列。

### 1.2 特征

1. **有穷性**：一个算法必须总是在执行有穷步后结束，且每一步都必须在有穷时间内完成。
2. **确定性**：对每种情况下所应执行的操作，在算法中都有确切的规定，使算法的执行者或阅读者都能明确其含义及如何执行，不会产生二义性。
3. **可行性**：算法中的所有操作都可以通过已经实现的基本操作运算执行有限次来实现。
4. **输入**：一个算法有零个或多个输入。当用函数描述算法时，输入往往是通过形参表示的，在它们被调用时，从主调函数获得输入值。
5. **输出**：一个算法有一个或多个输出，它们是算法进行信息加工后得到的结果。

### 1.3 一个“公式”

$$程序=数据结构 + 算法$$

### 1.4 算法的表示

1. 自然语言
2. **流程图**和 **N-S 图**
3. **伪代码**（《算法导论》中采用这种方法）

## 2. 从问题描述到实现

编写代码之前，应先明确三点：输入是什么，输出是什么，算法由哪些步骤组成、为什么在有限步后结束。明确这三点之后，C 语言实现中的每个循环和分支都能对应到描述中的某一步，程序出错时也容易判断是算法有误还是实现有误。

## 3. 正确性与复杂度要同时给出

给出一个算法时，应同时回答两个问题：它为什么一定得到正确结果；它的时间和空间代价随输入规模如何增长。缺少正确性论证，就无法确认算法在边界输入上的行为；缺少复杂度分析，就无法判断输入规模增大后算法是否仍然可用。后续章节讨论每个算法时都会回答这两个问题。

## 4. 示例：线性搜索

下面的函数在数组中查找目标值第一次出现的位置，若不存在则返回 `-1`。

```c
#include <stdio.h>

static int linear_search(const int *a, int n, int target) {
    for (int i = 0; i < n; ++i) {
        if (a[i] == target) {
            return i;
        }
    }
    return -1;
}

int main(void) {
    int a[] = {8, 3, 2, 7, 3};
    int n = (int)(sizeof(a) / sizeof(a[0]));
    printf("index(7) = %d\n", linear_search(a, n, 7));
    printf("index(9) = %d\n", linear_search(a, n, 9));
    return 0;
}
```

运行结果：

::: terminal

index(7) = 3
index(9) = -1

:::

线性搜索在最坏情况下比较 $n$ 次，时间复杂度为 $O(n)$；它只使用常数个额外存储空间，空间复杂度为 $O(1)$。

实现满足严格前置条件与后置条件契约的欧几里得最大公约数、防溢出最小公倍数与扩展欧几里得算法：

```c
#include <stdbool.h>
#include <stdint.h>

uint64_t gcd_u64(uint64_t a, uint64_t b);
bool lcm_u64(uint64_t a, uint64_t b, uint64_t *out_lcm);
bool extended_gcd_i64(
    int64_t a,
    int64_t b,
    int64_t *out_gcd,
    int64_t *out_x,
    int64_t *out_y
);
```

要求：

1. `gcd_u64`：对任意 `uint64_t` 输入返回 $\gcd(a, b)$；规定 $\gcd(a, 0) = \gcd(0, a) = a$，且 $\gcd(0, 0) = 0$。
2. `lcm_u64`：当 `out_lcm == NULL` 时返回 `false`；若 $a = 0$ 或 $b = 0$，最小公倍数规定为 `0`；否则先除后乘计算 $\frac{a}{\gcd(a, b)} \times b$，若乘积超出 `UINT64_MAX` 则返回 `false` 且不改写输出。
3. `extended_gcd_i64`：若任一输出指针为 `NULL` 返回 `false`；若 $\gcd(a, b)$ 无法表示为非负 `int64_t`（如 `a == INT64_MIN && b == 0`），返回 `false`；否则使 `*out_gcd >= 0` 并求出满足贝祖等式 $a \cdot (*\text{out\_x}) + b \cdot (*\text{out\_y}) = *\text{out\_gcd}$ 的整数解，运算全程不得触发有符号整数溢出。
4. 说明欧几里得算法的规约不变式与基于良基关系的停机性。

</Exercise>

为经典二分查找算法编写形式化前置条件与后置条件契约断言，接口如下：

```c
#include <stdbool.h>
#include <stddef.h>
#include <stdint.h>

bool binary_search_contract(
    const int64_t *arr,
    size_t count,
    int64_t target,
    size_t *out_index
);
```

要求：

1. 前置条件断言：指针有效性（若 `count > 0` 则 `arr != NULL`，`out_index != NULL`），以及数组在区间 `[0, count)` 内严格满足非递减偏序关系。
2. 后置条件契约：若返回 `true`，`*out_index` 必满足分界性质——对所有下标 $i < *\text{out\_index}$ 恒有 $\text{arr}[i] < \text{target}$；若 $*\text{out\_index} < \text{count}$，则 $\text{arr}[*\text{out\_index}] \ge \text{target}$。
3. 在循环体内显式包含循环不变式断言，并分析其时间复杂度与空间复杂度。

</Exercise>
