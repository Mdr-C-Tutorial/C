# 8. 动态规划

动态规划 (Dynamic Programming, DP) 适用的问题通常有两个特征：同一子问题会被重复求解，且原问题的最优解可以由子问题的最优解组合得到。使用动态规划时，需要把问题划分为一组按一定顺序求解、结果可以复用的子问题，称为状态；再写出由已知状态求出新状态的转移方程。

## 1. 什么时候该考虑动态规划

如果直接递归求解时，同一个子问题（例如同一段区间、同一对下标、同一剩余容量）被反复求解，即存在重叠子问题，就可以考虑改用动态规划。另一个条件是最优子结构：问题的最优解可以由规模更小的子问题的最优解组合得到。最长公共子序列、背包和编辑距离都满足这两个条件。如果后续决策依赖的历史信息无法用规模可以接受的状态描述，就不适合直接用动态规划建模。

## 2. 状态、转移、边界

设计动态规划算法需要确定三件事。状态描述求解进行到了哪一步，它必须包含后续决策需要的全部信息，但不应包含无关的细节。转移描述状态之间的依赖关系，通常是对若干个已知状态取 `max`、`min` 或求和。边界条件给出递推的起点，决定 DP 表能否被正确填满。动态规划程序的错误多来自边界条件遗漏或下标含义前后不一致，因此编写代码前，应先用一句话写明状态的含义。

## 3. 两种实现路径

记忆化搜索 (memoization) 和自底向上填表是同一组转移方程的两种计算顺序。记忆化搜索的写法与递归式一一对应，代码短，便于推导；自底向上填表没有递归调用，计算顺序明确，也更容易压缩空间。可以先写记忆化版本验证状态定义是否正确，再改写为迭代版本以提高效率。

## 4. 示例一：斐波那契的记忆化搜索

下面的程序用数组 `memo` 缓存已经计算过的斐波那契数，使每一项只计算一次，时间复杂度为 $O(n)$。`memo[n]` 保存第 `n` 项的值，值为 `-1` 表示尚未计算。

```c
#include <stdio.h>

enum { MAX_N = 93 };

static long long memo[MAX_N + 1];

static void init_memo(void) {
    for (int i = 0; i <= MAX_N; ++i) {
        memo[i] = -1;
    }
}

static long long fib(int n) {
    if (n <= 1) {
        return n;
    }
    if (memo[n] != -1) {
        return memo[n];
    }
    memo[n] = fib(n - 1) + fib(n - 2);
    return memo[n];
}

int main(void) {
    init_memo();
    int n = 50;
    printf("fib(%d) = %lld\n", n, fib(n));
    return 0;
}
```

运行结果：

::: terminal

fib(50) = 12586269025

:::

## 5. 示例二：0/1 背包的自底向上写法

0/1 背包问题中，每件物品只有选与不选两种决策。设 `dp[i][c]` 表示只考虑前 `i` 件物品、容量上限为 `c` 时能达到的最大价值。若第 `i` 件物品的重量超过 `c`，则只能不选，`dp[i][c] = dp[i-1][c]`；否则取 `dp[i-1][c]` 与 `dp[i-1][c - w[i]] + v[i]` 中的较大者。第 7 节的空间压缩也基于这一状态定义。

```c
#include <stdio.h>

enum { N = 4, CAP = 8 };

int main(void) {
    int w[N + 1] = {0, 2, 3, 4, 5};
    int v[N + 1] = {0, 3, 4, 5, 8};
    int dp[N + 1][CAP + 1] = {0};

    for (int i = 1; i <= N; ++i) {
        for (int c = 0; c <= CAP; ++c) {
            dp[i][c] = dp[i - 1][c];
            if (c >= w[i]) {
                int cand = dp[i - 1][c - w[i]] + v[i];
                if (cand > dp[i][c]) {
                    dp[i][c] = cand;
                }
            }
        }
    }

    printf("max_value = %d\n", dp[N][CAP]);
    return 0;
}
```

运行结果：

::: terminal

max_value = 12

:::

## 6. 示例三：最长公共子序列（LCS）长度与回溯

LCS 的状态常定义为 `dp[i][j]`，表示 `a` 的前 `i` 个字符与 `b` 的前 `j` 个字符的 LCS 长度。若 `a[i-1] == b[j-1]`，则 `dp[i][j] = dp[i-1][j-1] + 1`；否则取 `dp[i-1][j]` 与 `dp[i][j-1]` 中的较大者。填表完成后，从 `dp[n][m]` 开始逆向回溯，可以恢复一条最长公共子序列。

```c
#include <stdio.h>
#include <string.h>

enum { MAX_LEN = 64 };

int main(void) {
    const char *a = "ABCBDAB";
    const char *b = "BDCABA";
    int n = (int)strlen(a);
    int m = (int)strlen(b);
    int dp[MAX_LEN][MAX_LEN] = {0};

    for (int i = 1; i <= n; ++i) {
        for (int j = 1; j <= m; ++j) {
            if (a[i - 1] == b[j - 1]) {
                dp[i][j] = dp[i - 1][j - 1] + 1;
            } else {
                dp[i][j] = dp[i - 1][j] > dp[i][j - 1] ? dp[i - 1][j] : dp[i][j - 1];
            }
        }
    }

    char out[MAX_LEN] = {0};
    int k = dp[n][m];
    out[k] = '\0';
    int i = n;
    int j = m;
    while (i > 0 && j > 0) {
        if (a[i - 1] == b[j - 1]) {
            out[--k] = a[i - 1];
            --i;
            --j;
        } else if (dp[i - 1][j] >= dp[i][j - 1]) {
            --i;
        } else {
            --j;
        }
    }

    printf("lcs_len = %d\n", dp[n][m]);
    printf("lcs = %s\n", out);
    return 0;
}
```

运行结果：

::: terminal

lcs_len = 4
lcs = BCBA

:::

## 7. 常见优化：空间压缩

当 `dp[i][*]` 只依赖上一行时，可以把二维表压缩为一维数组。以 0/1 背包为例，空间复杂度从 $O(nC)$ 降为 $O(C)$。容量必须从大到小枚举，这样读取 `dp[c - w[i]]` 时得到的仍是处理上一件物品之后的结果；若从小到大枚举，同一件物品可能被重复选择，求解的就变成了完全背包问题。

```c
for (int i = 1; i <= n; ++i) {
    for (int c = cap; c >= w[i]; --c) {
        int cand = dp[c - w[i]] + v[i];
        if (cand > dp[c]) {
            dp[c] = cand;
        }
    }
}
```

这段代码是第 5 节二重循环的一维写法，其中 `dp` 是长度为 `cap + 1`、初值全为 0 的数组。

## 8. 写 DP 代码时最容易出错的点

常见的错误之一是状态含义前后不一致，例如一段代码把 `dp[i][j]` 当作前缀长度为 `i` 的结果，另一段代码又把 `i` 当作下标，导致边界与转移互相矛盾。另一个常见错误是遗漏初值，特别是没有用明确的哨兵值标记不可达状态，使 `max` 或 `min` 把不合法的路径也计算在内。检查时，可以先写出状态的含义，逐一核对各循环的边界是否与之一致，再用最小的样例手工填一遍表格，确认每个格子的值都来自正确的状态。
