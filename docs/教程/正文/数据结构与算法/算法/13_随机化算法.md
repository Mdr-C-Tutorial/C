# 13. 随机化算法

在确定性快速排序或快速选择中，如果枢轴（Pivot）总是按固定位置（如首元素、尾元素或中点）选取，攻击者或特定业务场景总能构造出使每次划分都极度失衡的输入序列，导致时间复杂度退化为 $\Theta(n^2)$。**随机化算法 (Randomized Algorithm)** 通过在算法内部引入随机数源，将运行时间的期望分布转移到算法自身的随机选择上，从而保证**对于任意固定的输入（包括精心构造的对抗性输入）**，都能获得优异的期望性能。

本章讨论的洗牌、随机化选择与随机化快速排序均属于**拉斯维加斯 (Las Vegas) 算法**：它们永远给出完全精确、正确的结果，随机性仅体现在运行时间的分布上（但仍需清醒认识：期望 $O(n \log n)$ 不等于最坏情况上界保证）。

## 1. 模偏差 (Modulo Bias) 与无偏拒绝采样

给定一个每次均匀产生 64 位无符号随机整数（取值范围 $[0, 2^{64})$）的回调源 `uint64_t random_bits(void *ctx)`，我们经常需要从区间 $[0, \text{bound})$（$\text{bound} \ge 1$）中等概率抽取一个下标。

### 1.1 为什么不能直接写 `random_bits(ctx) % bound`

设全域大小 $M = 2^{64}$。当 $\text{bound}$ 不是 $2^{64}$ 的约数（即 $\text{bound}$ 不是 2 的整数次幂）时，设带余除法为：

$$2^{64} = q \cdot \text{bound} + R \quad (0 < R < \text{bound})$$

如果直接计算 `r % bound`，那么余数落在 $[0, R)$ 内的每个值都有 $q + 1$ 个原像，而余数落在 $[R, \text{bound})$ 内的每个值只有 $q$ 个原像——前一部分下标被抽中的概率高于后一部分，这种分布失真称为**模偏差 (Modulo Bias)**。

### 1.2 无偏拒绝采样 (Rejection Sampling)

要彻底消除模偏差，只需丢弃头部（或尾部）多出来的那 $R = 2^{64} \bmod \text{bound}$ 个值，只在长度为 $\text{bound}$ 整数倍的区间内取模。

在 C 语言的 64 位无符号算术中，`-bound`（即 `0 - bound`）的值恰好是 $2^{64} - \text{bound}$。因此余数 $R = 2^{64} \bmod \text{bound}$ 可以用一行无符号运算精确求出：

```c
static uint64_t uniform_index(
    uint64_t bound,
    uint64_t (*random_bits)(void *),
    void *ctx
) {
    uint64_t threshold = (UINT64_C(0) - bound) % bound; // 等于 2^64 mod bound
    for (;;) {
        uint64_t r = random_bits(ctx);
        if (r >= threshold) {
            return r % bound;
        }
    }
}
```

因为 $R < \text{bound} \le 2^{63}$ 时单次采样落入拒绝区 $[0, \text{threshold})$ 的概率严格小于 $1/2$，平均采样次数少于 $2$ 次，期望耗时为 $O(1)$，且输出的下标在 $[0, \text{bound})$ 上**严格均匀分布**。

## 2. Fisher–Yates 原地洗牌算法

要将长度为 $n$ 的数组原地打乱，使得全部 $n!$ 种排列以严格相等的概率 $\frac{1}{n!}$ 出现，标准解法是 **Fisher–Yates（Knuth）洗牌算法**：

- 下标 $i$ 从 $n - 1$ 递减到 $1$：
  - 使用无偏采样从闭区间 $[0, i]$（即 $\text{bound} = i + 1$）中等概率随机抽取一个下标 $j$；
  - 交换 `items[i]` 与 `items[j]`。

**等概率证明**：在第 $1$ 步（$i = n - 1$），任意元素被换到末尾位置 $n - 1$ 的概率均为 $\frac{1}{n}$；此后位置 $n - 1$ 不再参与后续交换。在第 $2$ 步（$i = n - 2$），剩余 $n - 1$ 个元素中任意一个被换到位置 $n - 2$ 的条件概率均为 $\frac{1}{n - 1}$。由乘法原理，任何特定排列生成的概率恰为：

$$\frac{1}{n} \times \frac{1}{n - 1} \times \cdots \times \frac{1}{2} \times 1 = \frac{1}{n!}$$

::: warning 经典错误：每一步都从 $[0, n - 1]$ 随机抽取

如果把 `j = uniform_index(i + 1, ...)` 误写成 `j = uniform_index(n, ...)`，那么 $n$ 步共有 $n^n$ 种等概率路径。当 $n \ge 3$ 时，$n^n$ 不能被 $n!$ 整除（例如 $3^3 = 27$ 不能被 $3! = 6$ 整除），生成的排列分布必然是有偏的！

:::

## 3. 随机化三路快速排序与调用栈空间控制

结合无偏随机枢轴与三路分区（Dutch National Flag），可以得到在含大量重复元素或已排序输入上依然保持优异性能的**随机化快速排序**：

1. **随机选取枢轴**：在当前子区间 `[left, right]` 内用 `uniform_index(right - left + 1, ...)` 等概率选出一个位置，以该位置的元素作为 `pivot`。
2. **三路原地分区**：将 `[left, right]` 划分为 `< pivot`（`[left, lt - 1]`）、`== pivot`（`[lt, gt]`）和 `> pivot`（`[gt + 1, right]`）三段。与相等段重合的所有元素一步到位，不再进入后续递归。
3. **小分区递归、大分区循环迭代**：为了防止极端随机数序列下递归调用栈退化为 $O(n)$，在每轮分区结束后，比较左子区间 `[left, lt - 1]` 与右子区间 `[gt + 1, right]` 的长度：**仅对较短的那个子区间发起递归调用，而将较长的那个子区间通过更新 `left` 或 `right` 留在当前函数的 `while` 循环中继续迭代**。由于每次递归进入的子区间长度至多是原区间的一半，调用栈深度在**最坏情况下也严格不超过 $\lfloor \log_2 n \rfloor$**，额外栈空间复杂度保证为 $O(\log n)$。

## 4. C 语言实现示例：Fisher–Yates 洗牌与随机化三路快排

```c
#include <stddef.h>
#include <stdint.h>
#include <stdio.h>

static uint64_t xorshift64(void *ctx) {
    uint64_t *state = (uint64_t *)ctx;
    uint64_t x = *state;
    x ^= x << 13;
    x ^= x >> 7;
    x ^= x << 17;
    *state = x;
    return x;
}

static uint64_t uniform_index(uint64_t bound, uint64_t (*rng)(void *), void *ctx) {
    uint64_t threshold = (UINT64_C(0) - bound) % bound;
    for (;;) {
        uint64_t r = rng(ctx);
        if (r >= threshold) {
            return r % bound;
        }
    }
}

static void swap_i64(int64_t *a, int64_t *b) {
    int64_t t = *a;
    *a = *b;
    *b = t;
}

static void fisher_yates_shuffle(
    int64_t *a,
    size_t n,
    uint64_t (*rng)(void *),
    void *ctx
) {
    for (size_t i = n - 1; i > 0; --i) {
        size_t j = (size_t)uniform_index((uint64_t)(i + 1), rng, ctx);
        swap_i64(&a[i], &a[j]);
    }
}

static void rqsort_range(
    int64_t *a,
    size_t left,
    size_t right,
    uint64_t (*rng)(void *),
    void *ctx
) {
    while (left < right) {
        size_t len = right - left + 1;
        size_t piv_idx = left + (size_t)uniform_index((uint64_t)len, rng, ctx);
        int64_t pivot = a[piv_idx];

        size_t lt = left, i = left, gt = right;
        while (i <= gt) {
            if (a[i] < pivot) {
                swap_i64(&a[lt++], &a[i++]);
            } else if (a[i] > pivot) {
                swap_i64(&a[i], &a[gt--]);
            } else {
                i++;
            }
        }

        size_t left_len = (lt > left) ? (lt - left) : 0;
        size_t right_len = (right > gt) ? (right - gt) : 0;
        if (left_len < right_len) {
            if (left_len > 1) {
                rqsort_range(a, left, lt - 1, rng, ctx);
            }
            if (right_len == 0) {
                break;
            }
            left = gt + 1;
        } else {
            if (right_len > 1) {
                rqsort_range(a, gt + 1, right, rng, ctx);
            }
            if (left_len == 0) {
                break;
            }
            right = lt - 1;
        }
    }
}

int main(void) {
    uint64_t seed = UINT64_C(88172645463325252);
    int64_t a[] = {1, 2, 3, 4, 5, 5, 6};
    size_t n = sizeof(a) / sizeof(a[0]);

    fisher_yates_shuffle(a, n, xorshift64, &seed);
    rqsort_range(a, 0, n - 1, xorshift64, &seed);

    for (size_t i = 0; i < n; ++i) {
        printf("%lld ", (long long)a[i]);
    }
    printf("\n");
    return 0;
}
```

:::
