# 10. 图遍历与拓扑排序

图上的绝大多数算法都建立在系统化访问所有可达顶点的**图遍历**之上。广度优先搜索（BFS）按距离由近及远逐层扩展，天然给出无权图的最短路；深度优先搜索（DFS）沿路径深入到底再回溯，不仅能划分无向图的连通分量，还能通过顶点状态染色判定有向环并构造有向无环图（DAG）的拓扑序。

## 1. 广度优先搜索 (BFS) 与无权图最短路

给定源点 $s$，**广度优先搜索 (Breadth-First Search, BFS)** 使用先进先出（FIFO）队列，按与源点距离（最少边数）递增的顺序逐层访问顶点：

1. 初始化距离数组：$\text{dist}[s] = 0$，其余所有顶点 $\text{dist}[v] = \infty$（在 C 语言中常用 `SIZE_MAX` 表示不可达），并将 $s$ 入队。
2. 当队列非空时，弹出队首顶点 $u$，依次扫描 $u$ 的每个邻接顶点 $v$：
   - 若 $\text{dist}[v] == \text{SIZE\_MAX}$（说明 $v$ 尚未被发现），则立即令 $\text{dist}[v] = \text{dist}[u] + 1$ 并将 $v$ 压入队尾。

### 1.1 为什么每个顶点最多入队一次且给出最短路

- **入队时机决定 $O(V + E)$ 复杂度**：必须在**将顶点 $v$ 压入队列的同时**修改其访问状态（或设置 `dist[v]`），而不是等它从队首弹出时才标记。这样任何已在队列中等待的顶点都不会被其他邻居重复入队；每个顶点至多入队、出队各一次，每条邻接表边至多被扫描一次，总时间复杂度严格为 $O(V + E)$。
- **队列距离单调不变式**：归纳可知，任意时刻队列中的顶点距离具有形如 $d, \dots, d, d + 1, \dots, d + 1$ 的非递减两段性。因此顶点 $v$ 第一次被发现时赋予的 $\text{dist}[v]$ 必定是从 $s$ 到 $v$ 的最短路径边数。

## 2. 深度优先搜索 (DFS)、连通分量与三色环检测

**深度优先搜索 (Depth-First Search, DFS)** 优先沿着当前顶点的第一条未访问出边不断深入，直到某个顶点的所有出边均已探查完毕，再回溯到其父结点继续探查下一条分支。

- **显式栈顺序控制**：在递归实现中，按邻接表下标从 $0$ 到 $\text{count} - 1$ 依次递归天然符合加边顺序。若当顶点数 $V$ 很大、为避免调用栈溢出而改用**显式栈**时，可以在栈帧中保存 `(vertex, next_edge_index)` 游标，或者将未访问邻居按逆序压栈，从而与递归访问顺序完全一致。
- **无向图连通分量统计**：对于无向图，从 $0$ 到 $V - 1$ 依次检查每个顶点；每当遇到一个未访问顶点，就将连通分量计数加 $1$ 并从该顶点启动一次完整遍历（标记其所在连通分量的全部顶点）。

### 2.1 有向图的三色标记与有向环检测

在无向图中，只需布尔数组 `visited` 即可遍历；但在**有向图**中，遇到一个“已经被访问过的顶点 $v$”**并不一定**意味着存在有向环（例如从根分别走两条路径汇合到同一个已搜索完毕的汇点 $v$）。

为了准确识别有向环，DFS 为每个顶点维护**三种颜色状态**：

| 状态值 | 颜色名称 | 语义说明 |
| --- | --- | --- |
| `0` | **白色 (`WHITE`)** | 尚未被发现的顶点 |
| `1` | **灰色 (`GRAY`)** | 已被发现、但其子树尚未搜索完毕，当前正处于**活动调用栈**上（即当前顶点的祖先） |
| `2` | **黑色 (`BLACK`)** | 该顶点及其所有可达后代均已搜索完毕，已退栈 |

**定理**：有向图 $G$ 存在有向环，当且仅当在三色 DFS 过程中，从当前灰色顶点 $u$ 扫描到一条指向**灰色顶点** $v$ 的有向边 $(u, v)$（称为**回边 / Back Edge**）。因为 $v$ 为灰色意味着 $v$ 是 $u$ 在当前调用栈上的祖先，存在路径 $v \leadsto u$，加上边 $u \to v$ 即构成有向环。而指向黑色顶点的边只是横叉边或前向边，不会形成环。

## 3. 有向无环图 (DAG) 与拓扑排序

如果一个有向图不包含任何有向环，则称为**有向无环图 (Directed Acyclic Graph, DAG)**。DAG 的**拓扑排序 (Topological Sort)** 是将所有顶点排成一个线性序列，使得对于图中每一条有向边 $u \to v$，顶点 $u$ 在序列中都排在 $v$ 的前面。

工程上最常用的是无需递归的 **Kahn 算法（入度队列法）**：

1. 遍历所有边，统计每个顶点的入度 `in_degree[v]`；
2. 将所有初始 `in_degree[u] == 0`（无任何前置依赖）的顶点压入队列；
3. 当队列非空时，弹出顶点 $u$ 追加到拓扑序输出数组，并遍历 $u$ 的每条出边 $u \to v$：将 `in_degree[v]` 减 $1$；若减 $1$ 后 `in_degree[v] == 0`，则将 $v$ 压入队列；
4. 循环结束时，若输出的顶点总数等于 $V$，则得到合法拓扑序；若输出顶点数小于 $V$，说明剩余顶点互为前置依赖，图中必然存在有向环！

## 4. C 语言实现示例：Kahn 拓扑排序与环检测

```c
#include <stdbool.h>
#include <stddef.h>
#include <stdio.h>
#include <stdlib.h>

typedef struct {
    size_t from;
    size_t to;
} DirectedEdge;

static bool kahn_topological_sort(
    size_t v_count,
    const DirectedEdge *edges,
    size_t e_count,
    size_t *out_order
) {
    size_t *in_deg = (size_t *)calloc(v_count, sizeof(size_t));
    size_t *queue = (size_t *)malloc(v_count * sizeof(size_t));
    if (in_deg == NULL || queue == NULL) {
        free(in_deg);
        free(queue);
        return false;
    }
    for (size_t i = 0; i < e_count; ++i) {
        in_deg[edges[i].to]++;
    }
    size_t head = 0, tail = 0;
    for (size_t u = 0; u < v_count; ++u) {
        if (in_deg[u] == 0) {
            queue[tail++] = u;
        }
    }
    size_t count = 0;
    while (head < tail) {
        size_t u = queue[head++];
        out_order[count++] = u;
        for (size_t i = 0; i < e_count; ++i) {
            if (edges[i].from == u) {
                size_t v = edges[i].to;
                if (--in_deg[v] == 0) {
                    queue[tail++] = v;
                }
            }
        }
    }
    free(in_deg);
    free(queue);
    return count == v_count;
}

int main(void) {
    DirectedEdge dag[] = {{0, 1}, {0, 2}, {1, 3}, {2, 3}};
    size_t order[4] = {0};
    if (kahn_topological_sort(4, dag, 4, order)) {
        printf("topo order: %zu %zu %zu %zu\n",
               order[0], order[1], order[2], order[3]);
    }
    DirectedEdge cyc[] = {{0, 1}, {1, 2}, {2, 0}};
    printf("has_topo(cyc) = %d\n", kahn_topological_sort(3, cyc, 3, order));
    return 0;
}
```

:::
