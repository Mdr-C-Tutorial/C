# 7. 贪心算法

在求解最优化问题时，**贪心算法 (Greedy Algorithm)** 在每一步决策中都直接作出在当前状态下局部看起来最好的选择，并期望通过一系列局部最优选择直接导向全局最优解。与动态规划需要枚举并保存所有子问题状态不同，贪心算法一旦作出选择便不再回退，因此通常更为高效；但贪心策略并非对所有问题都成立，使用前必须严格证明其正确性。

## 1. 贪心法的两个理论支柱与证明方法

一个问题能够用贪心算法精确求解，当且仅当它同时具备以下两条性质：

1. **贪心选择性质 (Greedy-Choice Property)**：存在某个局部最优选择，它一定包含在原问题的**某一个**全局最优解之中。
2. **最优子结构 (Optimal Substructure)**：作出第一步贪心选择后，剩余待解决的子问题具有与原问题相同的形式，且原问题的最优解由该贪心选择与子问题的最优解直接组合而成。

证明贪心选择性质最常用的技术是**交换论证法 (Exchange Argument)**：

- 任取原问题的一个全局最优解 $O$；
- 若 $O$ 已经包含了贪心算法作出的第一步选择 $g_1$，则命题得证；
- 若 $O$ 没有包含 $g_1$，则从 $O$ 中找出与 $g_1$ 对应的某个元素 $x$，将 $x$ 替换为 $g_1$ 构造出新解 $O'$，并证明 $O'$ 既满足全部约束条件，其目标函数值又**不劣于** $O$。这就证明了必存在一个包含 $g_1$ 的全局最优解。

## 2. 三类经典贪心模型

### 2.1 不重叠区间选择（最早结束时间优先）

给定 $n$ 个半开区间 $[s_i, e_i)$，要求选出数量最多的两两不重叠区间。

- **贪心策略**：将所有区间按**结束时刻 $e_i$ 升序**排列。第一步选择结束最早的区间 $g_1$；随后线性扫描，每当遇到开始时刻 $s_i \ge$ 上一个已选区间结束时刻的区间，就立即选中它。
- **交换论证**：设某个最优解按时间顺序选出的第一个区间为 $x_1$。由于贪心选择 $g_1$ 是全局结束最早的区间，必有 $e(g_1) \le e(x_1)$。在最优解中将 $x_1$ 替换为 $g_1$，由于 $e(g_1) \le e(x_1) \le s(x_2)$，$g_1$ 与最优解中的后续区间 $x_2, x_3, \dots$ 依然互不重叠，且选出的区间总数不变。对剩余子问题归纳即证贪心解必为全局最优。

### 2.2 最小代价两两合并（哈夫曼树思想）

给定 $n$ 堆重量为 $w_1, w_2, \dots, w_n$ 的材料，每次将任意两堆合并为一堆，消耗代价为两堆重量之和，求合并为一堆的最小总代价。

- **贪心策略**：将所有重量放入**小根堆**；只要堆中元素不少于 $2$ 个，每次弹出当前**最小的两个重量 $x, y$**，将代价 $x + y$ 累加入总和，再把新堆重量 $x + y$ 压回小根堆中，时间复杂度为 $O(n \log n)$。
- **交换论证**：合并过程对应一棵带权二叉树，总代价等于各初始叶结点的重量乘以其在树中的深度之和 $\sum w_i d_i$。若在某棵最优合并树中，权重最小的两个叶结点 $x, y$ 不在最大深度 $d_{\max}$ 处，将它们与最大深度处的叶结点交换后，权重更小的项乘以更大的深度，总代价不会增加。因此将最小两项优先合并为兄弟结点一定不破坏全局最优性。

### 2.3 区间划分与峰值并发资源数（最早开始优先 + 小根堆）

给定 $n$ 个任务区间 $[s_i, e_i)$，同一台资源上的任务不可重叠，求完成全部任务所需的最少资源数。

- **贪心策略**：将所有任务按**开始时刻 $s_i$ 升序**排列，并用一个**小根堆**维护当前已分配各台资源的“最后结束时刻”。遍历每个任务 $[s_i, e_i)$：若堆非空且堆顶（最早空闲的资源结束时刻）$\le s_i$，则弹出堆顶并压入 $e_i$（复用该资源）；否则直接压入 $e_i$（新分配一台资源）。遍历结束时堆中的元素个数即为所需的最少资源数（等于最大并发重叠区间数）。

::: warning `qsort` 比较器严禁用整数相减代替三路比较

在 C 语言中为 `qsort` 编写 `int64_t` 比较函数时，**绝对不能**写成 `return (int)(a->end - b->end);`：一方面，两个 `int64_t` 相减极易超出 `INT64_MIN..INT64_MAX` 触发有符号整数溢出（未定义行为）；另一方面，把 `int64_t` 差值截断为 `int` 会丢失高位符号。标准安全写法是 `(a->end > b->end) - (a->end < b->end)`。

:::

## 3. C 语言实现示例：区间调度贪心算法

```c
#include <stddef.h>
#include <stdint.h>
#include <stdio.h>
#include <stdlib.h>

typedef struct {
    int64_t start;
    int64_t end;
} Interval;

static int cmp_interval_by_end(const void *lhs, const void *rhs) {
    const Interval *a = (const Interval *)lhs;
    const Interval *b = (const Interval *)rhs;
    if (a->end != b->end) {
        return (a->end > b->end) - (a->end < b->end);
    }
    return (a->start > b->start) - (a->start < b->start);
}

static size_t max_non_overlapping(Interval *items, size_t count) {
    if (count == 0) {
        return 0;
    }
    qsort(items, count, sizeof(Interval), cmp_interval_by_end);
    size_t chosen = 1;
    int64_t last_end = items[0].end;
    for (size_t i = 1; i < count; ++i) {
        if (items[i].start >= last_end) {
            chosen++;
            last_end = items[i].end;
        }
    }
    return chosen;
}

int main(void) {
    Interval movies[] = {{1, 4}, {3, 5}, {0, 6}, {5, 7}, {8, 9}, {5, 9}};
    size_t n = sizeof(movies) / sizeof(movies[0]);
    printf("max movies = %zu\n", max_non_overlapping(movies, n));
    return 0;
}
```

运行结果：

::: terminal

max movies = 3

:::

电影院在同一个放映厅安排了若干部电影。每部电影用半开区间 `[start, end)` 表示，实现：

```c
#include <stdbool.h>
#include <stddef.h>
#include <stdint.h>

typedef struct {
    int64_t start;
    int64_t end;
} Movie;

bool maximum_movie_count(
    Movie *movies,
    size_t count,
    size_t *out_count
);
```

要求：

1. 求一个人从头到尾能够观看的最多电影数量；一部电影结束时可以立即观看此时开始的另一部电影。
2. 每个区间必须满足 `start < end`；先检查全部区间，再修改数组。
3. 可以使用 `qsort` 原地重排输入数组，并在接口说明中明确这一点。
4. 比较器不得用两个时间直接相减来决定顺序。
5. 参数无效时返回 `false`，并保持输出对象和电影数组不变。
6. 排序后使用一次线性扫描完成选择，总时间复杂度为 $O(n\log n)$。

分数背包问题（Fractional Knapsack）按性价比贪心求解与形式化证明：

给定 $n$ 种物品，每种物品具有重量 $w_i > 0$ 和总价值 $v_i \ge 0$。背包最大承重为 $W$。物品可以分割任意连续比例装入：

```c
#include <stdbool.h>
#include <stddef.h>

typedef struct {
    double weight;
    double value;
} KnapsackItem;

bool fractional_knapsack(
    KnapsackItem *items,
    size_t count,
    double capacity,
    double *out_max_value
);
```

要求：

1. 按照单位重量价值（性价比 $\rho_i = v_i / w_i$）降序排列物品；
2. 优先装入性价比最高者，最后一件若容量不足则按剩余容量比例切分装入；
3. 使用**交换论证法（Exchange Argument）**严格证明：若存在不同于贪心选择的最优解，总能通过等量替换转化为包含贪心解且总价值不减的新解，从而确立贪心选择性质；
4. 编写包含容量不足、容量富余、性价比相同等场景的测试断言。

</Exercise>

加油站环形循环回路存在性（贪心前缀和波谷定位）：

在一条环形公路上有 $n$ 个加油站，第 $i$ 个加油站有汽油 `gas[i]`，从第 $i$ 个加油站开往下一个加油站消耗汽油 `cost[i]`。判断是否存在一个起始加油站，使得汽车能顺时针绕环路行驶一周：

```c
#include <stddef.h>
#include <stdint.h>

int64_t can_complete_circuit(
    const int64_t *gas,
    const int64_t *cost,
    size_t n
);
```

要求：

1. 若存在解，返回起始加油站下标（保证若有解则解唯一）；若不存在返回 -1；
2. 形式化证明：环路可完成的充分必要条件为净收益总和 $\sum_{i=0}^{n-1} (\text{gas}[i] - \text{cost}[i]) \ge 0$；
3. 证明合法的唯一出发点必然位于前缀净油量和的**全局波谷（全局最小值）的下一个站点**；
4. 一次遍历完成求解，时间复杂度严格为 $\Theta(n)$，空间复杂度严格为 $O(1)$。

</Exercise>

拟阵（Matroid）与贪心选择性质的形式化证明：

拟阵是定义在有限子集系统上的代数结构，为贪心算法提供统一的理论框架。

1. 形式化给出拟阵 $M = (S, \mathcal{I})$ 的三条公理：非空性、遗传性（Hereditary Property）与交换性（Exchange Property / Augmentation Property）；
2. 证明 Rado-Edmonds 定理：对有限子集系统赋予任意正权函数，贪心算法总能找到具有最大权值的基（极大独立集），当且仅当该系统是一个拟阵；
3. 将最小生成树问题形式化为图拟阵（Graphic Matroid），并使用拟阵理论证明 Kruskal 算法贪心选择的全局最优性；
4. 编写 C 语言通用的拟阵贪心算法求解框架，并在图拟阵上测试验证。

</Exercise>
