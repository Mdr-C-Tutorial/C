# 12. 字符串匹配

给定长度为 $n$ 的文本字节序列 $T[0..n)$ 与长度为 $m$ 的模式字节序列 $P[0..m)$，**精确子串匹配问题**要求找出 $P$ 在 $T$ 中第一次出现的起始下标 $s$（满足 $0 \le s \le n - m$ 且对所有 $0 \le j < m$ 有 $T[s + j] == P[j]$）。

在朴素匹配算法中，每次在位置 $s + q$ 发生失配时，都会丢弃已经匹配成功的 $q$ 个字符信息，将模式右移 $1$ 位（令 $s \leftarrow s + 1$）从头重新比较。在形如 $T = \text{"aaaa}\dots\text{ab"}$、$P = \text{"aaab"}$ 的周期性数据上，朴素算法会退化为 $\Theta(nm)$。**KMP 算法**（Knuth–Morris–Pratt）利用模式串自身的局部周期性质，使文本下标永不回退，在最坏情况下以严格的线性时间 $O(n + m)$ 完成匹配。

## 1. 前缀函数（$\pi$ 数组）的定义与几何意义

对于模式串 $P[0..m)$，定义其**前缀函数 (Prefix Function)** $\pi[0..m)$：对每个下标 $i \in [0, m)$，$\pi[i]$ 表示子串 $P[0..i]$ 的**最长相等真前缀与真后缀的长度**：

$$\pi[i] = \max\{\, k \in [0, i] \;\mid\; P[0..k - 1] == P[i - k + 1..i] \,\}$$

这里“真前缀”指不等于 $P[0..i]$ 自身的前缀，因此恒有 $0 \le \pi[i] \le i$，且必然有 $\pi[0] = 0$。

例如，对于模式串 $P = \text{"ABABCABAA"}$，其前缀函数表为：

| 下标 $i$ | `0` | `1` | `2` | `3` | `4` | `5` | `6` | `7` | `8` |
| --- | --- | --- | --- | --- | --- | --- | --- | --- | --- |
| $P[i]$ | `A` | `B` | `A` | `B` | `C` | `A` | `B` | `A` | `A` |
| 前缀 $P[0..i]$ | `A` | `AB` | `ABA` | `ABAB` | `ABABC` | `ABABCA` | `ABABCAB` | `ABABCABA` | `ABABCABAA` |
| $\pi[i]$ | `0` | `0` | `1` | `2` | `0` | `1` | `2` | `3` | `1` |

### 1.1 失配时为什么可以直接跳到 $q \leftarrow \pi[q - 1]$

假设当前文本扫描到 $T[i]$，此前模式串的前 $q$ 个字符 $P[0..q - 1]$ 已经与文本后缀 $T[i - q..i - 1]$ 完全匹配，而在比较 $T[i]$ 与 $P[q]$ 时发生失配（$T[i] \neq P[q]$）。

此时我们无需回退文本下标 $i$，而是考察：把模式串向右滑动后，若新对齐位置仍能与 $T[i]$ 之前的字符完全吻合，模式串留在 $T[i]$ 左侧的这段新前缀 $P[0..k - 1]$（$k < q$）必须同时等于此前已匹配段的后缀 $P[q - k..q - 1]$！

由前缀函数的定义，满足这一条件的最大长度恰好是 $k = \pi[q - 1]$：

- 任何长度介于 $(k, q)$ 之间的对齐都必然在 $T[i]$ 之前就已经失配，跳过它们绝对不会漏掉合法匹配；
- 令 $q \leftarrow \pi[q - 1]$ 后，新的 $P[0..q - 1]$ 已经保证与 $T[i - q..i - 1]$ 相等，只需直接比较 $T[i]$ 与新的 $P[q]$ 即可。

## 2. 线性时间复杂度 $O(n + m)$ 的势能法证明

无论是在 $O(m)$ 时间内递推构造 $\pi$ 数组，还是在 $O(n)$ 时间内扫描文本 $T$，算法的核心循环都具有完全相同的结构：

```c
size_t q = 0; // 当前已匹配的模式前缀长度
for (size_t i = 0; i < text_count; ++i) {
    while (q > 0 && pattern[q] != text[i]) {
        q = pi[q - 1];
    }
    if (pattern[q] == text[i]) {
        q++;
    }
    if (q == pattern_count) {
        return i + 1 - pattern_count; // 找到首次出现位置
    }
}
```

初学者看到外层 `for` 循环套内层 `while` 循环，容易误以为复杂度是乘积关系。用**势能分析**可以清晰地看到为什么总步数是线性的：

- 将已匹配长度 $q$ 视为势能函数 $\Phi = q$，在算法全过程中恒有 $\Phi \ge 0$；
- 外层 `for` 循环共执行 $n$ 次迭代，每次迭代至多在 `if (pattern[q] == text[i])` 分支中使 $q$ **增加 $1$**，因此整个过程中 $q$ 的累计增加量至多为 $n$；
- 内层 `while` 循环每执行一次迭代，都会将 $q$ 替换为 $\pi[q - 1] < q$，使 $q$ **至少减少 $1$**；
- 由于 $q$ 从 $0$ 出发且永不为负，“累计减少次数”不可能超过“累计增加量”。因此，内层 `while` 循环在**全部 $n$ 步外层迭代中累计执行的总次数不超过 $n$ 次**！

同理，模式串自匹配构造 $\pi[0..m)$ 的总比较次数不超过 $2m$，故总时间复杂度为 $O(n + m)$，额外空间复杂度仅为存放 $\pi$ 数组的 $O(m)$。

## 3. C 语言实现示例：任意字节序列上的 KMP 匹配

```c
#include <stdbool.h>
#include <stddef.h>
#include <stdio.h>
#include <stdlib.h>
#include <string.h>

static bool kmp_search_bytes(
    const unsigned char *text,
    size_t n,
    const unsigned char *pat,
    size_t m,
    size_t *out_idx
) {
    if (m == 0) {
        *out_idx = 0;
        return true;
    }
    if (n < m) {
        *out_idx = SIZE_MAX;
        return true;
    }
    size_t *pi = (size_t *)malloc(m * sizeof(size_t));
    if (pi == NULL) {
        return false;
    }
    pi[0] = 0;
    size_t k = 0;
    for (size_t i = 1; i < m; ++i) {
        while (k > 0 && pat[k] != pat[i]) {
            k = pi[k - 1];
        }
        if (pat[k] == pat[i]) {
            k++;
        }
        pi[i] = k;
    }

    size_t q = 0;
    for (size_t i = 0; i < n; ++i) {
        while (q > 0 && pat[q] != text[i]) {
            q = pi[q - 1];
        }
        if (pat[q] == text[i]) {
            q++;
        }
        if (q == m) {
            free(pi);
            *out_idx = i + 1 - m;
            return true;
        }
    }
    free(pi);
    *out_idx = SIZE_MAX;
    return true;
}

int main(void) {
    const unsigned char *t = (const unsigned char *)"ABABDABACDABABCABAB";
    const unsigned char *p = (const unsigned char *)"ABABCABAB";
    size_t pos = 0;
    kmp_search_bytes(t, strlen((const char *)t), p, strlen((const char *)p), &pos);
    printf("match index = %zu\n", pos);
    return 0;
}
```

2. `shortest_period_u8` 计算非空字节序列（`count > 0`）的最小整除周期长度 $p$（即满足 $p \mid \text{count}$ 且对所有 $0 \le i < \text{count} - p$ 有 `bytes[i] == bytes[i + p]` 的最小正整数 $p$）：若候选值 $k = \text{count} - \pi[\text{count} - 1]$ 整除 `count`，则最小周期为 $k$，否则为 `count`。

4. 两个函数的时间复杂度分别应为 $O(n+m)$ 与 $O(n)$，额外空间复杂度分别为 $O(m)$ 与 $O(n)$。

</Exercise>
