# 5. 平衡搜索树

上一章看到，普通二叉搜索树的操作代价均为 $O(h)$。当输入序列接近随机时，树高期望为 $O(\log n)$；但若按递增或递减顺序依次插入 $n$ 个键，二叉搜索树会退化为一条长度为 $n$ 的单链，单次查找与插入的代价恶化为 $\Theta(n)$。**平衡搜索树 (Self-Balancing Binary Search Tree)** 通过在每次修改后维护局部平衡不变式并执行树旋转，保证在任意输入顺序下树高始终为 $O(\log n)$。

## 1. AVL 树与高度平衡不变式

**AVL 树**（由 Adelson-Velsky 和 Landis 于 1962 年提出）是最早的自平衡二叉搜索树。约定空树高度为 $0$、叶结点高度为 $1$，定义任意结点 $u$ 的高度为：

$$h(u) = 1 + \max\{h(u.\text{left}), \; h(u.\text{right})\}$$

并定义结点 $u$ 的**平衡因子 (Balance Factor)** 为左子树高度减去右子树高度：

$$\text{bf}(u) = h(u.\text{left}) - h(u.\text{right})$$

**AVL 不变式**：树是一棵合法的二叉搜索树，且对于树中**每一个**结点 $u$，其平衡因子满足：

$$\text{bf}(u) \in \{-1, 0, 1\}$$

### 1.1 为什么 AVL 树的高度必为 $O(\log n)$

设 $N(h)$ 表示高度为 $h$ 的 AVL 树最少需要包含的结点数。为了使结点数最少，根的左、右子树高度应相差 $1$（分别为 $h - 1$ 和 $h - 2$），从而得到递推关系：

$$N(0) = 0, \quad N(1) = 1, \quad N(h) = 1 + N(h - 1) + N(h - 2) \quad (h \ge 2)$$

这与斐波那契数列完全同构（$N(h) = F_{h + 2} - 1$）。由于 $N(h) > 2 \cdot N(h - 2)$，每下降两层最少结点数至少翻倍，即 $n \ge N(h) \ge 2^{\lfloor h / 2 \rfloor}$，两边取对数即得 $h = O(\log n)$（更精确的上界为 $h < 1.44 \log_2(n + 2)$）。

## 2. 树旋转与四种失衡情形

当插入新叶结点后，沿着插入路径向上回溯更新高度时，若某个祖先结点 $z$ 的平衡因子变为 $+2$ 或 $-2$，需要通过**左旋 (Left Rotation)** 或**右旋 (Right Rotation)** 在 $O(1)$ 时间内修复平衡，同时保持中序遍历序列不变：

- **对 $y$ 执行右旋**：设 $x = y.\text{left}$，$T_2 = x.\text{right}$（满足 $x < T_2 < y$）。右旋将 $x$ 提升为新子树根，令 $x.\text{right} = y$ 且 $y.\text{left} = T_2$。
- **对 $x$ 执行左旋**：设 $y = x.\text{right}$，$T_2 = y.\text{left}$（满足 $x < T_2 < y$）。左旋将 $y$ 提升为新子树根，令 $y.\text{left} = x$ 且 $x.\text{right} = T_2$。

根据首次失衡结点 $z$ 及其较高方向上的子结点、孙结点的方位，失衡共有四种情形：

| 失衡类型 | 判定条件 | 修复步骤 |
| --- | --- | --- |
| **LL 型**（左左） | $\text{bf}(z) = +2$ 且 $\text{bf}(z.\text{left}) \ge 0$ | 对 $z$ 执行一次**右旋** |
| **RR 型**（右右） | $\text{bf}(z) = -2$ 且 $\text{bf}(z.\text{right}) \le 0$ | 对 $z$ 执行一次**左旋** |
| **LR 型**（左右） | $\text{bf}(z) = +2$ 且 $\text{bf}(z.\text{left}) < 0$ | 先对 $z.\text{left}$ **左旋**化为 LL 型，再对 $z$ **右旋** |
| **RL 型**（右左） | $\text{bf}(z) = -2$ 且 $\text{bf}(z.\text{right}) > 0$ | 先对 $z.\text{right}$ **右旋**化为 RR 型，再对 $z$ **左旋** |

单次插入最多只需修复最低处的失衡祖先（一次单旋或双旋）即可使整棵树恢复平衡。

## 3. C 语言实现示例：AVL 树的平衡插入与完整性校验

下面的程序按严格递增顺序插入 `10, 20, 30, 40, 50, 25`，涵盖 RR 单旋与 RL 双旋，并用递归校验函数验证搜索序、结点高度记录和所有结点的平衡因子：

```c
#include <stdbool.h>
#include <stddef.h>
#include <stdint.h>
#include <stdio.h>
#include <stdlib.h>

typedef struct AvlNode {
    int64_t key;
    int height;
    struct AvlNode *left;
    struct AvlNode *right;
} AvlNode;

static int node_height(const AvlNode *n) {
    return (n != NULL) ? n->height : 0;
}

static void update_height(AvlNode *n) {
    int hl = node_height(n->left);
    int hr = node_height(n->right);
    n->height = 1 + (hl > hr ? hl : hr);
}

static int balance_factor(const AvlNode *n) {
    return (n != NULL) ? (node_height(n->left) - node_height(n->right)) : 0;
}

static AvlNode *rotate_right(AvlNode *y) {
    AvlNode *x = y->left;
    AvlNode *t2 = x->right;
    x->right = y;
    y->left = t2;
    update_height(y);
    update_height(x);
    return x;
}

static AvlNode *rotate_left(AvlNode *x) {
    AvlNode *y = x->right;
    AvlNode *t2 = y->left;
    y->left = x;
    x->right = t2;
    update_height(x);
    update_height(y);
    return y;
}

static AvlNode *rebalance(AvlNode *z) {
    update_height(z);
    int bf = balance_factor(z);
    if (bf > 1) {
        if (balance_factor(z->left) < 0) {
            z->left = rotate_left(z->left);
        }
        return rotate_right(z);
    }
    if (bf < -1) {
        if (balance_factor(z->right) > 0) {
            z->right = rotate_right(z->right);
        }
        return rotate_left(z);
    }
    return z;
}

static AvlNode *avl_insert_rec(AvlNode *node, int64_t key, bool *out_inserted, bool *out_ok) {
    if (node == NULL) {
        AvlNode *n = (AvlNode *)malloc(sizeof(AvlNode));
        if (n == NULL) {
            *out_ok = false;
            return NULL;
        }
        n->key = key;
        n->height = 1;
        n->left = NULL;
        n->right = NULL;
        *out_inserted = true;
        *out_ok = true;
        return n;
    }
    if (key == node->key) {
        *out_inserted = false;
        *out_ok = true;
        return node;
    }
    if (key < node->key) {
        node->left = avl_insert_rec(node->left, key, out_inserted, out_ok);
    } else {
        node->right = avl_insert_rec(node->right, key, out_inserted, out_ok);
    }
    return *out_ok ? rebalance(node) : node;
}

static bool avl_check_node(const AvlNode *n, const int64_t *low, const int64_t *high) {
    if (n == NULL) {
        return true;
    }
    if ((low != NULL && n->key <= *low) || (high != NULL && n->key >= *high)) {
        return false;
    }
    int hl = node_height(n->left);
    int hr = node_height(n->right);
    int expected_h = 1 + (hl > hr ? hl : hr);
    int bf = hl - hr;
    if (n->height != expected_h || bf < -1 || bf > 1) {
        return false;
    }
    return avl_check_node(n->left, low, &n->key) &&
           avl_check_node(n->right, &n->key, high);
}

static void avl_free(AvlNode *n) {
    if (n == NULL) {
        return;
    }
    avl_free(n->left);
    avl_free(n->right);
    free(n);
}

int main(void) {
    AvlNode *root = NULL;
    int64_t seq[] = {10, 20, 30, 40, 50, 25};
    for (size_t i = 0; i < sizeof(seq) / sizeof(seq[0]); ++i) {
        bool ins = false, ok = false;
        root = avl_insert_rec(root, seq[i], &ins, &ok);
    }
    printf("root = %lld, height = %d, valid = %d\n",
           (long long)root->key, node_height(root),
           avl_check_node(root, NULL, NULL));
    avl_free(root);
    return 0;
}
```

root = 30, height = 3, valid = 1

:::

实现自调整二叉搜索树——伸展树（Splay Tree），支持结点的插入、查找、删除，以及核心的自底向上伸展操作（Splay），涵盖 Zig、Zig-Zig、Zig-Zag 三种旋转构型。

```c
#include <stdbool.h>
#include <stddef.h>
#include <stdint.h>

typedef struct SplayTree SplayTree;

SplayTree *splay_create(void);
void splay_destroy(SplayTree *tree);
bool splay_insert(SplayTree *tree, int64_t key);
bool splay_find(SplayTree *tree, int64_t key);
bool splay_remove(SplayTree *tree, int64_t key);
```

要求：

1. 结点结构中**无需存储**平衡因子或颜色标记，仅保存父指针与左右孩子指针。
2. 任何访问操作（查找、插入、删除）均将目标结点（或最后访问的最近邻结点）自底向上伸展（Splay）到根结点。
3. 严格遵循 Tarjan 伸展规则：
   - **Zig**：目标结点的父结点为根，执行一次单旋转；
   - **Zig-Zig**：目标结点与父结点具有同向倾斜（同为左孩子或同为右孩子），**必须先旋转祖父结点，再旋转父结点**；
   - **Zig-Zag**：目标结点与父结点反向倾斜（内侧折线），先旋转父结点，再旋转祖父结点。
4. 保证在任意访问序列下，单次操作的均摊时间复杂度为 $O(\log n)$。

</Exercise>
