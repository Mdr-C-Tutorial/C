# 4. 树与二叉搜索树

线性结构将元素排列成一条链，而**树 (Tree)** 结构表达层次关系与分支划分。其中**二叉搜索树 (Binary Search Tree, BST)** 将二分查找的有序性与链式结构的动态插入、删除结合起来，是平衡搜索树与众多有序容器的理论基石。

## 1. 树与二叉树的基本概念

**二叉树 (Binary Tree)** 是由有限个结点组成的集合：它要么为空树，要么由一个**根结点 (Root)** 以及两棵互不相交的、分别称为**左子树 (Left Subtree)** 和**右子树 (Right Subtree)** 的二叉树递归构成。

常用术语与度量约定如下：

- **叶结点 (Leaf)**：左、右孩子均为空的结点；非空且至少有一个孩子的结点称为**内部结点**。
- **深度 (Depth)**：从根结点到当前结点唯一简单路径上的边数（根结点深度为 $0$）。
- **高度 (Height)**：从当前结点到其子树内最远叶结点路径上的边数（单结点树高为 $0$，空树高常约定为 $-1$；也有教材按结点数约定单结点高为 $1$、空树高为 $0$，实现中保持前后一致即可）。

一棵高为 $h$（按边数计）的二叉树至多包含 $2^{h + 1} - 1$ 个结点；反之，包含 $n \ge 1$ 个结点的二叉树，其高度满足：

$$h \ge \lfloor \log_2 n \rfloor$$

## 2. 二叉搜索树 (BST) 的结构不变式

一棵二叉树是**严格二叉搜索树**，当且仅当对于树中的任意结点 $u$：

1. $u$ 的**左子树**中**所有**结点的键都严格小于 $u.\text{key}$；
2. $u$ 的**右子树**中**所有**结点的键都严格大于 $u.\text{key}$；
3. $u$ 的左子树和右子树本身也都是二叉搜索树。

### 2.1 为什么只检查父子关系不足以验证 BST

初学者常犯的一个错误是：验证每个结点只满足 `u->left->key < u->key` 且 `u->right->key > u->key`。考虑如下反例：根结点为 `10`，其左孩子为 `5`，而 `5` 的右孩子为 `12`。虽然局部满足 $5 < 10$ 且 $12 > 5$，但结点 `12` 位于根 `10` 的左子树中却大于 `10`，违反了全局搜索树不变式。

正确的验证方法有两种：

- **开区间上下界向下传递**：递归验证子树 `u` 时传入允许的开区间 `(low_ptr, high_ptr)`。进入左子树时将上界收紧为 `&u->key`，进入右子树时将下界收紧为 `&u->key`。使用指向边界值的指针（`NULL` 表示无界）而非构造 `key - 1` / `key + 1`，可以彻底规避 `INT64_MIN` 与 `INT64_MAX` 处的有符号整数溢出。
- **中序遍历单调性检查**：按中序遍历依次访问每个结点，检查序列是否严格递增。

## 3. 二叉树的遍历与中序有序性

对二叉树的深度优先遍历按访问根结点的时机分为三种：

1. **先序遍历 (Preorder)**：根 $\to$ 左子树 $\to$ 右子树。
2. **中序遍历 (Inorder)**：左子树 $\to$ 根 $\to$ 右子树。
3. **后序遍历 (Postorder)**：左子树 $\to$ 右子树 $\to$ 根（释放整棵树的所有结点时必须使用后序顺序，避免先释放父结点后无法读取子指针）。

**定理**：二叉搜索树的中序遍历序列必然严格递增。

**归纳证明**：空树与单结点树显然成立。设命题对结点数小于 $n$ 的所有 BST 成立；对于根为 $r$ 的 $n$ 结点 BST，中序遍历依次输出左子树序列、$r.\text{key}$、右子树序列。由归纳假设，左、右子树的输出序列各自严格递增；又由 BST 不变式，左子树所有键 $< r.\text{key} <$ 右子树所有键，故拼接后的完整序列严格递增。每访问一个结点耗时 $O(1)$，因此中序遍历的时间复杂度为 $\Theta(n)$。

## 4. 查找、插入与删除

- **查找 (`contains`)**：从根出发，若目标键等于当前结点键则命中；若更小则进入左孩子，若更大则进入右孩子，直到命中或到达空指针。每次比较下降一层，时间复杂度为 $O(h)$。
- **插入 (`insert`)**：沿查找路径下降；若途中遇到相等键则报告已存在；若到达空指针位置，则分配新叶结点挂接在父结点的对应分支上，时间复杂度为 $O(h)$。
- **删除 (`remove`)**：设待删结点为 $u$，分三种情形：
  1. $u$ 无左孩子：直接用 $u$ 的右孩子替代 $u$ 的位置；
  2. $u$ 有左孩子但无右孩子：直接用 $u$ 的左孩子替代 $u$ 的位置；
  3. $u$ 同时拥有左、右孩子：在 $u$ 的右子树中找到最小结点 $s$（即 $u$ 的**中序后继**，$s$ 一定没有左孩子），用 $s$ 的键替换 $u$ 的键，再从右子树中按情形 1 删除 $s$。

## 5. C 语言实现示例：BST 的插入、区间验证与中序遍历

```c
#include <stdbool.h>
#include <stddef.h>
#include <stdint.h>
#include <stdio.h>
#include <stdlib.h>

typedef struct BstNode {
    int64_t key;
    struct BstNode *left;
    struct BstNode *right;
} BstNode;

static bool bst_insert_node(BstNode **root, int64_t key, bool *out_inserted) {
    BstNode **cur = root;
    while (*cur != NULL) {
        if (key == (*cur)->key) {
            *out_inserted = false;
            return true;
        }
        cur = (key < (*cur)->key) ? &(*cur)->left : &(*cur)->right;
    }
    BstNode *node = (BstNode *)malloc(sizeof(BstNode));
    if (node == NULL) {
        return false;
    }
    node->key = key;
    node->left = NULL;
    node->right = NULL;
    *cur = node;
    *out_inserted = true;
    return true;
}

static bool bst_is_valid_range(const BstNode *node, const int64_t *low, const int64_t *high) {
    if (node == NULL) {
        return true;
    }
    if (low != NULL && node->key <= *low) {
        return false;
    }
    if (high != NULL && node->key >= *high) {
        return false;
    }
    return bst_is_valid_range(node->left, low, &node->key) &&
           bst_is_valid_range(node->right, &node->key, high);
}

static void bst_print_inorder(const BstNode *node) {
    if (node == NULL) {
        return;
    }
    bst_print_inorder(node->left);
    printf("%lld ", (long long)node->key);
    bst_print_inorder(node->right);
}

static void bst_free(BstNode *node) {
    if (node == NULL) {
        return;
    }
    bst_free(node->left);
    bst_free(node->right);
    free(node);
}

int main(void) {
    BstNode *root = NULL;
    int64_t keys[] = {20, 10, 30, 5, 15, 25, 10};
    for (size_t i = 0; i < sizeof(keys) / sizeof(keys[0]); ++i) {
        bool inserted = false;
        bst_insert_node(&root, keys[i], &inserted);
    }
    printf("valid = %d\ninorder: ", bst_is_valid_range(root, NULL, NULL));
    bst_print_inorder(root);
    printf("\n");
    bst_free(root);
    return 0;
}
```

运行结果：

::: terminal

valid = 1
inorder: 5 10 15 20 25 30 

:::

实现不透明的整数二叉搜索树：

```c
#include <stdbool.h>
#include <stddef.h>
#include <stdint.h>

typedef struct IntBst IntBst;

typedef enum {
    INT_BST_OK,
    INT_BST_INVALID,
    INT_BST_OUT_OF_MEMORY
} IntBstResult;

IntBst *int_bst_create(void);
void int_bst_destroy(IntBst *tree);
IntBstResult int_bst_insert(
    IntBst *tree,
    int64_t key,
    bool *out_inserted
);
bool int_bst_contains(const IntBst *tree, int64_t key);
bool int_bst_inorder(
    const IntBst *tree,
    int64_t *out_keys,
    size_t capacity,
    size_t *out_count
);
```

要求：

1. 每个结点的左子树键严格小于结点键，右子树键严格大于结点键；重复插入应成功返回并设置 `*out_inserted = false`。
2. 树拥有全部结点；`int_bst_destroy(NULL)` 必须安全。
3. 插入参数无效、分配失败或大小计算溢出时返回相应状态，树和 `*out_inserted` 保持不变。
4. 中序遍历必须按非递减顺序写入 `out_keys`；容量不足、参数无效时不得修改输出对象。
5. 空树的中序遍历允许 `out_keys == NULL`；`out_count` 必须非空。
6. 查找时间复杂度为 $O(h)$，其中 $h$ 为树高；中序遍历时间复杂度为 $O(n)$。

</Exercise>

验证一个用数组保存的二叉搜索树。结点编号为 `0` 到 `count - 1`，`SIZE_MAX` 表示空孩子：

```c
#include <stdbool.h>
#include <stddef.h>
#include <stdint.h>

typedef struct {
    int64_t key;
    size_t left;
    size_t right;
} BstNode;

bool bst_validate(
    const BstNode *nodes,
    size_t count,
    size_t root
);
```

要求：

1. `count == 0` 时只有 `root == SIZE_MAX` 才合法；非空树的根必须是有效下标。
2. 所有孩子下标必须有效或为 `SIZE_MAX`，不能出现环、共享子树或无法从根到达的结点。
3. 对每个结点，左子树所有键严格更小，右子树所有键严格更大；不得通过 `key - 1` 或 `key + 1` 构造边界。
4. 参数无效时返回 `false`；不要求修改输入数组。
5. 时间复杂度为 $O(n)$，额外空间复杂度为 $O(n)$。

</Exercise>
