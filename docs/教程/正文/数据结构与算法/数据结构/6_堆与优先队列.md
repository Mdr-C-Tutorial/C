# 6. 堆与优先队列

栈按“后进先出”顺序取出元素，队列按“先进先出”顺序取出元素；而在任务调度、离散事件模拟、最短路算法和数据流统计中，我们常常需要每次取出当前**优先级最高（最小或最大）**的元素。这种抽象数据类型称为**优先队列 (Priority Queue)**，而**二叉堆 (Binary Heap)** 是实现优先队列最紧凑、高效的数据结构。

## 1. 完全二叉树的数组表示

二叉堆在逻辑上是一棵**完全二叉树 (Complete Binary Tree)**：除最后一层外，每一层都被完全填满，且最后一层的结点全部靠左排列。

由于完全二叉树没有结构空洞，无需像普通二叉树那样为每个结点分配 `left`、`right` 指针，而是可以直接存放在从下标 `0` 开始的连续数组中。对于下标为 $i$（$0 \le i < n$）的结点：

- **父结点下标**（当 $i > 0$ 时）：$\text{parent}(i) = \lfloor (i - 1) / 2 \rfloor$
- **左孩子下标**：$\text{left}(i) = 2i + 1$（若 $2i + 1 < n$ 则存在）
- **右孩子下标**：$\text{right}(i) = 2i + 2$（若 $2i + 2 < n$ 则存在）

这种表示消除了指针开销，且内存连续，缓存局部性极佳。一棵含 $n$ 个结点的完全二叉树高度恰为 $\lfloor \log_2 n \rfloor$。

## 2. 堆序不变式与上浮、下沉

二叉堆分为小根堆与大根堆两类：

- **小根堆不变式 (Min-Heap Property)**：除根结点外，每个结点的键值都**大于或等于**其父结点的键值，即 `a[parent(i)] <= a[i]`。由此归纳可知，根结点 `a[0]` 必为全堆的最小元素。
- **大根堆不变式 (Max-Heap Property)**：除根结点外，每个结点的键值都**小于或等于**其父结点的键值，即 `a[parent(i)] >= a[i]`，根结点 `a[0]` 必为最大元素。

以小根堆为例，核心操作通过两个 $O(\log n)$ 的局部修复过程实现：

1. **插入 (`push`) 与上浮 (`sift_up`)**：将新元素追加在数组末尾下标 `i = n` 处（破坏点仅可能在 `i` 与其父结点之间）。只要 `i > 0` 且 `a[i] < a[parent(i)]`，就交换二者并令 `i = parent(i)` 继续向上比较，直到满足堆序或到达根结点。
2. **弹出堆顶 (`pop`) 与下沉 (`sift_down`)**：取出 `a[0]` 后，用数组末尾元素 `a[n - 1]` 覆盖 `a[0]` 并令元素个数减 1。从 `i = 0` 开始，在左、右孩子中找出键值较小者 `smallest`；若 `a[smallest] < a[i]`，则交换二者并令 `i = smallest` 继续向下调整，直到当前结点不大于其子结点或到达叶结点。

## 3. 线性时间建堆与两类经典工程模式

给定 $n$ 个无序元素，若逐个调用 `push`，总耗时为 $O(n \log n)$。若直接将元素放入数组，从最后一个非叶结点 $i = \lfloor n / 2 \rfloor - 1$ 递减到 $0$ 依次调用 `sift_down`（**Floyd 建堆算法**），由于距底层高度为 $h$ 的结点至多有 $\lceil n / 2^{h + 1} \rceil$ 个，总工作量为：

$$\sum_{h = 0}^{\lfloor \log_2 n \rfloor} \left\lceil \frac{n}{2^{h + 1}} \right\rceil O(h) = O\!\left(n \sum_{h = 0}^{\infty} \frac{h}{2^h}\right) = O(n)$$

在工程与算法设计中，优先队列常用于以下两类模式：

- **固定容量 $k$ 的 Top-$K$ 筛选**：若要从 $n$ 个元素中选出**最小的前 $k$ 个元素**且将额外空间控制在 $O(k)$，可以维护一个容量为 $k$ 的**大根堆**，保存目前见过的最小 $k$ 个数（堆顶是这 $k$ 个数中的最大值，即淘汰门槛）。遍历剩余元素时，若新元素严格小于堆顶，则弹出堆顶并压入新元素；遍历结束后将堆中 $k$ 个元素依次弹出即可按非递减序排好，总时间复杂度为 $O(n \log k)$。
- **$k$ 路有序序列归并**：合并 $k$ 条已排序序列（总元素数 $N$）时，用容量为 $k$ 的小根堆存放每条非空序列的当前首元素及其所属序列编号與游标。每次弹出最小元素写入结果，并将该序列的下一个元素压入堆中，总时间复杂度为 $O(N \log k)$。

## 4. C 语言实现示例：基于动态数组的小根堆

```c
#include <stdbool.h>
#include <stddef.h>
#include <stdint.h>
#include <stdio.h>
#include <stdlib.h>

typedef struct {
    int64_t *data;
    size_t size;
    size_t capacity;
} MinHeap;

static void sift_up(int64_t *a, size_t idx) {
    while (idx > 0) {
        size_t parent = (idx - 1) / 2;
        if (a[parent] <= a[idx]) {
            break;
        }
        int64_t tmp = a[parent];
        a[parent] = a[idx];
        a[idx] = tmp;
        idx = parent;
    }
}

static void sift_down(int64_t *a, size_t n, size_t idx) {
    for (;;) {
        size_t left = 2 * idx + 1;
        size_t right = 2 * idx + 2;
        size_t smallest = idx;
        if (left < n && a[left] < a[smallest]) {
            smallest = left;
        }
        if (right < n && a[right] < a[smallest]) {
            smallest = right;
        }
        if (smallest == idx) {
            break;
        }
        int64_t tmp = a[idx];
        a[idx] = a[smallest];
        a[smallest] = tmp;
        idx = smallest;
    }
}

static bool min_heap_push(MinHeap *h, int64_t val) {
    if (h->size == h->capacity) {
        size_t next_cap = (h->capacity == 0) ? 8 : h->capacity * 2;
        int64_t *buf = (int64_t *)realloc(h->data, next_cap * sizeof(int64_t));
        if (buf == NULL) {
            return false;
        }
        h->data = buf;
        h->capacity = next_cap;
    }
    h->data[h->size] = val;
    sift_up(h->data, h->size);
    h->size++;
    return true;
}

static bool min_heap_pop(MinHeap *h, int64_t *out) {
    if (h->size == 0) {
        return false;
    }
    *out = h->data[0];
    h->size--;
    if (h->size > 0) {
        h->data[0] = h->data[h->size];
        sift_down(h->data, h->size, 0);
    }
    return true;
}

int main(void) {
    MinHeap h = {NULL, 0, 0};
    int64_t inputs[] = {40, 15, 30, 10, 25, 15};
    for (size_t i = 0; i < sizeof(inputs) / sizeof(inputs[0]); ++i) {
        min_heap_push(&h, inputs[i]);
    }
    int64_t v = 0;
    while (min_heap_pop(&h, &v)) {
        printf("%lld ", (long long)v);
    }
    printf("\n");
    free(h.data);
    return 0;
}
```

二叉堆通常使用连续内存数组进行紧凑存储。对于基于 $0$ 的下标体系，实现一系列父子节点检索、叶节点判断、最后非叶节点定位及堆序不变式验证函数：

```c
#include <stdbool.h>
#include <stddef.h>
#include <stdint.h>

bool heap_parent(size_t index, size_t *out_parent);
bool heap_left_child(size_t index, size_t size, size_t *out_left);
bool heap_right_child(size_t index, size_t size, size_t *out_right);
bool heap_is_leaf(size_t index, size_t size);
size_t heap_last_non_leaf(size_t size);
bool heap_is_max_heap(const int64_t *array, size_t size);
bool heap_is_min_heap(const int64_t *array, size_t size);
```

要求：

1. 根节点下标为 $0$。若 `index == 0`，不存在父节点，`heap_parent` 返回 `false` 且不修改输出对象；若 `index > 0`，父节点下标为 `(index - 1) / 2`，写入 `*out_parent` 并返回 `true`。
2. 左孩子下标为 `2 * index + 1`，右孩子下标为 `2 * index + 2`。必须严谨防范算术溢出；若计算出的子节点下标超出 `size - 1` 或发生溢出，返回 `false` 且不修改输出对象。
3. `heap_is_leaf` 判定下标 `index` 在规模为 `size` 的二叉堆中是否为叶节点。若 `index >= size`，返回 `false`；若没有合法的左孩子（即 `index >= size / 2` 且 `index < size`），判定为叶节点并返回 `true`。
4. `heap_last_non_leaf` 计算并返回规模为 `size` 的二叉堆中最后一个非叶节点的下标。若 `size <= 1`，不存在非叶节点，返回 `0`；若 `size >= 2`，返回 `(size / 2) - 1`。
5. `heap_is_max_heap` 与 `heap_is_min_heap` 遍历所有非叶节点，验证堆序不变式是否全局成立。空堆或单节点堆恒返回 `true`；若数组指针参数为 `NULL` 且 `size > 0`，返回 `false`。
