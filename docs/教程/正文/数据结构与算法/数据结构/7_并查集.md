# 7. 并查集

在图的连通分量维护、Kruskal 最小生成树算法以及等价类划分问题中，我们需要维护若干个互不相交的动态集合，并高频执行两类操作：判断两个元素是否属于同一个集合，以及将两个集合合并为一个。**并查集 (Disjoint-Set Union, DSU / Union-Find)** 是专为此类动态等价关系设计的数据结构。

## 1. 森林表示与代表元不变式

设全集包含 $n$ 个元素，编号为 $0, 1, \dots, n - 1$。并查集将每个集合表示为一棵**有根树**，所有集合共同构成一片森林：

- 每个集合以该树的**根结点**作为唯一**代表元 (Representative)**；
- 数组 `parent[i]` 记录元素 `i` 的父结点下标；根结点满足自环约定 `parent[r] == r`；
- 数组 `size[r]`（或 `rank[r]`）记录以根 `r` 为代表的集合大小（或树秩上界）。注意：**只有当 `r` 是根结点时，`size[r]` 才表示整个连通块的元素个数**。

初始状态下，每个元素各自构成一个单元素集合，即对所有 $0 \le i < n$，有：

$$\text{parent}[i] = i, \quad \text{size}[i] = 1$$

## 2. 按大小合并与路径压缩

若不加限制地将一棵树的根随便挂到另一棵树的根下，经过 $n - 1$ 次合并后树可能退化为深 $n - 1$ 的单链，使单次 `find` 退化为 $\Theta(n)$。通过同时引入以下两项优化，可将分摊代价降至近乎常数：

### 2.1 按大小合并 (Union by Size) 或按秩合并 (Union by Rank)

合并两个不同集合的根 $r_x$ 与 $r_y$ 时，始终**将结点数较少（或秩较小）的树根挂接到结点数较多（或秩较大）的树根之下**：

```c
if (dsu->size[rx] < dsu->size[ry]) {
    size_t tmp = rx;
    rx = ry;
    ry = tmp;
}
dsu->parent[ry] = rx;
dsu->size[rx] += dsu->size[ry];
```

**不变式证明**：仅使用按大小合并时，任意元素 $u$ 的深度每增加 $1$，它所在集合的结点总数至少翻倍（因为只有当 $u$ 所在树的大小不大于另一棵树时，$u$ 所在树的根才会成为子结点）。因此，任意含 $k$ 个结点的树高度至多为 $\lfloor \log_2 k \rfloor \le \lfloor \log_2 n \rfloor$。

### 2.2 路径压缩 (Path Compression)

在执行 `find(x)` 向上寻找根结点 $r$ 后，顺便将查找路径上经过的所有结点的 `parent` 直接改写为根 $r$，使后续对这些结点及其子树的查找一步到位：

```c
static size_t dsu_find_root(size_t *parent, size_t x) {
    size_t root = x;
    while (parent[root] != root) {
        root = parent[root];
    }
    while (x != root) {
        size_t next = parent[x];
        parent[x] = root;
        x = next;
    }
    return root;
}
```

上面的**两趟迭代写法**无需递归调用栈，即使在极端树高下也不会发生栈溢出。Tarjan 证明了：同时采用按大小（或按秩）合并与路径压缩时，在 $n$ 个元素上执行任意 $m$ 次 `find` 与 `union` 操作的总时间为 $O(m \alpha(n))$，单次操作的摊还时间复杂度为 $O(\alpha(n))$，其中 $\alpha(n)$ 为反阿克曼函数，对宇宙可观测范围内的全部整数 $n$ 均有 $\alpha(n) \le 4$。

## 3. C 语言实现示例：并查集的合并、连通查询与分量统计

```c
#include <stdbool.h>
#include <stddef.h>
#include <stdio.h>
#include <stdlib.h>

typedef struct {
    size_t *parent;
    size_t *size;
    size_t count;
} DisjointSet;

static bool dsu_init(DisjointSet *dsu, size_t count) {
    dsu->parent = (size_t *)malloc(count * sizeof(size_t));
    dsu->size = (size_t *)malloc(count * sizeof(size_t));
    if (count > 0 && (dsu->parent == NULL || dsu->size == NULL)) {
        free(dsu->parent);
        free(dsu->size);
        return false;
    }
    dsu->count = count;
    for (size_t i = 0; i < count; ++i) {
        dsu->parent[i] = i;
        dsu->size[i] = 1;
    }
    return true;
}

static size_t dsu_find(const DisjointSet *dsu, size_t x) {
    size_t root = x;
    while (dsu->parent[root] != root) {
        root = dsu->parent[root];
    }
    while (x != root) {
        size_t next = dsu->parent[x];
        dsu->parent[x] = root;
        x = next;
    }
    return root;
}

static bool dsu_union(DisjointSet *dsu, size_t a, size_t b) {
    size_t ra = dsu_find(dsu, a);
    size_t rb = dsu_find(dsu, b);
    if (ra == rb) {
        return false;
    }
    if (dsu->size[ra] < dsu->size[rb]) {
        size_t tmp = ra;
        ra = rb;
        rb = tmp;
    }
    dsu->parent[rb] = ra;
    dsu->size[ra] += dsu->size[rb];
    return true;
}

int main(void) {
    DisjointSet dsu;
    dsu_init(&dsu, 6);
    dsu_union(&dsu, 0, 1);
    dsu_union(&dsu, 1, 2);
    dsu_union(&dsu, 3, 4);

    printf("same(0, 2) = %d, same(0, 4) = %d, size(2) = %zu\n",
           dsu_find(&dsu, 0) == dsu_find(&dsu, 2),
           dsu_find(&dsu, 0) == dsu_find(&dsu, 4),
           dsu.size[dsu_find(&dsu, 2)]);

    free(dsu.parent);
    free(dsu.size);
    return 0;
}
```

运行结果：

::: terminal

same(0, 2) = 1, same(0, 4) = 0, size(2) = 3

:::

实现支持动态合并和连通性查询的整数并查集：

```c
#include <stdbool.h>
#include <stddef.h>

typedef struct IntDisjointSet IntDisjointSet;

IntDisjointSet *int_dsu_create(size_t count);
void int_dsu_destroy(IntDisjointSet *set);
bool int_dsu_union(
    IntDisjointSet *set,
    size_t left,
    size_t right,
    bool *out_merged
);
bool int_dsu_same(
    const IntDisjointSet *set,
    size_t left,
    size_t right,
    bool *out_same
);
bool int_dsu_component_size(
    const IntDisjointSet *set,
    size_t element,
    size_t *out_size
);
```

要求：

1. 初始时每个元素单独成集合；下标必须小于 `count`。
2. `union` 使用按大小或按秩合并，并在查找时进行路径压缩。
3. 重复合并成功返回并设置 `*out_merged = false`；失败时不得修改输出对象和集合结构。
4. `destroy(NULL)` 安全；`count == 0` 可以创建空集合。
5. 分摊时间复杂度应达到 $O(\alpha(n))$，并说明所维护的不变式。

实现维护二元奇偶关系（同类 / 异类，常用于动态二分图判定）的带权并查集 `ParityDisjointSet`：

```c
#include <stdbool.h>
#include <stddef.h>

typedef struct ParityDisjointSet ParityDisjointSet;

ParityDisjointSet *parity_dsu_create(size_t count);
void parity_dsu_destroy(ParityDisjointSet *set);
bool parity_dsu_relate(
    ParityDisjointSet *set,
    size_t left,
    size_t right,
    bool different,
    bool *out_consistent
);
bool parity_dsu_query(
    const ParityDisjointSet *set,
    size_t left,
    size_t right,
    bool *out_known,
    bool *out_different
);
```

要求：

1. 每个结点维护到父结点的模 $2$ 异或边权（`0` 表示与父结点同类，`1` 表示与父结点异类）；支持按大小（或按秩）合并与带边权更新的路径压缩。
2. `parity_dsu_relate` 尝试建立 `left` 与 `right` 的同类（`different == false`）或异类（`different == true`）关系：若两者已在同一连通分量且已有奇偶路径与新关系矛盾，成功返回 `true`、设置 `*out_consistent = false`，且不得改变集合中的已有关系；若一致或分属不同分量，合并（或保持）并设置 `*out_consistent = true`。
3. `parity_dsu_query` 查询 `left` 与 `right` 的奇偶关系：若两者尚不在同一连通分量，成功返回 `true`、设置 `*out_known = false`，且不得修改 `*out_different`；若在同一分量，设置 `*out_known = true` 并将两者是否异类写入 `*out_different`。
4. 下标越界、分配失败或指针参数无效时返回 `false`，不得修改集合与输出对象；`count == 0` 可以创建空集合，`parity_dsu_destroy(NULL)` 安全。
5. 说明路径压缩与两根合并时的异或边权转移方程，单次操作的摊还时间复杂度应达到 $O(\alpha(n))$。

实现基础并查集的两种核心变体：基于展平标记数组的 **Quick-Find** 与基于父节点树形数组的无优化 **Quick-Union**，并深入分析两者的性能瓶颈与退化场景：

```c
#include <stdbool.h>
#include <stddef.h>

typedef struct QuickFindDSU QuickFindDSU;
typedef struct QuickUnionDSU QuickUnionDSU;

QuickFindDSU *qf_create(size_t n);
void qf_destroy(QuickFindDSU *dsu);
bool qf_find(const QuickFindDSU *dsu, size_t p, size_t *out_id);
bool qf_union(QuickFindDSU *dsu, size_t p, size_t q, bool *out_merged);

QuickUnionDSU *qu_create(size_t n);
void qu_destroy(QuickUnionDSU *dsu);
bool qu_find(const QuickUnionDSU *dsu, size_t p, size_t *out_root);
bool qu_union(QuickUnionDSU *dsu, size_t p, size_t q, bool *out_merged);
```

要求：

1. 初始时每个元素各自构成独立的单元素集合，外部标识符范围为 $[0, n - 1]$。
2. `QuickFindDSU` 维护 `id` 数组，保证同属一个集合的所有成员具有完全相同的标识：
   - `qf_find` 实现 $O(1)$ 常数时间查询；
   - `qf_union` 遍历整个数组将所有属于集合 $p$ 的槽位批量更新为集合 $q$ 的标识。
3. `QuickUnionDSU` 维护 `parent` 树形数组，根节点满足 `parent[root] == root`：
   - `qu_find` 沿父节点指针向上回溯直至根节点；
   - `qu_union` 找到两者的树根，若分属不同根则将其中一个树根直接作为另一个树根的孩子（`parent[root_p] = root_q`）。
4. 参数非法或内存分配失败时返回 `false` 且不修改输出对象；`destroy(NULL)` 安全。
5. 在题解中证明朴素 Quick-Union 在特定合并输入下会退化为高为 $n$ 的单链，导致单次操作时间复杂度劣化为 $O(n)$。

</Exercise>

在无向图中，边的加入是一个动态流式过程。利用并查集实现无向图动态连通性跟踪器 `GraphConnectivityTracker`，实时维护连通分量总数并在加边时瞬间判定该边是否在图中引入了环路：

```c
#include <stdbool.h>
#include <stddef.h>

typedef struct GraphConnectivityTracker GraphConnectivityTracker;

GraphConnectivityTracker *gct_create(size_t vertex_count);
void gct_destroy(GraphConnectivityTracker *tracker);
bool gct_add_edge(
    GraphConnectivityTracker *tracker,
    size_t u,
    size_t v,
    bool *out_created_cycle
);
size_t gct_component_count(const GraphConnectivityTracker *tracker);
bool gct_is_connected(
    const GraphConnectivityTracker *tracker,
    size_t u,
    size_t v,
    bool *out_connected
);
```

要求：

1. 初始时图包含 $V$ 个孤立顶点，连通分量总数为 $V$。
2. 每当加入无向边 $(u, v)$ 时：
   - 若 $u$ 与 $v$ 已处于同一连通分量，说明该边属于多余边，在图中构成了一个简单环路，置 `*out_created_cycle = true`，连通分量数保持不变；
   - 若 $u$ 与 $v$ 分属不同分量，将两分量合并，置 `*out_created_cycle = false`，连通分量总数精确减少 1。
3. `gct_is_connected` 判定顶点 $u$ 与 $v$ 当前是否相互可达。
4. 顶点编号越界或指针非法时返回 `false`，且不得修改内部连通分量状态和输出对象。

实现基于**扩展域（Extended Domain）**建模的种类并查集 `EnemyDisjointSet`，处理包含“朋友”与“敌人”二元对立关系的动态图场景（“敌人的敌人是朋友”），支持冲突关系检测与逻辑推断：

```c
#include <stdbool.h>
#include <stddef.h>

typedef struct EnemyDisjointSet EnemyDisjointSet;

EnemyDisjointSet *enemy_dsu_create(size_t n);
void enemy_dsu_destroy(EnemyDisjointSet *dsu);
bool enemy_dsu_add_friends(EnemyDisjointSet *dsu, size_t x, size_t y, bool *out_consistent);
bool enemy_dsu_add_enemies(EnemyDisjointSet *dsu, size_t x, size_t y, bool *out_consistent);
bool enemy_dsu_are_friends(EnemyDisjointSet *dsu, size_t x, size_t y, bool *out_friends);
bool enemy_dsu_are_enemies(EnemyDisjointSet *dsu, size_t x, size_t y, bool *out_enemies);
```

要求：

1. 集合包含 $n$ 个实体，编号为 $[0, n - 1]$。底层通过开辟 $2n$ 大小的扩展域数组进行逻辑推演：
   - 域 $[0, n - 1]$ 表示“实体处于同盟阵营”；
   - 域 $[n, 2n - 1]$ 表示“实体处于敌对阵营”（记实体 $x$ 的敌对域为 $x + n$）。
2. `enemy_dsu_add_friends`：若此前已推导出 $x$ 与 $y$ 为敌人（即 $x$ 与 $y + n$ 连通），产生逻辑冲突，置 `*out_consistent = false` 且不改变集合状态；否则合并 $(x, y)$ 与 $(x + n, y + n)$，置 `*out_consistent = true`。
3. `enemy_dsu_add_enemies`：若此前已推导出 $x$ 与 $y$ 为朋友（即 $x$ 与 $y$ 连通），产生逻辑冲突，置 `*out_consistent = false`；否则合并 $(x, y + n)$ 与 $(y, x + n)$，置 `*out_consistent = true`。
4. `enemy_dsu_are_friends` 与 `enemy_dsu_are_enemies` 分别查询两实体当前是否已确定属于朋友或敌对关系。
5. 在题解中对比分析“扩展域并查集”与“带权并查集”在建模思路、实现复杂度及应用场景上的异同。

</Exercise>

实现支持历史状态按序回退的**可撤销并查集（Undoable DSU）**，支持检查点（Checkpoint）保存与多步批量回退：

```c
#include <stdbool.h>
#include <stddef.h>

typedef struct UndoableDSU UndoableDSU;

UndoableDSU *undoable_dsu_create(size_t count);
void undoable_dsu_destroy(UndoableDSU *dsu);
bool undoable_dsu_union(UndoableDSU *dsu, size_t u, size_t v, bool *out_merged);
bool undoable_dsu_same(const UndoableDSU *dsu, size_t u, size_t v, bool *out_same);
bool undoable_dsu_rollback(UndoableDSU *dsu);
size_t undoable_dsu_checkpoint(const UndoableDSU *dsu);
bool undoable_dsu_rollback_to(UndoableDSU *dsu, size_t checkpoint);
```

要求：

1. 内部**严禁采用路径压缩**，仅允许使用**按秩合并（Union by Rank）**；详细证明为什么可撤销并查集不能使用路径压缩。
2. 维护动态操作历史栈 `history`。每次调用 `undoable_dsu_union` 无论是否发生实质合并，均向栈中压入一条快照记录，耗时 $O(1)$。
3. `undoable_dsu_rollback` 弹出栈顶的最近一次合并操作，并以 $O(1)$ 时间完全恢复树形拓扑结构与秩信息；若历史栈为空，返回 `false`。
4. `undoable_dsu_checkpoint` 返回当前历史栈的深度；`undoable_dsu_rollback_to` 反复回退至指定的检查点深度。
5. 结合线段树分治（Divide and Conquer on Time）场景，阐述可撤销并查集离线解决动态连通性问题的标准范式。
