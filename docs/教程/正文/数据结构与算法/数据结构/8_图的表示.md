# 8. 图的表示

线性表表达一对一的前驱后继关系，树表达一对多的层次父子关系，而**图 (Graph)** 表达任意对象之间多对多的二元关系。通信网络、依赖调度、道路导航与状态转移系统都可以自然地抽象为图。在编写图算法之前，必须先根据顶点数 $|V|$、边数 $|E|$ 以及操作模式选择合适的图表示。

## 1. 图的数学模型与基本概念

一个图记为二元组 $G = (V, E)$，其中 $V$ 是有穷**顶点集 (Vertex Set)**，$E$ 是连接顶点的**边集 (Edge Set)**（习惯上在复杂度表达式中直接用 $V$ 和 $E$ 分别代表顶点数 $|V|$ 和边数 $|E|$）：

- **有向图 (Directed Graph)**：每条边是有序点对 $(u, v)$，表示从起点 $u$ 指向终点 $v$ 的单向边。以 $u$ 为终点的边数称为 $u$ 的**入度 (In-degree)**，以 $u$ 为起点的边数称为**出度 (Out-degree)**。
- **无向图 (Undirected Graph)**：每条边是无序点对 $\{u, v\}$，等价于同时存在 $(u, v)$ 和 $(v, u)$ 两个方向的邻接关系。
- **带权图 (Weighted Graph)**：每条边附带一个数值权重 $w(u, v)$（表示距离、费用或容量）。
- **稀疏图与稠密图**：当 $E \ll V^2$（如 $E = O(V)$）时称为**稀疏图**；当 $E$ 接近 $V^2$ 时称为**稠密图**。

## 2. 邻接矩阵与邻接表的权衡

在 C 语言中，图主要有两种标准表示方式：

| 表示方式 | 空间复杂度 | 判断 $(u, v)$ 是否相连 | 遍历顶点 $u$ 的所有出边 | 适用场景 |
| --- | --- | --- | --- | --- |
| **邻接矩阵** (`adj[V][V]`) | $\Theta(V^2)$ | $O(1)$ | $\Theta(V)$ | 顶点数较小（如 $V \le 1000$）的稠密图、Floyd 全源最短路 |
| **邻接表**（每个顶点一条边表） | $\Theta(V + E)$ | $O(\text{deg}(u))$ | $\Theta(\text{deg}(u))$ | 绝大多数稀疏图算法（BFS、DFS、拓扑排序、Dijkstra） |

在实现**邻接表 (Adjacency List)** 时，每个顶点 $u \in \{0, \dots, V - 1\}$ 维护一个动态数组（或单链表）存放其所有邻接顶点。为了在广度优先遍历或深度优先遍历中获得确定的访问顺序，通常需要**保持邻接表中邻居的加边先后顺序**（使用动态数组尾插或带尾指针的链表）。

::: tip 无向图加边的异常安全（失败回滚）

在无向图中添加一条边 $\{u, v\}$ 时，需要先后向 `adj[u]` 追加 `v`、向 `adj[v]` 追加 `u`（当 $u = v$ 自环时也要与接口约定保持一致）。如果第一步向 `adj[u]` 追加成功，而第二步为 `adj[v]` 扩容时内存分配失败，实现必须**将 `adj[u]` 的长度回退 $1$**，保证图恢复到调用前的合法状态，不得留下单向半边。

:::

## 3. C 语言实现示例：邻接表图与广度优先遍历 (BFS)

下面的程序用每个顶点一条动态数组构建邻接表，并展示使用环形/线性队列执行 $O(V + E)$ 广度优先遍历的完整过程：

```c
#include <stdbool.h>
#include <stddef.h>
#include <stdio.h>
#include <stdlib.h>

typedef struct {
    size_t *neighbors;
    size_t count;
    size_t capacity;
} AdjList;

typedef struct {
    AdjList *lists;
    size_t vertex_count;
    bool directed;
} Graph;

static bool adj_push(AdjList *list, size_t to) {
    if (list->count == list->capacity) {
        size_t next_cap = (list->capacity == 0) ? 4 : list->capacity * 2;
        size_t *buf = (size_t *)realloc(list->neighbors, next_cap * sizeof(size_t));
        if (buf == NULL) {
            return false;
        }
        list->neighbors = buf;
        list->capacity = next_cap;
    }
    list->neighbors[list->count++] = to;
    return true;
}

static bool graph_add_edge(Graph *g, size_t u, size_t v) {
    if (u >= g->vertex_count || v >= g->vertex_count) {
        return false;
    }
    if (!adj_push(&g->lists[u], v)) {
        return false;
    }
    if (!g->directed) {
        if (!adj_push(&g->lists[v], u)) {
            g->lists[u].count--; // 失败回滚，保持无向图对称性
            return false;
        }
    }
    return true;
}

static void graph_bfs_print(const Graph *g, size_t source) {
    unsigned char *visited = (unsigned char *)calloc(g->vertex_count, 1);
    size_t *queue = (size_t *)malloc(g->vertex_count * sizeof(size_t));
    if (visited == NULL || queue == NULL) {
        free(visited);
        free(queue);
        return;
    }
    size_t head = 0, tail = 0;
    visited[source] = 1;
    queue[tail++] = source;

    while (head < tail) {
        size_t u = queue[head++];
        printf("%zu ", u);
        const AdjList *adj = &g->lists[u];
        for (size_t i = 0; i < adj->count; ++i) {
            size_t v = adj->neighbors[i];
            if (!visited[v]) {
                visited[v] = 1;
                queue[tail++] = v;
            }
        }
    }
    printf("\n");
    free(visited);
    free(queue);
}

int main(void) {
    size_t n = 5;
    Graph g = {(AdjList *)calloc(n, sizeof(AdjList)), n, false};
    graph_add_edge(&g, 0, 1);
    graph_add_edge(&g, 0, 2);
    graph_add_edge(&g, 1, 3);
    graph_add_edge(&g, 2, 4);

    printf("BFS from 0: ");
    graph_bfs_print(&g, 0);

    for (size_t i = 0; i < n; ++i) {
        free(g.lists[i].neighbors);
    }
    free(g.lists);
    return 0;
}
```

运行结果：

::: terminal

BFS from 0: 0 1 2 3 4 

:::

实现拥有邻接表的整数图，并提供广度优先遍历：

```c
#include <stdbool.h>
#include <stddef.h>

typedef struct IntGraph IntGraph;

IntGraph *int_graph_create(size_t vertex_count, bool directed);
void int_graph_destroy(IntGraph *graph);
bool int_graph_add_edge(
    IntGraph *graph,
    size_t from,
    size_t to
);
bool int_graph_bfs(
    const IntGraph *graph,
    size_t source,
    size_t *out_order,
    size_t capacity,
    size_t *out_count
);
```

要求：

1. 顶点编号为 `0` 到 `vertex_count - 1`；无向图加边时必须同时维护两个方向。
2. 图拥有全部邻接结点；加边过程中分配失败时，图必须恢复到调用前的状态。
3. 允许重复边，但不能因为重复边重复访问同一个顶点；邻接表按加边顺序保存。
4. `bfs` 按邻接表顺序输出每个可达顶点一次；容量不足、参数无效时不得修改输出数组和 `*out_count`。
5. `destroy(NULL)` 安全；时间复杂度为 $O(V+E)$，并说明边和邻接结点由谁拥有、何时释放。

</Exercise>

在 `31801` 的有向 `IntGraph` 上实现入度与出度统计以及转置有向图构造：

```c
#include <stdbool.h>
#include <stddef.h>

bool int_graph_degrees(
    const IntGraph *graph,
    size_t vertex,
    size_t *out_in_degree,
    size_t *out_out_degree
);
IntGraph *int_graph_transpose(const IntGraph *graph);
```

要求：

1. 两个接口仅对有向图（`directed == true`）生效；若 `graph == NULL`、图为无向图或参数无效，`int_graph_degrees` 返回 `false` 且不修改输出对象，`int_graph_transpose` 返回 `NULL`。
2. `int_graph_degrees` 计算顶点 `vertex` 的入度与出度；自环 `v -> v` 同时使 `v` 的入度和出度各加 $1$，重复有向边按实际条数统计。
3. `int_graph_transpose` 创建并返回一个拥有独立邻接结点的新有向图，按原图顶点 `0` 到 `vertex_count - 1` 及其邻接表顺序将每条边 `u -> v` 反转为 `v -> u`。
4. 转置中途若发生内存分配失败，必须调用销毁逻辑完整释放已分配的半成品图并返回 `NULL`，不得泄漏内存。
5. 说明邻接表下计算单点入度、出度以及整图转置的时间复杂度与空间复杂度。

</Exercise>

实现基于二维扁平数组存储的图邻接矩阵表示法 `MatrixGraph`，支持有向图与无向图建模、边存在性即时判定以及顶点的出度与入度统计：

```c
#include <stdbool.h>
#include <stddef.h>

typedef struct MatrixGraph MatrixGraph;

MatrixGraph *matrix_graph_create(size_t vertex_count, bool directed);
void matrix_graph_destroy(MatrixGraph *graph);
bool matrix_graph_add_edge(MatrixGraph *graph, size_t from, size_t to);
bool matrix_graph_has_edge(const MatrixGraph *graph, size_t from, size_t to, bool *out_has_edge);
bool matrix_graph_degrees(const MatrixGraph *graph, size_t vertex, size_t *out_in_deg, size_t *out_out_deg);
size_t matrix_graph_vertex_count(const MatrixGraph *graph);
```

要求：

1. 顶点编号为 $[0, \text{vertex\_count} - 1]$。底层通过长度为 $V^2$ 的连续布尔数组 `matrix` 紧凑维护。
2. 严谨校验 $V^2$ 的大小计算溢出；若 `vertex_count == 0`，允许创建空图。
3. `matrix_graph_add_edge`：
   - 若为有向图，设置 `matrix[from * V + to] = true`；
   - 若为无向图，必须同时将两个对称槽位 `matrix[from * V + to]` 与 `matrix[to * V + from]` 均置为 `true`。
4. `matrix_graph_has_edge` 在 $O(1)$ 常数时间内完成两顶点间是否存在直接邻接边的查询。
5. `matrix_graph_degrees` 统计顶点 `vertex` 的出度与入度：
   - 对于有向图，分别沿行与列扫描累加出度与入度；
   - 对于无向图，自环使得该顶点的出度和入度均自增 1；普通无向边使两端点度数各加 1。

</Exercise>

<Exercise id="31804" :d="3" :w="2">

普通邻接表依赖离散的堆指针链表存储边，容易引发严重的内存碎片与 CPU 缓存未命中（Cache Miss）。实现基于紧凑连续内存数组的静态链表化图表示法——**链式前向星（Forward Star）**：

```c
#include <stdbool.h>
#include <stddef.h>
#include <stdint.h>

typedef struct ForwardStarGraph ForwardStarGraph;

ForwardStarGraph *fs_graph_create(size_t vertex_count, size_t edge_capacity, bool directed);
void fs_graph_destroy(ForwardStarGraph *graph);
bool fs_graph_add_edge(ForwardStarGraph *graph, size_t from, size_t to, int64_t weight);
bool fs_graph_out_degree(const ForwardStarGraph *graph, size_t vertex, size_t *out_deg);
```

要求：

1. 内部仅分配两块平整的连续内存数组：
   - 表头索引数组 `head`：长度为 `vertex_count`，记录每个顶点出发的第一条边在边数组中的下标；初始全置为无效哨兵值（`SIZE_MAX`）；
   - 边对象连续数组 `edges`：容量为 `edge_capacity`，元素结构包含终点 `to`、权重 `weight` 以及同一起点的下一条边下标 `next`。
2. `fs_graph_add_edge` 在 $O(1)$ 时间内以类似单链表头插法的机制追加边，并更新 `head[from]`；若边数组容量已满或参数非法，安全返回 `false` 且不修改原图。
3. `fs_graph_out_degree` 遍历该顶点的链式索引，统计出度。
4. 深入剖析链式前向星在现代 CPU 体系结构下的缓存局部性优势，对比分析其与传统邻接表的优缺点。

</Exercise>

<Exercise id="31805" :d="5" :w="4">

普通邻接表仅能快速遍历出边，查询入边与前驱顶点需要耗时 $O(V + E)$ 全图扫描；而逆邻接表又失去了快速遍历出边的能力。实现将邻接表与逆邻接表无缝缝合的经典数据结构——**有向图十字链表（Orthogonal List）**：

```c
#include <stdbool.h>
#include <stddef.h>

typedef struct OrthogonalGraph OrthogonalGraph;

OrthogonalGraph *ortho_graph_create(size_t vertex_count);
void ortho_graph_destroy(OrthogonalGraph *graph);
bool ortho_graph_add_arc(OrthogonalGraph *graph, size_t tail, size_t head);
bool ortho_graph_in_degree(const OrthogonalGraph *graph, size_t vertex, size_t *out_in_deg);
bool ortho_graph_out_degree(const OrthogonalGraph *graph, size_t vertex, size_t *out_out_deg);
```

要求：

1. 顶点编号为 $[0, \text{vertex\_count} - 1]$。每个顶点记录出弧链表头指针 `first_out` 与入弧链表头指针 `first_in`。
2. 弧（有向边）节点包含四项核心成员：
   - 弧尾顶点 `tail_vex`（起点）与弧头顶点 `head_vex`（终点）；
   - 入弧链指针 `hlink`：指向同一弧头（入点相同）的下一条弧；
   - 出弧链指针 `tlink`：指向同一弧尾（出点相同）的下一条弧。
3. `ortho_graph_add_arc` 在 $O(1)$ 时间内同时将新弧挂载到起点的出弧链表与终点的入弧链表头部。
4. `ortho_graph_in_degree` 与 `ortho_graph_out_degree` 分别在正比于该顶点自身入度与出度（严格为 $O(\text{deg}(v))$）的时间内完成统计，严禁扫描任何无关顶点的链表。
5. 析构函数必须确保每条在两组链表中被共同引用的弧节点被且仅被释放一次，严防重复释放（Double Free）与悬挂指针。

</Exercise>

<Exercise id="31806" :d="5" :w="4">

在普通邻接表中表示无向图时，每一条无向边 $(u, v)$ 都必须拆分复制为两个独立的边节点（分别挂在 $u$ 与 $v$ 的链表中）。这导致对某条边进行状态标记（如是否访问过、权重修改、删除）时，必须在两个链表中分别搜寻同步，极易产生状态不一致。实现无向图边对象共享表示法——**邻接多重表（Adjacency Multilist）**：

```c
#include <stdbool.h>
#include <stddef.h>

typedef struct MultiListGraph MultiListGraph;

MultiListGraph *ml_graph_create(size_t vertex_count);
void ml_graph_destroy(MultiListGraph *graph);
bool ml_graph_add_edge(MultiListGraph *graph, size_t u, size_t v);
bool ml_graph_mark_edge(MultiListGraph *graph, size_t u, size_t v, bool *out_previously_marked);
void ml_graph_reset_marks(MultiListGraph *graph);
size_t ml_graph_degree(const MultiListGraph *graph, size_t vertex);
```

要求：

1. 顶点编号为 $[0, \text{vertex\_count} - 1]$。全图的每一条物理无向边**仅且必须仅分配一个单一的边对象结构体**。
2. 边节点结构体包含：
   - 两个端点 `ivex` 与 `jvex`；
   - 依附于 `ivex` 的下一条边指针 `ilink`；
   - 依附于 `jvex` 的下一条边指针 `jlink`；
   - 边状态标记 `marked`。
3. `ml_graph_add_edge` 在 $O(1)$ 时间内将同一个边对象同时挂接至两个端点的链表头部。
4. `ml_graph_mark_edge` 找到连接 $u$ 与 $v$ 的边对象，将其 `marked` 设为 `true`，并将此前旧标记值写入 `*out_previously_marked`。验证从 $u$ 侧标记该边后，从 $v$ 侧立刻可感知该标记已更新。
5. 析构时必须安全释放全图所有共享边节点，保证每条边恰被释放一次，零内存泄漏与零重复释放。

</Exercise>
