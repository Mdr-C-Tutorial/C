# 3.3 赋值运算符

## 1. 直接赋值

很简单，`=` 左侧写要赋值的对象，右侧写要赋予的值。比如：

```c
int a = 0; // 在定义对象 a 的同时，将 0 赋值给 a
a = 5; // 把 5 这个值给 a 这个对象
```

## 2. 复合赋值

复合赋值运算符由一个二元运算符和 `=` 组成，如 `+=`、`<<=`，可以把运算和赋值写在一起，使代码更简洁。

### 2.1 加法复合赋值 `+=`

`a += b;` 等效于 `a = a + b;`，把 `a` 与 `b` 的和存入 `a`。

```c
int a = 10;
a += 5; // 等效于 a = a + 5;
// 此时 a 的值为 15
```

### 2.2 减法复合赋值 `-=`

`a -= b;` 等效于 `a = a - b;`，把 `a` 与 `b` 的差存入 `a`。

```c
int a = 10;
a -= 5; // 等效于 a = a - 5;
// 此时 a 的值为 5
```

### 2.3 乘法复合赋值 `*=`

`a *= b;` 等效于 `a = a * b;`，把 `a` 与 `b` 的积存入 `a`。

```c
int a = 10;
a *= 5; // 等效于 a = a * 5;
// 此时 a 的值为 50
```

### 2.4 除法复合赋值 `/=`

`a /= b;` 等效于 `a = a / b;`，把 `a` 除以 `b` 的商存入 `a`。

```c
int a = 10;
a /= 5; // 等效于 a = a / 5;
// 此时 a 的值为 2
```

两个操作数都是整数时，进行的是整数除法，小数部分被舍去。

### 2.5 取模复合赋值 `%=`

`a %= b;` 等效于 `a = a % b;`，把 `a` 除以 `b` 的余数存入 `a`。

```c
int a = 10;
a %= 3; // 等效于 a = a % 3;
// 此时 a 的值为 1
```

### 2.6 位运算复合赋值

位运算符也可以与 `=` 组成复合赋值运算符：

- `a &= b;` 等效于 `a = a & b;`（按位与）。
- `a |= b;` 等效于 `a = a | b;`（按位或）。
- `a ^= b;` 等效于 `a = a ^ b;`（按位异或）。
- `a <<= b;` 等效于 `a = a << b;`（左移）。
- `a >>= b;` 等效于 `a = a >> b;`（右移）。

```c
int n = 10; // 二进制为 1010
int MASK = 12; // 二进制为 1100
n &= MASK; // 执行按位与运算，结果为 1000（十进制为 8）
// 此时 n 的值为 8
```

