# 3.1 运算符

运算符 (Operator) 把一个或多个操作数 (Operand) 组合成表达式。学习每个运算符时，需要弄清三点：

1. 它对操作数的**类型要求**；
2. 求值时操作数会发生哪些**隐式转换**；
3. 它的操作数之间、副作用之间有怎样的**求值顺序**。
