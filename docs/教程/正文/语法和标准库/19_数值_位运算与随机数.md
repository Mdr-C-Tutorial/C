# 19. 数值、位运算与随机数

C 标准库的数值处理能力分布在多个头文件中。本章依次介绍实数与复数函数、类型泛型数学宏、伪随机数、位操作、带检查的整数算术和浮点环境。

::: warning 注意

`<stdbit.h>` 和 `<stdckdint.h>` 从 C23 开始提供。使用前应确认目标实现及所选语言模式是否支持。

:::

## 本章目录

1. [19.4 `<math.h>`](/教程/正文/语法和标准库/19_数值_位运算与随机数/19_4_math)：实数数学函数。
2. [19.5 `<complex.h>`](/教程/正文/语法和标准库/19_数值_位运算与随机数/19_5_complex)：复数类型与函数。
3. [19.6 `<tgmath.h>`](/教程/正文/语法和标准库/19_数值_位运算与随机数/19_6_tgmath)：按实参类型选择数学函数。
4. [19.7 随机数生成](/教程/正文/语法和标准库/19_数值_位运算与随机数/19_7_随机数生成)：`rand` 和 `srand`。
5. [19.8 `<stdbit.h>`](/教程/正文/语法和标准库/19_数值_位运算与随机数/19_8_stdbit)：无符号整数的位操作。
6. [19.9 `<stdckdint.h>`](/教程/正文/语法和标准库/19_数值_位运算与随机数/19_9_stdckdint)：带溢出检查的整数算术。
7. [19.10 `<fenv.h>`](/教程/正文/语法和标准库/19_数值_位运算与随机数/19_10_fenv)：浮点环境和浮点异常。

要求：

1. 使用 `<math.h>`；
2. 保留 6 位小数输出；
3. 不要假设输入一定成功（检查输入函数返回值）。
