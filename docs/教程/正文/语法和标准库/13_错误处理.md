# 错误处理

C 没有内建的异常机制。本章只介绍标准库提供的断言、`errno` 和信号；普通函数还会通过返回值报告成功或失败。

## 三种机制

| 场景 | 推荐手段 | 目的 |
| :-- | :-- | :-- |
| 程序内部前提被破坏 | `assert` | 在启用断言时报告失败并终止。 |
| 标准库函数明确以 `errno` 补充失败原因 | 返回值和 `errno` | 先由返回值判断失败，再读取原因。 |
| 接收标准信号 | `signal` | 安装信号处理函数或恢复默认处理。 |

::: warning 重要

定义了 `NDEBUG` 后，`assert` 会被移除，其表达式也不会被求值。因此不能用断言处理必须在发布版本中检查的输入或运行失败。

:::
