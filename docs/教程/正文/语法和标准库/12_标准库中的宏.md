# 标准库中的宏

标准头文件提供了一组用于描述实现能力和类型范围的宏，同时也声明相关类型。例如，`INT_MAX` 表示 `int` 的最大值，`PRId64` 提供适合 `int64_t` 的格式片段，`offsetof` 计算结构体成员的偏移。

## 本章内容

1. [12.1 `<stddef.h>`](/教程/正文/语法和标准库/12_标准库中的宏/12_1_stddef)：常用类型、`NULL` 和 `offsetof`。
2. [12.2 `<stdint.h>`](/教程/正文/语法和标准库/12_标准库中的宏/12_2_stdint)：定宽整数类型及其范围宏。
3. [12.3 `<inttypes.h>`](/教程/正文/语法和标准库/12_标准库中的宏/12_3_inttypes)：整数转换函数和格式宏。
4. [12.4 `<limits.h>`](/教程/正文/语法和标准库/12_标准库中的宏/12_4_limits)：基本整数类型的范围。
5. [12.5 `<float.h>`](/教程/正文/语法和标准库/12_标准库中的宏/12_5_float)：浮点类型的特征与范围。
6. [12.6 功能特性测试宏](/教程/正文/语法和标准库/12_标准库中的宏/12_6_功能特性测试宏)：判断语言版本和实现能力。

这些名称表达的是标准或具体实现给出的事实。不要用某个平台上的常见数值代替它们，也不要假定 `int`、`long` 等类型具有固定宽度。
