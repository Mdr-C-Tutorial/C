# 4.1 表达式语句

表达式语句 (expression statement) 是最常见、也最容易被忽略的一类语句：它的形式是“表达式后接分号”。程序会先对表达式求值，再丢弃求得的值；写表达式语句是为了它的副作用。

## 1. 基本形式

```c
count++;          /* 修改对象状态 */
sum += value;     /* 复合赋值 */
printf("ok\n");   /* 函数调用 */
```

这三行都是表达式语句。它们的作用都来自副作用：前两行修改对象的值，第三行通过函数调用写出输出。

## 2. 空表达式语句

只有一个分号 `;` 也是合法语句，称为空语句 (null statement)。它常见于循环体故意留空的场景。

```c
while (*p++ != '\0') {
    ;
}
```

空语句本身不执行任何操作；上例中，循环的全部工作都写在条件 `*p++ != '\0'` 里。如果代码意图不够清楚，建议加注释或改成显式块。

## 3. 常见误用

把条件判断后面误写一个分号，会导致控制语句失效。

::: code-group

```c [正确]
if (ready) {
    do_work();
}
```

```c [错误]
if (ready);
{
    do_work();
}
```

:::

第二段中 `if` 实际控制的是空语句，后面的块会无条件执行。这类问题在代码评审中很常见，务必通过格式化和告警规则提前拦截。

## 4. 有意忽略返回值时的写法

有些函数返回值在当前语境下确实可以忽略。此时可以显式写 `(void)` 转换，表达“这里是有意丢弃”，同时避免和遗漏检查混在一起。

```c
#include <stdio.h>

int main(void) {
    (void)puts("hello");
    return 0;
}
```

输出：

::: terminal

hello

:::

这仍然是表达式语句，但意图更清楚：这次调用只关心副作用，不关心返回值。

## 5. 赋值与条件

赋值表达式加上分号就构成表达式语句。赋值表达式也可以出现在 `if`、`while` 的条件中，但这样容易与比较运算符 `==` 混淆。若只是要更新对象，应写成单独的表达式语句；若确实需要在条件中赋值，宜写成 `if ((x = f()) != 0)` 这样的形式，使赋值和比较各自明确。

## 6. 完整表达式

每条表达式语句中的表达式都是一个完整表达式。前一条表达式语句中的副作用会在下一条开始前完成。把复杂逻辑拆成多条表达式语句，不仅更易读，也不必再依赖同一个表达式内部的求值顺序。

## 7. 与 `for` 三段式的区分

`for (init; cond; step)` 中的 `init`、`cond`、`step` 都不是普通的“表达式语句 + 分号”（`init` 还可以是声明）。`step` 部分常写成逗号表达式，见 [5.4 逗号运算符](/教程/正文/语法和标准库/5_循环与跳转/5_4_逗号运算符)；若 `step` 逻辑过重，拆回循环体往往更清楚。

### 8.2 编程

<Exercise id="10409" :d="3" :w="3">

下面的程序把赋值写进了条件，三处条件的本意各不相同。

```c
#include <stdio.h>

/* 成功返回 0，失败返回负的错误码 */
static int open_sensor(void) {
    return 0;
}

/* 失败返回 -1，成功返回 0～100 的读数 */
static int read_level(void) {
    return 0;
}

static int remaining = 2;

/* 取走一个样本；没有样本时返回 0 */
static int take(void) {
    if (remaining == 0) {
        return 0;
    }
    --remaining;
    return 100;
}

int main(void) {
    int status;
    int level;
    int value;
    int total = 0;

    if (status = open_sensor()) {
        printf("open failed: %d\n", status);
    } else {
        printf("open ok\n");
    }

    if (level = read_level()) {
        printf("level = %d\n", level);
    } else {
        printf("level unavailable\n");
    }

    while (value = take()) {
        total += value;
    }
    printf("total = %d\n", total);
    return 0;
}
```

1. 编译运行，写出输出。三处条件各触发了哪条警告？
2. 逐个说明每处条件的本意与实际判断的内容。为什么读数 0 会被判成“读取失败”？
3. 按 4.1 节第 5 小节的建议改写三处条件，使赋值与比较各自明确。注意 `open_sensor` 用 0 表示成功，`read_level` 用 -1 表示失败，两处的判断条件不能照抄。改写后的输出是什么？
4. `while` 循环把“没有样本”和“样本值为 0”混为一谈。如果传感器确实可能读到 0，这个循环该怎样改？不用指针，改成两个函数（一个报告是否还有样本，一个取出样本）也可以。
5. 编译器对 `if (status = open_sensor())` 只给警告而不报错，原因是什么？

</Exercise>
