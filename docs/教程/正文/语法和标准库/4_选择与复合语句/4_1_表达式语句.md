# 4.1 表达式语句

表达式语句 (expression statement) 是最常见、也最容易被忽略的一类语句：它的形式是“表达式后接分号”。程序会先对表达式求值，再丢弃求得的值；写表达式语句是为了它的副作用。

## 1. 基本形式

```c
count++;          /* 修改对象状态 */
sum += value;     /* 复合赋值 */
printf("ok\n");   /* 函数调用 */
```

这三行都是表达式语句。它们的作用都来自副作用：前两行修改对象的值，第三行通过函数调用写出输出。

## 2. 空表达式语句

只有一个分号 `;` 也是合法语句，称为空语句 (null statement)。它常见于循环体故意留空的场景。

```c
while (*p++ != '\0') {
    ;
}
```

空语句本身不执行任何操作；上例中，循环的全部工作都写在条件 `*p++ != '\0'` 里。如果代码意图不够清楚，建议加注释或改成显式块。

## 3. 常见误用

把条件判断后面误写一个分号，会导致控制语句失效。

::: code-group

```c [正确]
if (ready) {
    do_work();
}
```

```c [错误]
if (ready);
{
    do_work();
}
```

:::

第二段中 `if` 实际控制的是空语句，后面的块会无条件执行。这类问题在代码评审中很常见，务必通过格式化和告警规则提前拦截。

## 4. 有意忽略返回值时的写法

有些函数返回值在当前语境下确实可以忽略。此时可以显式写 `(void)` 转换，表达“这里是有意丢弃”，同时避免和遗漏检查混在一起。

```c
#include <stdio.h>

int main(void) {
    (void)puts("hello");
    return 0;
}
```

输出：

::: terminal

hello

:::

这仍然是表达式语句，但意图更清楚：这次调用只关心副作用，不关心返回值。

## 5. 赋值与条件

赋值表达式加上分号就构成表达式语句。赋值表达式也可以出现在 `if`、`while` 的条件中，但这样容易与比较运算符 `==` 混淆。若只是要更新对象，应写成单独的表达式语句；若确实需要在条件中赋值，宜写成 `if ((x = f()) != 0)` 这样的形式，使赋值和比较各自明确。

## 6. 完整表达式

每条表达式语句中的表达式都是一个完整表达式。前一条表达式语句中的副作用会在下一条开始前完成。把复杂逻辑拆成多条表达式语句，不仅更易读，也不必再依赖同一个表达式内部的求值顺序。

## 7. 与 `for` 三段式的区分

`for (init; cond; step)` 中的 `init`、`cond`、`step` 都不是普通的“表达式语句 + 分号”（`init` 还可以是声明）。`step` 部分常写成逗号表达式，见 [5.4 逗号运算符](/教程/正文/语法和标准库/5_循环与跳转/5_4_逗号运算符)；若 `step` 逻辑过重，拆回循环体往往更清楚。
