# 4.2 复合语句

复合语句 (Compound Statement) 是用花括号包裹的一组声明与语句，也常被称为“块”。它不仅是排版工具，更是作用域和存储期的边界。

## 1. 基本语法

```c
{
    声明序列
    语句序列
}
```

进入块时，块内自动存储期对象开始生效；离开块时，它们的生命周期结束。

## 2. 复合语句与作用域

```c
#include <stdio.h>

int main(void) {
    int x = 1;

    {
        int y = 2;
        printf("%d %d\n", x, y);
    }

    printf("%d\n", x);
    return 0;
}
```

输出：

::: terminal

1 2
1

:::

`y` 的作用域到内层块的 `}` 为止，外层的第二个 `printf` 不能使用 `y`。把只在局部用到的对象声明在内层块中，可以缩小它的作用域和生存期。

## 3. 空复合语句

`{}` 也是合法语句。它常用于占位、宏展开兼容或分支对齐。虽然语义简单，但若频繁出现空块，通常说明控制流可以重构得更清晰。

## 4. 用复合语句作为分支体

即使控制分支当前只有一条语句，也优先使用复合语句。这样在后续扩展时不会破坏结构，也能避免 [4.3.1](/教程/正文/语法和标准库/4_选择与复合语句/4_3_选择语句/4_3_1_if_else) 中介绍的悬垂 if 等陷阱。

## 5. 声明与语句交错

现代 C 允许在复合语句中把声明和普通语句交错书写。这样可以把对象声明放在首次使用附近，减少“声明处离使用处过远”的阅读负担。

```c
{
    step1();
    int code = step2();
    if (code != 0) {
        handle(code);
    }
}
```

当对象生命周期应尽量短时，这种写法通常更清晰。

static int order_total(int price, int qty) {

### 6.3 综合与挑战

<Exercise id="10417" :d="3" :w="3">

下面的工资计算能正确运行，但所有中间量都摊在同一层，而且只能在 C99 及以后编译。

```c
#include <stdio.h>

/* 返回实发工资（元）；hours 或 rate 为负时返回 -1 */
static int payroll(int hours, int rate) {
    if (hours < 0 || rate < 0) {
        printf("invalid\n");
        return -1;
    }

    int normal_hours = hours < 40 ? hours : 40;
    int extra_hours = hours > 40 ? hours - 40 : 0;
    int base_wage = normal_hours * rate;
    int extra_wage = extra_hours * (rate * 3 / 2);
    int gross = base_wage + extra_wage;
    int base = 1000;
    int taxable = gross > base ? gross - base : 0;
    int tax;
    if (gross <= base) {
        tax = gross / 10;
    } else if (gross <= 3000) {
        tax = 100 + taxable / 5;
    } else {
        tax = 500 + taxable * 3 / 10;
    }
    int net = gross - tax;
    printf("gross=%d tax=%d net=%d\n", gross, tax, net);
    return net;
}

int main(void) {
    payroll(20, 15);
    payroll(40, 20);
    payroll(45, 20);
    payroll(50, 30);
    payroll(0, 20);
    printf("%d\n", payroll(-1, 20));
    return 0;
}
```

1. 写出六行输出。
2. 用 `gcc -std=c89 -pedantic -Wall -Wextra` 编译，抄下所有诊断，并指出每条对应哪个声明。
3. 重构：用复合语句把计算工资与计算税额分成两个块，让每个中间量只在需要的范围内可见；函数最外层只保留最终要返回的结果以及确实跨块使用的对象。要求输出与原来逐字节相同。
4. 重构后的程序必须在 `-std=c89 -pedantic -Wall -Wextra` 与 `-Wshadow` 下都零诊断。说明你的块划分是如何同时满足这两条要求的。
5. 验收：`payroll(20, 15)` 输出 `gross=300 tax=30 net=270`；重构后六个调用依次输出 `gross=300 tax=30 net=270`、`gross=800 tax=80 net=720`、`gross=950 tax=95 net=855`、`gross=1650 tax=230 net=1420`、`gross=0 tax=0 net=0`、`-1`。先把期望结果抄成对照表再运行，不要边看输出边改。
6. 把你重构后的版本与原来的版本并排比较：块划分多出来的花括号给读者提供了什么信息？哪些对象的作用域缩小后，阅读时不再需要往上翻找？

</Exercise>
