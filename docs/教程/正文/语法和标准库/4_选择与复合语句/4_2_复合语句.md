# 4.2 复合语句

复合语句 (Compound Statement) 是用花括号包裹的一组声明与语句，也常被称为“块”。它不仅是排版工具，更是作用域和存储期的边界。

## 1. 基本语法

```c
{
    声明序列
    语句序列
}
```

进入块时，块内自动存储期对象开始生效；离开块时，它们的生命周期结束。

## 2. 复合语句与作用域

```c
#include <stdio.h>

int main(void) {
    int x = 1;

    {
        int y = 2;
        printf("%d %d\n", x, y);
    }

    printf("%d\n", x);
    return 0;
}
```

输出：

::: terminal

1 2
1

:::

`y` 的作用域到内层块的 `}` 为止，外层的第二个 `printf` 不能使用 `y`。把只在局部用到的对象声明在内层块中，可以缩小它的作用域和生存期。

## 3. 空复合语句

`{}` 也是合法语句。它常用于占位、宏展开兼容或分支对齐。虽然语义简单，但若频繁出现空块，通常说明控制流可以重构得更清晰。

## 4. 用复合语句作为分支体

即使控制分支当前只有一条语句，也优先使用复合语句。这样在后续扩展时不会破坏结构，也能避免 [4.3.1](/教程/正文/语法和标准库/4_选择与复合语句/4_3_选择语句/4_3_1_if_else) 中介绍的悬垂 if 等陷阱。

## 5. 声明与语句交错

现代 C 允许在复合语句中把声明和普通语句交错书写。这样可以把对象声明放在首次使用附近，减少“声明处离使用处过远”的阅读负担。

```c
{
    step1();
    int code = step2();
    if (code != 0) {
        handle(code);
    }
}
```

当对象生命周期应尽量短时，这种写法通常更清晰。
