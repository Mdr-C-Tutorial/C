# 输入输出库

C 标准库的输入输出接口主要声明在 `<stdio.h>` 中。程序通过流读写字符序列，并用 `FILE *` 指向关联的 `FILE` 对象。

::: warning 注意

本章只讨论 C 标准库接口，不讨论操作系统提供的文件接口。

:::

## 先记住

输入输出函数的返回值属于接口结果的一部分，必须按对应函数的约定检查。读取结束后，可用 `feof` 和 `ferror` 区分到达文件末尾与发生错误。
