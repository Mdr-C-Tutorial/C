# 4. 选择与复合语句

语句描述程序要执行的动作以及控制流怎样继续。本章先学习一次执行一条表达式语句、把多条语句组成一个块，以及根据条件选择路径；重复执行和跳转留到下一章。

## 1. 本章内容

1. [表达式语句](/教程/正文/语法和标准库/4_选择与复合语句/4_1_表达式语句)：求值一个可选表达式。
2. [复合语句](/教程/正文/语法和标准库/4_选择与复合语句/4_2_复合语句)：把多条语句组成一个块。
3. [选择语句](/教程/正文/语法和标准库/4_选择与复合语句/4_3_选择语句)：使用 `if`、`else` 和 `switch` 选择执行路径。

语句之间的执行顺序，不等于一个表达式内部各部分的求值顺序；后者仍由表达式规则决定。

## 2. 习题

<Exercise id="10402" :d="2" :w="2">

下面的程序把 [4.1](/教程/正文/语法和标准库/4_选择与复合语句/4_1_表达式语句) 与 [4.3.1](/教程/正文/语法和标准库/4_选择与复合语句/4_3_选择语句/4_3_1_if_else) 中的三个片段放进一个文件。逐个写出每个片段的输出，并说明原因。

```c
#include <stdio.h>

static void snippet_a(void) {
    int ready = 0;
    if (ready);
    {
        printf("A\n");
    }
}

static void snippet_b(void) {
    int a = 1;
    int b = 0;
    if (a)
        if (b)
            printf("inner\n");
        else
            printf("else\n");
}

static void snippet_c(void) {
    int x = 1;
    {
        int x = 2;
        printf("%d ", x);
    }
    printf("%d\n", x);
}
```

要求：

1. 分别给三个片段加上 `main` 调用后编译，用 `gcc -std=c17 -Wall -Wextra` 观察警告；把警告抄下来，指出每条警告对应哪个片段。
2. 用大括号和复合语句改写 `snippet_a` 与 `snippet_b`：`snippet_a` 改成「条件成立才执行那块代码」，`snippet_b` 改写后 `else` 的归属一目了然，不再依赖缩进去猜。
3. `snippet_c` 里内层 `x` 与外层 `x` 是什么关系？在内层块之后再写 `printf("%d\n", x);`，读到的是哪个对象？

本机输出：`A`、`else`、`2 1`（三行按调用顺序）。

</Exercise>

<Exercise id="10404" :d="4" :w="3">

用 `switch` 的 fallthrough 计算累进税率。税率表如下，收入以元为单位：

| 级距 | 月收入 | 税率 |
|---|---|---|
| 1 | 不超过 3000 | 3% |
| 2 | 3000 以上至 12000 | 10% |
| 3 | 12000 以上至 25000 | 20% |
| 4 | 25000 以上至 35000 | 25% |
| 5 | 超过 35000 | 30% |

要求：

1. 先用 `if`/`else if` 求出收入落在哪一级，再写一个 `switch`，从最高级往低级依次 `case`，靠故意不写 `break` 的 fallthrough 把各级税额累加；
2. 每一处有意的 fallthrough 都要让 `-Wall -Wextra` 不报 `-Wimplicit-fallthrough`。先用注释 `/* fall through */` 试，再换成 C23 的 `[[fallthrough]];`：用 `-std=c17` 编译时加不加 `-pedantic` 有什么不同？用 `-std=c2x` 编译时又怎样？据此说明在 C17 项目里该选哪种写法；
3. 收入为负时返回 -1；
4. 每一级只对落进本级区间的那一段收入计税，最高一级没有上界。照搬「上界减本级下限」的写法时，最高一级的上界该取多大？用 `INT_MAX` 封顶会漏算超过它的收入，形参为什么用 `long long` 更合适；
5. 用这张表验收（本机结果）：`0→0`、`3000→90`、`5000→290`、`12000→990`、`20000→2590`、`25000→3590`、`30000→4840`、`35000→6090`、`50000→10590`、`-100→-1`。验算：5000 元是 3000×3% + 2000×10%。

</Exercise>

<Exercise id="10405" :d="5" :w="4">

下面的程序用嵌套 `if` 实现快递运费，逻辑正确但缩进有六层。先读懂它，再用卫语句和 `switch` 重写，最后验证两者对所有输入的输出完全相同。

```c
int shipping_fee(char zone, int grams, bool express) {
    int fee;

    if (grams > 0) {
        if (zone == 'A') {
            fee = 800;
            if (grams > 1000) {
                fee += ((grams - 1000 + 499) / 500) * 300;
            }
        } else {
            if (zone == 'B') {
                fee = 600;
                if (grams > 1000) {
                    fee += ((grams - 1000 + 499) / 500) * 400;
                }
            } else {
                if (zone == 'C') {
                    fee = ((grams + 999) / 1000) * 900;
                } else {
                    return -1;
                }
            }
        }
        if (express) {
            fee += 500;
        }
        return fee;
    } else {
        return -1;
    }
}
```

要求：

1. 重写后的函数只在开头用卫语句处理 `grams <= 0` 和未知 `zone`，主路径最多两层缩进；
2. 用 `switch (zone)` 代替嵌套的 `zone` 判断；
3. 写一个测试函数，对 `zone` 取 `'A'`、`'B'`、`'C'`、`'D'`，`grams` 取 0、1、500、1000、1001、1500、1501、2000，`express` 取 `false`、`true` 的全部组合，逐个与上面的原函数比较；
4. 两者不一致时打印参数和两个结果，全部一致时打印 `all N cases match`，N 是组合数。

验收：本机原函数对 `('A',500,0)`、`('A',1001,0)`、`('A',1501,0)`、`('B',2000,0)`、`('C',1001,0)`、`('A',1000,1)`、`('D',1000,0)`、`('A',0,0)` 的结果依次为 800、1100、1400、1400、1800、1300、-1、-1。

</Exercise>
