# 9.1 字符串字面量 (String Literal)

字符串字面量是把文本直接写进源代码的方式，例如 `"hello"`。编译器会用每个字符串字面量创建一个数组对象，程序通过这个数组访问其中的字符。

## 1. 基本语义

普通字符串字面量的类型是“`char` 数组”，长度等于字符数加终止空字符 `'\0'`。它具有静态存储期，程序整个执行期间都存在。你可以读取它的内容，但对其进行修改会触发未定义行为。

```c
const char *s = "abc";
```

用 `const char *` 指向字符串字面量，误写的修改操作会被编译器当作错误报告出来。

## 2. 字面量拼接

相邻字符串字面量会在翻译阶段自动拼接，因此下面两段写法等价：

```c
const char *a = "hello, " "world";
const char *b = "hello, world";
```

拼接发生在编译期，不会在运行期产生额外连接开销。

## 3. 内嵌空字符

字面量中可以出现 `'\0'`。字符串函数和 `%s` 都把第一个空字符当作字符串的结尾。

```c
const char raw[] = "ab\0cd";
```

`raw` 的数组长度仍包含全部字符和最终终止符，但用 `%s` 输出时会在第一个 `'\0'` 处停止。

## 4. 编码前缀

C 还支持带前缀的字符串字面量，它们的元素类型和编码各不相同：

- `u8"..."`：UTF-8 字符串字面量，元素类型为 `char`（C23 起为 `char8_t`）。
- `u"..."`：UTF-16 字符串字面量，元素类型为 `char16_t`。
- `U"..."`：UTF-32 字符串字面量，元素类型为 `char32_t`。
- `L"..."`：宽字符串字面量，元素类型为 `wchar_t`。

`char8_t`、`char16_t` 和 `char32_t` 在 `<uchar.h>` 中定义。

## 5. 与字符数组初始化的区别

下面两种写法看起来相似，但语义不同：

```c
char a[] = "abc";         /* 数组对象，可修改内容 */
const char *p = "abc";    /* 指向字符串字面量，不应修改 */

a[0] = 'A';               /* 有效 */
/* p[0] = 'A'; */         /* 编译错误：不能通过 const char * 修改 */
```

即使去掉 `const`，通过 `p` 修改字面量仍然是未定义行为。当遇到需要可写入内容的字符串的场景时，要选择字符数组。
