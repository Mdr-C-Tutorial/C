# 2.6 常量和字面量

把值直接写进源码，看起来只是选一种写法；实际上，写法还会决定这个值的类型，进而影响整个表达式的计算方式。

本节的主体示例适用于 C11、C17 和 C23。

## 1. 从一个意外的结果开始

先运行下面的程序：

```c
#include <stdio.h>

int main(void) {
    double first = 1 / 2;
    double second = 1.0 / 2.0;

    printf("%.1f\n", first);
    printf("%.1f\n", second);
    return 0;
}
```

输出为：

::: terminal

0.0
0.5

:::

第一行为什么不是 `0.5`？

`1` 和 `2` 是整数常量，因此 `1 / 2` 先进行整数除法，结果为 `0`，随后才用这个结果初始化 `double` 对象。`1.0` 和 `2.0` 则是 `double` 类型的浮点常量，所以 `1.0 / 2.0` 的结果是 `0.5`。

程序中只改了值的写法，计算结果就发生了变化。这正是本节要建立的认识：**源码中的值不仅有数值或文本内容，还有类型。**

## 2. 四种常见写法

观察下面四个记号：

```c
1
1.0
'1'
"1"
```

它们分别表示整数、浮点数、字符和字符串，不能互相替换。在日常教学中，这些直接写进源码的形式常被统称为“字面量”。严格按照 ISO C 的词法分类，`1`、`1.0`、`'1'` 分别是整数常量、浮点常量和字符常量，`"1"` 是字符串字面量。

阅读后续内容时，先问两个问题：

1. 这个记号表示数、字符，还是真正的文本？
2. 它具有什么类型，会怎样影响所在的表达式？
