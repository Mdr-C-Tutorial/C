# 2.1 对象 (Object)

## 1. 概念

::: concept object-definition title="对象的定义"

对象是执行环境中数据存储的一个区域，其内容可以表示值。对象不是源代码中的名字，而是那块存储本身：同一个对象可以被不同表达式访问，也可以暂时没有可见标识符（例如通过指针间接访问，或在复合字面量中创建）。

:::

::: generate object-intro kind=explanation concepts=object-definition

面向刚开始学习 C 的读者，解释为什么 C 语义中的“对象”指存储本身而不是标识符；说明同一个对象可以被不同表达式访问、也可以暂时没有可见名字；点明“把对象和标识符分开理解”是后续学习作用域、生存期、链接属性和对象表示的前提，但不要展开这些主题的细节。

:::

## 2. 对象的关键属性

::: concept object-core-attributes title="对象的三组关键属性"

每个对象至少包含三组关键属性：类型、存储期和值。类型决定这段存储如何被解释，存储期决定它何时创建与销毁，值表示当前状态。

:::

::: generate object-attributes kind=explanation concepts=object-core-attributes

面向刚开始学习 C 的读者，逐一解释类型、存储期、值三组属性各自回答什么问题，并用“程序真正操作的是对象，而不是名字”这一原则把三者串联起来。对齐、对象表示和限定符留给后续章节，本节只提及名称。

:::

## 3. 对象与标识符

标识符是源代码中的记号；对象是执行期实体。二者常常一一对应，但并不总是如此：结构体成员并不是独立的顶层标识符，却仍然对应对象；同一块存储也可以通过不同标识符间接访问（第8章指针一节会展开此话题）。

```c
#include <stdio.h>

int main(void) {
    int a = 10;
    int b = a;

    a = 15;
    printf("a = %d, b = %d\n", a, b);
    return 0;
}
```

可能的输出（示例）：

::: terminal
a = 15, b = 10

:::

::: generate object-vs-identifier kind=explanation concepts=object-definition

借助上面的示例代码，面向刚开始学习 C 的读者分步解释：`a` 和 `b` 是两个独立的对象，赋值 `b = a` 把 `a` 的值复制到 `b` 的存储中，因此之后修改 `a` 并不影响 `b`。强调标识符只是访问入口，真正变化的是对象内部状态。

:::

## 4. 对象状态与不确定值

::: concept object-indeterminate-value title="对象存在不等于对象有可用值"

对象创建后并不总是立即具有可读取的值。自动存储期对象若未初始化，其值是不确定的，读取它通常没有语义保障；动态分配存储在写入前也不应被当作已有有效值。

:::

::: generate object-indeterminate kind=explanation concepts=object-indeterminate-value

面向刚开始学习 C 的读者，解释“对象已存在”与“对象已有可用状态”的区别，说明为什么读取未初始化的自动对象没有语义保障，并给出“声明时即初始化”的防御性建议。把这一点定位为避免未定义行为的基础前提。

:::
