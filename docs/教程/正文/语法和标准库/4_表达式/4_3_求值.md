# 求值

求值讨论表达式怎样得到结果，以及求值过程中会发生哪些副作用。一个表达式中有多个子表达式时，还要判断它们之间是否存在标准保证的先后关系。

## 1. 一个需要拆开的表达式

```c
int i = 0;
int x = i++ + ++i; /* UB */
```

这里对 `i` 的两次修改之间没有标准保证的先后关系，因此行为未定义。不要根据某次运行结果猜测顺序，应把操作拆开：

```c
int i = 0;
int a = i++;
int b = ++i;
int x = a + b;
```
