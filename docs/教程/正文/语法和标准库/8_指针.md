# 8. 指针

本章的完整目录：

1. [8.1 其他运算符](/教程/正文/语法和标准库/8_指针/8_1_取地址与间接访问)：取地址与解引用，以及需要更多基础才能讲严谨的其余运算符。

## 1. 定义

::: tip 不同概念

本篇讲义所说的**指针**，和 _体系结构_ 中的指针不是同一个概念：前者指**语言特性**，是 C 语言中**一类类型**的统称；后者指特定的**整数字节地址（偏移量）**。

:::

1. 指针是一种对象类型，它**引用**函数或另一种类型的对象
2. 指针可以不引用任何内容，此时它是一个**空指针**

## 2. 声明

1. 指针声明符的格式：`* 声明符`（一个星加上另一个声明符）
   > 函数声明符：`声明符 ( 形参列表 )`  
   > 数组声明符：`声明符 [ 表达式 ]`  
   > 当上述两行的**声明符**是指针声明符时，得加括号
2. 其中 `声明符` 可以是标识符，也可以是其他的声明符（包括指针声明符）
3. 如果指针声明符是其他声明符的 `声明符` 部分，那么声明一个“指向”其他声明符声明的类型“的指针”

   ```c
   int **p;
    // '**p' 是 指针声明符
    // 它的“声明符”部分为 '*p'，是个指针声明符
    // 声明一个指向“指向 int 的指针”的指针
    ```

## 3. 取地址与解引用

指针最基础的两个操作是取地址 `&` 和解引用 `*`。前者从对象得到地址，后者通过地址访问对象。

```c
int n = 10;
int *p = &n;

*p = 20;
```

这里 `p` 保存 `n` 的地址，对 `*p` 赋值会直接修改 `n`。空指针或无效地址解引用会导致未定义行为，因此解引用前应保证地址有效。

## 4. 空指针

空指针表示“不指向任何对象”，通常写作 `NULL`。空指针可以比较、赋值、传参，但不能解引用。

```c
#include <stddef.h>

int *p = NULL;
if (p == NULL) {
    /* 尚未绑定对象 */
}
```

### 4.1 C23 的 `nullptr` 与 `nullptr_t`

在 C17 及之前，`<stddef.h>` 中的 `NULL` 宏由实现定义为 `(void *)0` 或整数常量 `0`。这导致 `NULL` 在泛型选择（`_Generic`）或可变参数函数中可能退化为普通整数，从而丢失“这是一个指针”的类型信息。

C23 引入了关键字 `nullptr` 作为专属的空指针常量，其类型为 `nullptr_t`（在 `<stddef.h>` 中通过 `typedef typeof(nullptr) nullptr_t;` 定义）：

```c
int *p = nullptr; /* C23 起直接可用，无需包含头文件 */
```

`nullptr` 可以隐式转换为任意指针类型，但**不能**隐式转换为整数类型（除 `bool` 外），因此在 C23 代码中用 `nullptr` 代替 `NULL` 能让编译器拦截误把空指针赋给整数对象的错误。

## 5. 指针与数组

数组表达式在大多数上下文会退化为首元素指针，因此数组与指针在访问语法上经常看起来相似，但两者并不是同一种类型。

```c
int arr[4] = {1, 2, 3, 4};
int *p = arr;      /* 等价于 &arr[0] */

int a = arr[2];
int b = p[2];
```

`arr` 的类型是“4 个 int 的数组”，`p` 的类型是“指向 int 的指针”；`sizeof arr` 与 `sizeof p` 一般不同。数组表达式**不会**退化为指针的常见例外只有四个：作为 `sizeof` 的操作数、作为一元取地址运算符 `&` 的操作数（`&arr` 产生指向整个数组的指针，类型为 `int (*)[4]`）、作为 `alignof` 或 `typeof` 的操作数、以及字符串字面量用于初始化字符数组时。

### 5.1 指针数组与指向数组的指针

阅读声明时要严格区分以下两种构造（`[]` 的优先级高于 `*`）：

1. **指针数组** `int *ptrs[4];`：`ptrs` 是一个包含 4 个元素的数组，每个元素的类型是 `int *`（常见于保存一组字符串首地址，如 `const char *names[]`）。
2. **指向数组的指针** `int (*row_ptr)[4];`：`row_ptr` 是一个指针，它指向一个包含 4 个 `int` 的一维数组。对 `row_ptr + 1` 求值时，地址会一次跨过整行（即 `4 * sizeof(int)` 个字节）。当把二维数组 `int mat[3][4]` 传给函数时，它退化成的正是 `int (*)[4]` 类型的行指针。

## 6. 指针算术

指针加减是按“所指对象类型大小”移动，而不是按字节裸移动。`p + 1` 表示跳到下一个同类型对象地址。

```c
int arr[3] = {10, 20, 30};
int *p = arr;

int x = *(p + 1); /* 20 */
```

::: concept pointer-arithmetic-bounds title="指针算术的范围"

指针加减整数的结果必须仍指向同一数组的元素，或者指向最后一个元素之后的位置（尾后位置），否则行为未定义。对尾后位置的指针解引用也是未定义行为。

:::

### 6.1 指针相减与关系比较

当两个指针 `p` 和 `q` 指向**同一个数组对象**中的元素（或该数组的尾后位置）时：

1. **指针相减 (`p - q`)**：结果表示两个位置之间相隔的元素个数（即下标之差），其类型为定义在 `<stddef.h>` 中的有符号整数类型 `ptrdiff_t`（打印格式说明符为 `%td`）。若两个指针不指向同一数组对象，对它们作减法是未定义行为。
2. **关系比较 (`<`、`<=`、`>`、`>=`)**：仅在两个指针指向同一数组对象的元素（或尾后位置）时良定义，用于比较元素下标的前后位置。对指向两个互不相干的独立对象的指针使用 `<` 或 `>` 比较是未定义行为。
3. **相等性比较 (`==`、`!=`)**：适用于任意两个兼容类型的指针（包括空指针、指向不同对象的指针以及尾后指针），用于判断它们是否指向同一个实体或同为空指针。

```c
#include <stddef.h>
#include <stdio.h>

int main(void) {
    int arr[5] = {10, 20, 30, 40, 50};
    int *begin = &arr[0];
    int *end = &arr[5]; /* 尾后指针：可比较、可相减，但不可解引用 */

    ptrdiff_t len = end - begin;
    printf("len = %td\n", len);

    for (int *cur = begin; cur < end; ++cur) {
        printf("%d ", *cur);
    }
    printf("\n");
    return 0;
}
```

输出：

::: terminal

len = 5
10 20 30 40 50 

:::

## 7. `const` 与指针

`const` 位置不同，含义不同：

```c
int a = 1;
int b = 2;

const int *p1 = &a; /* 不能通过 p1 修改 a，但 p1 可以改为指向 b */
int *const p2 = &a; /* 可以通过 p2 修改 a，但 p2 不能改为指向 b */
```

前者限定的是所指对象（不能通过该指针修改），后者限定的是指针对象本身（不能再指向别的对象），阅读声明时要分开判断。

## 8. 函数指针

函数也有地址，可以通过函数指针间接调用函数，实现回调。

```c
int add(int x, int y) {
    return x + y;
}

int main(void) {
    int (*fp)(int, int) = add;
    return fp(3, 4) == 7 ? 0 : 1;
}
```

标准库的 `qsort`、`bsearch` 通过函数指针形参接收调用者提供的比较函数。

## 10. 形参数组声明的调整规则

::: tip 关于指针

本节涉及指针语法（`int *a` 是声明指针类型的形参，`*` 表示间接访问）。指针是第8章的核心内容，此处只需理解「函数通过指针形参可以访问调用方传入的对象」即可。

:::

形参声明为“某类型的数组”时，会被调整为“指向该类型的指针”。例如 `void f(int a[10]);` 与 `void f(int *a);` 声明的是同一个函数类型，`a[10]` 中的长度不会使编译器检查实参数组的长度。因此函数通常另用一个形参接收元素个数。

```c
void fill(int a[10], int n);   /* 声明层面 a 仍是 int * */
void fill(int *a, int n);      /* 与上式兼容 */
```

### 10.1 形参方括号内的 `static` 与限定符（C99）

为了弥补普通形参数组长度不具约束力的不足，C99 允许在**函数形参最外层的方括号内**编写 `static` 以及类型限定符（`const`、`volatile`、`restrict`）：

1. **`int a[static 10]`**：向编译器承诺调用方传入的实参指针**非空**，且至少指向连续的 `10` 个 `int` 元素。若调用方传入 `NULL` 或长度明显不足的已知数组，编译器可以给出诊断，并据此优化循环。
2. **`int a[const]`**：等价于 `int *const a`，限定形参指针本身在函数体内不可修改指向。
3. **多维数组形参**：只有最外层维度会退化为指针，内层维度仍属于所指数组类型的一部分，因此内层维度不能省略。例如 `void sum_matrix(size_t rows, int mat[][4]);` 中，`mat` 被调整为 `int (*mat)[4]`；若配合变长数组形参语法，也可写作 `void sum_matrix(size_t rows, size_t cols, const int mat[rows][cols]);`（其中 `rows` 与 `cols` 必须在 `mat` 之前声明）。

## 11. void 指针的转换边界

对象指针在 `void*` 之间的往返转换是 C 里常见能力，但前提是“转回原始对象类型”再使用。若转成不兼容类型后直接解引用，行为就不再有保障。

```c
int x = 42;
void *vp = &x;
int *ip = (int *)vp;   /* 转回原类型 */
```

通用容器和回调接口（如 `qsort` 的比较函数）常用 `void *` 传递任意类型对象的地址。
