# 14.3 程序支持

本章介绍三组与程序运行直接相关的标准库能力：结束程序、访问执行环境，以及在函数调用之间进行非局部跳转。

## 本章内容

1. [14.3.1 终止程序](/教程/正文/语法和标准库/14_文本转换_错误与程序生命周期/14_3_程序生命周期/14_3_1_终止程序)：比较从 `main` 返回以及调用 `exit`、`quick_exit`、`_Exit`、`abort` 时的不同效果。
2. [14.3.2 环境访问](/教程/正文/语法和标准库/14_文本转换_错误与程序生命周期/14_3_程序生命周期/14_3_2_环境访问)：使用命令行实参、环境表项和 `system`。
3. [22.2 跳转](/教程/正文/语法和标准库/22_非局部控制与信号/22_2_非局部跳转)：理解 `setjmp` 与 `longjmp` 的语义和限制。

先学习各种终止方式会执行哪些清理，再阅读环境访问。`setjmp` 和 `longjmp` 会绕过通常的函数返回路径，应在掌握普通控制流后再学习。
