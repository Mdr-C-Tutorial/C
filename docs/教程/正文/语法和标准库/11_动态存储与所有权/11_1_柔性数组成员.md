# 11.1 柔性数组成员

柔性数组成员 (Flexible Array Member, FAM) 由 C99 引入，它让一个结构体对象可以由固定的头部和长度可变的尾部组成。网络报文、内存块头部、字符串池等常采用这种布局。

## 1. 基本规则

柔性数组成员必须是结构体的最后一个成员，类型写成不带长度的数组声明。该结构体必须至少还有一个具名成员，因此“只含柔性数组成员”不合法。

```c
struct packet {
    size_t len;
    unsigned char data[];
};
```

`sizeof(struct packet)` 不包含 `data` 的实际存储区；它只计算固定头部，并可能包含对齐填充。

## 2. 正确分配方式

带柔性数组成员的对象通常通过一次动态分配获得，分配的大小为头部大小加上尾部数据的长度。头部大小可以用 `sizeof(struct packet)` 或 `offsetof(struct packet, data)` 计算；做加法之前要检查是否溢出。

```c
#include <stddef.h>
#include <stdint.h>
#include <stdlib.h>
#include <string.h>

struct packet {
    size_t len;
    unsigned char data[];
};

struct packet *packet_create(const unsigned char *src, size_t n) {
    if (n > SIZE_MAX - sizeof(struct packet)) {
        return NULL;
    }

    struct packet *p = malloc(sizeof(struct packet) + n);
    if (p == NULL) {
        return NULL;
    }

    p->len = n;
    if (n != 0) {
        memcpy(p->data, src, n);
    }
    return p;
}
```

与“头部中保存一个指向另一块存储的指针”的做法相比，这种布局只需要一次分配和一次释放，头部与数据在内存中连续存放，局部性也更好。

## 3. 使用边界

柔性数组成员不是普通数组对象，不能单独赋值；只有为尾部实际分配了存储，才能访问 `data[i]`。

## 4. 赋值与复制

对包含柔性数组成员的结构体对象赋值时，只复制 `sizeof(struct packet)` 范围内的头部，不复制尾部数据。需要完整复制时，应按头部大小加尾部长度重新分配，再复制全部数据，而不能依赖结构体赋值。

## 5. 嵌套与容器设计

包含柔性数组成员的结构体不能再作为其他结构体的成员，也不能作为数组元素。设计容器时，通常把它放在最外层，需要多个这样的对象时分别分配，再通过指针引用它们。
