# 数学库

C 标准库的数值处理能力分布在多个头文件中。本章依次介绍实数与复数函数、类型泛型数学宏、伪随机数、位操作、带检查的整数算术和浮点环境。

::: warning 注意

`<stdbit.h>` 和 `<stdckdint.h>` 从 C23 开始提供。使用前应确认目标实现及所选语言模式是否支持。

:::

## 本章目录

1. [18.1 `<math.h>`](/教程/正文/语法和标准库/18_数学库/18_1_math)：实数数学函数。
2. [18.2 `<complex.h>`](/教程/正文/语法和标准库/18_数学库/18_2_complex)：复数类型与函数。
3. [18.3 `<tgmath.h>`](/教程/正文/语法和标准库/18_数学库/18_3_tgmath)：按实参类型选择数学函数。
4. [18.4 随机数生成](/教程/正文/语法和标准库/18_数学库/18_4_随机数生成)：`rand` 和 `srand`。
5. [18.5 `<stdbit.h>`](/教程/正文/语法和标准库/18_数学库/18_5_stdbit)：无符号整数的位操作。
6. [18.6 `<stdckdint.h>`](/教程/正文/语法和标准库/18_数学库/18_6_stdckdint)：带溢出检查的整数算术。
7. [18.7 `<fenv.h>`](/教程/正文/语法和标准库/18_数学库/18_7_fenv)：浮点环境和浮点异常。
