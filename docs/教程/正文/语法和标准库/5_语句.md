# 语句

语句描述程序要执行的动作以及控制流怎样继续。语句前可以带标号；复合语句还能把多条语句组成一个块。

## 本章内容

1. [5.1 表达式语句](/教程/正文/语法和标准库/5_语句/5_1_表达式语句.md)：求值一个可选表达式。
2. [5.2 复合语句](/教程/正文/语法和标准库/5_语句/5_2_复合语句.md)：把多条语句组成一个块。
3. [5.3 选择语句](/教程/正文/语法和标准库/5_语句/5_3_选择语句.md)：按条件选择执行路径。
4. [5.4 循环语句](/教程/正文/语法和标准库/5_语句/5_4_循环语句.md)：重复执行语句。
5. [5.5 跳转语句](/教程/正文/语法和标准库/5_语句/5_5_跳转语句.md)：改变通常的控制流。

语句之间的执行顺序，不等于一个表达式内部各部分的求值顺序；后者仍由表达式规则决定。
