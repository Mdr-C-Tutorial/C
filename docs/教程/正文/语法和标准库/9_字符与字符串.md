# 9. 字符与字符串

本章从字符、基本字符集和字符串字面量出发，再学习 `<ctype.h>` 与 `<string.h>`。单个字符、以空字符结尾的字符串和指定长度的字节序列是三种不同的数据，标准库分别为它们提供了不同的函数。

## 1. 本章内容

1. [字符串字面量](/教程/正文/语法和标准库/9_字符与字符串/9_1_字符串字面量)
2. [ASCII 与基本字符集](/教程/正文/语法和标准库/9_字符与字符串/9_2_ASCII与基本字符集)
3. [`<ctype.h>`](/教程/正文/语法和标准库/9_字符与字符串/9_3_ctype)：判断字符类别并转换大小写。
4. [`<string.h>`](/教程/正文/语法和标准库/9_字符与字符串/9_4_string)：处理空终止字符串和指定长度的字节序列。

## 2. 两条基本规则

传给字符分类函数的值必须是 `EOF`，或能表示为 `unsigned char` 的值。使用字符串函数时，必须保证源字符串以空字符结尾，并且目标数组有足够的空间；处理可能含有空字符的任意字节序列时，应使用带显式长度的内存函数（如 `memcpy`、`memcmp`）。
