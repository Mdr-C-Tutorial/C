# 10. 预处理器

预处理器在 C 代码进入语法分析前处理预处理指令。文件包含、宏替换和条件包含都发生在这一阶段，处理结果随后成为翻译单元的一部分。

## 本章内容

1. [10.1 `#define`](/教程/正文/语法和标准库/10_预处理器/10_1_define.md)：定义和取消定义宏。
2. [10.2 `#include`](/教程/正文/语法和标准库/10_预处理器/10_2_include.md)：包含头文件。
3. [10.3 条件包含](/教程/正文/语法和标准库/10_预处理器/10_3_if_n_def.md)：按条件保留或排除源码。
4. [10.4 `#error` 与 `#warning`](/教程/正文/语法和标准库/10_预处理器/10_4_error_warning.md)：在翻译阶段产生诊断。
5. [10.5 `#embed`](/教程/正文/语法和标准库/10_预处理器/10_5_embed.md)：把资源内容嵌入源码。
6. [10.6 `#pragma`](/教程/正文/语法和标准库/10_预处理器/10_6_pragma.md)：使用实现提供的预处理指令。
7. [10.7 `#line`](/教程/正文/语法和标准库/10_预处理器/10_7_line.md)：改变后续诊断使用的行号和文件名。

先学习最常用的 `#define`、`#include` 和条件包含，再按需阅读其余指令。阅读宏代码时，应先确认展开后的预处理记号，而不是把宏当作普通 C 函数。
