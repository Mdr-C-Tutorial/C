# 24.1 运算符宏

`<iso646.h>` 定义了一组宏，用单词拼写某些运算符。ISO 646 字符集的某些国家变体中没有 `|`、`^`、`~` 等字符，这些宏为在这类环境中编写程序提供了替代写法。

## 1. 对应关系

| 运算符 | 宏       |
| ------ | -------- |
| `&&`   | `and`    |
| `&=`   | `and_eq` |
| `&`    | `bitand` |
| `\|`   | `bitor`  |
| `~`    | `compl`  |
| `!`    | `not`    |
| `!=`   | `not_eq` |
| `\|\|` | `or`     |
| `\|=`  | `or_eq`  |
| `^`    | `xor`    |
| `^=`   | `xor_eq` |

这些宏在预处理阶段被替换为对应的运算符，因此不改变运算符的含义和优先级。

## 2. 示例

```c
#include <iso646.h>
#include <stdio.h>

int main(void) {
    int a = 5;
    int b = 10;

    if (a not_eq b and a < b) {
        puts("a < b");
    }
    return 0;
}
```

输出：

::: terminal

a < b

:::

## 3. 命名冲突

这些名字是宏，包含 `<iso646.h>` 之后，`and`、`or`、`not` 等名字只要作为标识符出现就会被替换，不只是在表达式中。如果程序把这些名字用作标识符（例如函数名 `xor` 或结构成员 `compl`），包含该头文件后就无法通过编译。因此，若要使用 `<iso646.h>`，应只在需要它的源文件中包含，而不要在被广泛包含的公共头文件中包含它。

## 4. 与代用记号的区别

`<iso646.h>` 中的名字是普通的宏，只有包含该头文件后才可用；24.2 介绍的代用记号（如 `<%`、`<:`）则是语言本身的记号，无需包含任何头文件，编译器识别记号时就把它们当作对应的标点。
