# 15.3 存储期与链接

本节从声明规则的角度，整理对象的存储期 (Storage duration) 与标识符的链接 (Linkage)。

它们分别回答两个问题：

1. **存储期**：对象的存储持续多久？（影响生存期）
2. **链接**：同名标识符在不同作用域/翻译单元中，是否指向同一个实体？

## 1. 存储期 (Storage duration)

（C11 起）C 有四类存储期：

1. 自动存储期：块作用域内、未使用 `static` 的对象，进入块创建，离开块销毁。
2. 静态存储期：文件作用域对象，以及块作用域内用 `static` 声明的对象，从程序开始到结束存在。
3. 线程存储期：用 `_Thread_local`（C11）或 `thread_local`（C23）声明的对象，从线程开始到线程结束存在。
4. 分配存储期：动态分配获得的存储（`malloc`/`free`）。

## 2. 链接 (Linkage)

链接决定“同名标识符”是否表示同一个实体。标准区分三类链接：

1. 外部链接 (External linkage)：可被其他翻译单元引用。
2. 内部链接 (Internal linkage)：只在当前翻译单元内可见。
3. 无链接 (No linkage)：只在其作用域内有效（例如函数内局部对象的标识符）。

::: warning 重要

若同一翻译单元中，同一标识符同时具有内部链接与外部链接，行为是未定义的。

:::

## 3. 常见声明组合（速查）

### 3.1 文件作用域（全局）

```c
int g;            /* 静态存储期 + 外部链接（也是“暂定定义”之一，见 15.4） */
static int s;     /* 静态存储期 + 内部链接 */
extern int e;     /* 仅声明：链接为外部；是否定义取决于别处 */
```

### 3.2 块作用域（函数内）

```c
void f(void) {
    int a = 0;        /* 自动存储期 + 无链接 */
    static int b = 0; /* 静态存储期 + 无链接（名字仅在该函数体内可见） */
    (void)a;
    (void)b;
}
```

### 3.3 线程存储期

线程存储期通常与 `static`/`extern` 组合使用，决定链接与可见性：

```c
thread_local int tls1;          /* 线程存储期 + 外部链接（C23） */
static thread_local int tls2;   /* 线程存储期 + 内部链接（C23） */
```

## 4. 函数的链接与 `inline` 内联定义（C99）

函数本身没有存储期，但函数的标识符拥有链接属性：默认情况下，函数声明与定义具有**外部链接**；加上 `static` 后变为**内部链接**（仅在当前翻译单元内可见）。

当使用 C99 引入的 `inline` 函数说明符时，标准区分了两种截然不同的模式：

1. **内部链接内联函数（`static inline`）**：
   每个包含该定义的翻译单元都会拥有一份独立的内部函数定义。编译器既可以在调用点将其内联展开，也可以在需要取函数地址或未开启优化时在当前翻译单元内生成私有函数体，绝不会引起多文件重定义链接错误。**在绝大多数工程头文件中，`static inline` 是最简单、最推荐的做法。**
2. **外部链接内联函数（不带 `static` 的 `inline`）**：
   如果一个函数在某个翻译单元中所有声明都带有 `inline` 且**没有**出现 `extern`，则该定义称为**内联定义 (Inline Definition)**。C99 规定：
   - 内联定义仅供当前翻译单元内联展开时参考，**不会向链接器产出可供外部调用的独立符号**；
   - 若编译器决定不展开某次调用（例如在 `-O0` 下或对该函数取了地址），链接器就必须去寻找该函数的**外部定义 (External Definition)**；
   - 要生成这份唯一的外部定义，需要在且仅在一个 `.c` 源文件中声明 `extern inline int fast_op(int x);`（或写一个不带 `inline` 的定义）。
   - 此外，具有外部链接的 `inline` 函数内部禁止定义可修改的块作用域 `static` 对象，也不得引用当前翻译单元具有内部链接的标识符。

```c
/* 推荐模式：使用 static inline，单文件与多文件头文件均可自足工作 */
static inline int clamp_i32(int v, int lo, int hi) {
    if (v < lo) {
        return lo;
    }
    if (v > hi) {
        return hi;
    }
    return v;
}
```
