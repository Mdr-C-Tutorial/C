# 18. 标准库的使用契约

**C 标准库** (C standard library) 是 C 语言标准的组成部分，由一组标准头文件中声明的函数、宏和类型组成，内容涵盖输入输出、字符串处理、数学运算、动态内存管理、日期与时间、错误处理、数值转换、排序与查找、泛型数学函数和多线程等方面。

## 1. 头文件

### 1.1 `<stdio.h>`

提供输入输出功能，包括：

- 文件操作（如 `fopen()`, `fclose()`, `fread()`, `fwrite()`）
- 格式化输入输出（如 `printf()`, `scanf()`, `fprintf()`, `fscanf()`）
- 字符和字符串的输入输出（如 `getchar()`, `putchar()`, `fgets()`, `puts()`）
- 缓冲区控制（如 `fflush()`, `setvbuf()`）
- 文件定位（如 `fseek()`, `ftell()`, `rewind()`）

等。

### 1.2 `<stdlib.h>`

提供通用工具函数，包括：

- 动态内存分配（如 `malloc()`, `calloc()`, `realloc()`, `free()`）
- 随机数生成（如 `rand()`, `srand()`）
- 整数算术（如 `abs()`, `div()`, `labs()`）
- 搜索和排序（如 `qsort()`, `bsearch()`）
- 环境交互（如 `system()`, `getenv()`, `exit()`）
- 字符串转换（如 `atoi()`, `atof()`, `strtol()`）

等。

### 1.3 `<string.h>`

提供字符串操作函数，用于：

- 字符串复制和连接（如 `strcpy()`, `strncpy()`, `strcat()`, `strncat()`）
- 字符串比较（如 `strcmp()`, `strncmp()`, `strcoll()`）
- 字符串搜索（如 `strchr()`, `strstr()`, `strspn()`, `strpbrk()`）
- 内存操作（如 `memcpy()`, `memmove()`, `memset()`, `memcmp()`）
- 字符串长度计算（如 `strlen()`）

等。

### 1.4 `<math.h>`

提供数学函数，包括：

- 三角函数（如 `sin()`, `cos()`, `tan()`, `asin()`）
- 双曲函数（如 `sinh()`, `cosh()`, `tanh()`）
- 指数和对数（如 `exp()`, `log()`, `log10()`）
- 幂运算（如 `pow()`, `sqrt()`）
- 取整函数（如 `ceil()`, `floor()`, `round()`）
- 绝对值和余数（如 `fabs()`, `fmod()`）

等。

### 1.5 `<time.h>`

提供时间和日期功能：

- 时间测量（如 `time()`, `clock()`, `difftime()`）
- 时间转换（如 `localtime()`, `gmtime()`, `mktime()`）
- 格式化时间显示（如 `strftime()`, `asctime()`, `ctime()`）

### 1.6 `<stdint.h>`

提供固定宽度整数类型和相关宏：

- 精确宽度整数类型（如 `int8_t`, `int16_t`, `int32_t`, `int64_t`）
- 最小宽度类型（如 `int_least8_t`, `int_least16_t`）
- 最快最小宽度类型（如 `int_fast8_t`, `int_fast16_t`）
- 指针整数类型（如 `intptr_t`, `uintptr_t`）
- 最大宽度整数类型（如 `intmax_t`, `uintmax_t`）
- 范围宏（如 `INT8_MIN`, `INT8_MAX`, `UINT8_MAX`）

等。

### 1.7 `<ctype.h>`

提供字符分类和转换函数：

- 字符分类（如 `isalpha()`, `isdigit()`, `isspace()`, `ispunct()`）
- 字符转换（如 `toupper()`, `tolower()`）
- 区域设置相关的字符处理

等。

### 1.8 `<assert.h>`

提供断言功能：

- 运行时断言检查（`assert()` 宏）
- 编译时静态断言（`static_assert`）

### 1.9 `<signal.h>`

提供信号处理功能：

- 信号处理函数注册（`signal()`）
- 信号发送（`raise()`）

### 1.10 `<locale.h>`

提供本地化支持：

- 区域设置控制（`setlocale()`）
- 本地化数据访问（`localeconv()`）

### 1.11 `<threads.h>`

提供多线程支持（C11 起）：

- 线程管理：
  - `thrd_create()` - 创建新线程
  - `thrd_join()` - 等待线程结束
  - `thrd_detach()` - 分离线程
  - `thrd_current()` - 获取当前线程
  - `thrd_exit()` - 终止当前线程

- 互斥量：
  - `mtx_init()` - 初始化互斥量
  - `mtx_lock()` - 加锁
  - `mtx_unlock()` - 解锁
  - `mtx_destroy()` - 销毁互斥量

- 条件变量：
  - `cnd_init()` - 初始化条件变量
  - `cnd_signal()` - 唤醒一个等待线程
  - `cnd_broadcast()` - 唤醒所有等待线程
  - `cnd_wait()` - 等待条件变量
  - `cnd_destroy()` - 销毁条件变量

- 线程局部存储：
  - `tss_create()` - 创建线程特定存储
  - `tss_get()` - 获取线程特定值
  - `tss_set()` - 设置线程特定值
  - `tss_delete()` - 删除线程特定存储

### 1.12 `<stdatomic.h>`

提供原子操作支持（C11 起）：

- 原子类型定义（如 `atomic_int`, `atomic_flag`）
- 原子操作函数（如 `atomic_store()`, `atomic_load()`, `atomic_exchange()`, `atomic_compare_exchange_strong()`）

### 1.13 `<complex.h>`

提供复数运算支持：

- 复数类型定义（`complex`）
- 复数运算函数
- 复数三角函数
- 复数指数和对数函数

### 1.14 `<tgmath.h>`

提供泛型数学函数支持：

- 包含 `<math.h>` 和 `<complex.h>`
- 为其中的数学函数提供泛型宏，按实参的类型自动选用对应的函数

### 1.15 `<stdbit.h>`

提供位操作函数和宏（C23 起）：

- 前导与尾随位计数：`stdc_leading_zeros()`, `stdc_leading_ones()`, `stdc_trailing_zeros()`, `stdc_trailing_ones()`
- 首个 0/1 位的位置：`stdc_first_leading_zero()`, `stdc_first_leading_one()`, `stdc_first_trailing_zero()`, `stdc_first_trailing_one()`
- 位计数：`stdc_count_zeros()`, `stdc_count_ones()`
- 2 的幂与位宽：`stdc_has_single_bit()`, `stdc_bit_width()`, `stdc_bit_floor()`, `stdc_bit_ceil()`
- 字节序：`__STDC_ENDIAN_LITTLE__`, `__STDC_ENDIAN_BIG__`, `__STDC_ENDIAN_NATIVE__`

### 1.16 `<stdckdint.h>`

提供带溢出检查的整数运算（C23 起）：

- 检查算术（宏）：`ckd_add`, `ckd_sub`, `ckd_mul`

::: warning 注意

1. 使用标准库函数前，应包含声明它的头文件。
2. 应检查函数的返回值，了解函数对实参的要求，避免未定义行为。
3. 标准库已提供的功能，应优先使用标准库函数，而不是自行实现。

:::

## 2. 独立实现和宿主实现

C 语言的实现分为两种：独立实现 (freestanding implementation) 和宿主实现 (hosted implementation)。

### 2.1 独立实现

独立实现的执行环境通常没有操作系统支持，常见于单片机程序、实时操作系统 (RTOS) 内核、设备驱动程序、操作系统内核和引导加载程序。

在独立环境中，只保证提供以下头文件：

- `<float.h>`
- `<iso646.h>`
- `<limits.h>`
- `<stdalign.h>`
- `<stdarg.h>`
- `<stdbool.h>`
- `<stddef.h>`
- `<stdint.h>`
- `<stdnoreturn.h>`

这些头文件提供了基本的类型定义、常量和宏，但不包含任何需要操作系统支持的功能。

### 2.2 宿主实现

宿主实现的执行环境通常是操作系统，桌面应用程序、命令行工具和服务器程序都运行在这种环境中。宿主实现提供全部 C 标准库头文件，包括文件操作、标准输入输出和动态内存管理等功能。

#include <stdio.h>

<Exercise id="11804" :d="6" :w="4">

下面这个模块把标准库的活重新实现了一遍，而且实现有缺陷：

```c
#include <stdio.h>
#include <stdlib.h>
#include <string.h>

static size_t mdr_length(const char *s) {
    size_t n = 0;
    while (s[n] != '\0') {
        n++;
    }
    return n;
}

static void mdr_copy(char *dst, const char *src) {
    size_t n = mdr_length(src);
    for (size_t i = 0; i <= n; i++) {
        dst[i] = src[i];
    }
}

static int compare_int(const void *a, const void *b) {
    return *(const int *)a - *(const int *)b;
}

static void report_sorted(int *values, size_t count) {
    qsort(values, count, sizeof values[0], compare_int);
    for (size_t i = 0; i < count; i++) {
        printf("%d ", values[i]);
    }
    printf("\n");
}

int main(void) {
    int values[] = {-2000000000, 2000000000, 0};
    report_sorted(values, 3);

    char text[32] = "abcdef";
    mdr_copy(text + 2, text);
    printf("[%s]\n", text);
    return 0;
}
```

本机运行输出（第一行末尾有一个空格，来自循环里的 `printf("%d ", ...)`）：

```text
2000000000 -2000000000 0 
[ababababa]
```

1. 指出两处真正的缺陷：比较函数里的减法溢出、`mdr_copy` 在源与目标重叠时的行为。再说明第 3 处看似可疑的写法（把数组末尾的终止空字符一并复制）为什么本身没有问题。
2. 用标准库改写：排序用 `qsort` 加一个不会溢出的比较函数；复制换成能处理重叠区的函数。给出修正后的完整程序与输出。
3. `mdr_length` 与 `mdr_copy` 都在重复 `<string.h>` 已有的功能。用一句话说明为什么这里应当直接调用标准函数，而不是自己写。
4. 把 `report_sorted` 的 `sizeof values[0]` 改成 `sizeof values`。说明 `qsort` 这时会按什么步长在数组里移动、越过数组末尾多远，为什么运行结果不可预料，以及编译器为什么发现不了这个错误。

</Exercise>
