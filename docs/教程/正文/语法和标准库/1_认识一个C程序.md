# 1. 认识一个 C 程序

下面的程序只做一件事：输出一行文字。

```c
#include <stdio.h>

int main(void) {
    puts("Hello, C!");
    return 0;
}
```

输出：

::: terminal

Hello, C!

:::

## 1. 源文件

把代码保存在扩展名为 `.c` 的文本文件中，例如 `main.c`。第一部分的所有必做程序都只需要这一个源文件。

## 2. 标准头

`#include <stdio.h>` 使本文件能够按照标准声明使用 `puts`。现在只需要照此书写；预处理的完整规则将在第 17 章说明。

## 3. main 函数

在宿主环境中，程序从 `main` 开始执行。这里使用的 `int main(void)` 表示函数不接收实参，并向执行环境返回一个整数状态。

## 4. 函数调用和语句

`puts("Hello, C!");` 调用标准库函数并输出文字。末尾的分号标志这条语句结束。

`return 0;` 结束 `main`；返回 0 表示正常结束。
