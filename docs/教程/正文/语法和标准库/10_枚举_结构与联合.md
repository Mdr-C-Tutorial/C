# 10. 枚举、结构与联合

数组将同类型的元素排成序列，而现实问题中的数据往往包含离散的状态码、由不同类型字段组合而成的记录，或者在同一时刻只取其一的变体表示。本章依次介绍枚举、结构、联合和类型别名：

## 1. 四种构造的分工

| 语法构造 | 核心用途 | 存储与类型特征 |
| --- | --- | --- |
| 枚举 (`enum`) | 定义具名的离散整数常量集合（如状态码、命令类别） | 底层为整数类型；C23 起可通过 `: 类型` 指定固定底层类型 |
| 结构体 (`struct`) | 将多个不同类型的相关成员按顺序聚合为一个复合对象 | 各成员拥有各自独立的存储空间，总大小包含必要的对齐填充字节 |
| 联合体 (`union`) | 让多个不同类型的成员重叠共用同一段存储空间 | 同一时刻只有一个成员有效，大小由最大成员及对齐要求决定 |
| 类型别名 (`typedef`) | 为已有类型引入易读的同义名称 | 不创建新类型，也不改变原有类型的兼容性 |

在工程实践中，这四种构造经常协同使用：例如用 `enum` 作为判别标签、用 `union` 存放不同分支的载荷、再用 `struct` 将两者封装为**带标签的联合体 (Tagged Union)**，并通过 `typedef` 对外提供简洁的类型名称。
