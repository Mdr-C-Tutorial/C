# 程序支持

本章介绍三组与程序运行直接相关的标准库能力：结束程序、访问执行环境，以及在函数调用之间进行非局部跳转。

## 本章内容

1. [14.1 终止程序](/教程/正文/语法和标准库/14_程序支持/14_1_终止程序.md)：比较从 `main` 返回以及调用 `exit`、`quick_exit`、`_Exit`、`abort` 时的不同效果。
2. [14.2 环境访问](/教程/正文/语法和标准库/14_程序支持/14_2_环境访问.md)：使用命令行实参、环境表项和 `system`。
3. [14.3 跳转](/教程/正文/语法和标准库/14_程序支持/14_3_跳转.md)：理解 `setjmp` 与 `longjmp` 的语义和限制。

先学习各种终止方式会执行哪些清理，再阅读环境访问。`setjmp` 和 `longjmp` 会绕过通常的函数返回路径，应在掌握普通控制流后再学习。
