# 并发支持库

C11 在标准库中加入了线程和原子操作支持。`<threads.h>` 提供线程及同步接口，`<stdatomic.h>` 提供原子类型和原子操作。

## 本章内容

1. [22.1 线程](/教程/正文/语法和标准库/22_并发支持/22_1_线程.md)：创建、等待和结束线程。
2. [22.2 原子操作](/教程/正文/语法和标准库/22_并发支持/22_2_原子操作.md)：对共享对象进行原子访问。
3. [22.3 互斥](/教程/正文/语法和标准库/22_并发支持/22_3_互斥.md)：用互斥量保护临界区。
4. [22.4 条件等待](/教程/正文/语法和标准库/22_并发支持/22_4_条件变量.md)：等待共享条件发生变化。
5. [22.5 线程局部存储](/教程/正文/语法和标准库/22_并发支持/22_5_线程局部存储.md)：让每个线程拥有各自的对象。

## 先记住

多个线程并发访问同一对象，并且至少有一次访问会修改它时，必须使用标准允许的同步方式；否则可能形成数据竞争，而数据竞争会导致未定义行为。不同实现对 `<threads.h>` 的支持程度可能不同，使用前还应确认目标实现是否提供这些接口。
