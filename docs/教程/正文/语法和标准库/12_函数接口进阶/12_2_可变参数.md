# 12.2 可变参数

可变参数函数在调用时可以接收个数不定的实参，典型例子是 `printf`。读取这些实参要用到 `<stdarg.h>` 中的 `va_list`、`va_start`、`va_arg`、`va_end`（以及 `va_copy`）。

## 1. 约束与设计要点

与 `...` 对应的实参不携带类型信息，函数本身无法得知调用方实际传入了多少个实参，也无法得知每个实参的类型。因此调用方和函数之间必须事先约定，例如用第一个形参给出实参的个数，或者像 `printf` 那样用格式字符串描述每个实参的类型。

## 2. 一个安全的最小模式

```c
#include <stdarg.h>
#include <stddef.h>

long long sum_ints(size_t count, ...) {
    va_list ap;
    long long total = 0;

    va_start(ap, count);
    for (size_t i = 0; i < count; ++i) {
        total += va_arg(ap, int);
    }
    va_end(ap);

    return total;
}
```

这里约定：第一个实参 `count` 给出其后 `int` 实参的个数。例如 `sum_ints(3, 1, 2, 3)` 的结果是 `6`。

## 3. 默认实参提升

在可变参数部分，`float` 会提升为 `double`，较窄整数类型会提升为 `int` 或 `unsigned int`。因此 `va_arg` 取值类型必须与提升后类型一致，否则行为未定义。

## 4. `va_copy` 的使用场景

当同一组可变实参需要被遍历不止一次时，应使用 `va_copy` 复制实参游标。直接重复读取同一个 `va_list` 会导致未定义行为。

```c
#include <stdarg.h>

int consume_twice(int n, ...) {
    va_list ap;
    va_list ap2;

    va_start(ap, n);
    va_copy(ap2, ap);

    /* 第一次读取 ap ... */
    /* 第二次读取 ap2 ... */

    va_end(ap2);
    va_end(ap);
    return 0;
}
```

## 5. 前向转发模式

可变参数函数常写成两层：外层函数接收 `...`，用 `va_start` 得到 `va_list`，再交给接受 `va_list` 形参的内层函数处理。标准库成对提供了这两种形式，例如 `printf` 与 `vprintf`、`fprintf` 与 `vfprintf`。这样，格式解析等逻辑只需要在内层实现一次。
