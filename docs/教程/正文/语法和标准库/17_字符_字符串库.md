# 字符和字符串库

C 标准把字符分类与大小写转换放在 `<ctype.h>` 中，把字符串和字节序列操作放在 `<string.h>` 中。两组接口处理的对象不同，不应只凭函数名混用。

## 本章内容

1. [17.1 `<ctype.h>`](/教程/正文/语法和标准库/17_字符字符串库/17_1_ctype)：判断字符类别并转换大小写。
2. [17.2 `<string.h>`](/教程/正文/语法和标准库/17_字符字符串库/17_2_string)：处理空终止字符串和指定长度的字节序列。

## 两个基本边界

传给字符分类函数的值必须是 `EOF`，或能表示为 `unsigned char` 的值。使用字符串函数时，则必须确认空字符结尾和目标空间是否满足接口要求；处理任意字节序列时应使用带显式长度的内存函数。
