## 1. 函数声明

简单地，函数声明可以有以下形式：`返回类型 标识符 ( 形式参数列表 )`  
其中，如果这个函数不返回任何东西，则 `返回类型` 的位置填 `void`；如果不接受参数，形式参数列表（以下简称 **形参列表**）里面填 `void`。

例如，要编写一个函数 `say_hello()`，让它在屏幕上输出一段话（这个函数既不接受参数，也不返回值）：

```c
void say_hello(void) {
    puts("Hello, World!");
}
```

例如，编写一个函数 `print_add()`，让它在屏幕上输出两个数的和（这个函数接受两个参数，不返回值）：

```c
void print_add(double a, double b) {
    printf("%g + %g = %g\n", a, b, a + b);
}
```

例如，编写一个函数 `add()`，让它返回两个数的和（这个函数接受两个参数，返回一个值）：

```c
double add(double a, double b) {
    return a + b;
}
```

## 2. 函数调用

使用 `函数名 ( 实际参数列表 )` 的形式调用函数。每个实参表达式会先被求值，再把得到的值赋给对应的形参对象。  
当函数的形参列表为空的时候，实际参数列表（以下简称**实参列表**）什么都不填。

函数调用在程序执行时求值，这与预处理阶段对记号进行的宏替换不同。形参是被调函数内部的对象，对形参赋新值不会改变调用方传入的对象，见第 3 节。

例如，调用 `say_hello()`：

```c
#include <stdio.h>

void say_hello(void) {
    puts("Hello, World!");
}

int main(void){
    say_hello();
    say_hello();
    say_hello();
    return 0;
}
```

运行结果：

```ansi
Hello, World!
Hello, World!
Hello, World!
```

例如，调用 `print_add()`：

```c
#include <stdio.h>

void print_add(double a, double b) {
    printf("%g + %g = %g\n", a, b, a + b);
}

int main(void){
    print_add(1.2, 2.3);
    return 0;
}
```

运行结果：

```ansi
1.2 + 2.3 = 3.5
```

例如，调用 `print_add()` 和 `add()`：

```c
#include <stdio.h>

double add(double a, double b) {
    return a + b;
}

void print_add(double a, double b) {
    printf("%g + %g = %g\n", a, b, a + b);
}

int main(void){
    print_add(add(3.5, 7.4), add(4.5, 4.4));
    return 0;
}
```

`add(3.5, 7.4)` 返回 10.9，`add(4.5, 4.4)` 返回 8.9。如同调用 `print_add(10.9, 8.9)`，会输出：

```ansi
10.9 + 8.9 = 19.8
```

## 3. 形参与实参的边界

下面的例子说明“形参对象得到的是实参的值”：

```c
#include <stdio.h>

void set_to_zero(int x) {
    x = 0;
}

int main(void) {
    int n = 5;

    set_to_zero(n);
    printf("%d\n", n);
    return 0;
}
```

输出：

::: terminal

5

:::

`set_to_zero` 内部修改的是形参对象 `x`，`main` 中的对象 `n` 不会因此改变。若函数需要修改调用方的对象，应传入该对象的地址（指针在第 8 章介绍）：

```c
void set_to_zero(int *p) {
    *p = 0;
}
```

调用时写成 `set_to_zero(&n)`。从函数的形参类型和调用处的 `&` 都能看出 `n` 可能被修改。

## 4. 实参求值顺序

::: concept argument-evaluation-order title="实参的求值顺序"

函数调用中，各实参的求值顺序没有规定，不一定按书写顺序；所有实参求值完成后，才进入被调函数。如果一个实参修改了某个对象，而另一个实参也修改或读取这个对象，行为未定义，例如 `print_add(i++, i++)` 和 `print_add(i++, i)`。

:::

```c
int i = 0;

/* 未定义行为：两个实参都修改 i */
/* print_add(i++, i++); */

print_add(i, i + 1);
```

如果一个调用需要多个有副作用的步骤，先拆成多条语句，再调用函数。

## 6. 函数调用运算符

函数调用表达式会先对被调函数表达式和实参求值，再进入被调函数执行。C 标准没有规定实参求值的先后顺序，因此实参之间不应依赖彼此副作用。

```c
int add(int a, int b) {
    return a + b;
}

int main(void) {
    int s = add(3, 4);
    return s == 7 ? 0 : 1;
}
```

像 `f(i++, i++)` 这类写法是未定义行为，应避免。

## 7. 函数说明符：`inline` 与不返回函数

在函数声明与定义中，除了返回类型和形参列表，还可以使用**函数说明符 (Function Specifiers)** 描述函数的调用与返回特性：

1. **`inline`（C99 引入）**：向编译器建议将该函数的调用在调用点直接展开（内联），以省去短小函数的调用开销。在单文件程序或头文件中，最常用、最稳妥的形式是配合 `static` 写作 `static inline`：

   ```c
   static inline int max_int(int a, int b) {
       return a > b ? a : b;
   }
   ```

   与宏相比，`static inline` 函数拥有完整的形参类型检查，且每个实参只求值一次，不会引发宏展开的重复求值副作用。关于不带 `static` 的 `inline` 与 `extern inline` 在多文件链接时的规则，将在 [15.3 存储期与链接](/教程/正文/语法和标准库/15_声明_名称与生存期/15_3_存储期与链接) 中详细说明。

2. **不返回函数说明**：某些函数（例如报告致命错误并调用 `exit` 或 `abort` 终止程序的函数）一旦被调用就永远不会返回到调用方。C11 引入了 `_Noreturn` 函数说明符（以及 `<stdnoreturn.h>` 中的 `noreturn` 宏），C23 则将其统一升级为标准属性 `[[noreturn]]`（见 [15.6 属性](/教程/正文/语法和标准库/15_声明_名称与生存期/15_6_属性)）。标记该函数不会返回有助于编译器进行控制流分析，并消除调用点后续分支“缺少返回值”的误报警告。
