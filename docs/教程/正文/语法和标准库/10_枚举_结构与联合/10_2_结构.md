# 10.2 结构体

结构体是一种由一系列成员组成的类型，这些成员按顺序分布在内存中。

本章的完整目录：

1. [10.2.1 位域](/教程/正文/语法和标准库/10_枚举_结构与联合/10_2_结构/10_2_1_位域)：指定成员所占的二进制位数。

## 1. 定义

关键字 `struct` + “名字” + 声明列表
其中声明列表是一个用**花括号**环绕的列表，列表中的每一项是一个成员的声明，每个声明以**分号**结尾

```c
struct aircraft_carrier {
    char* name;
    int id;
};
```

上述代码引入了一个新的类型 `struct aircraft_carrier`，并指定了它的含义。
这个类型包含两个成员：`name` 和 `id`。

### 1.1 `typedef` 起别名

```c
typedef struct {
    char* name;
    int id;
} aircraft_carrier;
```

或者

```c
struct aircraft_carrier {
    char* name;
    int id;
};
typedef struct aircraft_carrier aircraft_carrier;
```

取别名之后，可以用 `aircraft_carrier` 表示这个结构体类型。（在第二种情况中，`struct aircraft_carrier` 也可用）

## 2. 初始化

```c
struct aircraft_carrier carrier = { "LiaoNing", 16 };
struct aircraft_carrier carrier2 = { .id = 17, .name = "ShanDong" };
```

初始化结构体要用**花括号**环绕，**逗号**分隔的列表，列表中的每一项都应该是能初始化对应成员的表达式。
可以为列表中的表达式提供**指派符**（一个点 `.` 后加成员名称），初始化结构体内特定的成员。
第二行中 `.id` `.name` 即为**指派符**。

### 2.1 嵌套初始化

```c
#include <stdio.h>

typedef struct {
    int a;
    int b[2];
} A;

typedef struct {
    int c;
    A d;
} B;

int main(void) {
    A a1 = {.a = 1, .b[0] = 4, .b[1] = 5};
    B arr1[] = {
                   {10, .d = a1, .d.a = 2},  // .d.a = 2 覆盖了 a1 中的 a，此时 arr1[0].d.a 为 2
                   [0].d.b[0] = 6            // 此时 arr1[0].d.b[0] 为 6
                };
    // B arr2[] = {{10, .d = a1, .d.a = 2}, [0] = {.d.b[0] = 6}};
    printf("%d", arr1[0].d.a);
    // printf("%d", arr2[0].d.a);

    return 0;
}
```

输出：

::: terminal

2

:::

注释掉的行会报 **warning**，因为在列表的第一个表达式里面已经初始化了 `arr2[0]`，再初始化一遍会覆盖之前的初始化结果。

先用 `.d = a1` 整体初始化 `d`、再用 `.d.a = 2` 覆盖其中一个成员时，`d` 的其余成员是否保留 `a1` 中的值，各编译器的处理并不一致，不要依赖这种写法。

## 4. 成员访问运算符

`.` 用于结构体或联合体对象本身，`->` 用于指向结构体或联合体对象的指针。`a->b` 与 `(*a).b` 语义等价，但后者更容易出错（括号不能省）。

```c
struct point {
    int x;
    int y;
};

struct point p1 = {1, 2};
struct point *pp = &p1;

pp->x = 3;
p1.y = 4;
```

当一个接口以“对象指针”作为输入时，统一使用 `->` 能减少视觉噪声。

## 5. 整体赋值、传参与相等性比较

与数组不同，**同一个结构体类型的两个对象可以直接使用 `=` 整体赋值**，也可以直接作为函数的按值形参或返回值。整体赋值会把结构体内的所有成员（包括嵌在结构体内部的定长数组成员）一并按值拷贝：

```c
#include <stdio.h>

struct buffer {
    int data[3];
    int len;
};

int main(void) {
    struct buffer a = {.data = {10, 20, 30}, .len = 3};
    struct buffer b = a; /* 整体拷贝，b.data 与 a.data 相互独立 */

    b.data[0] = 99;
    printf("a.data[0] = %d, b.data[0] = %d\n", a.data[0], b.data[0]);
    return 0;
}
```

输出：

::: terminal

a.data[0] = 10, b.data[0] = 99

:::

在设计函数接口时：

1. 对于只含两三个标量字段的小型结构体（如二维坐标 `struct point`），按值传参和按值返回直观且高效。
2. 对于体积较大的结构体，按值传参会产生整块内存拷贝开销，应优先传递指向常量结构体的指针 `const struct T *`。
3. **结构体不支持 `==` 或 `!=` 运算符**：C 语言不允许直接写 `p1 == p2`。此外，由于结构体成员之间可能存在值不确定的**填充字节 (Padding)**，也不能简单用 `memcmp(&p1, &p2, sizeof p1) == 0` 判断两个结构体是否相等，而应编写专用的比较函数逐个比较有意义的成员。

## 6. 内存布局、填充字节与 `offsetof`

结构体各成员在内存中严格按照声明顺序依次存放，第一个成员的偏移量必定为 `0`（因此指向结构体的指针在经过显式类型转换后，可以安全地与指向其第一个成员的指针互相转换）。

为了满足各个成员类型的硬件对齐要求（详见 16.2.1 节），编译器可能在相邻成员之间或结构体末尾插入填充字节。因此，结构体的 `sizeof` 往往大于或等于各成员 `sizeof` 之和。可以使用 `<stddef.h>` 中的宏 `offsetof(type, member)` 在编译期查询某个成员距离结构体起始位置的字节偏移：

```c
#include <stddef.h>
#include <stdio.h>

struct record {
    char tag;
    int value;
    char flag;
};

int main(void) {
    printf("offset(tag)   = %zu\n", offsetof(struct record, tag));
    printf("offset(value) = %zu\n", offsetof(struct record, value));
    printf("offset(flag)  = %zu\n", offsetof(struct record, flag));
    printf("sizeof(record)= %zu\n", sizeof(struct record));
    return 0;
}
```

在 `int` 为 4 字节且按 4 字节对齐的常见平台上，输出为：

::: terminal

offset(tag)   = 0
offset(value) = 4
offset(flag)  = 8
sizeof(record)= 12

:::

若将相同对齐要求的成员归拢在一起（例如把 `tag` 和 `flag` 都放在 `value` 之前或之后），往往可以减少填充字节，将 `struct record` 的大小从 12 字节压缩到 8 字节。

## 7. 匿名结构体与匿名联合体成员（C11）

C11 起，结构体或联合体内部可以包含一个**既没有类型标签、也没有成员标识符**的嵌套 `struct` 或 `union`，称为匿名结构体或匿名联合体。匿名成员内部的字段会被直接提升到外层结构体的成员命名空间中，省去中间层的名字：

```c
#include <stdio.h>

struct packet {
    int kind;
    union { /* 匿名联合体：无需再起类似 .payload 的中间成员名 */
        int int_val;
        double float_val;
    };
};

int main(void) {
    struct packet pkt = {.kind = 1, .int_val = 42};
    printf("kind = %d, val = %d\n", pkt.kind, pkt.int_val);
    return 0;
}
```

输出：

::: terminal

kind = 1, val = 42

:::

## 8. 复合字面量 (Compound Literals，C99/C23)

C99 引入了**复合字面量**，语法为：

```c
(type-name){ initializer-list }
```

复合字面量会在表达式所在位置直接构造一个**未命名的对象**，可用于结构体、联合体、数组乃至标量类型。它在向函数临时传递结构体或数组时尤为实用，无需先单独声明一个具名局部对象：

```c
#include <stdio.h>

struct point {
    int x;
    int y;
};

static void print_point(struct point p) {
    printf("(%d, %d)\n", p.x, p.y);
}

static int sum_array(const int *items, size_t count) {
    int total = 0;
    for (size_t i = 0; i < count; ++i) {
        total += items[i];
    }
    return total;
}

int main(void) {
    print_point((struct point){.x = 3, .y = 4});

    int s = sum_array((const int[]){10, 20, 30}, 3);
    printf("sum = %d\n", s);
    return 0;
}
```

输出：

::: terminal

(3, 4)
sum = 60

:::

使用复合字面量时需牢记两条核心语义：

1. **它是左值**：复合字面量表示一个真实存在的对象，因此可以对它取地址（如 `&(struct point){1, 2}`），若未加 `const` 限定，甚至可以修改其成员。
2. **生存期由所在作用域决定**：若复合字面量出现在文件作用域（函数外部），它具有静态存储期，在整个程序运行期间存在；若出现在函数体内部的块作用域中，它默认具有自动存储期，生存期在离开所在的最内层块 `{ ... }` 时结束（切勿将指向块内复合字面量的指针返回到函数外部）。C23 起还允许在类型名前添加存储类说明符，例如 `(static const int[]){1, 2, 3}` 可在块作用域内直接创建具有静态存储期的只读复合字面量。
