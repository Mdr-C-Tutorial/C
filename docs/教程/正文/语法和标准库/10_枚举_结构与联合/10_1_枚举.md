# 10.1 枚举

## 1. 定义

1. 枚举由一组已命名的整数常量值组成，每个不同的枚举构成不同的枚举类型
2. 每个枚举都有一个**底层类型**

## 2. 声明

枚举类型的声明为：`enum (属性说明符序列) (标识符) (: 类型) { 枚举项列表 }`

1. 枚举项列表中的每个 `枚举项` 之间由逗号分隔
2. 每个 `枚举项` 为 `枚举常量 (= 常量表达式)` 的形式
3. 如果省略 `: 类型`，则为无固定底层类型的枚举：这个枚举的底层类型由实现定义，这个类型一定能表示每一个枚举项的值；
   否则为固定底层类型的枚举，底层类型即为 `类型`

当某个枚举项省略 `= 常量表达式` 时，它的值等于前一项加一；首项若也省略，则默认从 `0` 开始。

```c
enum color {
    COLOR_RED,       // 0
    COLOR_GREEN,     // 1
    COLOR_BLUE = 8,  // 8
    COLOR_ALPHA      // 9
};
```

## 3. 作用域与名称

枚举常量名进入其所在作用域，不带 `enum` 前缀，因此要避免与其他标识符重名。枚举类型名本身需要通过 `enum 类型名` 使用；如果希望省去 `enum` 关键字，可以配合 `typedef`。

```c
typedef enum color color_t;

color_t c = COLOR_GREEN;
```

## 4. 转换与比较

枚举对象在表达式中按整数的转换规则参与运算。比较运算和 `switch` 的 `case` 标签都可以直接使用枚举常量，这比直接写整数字面量更容易阅读。

```c
enum state {
    STATE_INIT,
    STATE_READY,
    STATE_STOP
};

int run(enum state s) {
    switch (s) {
        case STATE_INIT:
            return 0;
        case STATE_READY:
            return 1;
        case STATE_STOP:
            return 2;
    }
    return -1;
}
```

`switch` 默认分支仍然建议保留，因为枚举对象在运行期仍可能接收到未预期值。

## 5. 关于固定底层类型

固定底层类型的写法（`enum E : unsigned char`）由 C23 引入；如果目标编译器尚未支持 C23，可以继续使用普通枚举，并在函数接口处检查取值范围。

## 6. 重复枚举值是合法的

同一个枚举中的不同枚举常量可以具有相同的值，标准并不禁止。这可以用来为旧名称提供兼容的别名，但要注意可读性：多个名字对应同一个值时，`switch` 中只会出现其中一个，应在该分支注释说明，避免读者误以为遗漏了分支。

```c
enum token_kind {
    TOK_EOF = 0,
    TOK_END = 0,   /* 与 TOK_EOF 同值，作为兼容别名 */
    TOK_ID  = 1
};
```

## 7. 枚举与位标志

普通枚举适合表示互斥的状态，例如解析器所处的阶段、连接状态或错误类别。可以同时成立的多个选项更适合用位标志表示：每个选项占一个二进制位，用无符号整数保存它们的组合，并为每一位单独定义常量。如果把选项的各种组合逐一列为枚举常量，常量的个数会随选项数成倍增长。
