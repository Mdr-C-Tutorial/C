# 派生类型

派生类型由已有类型构造而来。本章介绍数组、指针、结构体和联合体，它们分别用于表示连续元素、间接访问和复合对象。

## 本章内容

1. [8.1 数组](/教程/正文/语法和标准库/8_派生类型/8_1_数组.md)：由同一元素类型组成的连续序列。
2. [8.2 指针](/教程/正文/语法和标准库/8_派生类型/8_2_指针.md)：间接引用对象或函数。
3. [8.3 结构体](/教程/正文/语法和标准库/8_派生类型/8_3_结构体.md)：把多个成员组成一个类型。
4. [8.4 联合体](/教程/正文/语法和标准库/8_派生类型/8_4_联合体.md)：让多个成员共享同一段存储。

建议按列表顺序学习：先理解数组与指针之间的关系，再学习结构体和联合体怎样组织成员。
