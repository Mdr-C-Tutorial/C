# 选择语句

选择语句根据条件决定执行哪一条路径。C 提供 `if` 和 `switch` 两种形式。

## 如何选择

- [5.3.1 `if` 和 `else`](/教程/正文/语法和标准库/5_语句/5_3_选择语句/5_3_1_if_else.md) 直接判断表达式，适合范围判断和复合条件。
- [5.3.2 `switch`](/教程/正文/语法和标准库/5_语句/5_3_选择语句/5_3_2_switch.md) 把一个整数类型表达式与多个常量分支比较，适合按离散值选择路径。

两种语句都只负责选择路径。条件表达式怎样求值、是否包含副作用，仍由表达式规则决定。
