# 7. 数组

数组把固定数量、具有相同元素类型的对象连续组织起来。本章介绍数组本身的声明、初始化、元素个数计算、多维数组布局以及变长数组；数组表达式与指针的关系在下一章说明。

## 2. 核心要点

1. **连续存储与零起始下标**：数组对象在内存中连续存放，元素之间没有填充字节。长度为 $N$ 的数组，其有效下标范围严格为 `0` 到 `N - 1`。
2. **不携带长度元数据**：C 语言的数组对象在运行期只是一段连续的元素存储，不额外保存自身的元素个数，用下标访问元素时编译器和运行时也不自动检查边界。下标越界访问（或构造越过尾后位置的地址）属于未定义行为。
3. **元素类型必须是完整对象类型**：数组的元素类型不能是不完整类型（如 `void` 或未知长度的数组）或函数类型；当元素类型本身又是定长数组时，就构成了多维数组（即“数组的数组”）。
