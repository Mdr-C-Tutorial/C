# 学习路线

本教程正文分为六部分：

1. **语法和标准库**
2. **开发与工程基础**
3. **数据结构与算法**
4. **系统编程**
5. **项目案例**
6. **嵌入式**

## 主线

第一次系统学习 C 时，建议先完成“语法和标准库”中的基础内容，再进入“开发与工程基础”。第二部分只要求掌握后续学习必需的工程能力：执行命令、编译与链接、使用 Git、组织多文件程序、运行测试，以及借助检查工具发现问题。

具备这些能力后，可以进入“数据结构与算法”。学习者不必等到第三部分全部完成才继续：掌握所需的数据结构后，即可进入“系统编程”或“嵌入式”；“项目案例”则根据具体项目列出前置内容。

## AI 时代的学习重点

命令、接口和样板代码可以随用随查，也可以由 AI 协助生成，不要求机械背诵。学习重点是理解工具和程序的执行模型，能够阅读改动、判断边界，并通过编译器诊断、测试、程序检查工具和 Git 差异验证结果。
