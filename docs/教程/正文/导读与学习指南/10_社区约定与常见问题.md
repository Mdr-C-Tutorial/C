## 3. C 与 C++

C++ 是一门更复杂的编程语言。关于它的讨论超出了本教程的范围。

但你可以通过以下书籍学习 C++：

1. Bjarne Stroustrup 的 **_C++ 程序设计：原理与实践_**（最推荐）
2. Bjarne Stroustrup 的 **_The C++ Programming Language_**（偏工具书）
3. Stanley B. Lippman、Josée Lajoie 和 Barbara E. Moo 的 **_C++ Primer_**（偏工具书）

在 [**C++ Reference**](https://zh.cppreference.com) 上可以找到 C++ 的全部语言特性和标准库功能。

## 4. 提问时应提供什么

1. 希望实现的行为。
2. 能够单独运行的最小代码。
3. 使用的标准模式、编译器及版本。
4. 完整输入、输出和诊断。
5. 已经尝试过的排查方法。

## 5. 常见问题

- 第一部分需要命令行吗？不需要，能够运行一个 `.c` 文件即可。
- 第一部分可以使用标准头吗？可以。第一部分只要求读者自己编写一个源文件，标准头和标准库照常使用。
- 什么时候学习 Git、构建和测试？从第二部分开始。
- 需要背下全部标准库函数吗？不需要。了解标准库有哪几类函数，并学会查阅可靠的资料即可。
