# 4. 如何使用本站

## 1. 正文与生成内容

作者正文负责给出标准版本、事实、代码和准确性边界。标记为 `generate` 的区域根据读者选择的详略、语气和示例偏好生成主讲内容；没有配置生成能力时，作者正文仍然可以直接阅读。

`concept` 块给出生成内容必须遵守的知识边界。移动正文时，关联的 `concept` 与 `generate` 块必须一起保留。

## 2. 习题与自测

`Quiz` 用于当前页面的即时自测；`Exercise` 是需要单独完成的实践任务。习题编号共有五位：第一位表示专业模块，中间两位表示章号，最后两位表示本章内编号。

第 0 部分不设置编号习题。这里的实践建议不会占用六个专业模块的编号。

## 3. 题解与代码

有题解的习题可以从[习题快速导航](/教程/题解/快速导航)进入。正文中的示例负责说明知识，完整程序和测试数据则放在对应代码目录中。

## 4. 报告问题

报告正文或代码问题时，请提供页面地址、相关代码、输入、预期结果、实际结果和完整诊断信息。
