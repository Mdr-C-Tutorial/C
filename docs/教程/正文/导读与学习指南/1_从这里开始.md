# 1. 从这里开始

本教程面向愿意通过阅读、运行、修改和验证程序来学习 C 的读者。开始第一部分前，只需要能够在在线环境或 IDE 中运行一个 `.c` 文件，不要求掌握命令行、Git 或构建系统。

## 1. 第一次阅读

1. 选择一种能运行单文件程序的环境。
2. 从[第一部分：语法和标准库](/教程/正文/语法和标准库)开始。
3. 遇到暂未学习的名称时，先确认当前章节要求理解到什么程度。
4. 完成示例后的修改实验和习题。

## 2. 两条边界

- 第一部分的全部必做示例和习题都能写在一个 `.c` 文件中。
- 自建头文件、多源文件、构建系统、调试、测试和 Git 从第二部分开始。

使用 `<stdio.h>` 等标准头不改变单文件边界；读者编写的源文件仍然只有一个。
