# 2. 教程地图与学习路线

整套教程由一个全站导读和六个专业模块组成。第 0 部分不教授某一项专业知识，而是说明全站的阅读方法、工具入口和资料边界。

1. **第 0 部分：导读与学习指南**
2. **第一部分：语法和标准库**
3. **第二部分：开发与工程基础**
4. **第三部分：数据结构与算法**
5. **第四部分：系统编程**
6. **第五部分：项目案例**
7. **第六部分：嵌入式**

## 1. 连续主线

第一次系统学习 C 时，先完成[第一部分：语法和标准库](/教程/正文/语法和标准库)。这一部分围绕单文件程序建立语言模型：值、对象、类型、表达式、控制流、函数、数组、指针、复合类型、存储、预处理和标准库。

随后进入[第二部分：开发与工程基础](/教程/正文/开发与工程基础)，学习命令行与目录、编译与链接、头文件和接口边界、构建系统、调试、测试、检查工具、Git 和工程组织。工程知识在这里第一次成为主线，而不是穿插在语言规则中。

完成前两部分后，进入[第三部分：数据结构与算法](/教程/正文/数据结构与算法)。之后可以按目标选择[系统编程](/教程/正文/系统编程)、[项目案例](/教程/正文/项目案例)或[嵌入式](/教程/正文/嵌入式)；每个专题应在开头列出额外前置内容。

## 2. 可以交错阅读的内容

- 第一部分中的标准库内容与语法同步出现，不必先学完全部语法再接触标准库。
- 第二部分中的调试和 Git 可以在开始写工程后立即使用，不必等待构建系统章节结束。
- 数据结构与算法不要求覆盖完所有条目才进入应用模块，只需满足目标专题的前置条件。
- 第 0 部分的资料检索、AI 使用和环境页面始终可以按需返回。
