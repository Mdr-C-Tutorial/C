# 3. 编程、C 与标准

## 1. 编程首先是形式化

::: concept intro-programming-formalization title="编程首先是形式化"

用不严谨的话说：**编程是把人类世界的问题，抽象成计算机世界的逻辑，并指挥计算机去执行。**

这个过程包含两个核心步骤：

1. **思维的形式化（Formalization）**：
    你首先要把脑海中模糊的想法（比如“帮我算一下全班平均分”），拆解成逻辑严密、毫无歧义的步骤（“读取所有分数” -> “累加” -> “除以总人数”）。
2. **逻辑的翻译（Translation）**：
    使用一种人能读懂、计算机也能通过工具（编译器）理解的语言——**编程语言**，将上述步骤记录下来。

所以，编程不是单纯的“敲代码”，那是打字员的工作。

:::

## 4. C 标准

::: concept intro-c-standard-lineage title="标准版本与实现支持是两件事"

1. 事实标准：**K&R C**
2. **ANSI C**（被 ISO 采纳）
3. 从 **C89** 到 **C23**（建议大家有空了看看标准）
4. 未来的 C2y（如果有精力和能力，可以关注最新的草案，了解新标准的制定进程）

:::

::: generate intro-c-version-choice kind=comparison concepts=intro-c-standard-lineage

构造一个真实选择场景：学习者电脑上安装了某个版本的 GCC 或 Clang，但课程示例分别使用 C11 与 C23 特性；比较“编译器版本”“`-std=` 模式”和“ISO C 标准版本”，并说明如何判断一段代码能否使用。不得把编译器扩展当作标准特性。

:::
