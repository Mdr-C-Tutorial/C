# 9. 推荐资源

## 1. 网站

1. [**C++ 参考手册**](https://zh.cppreference.com/)
   学习 C 和 C++ 必备网站（注：C 和 C++ 是不同的编程语言；这个网站虽然名字中带 C++，但是其中也有 C 语言的内容，阅读这部分内容即可）
   ![cppreference](/images/导读与学习指南/资源/001.png)
2. [**Compiler Explorer**](https://godbolt.org/)
   在线编译器，支持生成汇编等多项功能，支持非常多的语言和多种编译器
   ![compiler explorer](/images/导读与学习指南/资源/002.png)
3. [**Codewars**](https://www.codewars.com/)
   偏实际应用的题目，注重语言特性和实践，需要登录后使用；**成功解题之后可以看到所有人的解题方法并进行评价**
   ![codewars](/images/导读与学习指南/资源/006.png)
   登录后初始化账号，鼠标移动到左边打开侧边栏，点击 **practice**

## 2. C 书籍

**_C 程序设计语言 第 2 版_**：C 语言之父力作，它有个更熟悉的名字叫 **K&R**；

**_C Programming: A Modern Approach, 2nd Edition_**：优秀的入门书；
习题答案暂时见[**这里**](https://github.com/williamgherman/c-solutions)

**_C Primer Plus 第六版（中文版）_**：C 语言的经典教材;
习题答案暂时见[**这里**](https://github.com/Relph1119/c-primer-plus)

**_Modern C_**：C 语言标准委员会成员 Jens Gustedt 编写，紧跟语言发展，但节奏较快；MCT 给出了这本书的[中文翻译](/教程/ModernC/目录)。

## 3. 后续阅读

1. **SICP** (Structure and Interpretation of Computer Programs) 第二版（用 **Scheme** 写的那个版本）
2. **CS:APP** (Computer Systems: A Programmer’s Perspective)
3. [**pl-docs**](https://github.com/FrankHB/pl-docs/blob/master/zh-CN)
