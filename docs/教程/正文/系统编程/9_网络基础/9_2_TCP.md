# 9.2 传输控制协议（TCP）

## 1.1 什么是 TCP

### 1.1.1 TCP 的作用和特点

TCP（传输控制协议）是一种在计算机网络中广泛使用的协议，它提供了可靠的、面向连接的数据传输服务。
TCP 的主要作用是确保数据的可靠传输，以及维护数据传输的顺序和完整性。以下是 TCP 的一些特点和作用：

1. 可靠性：TCP 使用确认和重传机制来确保数据的可靠性。当发送方发送数据时，它会等待接收方的确认，如果未收到确认，就会重新发送数据。

2. 面向连接：TCP 在数据传输之前需要建立连接，这个连接是双向的，数据可以在两端自由传输。连接建立后，数据的传输是可控的。

3. 数据流控制：TCP 可以根据接收方的处理能力来控制数据的发送速率，以避免数据丢失或堆积。

4. 有序性：TCP 确保数据按照发送的顺序到达接收端，这样数据不会混乱或错乱。

5. 错误检测和纠正：TCP 使用校验和与序列号来检测和纠正数据传输中的错误。

## 1.2 TCP 的基本功能

### 1.2.1 建立连接

TCP 连接的建立是一个三步握手的过程。
客户端首先向服务器发送一个连接请求，服务器收到请求后回复一个确认，并分配资源以准备接收数据，然后客户端发送最后的确认，建立连接。

### 1.2.2 数据传输

一旦连接建立，数据可以在客户端和服务器之间双向传输。数据被分割成小的数据段，每个数据段都有序号，接收方会按顺序组装这些数据段。

其中一方发送一个连接关闭请求，表明这一方没有需要发送的数据，另一方回复确认。若是另一方也没有需要发送的数据了，也发送一个连接关闭请求。此时对端也要回复一个确认（这意味着，双向的数据通路可以分别关闭）。在这之后，进入 TIME\_WAIT 阶段，双方都需要等待两个 MSL（最大报文生存时间）以确保连接中残存的报文彻底消散，这是为了防止数据丢失，在这之后，连接才正式被关闭。

还有一种断开连接的方式被称为连接重置。简单来说，它是一种异常的关闭。收到连接重置会导致缓冲区的数据全部丢失，且连接立即关闭。常见的原因包括进程突然被杀死、反复超时、SO\_LINGER 参数设为 0 等。当连接重置发生时，你可以抓取到一个 TCP 段，其中 RST Flag 置位为 1。这个 TCP 段没有应答，因为连接此时已经关闭，若该 TCP 段丢失，则当对端再次发送数据的时候，该 TCP 段会再次被发送。

## 1.3 TCP 的特点和可靠性

### 1.3.1 数据分段

TCP 将数据分割成小的数据段，每个数据段都有序号和确认号。
这样可以确保数据在传输过程中可以按照正确的顺序重新组装，同时还可以检测和纠正传输中的错误。

值得注意的是，TCP 不会保护数据段的边界。这意味着，当一端连续发送了两个小数据段，另一端接收到的可能是一个大数据段，如果一端发送的是一个大数据段，TCP 为了防止 IP 对报文进行分片，可能会把数据段拆分成多个数据段，具体的拆分由 TCP 三次握手时协商的 MSS(Maximum Segment Size) 字段控制。同时诸如 TCP_NODELAY 和 TCP_CORK 等套接字选项也会影响具体的分段策略。俗称粘包和分包的问题，其就来自于此。

### 1.3.2 序列号和确认号

TCP 使用序列号来标识每个数据段的顺序，同时使用确认号来确认已接收的数据。这两个机制有助于维护数据的顺序和完整性。

### 1.3.3 拥塞控制

TCP 具有拥塞控制机制，它可以根据网络的拥塞情况来动态调整数据的发送速率，以避免数据丢失或堆积。

值得注意的是，TCP 的拥塞控制算法较为的保守。一旦发生了丢包，传输速率会直接掉到最低速率，这也是通常下载的时候，下载速率突然掉的很低然后又提高的一个可能原因。

## 1.4 C 语言中的 TCP 编程

1. 创建套接字
   在 C 语言中，可以使用 Socket API 来创建 TCP 套接字，套接字是网络通信的端点，用于建立连接和数据传输。
2. 绑定和监听（服务端）
   一旦创建套接字，可以将套接字绑定到本地地址和端口，并使用 listen 函数监听连接请求，等待客户端的连接。如果
3. 建立连接
   在服务端，使用 accept 函数来接受客户端的连接请求，建立 TCP 连接。在客户端，使用 connect 函数来连接到指定的服务器。一旦连接建立，可以使用套接字来进行数据传输。
4. 数据传输
   数据传输可以使用 send 和 recv 函数来发送和接收数据。发送方将数据分割成小的数据段并发送，接收方按顺序接收和组装数据段。在 Linux 中，socket 本身也是一个 file descriptor，它也可以使用标准的文件操作来传输数据，例如 read、write 和 sendfile。实际上，对于 blocking 的 socket，还可以使用 fdopen 函数转成 C 的 FILE* 然后使用 stdio 的格式化输入输出函数来传输数据。
5. 断开连接
   使用 close 函数来关闭 TCP 连接，这将触发四步挥手的过程，确保连接的正确关闭。

这些是关于 TCP 的基本概念、功能和在 C 语言中的编程实现。
TCP 作为一种可靠的协议，在网络通信中扮演着重要的角色，确保了数据的可靠传输和顺序传递。
